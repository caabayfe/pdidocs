    1. Requesting a knowledge base NEW

    1. Request Knowledge Base creates a kb_knowledge_base_request; open to everyone, in the Service Catalog and the Technical Catalog. E02
    2. Request new Knowledge Base starts on create. E03
    3. It asks one fixed user for approval, the default admin account, and emails A new Knowledge Base has been requested. E04
    4. Approved: Create KB makes the knowledge base with the requester as owner, and the requester gets Knowledge Base request approved; rejected, Knowledge Base rejected. E04 E05

    glide.approval_engine.kb_knowledge_base_request has no value in the mirror. E06 The knowledge_manager role's description expects knowledge administrators to approve requests; the flow does not. E04 E39 Q03

    2. Creating and editing NEW

    OperationWhoRecord
    CreateisAdminUserE07 E08

    Rules on save, in order of effect:

    1. Duplicate Knowledge Base: unique titles. E09
    2. Populate Default Flows if Empty (insert): the instant flows; the legacy workflow fields are inactive, so Validate Flow Engine selection does not run. E13 E14 E15
    3. Set mandatory fields: a data policy per knowledge base for its mandatory article fields; only admin can change the list on the form. E17 E18
    4. Validate Weightage: the checklist's weights must total 100. E22 E40
    5. Validate Standard Template Usage: the Standard template can't be disabled while articles use it. E20
    6. Update knowledge_manager roles (after): grants and revokes knowledge_manager. E10 E11 The form warns before saving. E12

    On articles: Inherit commenting and suggesting copies the knowledge base's settings to new articles E19; Change workflow when KB changes re-runs publishing when an article in Review moves to another knowledge base E16; Article Validity sets the default Valid to. E21

    Approvers are the owner and managers: ownership groups are off, so the Knowledge Center's Ownership Groups lists are unused. E36 E38

    4. Diagnostics NEW

    • Knowledge Center: the page User Criteria Diagnostic runs KBDiagnostics for a user and a knowledge base or article; its data broker needs knowledge_manager or knowledge_admin. E33 E34
    • Classic: Run User Criteria Diagnostics related links on knowledge bases and articles open user_diagnostics.do. E35

    5. The Knowledge Center's administration lists NEW

    The Administration group (order 500) has no roles of its own: what each user sees follows the tables' ACLs. E37
