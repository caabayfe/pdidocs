    3. Set up and maintain a shift

    For: Shift manager, On-call administratorWhere: Service Operations Workspace, the classic incident formChecked against pdi2 on 2026-10-20 (mirror fcd5bcad66af)

    When to use this page NEW

    A group needs a shift before anyone in it can be on call. This page is for the people who set one up and keep it right: the group's shift manager and the on-call administrator. Members who only want to see their own shifts or ask for time off should read Your shifts, preferences and time off.

    On pdi2 today NEW

    No group has a shift on pdi2: the list of shifts is empty E01, and no group has on-call preferences E03. Q01 Everything below describes how to create the first one. Nothing is on call until a shift is published.

    Who can set up a shift NEW

    You areYou can
    On-call administrator (rota_admin)create, change and delete any group's shift; open Create / Edit Schedule in the navigator E04 E06
    The group's managercreate shifts and manage your group's shifts, from My Group Schedules › New E05 E06 E07

    The wizard only offers the groups you manage. E08

    Create a shift with the wizard NEW

    Transcript (6 steps)
    1. Start. Open create or edit schedule, or new on my group schedules. In the first step, select the group, name the shift, and set its days and times. You only see the groups you manage.
    2. Members. Add one or more rosters, such as a primary and a backup, with their members in the order they take turns. Each roster rotates weekly unless you change it.
    3. Escalation. Choose the catch-all: one person, everyone on a roster, or the group manager. They are told when nobody accepts.
    4. Review. Check the members and the escalation. The shift is saved as a draft, so nobody is on call from it yet.
    5. Publish. On the shift, choose publish. The shift is now live, and its rosters decide who is on call.
    6. Trigger. Finally, add a trigger rule, so that work assigned to the group starts the on-call subflow. On pdi2 there is none yet.

    Download the video (MP4)

    Open On-Call Scheduling › Create / Edit Schedule (administrators) E04, or My Group Schedules and New (group managers) E05 E07. The wizard has four steps; Next Step and Previous Step move between them, and Save keeps your work. E02 Q24

    1. Define Schedule. Select the group E02, name the shift and say when it applies: from a schedule template, or with a start and end time, the days it repeats and a time zone. You can add a holiday schedule. Reminders start switched on, two days ahead. E08
    2. Members. Add one or more rosters (for example a primary and a backup) and their members in the order they take turns. Each roster rotates weekly by default; you can choose daily, weekly or monthly, how often, and the date the rotation starts. E08
    3. Escalation Setup. Choose the catch-all: who is told last when nobody accepts. The escalation itself is explained in Set the escalation and trigger rules. E08
    4. Review And Publish. Check each shift's members and its escalation: Rotate through members (one roster), Rotate through rosters (several), or Custom. E08

    The shift is saved as a draft, and the form says "This Shift is in Draft State. Click on Publish to make it live." E09 E10 If its times overlap another of the group's shifts, the wizard refuses it: "Cannot create the shift, The selected schedule overlaps with the '…' rotation schedule." E09 E31

    Change the members of a roster NEW

    Open the shift, then the roster, and use the buttons above its member list. On pdi2 these are Add, Remove and Move, which keep the rotation balanced; the older Edit… list is not offered. E14

    The group's preferences NEW

    On-Call Scheduling › Group Preferences (administrators and rota_manager) holds one record per group. E27 E29

    Default means the instance-wide setting. E30 On pdi2 that is: no overlapping shifts E31, and members can't create their own time off E32, so a shift manager records it for them. Q05 To let a group's members ask for time off, set PTO approval preferences for that group.

    Keep it healthy NEW

    • Each week, on-call administrators and each group's manager receive a report of the gaps and conflicts in the schedules of the groups with a live shift. E34 E35
    • A shift made before the 2024 schedule engine shows Migrate Now: "This shift will be upgraded to new schedule engine. Do you want to continue?" New shifts already use it. E09 E33
    • Group Templates keep a set of shifts you can reuse for several groups. E36 Q13

    Tips

    • Build the shift as a draft, check the calendar, then publish: nothing is on call while it is a draft. E09 E11
    • Set the escalation before you publish, so that urgent work does not reach only the first person.
    • When someone leaves the team, use Remove with the date they stop, rather than editing the list, so the rotation stays even. E19
