    The engine is the 2011 one, synchronous; the old engine is off. E19 E20 E21 The 2010 business rules on task_sla (Pause SLA, Resume SLA, Run SLA calculation, Set planned end time) are active but guarded by the engine version, so they don't run. E24

    Incident SLA Flow - Incident Communication Task serves communication tasks, not incidents: 75% and breach events for Communication Due Warning and Communication Overdue. E12 See Communication plans - configuration.

    3. Timers in the workspace NEW

    1. The route Record Information puts a side panel tab on the record page. E26 Its screen applies to saved incidents and interactions. E27
    2. The data broker SOW Record Information calls SOWIncidentInfo.getRecordInfo() when the user can read the incident. E28
    3. getSLAConfig names two timer configurations; getSlaInfo counts the task SLAs for View all SLAs. E29
    4. Each configuration maps the four priority SLAs of its kind, in priority order; completed SLAs and actual time are shown, cancelled ones aren't. E30 E31 SLATimerSNC prefers a running, then a paused, then a breached task SLA. E32

    The OLAs and the underpinning contract are in no mapping, so they only show in the Task SLAs list. E30 E31 sn_slm_timer's own Incident Response and Resolution Team maps all eight priority SLAs and isn't used by the panel. E33

    Open questions OPEN QUESTION

    1. The flows' If steps (for example "only if there is an assignee") aren't in the mirror; who gets the warnings on an unassigned incident? E10 E11
    2. Is the 50% warning to the CI's Supported by wanted, given that no breach email follows it? E11 E16
    3. Should the OLAs and the underpinning contract show in the workspace timers? They are in no timer mapping. E30 E31
    4. The two ATF definitions are active on incident, but start only on incidents whose short description begins "ATF SLA Incident". E07 E08 Can they stay, or should they be inactive outside test runs?
    5. The SLA definition that runs the communication task flow isn't in the mirror. E12
