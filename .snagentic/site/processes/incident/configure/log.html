    Dictionary defaults: category inquiry, impact 3, urgency 3, priority 4. Only task.company is mandatory in the dictionary, so company may be required on save even when the form doesn't show it. Q73 The display rule VIP scratchpad reads the assignee's VIP flag, not the caller's. E11 Q46

    Copy Incident NEW

    The records in the order they run in the Service Operations Workspace:

    StepRecordWhat it does
    1. Shownaction assignment Copy Incident (sn_sow_inc)roles itil or sn_incident_write, views sow and aitsm, IncidentUtils.isCopyIncidentEnabled(); no record condition, so closed incidents too E12
    2. Placedform action layout itemMore actions (overflow), order 300 E13
    3. Dialogthe action's client scriptasks for a caller; offers Include attachments when the incident has any E14
    4. CopyIncidentUtils2SNC.makeIncidentCopybuilds the record from the attribute list, sets the caller, adds the work note, inserts it if the user may create incidents E15
    5. After insertIncidentUtilsSNC.copyIncidentAttachments, copyIncidentRelatedListscopies attachments (the dialog's choice) and the configured related lists E15 E16

    Properties (read and written by incident_manager E17):

    Propertypdi2Effect
    com.snc.incident.copy.enabletrueshows the action E17
    com.snc.incident.copy.attributesnot in the mirrorfields to copy; script default below E18 Q53
    com.snc.incident.copy.attachtrueInclude attachments ticked by default E19
    com.snc.incident.copy.related_listsnot in the mirrorrelated lists to copy; none by default E20 Q53

    Script default fields: assignment_group, business_service, category, caused_by, cmdb_ci, company, description, impact, location, parent_incident, problem_id, rfc, short_description, subcategory, urgency, priority, service_offering. Fields such as number, watch list, close code and notes, opened by and at and domain are removed from any list. E16

    The classic form has its own UI action, in the form's context menu only: it opens an unsaved, prefilled form, and copies parent incident, problem and change only when they are active, with the work note "Created from a similar incident". E21 E16 The workspace path doesn't make that active check, so a copy can point at a closed problem or change. E15 E16 Q23

    The two ATF tests for Copy Incident are inactive. E22 Q47
