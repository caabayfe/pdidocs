    Agent Assist on pdi2 is Contextual Search: a keyword search over tables. It uses neither AI Search E21 nor Predictive Intelligence. E14 E15 E51

    1. The Agent Assist tab NEW

    1. The route Agent Assist puts the tab in the record page's side panel, order 300. E01
    2. The screen Agent assist SNC shows it for incident and eight other tables. Its configuration maps each table to a search configuration. E03 A client script picks the right one. E04
    3. For incident: Agent Assist [incident] in sn_sow_inc. It applies only to active incidents, has no required roles, and offers a source selector. E05

    No role restricts the tab beyond the workspace itself. E03 E05

    2. What it searches NEW

    The search term is the short description E06, at least 3 characters E53; 10 results a page E05 E54. The context Incident Deflection (SOW) E07 Q26 has these sources:

    OrderSource (resource context)Search resourceRecords
    defaultKnowledge & Catalog E07searcher: knowledge, pinned knowledge, catalog interleaved E20knowledge E08 E14; catalog, all catalogs E09 E15
    100Outages E10GlideRecordSearchResourcecmdb_ci_outage, last 6 months E19
    200Incidents E11GlideRecordSearchResourceincident, last 6 months E17
    300Open Incidents E12GlideRecordSearchResourceactive, last 3 months, not under an accepted major incident E16
    400Resolved Incidents E13GlideRecordSearchResourceresolved or closed, last 3 months, six resolution codes E18

    The ML resources Similar Incidents, Similar Open Incidents, Similar Resolved Incidents and Similar Knowledge Articles exist but are not in this context. E51

    3. Actions on results NEW

    Each source has its own cxs_ui_action_config records under Agent Assist [incident]:

    ResultActionsNotes
    Knowledge, pinned articleAttach, Flag Article, Full View, HelpfulAttach writes an embedded link into comments E28; Flag only where the knowledge base allows suggestions E29
    Catalog itemOrder, Request, Submit, Helpfulby the item's request method
    Open, recent and resolved incidentsLink to Incident, Copy Resolution, View Full, HelpfulLink sets parent_incident on the current incident E22 E23; Copy Resolution needs a resolution code or notes on the result E27
    OutageLink to Incident, View Fullinserts task_outage; itil or sn_incident_write E26

    Two REST operations are named link_incident: the global one E23, and the sn_sow_inc one with a dialog for work notes and comments, which only answers action ids containing "rest". E24 Its execute ACL allows itil and sn_incident_write. E25 The Agent Assist action id is link_to:link_to_incident. E22 Q71

    4. Recommendations NEW

    1. The screen Recommended Actions Default serves the Recommendations tab for saved incidents and nine other tables. E30 Its condition calls canViewRAPanel: itil or sn_incident_write for incident. E31
    2. The Incident context evaluates its rules synchronously, refreshes every 15 minutes and searches with the short description. E32
    3. Rules: AI Search (itil) E33, Active non-child non-MI Incident E34 and Active incident E35.
    4. Recommended actions: only AI Search Recommendation is active. E36 The three based on the CI and service are inactive. E37 E38 E39
    5. AI Search Recommendation takes the top 5 AI Search results for the short description E40, from a search configuration that uses the ai_search engine. E41 Results are mapped to guidances: an article to Attach and share article E42, an incident to Show genius result E43 or [Task] Link incident, and the same for problems, changes, outages and catalog items. E44

    On pdi2, nothing reaches the panel: glide.ais.enabled is false. E21 To use it, switch AI Search on and index the sources, or activate the CI and service recommendations, which use scripted generators instead. E37 E38 E39 Q04

    5. Predictive Intelligence NEW

    Solution definitionpdi2
    Similar Incidents (and Similar Open, Similar Resolved, Similar Knowledge Articles)definition active, retrained every 90 days E48
    Incident Assignmentinactive E49
    Incident Categorizationinactive E50

    The mirror holds the definitions, not the trained solutions, so it can't show whether any model was ever trained. Q62 Nothing in Service Operations Workspace's Agent Assist uses them: no source in its context has an ML solution E14 E15 E51, and the PI recommendation Common Incident Resolutions is attached to the older table configuration E45 E46, used only by the Agent Workspace action. E52 Q25 Even there, it needs an active trained solution. E47
