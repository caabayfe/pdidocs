    2. Use a standard change

    For: Change requesterWhere: Service Operations Workspace, the classic incident formChecked against pdi2 on 2026-10-20 (mirror 9f3658cfb43d)

    What's available

    Standard changes are routine work done the same way every time, already approved. Find them on Create a change request or under Change › Standard Change › Standard Change Catalog, in Network and Server standard changes. E01 E02 E08

    NetworkServer
    Add network switch to datacenter cabinetReboot Windows Server
    Change VLAN on a Cisco switchportDecommission local office Domain Controller
    Clear BGP sessions on a Cisco router

    Replace printer toner also shows, but it is a template for automated tests. E07

    Use one

    Transcript (5 steps)
    1. Find it. Find the standard change in the catalog, under network or server.
    2. Fill it. The description and the plans come from the template and can't be changed. Complete the assignment group, the justification, and the risk analysis.
    3. Approved. Submit it. A standard change is approved at once.
    4. Scheduled. It goes to scheduled. Carry on with the implementation.
    5. Propose one. If you do the same normal change often, propose it as a standard change template. The change manager approves proposals.

    Download the video (MP4)

    Choose it. The description and the implementation, backout and test plans come from the template and are read-only; make sure the required Short description, Assignment group, Justification and Risk and impact analysis are filled E03, and submit. It is approved at once E04 and goes to Scheduled: carry on with Schedule and implement.

    Propose a new one

    When you do the same normal change often, propose it as a standard: Propose a Standard Change Template from a change's menu E05, or the catalog item Propose a new Standard Change Template. E06 The Change Management group approves proposals. E09

    Tips

    • Look for a standard change before raising a normal one: it needs no approval. E04
    • The plans come prefilled from the template and can't be edited: if they don't fit, raise a normal change instead. E03
    • Don't use Replace printer toner: it is a test template. E07
