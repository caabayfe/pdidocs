    4. Share a workaround and known error

    For: Problem coordinatorWhere: Service Operations Workspace, the classic incident formChecked against pdi2 on 2026-10-20 (mirror fcd5bcad66af)

    Share the workaround

    Transcript (5 steps)
    1. Write it. Write the workaround in the analysis information section, and save.
    2. Communicate. Choose communicate workaround.
    3. Teams. Every open linked incident gets a work note. It is internal, so tell callers yourself where it applies.
    4. Known error. To publish it, create a known error article. It starts with the problem statement, the cause, and the workaround.
    5. Published. Once saved, it becomes the problem's primary known error article, and linked incidents get a note naming it.

    Download the video (MP4)

    On the classic problem form:

    1. Write the Workaround in the Analysis Information section and save. E01
    2. Choose Communicate Workaround (related link or form menu). You see "Workaround communicated". E01
    3. Each linked incident still open gets the work note "Workaround shared from PRB…: …" with your text. E02

    The note is internal: tell callers yourself where the workaround applies to them.

    Publish a known error

    1. Choose Create Known Error article (related link or form menu). E03 E08 A new article opens, already filled with the problem statement, description, cause notes and workaround. E04
    2. Complete it and save. You see "Known Error article … created"; it becomes the problem's Primary Known Error article. E05
    3. Linked incidents get the work note "Known Error article created against PRB…: KB…". E06
    4. Publish the article through knowledge as usual.

    What happens next

    Keep the workaround current while the cause is worked on; when the fix is ready, see Fix and resolve. Attaching the article to other incidents links them to this problem (see Link incidents to a problem).

    Which knowledge base

    Known error articles go to the knowledge base named in problem.knowledgebase.known_error_article, whose value only problem managers can read. E07 Which knowledge base that is, and whether employees can find known errors in Employee Center, is not known yet. Q13 If they can, employees could be pointed to them while they wait.
