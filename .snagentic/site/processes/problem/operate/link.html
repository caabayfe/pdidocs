    2. Link incidents to a problem

    For: Service desk agent or resolver, Problem coordinatorWhere: Service Operations Workspace, the classic incident formChecked against pdi2 on 2026-10-20 (mirror d13485ddb833)

    Link from the incident

    Transcript (5 steps)
    1. From the incident. Link from the incident side. Open each incident and go to related records.
    2. Set Problem. Set the problem field. On pdi2 the problem form doesn't list its incidents.
    3. On hold. If only the problem can fix it, put the incident on hold, awaiting problem. An incident that is only linked stays with its team.
    4. Resolved. When the problem is fixed, the incidents waiting for it are resolved for you.
    5. Shortcut. A shortcut: attaching the problem's known error article to an incident links it to the problem.

    Download the video (MP4)

    Open each incident and set Problem in its Related Records section, on the classic form or in the workspace. E01 E02 The problem form doesn't list its incidents, so link from the incident side. E03

    Only a problem coordinator can link a closed incident. E06

    Put the incident on hold

    If the incident can only be fixed by the problem, set its State to On Hold with the reason Awaiting Problem. E04 When the problem is fixed, it is resolved for you (see Fix and resolve). An incident that is only linked, not on hold, stays with its team.

    A shortcut through knowledge

    Attaching a problem's known error article to an incident links the incident to that problem. E05
