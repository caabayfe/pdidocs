    Raising - configuration

    Technical referenceReviewed 2026-10-17Checked against pdi2 on 2026-10-20 (mirror fcd5bcad66af)Operator guide: Raise a problem

    Models

    Models are on E01: new problems get General E02, whose transitions replace the older state model, which now covers only problems without a model. E03

    Assignment

    Only problem coordinators can be assigned E04, and the assignee must be in the group. E05

    No other way in

    Problems can only be created from Problem › Create New: interactions can't E06, the major incident flow is inactive E07, and the workspace's Create problem on incidents points to a UI action the instance doesn't have. E08 Whether that is intended is not decided yet. Q02

    Open questions OPEN QUESTION

    • Q02 Is it intended that problems can be raised only from Problem › Create New, and not from interactions, the major incident flow or the workspace's Create problem on incidents? Decision, for the process owner
