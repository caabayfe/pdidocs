    4. Discuss a request with colleagues

    For: Fulfiller, Service desk agentWhere: Service Operations Workspace, the classic incident formChecked against pdi2 on 2026-10-20 (mirror 9f3658cfb43d)

    When to use a discussion NEW

    A Sidebar discussion is a chat about one record with the people who can help: another fulfilment team, a specialist, the requester's manager or the person the order is for. It works on requests, requested items and catalog tasks as it does on incidents; the steps are in Discuss an incident with colleagues. This page says what is different for requests.

    Messages stay in the discussion, not in the work notes. When it settles something, write the outcome in the Work notes of the task or item.

    Start one on a request, item or task NEW

    Transcript (6 steps)
    1. Pick the record. Open the record the conversation is about: the catalog task for the work, the requested item, or the whole request. Each discussion belongs to one record.
    2. Open it. In the side panel, open collaborate, choose plus, then start sidebar discussion.
    3. Who. On a request, the dialog suggests who opened it, who it is for, and its assignee. On items and tasks there are no suggestions, so search for the people yourself.
    4. Start. Check the subject, write a short message, and start the discussion.
    5. Record it. When the discussion settles something, write the outcome in the work notes, where the next team will look.
    6. No email. You can add the person the order is for, but on pdi2 they get no email about the discussion. Tell them in the additional comments.

    Who can read it NEW

    Anyone who can open the record can see its discussions that aren't private; only members can write in them. E14 E15 The person an item is for may be able to open it, so keep a discussion Private when it must stay between colleagues. E02

    Tips

    • If you add the person the order is for, tell them in the item's Additional comments: they get no email about the discussion. E11
    • Start the discussion on the catalog task when it's about the work, so the team that owns the task finds it under This record. E02 E06
    • Put the decision in the work notes, where the next team will look.
