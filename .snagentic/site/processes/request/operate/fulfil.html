    1. Fulfil catalog tasks

    For: FulfillerWhere: Service Operations Workspace, the classic incident formChecked against pdi2 on 2026-10-20 (mirror fcd5bcad66af)

    Find your work

    Transcript (5 steps)
    1. Queue. In the workspace, open the catalog tasks assigned to you, or to your groups.
    2. Hardware. Most hardware goes first to procurement, then to field services to deploy it to the user.
    3. Work it. The task shows the item, who it is for, and the answers. Record progress in work notes, then press close task.
    4. Complete. Closing the last task lets the item complete.
    5. Reassign. To reassign a task, use the workspace. The classic form has no assignment group field.

    Download the video (MP4)

    In the Service Operations Workspace, open Catalog tasks › Assigned to you, or Assigned to your groups to pick up your team's. E01 E02 Most hardware goes first to Procurement ("Please fulfill this order"), then to Field Services ("Please deploy item to the user"). E07 E08

    Take a task: Assign to me NEW

    Before you start, make the task yours, so nobody works it twice.

    1. Open the catalog task in the workspace. Assign to me shows in the header while the task is open, nobody is assigned to it, and its assignment group is empty or one of yours. You need the itil or sn_request_write role. E11 E12 Q19
    2. Press Assign to me. Assigned to becomes you and the task is saved. E13
    3. If the task had no assignment group and you belong to one group only, that group is set too. If you belong to several, the group stays empty: set it yourself. E13 E14

    What follows: nobody is emailed. The "Task … has been assigned to you" email isn't sent when you assign yourself. E16

    WhereAssign to me
    catalog task header, workspaceyes, as above E11
    catalog task lists, workspaceno: the list action covers incidents, problems and changes only E15
    classic list, right-click menuyes, for anyone who can edit the task; it doesn't check the group E17 Q06

    The membership check on save runs only when the group changes E18, so from the classic list you can end up assigned to a task of a group you're not in. Use the workspace header instead.

    Work a task

    1. Open the task from the list. It shows the requested item, who it's for, and the requester's answers to the item's questions. E03
    2. Set State to Work in Progress and record progress in Work notes. E09 E03
    3. Finish it one of three ways:
    YouHowThe task becomes
    did the workpress Close Task E04Closed Complete E10 E06
    can't do itset State to Closed Incomplete, say why in Work notes, saveClosed Incomplete E09
    it isn't neededset State to Closed Skipped, saveClosed Skipped E09

    Close Task shows only while the task is open and not waiting for approval. E04 Closing the last task lets the item complete. What the item does when a task closes Incomplete or Skipped isn't verified yet. Q20

    Reassign it

    Change Assignment group (and clear Assigned to) in the workspace form, then save. E03 Classic form: the catalog task form has no Assignment group field: reassign from the workspace. E05

    When the item is out of stock

    On the Procurement task ("Please fulfill this order"), pull the item from stock or order it from the vendor. If it has to be ordered, open the requested item, tick Backordered and set the Estimated Delivery date, as the task's description says. E08 The item then shows Backordered, and a task "Please close this task once the backordered item arrives" waits for you: close it when the item arrives. E08

    What happens next

    When Procurement closes its task, Field Services gets "Please deploy item to the user". E08 When the last task is closed, the item completes and the request closes after its items (see The life of a request).

    Tips

    • Pick from Assigned to your groups and press Assign to me on the task before you start, so nobody works it twice. E02 E11
    • To work a task out with colleagues in real time, start a discussion (see Discuss a request with colleagues).
    • Read the requester's answers before you order: they say which options to add. E03
    • Problem with what was delivered? Ask them to report an incident (see Report an incident).
