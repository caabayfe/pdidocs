    3. Manage a request

    For: Service desk agent, FulfillerWhere: Service Operations Workspace, the classic incident formChecked against pdi2 on 2026-10-20 (mirror d13485ddb833)

    You manage requests from the Service Operations Workspace: find them, cancel them, add items to them while they wait for approval, and answer their approvals.

    Find it

    Transcript (5 steps)
    1. Find it. Find requests under open requests and open items in the workspace.
    2. When. While a request is pending approval or approved, you can still cancel it.
    3. Cancel. Cancel request closes it, and its items' tasks close with it.
    4. Add an item. On the classic form, add new item adds another item while the request waits for approval.
    5. Approvals. IT approvers find request approvals under my approvals, as for changes.

    Download the video (MP4)

    1. In the workspace open Requests › Open requests for whole orders, or Open items for each ordered item. E01 E02
    2. Open the request to see its items, state and approvals.

    Cancel

    1. Open the request. Cancel Request shows in the header (or as a classic form button) while the request is pending approval or approved. E03
    2. Press it. The request becomes Closed Cancelled. E03

    What follows: its flows are canceled with the note "Due to request cancellation by …" E07, its items' tasks close E04, and the request becomes inactive with the closing time and who closed it. E08

    Add an item

    1. Open the request on the classic form while it waits for approval. E05
    2. Press Add New Item. The Add Catalog Item window asks the item and the quantity. E05
    3. Choose them and confirm: the item joins the request.

    Add a catalog task by hand NEW

    Transcript (5 steps)
    1. Open the item. Open the requested item in the workspace, and go to the catalog tasks list in its related records.
    2. New. Press new. It shows while the item is active, and only to catalog administrators, who may create catalog tasks.
    3. Fill it. The new task opens with the requested item already set. Add a short description and an assignment group, and save.
    4. Told. The group is emailed that the task has been assigned to it.
    5. The flow. The item's flow waits only for the tasks it created, so the item can complete while your task is still open. Close yours first.

    Download the video (MP4)

    The item's flow creates the tasks it needs, one after another. E14 Add a task by hand only for extra work the flow doesn't know about, such as a check by another team.

    Only catalog administrators (and admins) can do it: New needs the right to create catalog tasks, which itil and sn_request_write don't give. E10 E11 Fulfillers and agents ask a catalog administrator.

    1. Open the requested item in the workspace and go to Related records › Catalog Tasks. E09
    2. Press New. It shows while the item is active. E10
    3. A new catalog task opens with the Requested item filled in. E10 Give it a short description and an Assignment group, and save.

    What follows: the task is linked to the item and its request, and its start time is set. E12 The group is emailed "Catalog Task … has been assigned to group …" while nobody is assigned. E13

    How the item's flow treats your task:

    Your task
    holds up the flow's next taskno: each flow step waits only for the task it created E14
    holds up the item's completionno: nothing in the mirror waits for it, so the item can complete while it is still open E14
    when the item is cancelledclosed Closed Incomplete, with the flow's tasks E15

    Close your task before the flow's last task, or the item may be delivered while it is still open.

    Copy a request NEW

    Use it when the same order is needed again, for example for a second person. Only admins and catalog administrators see Copy; service desk agents don't. E16 E17

    1. Open the request in the workspace or on the classic form. Copy is in the header. E16 E19
    2. Press Copy. If some of its items are no longer offered in the catalog, you're warned "Some items are inactive and will not be copied". E17 If none is offered any more, Copy doesn't show. E16 E17
    3. "Request copied successfully" shows, and the new request opens. E18

    The workspace describes it as copying "the request and all its related records", leaving out items whose catalog item is inactive. E19 The copy itself is done by the platform, not by a script you can read E18: check the new request's items, quantities and who it is for before it goes on.

    Approvals

    IT approvers find request approvals under Approvals › My approvals, as for changes (see Approve as a technical approver). E06

    Tips

    • Look at Open items first: Cancel Request stops every item in the request, not just one. E03 E04
    • Write the reason in the request's comments before you cancel, so the requester knows why.
    • Add New Item only works while the request waits for approval E05; after that, the requester orders the extra item separately.
    • Don't copy a request to change it: copy it when the same order is wanted again, and cancel the old one if it is no longer needed. E03 E18
