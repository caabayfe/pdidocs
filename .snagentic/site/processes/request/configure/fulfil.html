    Fulfilment - configuration

    Technical referenceReviewed 2026-10-19Checked against pdi2 on 2026-10-20 (mirror d13485ddb833)Operator guide: Fulfil catalog tasks

    Assign to me on catalog tasks NEW

    StepRecordWhat it does
    1. ShownUI action Assign to me (sn_sow_itsm_common, table task) E08, in the SOW views only E09, placed in the catalog task header by its layout E10condition canAssignToMe: active or new task, itil or sn_request_write, Assigned to writable and empty, group empty or the user a member E11
    2. Pressedits client script E12 with getMemberGroups E13fills the group when it is empty and the user has one group; asks for a group only when the field is mandatory; sets Assigned to; saves
    3. SavedAbort changes on group E16checks membership only when the group changes
    4. ToldEmail assigned to (sc_task) E17not sent: the assignee is the sender and send to self is off

    The group dialog shouldn't appear on pdi2's catalog tasks: no UI policy, data policy or dictionary override in the mirror makes Assignment group mandatory on sc_task. When the group is empty and the user is in several groups, only Assigned to is set, and Email assigned to group doesn't fire either. E12 E18

    Lists: the workspace list action is overridden for the SOW view by one whose condition excludes sc_task E14; the classic list keeps a right-click Assign to me for anyone who can write the task, with no group check. E15

    Engines

    The request flow handles the approval over $1,000 E02 (the legacy approval engine is off E03); most items use Service Catalog item request E01. The request closes after its items. E04

    Rejected task approvals

    Reject Parent (on catalog tasks, after insert and update, order 100) only covers tasks from legacy execution plan approvals: when such a task is rejected and its approval step is set to cancel on reject, the item gets the stage Request Cancelled and is rejected. E07 Flow-based items don't use it.

    Gaps OPEN QUESTION

    • Items still point to inactive execution plans such as IT Service - General. E05
    • Eight service items use a flow described as a demo that creates no tasks. E06
    • Some items name legacy workflows the mirror doesn't hold, and nine have no fulfilment at all.

    Check what happens when each of these is ordered.

    Assign to me OPEN QUESTION

    • Should Assign to me be offered in the workspace's catalog task lists, as it is for incidents? It would need an override of canAssignToMeOnList. E14
    • Should the classic right-click Assign to me, which skips the group check, stay on sc_task? E15
