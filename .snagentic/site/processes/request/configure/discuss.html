    Sidebar discussions on requests - configuration

    Technical referenceReviewed 2026-10-19Checked against pdi2 on 2026-10-20 (mirror d13485ddb833)Operator guide: Discuss a request with colleagues

    What is the same NEW

    Sidebar, its access rules, its notifications and its properties are shared by every task table; they are described in Sidebar discussions - configuration. This page covers what differs for sc_request, sc_req_item and sc_task.

    1. Where the Collaborate chat shows NEW

    TableVisibility recordRule
    sc_request, sc_req_itemContextualPanelRequestVisibility (sn_sow_req) E01 E02Sidebar supported for the record
    sc_taskthe default of sn_uib_collab E03Sidebar supported, saved records only

    The data broker that loads the panel's chats runs for itil, sn_incident_write, interaction_agent and sn_change_write E04, and sn_request_write contains neither those roles nor sn_uib_collab.user E05. A fulfiller with sn_request_write but not itil can't load the panel's chats; the header's Sidebar isn't limited by these roles.

    The classic form's Open Sidebar discussion button is on every task table. E13

    2. Suggestions and groups NEW

    TableSuggestedGroup with on-call shifts
    sc_requestOpened by, Requested for, Assigned to, on-call user of the group E06whole group E07
    sc_req_item, sc_tasknone E06whole group E07

    3. The requester NEW

    Requesters may be added: the property is true E11, so Exclude requester from sidebar discussion doesn't apply to requests and items. E10 But the only requester mapping is for incident E08, and the Sidebar emails find their recipient through it E09. On requests, items and tasks nobody receives "You have been added to a discussion" or the daily unread digest. Sidebar Discussion Started is for incidents only as well. E12

    To email the person an item is for, add an active sys_cs_collab_chat_requester record for sc_req_item with requested_for (and for sc_request, requested_for). E08 E09

    Open questions OPEN QUESTION

    1. Is Sidebar enabled per record for sc_request, sc_req_item and sc_task? The mirror can't show it; the Collaborate icon was seen on a requested item.
    2. Should sn_request_write load the Collaborate chats? It would need the role in the data broker ACLs E04, or itil for every fulfiller.
    3. Should requesters be emailed about discussions on their items? E08
