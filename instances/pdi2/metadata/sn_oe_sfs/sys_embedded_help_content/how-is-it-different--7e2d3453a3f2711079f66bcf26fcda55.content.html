The inclusion of Now Assist in Virtual Agent means no admin is required to manage Natural Language Understanding (NLU) models. Built-in generative AI capabilities means Now Assist leverages the underlying gen AI and search engine to address user queries. This streamlined experience helps admins quickly set up Virtual Agent setup, with basic configuration complete in minutes, using content in the ServiceNow platform. You can further extend this content-driven experience by building and enabling Now Assist topics capabilities.
