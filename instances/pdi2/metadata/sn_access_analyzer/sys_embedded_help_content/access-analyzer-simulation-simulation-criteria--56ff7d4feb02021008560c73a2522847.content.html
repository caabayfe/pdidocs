Simulation Criteria

The Simulation Criteria page helps you to take control of your simulation experience by handpicking your simulation criteria. You can fill the following fields for your simulation: 

  • Select user - Select a user from the list. For example, ITIL User.
  • Select role - Select a role from the list. For example, incident_manager.
  • Rule type - Rule type is auto populated as table.
  • Select table - Select the table from the list. For example, Incident.
  • Select record - Select the record from the list.
  • Select field - Select the field from the list.
