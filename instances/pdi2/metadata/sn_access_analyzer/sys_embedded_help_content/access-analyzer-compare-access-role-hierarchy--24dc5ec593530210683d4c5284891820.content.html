Role Hierarchy

A role hierarchy shows the access permissions that defines who have the right to access specific resources. The hierarchy of access permissions is based on a set of ACLs which determines who has the right to access what.

FAQs

How to read the results on the showing role hierarchy page?

The showing role hierarchy page displays the role that is assigned for user 1 and user 2. You can understand the role that is required for the user for a particular ACL operation. 

How can I see the details of the user? 

You can select the User (node) > More actions > View user details to know more about the user. 

How can I see the details of the role?  

You can select the Role (node) > More actions > View role details to know more about the role. 

How can I see the details of the resources the role can access?  

You can select the Role (node) > More actions > View all the resources that the role has access to know     the resources the role can access. 

How can I see the details of the group?  

You can select on the Group (node) > More actions > View group details to know more about the group.
