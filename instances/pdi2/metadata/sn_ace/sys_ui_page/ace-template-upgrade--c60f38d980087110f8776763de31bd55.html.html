Template Upgrade from V2 to V3

  1. From Ace builder click on "Upgrade Template" button this will modify the page composition
  2. After clicking on "Upgrade Template" preset and controller will get added to your page.
  3. "beforePageLoad" client script we need to move to success event of 'ace default controller'
  4. We need to add dependency for 'ACEClientScriptUtils' in "beforePageLoad" script
  5. We need to replace all api.state.blockcontext and api.state.contentBlocks from client scripts and use aceutils getContext ,setContext, getContentBlocks and setContentBlocks methods.
    6. Please reach out to our support channel for any details.
