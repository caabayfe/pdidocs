Create a Report

ServiceNow provides many intuitive reports, but creating your own is easier than you think. Let's create a report that groups all open Incidents by assignment group, stacked by priority. This will tell us which groups are dealing with the high priority issues.

Navigate back to Reports > View / Run and click the Create a report button to open the report builder. Change the Table to "Incident", the Type to "Bar", the Group by field to "Assignment group", and the Stacked by field to "Priority". Click the Run button to see the results.

The report immediately tells us that there are five critical Incidents that haven't been assigned to a group yet - definitely something to fix quickly! And creating this report from scratch took less than a minute. To save even more time running this report in the future, give it a name and click Save. Now when you go to Reports > View / Run, your new report will be there. If you made it globally available before saving it, everyone in your organization will be able to run it.
