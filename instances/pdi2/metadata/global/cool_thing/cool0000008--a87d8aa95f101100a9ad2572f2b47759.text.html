Configure a Form

At ServiceNow, we design our forms to be clear and concise. We try to include the fields you need and only the fields you need. We realize, however, that every organization is unique*. With that in mind, we make it easy to configure forms.

To see how, navigate to User Administration > Users, and click New. You'll see an empty "User" form, ready for input. Say, for example, your organization decides it doesn't want to use photos in the user records. In that case, it would make sense to remove that field from the form.

To configure any form, right-click the form header and select Configure > Form Design. On the left you'll see a list of available fields, while on the right you'll see the layout of what is currently on the form. You can drag and drop to add/remove fields or move them around. You can even create new fields right here. Click Save when done.

 

* except the one that isn't...
