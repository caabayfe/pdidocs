Right-click Filtering

Now that we've looked at using charts to filter data, let's try an even easier way to get that same list of high priority Incidents. Navigate back to Incident > All to see the complete list of Incidents. Right-click on a Priority 2 Incident's Priority value, and select "Show Matching".

Voila! Conversely, you could have viewed everything except Priority 2 Incidents by selecting "Filter Out" instead.
