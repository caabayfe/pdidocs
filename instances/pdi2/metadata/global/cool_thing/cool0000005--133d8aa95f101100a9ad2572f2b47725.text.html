Quick Filters

How about a third easy way to distill your data, using a filter to see all Priority 1 and 2 Incidents? Navigate back to Incident > All. Click the filter toggle next to the list breadcrumbs to expand the current filter conditions (there aren't any).

Where you see "-- choose field --", set the following condition: Field = "Priority"; Operator = "is one of"; Values = both "1 - Critical" and "2 - High" (hold down the Ctrl key on the keyboard to select multiple values).

Click Run when finished. The result is a filtered list of all Priority 1 and 2 Incidents. To save this filter so you could quickly run it anytime, you would have clicked "Save...", given the filter a name, set the visibility, and clicked Save.
