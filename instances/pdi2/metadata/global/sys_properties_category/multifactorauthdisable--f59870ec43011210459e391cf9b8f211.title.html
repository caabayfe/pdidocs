MFA (Multi-Factor Authentication) is a crucial security measure that safeguards user accounts from potential threats like stolen credentials, credential stuffing, password spraying and phishing attacks. It plays a key role in reducing the risk of unauthorized access, thereby enhancing the security of your data and systems. We highly advise against turning off MFA. Instead, you can modify the MFA context policy to customize MFA enforcement. For more detailed guidance, please refer to the FAQ section of this MFA Implementation Guide.
