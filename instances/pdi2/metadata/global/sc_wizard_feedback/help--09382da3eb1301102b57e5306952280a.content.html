Preprocessing extension

Server script to perform data cleanup or manipulation on the issue before it is processed by machine learning APIs. The preprocessing script is available only when the Advanced setting is enabled.

Postprocessing extension

Server script to perform additional actions on the results from machine learning APIs. The postprocessing script is available only when the Advanced setting is enabled.
