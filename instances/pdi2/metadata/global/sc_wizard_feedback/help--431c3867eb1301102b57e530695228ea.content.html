Follow up sequence

Defines how to deliver deflection content to your users.

All - Delivers deflection content to the user on all available response channels.

First match - Delivers deflection content on an active channel where the user is available, in the order defined by the Response Channels list.

Response channels

List of available response channels to deliver deflection content.

When  followup sequence is set to First match, the response channel order determines the channel used to reach the user. Adjust the order number to change the priority sequence.

Email properties must be set up to set Email as an active channel.

Glide Virtual Agent plugin is required and Virtual Agent notifications must be enabled to set Chatbot as an active response channel.

Email properties must be set up to set Email as an active response channel.

Twilio Notifiy must be configured to set SMS as an active response channel.
