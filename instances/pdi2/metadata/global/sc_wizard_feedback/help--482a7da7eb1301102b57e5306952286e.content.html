Use SLA engine

Auto resolution reminders

Contains the list of reminders and the Email and SMS templates used to deliver the reminders.

Specifies the SLA percentage at which to send the reminder using the Email and SMS templates.

To send auto resolution reminders, Use SLA engine must be set to true.

Note : SMS Notification template is only available when the Notify app is installed.

Task SLA

Duration for which an issue is assigned to IAR before it is automatically reassigned to a live agent if not yet resolved.
