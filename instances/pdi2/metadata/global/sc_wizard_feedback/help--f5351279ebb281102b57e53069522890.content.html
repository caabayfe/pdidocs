Table

Name of the table for which the Issue Auto Resolution must be processed.

IAR invocation

Select how IAR must be triggered for the case. Setting the value to Business Rule will trigger IAR as soon as the case is created and API will require the IAR to be triggered on-demand using the API.

Assigned to

The assignee for the case while the case is being processed by IAR.

Requester

The user requesting assistance on the issue.

Task SLA

Duration for which the issue needs to be assigned to IAR Assigned to the user before it is assigned to an agent for assistance.

Task assignment template

Template applied to the issue that sets the fields and values necessary when it is being assigned to the IAR assigned to the user.

Task completion template

Template applied to the issue that sets the fields and values necessary during the interim state, while the matched topic conversation flow runs.

Task resolution template

Template applied to the issue that sets the fields and values necessary when the end-user indicates that the issue is resolved with IAR.

Unresolved task template

Template applied to the issue that sets the fields and values necessary when the end-user requests agent assistance.
