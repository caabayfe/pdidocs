• Configure auto-populate when you want the value of a question to change dynamically whenever the requester changes another dependent question.

  • For example, you might want to auto-populate the manager, or department question as soon as the requester user is selected or changed.

  • You can select a reference question type only as a dependent question.

  • After you select the reference question on which the current question depends, select the field which contains the value you want to set for the current question.

  • After configuring, check out the item preview to see your question values populate automatically on changing the dependent question value.
