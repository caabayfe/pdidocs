Runs a client-side test script entirely in the browser, with no server-side execution required.

The test script has access to the following APIs:

  • screen — DOM and accessibility query API (getByRole, getByText, findByRole, queryByRole, etc.) and screen.waitFor() / screen.debug()
  • user — standard user interactions: user.click(el), user.type(el, text), user.keyboard(keys), user.tab(), user.clear(el), user.selectOptions(el, values), user.hover(el), etc.
  • sn_atf — utility APIs:
    • Navigation: sn_atf.navigate(url), sn_atf.reload(), sn_atf.goBack(), sn_atf.goForward()
    • Page evaluation: sn_atf.evaluate(fn, arg?) — runs fn in the tested iframe's JavaScript realm and returns a Promise with the result
    • Impersonation: sn_atf.impersonate(userId) — accepts sys_id or user_name
    • Upload: sn_atf.upload(source), sn_atf.uploadInSP(source, table?, id?), sn_atf.uploadInWS(source, table?, id?), sn_atf.uploadInSCVariable(source, varName), sn_atf.uploadInSPVariable(source, varName, opts?) — source is a sys_id string or a File object
    • Attachment fetch: sn_atf.getAttachmentFile(sysId) — returns a File object via REST API
    • DOM wait: sn_atf.waitForElementToBeRemoved(element, options?) — waits until an element leaves the DOM; resolves immediately if the element is already disconnected
    • DOM utilities: sn_atf.querySelector(root, selector), sn_atf.querySelectorAll(root, selector) — shadow-DOM-piercing queries; sn_atf.getActiveElement(root?) — shadow-aware focused element; sn_atf.delay(ms) — returns a Promise that resolves after ms milliseconds
  • expect(elementOrValue) — assertions; pass a screen.getBy* result for element assertions (.toBeVisible(), .toHaveTextContent(), etc.) or a plain value for value assertions (.toBe(), .toEqual(), etc.)
  • waitFor(callback, options?) — polls until callback stops throwing; options.timeout (ms), options.interval (ms)
  • steps(stepSysId) — returns the output variables of a previously executed step. Dotwalking is supported: steps('abc123').record_sys_id retrieves a flat output; steps('abc123').assigned_to.department.name traverses reference fields. Returns empty string for unknown steps or unresolvable paths. Use == rather than === for comparisons.
  • params(paramName) — returns the value of a parameter from the active parameter set when running a parameterized test; e.g. params('first_name'). Dotwalking is supported: params('assigned_to').department.name traverses reference fields. Returns empty string ('') when the test is not parameterized or the parameter does not exist. Use == rather than === for comparisons.
  • Synchronous element predicates for use in .find() / .filter() callbacks — all return boolean:
    • State: isVisible(el), isHidden(el), isEnabled(el), isDisabled(el), isChecked(el), isPartiallyChecked(el), isInDocument(el), isEmpty(el), hasFocus(el)
    • Properties: hasClass(el, ...classes), hasAttribute(el, name, value?), hasText(el, text), hasValue(el, value), hasRole(el, role), hasStyle(el, styles), hasFormValues(el, values), hasAccessibleName(el, name), hasAccessibleDescription(el, desc), containsElement(el, child)
    Example: const visible = (await screen.findAllByText(/^Number$/)).find(el => isVisible(el));

Return a Promise from the test script to signal async completion. Synchronous scripts auto-resolve. All element interactions (click(), fill(), type(), etc.) return Promises — use await.
