ToDo this
Add a skill
  1. In the skill matrix, click Addskill that you want to add to the agent.
  2. In the Skill level field, select a level for the skill.
  3. Click OK. The skill gets automatically added to the agent.
Update a skill level
  1. In the skill matrix, select a skill level for an agent.
  2. Select the skill level that you want to add for the agent.
  3. Click OK.
