FieldDescription
OperatorMathematical comparison operator that qualifies how the hit count triggers an alert of this kind. This field is automatically set to Bigger Than.
Hit countNumber of matching log entries that serve as the trigger for an alert of this kind.
Time periodPeriod of time over which the hit count is measured. The period is measured in the units specified by the Time unit value.
Time unitUnits of the time period. This field is automatically set to minutes.
PersistenceTime period over which the specified hit count per unit time must persist in order to trigger an alert of this kind. The field is automatically set to 1 minute.
