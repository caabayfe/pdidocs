ButtonDescription
Create a taskCreate an error task to assign the errors to an individual for further action and track the progress of the task.

When you select Create a task, Cloud Discovery creates an error task for all the errors that are grouped under the same error code. It displays the error task number on the grouped error card.

Retry discoveryRetry discovery on the IP address mentioned in the error.

You can retry the discovery for all the errors or the selected errors only.

Important: You can retry discovery only if the discovery plugin is installed.
IgnoreIgnore the selected error.
