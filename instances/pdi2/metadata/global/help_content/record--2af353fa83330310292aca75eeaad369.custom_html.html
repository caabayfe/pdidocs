ActionDescription
+ Create newOpens new tab for creating a dashboard.
DuplicateCopies current dashboard into a new tab. Window opens for you to name the duplicate.
ShareShares the dashboard with other users, with different permissions. For details, see the "Share a dashboard" topic.
ExportExport the dashboard to Microsoft PowerPoint or PDF. Choose to export a single tab or the whole dashboard. In PowerPoint, each data visualization is a separate slide.
ScheduleSchedule the export of the dashboard. Available only to dashboard administrators.
Printer friendlyOpens a new tab with a printable version of the dashboard.
Clear all filtersClear all filters on the dashboard.
Add to/Remove bookmarksAdds the dashboard to or removes it from your personal bookmarks.
Open recordOpens the dashboard record.
DeleteDeletes the dashboard. You must own the dashboard or be an admin.
