ToolDescription
CMDB HealthCentrally view aggregated health reports for CIs and relationships in your CMDB at a glance and configure CMDB Health Key Performance Indicators (Completeness, Correctness, and Compliance KPIs) and metrics. This tool can help you understand the health of your CMDB. You can then use CMDB remediation tools to remediate issues.

Before use, set up and configure CMDB Health before use.

Additional role requirement: asset or itil.

CMDB Data Foundations DashboardThis dashboard checks that important data is valid and properly configured, and identifies and provides visibility into potential risks in the implementation. Use the dashboard to prevent issues and support continuous effective functioning of the CMDB.

Before use, set up and configure CSDM and CMDB Data Foundations Dashboards and enable the com.snc.cmdb.getwell plugin.

Additional role requirement: asset, itil_admin, or admin.

De-Duplication TasksAccess this list of de-duplication tasks to view and edit existing de-duplication tasks.

When the instance encounters duplicate CIs during identification and reconciliation, it groups each set of duplicate CIs into a de-duplication task for review and remediation.

From a de-duplication task, you can run the Duplicate CI Remediator wizard to reconcile a set of duplicate CIs into a single CI and eliminate the duplication.

Additional role requirement: itil.

CMDB Remediation RulesA list of your existing CMDB remediation rules. A CMDB remediation rule is associated with a task that was created for a failed CMDB health test. A CMDB remediation rule is applied automatically or manually to execute a remediation workflow that you can, for example, use to delete stale CIs.

You must create and publish a remediation workflow before you create a remediation rule. The workflow can be a regular workflow, or an Orchestration workflow, and the table in the workflow needs to match the task type in the remediation rule. Do not configure the workflow with any filter conditions by setting If condition matches to None, so that the filters of the CMDB remediation rule will apply.

You can access this list to create new remediation rules, or view and edit existing rules.
