FieldDescription
Channel StockroomStockroom that you want to link as part of the distribution channel.
RankRank of the stockroom that you want to link. If the distribution channel contains more than one linked stockroom, this rank corresponds directly with the order of linked stockrooms that you can source and transfer assets between. Enter a numerical value, such as 1 or 5. The lower the numerical value is, the higher the stockroom is within the order of linked stockrooms.
ActiveOption that indicates if the linked stockroom is active within the distribution channel.
