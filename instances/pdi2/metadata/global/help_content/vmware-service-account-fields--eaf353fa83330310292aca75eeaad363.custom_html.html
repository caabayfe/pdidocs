UUIDUniversal Unique Identifier (UUID) of the instance.
To access the UUID, do the following:
  1. Open the Managed Object Browser (MOB) for the vCenter.
  2. Select Content > About.
  3. Paste the value of the instance UUID property in this field.

If required, you can select an existing credential and then edit it by selecting the Edit credentials icon (Edit credentials icon.).
