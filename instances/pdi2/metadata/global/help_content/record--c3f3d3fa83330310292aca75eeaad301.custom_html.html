OptionAction and description
Remote Machine

If a robot pool option is enabled, select one robot from the associated robot pool and then select Launch.

Only the robots that have mapped, assigned process robot credentials and are in the Available and Busy states are available.

If a robot pool option isn’t enabled, select one assigned robot and then select Launch.

Only the robots that have an assigned credential group and are in the Available and Busy states are available.

The associated package version opens in the selected robot machine.

Local MachineSelect Launch.

The associated package version opens in the Windows machine (where your instance is rendering), within the RPA Desktop Design Studio.
