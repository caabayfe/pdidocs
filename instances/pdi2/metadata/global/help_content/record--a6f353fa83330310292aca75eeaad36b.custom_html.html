SettingDescription
Show refresh informationDisplay the last time the dashboard was refreshed under the dashboard title. This information updates when the dashboard is automatically refreshed and when a user selects the refresh button
Scheduled repetitionSpecify in minutes or hours how often the dashboard is reloaded.
Enable data cacheShorten the load time on page refreshes for data visualizations based on table or indicator data. Also applies to indicator scorecards.
Cached expiration timeSet the length of time for cached data to be valid. Options are 1, 2, 4, 8, 12, or 24 hours.
