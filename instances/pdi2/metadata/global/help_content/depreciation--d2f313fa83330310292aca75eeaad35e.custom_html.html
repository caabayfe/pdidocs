FieldDescription
DepreciationDepreciation method that is applied. Base system choices are Declining Balance and Straight Line. The depreciation value is defaulted from the associated Model.
Residual dateNumber of days that have passed since the Depreciation effective date.
Depreciation effective dateDate on which the specified depreciation method begins.
Residual valueValue in the Cost field with the depreciation method applied.
Salvage valueEstimated value of an asset at the end of its useful life. This value must be less than or equal to the Cost of the asset.
Depreciated amountAmount the asset has depreciated.
