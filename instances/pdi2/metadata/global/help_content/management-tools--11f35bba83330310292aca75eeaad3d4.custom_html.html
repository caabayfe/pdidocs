ToolDescription
CI Class ManagerCentrally view, create, or edit basic class definitions and class settings for Identification and Reconciliation (IRE) and CMDB Health.

You can't use the CI Class Manager to manage non-CMDB tables.

Additional role requirement: itil or personalize_dictionary.

CMDB Data ManagerCentrally create, edit, review, publish, and track Data Manager policies and the tasks generated by the policies.

CMDB Data Manager helps you bulk manage CI life cycle operations, such as deletion, retire, and archival. Use these life cycle policies to mitigate performance issues in your CMDB by reducing the number of stale and unneeded CIs.

CMDB GroupsA list of your currently configured CMDB groups. A CMDB group is a collection of CIs that lets you apply CI actions collectively to all members of the group.

Access this list to create new CMDB groups, or view and edit the records of existing CMDB groups.

Dynamic CI GroupA list of your Dynamic CI groups. A Dynamic CI group is a dynamic grouping of CIs that is based on some common criteria. For example, you can create a dynamic CI group based on the location of all web servers in Detroit or all Oracle databases in Boston.

Access this list to create new dynamic CI groups, or view and edit the records of existing groups.

De-duplication template libraryA list of your de-duplication templates, organized by template library. The libraries enable you to structure and organize templates. For example, you can create a library for Computer [cmdb_ci_computer] and ensure that the templates in the library cover different conditions for matching de-duplication tasks.

Access the library to manage de-duplication templates and libraries or create a new template.

De-duplication dashboardCentrally view your de-duplication templates, sorted by Ready, Running, and Completed. De-duplication templates use a single action to apply a consistent remediation to multiple, similar, de-duplication tasks. A template also contains conditions that tasks are matched on.

Access the De-duplication dashboard to run a template and remediate assigned tasks, or to view the De-duplication insights pane.
