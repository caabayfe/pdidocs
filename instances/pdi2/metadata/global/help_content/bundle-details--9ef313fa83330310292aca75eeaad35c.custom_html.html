FieldDescription
Display nameName of the asset as it appears in the record lists. Automatically set when the asset is created, based on Asset Tag and Model fields.
Model categoryModel grouping of the asset. Based on the model category selected, the asset can be linked to a configuration item.
ModelSpecific product model of the asset.
Asset tagAlphanumeric information assigned by your organization to help track the asset.
Serial numberSerial number of this asset.
StateCurrent state of the asset, such as On order or In use.
SubstateCurrent substate of the asset, such as Available or Reserved. The values in the Substate list change based what you select from the State list.
Assigned toPerson using or mainly responsible for this item. This field appears only when In Use is selected from the State field.
LocationCurrent physical location of the asset.
StockroomName of the stockroom. This field appears only when In stock or Build is selected from the State field.
DepartmentDepartment to which the asset belongs.
Managed byPerson who maintains the asset. This person can be different from the person in the Owned by field.
CompanyCompany or organization to which this asset belongs.
Owned byPerson who has financial ownership of the asset. This person can be different from the person in the Managed by field.
Asset functionFunction of the asset such as Primary, Secondary, Shared, Loaner, or Asset Bundle.
ParentParent asset of the asset. For example, a monitor or peripheral can have a workstation as its parent asset. When a parent link is defined, the fields related to assignment and state of the child assets are set to read-only and are populated based on the parent assignment and state fields.
InstalledDate on which the asset was installed.
AssignedDate on which the asset was assigned to a user.
CommentsMessage to add if any.
