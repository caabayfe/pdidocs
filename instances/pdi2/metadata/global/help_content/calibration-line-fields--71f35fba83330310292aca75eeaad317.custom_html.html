FieldDescription
Details
InstrumentInstrument that you are using to perform the calibration. If you specified an instrument model in the Instrument model field of the corresponding calibration attribute, the options in this field are filtered based on the specified instrument model.
Calibration dateDate and time at which you are performing the calibration. This field populates automatically based on the date and time at which the Details lane was marked as complete. You can overwrite this field if needed.
Readings
Expected valueValue that you are measuring tolerance conformance against. This field populates automatically based on the expected value that you specified in the calibration attribute.
Note: This field appears only if you set the Value type of the calibration attribute to either Accuracy % full scale, Accuracy % point, or True/false.
As found valueValue that you measure prior to the calibration.
As left valueValue that you measure after the calibration.
