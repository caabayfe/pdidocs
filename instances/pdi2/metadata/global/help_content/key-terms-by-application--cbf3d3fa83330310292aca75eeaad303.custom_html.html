Security Posture Control recordConfiguration Compliance recordDescription
PolicyTestA set of conditions used to audit assets.

Policy records (SPC#) are displayed on the Policies list in the workspace.

Test records (CT#) in Configuration Compliance are displayed on fields on Test result records (CTR#) that refer to SPC policies.

AssetConfiguration item (CI)Assets in your on-premise and Enterprise environments that include servers, networks, virtual machines, and so on.

Assets are referred to as a Hardware Asset or a Cloud Virtual Machines in SPC policies.

Configuration items and Discovered items are fields on Test result records that refer to specific assets listed in your CMDB.

FindingTest resultsThe returned results for the audits of your assets.

Examples of Findings might be High-risk combinations or Tool coverage that are displayed on the Findings list in the workspace that are based on a specific policy match.

 Remediation tasks

Remediation tasks (CRG#) or on some pages, Test Result Groups, are created based on grouping rules in Configuration Compliance that organize test results so they can be resolved in bulk. An example of a remediation task might be test results grouped based on CIs that have the same associated vulnerability.
