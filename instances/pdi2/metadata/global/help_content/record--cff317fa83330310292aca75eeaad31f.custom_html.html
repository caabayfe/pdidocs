OptionDescription
View HistoryClick to view the historical data of the metrics along with the time when the data is retrieved on a separate tab.
You can also select a time range from the drop-down options to view the historical data for that specific time range. You can view the graphical representation of the following CI metrics (color-coded) in scatter plots for the selected time range along with the critical threshold values:
  • CPU utilization
  • Disk utilization
  • Memory utilization
Point your mouse device device over a data point (represents specific date or time) on the scatter plot to view the values of the metrics along with the date when the metrics data is retrieved.

Click a data point (represents specific date or time) on the scatter plot to display the data of all the CI metrics on the Metrics snapshot section along with the date and time.

Top processes by CPUView the top processes that are sorted based on the CPU utilization of the processes in the affected CI
Top processes by MemoryView the top processes that are sorted based on the memory consumed by the processes for the affected CI.
Logged in usersView the list of the logged in users in the affected CI.
Installed applicationsView the list of applications installed on the CI.
ServicesView the list of services (device or server) running on the affected CI.
