Search fieldDescription
QueryThe search query.
Tip: The Log viewer uses the Elasticsearch search engine, so you can use any supported search term structure in the Query field.
ComponentLogical component of the application service that generated the event.
Time rangeThe time range to apply to the X-axis when displaying the returned data. The setting that you specify appears in the Start time and End time fields.
Use one of the following methods:
  • Select a time period from the list.
  • Specify a custom range.

    Modify the settings in the Start time and End time fields manually. The selected time range shown in Select range then changes to Custom range.
