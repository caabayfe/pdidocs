ToDo this
Add a skill
  1. In the skill matrix, click Add for the skill that you want to add to the agent.

    The agent's user name and skill gets automatically populated in the user skill record.

  2. Optionally, in the Skill level field, select a level for the skill.
  3. Click Save.
Update a skill level
  1. In the skill matrix, select a skill level for an agent.
  2. Select the skill level that you want to add for the agent.
  3. Click Save.
