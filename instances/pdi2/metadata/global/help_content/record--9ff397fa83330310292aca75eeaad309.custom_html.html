ToDo this
Analyze indicator performanceClick the Performance tab to track and analyze the overall indicator performance for all members in the team.
  1. To analyze the indicator performance for the team, click on an indicator. You can then select a location on the time-series visualization or on an case/incident count in the table to drill down further.
  2. To analyze indicator performance for a team member, click an indicator value for the team member.
Track cases/incidentsClick the Cases or Incidents tab and analyze all cases/incidents that are related to the team.
  • To view the case/incident details, select a case/incident.
  • To view a team member's details, from the Assigned to column, select a team member.
Analyze skills for your teamClick the Performance tab to analyze skills for each agent in your team.
  1. Select an agent for whom you want to analyze skills based on skill-level type.
  2. Do one of the following:
    • To analyze all skills for the agent, click the Skills tab.
    • To analyze skills based on the skill level types associated with the agent, click the Overview tab and in the Skills section, select a score for the skill level type.
