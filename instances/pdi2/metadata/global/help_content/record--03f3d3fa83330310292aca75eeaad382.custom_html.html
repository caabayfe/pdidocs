OptionsDescriptions
AcceptAccept the unassigned walk-up interaction. When you accept, the walk-up interaction record is moved from the Open – Unassigned to My Assigned walk-ups list.

This option is available only for the records in the Open – Unassigned Walk-ups list.

CloseClose the walk-up interaction record when the walk-up appointment is completed.
Re-queuePut the requester back again to queue when the requester isn’t available after the agent or technician accepts the walk-up interaction.
Put on holdChange the interaction status to On Hold if the requester isn’t present for an appointment or if the interaction entails a lengthy process, such as, for example, an OS upgrade.
Continue workingResume working on the walk-up interaction. This option is available only when the status of the walk-up interaction is On Hold.
AbandonReject the Walk-up interaction.
Stockroom consumablesConsume the stockroom inventory assets to fulfill the asset requirements of the requester.
Create incidentCreate an incident from the walk-up interaction.
Create requestCreate a service catalog request from the walk-up interaction.
Create changeCreate a change request from the walk-up interaction.
Create caseCreate an HR case from the walk-up interaction.
Associate recordManually associate any entity record to the walk-up interaction record.
SaveSaves the walk-up interaction data.
