Add a record producer

Types of record producers you can build

A record producer enables users to create task-based records, such as an incident record, in apps you create. It enables a better end-user experience by standardizing requests using a simplified form.

Add a standard catalog item

Types of standard catalog items you can build

A standard catalog item enables users to submit requests for services and offerings.

Add a workspace

Types of workspaces you can build

A workspace creates a place where agents, case managers, help desk professionals, and managers can access tools to help answer customer questions and resolve customer problems.

Add a portal

Types of portals you can build

A portal provides users a site where they can find information, create requests, and complete business tasks.

Add a mobile experience

Types of mobile experiences you can build

A mobile experience enables users to access your application from a ServiceNow native mobile app.
