ResourceDescription
Configure Pipelines and DeploymentsUse the AES Pipelines and Deployments guided setup to step through the initial pipeline setup.
Configure environment credentialsConfigure credentials in your production instance so that the flows used by AEMC can access different instances.
Configure your pipeline environmentsSet up your development, test, staging, and production environments by adding the URLs and credentials used to access each instance.
Configure your pipelineSet up and configure each pipeline by naming it, identifying each of its associated environments, and specifying the order in which apps are deployed between the environments in that pipeline.
Add ATF and instance scan suites for testingAdd your customized test suites as part of an application deployment in addition to the instance scan and Automated Test Framework (ATF) testing suites that are standard in AEMC.
Enable ATF propertiesEnable system properties that allow the ATF suite to run during the deployment process.
Configure your controller instanceIdentify the instance that contains your pipeline deployment flows and all data associated with the pipeline. As tasks in each instance are completed, the controller determines where the next stage of deployment occurs and initiates deployment accordingly.
Add users to the App Engine Admin groupAdd users involved with app deployment to the App Engine admin group.
Managing app deployments using the AEMCThe AES admin can view multiple pipelines and manage applications at all stages of deployment using the AEMC dashboard.
Submit a deployment requestAfter a developer submits an application, a deployment request is created. A deployment request is a record to track the review of submitted applications.
Test your application

The goal of testing is to ensure the viability of your app on the production instance. So, prior to publishing thew app you submitted, test it in a non-production instance.

Publish your appIf your app passes testing, open the deployment request in the AEMC and deploy it to your production environment.
