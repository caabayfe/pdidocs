VisualizationDescription
Horizontal bar visualizationHorizontal bar charts show categories labeled in the y-axis and values in the x-axis. Use to compare nominative categories, especially when you have many categories. A typical use cases is the number of users in different assignment groups.
Vertical bar visualizationVertical bar charts show categories labeled in the x-axis and values in the y-axis. Use to compare ordinal data, especially when there are not too many categories. A typical use case is the number of incidents in different age buckets.
Pareto visualizationPareto bar visualizations help you identify the most important dimension in a large set of dimensions. Columns show data in descending order. A line shows cumulative percentage. Pareto charts contain both bar and line graphs. The bars display the data in descending order from left to right, and the line graph shows the cumulative totals from each category in the same order. The left Y axis is the record count, and the right Y axis is the cumulative percentage of the total number of records evaluated.
