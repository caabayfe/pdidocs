ActionDescription
AttestConfirms that the CI exists.
RejectAttests that the CI doesn't exist or can't be found.

In the confirmation dialog box, enter an explanation and click Proceed.

ExcludeAdds the CI to the exclusion list of CMDB Data Manager attestation policies. CIs on the exclusion list are removed from consideration for all current and future attestation tasks and policies.

In the confirmation dialog box, enter an explanation and click Proceed.

Only CMDB Admins can remove a CI from the exclusion list.

Remove duplicates from taskRemoves the selected CIs from the attestation task and creates a de-duplication task for all selected CIs.

In the confirmation dialog box, enter an explanation and click Proceed.

Only CMDB Admins can undo this action. Perform this action for each set of duplicate CIs.
