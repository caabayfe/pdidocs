FieldDescription
NumberThe unique number identifying the purchase order line item.
Purchase orderThe purchase order record number associated with this purchase order line item.
VendorThe supplier from which this product should be ordered.
StatusThe status of the purchase order line item such as Canceled, Ordered, Pending Delivery, Received, or Requested.
Product ModelThe model of the purchase order line item.
Ordered quantityThe number of product models that were ordered.
Part numberThe identification number assigned to the product model.
Received quantityThe number of product models that were shipped and received. The vendor may have sent multiple shipments.

The received quantity can be larger or smaller than the ordered quantity. For example, you may have ordered five laptops but the vendor sent six.

Product catalogThe product catalog category to which the product model is assigned. For example, Hardware, Software, or Supplies.
Remaining quantityThe number of product models that still must be received to fulfill the ordered quantity.
Request lineThe identification number of the requested item record associated with this purchase order line item.
List priceThe price at which the item retails, not including discounts. If the system creates the purchase order from the service catalog ordering process, the purchase order line item inherits the list price from the associated vendor catalog item. If the vendor catalog item doesn’t have a list price value and you haven’t entered a value, this field is automatically populated with the value from the Cost field.
OrderedThe date and time at which this purchase order line item was ordered.
CostThe cost of a single product model, including discounts. If the system creates the purchase order from the service catalog ordering process, the purchase order line item inherits the cost from the associated vendor catalog item Vendor Price.
Expected deliveryThe date the purchase order line item is expected to arrive in the stockroom identified in the Ship to field on the purchase order record. This field is automatically filled with the value in the Expected delivery field on the purchase order record. This field can be edited when the purchase order line item has a Status of Requested.
Total costThe cost of a single product model multiplied by the value specified in Quantity.
ReceivedThe date and time at which the purchase order line item status was changed to Received.
Stock orderRead only and selected if the related request is using the bulk stock order workflow.
Note: Appears for all purchase order line items when the Hardware Asset Management application is installed from ServiceNow Store.
Short descriptionA few words or short phrase describing the purchase order line item.
Shipment
CarrierName of the carrier for the shipment.
Tracking numberNumber to track the shipment status.
Ship dateShipping date of the shipment.
LocationCurrent location of the shipment.
