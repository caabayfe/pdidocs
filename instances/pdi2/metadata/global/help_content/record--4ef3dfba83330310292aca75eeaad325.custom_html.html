FieldDescription
Aggregation methodAggregation method refers to the method used to calculate the metric data for all the entities. The four choices for aggregation methods are as follows:
  • Sum: The metric data for all entities are added together to create a single score.
  • Average: The metric data for all entities are averaged to create a single score.
  • Maximum: The highest metric data among all entities is used as the single score.
  • Minimum: The lowest metric data among all entities is used as the single score.
Due date offsetNumber of days after the schedule end date when the metric data task becomes overdue. For example, if the frequency of a metric definition is monthly and if the you enter 15 in this field, then the due date for metric data task will be overdue 15 days after the month ends.
DirectionDirection indicates whether the metric is meant to increase or decrease over time. For example, assume that you have a metric called Gender diversity on corporate boards. This metric evaluates the representation of women on the boards of directors of a company. The direction for this metric is to increase over time.
PrecisionNumber of digits behind the decimal separator. These digits represent a more precise value of the number and provide information about its fractional part.
NatureNature determines if the metric is leading (predictive), lagging (measures impact), or current (monitors processes, identifies real-time improvement areas).
  • Leading (Predictive) metric: Is predictive and helps anticipate future outcomes.
  • Lagging (Measures Impact) metric: Measures the impact of past actions or events.
  • Current metric: Monitors ongoing processes and identifies real-time improvement areas.
