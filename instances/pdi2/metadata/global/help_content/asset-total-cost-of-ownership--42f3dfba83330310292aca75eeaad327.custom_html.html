FieldDescription
Reached benchmark TCOThe number of assets that have their TCO more than or equal to the benchmark cost.
Approaching benchmark TCOThe number of assets that have their TCO more than or equal to the benchmark threshold but less than the benchmark cost.

The TCO benchmark threshold percentage is set to 75% of the TCO benchmark cost by default. Use the system property sn_itam_common.asset_tco_benchmark_threshold_percentage to update the benchmark threshold percentage.

For example, if you have set the benchmark as $1000 and the asset cost has reached $750, the asset is considered to be approaching the benchmark TCO.

For more information about the hardware asset field values, see Asset record fields.
