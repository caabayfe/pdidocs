PropertyDescription
Data retrieval configuration
Organization idMuleSoft organization identifier from which API data is imported. If you have multiple organizations, create separate connections for each.

For multiple organizations, create separate connections for each.

Environment filterMuleSoft environments to include in the connection.

For multiple environments, separate them with commas. Only API proxies in the environments listed in the Environment filter property are imported.

If you leave this field empty, the data sources within the connector import API proxies from all environments.

API Manager filterAPI manager instance status filter.

Accepts a single value: active, inactive, or unregistered. When specified, only APIs matching that status are imported.

If you leave this field empty, all APIs are imported regardless of status.

Only deployed API managersOption to import only APIs currently deployed to runtime instances.
Import deployed applicationsOption to collect deployed applications from runtime manager as Data Service Instances.
Collection period (in days)Duration in days for collecting API usage data.
Collect usage dataOption to enable usage data collection to retrieve API usage metrics over a specified duration.
Tags settings
Import tagsOption to ingest tags from the MuleSoft API Manager.
Tag key/value indicatorSeparator for key and value in tags.
