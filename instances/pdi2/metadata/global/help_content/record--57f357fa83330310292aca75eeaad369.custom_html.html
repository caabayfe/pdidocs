OptionDescription
Quarterly (Every 3 months)Schedules Remediation Effort once in every three month.
Note:

If the month you select has only 30 days, the remediation effort is created on that last date of the month.

MonthlySchedules Remediation Effort once in every month.
WeeklySchedules Remediation Effort once in every week.
Note: This option is available starting from the version 19.0 of Vulnerability Response.
DailySchedules Remediation Effort everyday.
Note: This option is available starting from the version 19.0 of Vulnerability Response.
