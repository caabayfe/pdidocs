Feature or toolDescription
Level on mapsYou can configure the default or maximum number of levels on a map. Admins can set default and maximum levels using the unifiedmap.map_search_filter.default_levels or unifiedmap.map_search_filter.max_levels property in the workspace-specific [sn_cmdb_ws_config_property] table. See Configure the default or maximum number of levels on maps.
Endpoint deduplication on mapsYou can configure endpoint deduplications on maps. See Configure endpoint de-duplication on maps.
Number of elementsThe unifiedmap.map_search.max_nodes property in the workspace-specific [sn_cmdb_ws_config_property] table specifies the maximum number of nodes that the app retrieves and displays. CIs in a collapsed group CI are counted. Nodes beyond the specified count don't appear on the map. Default value: 250. See Configure how many nodes can appear on a map.
Note: The unifiedmap.map_search.max_nodes property replaces the deprecated sn_cmdb_ws.node.map.max.edge.count property.
Filtering by non-operational state of CIsBy default, non-operational CIs are filtered out of the map and only CIs in which Life Cycle Stage is Operational or empty appear on maps. When searching for CIs in a map, CIs that are filtered out based on operational state aren't included in the results.

An administrator can set the behavior to show non-operational CIs, or CIs of any combination of Life Cycle Stage values. See Configure CIs to appear based on life cycle stage value.

Related itemsYou can add related items categories and configure what appears on individual cards in the Related items module. You can also configure how related items appear on time lines and in badges.

See Configure how to display related items on the map.

Extended properties for a classUnique extended properties of a class can appear in the Unified Map Attributes panel. While many classes are preconfigured with these extended properties, consider modifying the default settings or globally configure extended properties for additional classes.

See Configure which attributes to display in the Attributes panel.

Map references for CIs with no relationshipYou can configure a Reference relationship type to connect CIs that aren't connected by a relationship. When you connect CIs with Reference, the relationship type is visually represented on the map.

See Configure display of connections to a referenced class.

Class profilesYou can configure profiles to set default map filters and map orientation when you access the Unified Map for a class. This enables you to load the map with the custom view and content that you need.

See Create a class profile of visible layers for classes.
