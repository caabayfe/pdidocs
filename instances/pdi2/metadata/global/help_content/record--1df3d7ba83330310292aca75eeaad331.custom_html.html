ResourceDescription
Create your app using an app templateWhen using an AES app template, use the template's data model as your starting point.

Create a blank table

Create a blank data table manually or extend an existing platform table to create a new blank table.

Use a spreadsheet to add data

Import a spreadsheet to build out your data model with or without importing data records in the spreadsheet.

You can use this spreadsheet import to create a new table, modify an existing table in your application, or create a new table from an extensible table and then modify the table using the imported spreadsheet.

Use a PDF to create data tables

Import a PDF to create the structure for blank data tables in your data model.

Create a data integration

Import specific data records to your app data tables. Import and map records to an existing app data table from a spreadsheet during initial table creation or schedule a regular import.

Modify application data tables

After the data model is created, modify tables in the app data model using Table Builder.
