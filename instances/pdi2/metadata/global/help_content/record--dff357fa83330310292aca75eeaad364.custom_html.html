ToDo this
Add a target
  1. Click the plus (+) icon.
  2. Select For everyone to set a global target or For me to set a personal target.
  3. In the New Value field, enter the value for the target you want to achieve for the indicator score.
  4. In the Target start date field, enter the date you want to start tracking the goal for the target.
  5. In the End review date field, enter the date you want to start tracking the goal for the target.
  6. Click Save.
Update an existing target
  1. Select the target you want to update.
  2. In the New value field, enter a target value you'd like to get your indicator score to.
    Note: This value could be based on the previous target, the average KPI score you want to achieve over a period, a specific value.
  3. In the Target start date field, enter the date you want to start tracking the goal for the target.
  4. In the End review date field, enter the date you want to start tracking the goal for the target.
  5. Click Update.
