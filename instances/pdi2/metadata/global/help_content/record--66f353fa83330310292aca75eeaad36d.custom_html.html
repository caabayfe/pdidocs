Field

Description

NameThe name should be meaningful. If you have editing rights, you can change the name here.
DescriptionThe description should be information that helps other users understand the nature and purpose of the visualization. If you have editing rights, you can change the description here.
Mark as certifiedIf you have a role that lets you certify a data visualization for use in your organization, certify or decertify the visualization here. For more information, see "Certify a data visualization."
Requested byIf a user on the instance requested that you create or edit this visualization, you can name the person here. The user is considered a responsible user. The data visualization is shared with them, with editing rights.
Created by, Last updated byThe users who created and last updated this visualization with the date of creation or update.

Usage

n dashboards

If the visualization is used on any dashboards, the number of dashboards displays here.

The View your dashboards link opens a simple list of those dashboards that you created or were shared with you and that contain this data visualization. The number of dashboards listed can be smaller than the total number of dashboards that contain the visualization.

Shared withIcons for every user who the visualization is shared with. Point to an icon to view the user's full name and the sharing details. For more information, see "Share a visualization" and "Manage data visualization access."
