FieldDescription
ModelProduct model to which the rule applies.
StockroomCurrent physical location of the asset.
ThresholdQuantity that the stock must reach to trigger restocking. For example, enter a threshold of 10 for a laptop computer that should be restocked when inventory drops below 10 in the specified stockroom.
Note: If a stock rule is created for a hardware or software model reaches the threshold limit, a notification is sent to the stockroom manager, and a stock order request is automatically created.
Restocking optionLocation where additional supplies should come from. If Procurement isn’t active, the restocking option is Stockroom only. Otherwise, select one of the following:
  • Stockroom: Creates a transfer order to obtain the asset from another stockroom.
  • Vendor: Sends an email to the stockroom manager to order from a vendor. In addition to the email notification, a purchase order and purchase order line item are created.
Order sizeMinimum order quantity for stockroom transfers or vendor purchases. Hardware Asset Management calculates the smallest multiple of the order size needed to restock the item above the threshold. For example, there are 3 laptops in stock with a threshold of 10 and the Stockroom option selected. If the order size is set to 4, the system creates a transfer order for 8 laptops to exceed the threshold and satisfy the rule (3 in stock + 8 ordered = 11). When restocking from a vendor, an email is sent to the stockroom manager showing the total number of items to order, as multiples of the order size.
ActiveCheck box indicating if this stock rule is active. Clearing this check box prevents the stock rule from restocking automatically.
