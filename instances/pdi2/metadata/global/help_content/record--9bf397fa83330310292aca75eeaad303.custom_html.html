FieldDescription
AgentFirst and last name of the agent. Click the agent's name to view the agent's profile summary.
Service ChannelAgent’s associated service channel, so you know what type of work the available agent can handle. Click the channel to view the list of work items.
Total CapacityNumber of maximum work items that can be automatically assigned to agents (pending overrides).
  • Chat: The default is 4.
  • Incident: The default is 2.
Capacity in useNumber of ongoing work items. Click the score to view the ongoing work of an agent.
UtilizationAgent workload/capacity in percentage. The percentage is calculated from the Total Capacity and Capacity in Use.
Presence StateAgent’s current presence status. For example, Online or Offline.
Can Take WorkAgent's status to accept the work item.
Time in StateAmount of time the agent has been in the current presence status.
