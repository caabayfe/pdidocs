FieldDescription
TitleTitle of the list.
TableSource table for the list data. This is a required field.
Edit fixed filterA filter that the user cannot remove at runtime. Select a saved filter or construct one with the Condition builder.
Edit filterOpens a condition builder to create a query for filtering the list. This filter can be removed by the user at runtime.
ColumnsFields from the named table to display. Use the + Add control to add them.
Group by columnGroup the list by a specific column.
Max rowsMaximum number of rows to display per page. This value input overrides user preferences. For example, if the value input is set to 10, the list always displays 10 records regardless of user preference. To honor user preferences, leave the field blank.
Max columnsMaximum number of columns to display. A value of 0 displays all columns.
Highlighted values configSelects the highlighted values configuration to use for the list. This field is required if you are using highlighted values for the list.
Hide highlighted valuesShow or hide the highlighted values, regardless if the list meets the criteria set.

Default: false

Hide headerOption to show or hide the header.

Default: false

Hide titleShow or hide the title in the list header.

Default: false

Hide record count badgeShow or hide the row count in the list header.

Default: false

Hide refresh buttonShow or hide the refresh button in the list header.

Default: false

Hide "Last refreshed" textShow or hide the text label that displays the time of the last list refresh.

Default: false

Hide column groupingShow or hide the column grouping option and associated declarative actions.

Default: true

Hide column filteringShow or hide column level filtering option.

Default: true

Hide column sortingShow or hide the column sorting controls in grid headers.

Default: false

Hide column personalizationDisables ability to add, remove, or changing the order of columns at runtime in the list.

Default: false

Hide drag-and-drop-columnsAllows a user to reorder a column by dragging it to a different position.

Default: false

Hide dotwalkDisables the dotwalk capability in list personalization. This property is effective only when the Hide column personalization flag is set to false.

Default: false

Hide inline editingPrevents users from editing the list inline.

Default: true

Hide highlight contentDisables the user's ability to highlight text. Use this property in conjunction with search results.

Default: false

Highlight contentSpecifies the text that should be highlighted in the list.
Hide linksRemoves all the links in the list. Reference fields and links will render as plain text.

Default: false

Hide "View All" footerShow or hide View All link at the footer of list.

Default: false

Hide empty-state ImageShow or hide the empty state image for the list.

Default: false

Override word wrap user preferenceOverrides word wrap configured in user preferences and always observes the setting in this property.

Default: false

Word wrapDetermines if the text wraps in all columns of the list regardless of user preference.

Default: false

Max charactersInteger that determines the maximum characters allowed in a grid row cell. Text exceeding this limit truncates.

Default: 4000

Refresh RequestedObject containing a timestamp that can be passed down to trigger a refresh.
