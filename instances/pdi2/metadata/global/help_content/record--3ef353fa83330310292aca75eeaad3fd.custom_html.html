FieldDescription
ActiveSelect to enable delivery of scheduled reports.
ReoccurrenceSelect how often to send the visualization.
Day, Time, other calendar fieldsDepending on how often you chose to send the email in Reoccurrence, specify when you want the email to be sent. Time fields are in HH:MM:SS format.
Omit if no recordsTurn on to prevent the distribution of empty reports.
Use conditionsTurn on to specify a scripted condition for generating the report.
ConditionA conditional script that determines if a scheduled job should run. The last expression of the script should evaluate to a Boolean (true/false) value. This text box appears only if you select Use conditions. For more information about scripts on the ServiceNow platform, see Scripts.
Warning: Conditional scripts for scheduled emails are executed in the sandbox. Therefore, function definitions are not allowed. Some API calls and keywords are also not allowed. For more information, see Script sandbox property.
