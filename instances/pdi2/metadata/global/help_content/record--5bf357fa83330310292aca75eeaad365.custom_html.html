To Do this
View the records associated with the vendor scoreClick Show Records.
Narrow down the display of the data points in the chartClick the Filter icon and add or remove attributes you would like to view or remove from the chart.
View for different time aggregationsFrom the time aggregation list, select an option. The chart displays the average value of the data collected for the selected option.
Compare recordsClick Compare Records and select the dates for which you want to compare the data.
Customize the chartClick Chart options and select the desired options.
View for score for a specified time periodSelect the beginning and end dates from the calendar drop-down.
