FieldDescription
Short descriptionBrief description of the problem task.
DescriptionDetailed description of the problem task.
NumberUnique number to identify the task. This field is a read-only field.
State

State of the problem task.

The field value changes as the problem proceeds from one state to another state. The following states are available:
  • New
  • Assess
  • Root Cause Analysis
  • Fix in Progress
  • Resolved
  • Closed

The State field is read-only.

TypeThis value determines whether the problem task is created specifically to investigate the cause of the problem or is a general task. This field is a read-only field.
PriorityHow quickly the problem task analysts must address the problem task. The following values are available:
  • Critical
  • High
  • Moderate
  • Low
  • Planning
ProblemUnique number of the problem that the problem task is created for.
Due dateDate within which the problem task must be completed.
OrderOrder in which the problem tasks must be associated with the problem.
Configuration itemConfiguration item (CI) that the problem applies to. The CI class of the selected configuration item identifies the type of problem, for example, hardware, network, or database.
Assignment groupGroup to which the problem task is assigned.
Assigned to
Problem analyst to whom the task is assigned to.
Note: To assign the problem task to you, click Assign to me.
Work notesDescription of the work that you do on the problem task.
