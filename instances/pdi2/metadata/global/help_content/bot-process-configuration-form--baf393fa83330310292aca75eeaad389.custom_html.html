FieldDescription
NameName of the bot process configuration that is reused for the bot process that is associated with this configuration record.
Process TypeType of the bot process:
  • Unattended
  • Attended
OrderExecution priority of the bot process:
  • 1: Highest priority
  • 999999: Least priority

This field appears only when Unattended is selected from the Process Type field.

PackageAssociated published package of the bot process.
Package VersionVersion of the active package in use.

Only the published package versions can be associated.

Run Time Threshold (mins)Expected duration for the bot process to run.

This field appears only when Unattended is selected from the Process Type field.

Job Purging (days)Number of days after which the job data is deleted.
