FieldDescription
NameName of the shipping carrier. This field is required.
CompanyCore company of the shipping carrier.
Integration profileProfile for integrating with third-party carrier application.
StatusStatus of the carrier. This field is set to Active by default.
Max wait daysMaximum days that the carrier takes to deliver the shipment.

By default, this field is set to 90. However, you can change the value if necessary.

Note: This field isn’t shown on the form by default. You should customize the list of fields to show this field.

The ITAM: Process integration profiles and stale shipment job uses this field to identify the stale shipments. A shipment record that is not updated by the carrier even after the integration profile job has run for the maximum wait days is marked as stale shipment.

NotesAdditional information about the carrier.
