Create a planning hierarchy record

Role required: admin

Create a record for your custom planning hierarchy. This record acts as a placeholder to define your planning process by adding nodes later.

If you already selected a predefined planning hierarchy, you can skip this step. If not, proceed to the task below.

  1. Select New.
  2. On the form, fill in the fields and submit the form.
