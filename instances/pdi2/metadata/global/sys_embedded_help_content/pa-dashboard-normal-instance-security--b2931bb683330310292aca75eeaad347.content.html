Instance Security Dashboard (PA)

Overview tab

Trends and graphs on the Overview tab are updated every night after the Performance Analytics job is executed at 2:00 a.m. local time.

Non-Compliant Items

Number of security controls that do not comply with the security recommendations.

Total Items

Total number of security controls on the instance.

Hardening tab

Trends and graphs on the Hardening tab are updated every night after the Performance Analytics job is executed at 2:00 a.m. local time.

Mandatory page

Provides the statistics on the mandatory security configuration properties.

Recommended page

Provides the statistics on the recommended security configuration properties.

Optional page

Provides the statistics on the optional security configuration properties.

Instance Security Monitoring

Using the Instance Security Center and dashboards, you can monitor the security compliance score for your instance and detect, protect, and respond to instance-based security events. These functions have evolved over time, and certain rules govern their use in specific releases.

OAuth

Create an OAuth JSON Web Token (JWT) API endpoint to allow external clients to access your ServiceNow instance using web tokens.
