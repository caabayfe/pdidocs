Insights view

The Insights view shows your level of adoption of various CMDB tools, features, and application services. You can use this view to understand the benefits of individual CMDB features and to install CMDB tools and features that you haven't adopted yet.

Role requirement: sn_cmdb_user (CMDB User), or a user role containing sn_cmdb_user (sn_cmdb_admin, sn_cmdb_editor).

The Insights view includes the following tiles:

  • CMDB feature adoption
  • CMDB performance insights
  • Application services
  • Cloud vs Non-cloud resources
