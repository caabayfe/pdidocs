Code quality checks

A code quality check is a process that helps you to evaluate the automation file or script to assess its adherence to coding standards, best practices, maintainability, and overall quality. If you're an RPA release manager or an administrator, you can edit some fields in the code quality check rules.

What you can do on this page

View a list of the pre-defined code quality check rules with their active status and severity.

As an RPA release manager or administrator, you can edit the Severity, Regular Expression, Value, and Active fields in the code quality check rules.
