Activate installed integrations

Activate, deactivate, or delete installed integrations directly from the Installed integrations tab in the connector tiles, saving you time when activating, deactivating, or deleting installed integrations.

Before you begin

Role required: evt_mgmt_integration

Procedure


  2. In the primary navigation, select the Integrations Launchpad icon ().
  3. Select the Installed integrations tab.
  4. In the Installed Integrations tab, select the more actions icon and choose the operation you want to perform.
    • Activate - Activate the integration.
    • Deactivate - Deactivate the integration.
    • Delete - Delete the integration.

Result

The status is displayed on the connector tile.
