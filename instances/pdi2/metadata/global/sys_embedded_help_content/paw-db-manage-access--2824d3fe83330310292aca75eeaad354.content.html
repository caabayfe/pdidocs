Manage access to a shared dashboard

You can change the access rights of persons with whom the dashboard is shared.

Before you begin

Role required: You can share any dashboard that you created. You can share dashboards that have been shared with you, if sharing is allowed. If a dashboard is shared with you as a viewer and sharing is allowed, the people you share it with can only view it; they cannot edit it. Users with the admin or dashboard_admin role can share all dashboards.

Procedure

  1. Select Share.
    Under Manage Access, you see a tile for every user, group, or role that the dashboard is shared with.
  2. Optional: Filter the user tiles.
    1. In Audience type, limit the tiles that appear to show only users, only groups, or only roles.
    2. Enter a partial name of a user, group, or role in the search field.
  3. When you locate the desired tile, expand the list of rights and select the rights to grant.
    You can grant editing rights or only viewing rights. You can give or take away the right to share the dashboard. Lastly, you can remove the user, no longer sharing the dashboard with them.
  4. Select Confirm.

What to do next

To view who the dashboard has been shared with and which experiences contain the dashboard, open the dashboard details.
