Service Graph Connector for Jamf configuration properties

Set configuration properties for the connector.

Import managed application records only
Option to limit the import to managed application records only.
Note: If the Import managed application records only check box is cleared, the default behavior is to import all application records.
Use JAMF Pro API
Option to enable the use of the Jamf Pro API for querying computer records.
Note: When the Use JAMF Pro API check box is selected, the connector uses the Jamf Pro API, which offers pagination of response data and improved performance over the Jamf Classic API.
