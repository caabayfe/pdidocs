Close a case

Close a case at any time, except when it is in the Resolved state.

Before you begin

Role required: sn_customerservice_agent, sn_customerservice.consumer_agent

When you propose a solution for a case, the state changes to Resolved and the customer must accept or reject the proposed solution. When a case is in a state other than Resolved, it can be closed.

Procedure

  1. Select the Details tab.
  2. Scroll to the Closure Information section.
  3. Select a Resolution code.
  4. Enter any relevant information related to the closure in the Resolution notes field.
  5. Select Close Case.
