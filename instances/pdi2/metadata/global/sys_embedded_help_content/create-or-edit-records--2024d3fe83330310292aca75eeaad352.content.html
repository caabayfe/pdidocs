Create or edit records

You can create a new or edit an existing record in the simple list.

Before you begin

Role required: A role with write access to the table that the simple list shows.

Procedure

  1. To edit records, select the tickboxes for those records that you want to edit.
  2. Select either the Edit (number of records) or New button, as appropriate.
    The Edit item pane opens. This pane contains a field for every editable column in the record. If you are editing a record, existing values are ignored. All fields are blank, as when you are creating a new record.
  3. Fill in all required and desired fields.
  4. Select Update.
