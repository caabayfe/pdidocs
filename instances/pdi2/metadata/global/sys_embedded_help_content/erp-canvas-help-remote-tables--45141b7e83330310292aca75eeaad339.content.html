Zero Copy Connector for ERP remote tables

ERP (Enterprise Resource Planning) remote tables in Zero Copy Connector for ERP enable you to view and query data from the ERP system of record on the ServiceNow AI Platform.

Note: Zero Copy Connector for ERP doesn't replicate data into the ServiceNow AI Platform. It mirrors data that lives in the ERP system of record, and remains protected there.

Remote tables are linked to ERP models

Each ERP remote table is connected to one or more ERP models, which link the remote table to the ERP system and other related values. When you build a remote table, you can add any of the fields that Zero Copy Connector for ERP finds when scanning the ERP system of record, which is connected through the ERP model. Scanning for and adding fields ensures that all necessary fields are available, for example, when using the table as a data source when building an app.

The connected ERP model, which is defined on the remote table Details tab, controls the available fields on the remote table. If you change the ERP model for a remote table, the available fields change as well.

Zero Copy Connector for ERP scans the system of record for the ERP model to find all of the available fields that you can add to a remote table. You can view all of the available fields from the ERP system in the ERP model. Using the Manage fields modal to add available columns from the ERP system to a remote table automatically creates them in the remote table.

Limitations of remote tables

To ensure data integrity, you can't create new remote tables in Zero Copy Connector for ERP, but you can clone existing ERP models and extend standard ERP remote tables to customize them.

ERP remote tables have a limit of 1,000 records. If you need a larger amount of data, use an ERP extraction table.
