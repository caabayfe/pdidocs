Creating an Okta integration

Create an integration profile to connect the Okta SSO provider with the ServiceNow AI Platform. Use this integration to view software usage information and optimize stale licenses for all connected SSO applications.

Important: Before you can save and publish the integration profile, you will need to create an Okta OAuth 2.0 application in the Okta Developer Console.
To enable your Okta OAuth 2.0 application to connect with the ServiceNow AI Platform, you must configure the connection and credential information for the application using the connection & credential aliases record associated with your integration profile. To open this record, click the preview icon next to the Connection & Credential field and then click Open Record. When the record opens, click the Create New Connection & Credential related link and then enter the following information:
Name
Name of the connection. For example, Okta Connection.
Connection URL
URL for the connection. Enter https://<yourOktaDomain>.com, where <yourOktaDomain> is your organization domain.
Authorization URL
URL of the OAuth authorization endoint. Enter https://<yourOktaDomain>.com/oauth2/v1/authorize, where <yourOktaDomain> is your organization domain.
Token URL
URL of the OAuth endpoint that retrieves and refreshes access tokens. Enter https://<yourOktaDomain>.com/oauth2/v1/token, where <yourOktaDomain> is your organization domain.
Token Revocation URL
URL of the OAuth endpoint that revokes access tokens. Enter https://<yourOktaDomain>.com/oauth2/v1/revoke, where <yourOktaDomain> is your organization domain.
OAuth Client ID
Client ID that is assigned to your Okta OAuth 2.0 application.
OAuth Client Secret
Client secret that is assigned to your Okta OAuth 2.0 application.

After you publish the integration profile, you can connect your Okta SSO applications with your ServiceNow instance to monitor all users and groups with access to each application.
