Suggested steps generation: Choose inputs

The Suggested steps generation skill helps users generate resolution steps by clustering similar records and analyzing their solutions.

The base input fields for identifying similar records and the rule conditions for filtering them are displayed in this screen. These rule conditions ensure that only relevant and up-to-date records are used.

Select Switch scope if you are unable to edit the conditions.
