Workplace Contracts

Track, filter, renew, and view contract information under Workplace contracts in the Workplace Lease Administration dashboard.

You can renew a workplace contract after you have created it, either when it is approaching expiration, or it has expired. For more information, see Renew workplace contract in Workplace Central.

You can change the start date, end date, or amount to be paid for a contract in active state. For more information, see Adjust workplace contract in Workplace Central.

If a contract is no longer relevant, you can cancel it. For more information, see Cancel workplace contract in Workplace Central.

Use the list actions icon to edit or view additional information about contracts.
