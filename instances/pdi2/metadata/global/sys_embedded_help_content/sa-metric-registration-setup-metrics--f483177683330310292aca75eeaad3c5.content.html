Metric type registration


ColumnDescription
SourceSource of metric data.
Registration ModeDetermines how to process an unknown metric type for the data source that is detected in raw data:
  • Active: A new metric is automatically generated based on the unknown metric.
  • Inactive: The unknown metric is discarded.

For SCOM, value is set to Inactive by default.

Type default modeDetermines if a metric that is automatically generated by the system, is set to be active or inactive.

For SCOM, value is set to Inactive by default.

Generate Missing CIsDetermines how to process CIs in the raw data that could not be mapped to existing CIs:
  • true: Generate a new CI that is based on the raw CI that could not be mapped.
  • false: Discard the raw CI.

For SCOM, value is set to false by default.
