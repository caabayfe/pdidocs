Data visualizations

Create, update, certify, and share visualizations based on tables, indicators, or other data.

Table of data visualizations

The Data Visualizations tab shows you a table of the visualizations you can access, with one of the following filters applied:

All
See all data visualizations that you own or that have been shared with you. If you have the admin or data visualization_admin role, you can see all data visualizations on the instance.
Bookmarked
See all data visualizations that you have bookmarked. To bookmark a data visualization, select a data visualization to open it, then select Bookmark from the context menu ().
Certified
Data visualizations that have been certified for use throughout your organization.
Shared with me
Data visualizations that were shared with you either by their creator or by someone else they were shared with. The person who shared them with you may or may not have granted you editing rights.
Created by me
Those data visualizations that you have created.

You can customize what information you see in the table columns with the Edit columns list action.

List actions

A set of buttons allows you to take the following actions on the Data Visualization list.
Refresh list
There can be a lag in the list of visualizations after you create or delete a visualization. Select Refresh List to update the list.
Copy URL for data visualizations
Copies the data visualizations library URL to the clipboard.
New
Create a new data visualization. When you select this option, a different set of help topics becomes available.

You can also create a new visualization from the context menu in the visualization designer, saving you the trouble of navigating back to this page.
