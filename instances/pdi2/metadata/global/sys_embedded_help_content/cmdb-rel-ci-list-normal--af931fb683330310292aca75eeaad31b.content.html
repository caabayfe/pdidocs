CI relationships

Use the CI relationships table to track the relationships between configuration items in your CDMB. CI relationships can be automatically loaded into the system through the Discovery process or imported from another system.

You can add to automatically discovered relationships, create relationships, or edit relationships for a CI by launching the CI relationship editor from the CI form. As an alternative to the CI relationship editor, in the provides the latest functionality for editing CI relationships. For more information, see Edit relationships in Unified Map.

A relationship in the CMDB consists of two CIs and a relationship type:
  • Parent CI
  • Child CI
  • Type of the relationship that links both CIs
