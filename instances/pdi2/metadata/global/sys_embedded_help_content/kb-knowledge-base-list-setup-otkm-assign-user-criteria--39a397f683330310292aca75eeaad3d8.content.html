Assign user criteria

Role required: knowledge_admin or admin

You can assign user criteria to an OT knowledge base to control read or contribute access.

  1. Open the OT knowledge base record that you want to manage.
  2. Depending on the user criteria you want to set, select one or more of the related lists.
    Can Read
    Users can read knowledge articles in the knowledge base.
    Cannot Read
    Users can't read knowledge articles in the knowledge base.
    Can Contribute
    Users can create, modify, and retire knowledge articles in a knowledge base. Contribute access to a knowledge base also provides read access to all articles in the knowledge base.
    Cannot Contribute
    Users can't create, modify, retire, or read knowledge articles in the knowledge base.
  3. In the selected related list, add the required user criteria.
    • To add new user criteria, click New, fill in the required fields, and click Submit.
    • To add an existing user criteria record, click Edit, move the required user criteria from the Collection column to the Knowledge column, and click Save.
  4. Click Update.
