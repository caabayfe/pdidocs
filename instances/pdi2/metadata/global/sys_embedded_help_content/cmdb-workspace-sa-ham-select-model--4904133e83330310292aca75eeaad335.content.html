Model categories selection

Select key hardware model categories that are most critical to your organization to track initially. Expand gradually as CMDB data quality improves.

To determine which model categories to select, review the count of operational assets under each category in the Hardware Asset Workspace, or consult with your IT Asset Management (ITAM) or Hardware Asset Management (HAM) administrator for guidance. See Hardware Asset Workspace.

From the Available resource and model categories column, you can select resource categories and their corresponding model categories. All the selected model categories appear in the Selected column.

Note: Selecting model categories is required to start the setup process.
