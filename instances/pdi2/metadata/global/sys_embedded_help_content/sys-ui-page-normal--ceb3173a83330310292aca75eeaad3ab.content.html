Create a UI page

Create and display forms, dialogs, lists, and other UI components with a UI page. Use UI pages as widgets on dashboards.

  1. On the form, fill in the fields.
    Name
    Enter a name used to invoke the page via a URL. The name can't contain spaces.
    Direct
    Select this option to exclude the common HTML, CSS, and scripts from the page. This setting requires adding custom CSS and JavaScript to use in the page.
    HTML
    Specify the HTML code to define what is rendered when the page is shown. It can contain either static XHTML, dynamically generated content defined as Jelly, or call script includes and UI Macros.
    Client script
    Create a client-side script for interactive DHTML features after a page is loaded.
    Processing script
    Create a script that runs on the server when the page is submitted.

    With Now Assist for code generation enabled, you can provide text or code prompts to return AI-generated code suggestions and create scripts quickly.

  2. Select Submit.
