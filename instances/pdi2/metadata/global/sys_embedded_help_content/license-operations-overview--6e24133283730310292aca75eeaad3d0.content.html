License operations overview

View and manage all your licenses, discovery, client access, user subscription, and content suggestions lists from the License operations view.

The left hand pane shows all the lists, divided into categories, in your workspace. Click a list to view all its records in the right hand pane. You can further click on a record to view specific details pertaining to the record.
Note: The plugins you have activated on your instance, reflects the display of the lists. For example, if the SaaS plugin is activated, all SaaS related lists such as SAP named user types, SAP price lists, and SSO users are visible.
You can view a list of all records for the following licensing, discovery, client access, and content suggestions categories:
  • software entitlements, software models, entitlement imports and errors, and software lifecycle averages.
  • discovered engineering licenses, discovery models, engineering license servers, software usage.
  • SAP, SSO, and user subscription information.
  • client access to specify the number of devices or users that are accessing a particular version of software.
  • part number and normalization suggestions.
  • IBM licensing and usage details.
    Note: These details are available only if you are tracking and managing IBM licenses using the Anglepoint Elevate integration.

You can also create new records for software entitlements, software models, entitlement imports, software lifecycle averages software usage, SAP named user types, client access, and user subscription.
