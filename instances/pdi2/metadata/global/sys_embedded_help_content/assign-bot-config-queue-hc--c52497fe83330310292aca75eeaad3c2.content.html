Assign a bot process to a queue

Assign a bot process to a queue in RPA Hub so that it can interact with this queue. You can assign more than one bot process to a queue. Any robot that is associated with the assigned bot process can insert the work item, pick the work item, and update the work item.

Before you begin

Create a bot process and a queue. For more information, see Configuring a bot process record in RPA Hub and Create a queue in RPA Hub.

Role required: sn_rpa_fdn.rpa_release_manager or sn_rpa_fdn.rpa_admin

About this task

If the bot process is enabled for the robot pool, then only one queue that is not associated with any other bot process can be mapped to the current bot process.

To associate a queue to a bot process from the related list of the bot process, see c to the bot process from the related list.

Procedure

  1. On the Bot Process Configuration tab, select Add.
  2. On the Available Bot Process tab, select the required bot process.
  3. Select Add.
  4. Select Save.
