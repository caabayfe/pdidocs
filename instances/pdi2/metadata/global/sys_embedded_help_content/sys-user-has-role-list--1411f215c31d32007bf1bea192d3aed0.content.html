Edit the admin list

The admin role can override access control list rules and pass all role checks. It grants access to all system features, functions, and data. Before you go live, verify that the admin role is assigned only to the intended users and is limited to few users.

  1. Review the list of users who have the admin role assigned to them.
  2. To remove a user from the list, click the user name in the list and then click Delete .
    Alternatively, you can delete multiple users at a time as follows:
    1. Select the check box corresponding to the user record.
    2. From the action choice list, select Delete .
  3. To add a user to the list, click New .
