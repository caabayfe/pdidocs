Search for knowledge articles

Search for knowledge articles in the Contextual side panel that can help you resolve a case.

Before you begin

Role required: sn_customerservice_agent, sn_customerservice.consumer_agent

The Agent assist tab in the Contextual side panel displays contextual search results based on text entered in the Short description field on the Case form. These results include knowledge articles and other types of information, such as resolved cases and community content.

Procedure

  1. Select the Agent assist icon In the Contextual side panel.
  2. Select the search resource icon and select Knowledge Articles from the list.
  3. Select a knowledge article card to display the text of the article in the side panel.
  4. Select Attach at the top of the article to display the Attach Article pop-up window.
  5. If desired, add information to the Additional comments field.
  6. Select Attach article.
