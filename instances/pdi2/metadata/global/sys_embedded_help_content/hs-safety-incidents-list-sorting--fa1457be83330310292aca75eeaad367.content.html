Sort and group records in a list

After selecting a list in the List view, you can sort and group the records so that you can quickly find the record you want.

Select a list to display the corresponding list of records. From this list, you can:
  • Sort the records. For example, sort case records by state.
  • Group the records into expandable lists.

Sort the records in a list

  1. Select a column name in the list.
  2. Select the arrow icon next to the column name to sort in ascending or descending order.

Group the records in a list

  1. Point the mouse to a column name in the list and select the more actions icon ().
  2. Select Group by <column name> to group records by the available selections in that field.

    For example, select Group by Location to group records by the location. Records in the list are combined into expandable groups.
