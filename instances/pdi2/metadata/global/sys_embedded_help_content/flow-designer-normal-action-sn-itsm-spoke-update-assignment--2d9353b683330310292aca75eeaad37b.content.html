Update Assignment Group action

Updates the Assignment Group field of a Task record.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Task
Data type: Record

Reference to the Task to update.

Assignment Group
Data type: Record

Reference to the group to assign Task record.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Task
Data type: Record

Reference to the updated Task record.
