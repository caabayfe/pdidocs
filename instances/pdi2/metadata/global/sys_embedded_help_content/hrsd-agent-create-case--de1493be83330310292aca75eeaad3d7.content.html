Create a case

Create HR cases for employees or other individuals that require an HR service.

HR cases are created from requests or inquiries related to HR centers of excellence (CEO).

Create HR case from HR Service Delivery agent workspace

  1. Select the plus sign, and select Create HR case.
  2. Type a name in the search field to verify the user requesting the case and select the user.
  3. Select Next.
  4. Select a COE and an HR Service.
    Note: Your Center of Excellence (COE) selection enables a list of available HR Services.
  5. Select Create case.
