Reservations metrics

Use the Reservations metrics to view or edit the status of current day and pending approval reservations.

The following types of tiles are available. Select the tile to see the list of records.
  • Planned reservations for today: Reservations scheduled for the current day.
  • Reservations with extra services for today: Reservations scheduled for the current day that require additional services.
  • Canceled reservations of today: Reservations canceled for the current day.
  • Reservations pending approval for the coming month: Reservations scheduled for the coming month that require approval.
