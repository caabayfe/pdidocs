Choice

Choices are used in lists for users to select from on forms. Their values can be used in scripts for UI actions, catalog items, script includes, and more. After a Choice record is created, it must be appended to a Choice List if its going to appear on a form.

Element
Which form field that the choice applies to
Language
What language the choice is presented in. For English, use "en." For other languages, use the standard two-letter abbreviations
Label
What the choice says on the form
Value
What value the choice has. Values can be numbers or variable names.
