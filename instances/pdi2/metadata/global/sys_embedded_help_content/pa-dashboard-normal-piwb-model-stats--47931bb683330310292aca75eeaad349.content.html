View your use case model statistics

Find out what shape your machine learning model data is in for your use cases with the Predictive Intelligence dashboard Model Statistics tab. Displayed data helps you better understand your use case model prediction and training statistics.

Gain insight into how many classes, for example, for assignment groups, the model is able to predict from and how many were excluded. You can compare which assignment groups are being trained and which ones are being predicted. Drill down in the dashboard to make decisions on which classes you can tune or which new models need to be trained, based on your data spread.

To understand the class distributions for the predictions model, use the Date filter. This gives you a good indication of how your model performance is diverging in production from its trained performance.
