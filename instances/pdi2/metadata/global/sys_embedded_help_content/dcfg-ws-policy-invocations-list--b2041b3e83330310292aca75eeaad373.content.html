Policy invocations

Shows the execution or invocation activity for all policies.

The following details are displayed:
  • Evaluation time: Maximum, minimum, and average time taken to evaluate and execute all policies.
  • Decision: The total number of decisions and the number of compliant, non-compliant, and compliant-exception decisions.
  • Execution type: The number of standard and test executions.
  • Execution status: The execution status, whether it was successful, pending, or failed.

You can also view these details for each invocation including the start and end time, and the number of times the policy has been executed. Click on the Number link to view the Details page.
