Technology Portfolio: Refresh TPM data

Refresh the TPM data for a business application.

Before you begin

Role required: admin

Procedure

  1. In any TPM table, select a business application name to view the details of the business application in a new tab.
  2. In the business application form, select the three-dot menu (…).
  3. Select Update TPM Data to retrieve lifecycles only on the hardware and software elements composing the business application.
