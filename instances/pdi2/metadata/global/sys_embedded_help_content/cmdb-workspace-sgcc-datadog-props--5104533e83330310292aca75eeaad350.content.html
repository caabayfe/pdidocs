Service Graph Connector for Observability - Datadog configuration properties

Set configuration properties for the connector.

Hosts filter
Host tags entered in the key:value format to import data only from hosts that match the specified tags in Datadog.
Note: For multiple entries, separate the tags with commas. Example: datadog:monitored,env:production.

In the example, the filter includes monitored hosts in the key:value format as datadog:monitored and env:production. Therefore, the data from only these hosts with matching tags are imported.
