Set up a Deflection Configuration

Configure activity patterns for Self-Service Analytics.

Role required: sn_ssa_core.self_service_manager

Use this form to set up a deflection configuration for Self-Service Analytics in your instance. These configurations associate periods of time with activity contexts, which define how long a system waits for a case to be created to match a deflection pattern.

  1. On the form, fill in the fields.
    Name
    Input a unique identifier for the deflection configuration.
    Activity context
    Click the magnifying glass icon and select the type of activities for which you want to collect data. For more information, see Configure activity contexts for Self-Service Analytics.
    Application
    Set the scope of the application that contains the user entity. This field is automatically set based on the application scope selected in the application picker.
    Description
    Input a summary of the configuration.
    Window
    Set the activity context window (duration) for tracking activities that match a deflection pattern.

    Example: To track the create case activity for a consumer within a day, set the window as 1 day.

  2. Click Submit.
