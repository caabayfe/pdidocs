Monitoring your ingested Software Bill of Materials (SBOM) data

The data visualizations on this page help you see a breakdown of applications, containers, libraries, and other types of entities that are included with the SBOMs you ingest.

Regardless of whether you upload them with APIs or manually, data and records on this page update after SBOMs are successfully ingested and parsed. Use the data on this page to see a list of entities (SBOM files) and if they have vulnerabilities.

All BOM Entities
A breakdown of BOM entities by type: Application, Container, Library, and Others. An entity refers to the component for which an SBOM document was generated and uploaded.
BOM Entities with vulnerabilities
Entities that have a vulnerability associated with any component that they depend on. If an entity dependency has one Critical vulnerability, the entity's severity is considered Critical.
Active AVIs
The trend for the number of application vulnerable items (AVI)s created each day.

The trend is the last 30 days. The 30-day range isn’t editable. This data isn’t available until you've reviewed the creation rules for application vulnerable items and set up your AVI creation rules. For more information, see the following link.
