Monitor vendor key performance indicators

Analyze the performance score of the selected key performance indicator.

Before you begin

Role required: sn_vlm.vendor_manager

About this task

You can access the KPI details page when you drill down into a value that you want to analyze in the Performance score by vendor in the last 90 days or Vendor satisfaction by vendor charts in the Vendor Management Workspace homepage.

Procedure

  1. Analyze the vendor score for the KPI.
    View the KPI details for a specific date or the trend for a specific time period:
    • To view the score for a specific date, click the calendar icon for the selected date, select the date you for which you want to view vendor details and click OK.
    • To view the trend for a specific time period, click the calendar icon chart's date field, select the start and end date for which you want to view the trend and click OK.
  2. Analyze vendor score.
