Overlapping usage

Use the Overlapping usage view to get insights into the feature level usage and rationalize your SaaS and Single sign-on (SSO) applications to reduce spending.

The Overlapping usage view groups the spend on your applications into categories based on the main function of the software application, such as video conferencing, project management, email marketing.

Use the Overlapping usage view to do the following:
  • View details of an application usage within your organization.
  • Compare usage of applications within the same product category.
Note: You must install the Domain Extension Installer [com.glide.domain.msp_extensions.installer] and Domain Support [com.snc.pa.domain_support] plugins to view the domain data on the Overlapping usage view.

By selecting the Overlapping applications tab, you can view the following information:

  • Highest count in overlapping software application grouped by application category, which indicates the number of applications in each application category. Selecting an application category bar takes you to the Highest count in overlapping software application page, which includes the number of subscriptions, total spend, and overall usage details of each application in that category.
  • Highest spend in overlapping software application, which indicates your total spend for all the applications in each application category. Selecting an application category bar takes you to the Highest spend in overlapping software application page, which includes the number of subscriptions, total spend, and overall usage details of each application in that category.
  • All software categories that have subscriptions. The number next to each category indicates the number of applications in each category.

By selecting the Application feature usage tab, you can view the following information:

  • A list view of the application categories.
  • Detailed and descriptive feature usage information of an application by expanding an application category, which includes the spend, overall usage, and subscriptions of that application.
  • The SaaS feature usage page that includes the event details for each integration performed by the users, such as the event ID, event name, last activity, subscription, product, subscription profile, and publisher. Navigate to the SaaS feature usage page in the License operations view by selecting the SaaS feature usage link.
    Note: The SaaS feature usage page displays event details for up to one year from the current date.
  • Top five activities with the highest usage based on the number of users.
    Note: The Activities with high usage chart gets replaced by the Users with last login activity chart for SSO applications and the SaaS applications for which only the last login activity is pulled.
  • Top five departments with least application usage in your organization. The usage is based on the number of users. This data enables IT administrators to determine if users within these departments need access and also help drive adoption for those users.
  • Graphical representation of your monthly spending trend on the application.
  • List of reclamation candidates for the application that aren't closed by selecting View reclamation candidates.
