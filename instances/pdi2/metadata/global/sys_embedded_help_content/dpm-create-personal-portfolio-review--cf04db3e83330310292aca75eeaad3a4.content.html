Review items in a new personal portfolio

The final step to creating a new personal portfolio is to review the items that you have added.

Before you begin

Role required: sn_dpm.dpm_manager

Procedure

  1. Review all items that you want to add to your personal portfolio.
    Applications, Services/Service Offerings, and Application Services each have their own tab. Review all tabs. If there are no items listed, then select Back to return to the Add Items page.

    If your selected items are not displayed, then you may not have selected an add option on the previous page.

  2. Select Create.
