Add targets for a KPI to improve indicator performance

Set a specific goal to improve the indicator performance for the selected group.

Before you begin

Role required: pa_target_admin and sn_team_perf.team_performance_admin

Procedure

  1. Select the view targets icon ().
    • To create a new target, select the plus (+) sign.
    • To edit an existing target, select that target.
  2. Select the target type.
    • To set the target for all users in the group, select For everyone.
    • To set the target for yourself, select For me.
  3. Add a target.
    1. From the For the KPI menu, select the target for which you want to set goals.
    2. From the Based on menu, select whether you want to set the preference based on previous target, an average KPI score over a period, or enter a specific value.
    3. Select the calendar icon in the Target start date field, select the start date for which you want to start tracking the goal for the target.
    4. Select the calendar icon in the Target review date field, select the date for which you want to review the set goal.
  4. Set the target.
    • If you are creating a new target, click Save.
    • If you are updating an existing target, click Update.
