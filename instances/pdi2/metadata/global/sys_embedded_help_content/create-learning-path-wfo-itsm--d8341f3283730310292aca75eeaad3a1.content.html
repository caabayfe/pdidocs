Create a learning path in Workforce Optimization for ITSM

Create a learning path, add relevant skills and course items, and publish the path. When your agents complete the path, any skills associated with the path are automatically added to the agent's profile.

Before you begin

Role required: sn_wfo_cfg_ws.manager​

This video walks you through the steps for creating a learning path.

Create a learning path

Procedure

  1. Select the Learning tab.
  2. Navigate to Learning Paths > All learning paths.
    • You can search a path based on keywords using the Search field or narrow down the display of the paths based on skills using the Filter by skill field.
    • When you select a learning path, you can view details such as the path objective, skill associated with the courses in the path, total number courses in the path and the duration to complete them.
  3. Select Create new path.
    The New learning path screen displays.
  4. Fill in the fields on the form and select Next.
    Important: You can customize the publish flow for any catalog other than the Default Catalog.
    The learning path that is created is in Draft state. You can choose to complete it at a later time.
  5. Add or remove course items.
    • You can search courses based on keywords using the Search field or narrow down the display of the courses based on skills using the Filter by skill field.
    • When you select a course, you can preview the details.
      Note: You can add a quiz as a course item.
    1. Enable or disable the check box for the course items that you want to add or remove from the learning path.
    2. Select Add items.
    The Review screen appears. A learning path consists of a list of courses that a trainee takes in a given order. You can drag the courses in the list to set the order in which the trainee has to complete the path. In the Items in the learning path list, the added course items display in the order you have selected them. You can drag and reorder these items.
  6. Review the learning path.
    The skills associated with the selected courses are automatically populated in the Course skills field.
    1. Review and edit any required details.
      You can also add more skills to the learning path.
    2. Optional: To remove items that you no longer want to associate with the learning path, select the item and then select Remove selected items.
      A learning path is comprised of a list of courses that a trainee takes in a given order.
    3. Optional: You can drag and drop the courses in the list to set the order in which the trainee has to complete the path.
    4. Select Next.
      The screen displays the agent view of the learning path. The Publish screen appears. If you do not want to publish the learning path, you can select Save and come back to it at a later time.
  7. Select Submit to publish the learning path.
    The learning path is published based on the Publish flow.
