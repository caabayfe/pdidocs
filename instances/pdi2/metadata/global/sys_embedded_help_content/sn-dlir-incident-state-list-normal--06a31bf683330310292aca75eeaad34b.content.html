Create custom state for Data Loss Prevention Incident Response

Role required:
  • sn_dlir.admin - Create, edit, and delete.
  • sn_dlir.analyst - View (read-only).
Create and configure your own custom states for the DLP incidents. By default, the Data Loss Prevention Incident Response application provides you with the following states:
  • Closed
  • Open
  • In Review
  • Escalated
  • Overdue
  • Responded
  • Draft
  • Reported
You can select one of the default states or create your own custom states based on your DLP incidents.
  1. To create your own Custom state, click New in the DLP Incident States page.
  2. In the State field, enter a name for the custom state.
  3. Click Submit.
