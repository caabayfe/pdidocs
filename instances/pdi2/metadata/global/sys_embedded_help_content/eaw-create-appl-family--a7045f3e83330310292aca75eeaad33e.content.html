Create an application family

Create an application family to group a set of related applications based on the manufacturer classification of their products into product suites.

Before you begin

Role required: sn_apm.apm_admin

Procedure

  1. Select Application Families.
  2. Select New.
  3. Enter a name, description, and domain for the application family.
  4. Select Save.
