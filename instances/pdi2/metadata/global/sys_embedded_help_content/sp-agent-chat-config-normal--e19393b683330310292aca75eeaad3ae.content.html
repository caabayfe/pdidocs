Configure Agent Chat in Service Portal

Your end users can initiate and maintain an Agent Chat conversation in any portal page. Write a script to pass portal-specific data to Agent Chat. For example, pass the name of your knowledge base to a Virtual Agent conversation.

  1. On the form, enter a name for the chat configuration and then fill in the following fields.
    Portals
    The portals in which the chat configuration is used. If no portal is selected, the configuration applies to all portals in the system.
    Order
    A number that indicates in what order chat configurations should run. If there are multiple chat configurations on a portal, the system runs the first configuration found from lowest to highest.
    Server script
    Write a script that passes page and widget data to an Agent Chat conversation when a user initiates the conversation. For example, pass a field to the chat conversation to enable Agent Chat to access the value.
  2. Select Submit.

Customize the agent chat button or pass dynamic page data to Agent Chat using the spContextManager class in a widget client script.
