Data collection configuration

Role required: admin or pa_admin

The admin needs to complete the following steps before others can view the Operational Technology Visibility Dashboard.

  1. Select the check box next to the Active field and set a schedule to start collecting data, or use the Execute Now button to collect data manually so that the data is shown properly on the Operational Technology Visibility Dashboard.
  2. Check if the default schedule collection time works for you.

    The default time is 00:00:00 daily. If you want to change the default collection time, you can change it after activating the job. Please notify users of this change.
