Configure form layout

  1. Using the slushbucket, select the fields that you want display on the form and arrange them in the order in which you want them to appear.
    • To add a field to the Selected column, double-click the field in the Available column.
    • To remove a field from the Selected column, double-click the field in the Selected column.
    • To move a field up or down, select the field in the Selected column and click the up or down icon.
    • To select multiple consecutive fields, hold the Shift key and click the first and the last field.
    • To select multiple non-consecutive items, hold the Ctrl key ( command key on Mac) and click the required fields.
  2. Click Save .
