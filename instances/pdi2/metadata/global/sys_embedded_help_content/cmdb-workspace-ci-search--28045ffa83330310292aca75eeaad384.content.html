Conditional Search

To find CIs quickly, filter by class and attribute. Filtering enables you to view and access the details of a specific CI.

Attributes are specific to the class you select. You can access a CI to view details such as time line, health overview, and attributes.

In addition to any roles required to access CMDB Workspace, the following role requirements also apply.

These CIs require the app_service_user_role:
  • Mapped application service
  • Application service
  • Application service group
  • Dynamic CI group
  • Tag based service
These CIs require the service_viewer_role:
  • Business service
  • Technical service
  • Application service outage
With CI Search, you can:
  • Select New condition set to add a condition phrase.
  • Select Related List Condition to add a condition phrase for related lists.
  • Select Search to search through the CMDB.
