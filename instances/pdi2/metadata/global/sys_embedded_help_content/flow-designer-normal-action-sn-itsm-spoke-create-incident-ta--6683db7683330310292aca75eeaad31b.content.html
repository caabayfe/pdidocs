Create Incident Task on Incident action

Creates an incident task from an incident. The incident task inherits values from the incident.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Incident
Data type: Record

Reference to the incident to create an incident task from.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Incident task
Data type: Record

Reference to the incident task created.
