MID Server status

The MID Server status list displays basic information about each MID Server. If the version is not compatible, the MID Server status is not changed to Down. If this occurs, the MID Server might still appear to be processing commands when it is actually not doing so. Check the Version column to make sure your MID Server is compatible. The list also indicates the compatibility of the logged in user.

The list provides these version compatibility indicators:
Red
Incompatible. The MID Server and instance do not belong to the same release. You must upgrade the MID Server and verify that it is not pinned to an older version with the mid.version.override property. The MID Server cannot be upgraded until the parameter is cleared.
Yellow
Compatible, but an upgrade is recommended. This indicates that the MID Server version belongs to the same family as the instance, but not the same version.
Green
Compatible. No upgrade necessary.
Gray
Incompatible. The instance cannot detect the version.
The list provides these compatibility indicators for the logged in user:
Red
Incompatible. The user does not have the mid_server role or the user does not match the value defined in the mid.instance.username parameter in the config.xml file. Reconfigure the MID Server user and verify its compatibility.
Green
Compatible. The user has the mid_server role and matches the user in the configuration file.
