Create a producer replication set

Create a producer replication set that defines the tables and columns that you want to replicate on consumer instances.

  1. On the form, fill in the fields.
    Bi-directional
    Enables changes to records made on the producer instance to propagate to the consumer instance and vice versa.
    Discrete
    Distinguish consumers for this replication set.

    Define the mapping of each consumer subscription by setting a discrete value.

  2. Click Submit.

Create one or more outbound entries for the producer, and then activate the producer replication set.
