Create a Mobile UI Rule

Role required: Admin.

Use this form to create a new rule to modify the mobile UI in your instance. Examples include hiding and displaying fields, making fields mandatory, performing field value calculations, and applying UI styles to different UI elements.

  1. On the form, fill in the fields.
    Name
    Brief name of the UI rule.
    Active
    Indicates if the UI rule is in use.
    Condition
    Defines when a UI rule should apply. (Syntax should follow platform-encoded query.)
    Parent Table
    Source to apply the UI rule.
    Parent
    Individual record based on parent table.
    Triggers
    When the mobile UI rule is triggered. Select one or both of the following options.
    • onLoad: The mobile UI rule triggers when the record loads.
    • onChange: The mobile UI rule triggers when the record is changed.
    Order
    Order in which the mobile UI rule executes. If multiple rules affect the same element, the rules execute according to this value. Lower numbered rules execute before higher numbered rules.
    Reverse If False
    Indicates if the UI policy actions will reverse, if conditions in the UI policy are unmet.
  2. Click Submit.

After creating your mobile UI rule, you must create mobile UI rule actions to execute when your rule is used.
