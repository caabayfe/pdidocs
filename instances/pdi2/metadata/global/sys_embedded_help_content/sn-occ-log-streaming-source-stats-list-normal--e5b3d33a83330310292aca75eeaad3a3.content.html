Streaming sources

When you start using a data input, make sure log data is streaming to the MID Servers. If it isn't, the configuration may be flawed. The Streaming sources page lets you monitor all endpoints that stream log data to your instance. It lists the data input sources and the MID Servers to which the data is streamed. For each active endpoint that streams data to a MID Server, you can view the average number of log lines per second in five-minute intervals.
