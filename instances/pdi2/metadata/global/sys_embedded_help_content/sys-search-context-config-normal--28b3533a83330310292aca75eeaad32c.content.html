Create a search application configuration

Role required: ais_admin or search_application_admin.

Use this form to create a new search application configuration for AI search. Select a search profile for the application to use. Configure the application's settings for refinement and display of search results.

  1. Fill in all fields on the form.
    Name
    Title of the search configuration.
    Search Engine
    Type of search engine used.
    Search Results Limit
    Maximum number of results returned on a search.
    Search Suggestions Limit
    Maximum possible search completions based on terms entered in the search field.
  2. Click Submit.
The new search application configuration record appears in the Search Application Configurations list.

To use your new search application configuration, select it in the configuration for a ServiceNow AI Platform application that supports AI Search. For more information on these ServiceNow AI Platform applications, see Enabling and configuring AI Search in Now Platform applications.
