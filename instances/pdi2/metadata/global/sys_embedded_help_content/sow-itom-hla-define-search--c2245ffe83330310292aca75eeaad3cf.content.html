Define a search of log data

Define a search of log data to help you determine the cause of a Log Analytics alert.

Before you begin

Role required: evt_mgmt_operator or evt_mgmt_admin

Procedure

  1. On the Log viewer, select the selection icon () and then select New search.
  2. Set the values of the search parameters in the search fields.
  3. Select Search to run the defined search.
