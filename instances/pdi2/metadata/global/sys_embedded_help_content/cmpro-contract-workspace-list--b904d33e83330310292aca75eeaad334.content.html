Contract Workspace List View

Use lists in workspace to view high-priority issues and issues that are assigned to you. View the list of contract requests, contract repository records, obligation records, internal review tasks, and pending approvals.

This application enables you to do these tasks:
  • Work with contract requests.
  • Work with contract repository records.
  • Work with internal review tasks.
  • Work with obligation records.
  • Work with your approval requests.
  • Use advanced filters to view records for the specified condition.
