Workplace Analytics

Use the Workplace Analytics dashboard to view key metrics that enable you to optimize the use of workplace resources.

Workplace Analytics enables you to do the following tasks:
  • View data-driven insights, trends, and key performance indicators for the following applications:
    • Space Optimization
    • Lease Administration
    • Maintenance Management
  • Use filters to personalize data.
  • Prioritize resources by analyzing trends.
  • Reduce costs through resource optimization.
  • Customize widgets to see relevant metrics.
