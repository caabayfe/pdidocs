Delete Jobs list

This list provides information on the delete jobs available for your instance. These are used to safely delete records from a table without using scripts and without deleting the table.

Number
Number of the job which determines its place in the list.
Condition
Prerequisite(s) that must be met in order for the delete job to run; for example, if a record is from before or after a given time or date.
Rollback context
Context in which a rollback of the delete job is performed.
Run at
Time and date for the delete job to be run.
Schedule
Scheduled recurrence for a delete job to be run repeatedly, for example, every Monday, or every two weeks.
Run business rules and engines
Boolean value indicating whether any server-side scripts related to the targeted records should activate when the delete job is run.
State
Whether the delete job is new or has been activated yet.
Table
Table where the delete job will be run.
Transaction
Browser activity related to the delete job.
