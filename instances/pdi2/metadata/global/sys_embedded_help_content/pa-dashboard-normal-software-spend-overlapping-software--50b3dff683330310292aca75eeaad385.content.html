Overlapping software

Use the Overlapping Software dashboard to view software products with overlapping functionality and discover unnecessary spending on redundant software.

The graphs show software categories that have the highest number of purchased products and highest total spending. Click the bars in either graph to view a list of software products and transactions in each category. The number next to each product shows the number of transactions for that product.

By default, all data shown in the Overlapping Software dashboard is from software transactions within the last two years. Select a tab at the top of the dashboard to change the time range.
