Creating a GoTo Integration

Create an integration profile to connect your GoTo applications with the ServiceNow AI Platform. With this integration, you can view and analyze software usage information for the following GoTo applications:
  • GoToMeeting (user subscriptions, user activity, and reclamation candidates)
  • GoToWebinar (user subscriptions, user activity, and reclamation candidates)
  • GoToConnect (user subscriptions, user activity, and reclamation candidates)
  • GoToTraining (user subscriptions only)
  • GoToAssist (user subscriptions only)
  • OpenVoice (user subscriptions only)
You can use this information to optimize stale licenses for these applications.
Important: Before you can save and publish the integration profile, you will need to create a GoTo OAuth client for authenticating your GoTo API requests. You must also create a connection between the OAuth client and your ServiceNow instance so that you can retrieve user data from your GoTo applications.
The integration profile uses the GoTo Download Subscriptions, GoTo Update User Activity, and GoTo Reclaim Subscription subflows to retrieve user data from your GoTo applications. You can select the date and time that you want to analyze user activity from in the Analyze user activity from field on the Calculate Activity Subflow tab. By default, you can analyze user activity from up to 60 days prior to the current date. You can modify this value in the Last activity threshold field of your reclamation rules.
Note: The GoTo Download Subscriptions subflow is used for all supported GoTo applications. The GoTo Update User Activity and GoTo Reclaim Subscription subflows are used for only the GoToMeeting and GoToWebinar and GoToConnect applications.
