Viewing data fabric tables

View and manage your data fabric tables.

Data fabric tables

View a list of all the data fabric tables that you can access on the Data fabric tables tab.

  • Search for a data fabric table by label or name.
  • Filter the list of tables by data source and connection.
  • Filter the list of tables by creator.
  • View a list of data fabric tables from active connections in the Active tab.
  • View a list of data fabric tables from connections that are deactivated or not configured in the Others tab.

You can update the field mapping between a source table and a data fabric table by selecting Edit.

In the options menu for a data fabric table:

  • You can remove a data fabric table by selecting Delete.
  • You can view a list of records in the data fabric table by selecting Open list.
  • You can connect a data fabric table to a different data source by selecting Change connection.

Data fabric tables included with applications

Application developers can package both a physical table and a data fabric version of the same table in an application. The data fabric table has the same columns as the physical table, but can be used to access external data using a zero copy connection.

To connect a data fabric table from an application to an external data source, the connection admin must grant access to that connection first. After access is granted, the data steward can change the connection to use the established connection, and map external source columns to the data fabric table.

You can also connect a data fabric table included with an application to a different physical table on your instance. This allows you to reuse the data from the physical table in your data fabric table.
