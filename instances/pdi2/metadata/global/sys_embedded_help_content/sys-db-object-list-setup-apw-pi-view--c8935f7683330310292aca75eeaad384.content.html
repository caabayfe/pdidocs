Select a planning item to configure its form view

Role required: admin

The following are the form views necessary for a planning item table:
  • APW Default
  • APW New
  • APW Preview

Select a planning item and add these views by configuring its form layout.

For more details on what these views are for, and the procedure to add them to your planning item types, refer to the documentation from the Related information section below.
