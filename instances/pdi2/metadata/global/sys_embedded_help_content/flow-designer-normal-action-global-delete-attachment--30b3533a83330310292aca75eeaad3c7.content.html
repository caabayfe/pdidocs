Delete Attachment action

Remove one or all attachments associated with a record. Deletes the attachment record from the Attachments [sys_attachment] table.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Source Record
Data type: Record

Reference to record whose associated attachment records you want to delete.

Table
Data type: Table

Table name of the record to update. This value is automatically populated from the Source Record input.

Attachment File Name
Data type: String

Name of the attachment file you want to delete.

Delete All Attachments?
Data type: True/False

Option to delete all associated attachments from the record.

Outputs

This action has no outputs.
