Report a knowledge gap

Report a knowledge gap if you cannot find relevant knowledge articles to help resolve a case.

Before you begin

Role required: sn_customerservice_agent, sn_customerservice.consumer_agent

Procedure

  1. Select the more actions () icon at the top of the Case form.
  2. Select Report Knowledge Gap.
    The system opens a new knowledge feedback task in a sub-tab and copies the short description from the case to the Description field.
  3. Edit the knowledge feedback task description if necessary.
  4. Select Save.
    The system adds the task to the Knowledge Gaps related list on the Case form.
