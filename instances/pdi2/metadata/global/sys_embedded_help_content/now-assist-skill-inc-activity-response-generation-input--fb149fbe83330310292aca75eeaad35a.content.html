Incident activity response generation: Choose input

The incident activity response generation skill helps users automatically generate a response in an incident record activity stream. Then, add them to the work notes or comments to enhance the quality of your interactions with the user.

The skill relies on the Incident input table and following input fields to provide context for the Now LLM Service in the incident activity response:
  • Short description
  • Description
  • Priority
  • State
  • Work notes
  • Comments
