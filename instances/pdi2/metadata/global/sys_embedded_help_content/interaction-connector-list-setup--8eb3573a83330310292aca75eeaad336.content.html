Interaction connectors

Interaction connectors provide a way for you to configure different communication channels for your agents to use. Use interaction connectors to set up chat, phone, email, or web channels for your agents.

Use the provided configuration points to define what happens at each point of the interaction life cycle. See the list below for more information on the life cycle of an interaction.
  • On created
  • On queued
  • On assigned
  • On closed
  • On transferred
  • On abandoned
