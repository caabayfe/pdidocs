Federations list

Use the federations list to view the federations configured on your instance. Federations aggregate meta-data from multiple IdPs and service providers, including your instance. Federations then publish the meta-data as an XML file, which includes information like IdP names and IdP certificates.

Name
Name of the federation
Active
Whether the federation is active
Discovery Service URL
Enter the URL of the discovery service for this federation. This is the site where users are directed to select an IdP and log in
Meta Data URL
URL of the XML file that holds the federation meta-data
Type
Type of authentication this federation supports
x509 Certificate
Federation certificate for this federation
