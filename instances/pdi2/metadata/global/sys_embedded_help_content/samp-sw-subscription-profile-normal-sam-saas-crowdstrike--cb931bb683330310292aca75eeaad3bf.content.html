Creating a CrowdStrike integration profile

Create an integration profile to connect your CrowdStrike applications with the ServiceNow AI Platform. Use this integration to view CrowdStrike active host sensors information and check license compliance.

Important:

Before you can save and publish the integration profile, you will need to configure CrowdStrike Client API settings to receive a Client ID and Client secret.

In addition, you must create a connection between the CrowdStrike application and your ServiceNow instance so that you can retrieve device information from your CrowdStrike application.

The CrowdStrike integration profile uses the Download Subscriptions subflow to retrieve host device data from your applications.
