Configure risk rollup aggregation factors for OT Obsolesence Management

Role required: sn_risk_score_calc.admin role or sn_risk_score_calc.user role.

Preconfigured Aggregation Score Weight definitions are available by default. If you want to modify the existing Aggregation Score Weight definitions or add new definition, perform the following steps:

  1. Select Calculation factor related list.
  2. Modify the calculation factor according to your requirement.
  3. Select Update.
  4. You can also create a calculation factor:
    1. Select Calculation factor related list.
    2. Select New.
    3. Select Simple factor, Aggregation factor, or Scripted factor aggregation factor type according to your requirement.
    4. In the new form, you can provide the following details of the aggregation factor: Name, Weightage, Target table, Aggregation column (column in the target table) , Transform score and the details of how target table is linked with source table - Target table column, Join operator, Source table column.
  5. Select Submit.
