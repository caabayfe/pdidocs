Service Graph Connector for Wiz configuration properties

Set configuration properties for the connector.

Projects
Enter the list of project IDs for which the resources are to be imported.

For multiple IDs, separate them with commas.

Exclude projects
Enter the list of project IDs for which the resources are excluded only when the Projects property isn’t set. In this case, all the resources except for the specified projects are imported.

For multiple IDs, separate them with commas.
