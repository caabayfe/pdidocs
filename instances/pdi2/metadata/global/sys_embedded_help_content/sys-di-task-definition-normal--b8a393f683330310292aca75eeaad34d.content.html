Create a use case

DocIntel has two types of use cases: data extraction and document classification.

Create a use case to define a document you want to process in DocIntel.

For an improved DocIntel setup, configuration, and monitoring experience, install the Document Intelligence Admin application.

  1. On the Use Case form, fill in the fields.
    Display Name
    Name of the use case
    Document Type
    Type of document to be processed. Typically, default is recommended.
    Document Config
    Configuration of the document to be processed. Typically, default is recommended.
    Autofill Threshold
    If Auto-fill mode is enabled, DocIntel only auto-fills fields if the confidence score of the top recommendation is at or above this percentage.
    Fully automated (Straight Through Processing) Threshold
    If Fully Automated mode is enabled, DocIntel automatically processes the document task if the confidence scores for all classes or required fields are above this confidence threshold.
    Warning Threshold
    If Auto-fill mode is enabled, DocIntel shows a warning for auto-filled fields with a confidence score at or below this percentage.
  2. Submit the use case.

After creating a use case, continue setting it up by adding fields or classes.
