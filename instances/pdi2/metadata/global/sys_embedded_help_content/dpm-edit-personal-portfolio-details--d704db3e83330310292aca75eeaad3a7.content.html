Edit details in a personal portfolio

Edit your personal portfolio to add or remove items. The first step to editing a personal portfolio is to confirm or change the details.

Before you begin

Role required: sn_dpm.dpm_manager

Procedure

  1. Edit or confirm the Details of your personal portfolio.
    • Name
    • Description
    • Editors (optional)
    • Viewers (optional)
    You can't edit the Owned by field.
  2. Select Next.
