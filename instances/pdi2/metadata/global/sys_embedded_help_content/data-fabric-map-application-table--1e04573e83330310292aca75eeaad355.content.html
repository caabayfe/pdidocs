Map an application table

Map a data fabric table included with an application to an external data source.

Before you begin

To map an application table to an external data source, you must have access to an established connection first. Consult the connection admin if the connection that you want to use isn't available.

Role required: a role containing the df_data_steward role

Procedure

  1. In the Data fabric tables tab, find the application table that you want to update and select Change connection.
  2. Acknowledge that you're changing the data source by selecting Confirm.
  3. Choose an established connection and select Continue.
  4. Find the source table that you want to fetch data from and select Continue.
  5. Map source data to the target table.
    You can select the source columns to map, but you can't add or remove columns from the target table because the application requires those columns.
  6. Select Finish.

Result

The application table is connected to the data source and fields are mapped between the tables. Application users can access the external data as if it's stored locally on the instance.
