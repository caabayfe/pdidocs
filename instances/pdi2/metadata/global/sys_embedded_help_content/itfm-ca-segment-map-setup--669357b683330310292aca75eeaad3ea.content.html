Create a segment definition

You can define segments that match your business model.
  1. Provide a Segment name.
  2. Identify the Transactional table for the segment.
  3. Identify a Primary field in the transactional table for the segment to refer to.
  4. Select if the segment must be available for cost allocation and budgeting.
  5. If required, apply a fiscal validity parameter for the list of records to be displayed in this segment.
  6. Click Submit.
