Analyzing agent performance

Track the status of an agent's work and look at their schedule, skills, and performance from a central location.

Overview

Current Work
Displays the work the agent is currently doing, cases/incidents that the agents closed on the current day, and the rejected work items.
KPIs
Displays indicator status for KPIs configured for the agent for the selected KPI group and the selected time period.
Channels
Work assignments assigned to the agent through service channels.
Presence History
Displays how long the agents were active or were on breaks on a given day.
Skills
Displays which skills the agent has and the proficiency of each skill.
Upcoming time off
Displays upcoming time-off requests for the agent.
Overdue Training
Training that is past the completion due date.

Team information

Information icon
Information such as agent's primary and additional assignment groups, the manager and teammates. You can also view the top skills used by the agent.
Target icon
Enables you to set targets for the agent.
