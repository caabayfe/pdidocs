Virtual Agent Designer

Virtual Agent conversations are defined in a topic. When you open Virtual Agent Designer, the Topics landing page lists the topics and other objects in your instance. You can create and edit topics and other objects in Virtual Agent Designer. You can also test and preview active topics to verify that they work as intended.

When you open a topic, Virtual Agent Designer provides tabs that you let you define the conversation.

Properties tab
Identifies the name and purpose of the topic, along with the type of topic discovery that will be used to call it when the user makes a request. For example, keyword discovery, Natural Language Understanding (NLU) discovery, or Large Language Model (LLM) discovery.
Flow tab
A visual editor that allows you to drag and drop conversational components onto a canvas and build the conversation.
NLU Intent tab
If you are using NLU topic discovery, this tab lets you define utterances and entities for the topic. You can also train the model from here.
Languages tab
If multiple languages are enabled on your instance, you can manage topic localization here, as well as NLU mappings.
You can also use pre-built topics to get started more quickly. For example, these are some of the pre-built topic plugins available in the ServiceNow Store:
