Map marker click action list

This list provides details on click actions available to you in the Classic Environment. Click actions enable you to define what happens when you click a map marker on your Map Page.

Name
Name of the map marker click action.
Action type
Type of action performed by the click action. A Dialog form uses Title and Form view elements, while a Script action type uses the script you write instead.
Title
Title for the map marker click action, which is displayed on the dialog form on your Map Page.
Form view
The Form view used for the dialog box UI on your Map Page.
Script
Custom script that runs as part of the click action, if Script is chosen for the Action type.
