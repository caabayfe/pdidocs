Integrations

The Integrations list shows the DocIntel integrations in your instance.
  • Select (or right-click) the column headers to sort, filter, and edit the list.
  • Select the Personalize list icon to choose the columns in your list.
  • Select an integration to view and edit the integration details.

The Integrations list includes the following significant columns:

Name
Name of the integration
Target Table
Table to receive data from or send data to
Flow
Flow Designer flow for this integration
Conditions
Filters used to select certain fields to use as specific triggers for the integration

For an improved DocIntel setup, configuration, and monitoring experience, install the Document Intelligence Admin application.
