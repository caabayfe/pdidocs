Edit business application details using list view

You can make updates to the business application record directly from the list, without leaving the list view.

Before you begin

Role required: sn_apm.apm_analyst

Procedure

  1. Select List.
  2. Select the business application that you want to edit details for.

    A new pane appears on the List view screen and the details of the business application are displayed.

    Note: To view more details regarding the business application, select Full details.
  3. On the Business application form, fill in the fields.

    For a description of the field values, see Business application form.

  4. Select Update.
