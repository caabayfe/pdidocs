Send Message to Task Conversation action

Sends a message to a task record conversation, such as an incident, problem, or change request.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Task Record
Data type: Record

Reference to the task record for the conversation.

Message
Data type: String

Text of the message to send to the conversation.

Outputs

This action has no outputs.
