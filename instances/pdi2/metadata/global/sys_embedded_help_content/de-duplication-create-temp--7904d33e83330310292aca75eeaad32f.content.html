Create a de-duplication template

You can run a template to apply consistent remediation to de-duplication tasks in bulk. You can organize your templates in libraries.

Before you begin

Role required: cmdb_dedup_admin (contained by default in sn_cmdb_admin)

About this task

By default, a newly created template is set to draft mode. You must publish a template to make it available for remediation.

Procedure

  1. General information: Fill out the form and then select Next.
  2. Create condition: Use a condition builder or a custom script to narrow down the list of de-duplication tasks assigned to the template, and then select Next. Use script toggle options:
    • Off: Specify conditions to filter on CIs from the template class. Only the de-duplication tasks containing CIs that match the filter will be assigned to the template.
    • On: Enter a custom script that returns a valid array of de-duplications tasks sys ids (from the Remediate Duplication Task [reconcile_duplicate_task] table), that are applicable to the template class. Those de-duplication tasks will then be assigned to the template.
    Note: Ensure that the script doesn't exceed your intended runtime expectation and doesn't unexpectedly affect performance. Invalid values returned by the script are ignored.
  3. Select main CI: Select the method for choosing the main CI from the drop-down list and then select Next.
    Note:
    • Applying the chosen method to a set of duplicate CIs must result in exactly one CI. If during remediation, the chosen method yields no CIs or multiple CIs, then the Newest updated method is automatically applied regardless of your choice.
    • The main CI is considered separate from the rest of the duplicate CIs. After you select a main CI, 'duplicate CIs' refers to all initial duplicate CIs, aside from the selected main CI.
  4. Merge attributes: Select the method to use for merging the attributes of duplicate CIs, and then select Next.
    For each method card, select attributes.
  5. Merge relationships: Select an option for merging relationships from duplicate CIs into the main CI, and then select Next.
  6. Merge related items: Select the method to use for merging related items associated with the duplicate CIs into the main CI, and then select Next.
    For information about the default list of related items used in de-duplication processes, see Manage default related items list.
  7. Duplicate CI actions: Select what to do with the duplicate CIs after they’re merged into the main CI and then select Next.
  8. Review and test: Access the following tabs to complete the template by reviewing and testing it.
    1. Summary: Review all template settings and select Back to modify any settings.
    2. Test: Select a sample de-duplication task and then select Save and Preview Results to save and run the template and then preview the results of the remediation test.
    3. Select Save & Exit to save the template and return to the template's home page.
