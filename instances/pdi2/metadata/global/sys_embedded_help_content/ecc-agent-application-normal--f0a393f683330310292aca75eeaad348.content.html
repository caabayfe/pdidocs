Specify MID Server applications

The default MID Server does not need to meet any criteria (application, IP range, behavior, or capability) to be used. Specifying a default MID Server is optional, and you can use a MID Server as the default for more than one application.
  1. Select a MID Server from the list in the Default MID Server field.
  2. To select additional MID Servers for this application, click Edit in the MID Servers related list and select alternate MID Servers that this application is allowed to use.
  3. Click Update.
