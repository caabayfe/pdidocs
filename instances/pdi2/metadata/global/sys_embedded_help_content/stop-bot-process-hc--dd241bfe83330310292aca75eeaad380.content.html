Stop an unattended bot process

Stop a published, unattended bot process so that you can abort the automation by a selected robot.

Before you begin

Start a bot process. For more information, see Start an unattended bot process in RPA Hub.

Verify that the life-cycle stage status of the bot process is either in Published, In Maintenance, or Build.

Verify that the life-cycle stage status of the assigned robot is In Use and the state of the robot is Busy.

Role required: sn_rpa_fdn.rpa_developer, sn_rpa_fdn.rpa_support_user, sn_rpa_fdn.rpa_business_user, or sn_rpa_fdn.rpa_admin

About this task

You can stop the bot process gracefully by enabling the Graceful Stop toggle switch. To use the Graceful Stop toggle, make sure that the Graceful Stop component is used in the selected package version in RPA Desktop Design Studio. Graceful stop is applicable for assigned robots as well as robots in robot pool. For more information, see Using Graceful Stop functionality in RPA Hub.
Note: Only the robots that are assigned to the current bot process and execute the same bot process are displayed here (in step 4).

Another way to stop an unattended bot process is via triggering the Stop Process Action in Workflow Studio. For more information, see Workflow Studio actions and subflow in RPA Hub.

Procedure

  1. In the form header, select the down arrow in the Start Process button.
  2. Select Stop Process.
  3. Optional: Terminate the bot process gracefully by enabling the Graceful Stop toggle switch.
  4. Select the robot that is assigned to the current bot process that you want to stop.
  5. Select Stop Process.
