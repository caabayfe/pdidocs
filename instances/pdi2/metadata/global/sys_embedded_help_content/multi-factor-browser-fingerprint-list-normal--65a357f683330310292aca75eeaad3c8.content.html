Multi-factor browser fingerprints list

Use the multi-factor browser fingerprint list to view the existing browser fingerprints used for Multi-factor authentication (MFA). These records are created when MFA users log into your instance. When a MFA user logs in again using the browser identified by this fingerprint, they are not challenged for MFA until the fingerprint expires. The length of time before the fingerprint expires is determined by the glide.authenticate.multifactor.browser.fingerprint.validity system property.
