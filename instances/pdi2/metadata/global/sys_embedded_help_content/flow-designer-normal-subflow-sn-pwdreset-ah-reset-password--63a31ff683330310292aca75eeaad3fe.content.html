Password Reset subflow

Reset a user's password.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Password Reset Request
Data type: Record

Reference to the password reset request to fulfill.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Status
Data type: Choice

The completion status of the password reset request. The flow execution details page displays one of these values.

  • Success
  • Error
Error message
Data type: String

The error message the password reset request produced if any.
