Create an integration

Configure a DocIntel integration to set up flows with other applications.

For an improved DocIntel setup, configuration, and monitoring experience, install the Document Intelligence Admin application.

  1. On the Integration Setup form, fill in the fields.
    Name
    Name of the integration
    Create Flow
    Option to create a Flow Designer flow for the integration
    Domain
    Domain for the integration
    Type
    Type of integration: Process Task or Extract Values
    Use Case
    The use case associated with the integration
    Flow
    Flow Designer flow for this integration
  2. Submit the integration.
