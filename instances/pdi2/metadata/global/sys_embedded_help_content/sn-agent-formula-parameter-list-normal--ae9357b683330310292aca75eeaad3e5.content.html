Add formula parameters to calculate number of agents

Add parameters to the formula to calculate how many agents you need per hour in a day.

  1. Select New.
  2. On the form, fill in the fields.
    Name
    Unique name for the parameter.
    Value
    The value to be calculated for the formula.
    Advanced
    Script for the performance analytics score card API or the custom API.
    Note: The Average Chat Duration and Average Walkup Duration forecast parameters that are provided by default are examples of how you can use scripts to add the parameters.
  3. Click Submit.
