Monitor your use case models

Machine Learning model effectiveness is only as good as the data it consumes. Over time, model efficiency can drift, typically due to changes in business conditions.

The Predictive Intelligence dashboard Monitoring Models tab helps you monitor drift to ensure model efficacy. By enabling you to compare the actual net automation (model predictions) of the use case to its estimated net automation (model training).

Use this dashboard to periodically tune a completed and underperforming use case, or create a new model to train, to guarantee peak performance.
