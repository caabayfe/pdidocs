Schedule entry types

Roles required: admin or sn_isa_schedule_admin

Create a new schedule entry type.
  1. Click New.
  2. Enter type in the Element field.
    This is the field on Schedule Entry table.
  3. Enter the type name in the Label field.
    The value in this field is translated when the localization setting changes.
  4. Enter the type value in the Value field.
    This is description of the type.
  5. Enter the sequence number in the Sequence field.
  6. Click Submit.
