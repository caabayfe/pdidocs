Enable your teams to sign up for work shifts

Empower your teams to sign up for work shifts based on their availability and preference.

Before you begin

Role required: sn_shift_planning.admin

Procedure

  1. Add a schedule plan.
    1. Select the Team calendar tab.
    2. In the contextual side panel, click the Show Schedules icon () to display the schedules.
      Tip: Select the filter icon () and then select the desired sign-up state and sign-up dates to narrow down the schedule plans enabled for sign up.
    3. In the Schedules panel, select the + icon.
    4. Fill in the required fields on the form.
    5. To enable your agents to sign up for work shifts, enable the Request Agent Signup check box and in the Agents must sign-up by field, enter the date by which they need to sign up for shifts within that schedule.
    6. Select Save schedule.
  2. Add a work shift to the schedule plan.
    1. Select Add shift.
    2. In the Shift field, select the work shift that you want to add to the schedule plan.
      Note: If the schedule plan has been enabled for agents to sign up for shifts, the Request agent sign-up and Enable auto-assignment of agents check boxes are automatically enabled. You can disable these check boxes at any time if you want to manually assign agents.
    3. To enable auto-assigning your agents for the shift, enable the Enabled for auto-assignment for agents check-box.
      Your agents who have set the shift to be their top preference will be auto-assigned. The shift auto-assignments are also based on the value set in the sn_shift_planning.max_shifts_to_autoassign system property.
  3. If the shifts are enabled for sign-up, you can select Send for signup.
    All shifts that have been enabled for sign up will be sent to the agents to sign up for their shifts.
  4. Add agents to works shifts.
    1. In the Assign agents field, search for agents and add one or more agents to add to the shift.
    2. To add agents who had signed up for shifts, select +Add signed up agents.
      You can view the agents who had signed up and their preferred ranking to work on that shift. Use the Hide agents already assigned to other shifts toggle button if you don't want to display the agents who have been assigned to a schedule plan.
    3. Select Save selection.
    4. Select Save shift.
      The state for the shift changes to Generating Preview.
    5. To publish the schedule plan, selectPublish.
