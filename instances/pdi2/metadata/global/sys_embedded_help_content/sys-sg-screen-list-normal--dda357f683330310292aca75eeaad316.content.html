Screens list

The Screens list provides the list of potential screen views available.

Use the various filters to narrow down your search.

Name
The name of the screen
Available offline
Whether the entry can be viewed offline.
Description
A short text description of the entry.
Dynamic prefetch count
How many screen views may be loaded ahead of time.
Empty State
Whether content exists for a given screen.
Fetch Type
Determines when data is loaded, such as before or during viewing.
Filter
Whether given text matches content of the screen.
Hide filter and sorting
Whether the filter and sorting for the screen can be hidden.
Hide screen name
Whether the screen name can be hidden.
Icon
Image associated with the given screen
