Create a remediation task manually

You can create remediation tasks manually from the Host vulnerable items, Application vulnerable items, Container vulnerable items, and Configuration test results lists on the List page of Vulnerability Manager Workspace.

Before you begin

Role required:
  • sn_vul.write_all, sn_vul.vulnerability_analyst, or sn_vul.vulnerability_admin for host vulnerable items (VITs)
  • sn_vul.app_write_all, or sn_vul.app_sec_manager for application vulnerable items (AVITs)
  • sn_vul_container.write_all, sn_vul_container.vulnerability_analyst or sn_vul_container.vulnerability_admin for container vulnerable items (CVITs)
  • sn_vulc.write, or sn_vulc.admin for configuration test results (TRs)

Procedure

  1. Navigate to Workspaces > Vulnerability Manager Workspace > List.
  2. On the List page, open the Active or All list in one of the following lists:
    • Host Vulnerable Items
    • Application Vulnerable Items
    • Container Vulnerable Items
    • Configuration Test Results
  3. Optional: Select the check box of the records you want to update.
  4. Select the Create remediation task button.
  5. On the Create remediation task modal, fill in the fields.
    For more information on the field descriptions, see Create a remediation task manually in the Vulnerability Manager Workspace.
  6. Select Create remediation task.

Result

Remediation tasks are created based on the grouping criteria.
