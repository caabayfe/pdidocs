Project Workspace homepage

Use the Project Workspace homepage to plan, create, and manage your projects and sub projects. The homepage gives you real time information to help you track your projects and plan your work. You can view all the details pertaining to a specific project on the homepage.

On the Project Workspace homepage, you can perform any of the actions:
  • Drill down project cards to view high-level details of the project such as project name, planned dates, and status.
  • Perform a search for a project by its name or assignee.
  • Sort the display order of the projects by clicking Recent.
  • View all projects in your system including customer projects, teamspaces, and audit.
  • View all the projects that you own, including sub projects.
  • Use New Project to create a new project.

For more information on Project Workspace, see Project Workspace.
