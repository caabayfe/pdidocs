MID Server clusters

MID Server clusters enable multiple MID Servers with the appropriate capabilities to be grouped together for load balancing and fail-over protection.

Restrictions

For performance and reliability reasons, these data sources should be used with dedicated MID Servers only and not with clusters.
  • LDAP
  • Export sets
  • JDBC data sources

How clusters work

MID Servers in clusters must be able to connect to the instance and to all the devices with which they are expected to communicate. If all MID Servers in a cluster are down, the discovery is canceled. Make sure all the MID Servers are added to any Access Control List (ACL) in use.
Load balancing
If the cluster business rule determines that a MID Server is part of a load balancing cluster, the application using the MID Server automatically balances the work between the MID Servers in that cluster.
Fail-over protection
MID Servers in a fail-over cluster each have a configured order that the platform uses to determine which MID Server to use next in case of failure. Configure a fail-over MID Server with at least the same capabilities as the MID Server it is intended to relieve.
