Define data collection and associate an assignment group with a resource conversion formula

Define the data that you want to collect for incidents, interactions, or any table to forecast the number of agents that you require for your staffing needs.

  1. Define data collection for demand forecast.
    1. On the form, fill in the fields.
      Name
      Unique name for the collection forecast configuration.
      Table
      Name of table for collecting data.
      Date field
      Data from the selected date field collected to add to the forecast for future.
    2. Click Submit.
    A forecast parameter in Published state is automatically created.
    Note: You must add the formula parameters before configuring the resource conversion formula.
  2. Configure the resource conversion formula.
    1. On the form, fill in the fields.
      Name
      Name for the resource forecast configuration.
      Formula
      Formula to calculate the forecasted number of agents that you need.
    2. Click Submit.
