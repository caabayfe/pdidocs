Map marker icon list

This list provides details of the map marker icons available for your Map Page in the Classic Environment. These icons represent map markers for data items.

Name
The name of the map marker icon.
Co-located icon URL
Relative or absolute link to an icon for multiple data items from a map coordinate on your Map Page.
Level
Priority of the map marker on your Map Page. When multiple markers share coordinates, the lowest level marker is displayed.
Scripted condition
Optional scripting for the map marker.
Single icon URL
Relative or absolute link to an icon for a single data item from a map coordinate on your Map Page.
