Create a case of a specific type

Create a case of a specific type, such as an onboarding or complaint case, to address a customer's specific needs.

Before you begin

Role required: sn_customerservice_agent, sn_customerservice.consumer_agent

Procedure

  1. Select New.
  2. Select a Case Type in the Select Case Type pop-up window.
    If the single select option has been enabled, the Select Case Type pop-up window only displays the Case Type field.
  3. Optional: Select a category and subtype to narrow the available choices.
    If a subtype has not been configured for a case type, the Subtype field is not displayed.
  4. Select Create Case.
  5. Fill in the fields on the Create New Case form.
  6. Select Save.
