Chat feature

Turn on and configure Chat skills to use generative AI for chat-related functionality in workspaces and the Now Assist Panel.

The All Available Chat skills panel displays which skills are available for activation within this feature. Select the Turn on skill button in a skill card to activate it.

Use the Active Skills section to review the active skills on your instance for that feature, make any edits to their settings, or turn them off. Select the more icon () next to a skill to manage that skill.
  • Select Edit to configure or reconfigure a skill's settings.
  • Select Deactivate skill to turn off the skill.
