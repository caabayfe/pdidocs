Use shortcuts

Use the provided shortcuts to access items that you recently reviewed, including portfolios, incidents, and solutions. You can also access personal and enterprise portfolios.

Before you begin

Role required: sn_dpm.dpm_manager

Procedure

  1. In the Recently viewed section, select any item in the list to go to that item.
  2. In the Personal portfolios section, select any personal portfolio link to go to that item or select Go to personal portfolios to access a page display of all your personal portfolios.
  3. In the Enterprise portfolio section, select any enterprise portfolio link to go to that item or select Go to enterprise portfolios.
    Note: Service-related enterprise portfolios are created with Service Portfolio Management tables, and contain services and offerings that are grouped in a common shared portfolio.
