Data Collection Configuration for Operational Technology Obsolescence Management

Role required: admin or pa_admin

The OT Obsolescence Management Daily Data Collection is an on-demand job that you only need to execute once. After the data is collected, the daily data collection job runs on a scheduled time every day.

The Obsolescence Management (PA) dashboard uses OT Obsolescence Management Daily Data Collection job to collect the data that is shown on the dashboard. Scheduled Jobs are automated pieces of work that can be performed at a specific time or on a recurring schedule.

Perform the following steps before others can view the OT Obsolescence Management Dashboard tab:

  1. Select the check box next to the Active field and set a schedule to start collecting data, or use the Execute Now button to collect data manually so that the data is shown properly on the OT Obsolescence Management Dashboard tab.
  2. Check if the default schedule collection time works for you.
    The default time is 00:00:00 daily. If you want to change the default collection time, you can change it after activating the job. Please notify users of this change.
  3. Select Update.
  4. Select Execute Now.
