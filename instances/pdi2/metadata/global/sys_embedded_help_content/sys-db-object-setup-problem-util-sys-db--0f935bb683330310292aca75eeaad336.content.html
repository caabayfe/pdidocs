Problem and Problem Task table

During the preparation, if you have not used Problem Management before or you only have demo problem or problem task records and you want to remove all of your problem or problem task records, perform the following steps:

  1. In the Problem or the Problem Task table, if you are prompted with the message To edit this record click here, then click here.
    Note: Ensure you take a backup of your problem or problem task records before you remove them.
  2. Select Delete All Records.
