Validate connection

In the File Connection Information record, the following details are provided:
  • Connection
  • Provider
  • State
  • Source path
  • Destination path
  • Click the File Connection Information record and click  Validate. This step checks the validity of the credentials and existence of source and destination paths configured in the SFTP connection.
  • If the credentials provided by the user are correct, the state of SFTP connection is updated to  Validated.
  • In case you encounter any issues in validating the connection, triage it using an integration log. If you do not want to use a connection, move it to draft state by clicking Move to draft. In integration, only the File Connection Information record for which the state is Validated is used in the flows.
  • If the validation fails, enter the correct credentials and path again and click  Validate.
