MID Server script files

MID Server script files are reusable scripts, synchronized to all MID Servers, that do additional work on a target. For example, script files are used to create PowerShell modules or to retrieve an address list from an Exchange server.

File synchronization requires you to proactively take script files from your instance and save them on the MID Server. The files on the instance and the MID Server stay synchronized, but there is no longer any need for the MID Server to download the whole file. File synchronization also protects any updates you make in those script files from being overwritten during the upgrade of an instance.

Note: The MID Server Script File [ecc_agent_script_file] table is domain separated. You can create versions of these policies that only a MID Server from the same domain can use.
