Test suites execution using Cloud Runner option

Execute the generated tests suite using the Cloud Runner browser option.

Important information on this page:
  • You can execute either an individual test or a test suite
  • Select Cloud Runner as the browser option to execute the generated tests
    Note: As an admin user, you can hide the Cloud Runner option on the Pick a browser modal by setting the atf_cloud_runner.radio_visible to false. The property is set to true by default.
  • If you run a test suite using the cloud runner, all the tests within the suite run in parallel.
  • By default, only two cloud runners can be used simultaneously
  • The execution of the tests continues at the background even if you close the progress bar.
