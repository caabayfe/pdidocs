Create new enterprise classification import

Import multiple classification codes at one go to your ServiceNow instance.

Before you begin

Role required: sn_eam.enterprise_asset_manager

Procedure

  1. On the Create New Enterprise Classification Import page, enter a name for the import in the Import field.
  2. Select Download template to download a spreadsheet.
  3. Enter the details in the spreadsheet.
    Make sure to fill out either the Code or the Description column in the spreadsheet. Use commas to specify more than one model category in the Model categories column.
  4. Select Attach File to upload the spreadsheet (.xlsx).
  5. Select Import to perform a validation check on the spreadsheet.
    After you select Import, the Status field changes from Draft and moves to Pending, Uploading, Transforming. After the import process is completed, the status changes to either Completed, Completed with errors, or Failed. The details of the import process are displayed in the Enterprise Classification Import and Classification import results sections.
  6. Select the Classification Import Stagings related list to view the details of the spreadsheet that you uploaded and also view any errors you received.
  7. Open any record for which you got an error.
  8. Fix the error, upload the spreadsheet, and import the record again.
