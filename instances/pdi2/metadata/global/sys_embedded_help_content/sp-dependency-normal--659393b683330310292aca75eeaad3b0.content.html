Create a widget dependency

Create a dependency between a widget and third-party libraries, external style sheets, and angular modules.

  1. On the form, enter a name for the dependency and then fill in the following fields.
    Include on page load
    Whether the dependency loads onto the page on the initial page load of a portal or only when the widget is loaded onto a page.
    Portals for page load (optional)
    The portals that include the dependency on page load.
    Angular module name
    An Angular module that provides JavaScript for the dependency.
  2. Select Submit.

Use the related lists to add JS and CSS Include files. Then add the dependency to a widget.
