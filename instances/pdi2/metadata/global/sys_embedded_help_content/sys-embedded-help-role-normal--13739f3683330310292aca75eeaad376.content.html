Embedded help role priority numbers

Embedded help is displayed based on the user's role. If the content has no associated role, all users see it. If the role is different than admin, users with the specified role and above see the content. For example, content with the itil role appears for itil, itil_admin, and admin.

Table 1. Default embedded help priority order numbers
Order numberRole name
10admin

Examples: admin, chat_admin, pa_admin, survey_admin

Exception: itil_admin

100manager or itil_admin

Examples: itil_admin, catalog_manager, content_manager, sla_manager

300itil (only)
1000All other roles or no role (ESS user)

Examples: approver_user, financial_management_user, personalize_form, template_editor
