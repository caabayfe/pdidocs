Discovery performance metrics aggregated by build

Use the roll-up by build data to ensure that the processing times for Discovery components remain consistent for discoveries in a 24 hour period. View aggregate build data before and after an upgrade to compare the performance of the old and new versions.
  1. Sort the list by Build/version.
  2. Filter by a specific build to see the aggregated processing times for the probes and patterns that performed a Discovery on that build.
  3. Open a record to see the probe/pattern statistics for the selected build.
