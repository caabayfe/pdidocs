Service catalogs

Service Catalog enables you to set up one or more service catalogs and provides self-service opportunities. You can organize your catalog offerings by using the ability to publish multiple catalogs targeted to specific audiences.

You can perform the following on a catalog:
  • Enable the wish list for the catalog.
  • Designate editors who can edit or update the catalog, its categories, and items.
  • Create a custom homepage for the catalog.
  • Create a custom page by clicking Continue Shopping.
