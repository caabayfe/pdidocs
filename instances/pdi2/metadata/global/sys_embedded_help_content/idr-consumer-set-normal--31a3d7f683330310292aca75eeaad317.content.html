Create a consumer replication set

Create a consumer replication set that defines the tables and columns that receive data from the producer instance.

  1. On the form, fill in the fields.
    Producer instance URL
    The URL of the producer instance.
    Producer replication set name
    The exact name of the producer replication set. The name on the consumer must match the name on the producer.
  2. Click Submit.

On the consumer instance, select the name of the producer replication set, complete the form, and then select Request Producer Approval.
