Contract workspace overview

The Contract Workspace homepage provides information on open contract requests, document revisions pending approval, and contracts due to expire. Selecting a widget to displays the related list of contract requests on a separate page.

Access to the Contract Workspace requires activation of the Contract Workspace plugin.

This application enables you to do these tasks:
  • Get an overview contract requests, pending document revision approvals, and contracts that due to expire in the user action widgets.
  • Use the filtering capabilities to view only open contract requests that require immediate action.
