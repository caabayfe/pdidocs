Validate the completeness score calculation

Role required: admin

If you plan to include the OT Device Data Completeness (%) indicator, validate that the CMDB Health Dashboard - Completeness Score Calculation is activated to run.

  1. Open the CMDB Health Dashboard - Completeness Score Calculation Scheduled Script Execution record.
  2. Validate that the Active check box is checked.
  3. Validate that Run is configured to ensure accurate scores are collected for end of the month reporting.
  4. Click Update to save any updates to the record.

    For more details on how completeness is calculated, refer to the Completeness section of the documentation topic .
