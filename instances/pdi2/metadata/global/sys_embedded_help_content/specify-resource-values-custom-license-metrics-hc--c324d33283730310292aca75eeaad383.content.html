Specify resource values for your custom license metrics

If you create a custom license metric based on resource values, specify the resource value for each software product that you want to calculate licensing requirements for.

Before you begin

Role required: sam_admin

Procedure

  1. On the Create New Resource Value form, fill in the fields.
  2. Select Save.

Result

When subsequent reconciliations run, the Software Asset Management application determines the license compliance position of the associated software product by comparing the value of the Units consumed field against the value of the corresponding Licenses required field in the License Metric Results [samp_license_metric_result] table.
