Security Incident Overview tab

This section of the SIR workspace displays the key information associated with the security incident.

The donut charts are drill down enabled, when an analyst clicks on any of the chart item, then it navigates you to the respective record with a filtered list view of items within that corresponding tab. For example, if Malicious Observables is clicked it will take you to the observables with a filtered list view of malicious observables on the Related Records tab.
