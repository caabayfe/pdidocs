Custom controls

Virtual Agent Designer provides a default set of controls that represent user inputs, bot responses, and utilities for building a Virtual Agent conversation. As a developer, you can use Virtual Agent Designer to create additional custom controls (interface components) for specific inputs or output responses. For example, a slider is an example of a custom input control that enables end users to select a quantity.

Custom controls are based on customizable Next Experience Components that you can create by using the Next Experience Design System. To implement custom controls, you must have basic knowledge of the ServiceNow AI Platform and application table structures, web component development and design skills, knowledge of JavaScript, and understanding of the design process in Virtual Agent Designer.
