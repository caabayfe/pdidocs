Use the list view

Use the list view to monitor remediation progress, view Vulnerability Response records, and see status of approval requests and exceptions. You can also create your own lists.

Lists

In the left panel, the Lists tab displays default categories of records that are automatically organized by vulnerability type. Click a filtered list, Active or All, for a vulnerability category such as Remediation Efforts or Remediation Tasks, for example. You and other vulnerability managers can view the individual records on these lists.

The following lists display:

  • Remediation efforts (REs) - Shows active REs and all the REs assigned to your groups.
  • Remediation tasks (VULs) - Shows active Remediation Tasks and all Remediation Tasks assigned to your groups.
    Note: The Remediation tasks list shows the remediation tasks that are created in the classic UI and Vulnerability Manager Workspace in Vulnerability Response, Application Vulnerability Response, Container Vulnerability Response, and Configuration Compliance.
  • Vulnerable items - Shows active (open) records and all records assigned to your groups.
  • Solutions - Shows all the solution for records.
  • Exceptions - Shows approval states for all exception and false positive requests from your groups.
  • Approvals - Shows approval requests assigned to you for processing. For more information about processing your approvals in the workspace, see the link below in Related information.
  • Host Vulnerable items - Shows active host vulnerable Items (VIs) and all host VIs from the Host Vulnerabilities module.
  • Application Vulnerable items - Shows active application vulnerable items (AVITs) and all AVITs from the Application Vulnerabilities module.
  • Container Vulnerable items - Shows active container vulnerable items (CVITs) and all CVITs from the Container Vulnerabilities module.
  • Configuration Test Results - Shows active configuration test results and all configuration test results from the Configuration Issues module.
  • Libraries - Shows the following libraries, policies, and tests.
    • CVEs - Shows all the Common Vulnerability and Exposures (CVEs) from Vulnerability Response, Application Vulnerability Response, and Container Vulnerability Response.
    • TPEs - Shows all the Third-Party Entries (TPEs) from Vulnerability Response.
    • CWEs - Shows all the Common Weakness Enumerations (CWEs) from Vulnerability Response, Application Vulnerability Response, and Container Vulnerability Response.
    • App vulnerabilities - Shows all the third-party application vulnerability entries.
    • Policies - Shows all the Configuration Compliance policies.
    • Tests - Shows all the tests from Configuration Compliance.
    • Compensating Controls - Shows all the compensating controls.
