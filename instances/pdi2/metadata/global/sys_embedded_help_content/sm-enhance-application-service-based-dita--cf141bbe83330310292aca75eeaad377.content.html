Add to an existing application service based on Automated Service Suggestions

Select an application service candidate produced by Service Mapping, and add it to an existing service.

Before you begin

Role required: sm_admin

Procedure

  1. Select Add to existing service.
  2. Begin typing the name of the existing service and select it from the list.
  3. Select Map service.
