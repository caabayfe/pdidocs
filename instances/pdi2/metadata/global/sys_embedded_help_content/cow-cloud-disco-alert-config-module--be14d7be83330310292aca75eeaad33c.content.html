Alert configurations

The alert service of the cloud can raise alerts for any changes in the lifecycle state or the configuration of a cloud resource. You can configure the service to auto-update the latest resource information in the Configuration Management Database (CMDB) without waiting for the next scheduled Cloud Discovery to run.

The Cloud Discovery application supports Alert-based discovery for the following cloud providers only:
  • Amazon AWS Cloud
  • Microsoft Azure
  • VMware
  • Google Cloud Platform (GCP)

The Alert Configurations module displays the list of events received from the cloud.

Important:
  • The Azure change processing offers better performance than the Microsoft Azure alert-driven discovery. Starting with the Discovery and Service Mapping Patterns app version 1.1.0, the Azure change processing has replaced the Microsoft Azure alert-driven discovery. For more information, see Azure change processing.
  • If have configured Azure change processing in the ServiceNow AI Platform, the Cloud Discovery Workspace application doesn't display the Azure Alert Configuration page.
