Schedule Hardware Vulnerability Assessment jobs

Schedule jobs that provide periodical vulnerability assessment of all OT devices in the inventory.

Hardware Vulnerability Assessment - Full
Execute this job to perform a comprehensive assessment of all hardware vulnerabilities regardless of prior assessments. It ensures a complete inventory and assessment of vulnerabilities across the environment.
Important: You must run Full assessment before you schedule and activate Delta assessment.
Hardware Vulnerability Assessment - Delta
Activate this job for incremental assessments, targeting only changes or updates since the last assessment run. It captures changes in the vulnerabilities due to recent addition or modification of hardware, ensuring continuous monitoring and timely updates.
Note: Delta assessment can be scheduled to run daily, weekly, or as per required frequency. You can run Full Assessment on demand as needed.
