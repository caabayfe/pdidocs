Create a condition script

Create a condition script that executes when trigger conditions are met but before the trigger executes a flow. This can prevent triggers from executing flows even when trigger conditions are met.

  1. On the form, fill in the fields.
    Name
    Name of the condition script.
    Description
    Explanation of what the condition script does.
    Script
    Field to enter the JavaScript. Make it return True to execute a flow.
  2. Click Submit.

Use Flow Designer to associate a flow with a trigger. When configuring a flow, you can select the condition script you created.
