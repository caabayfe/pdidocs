Create a Find Gap query

Create a Find Gap query from the CMDB 360 dashboard to help you find CIs that are not being reported by a discovery source.

Before you begin

About this task

Reporting gaps occur when at least one discovery source reports on the CI and another does not. This information enables you to identify discovery sources that might have an issue.

Procedure

  1. Select the CI classes to check for gaps and then click Continue.
  2. Select at least one non-reporting discovery source.
    The non-reporting discovery source is the discovery source that doesn't report the CIs as expected.

    When you select multiple non-reporting discovery sources, the Find Gap query uses an OR condition to evaluate each source.

  3. Select one or two discovery sources that report the CIs as expected.
    These discovery sources report the CI as expected and act as a baseline for identifying the gap in reporting.

    To use all discovery sources, leave the Select reporting discovery sources for gap tracking prompt empty.

  4. Click Continue and then select options on the form.
  5. Click Continue.
  6. Enter a name and description for your query and then click Save or Save and go to the dashboard .

What to do next

To create a schedule or report, run the query at least one time.

On the CMDB 360 Query Results page:
  • If the number of results exceeds the number of results appearing on the page:
    • Click Load More Results​ to show the next page of results. The number of results that appear on each result page is specified by the glide.identification_engine.multisource.query.batch.limit system property (100 items by default).
    • Click Load All Results to show all results, up to the limit specified by the glide.identification_engine.multisource.query.max.limit system property (10000 by default).
    • Click a CMDB 360 Source link to access preview data of a source and see more details.
  • You can click Create Schedule to set up a schedule that runs the query on a regular basis. Scheduling a query enables you to use the query results in reports you create.
  • After creating a schedule, you can click Create Report to create a report that you can manage using Reporting capabilities.
  • On the Query Results page, access a record to view details. For example, click a link in the Primary Record column, and then in the CI Details page, click View CMDB 360 Data.
