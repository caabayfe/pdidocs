Service catalog record producers

A record producer is a specific type of catalog item that allows end users to create task-based records, such as incident records, from the Service Catalog. Use record producers to provide a better end-user experience instead of using the regular task-based form for creating records. The look and feel of a record producer is very similar to a catalog item, except that it generates a task record, such as incident, instead of a requested item.

The Create Incident record producer appears in the Service Catalog for end users to log incidents. It is listed in the Can We Help You? category. The description that the user enters becomes the incident Short description.
