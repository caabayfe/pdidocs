Source type structure

Health Log Analytics breaks down incoming log messages into properties and automatically maps labels to source type fields. If needed, you can fine-tune how the system reads your log data. You have the option to define or customize the raw data structure using the JavaScript function. For example, you can change auto-mapped labels to different ones. You can also reclassify properties that were extracted from the message body and classified automatically. How a property is classified determines how the system analyzes it and detects anomalies.
