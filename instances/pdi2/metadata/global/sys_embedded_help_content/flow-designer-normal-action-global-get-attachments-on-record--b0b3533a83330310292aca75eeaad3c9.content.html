Get Attachments on Record action

Access the list and count of the attachments associated with the provided source record as data pills in a flow. Use flow logic or scripting to process each attachment in the list of the attachments that the action returns.

Inputs

File Name
Data type: String

Entire a file name for the attachments you want to look up.

Source Record
Data type: Record

Record that the attachment is associated with.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Attachment Records
Data type: Records

Array of records (as Sys IDs) for the attachments found in the record according to the File Name input you specify.

Count
Data type: Integer

Number of records matching the File Name input you specify.
