Configure ribbon settings for case types

In the Customer Service Management application, a case type represents the data and processes that are needed to resolve a specific type of customer issue. The system administrator can create a table for a new case type that extends the Case table (sn_customerservice_case). The extended table for the case type inherits most of the functionality of the Case table.

As part of configuring forms, you can configure ribbon settings for case types. The ribbon appears at the top of the form and includes components that display customer and case information, such as Customer 360, Timeline, and Active SLA. Each component has a ribbon setting that stores configuration information about that component.

Case types that are extended from the Case table can display these components in the ribbon on the Case form. For case types, you can do the following:

  • Create new ribbon settings for case extensions.
  • Modify existing ribbon settings so that case extensions inherit the ribbon component behavior.

To inherit ribbon component behavior:

  1. Click the component name in the Ribbon Settings list. For example, click Customer 360.
  2. Enable the Inherit check box.
  3. Click Update.
  4. Repeat steps 1 to 3 for each component to be displayed in the ribbon.
