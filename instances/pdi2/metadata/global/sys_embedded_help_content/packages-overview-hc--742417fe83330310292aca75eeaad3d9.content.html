Packages

You can create a package that contains a set of workflows, scripts, configurations, and dependencies to automate tasks or processes. These packages can be published or imported onto the Robotic Process Automation (RPA) platforms to quickly deploy automation solutions.

Packages are used to encapsulate functionalities, libraries, or applications, making it simpler for developers or RPA administrators to deploy software components.

You can create a package in two ways:
  • Create a package from RPA Hub by selecting the New. For more information, see Create a package to assign to a bot process.
  • Create a package from RPA Desktop Design Studio, while you’re publishing an automation file. For more information, see Publish an automation project in RPA Desktop Design Studio.

After a package is created, the RPA developer publishes an automation from RPA Desktop Design Studio, which results in a new package version.
