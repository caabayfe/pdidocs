Create a UI action

Create a UI action to make the UI more interactive, customized, and specific to user activities. UI actions include the buttons, links, and context menu items on forms and lists.

  1. On the form, fill in the fields.
    Name
    Enter the text that appears on the button, link, or context menu item.
    Table
    Specify the table on which the UI action is available.
    Action name
    Enter a name to use when referencing the UI action in scripts.
    Condition
    Define conditions that restrict when a UI action appears, such as restricting it to certain users.
    Script
    Create a script to run when the UI action is executed.

    With Now Assist for code generation enabled, you can provide text or code prompts to return AI-generated code suggestions and create scripts quickly.

  2. Select Submit.
