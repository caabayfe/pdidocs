Create a new contract

Create a contract to define the contractual details of your enterprise assets.

Before you begin

Role required: sn_eam.enterprise_admin or sn_eam.enterprise_asset_manager

Procedure

  1. On the Create New Contract form, fill in the fields.

    For a detailed description of each field, refer to either the Contract fields for Enterprise Asset Management link (for lease contracts) or the Create a contract link (for any other type of enterprise asset contract) in the Related information section at the end of this topic.

  2. Select Save.
    A new contract record is created.
  3. Build terms and conditions for the contract.
    Before you can build terms and conditions for a contract, you must create a terms and conditions record and add it to the contract. For detailed instructions on how to create a terms and conditions record, see Create a terms and conditions record. For detailed instructions on how to add a terms and conditions record to a contract, see Add terms and conditions to a contract.
    1. On the contract record header, select the More Actions icon ().
    2. When prompted, select Build Terms and Conditions.
    The terms and conditions are built for the contract and added to the Contract History tab of the contract record. You can view the complete terms and conditions for the contract in the Terms and Conditions tab of the contract record.
  4. Add all enterprise assets that are covered by the contract.
    Note: If you created a multi-component asset from a multi-component model, only the parent asset can be added to the contract. The associated child assets cannot be added to the contract.
    1. On the Assets Covered tab of the contract record, select Add.
      The Add assets or Assets Covered dialog box opens.
    2. In the dialog box, select the check box for each enterprise asset that is covered by the contract.
    3. Select Add.
      The dialog box closes and the Assets Covered tab automatically reloads with the list of all enterprise assets that you added.
  5. Create expense lines to track the cost of each enterprise asset that is covered by the contract.
    1. On the Expense Lines tab of the contract record, select New.
    2. On the form, fill in the fields.

      For a detailed description of each field, refer to the Expense line fields for Enterprise Asset Management link in the Related information section at the end of this topic.

    3. Select Save.
      A new expense line record is created for the selected enterprise asset.
    4. Close the expense line record to return to the Expense Lines tab of the contract record.
    5. Repeat steps a to d for each expense line that you want to create.
  6. Create child contracts that you want to associate with the contract.
    1. On the Child Contracts tab of the contract record, select New.
    2. In the Contract model field, search for and select the type of contract that you want to create.
    3. Configure the child contract by following the same steps that you used to configure the contract.
    4. Select Submit For Review.
      A review notification is sent to the user that you specified in the Approver field of the child contract record. After reviewing the child contract, the user can either approve or reject it.
    5. Repeat steps a to d for every child contract that you want to create.
  7. Select Submit For Review.
    A review notification is sent to the user that you specified in the Approver field of the contract record. After reviewing the contract, the user can either approve or reject it.
