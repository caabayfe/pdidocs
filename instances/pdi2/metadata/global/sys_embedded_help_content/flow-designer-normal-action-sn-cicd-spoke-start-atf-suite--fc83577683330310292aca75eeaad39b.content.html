Start ATF Suite With ID action

Start a test suite by its Sys ID on the specified instance URL. Return the test suite execution results.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Test Suite Sys Id
Data type:

Credential alias
Data type: Record

Choose a Connection and Credential Alias record for the instance that you want to connect to.

Instance URL
Data type: String

The full HTTP address of the instance.

Browser Name
Data type: String

Name of browser being used.

Browser Version
Data type: String

Number of browser being used.

Browser Version
Data type: String

Number of browser being used.

OS name
Data type: String

Name of the operating system being used.

OS Version
Data type: String

Version number of the operating system being used.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Error
Data type: String

Reason for the error (if an error occurs).

Status
Data type: String

Displays one of these status codes:

  • 0: Pending
  • 1: Running
  • 2: Successful
  • 3: Failed
  • 4: Cancelled
Progress URL
Data type: String

URL of the REST endpoint to track the progress of this request.

Status Label
Data type: String

Label of the status code that was returned, such as Pending or Running.

Status Message
Data type: String

Message with a summary of why the operation failed (if an error occurred). This value can be null.

Status Detail
Data type: String

Details on why the operation failed (if an error occurred). This value can be null.

Percent Complete
Data type: String

Status of percent complete.

Progress id
Data type: String

System ID of the execution tracker record for this request.

HTTPS Status
Data type: String

HTTP status code of the response.
