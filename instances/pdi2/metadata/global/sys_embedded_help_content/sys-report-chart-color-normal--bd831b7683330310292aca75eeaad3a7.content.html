Define a chart color

You can add records to the Chart Colors list for elements of specified tables. Role required: report_admin
  1. Fill in the fields, as appropriate.
    ColumnDescription
    NameTable used for the report.
    Note: The list shows only tables and database views that are in the same scope as the chart colors record.
    Color Hexadecimal value used to specify a color that is not already defined in the Color Definition module.
    Note: If the Color name field contains a value, the Color field is ignored.
    Color nameColor name, as defined in the Color Definition module. When a report is generated, this color is used to represent the specified Value.
    DisplayA bar in the color defined by hexadecimal value indicated in the Color or Color name field.
    ElementColumn name specific to the selected table.
    ValueValue for which the specified color should be displayed.
    UpdatedThe date and time the color was last modified.
  2. Click Submit.

The value selected in the Element field for the table in the Name field is displayed with the specified color.

The chart color is now available for data visualizations on the Configuration panel.
