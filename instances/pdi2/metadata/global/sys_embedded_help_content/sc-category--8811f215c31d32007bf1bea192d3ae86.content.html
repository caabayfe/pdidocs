Create, modify, or delete a service catalog category

  • To create or modify a service catalog category:
    1. Enter or modify the category Title .
    2. Select the Catalog that the category belongs to.
    3. Select a Location associated with the category.
    4. Select the Active check box if you want the category to be active.
    5. Select a Parent category for which this category is a subcategory.
    6. Enter or modify the Description of the category.
    7. Next to Icon , upload the icon image file that you want to associate with the category.
    8. Next to Desktop image , upload the image file that you want to be displayed with the category.
    9. Next to Header icon , upload the icon image file that you want to be displayed alongside the category header.
    10. Next to Mobile image , upload the image file that you want to be displayed with the category on a mobile device.
    11. From the Mobile Subcategory Render Type list, select the rendering option to control how subcategories are displayed.
      Select List for a single-column list, or Cards for a multi-column display.
    12. If you do not want the description to be displayed at the top of the list on a mobile device, select the Hide description (mobile browsing) check box.
    13. Click Submit or Update .
  • To delete a service catalog category, click Delete .
