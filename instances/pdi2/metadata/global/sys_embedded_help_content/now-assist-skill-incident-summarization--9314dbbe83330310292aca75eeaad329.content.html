Incident summarization skill

Configure the incident summarization skill.

Before you begin

Role required: admin

Procedure

  1. In the Choose Inputs panel, select Save & Next.
    The table and fields have preset values, and aren’t configurable.
  2. In the Choose where to display panel, use the Display switch to choose whether incident summarization appears within incident assist products.
  3. Select Save & Next.
  4. In the Review and activate panel, review your configuration and select Activate.
