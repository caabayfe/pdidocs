Create a course catalog in Workforce Optimization for ITSM

Create course catalogs and set user criteria to define user access to the course items and learning paths associated with it.

Before you begin

Role required: sn_wfo_cfg_itsm.admin

Procedure

  1. Select the Learning tab.
  2. Go to Learning course catalogs > All course catalogs.
  3. Select New.
  4. Create a course catalog.
