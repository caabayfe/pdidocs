Submit Catalog Item Request action

Create a requested item [sc_req_item] on a Service Catalog Request [sc_request].

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Catalog Item [Catalog Item]
Data type: Record

Name of the requested catalog item.

Catalog Item Inputs
Data type: String

Any extra inputs available for the selected catalog item request. For example, when the requested catalog item is a new email account, a field for Preferred Email address appears.

Quantity
Data type: Integer

Number of items requested.

Special Instructions
Data type: String

Text describing any special instructions about the item request.

Delivery Address
Data type: String

Location where the requested item should be delivered.

Requested for [User]
Data type: Record

User that the item is requested for.

Don't fail on error
Data type: True/False

Option to determine whether to fail the flow if the action produces an error.

Wait for Completion
Data type: True/False

Option to force the flow to wait until the action has been completed before continuing.

Enable Timeout
Data type: True/False

Option to limit the amount of time that the flow waits for the action to be completed before continuing. This field appears only when the Wait for Completion option is selected.

Duration
Data type: Duration

Amount of time that the flow should wait before continuing. The time is entered in hours, minutes, and seconds. If you leave this field blank, the flow does not wait. This field appears only when the Wait for Completion option is selected.

Schedule
Data type: Record

Schedule for the timeout. For example, waiting for 10 hours as part of an 8-5 weekdays schedule causes the flow to wait for one or more business days. If you leave this field blank, the timeout runs without a schedule. This field appears only when the Wait for Completion option is selected.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Status
Data type: Choice

The completion status of the action. The flow execution details page displays one of these numeric values.

  • Success [0]: The action succeeded.
  • Error [1]: The action produced an error.
Requested Item
Data type: Record

The catalog item request record created.

Error Message
Data type: String

The error message the action produced, if any.
