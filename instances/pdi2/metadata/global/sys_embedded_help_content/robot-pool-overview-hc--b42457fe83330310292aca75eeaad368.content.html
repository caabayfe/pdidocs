Robot pools

You can distribute and manage the workload among multiple unattended robots for unattended bot processes by using a robot pool. A robot pool increases the scalability, improves the performance of the robots, and helps to prevent certain robots from being overburdened while other robots are underutilized.

What you can do on this page

Create a robot pool by selecting New. For more information, see Create a robot pool in RPA Hub.

Note: After you enable the robot pool option for a bot process, you can’t assign robots from the Assign Robots tab because this tab is hidden.

Enabling a robot pool

Enable a robot pool for a bot process by doing the following actions:
  1. Associate a queue to a bot process. Map one queue to one bot process.
  2. Create a robot pool.
  3. Select the Enable Robot Pool option and configure the related fields on the Bot Process form.
For more information, see Enable robot pool for a bot process in RPA Hub.

Calculating the number of robots that you need

You can calculate the number of robots required to complete a bot process execution by selecting the Calculate button on the Bot Process form. For more information, see Calculate the number of robots in RPA Hub.

Configuring the AHT fields on the Queue form

If you're an RPA release manager or an RPA administrator, you can configure the following new fields in the Average Handling Time (AHT) - Work Items section of the Queue form:
  • Include All Work Items
  • Work Item Count
Configure these fields to decide how many robots you need in the robot pool so that the bot process executes successfully. For more information about these fields, see Queue form in RPA Hub.
