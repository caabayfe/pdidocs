Extend a class to create a new class

  1. In the Class Hierarchy , click the context menu for the class that the new class will be extended from. Click Extend .
  2. Fill out the Table form.
    See Create a table for details about the Table form.
  3. Click Submit , and wait for the new class to be added to the Class Hierarchy .
To complete the creation of the new class, complete the tasks in the Configuration (CMDB) Guided Setup that:
  • Configure Identification and Reconciliation for the new class.
  • Define CMDB Health rules for the new class.
