Maintenance requests

You can use a maintenance request to track the status of the scheduled maintenance (SM) days on the robot calendar. After a scheduled maintenance event card is accepted or rejected by either an RPA release manager or an RPA admin on the robot calendar, a maintenance request (MR) is created for tracking.

What you can do on this page

Open a maintenance request to view more details about it, such as checking what the State field is set to.
The State field can be set to one of the following:
  • Pending: When you accept the associated SM event card, an MR is created.
  • In Progress: When the planned start date begins, the MR is executed.
  • Complete: When the MR completes the execution of the configuration item (robot or bot process) and the associated Change Request (CR) is closed, the life-cycle stage status of the configuration item (CI) moves to the Published state.
  • Canceled: When an MR is canceled.
  • Failed: When a CI (robot or bot process) fails due to any issue.
  • Rejected: When you reject the associated SM event card.
