Create a scheduled extraction

Schedule information extraction to capture data from a system of record at a regular interval.

Before you begin

You must have a standard or custom ERP extraction table in place to use.

Role required: en_erp_integration.erp_user

Procedure

  1. Select the New button.
  2. On the form, fill in the fields specifying information including the frequency, extraction time, and extraction table from which to pull data.
  3. Select Save.

What to do next

Check the executions. After the scheduled job has run, select the Executions tab. For details about an extraction, select any line item in the Extraction table column.
