Operational Intelligence extension

  1. Fill in the fields on the Operational Intelligence Metrics Context page.
    MID Server:
    Depending on the selection in Execute on, the name of the designated MID Server, or MID Server cluster respectively:
    • If you selected Specific MID Server, the name of the designated MID Server.
    • If you selected Specific MID Server Cluster, the name of the designated MID Server cluster. This option is not recommended for Operational Intelligence when used in a PUSH configuration.
    If you selected the MID Server cluster option, an algorithm determines which server in the cluster runs the extension.
  2. When using the Push method for collecting Metric Intelligence data, the MID Server Metric Intelligence extension must be configured with the Enable REST Listener enabled. This option enables a listener so that a REST endpoint can receive raw metric data. The raw metric data is then placed in the regular data flow where the data is sent to the instance and the anomaly detector looks for anomalies. When selected, it adds a handler to the web server to listen for any metrics that are pushed to the MID Server. When this option is selected, the Web Server extension, which starts a Web Server on the MID Server, must also be configured. For more information, see Configure the MID Web Server extension.
  3. Click Submit.
