Filter a list

Filter the list of all your cases to find cases by subject person, opened for, or other key fields.
  1. Select the Filter icon (the funnel icon).
  2. Select Advanced view.
  3. Build a filter by adding conditions that contain a field, operator, and values.
  4. Select Update to run the filter for the list.

Change displayed columns

Change the columns that are displayed to view only what you need.
  1. Select theList Actions icon (the gear icon).
  2. Select Edit columns.
  3. Select and order the columns.
  4. Select OK.

HR case states

  • Draft: Cases in a preliminary state awaiting additional information to be entered by an agent.
  • Ready: Cases with all the information needed for an agent to start work.
  • Awaiting Approval: Cases assigned to a user for approval. The approver must approve the case to enable the state to change.
  • Work in Progress: Cases that an agent is actively working.
  • Closed Complete: Cases closed with full resolution of all related records.
  • Closed Incomplete: Cases that are closed, but the related issues and tasks may not have been resolved.
  • Canceled: Cases that are no longer needed.
  • Awaiting Acceptance: Cases that must be accepted before an agent can start working on it. Acceptance is often required for actions that have a financial or resource cost that must be approved.
  • Suspended: Suspend a case when you need additional information from vendors or third parties. When a case is suspended, time counted toward a Service Level Agreement (SLA) is stopped. Cases in the suspended state can be reopened later when the information to close the case is available.
