Planning page

Use this page to plan and track your project including project tasks and sub projects. You can analyse data grid components, view project timelines and dependencies for your project on planning page.

On the planning page, you can perform any of the actions:
  • View and add project tasks to your project.
  • Edit the project details.
  • Track activity of your project and facilitate conversation between different stakeholders.
  • Create and compare project baselines.
  • Add internal and external dependencies.
  • Use column configuration to personalize the columns in list view.
  • Add a task to your project using Add task.
  • Use resource assignment pane to manage your resources.
  • Track resource allocation using allocation heatmap. View effort by week or month in heatmap.
  • Add resources to your resource assignment using Add resource.

For more information on planning page, see Project Workspace.
