Map to Sites

To limit visibility of OT Devices to OT users who have been assigned to those sites only, add a site to the OT Device. After sites are added to OT Devices, only users with both a cmdb_ot_viewer, editor or admin role and a cmdb_ot_isa_viewer or editor role and have been assigned the same site as the OT Device will have visibility. To assign sites to OT Devices individually:

  1. Open the OT Device you want to assign a site to
  2. Update the ISA entity site field with the appropriate site value
To assign sites to multiple OT Devices at the same time:
  1. Filter the list to show only the OT Devices you want to assign to a single site that has already been created in the Equipment Model (an entity with no parent is considered a "site")
  2. Click the "ISA Entity Site" cell on the first row you want to update.
  3. Hold down SHIFT and press the down arrow until all the rows you want to edit are highlighted
  4. Click ENTER and then select the Site you want to assign to all the OT Devices

Map to Equipment Model

In the platform, OT Devices can be assigned an "Automated by::Automates" relationship with one more Equipment Model entities. To do this in the platform:
  1. Select the OT Device you want to assign to an Equipment Model
  2. Scroll down and click the "+" (plus) icon in the Related Items section header
  3. Select the suggested relationship type of "Automates (Child)"
  4. Set any additional filter criteria in the Filter section and click "Run filter"
  5. Select the checkbox next to the Equipment Model entity (or entities) that you want to build the relationship with
  6. Click the "+" (plus) icon in the "Relationships" section header to add the relationships
  7. Click "Save and Exit"
