Create or configure a dashboard

Responsive dashboards enable you to share widgets such as reports and Performance Analytics visualizations in the classic environment. Configure the dashboard for use by specific users, groups, and roles.
The most important fields for dashboard configuration are:
Group
Specify a group so that users can find the dashboard easily. You can find dashboards without a specified group in the group Other. (Users with admin, pa_admin, and pa_power_user roles only.)
Order
Enter a number to indicate the order the dashboard appears on the dashboard picker. Dashboards with lower numbers appear first in the list.
Breakdown source
In this related list, click Edit to select one or more breakdown sources to include on the dashboard. In the resulting 'breakdown dashboard,' users can select one or more elements from a breakdown source to filter the visualizations on the dashboard. (Users with admin, pa_admin, and pa_power_user roles only.) For more information, see Add breakdown sources to a dashboard.
Act as filter
Configure the dashboard to act as an interactive filter. Click the magnifier to choose a filter. (Users with admin, pa_admin, and pa_power_user roles only.)
Restrict to roles
Specify additional roles required to access the dashboard when you share a dashboard with specified users, groups, and roles. Only users who the dashboard has been shared with and who have one of the specified roles are able to access the dashboard.
