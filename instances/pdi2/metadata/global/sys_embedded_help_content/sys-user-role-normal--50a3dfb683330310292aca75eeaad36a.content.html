System user role form

Create a new role to control access to features and capabilities in applications and modules.

Name
A name for the role.
Elevated privilege
A role that requires elevated privileges to prevent the system from assigning it to a user at login.
Requires Subscription
Indicates if users with this role require allocation to a subscription in the Subscription form in Subscription Management to stay in compliance.
Application Administrator
Makes this an Application Administrator role.
Description
The roles to delegate to the group member.
