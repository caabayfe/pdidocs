Replication payload errors

View transformation errors and replications that failed to load.

Created
The creation date. Select an error to view details about a payload error.
Error message
The error message that was returned. Hover your cursor to view the full message.
Payload
The JSON payload.
Replication set
The replication set that failed. Select the name to view the replication set.
Source
The source of the failure. If the value is Seeding, the error occurred during seeding. Otherwise, the error occurred during a replication set update.
