Configuration Hub overview

Configuration Hub helps you zoom into an application or a group of applications and view all its relevant information on a single page. You can look into its corresponding tables and records and can also edit them within Configuration Hub, without having to navigate to the record in a conventional way.

This application enables you to do these tasks:
  • One-stop experience for all relevant information
  • Ability to pin your preferences
  • Track information about changes, subscriptions and customizations on a single screen
  • Ability to use multiple filters simultaneously to find a particular application or record
  • Open and edit a record within Configuration Hub
Note: The application name doesn’t populate in the search bar if it’s not yet installed on the instance. The number under the family name shows the number of applications in the selected family that have been installed on the instance. If there is a product family that doesn’t have any app installed, it won’t show up on the list.

Select one of the product families to take you to the product home page.
