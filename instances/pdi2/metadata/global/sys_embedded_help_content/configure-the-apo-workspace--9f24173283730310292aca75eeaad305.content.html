Configure the APO workspace

You must configure the APO workspace by installing APO and its dependent applications from the ServiceNow® store.

You can install the following applications in the suggested sequence to get started with APO:
  • Source-to-Pay Common Architecture [com.snc.sn_shop]
  • Supplier Collaboration Portal [com.snc.sn_supplier_sp]
  • Advanced Work Assignment for Source-to-Pay Operations [com.snc.sn_spend_awa]
  • Invoice Case Management [com.sn_ap_cm]
  • Accounts Payable Invoice Processing [com.sn_ap_apm]
  • Document Intelligence [com.snc.docintel]
  • Document Intelligent Admin [com.snc.docintel_admin]
  • Accounts Payable Operations integration with Document Intelligence [com.sn_ap_ic]
  • Source-to-Pay Workspace [com.sn_spend_workspace]
