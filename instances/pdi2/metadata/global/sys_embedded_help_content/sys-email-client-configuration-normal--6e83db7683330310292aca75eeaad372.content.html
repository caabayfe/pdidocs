Configure email client

Define a configuration that controls the display and behavior of the email client that is based on a selected ServiceNow table.

  1. On the form, fill in the fields.
    Name
    Unique name for this email client configuration.
    Application
    Type of scoped application.
    Active
    Option that indicates that the configuration is active.
    Table
    ServiceNow table that this client configuration applies to. Select a table from the list.
  2. In the Recipient Configuration section, select Recipient Qualifiers to be used for this client configuration.
  3. In the Display Configuration section, select the Display From option if you want to display the From email address in the email client.
    Select the Display Reply-To option if you want to display the Reply To address in the email client.
  4. In the Attachment Handling section, select from one of three choices for the Attachment Send Action field.
    OptionDescription
    Attach to Email RecordKeep email client attachments on the Email [sys_email] record when you send an email.
    Attach to Target RecordAttach email client attachments to the target record when you send an email.
    Conditionally Attach to Target RecordSet conditions that define which email client attachments are moved to the target record when you send an email. Attachments that do not meet the conditions remain on the email record when you send an email.
    • In the Filter Configuration section, select Email Address Filters to be applied to the email client.
      Note:
      • Configurations with email address filters that have only deny lists require that evaluated addresses pass all deny lists to be considered valid.
      • Configurations with email address filters that have only allow lists require that evaluated addresses pass at least one allow list to be considered valid.
      • Configurations with email address filters that have both deny lists and allow lists require that evaluated addresses pass all deny lists and at least one allow list to be considered valid.
    • Click Submit.
