Search enterprise portfolios

Service-related enterprise portfolios are created with Service Portfolio Management tables. You can view them as well as enterprise portfolios that were created in DPM — business application portfolios and application service portfolios.

Before you begin

Role required: sn_dpm.dpm_manager

Procedure

  1. Select the Portfolio search field.
  2. Select a portfolio type that you want to view:
    • Service portfolios
    • Business application portfolios
    • Application service portfolios
  3. After you select the portfolio type, you can find the portfolio you seek by one of two ways:
    • Enter the portfolio name or a few letters of the portfolio name in the Search field.
    • Follow the content tree until you find the portfolio you seek.
  4. After you find the portfolio, select View details to access the details page of the portfolio.
  5. Optional: Search for a different enterprise portfolio type.
    Delete the value in the Portfolio search field, and then select the field again to see the list of enterprise portfolio types.
