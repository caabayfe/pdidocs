Product home page

Select one of the product families to go to the product home page where you can explore different functionalities of Configuration Hub.

The product home page enables you to do these tasks:
  • View and track the total errors, subscriptions, slow executions, and customizations on the singleOverview page
    Note: The total errors are weekly comparisons and the total customizations are tracked for the last 7 days.
  • View all the applications that have been installed on the instance as part of the selected product family
    Note: The core applications are hidden by default. It is recommended not to make any changes to the core applications to avoid rise in the number of skipped records during an upgrade.
  • Select See details or Explore files to read more about the selected applications or to list the records in the selected application of the product family.
  • Drill down to a particular application or record using the Explore tab
  • Search for table names, sys_id, or relevant records in the Configuration tables search bar
    Note: You can also make the files display as per their machine names
  • Select a table from the left nav bar and all its related records show up.
    Note: The number mentioned next to the table name is the number of records in that table and they also satisfy the Applications in filter on the right top corner.
  • You can make edits in the records directly within Configuration Hub.
