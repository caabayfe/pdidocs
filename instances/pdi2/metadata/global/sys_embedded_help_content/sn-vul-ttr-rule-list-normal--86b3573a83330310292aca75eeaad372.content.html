Create a remediation target rule for vulnerable items

Create remediation target rules to define the expected time frame for remediating a vulnerable item (VI). These rules can help you send reminders to remediation owners and track their remediation progress. Role required: sn_vul.vulnerability.admin.

Create remediation target rules by defining the remediation target date, the reminder target date, or the reminder and the notification recipients for VIs that are not Deferred, Resolved, or Closed. Remediation target rules are run on import, and if an existing VI is reopened. You can activate or deactivate rules from this list. You can also change and reapply the target rules on this list. If multiple target rules are applied to the same VI, the most restrictive rule is the applied rule.

  1. To create a new rule, click New.
  2. Review the following key terms and field descriptions to help you define the rule.
    Target (days)
    Enter the number of days remediation owners have to fix the VI. Remediation targets are calculated from the Last Opened date plus the number of days you enter (measured as 24-hour increments). For example, if a VI was last opened on the first day of the month, and the remediation target is 15 days, the remediation date is the 16th day of the month. If another target rule also applies to this VI that has a lower value for target days, the most restrictive rule applies.
    Notify (days before due)
    Enter the number of days before you want to send out reminders.
    Condition builder
    Set specific criteria for the vulnerable items you want the rule to apply to with the condition builder. An example might be, Risk rating is 1- Critical.
    Notifications
    Notify users and/or user groups that a target date is approaching.
  3. Fill in the fields.
  4. Click Submit.
  5. Alternatively, if you have changed target rules, click Apply Changes to rerun all changed rules on all active, Open vulnerable items.
