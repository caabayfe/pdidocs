Incident activity response in NACM: Configure experience

Configure actions for the context menu after you activate the skill.

The default trigger actions are as follows:
  • For Work notes, the actions are Summarize actions, and Post response.
  • For Additional comments, the actions are Follow up, Post response, and Acknowledge task.
Note: When you select the Now Assist icon in the Preview panel, it shows how the generated activity response will display in NACM.
