Interactions

Interactions are a centralized location for all communication channels in the platform. Each interaction represents a request for assistance through a given channel, for example, a call or a chat.

Select New to create a new interaction record.

Number
The ID number assigned to the interaction
Opened for
The user who started the interaction
State
The current state of the interaction
Type
The type of customer interaction (chat, messaging, or phone)
Assigned to
The name of the assigned user
