Configure system properties

This task requires either the admin or cmdb_ot_isa_admin role.

The following system properties are available.
sn_isa_model.cmdb_relationships_sync_levels
Number of levels of CMDB relationships to be Synchronized (Default 8).
sn_isa_model.short_code_validation_max_length
Maximum length for the Short Code Validation (Default 3).
sn_isa_model.user_search_matching_attribute
Column name on User table [sys_user] to be used to match with a user in the system. By default, the email column on the User table is used.
Note: Set these system properties before creating or importing the data.
