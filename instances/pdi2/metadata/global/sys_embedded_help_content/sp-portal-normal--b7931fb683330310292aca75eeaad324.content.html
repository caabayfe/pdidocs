Create a portal

Create a portal for users to browse company resources, discover articles, and get help.

  1. On the form, enter a Title for the portal and then fill in the following fields.
    URL suffix
    A string to append to the instance URL to access the portal. For example, if you use sp, the instance URL for the portal would be <instance name>.service-now.com/sp.
    Homepage
    The first page that users see after signing in.
    Theme
    The lowest-level theme to define the style and branding of the portal.
  2. Select Submit.
