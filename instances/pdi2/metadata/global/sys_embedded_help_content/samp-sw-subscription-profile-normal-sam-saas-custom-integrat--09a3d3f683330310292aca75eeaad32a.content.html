Creating a custom integration profile

Create a custom integration profile to connect any SaaS application to the NOW platform. View software usage information and optimize stale licenses.

Important: Before you can create the integration, you will need to set up a method of authentication (such as OAuth, JWT, or an API token) in the SaaS application admin or developer account.

Setting up a custom integration requires several tasks in addition to creating the integration profile. You will need to create a custom spoke if there is not an existing IntegrationHub spoke for the SaaS application you want to integrate with. You will also need to create subflows and actions to update your ServiceNow instance with data pulled from the SaaS application. If you are using an existing IntegrationHub spoke, check if it has actions that you can use before creating new actions.

After you save the integration profile, add the subflows to the profile. Add the download subscription subflow and then publish the integration profile. Then, add the calculate activity and reclaim subscription subflows and save the integration profile.
