Report Statistics list

Report statistics show how many times a report has been run and how long on average it takes to execute the run. The Report Statistics list displays all reports that have been run.

Click the column headers to search, sort, filter, and edit data.

  • Report – The name of the report. Click the hyperlink to view the report properties.
  • Last run – The date and time the report was last run.
  • Runs – The number of times the report has been run.
  • Runs on page – The number of times the report has been run on a dashboard or homepage.
  • Runs on schedule – The number of times the scheduled report has run according to schedule.
  • Recent run time – The average execution time of the report in milliseconds based on the 25 most recent runs. Edit the glide.report.recent_executions_number property to change the number of runs used to calculate this value.
  • Run time – The average execution time in milliseconds of all runs of the report.
  • To view the reports that take the most time to run, sort Recent run time from z-a.
  • To view used reports, filter out the value 0 from the Runs column.
  • To view the most used reports, sort the Runs column from z-a.
