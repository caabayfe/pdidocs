Dashboard settings

You can set refresh interval details and background colors, enable data caching to speed page refreshes, and choose which Insights cards to show.

To open dashboard settings, select the Settings icon.

You have the following settings you can change:

Data refresh settings

Background color settings

Select a color from a list of preconfigured colors, or use the color palette to specify a color.

Insights

Choose whether and which analytics to show.

When you turn on Show insights panel, an Insights button is added to the dashboard. When a viewer presses this button, insights cards corresponding to the selected analytics options are shown. For more information, see the Insights help topic or the product documentation.
