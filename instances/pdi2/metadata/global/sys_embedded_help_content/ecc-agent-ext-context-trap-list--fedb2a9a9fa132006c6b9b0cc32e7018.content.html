Process SNMP traps

You can set up SNMP trap listeners to process SNMP traps sent to ServiceNow from third party monitoring tools.

Event Management can process SNMP traps as events. In this configuration, a MID Server acts as a collection endpoint for SNMP traps. Event Management can then periodically pull events from the MID Server.
To add a new SNMP trap collector, click New or click an existing SNMP trap collector to modify it.
