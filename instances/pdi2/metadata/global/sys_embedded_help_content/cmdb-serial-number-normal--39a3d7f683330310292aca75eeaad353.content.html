Define the serial number and type

Serial number types vary depending on the configuration item (CI). You define serial number and its type for each CI in this form.
  1. Select the CI in the Configuration Item field.
  2. Enter the serial number for that CI.
  3. Enter the serial number type for that CI.
    The supported serial number types are categorized for Linux, Windows, and SNMP.
