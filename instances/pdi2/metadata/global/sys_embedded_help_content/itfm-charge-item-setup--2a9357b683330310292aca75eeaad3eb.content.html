Determine the statement item type

  1. Define a statement item depending on the source of your consumption data.
  2. Determine the statement item based on the data source.
  3. Select the type of statement item you want to create.
    FieldDescription
    Consumption Statement ItemClick the link to create a consumption statement item.

    If your cost and business service usage details are sourced from a consumption table, then create a consumption statement item to source the consumption details of the consumption table for the statement item.

    Cost Model Statement ItemClick the link to create a cost model statement item.

    If the cost of an item or service is derived from the allocation lines of financial modeling application, then create a cost model statement item.

    Service Catalog Statement ItemClick the link to create a service catalog statement item.

    If a business service request is fulfilled from a service catalog category or a catalog item, then the price listed for the service in the service catalog item is captured as the cost of the statement item for a fiscal period.

  4. Enter the respective form fields.
  5. Click Submit.
