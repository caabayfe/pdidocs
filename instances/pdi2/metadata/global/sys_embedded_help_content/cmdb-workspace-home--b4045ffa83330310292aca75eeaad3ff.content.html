CMDB Workspace

The CMDB Workspace provides access to a wide range of CMDB applications and features.

Overview of CMDB Workspace

Use CMDB Workspace to search and explore the CMDB, examine health and recent activity, and access CMDB dashboards and tools.

For CMDB Workspace to provide meaningful reports, overviews, and trends, you must set up and configure some of the CMDB features, such as CMDB Health or Governance.

Roles

CMDB Workspace requires at least one of the following roles:
  • CMDB Admin (sn_cmdb_admin)
  • CMDB Editor (sn_cmdb_editor)
  • CMDB User (sn_cmdb_user)
Particular roles have access to only some CMDB Workspace features. Some dashboards and list views require specific roles.
