View policy details

You can view details of an existing policy including the versions, mapping information, and any exceptions.

Details

The details of the policy including the policy name, category, date on which it was created, and a description is displayed. You can also see the following details:
  • State: The policy status is Inactive by default. You can activate a policy if have a Current published policy version. Click the More Actions icon and select Activate to activate the policy.
  • Exception status: Click the More Actions icon and select Enable exceptions to enable exceptions for the policy and associate it with a control objective in GRC.
  • Lock status: Default policies are locked and cannot be used directly. You can make a copy of a default policy and configure it based on your requirements.

Versions

Click the Versions tab to view the Versions page. When you create a policy, by default a draft policy version is created. Each policy version contains version meta-data, a policy script, and variable input definitions, which you can modify according to your requirements. From the Versions page, you can:
  • Create a new policy version
  • Edit a version
  • Duplicate a version
  • Compare policy versions

Mappings

Click the Mapping tab to define the object (table and document ID) to which the policy is to be mapped.
