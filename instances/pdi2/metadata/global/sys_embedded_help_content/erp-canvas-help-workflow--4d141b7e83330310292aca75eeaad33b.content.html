Workflow for using Zero Copy Connector for ERP

The following is a general workflow for using Zero Copy Connector for ERP to connect to and manage ERP (Enterprise Resource Planning) systems, ERP models, extractions, and remote tables.

  1. Have your administrator use the Connections and Credentials app to configure credentials to connect to the ERP system of record.
  2. Create an ERP system in Zero Copy Connector for ERP using the connection and credentials alias that you configured.
    Note: The rest of the workflow steps are in Zero Copy Connector for ERP. Build your ERP systems, ERP models, and tables in a development instance, and then promote them to a production instance when you're ready.
  3. Create or clone an ERP model that scans the specified ERP module in the system of record for available tables and fields. Note the tables and fields in the ERP model for use in extraction and remote tables.
  4. Add new tables, fields, and join conditions to include additional data in the ERP model.
  5. Work with remote tables to make them available for use as a data source, for example, when building apps in App Engine Studio.
  6. Work with ETL (extract, transform, load) extraction tables to scan the system of record on a regular basis and extract data to a staging table.
    • Create as many separate extraction tables as needed, for example, one for each supported country.
    • You must first create the table transform map that connects the source table (on the system of record) to a Glide table on the ServiceNow AI Platform.
    • Extraction processes are configured in the ServiceNow app that uses them. For example, Workflow Studio.
    • After the extraction process is run, use import sets to map imported data into ServiceNow AI Platform tables.
  7. Move the ERP systems, ERP models, and tables to a production environment when they are ready.
  8. Use the ERP data that is now available as the data source when building apps on the ServiceNow AI Platform, such as:
    • App Engine Studio
    • Workflow Studio
    • Table Builder
    • UI Builder
    • Workspace Builder
