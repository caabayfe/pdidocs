SNMP system OIDs

The SNMP classifier uses SNMP object identifiers (OID) to match known network devices by their unique object ID values. When Discovery finds a matching OID value, it uses the information to populate the CMDB with the specified manufacturer, model, and classification.
Note: SNMP OIDs must be manually attached to SNMP classifiers and are listed in the SNMP OID Classifications related list in the SNMP Classification form.
  1. Enter the OID for the network device in the Oid field.
  2. Enter the manufacturer and model information in the appropriate fields.
  3. Select the appropriate table for the device from the Table field.
  4. Select the classifier to which this OID is attached from the Classifier field.
  5. Click Submit.
