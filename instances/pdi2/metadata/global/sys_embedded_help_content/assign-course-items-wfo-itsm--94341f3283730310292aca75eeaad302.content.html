Assign course items to agents

Assign a course item to one or more agents and add a due date for them to complete the course.

Before you begin

Role required: sn_wfo_cfg_itsm.manager

Procedure

  1. Select the Learning tab.
  2. Select Learning Courses > All Courses.
  3. Select the Assign icon () for the course item you want to assign to agents.
  4. In the Assign learning course screen, assign the learning course to groups or team members.
    1. If the agents have to complete the course item within a given date, select the Mandatory check box.
    2. In the Due date field, select the date by which they need to complete it.
    3. Select Assign.
