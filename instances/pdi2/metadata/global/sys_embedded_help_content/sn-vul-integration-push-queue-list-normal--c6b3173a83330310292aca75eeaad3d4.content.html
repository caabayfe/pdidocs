Verify upload status

Ensure that the integration run is successful. Role required: sn_vul.vulnerability_admin.

Verify whether the vulnerability integration run was successful, partially successful or a failure.

  1. Navigate to All > Vulnerability Response > Manual Vulnerable Item Ingestion > Upload File History.
  2. In the Vulnerability Integration Push Queues table, check the time of the upload and status of the upload in the Created and State columns respectively.
  3. Click the vulnerability integration run number to view detailed notes on the reason for success or failure in the Notes field.
