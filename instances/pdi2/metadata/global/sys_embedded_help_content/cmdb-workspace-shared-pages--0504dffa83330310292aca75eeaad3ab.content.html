Shared Pages

Track the relationships between a CI and the services it supports. This page template also enables you to drill down into the services in each class.

You can use this page template to:
  • Directly access a dependent CI.
  • Track services that might be affected by an outage or a change.
  • Open a dashboard to view details for a dependent service.
  • View tasks, incidents, or change requests associated with a service.

The Content Tree component helps you review the parent and child nodes in a collapsible hierarchical structure. Each child node in the tree is linked to records displayed in the tabs.
