Viewing table rules

View a summary of the data management rules on a table.

Total rules

View the total number of data management rules created on the current table. See the number of active and inactive rules for the current table.

Records in backlog

Track the count of records in the current table that meet the requirements of a data management rule but haven't been processed yet over time.

  • Track the progress of different types of data management rules over time.
  • Monitor rule processing efficiency by checking for increases in the backlog count over time.
  • Check for bottlenecks that indicate a large number of records in the backlog waiting to be processed.
  • Look for spikes in the backlog across different types of data management rules. Consider scheduling rules at different times to avoid an influx of backlog records.

Rules executed in the last 7 days

View a summary of recent rule activities for the current table. Sort the list by rule type and view the number affected records for each executed rule.

Rules

View a list of the data management rules on the current table.

  • Determine whether a rule is active or inactive by checking the Status column.
  • View which types of rules are configured by checking the Type column.
  • Monitor the number of records that meet the conditions for a rule but haven't been processed yet by checking the Records in backlog column.
  • View a summary of records in the backlog and rule execution history for a specific rule by selecting a rule in the list.
  • Create a new data management rule for the current table by selecting New.
