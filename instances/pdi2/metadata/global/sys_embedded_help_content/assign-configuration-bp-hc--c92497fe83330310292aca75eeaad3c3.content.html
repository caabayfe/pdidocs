Assign a bot process configuration record

Select only one bot process to associate it with a bot process configuration record. By doing this action, you create a bot process record. A bot process is a predefined sequence of actions that a robot follows to accomplish a specific task or achieve a particular goal so that you don't have to do this work manually.

Before you begin

Before you assign a bot process configuration record, create a package and a robot. For more information, see Create a package to assign to a bot process and .

Before you can access a bot process, make sure that the Robotic Process Automation (RPA) business user (sn_rpa_fdn.rpa_business_user), RPA developer (sn_rpa_fdn.rpa_developer), or the RPA support user (sn_rpa_fdn.rpa_support_user) are in the Managed by Group list.

Role required: sn_rpa_fdn.rpa_release_manager or sn_rpa_fdn.rpa_admin

About this task

A bot process configuration record contains the bot process settings. The bot process configuration record is mapped to a bot process record. You can only select one bot process record to associate with a bot process configuration record. You can't edit a bot process configuration record that is associated with a bot process.

When you retire a bot process record, you can't associate the related bot process configuration record to other bot processes.

You can create a bot process configuration record in two ways. The first way is when you create and save a bot process configuration record.

The second way is when you move an update set from a lower environment to a higher environment, then an orphan bot process configuration record is created. After you select the Assign Configuration button and its record, the bot process record that is associated to the bot process configuration is created.

For more information about migrating your metadata from a lower environment to a higher environment, see Migrating your data from a lower environment to a higher environment in RPA Hub.

Procedure

  1. In the form header, select the down arrow in the Create Configuration button.
    For more information about creating a bot process configuration, see Create a bot process configuration record in RPA Hub.
  2. Select Assign Configuration.
  3. Select a bot process configuration record to associate it with a bot process.
  4. Select Submit.
  5. On the Bot Process form, fill in the fields.
    For a description of the field values, see Bot Process form in RPA Hub.
  6. Select Save.
