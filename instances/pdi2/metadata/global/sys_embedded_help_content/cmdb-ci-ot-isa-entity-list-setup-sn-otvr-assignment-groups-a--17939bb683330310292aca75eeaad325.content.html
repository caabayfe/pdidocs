Create an OT VR assignment group

Roles required: admin role or both cmdb_ot_isa_admin and user_admin roles

Create an OT VR assignment group. The assignment group should have the same name as the site it relates to. For example, if your site is in Milan, name this group the Milan OT VR Assignment Group.

  1. In the OT VR assignment group field, select the search icon to open the window displaying existing user groups.
  2. Select the correct OT VR assignment group depending on if the group exists.
    • If the desired group exists, select it from the list.
    • If the desired group doesn’t exist, select New to create the group. After filling in the form, select Submit.
  3. After returning to the site record, select Update to save the new OT VR assignment group.
