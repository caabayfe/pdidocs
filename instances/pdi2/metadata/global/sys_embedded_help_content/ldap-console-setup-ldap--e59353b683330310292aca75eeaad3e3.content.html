Import data using LDAP integration

Integrate your ServiceNow instance with your LDAP database to populate records into the tables that store information related to companies, users, locations, departments, groups, and group members. The integration uses the LDAP service account credentials in a read-only connection with the LDAP database and then updates the database of your instance with the queried information. You can map fields in an LDAP table to the fields in the target table of your instance before populating the records.

  1. Select an LDAP server.
    Alternatively, click Add New Server, and then complete the form to configure an LDAP server.
  2. Click Next to test the connection to the server.
  3. On the OU Definitions tab, select an organizational unit.
    Alternatively, click Add New OU and then complete the form to define an organizational unit.
  4. On the OU Definitions form, click Edit Transform Map.
  5. In the Field Mapping Assist window, perform the following steps:
    1. Create a field map between the source and the target tables.
    2. Click Next.
    3. Set the appropriate coalesce options.
    4. Click Save.
  6. Click Transform & Load.
