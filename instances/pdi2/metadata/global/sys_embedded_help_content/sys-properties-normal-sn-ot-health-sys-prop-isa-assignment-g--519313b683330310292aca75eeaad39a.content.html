Assign default assignment group for an OT alert

Assign True to the Value field to enable the sn_ot_health.ot_alert.isa_assignment_group_enabled property to assign a default assignment group for an OT alert. The default value is false.

The default assignment group is based on the assignment group of an equipment model entity for which the OT alert has been generated.

If the assignment group value is empty at the equipment model entity level, then the assignment group value at site level is considered.
