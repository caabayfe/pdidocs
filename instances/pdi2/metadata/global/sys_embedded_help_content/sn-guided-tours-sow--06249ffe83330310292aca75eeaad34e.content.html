Guided Tours

Guided tours help navigate and understand various features and functionalities. To access a guided tour, scroll down this list of help topics to find the Take a Tour or Select a Tour option. Note, this option is shown only when a guided tour is available for this UI page.

Access Guided tours

To access a guided tour, select the < Back option to return to the list of help topics. Scroll down to find the Take a Tour or Select a Tour option.
Note: This option is shown only when a guided tour is available for this UI page. Navigating to other UI pages will display the available tours here.

Create guided tours

To create additional guided tours, navigate to the All > Guided Tour Designer > Create Tour.
