Create New Knowledge

Create and edit knowledge articles within a knowledge base to share information across your organization.

Before you begin

Role required: sn_eam.enterprise_admin

Procedure

  1. On the Create New Knowledge page, fill in the details.
    For a detailed description of the fields, refer to the product documentation link in the Related information section.
  2. Select Save to create the article.
