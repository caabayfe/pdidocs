Export impacted CIs for software by a publisher

You can track the impacted assets list for new software by exporting the configuration items (CIs) related to an exposure assessment record to an excel sheet. This sheet can be used to share the assets details and owners to create incidents with the known impacted assets for the zero-day vulnerabilities.

Before you begin

Role required: sn_vul_analyst.vul_event_manager

Procedure

  1. Navigate to Workspaces > Vulnerability Assessment Workspace > Exposure Assessment > Assess by Publisher.
  2. Select the discovery model for the record whose CIs you want to export.
    The Software Installations tab contains the active CIs related to the software record. These CIs are stored in the Installed on column.
  3. Select the Export option.
  4. In the Export dialog box, select the File Type and Delivery Type to export the related CIs.
  5. Select the Export option.
