Associate an assignment group with the resource conversion formula

You can assign a forecast configuration to multiple assignment groups, but an assignment group can have only one forecast configuration.

  1. Select New.
  2. On the form, fill in the fields.
    Assignment Group
    Select the group to which you want to associate a forecast configuration.
    Forecast Configuration
    Select a resource conversion formula.
  3. Click Submit.
