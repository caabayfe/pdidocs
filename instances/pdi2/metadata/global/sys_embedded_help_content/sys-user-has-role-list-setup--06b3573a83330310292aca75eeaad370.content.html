User roles

Roles help control access to features and capabilities in applications and modules.

Review the default user roles to determine whether they align with your business needs.

To view the complete list of currently available user roles, click Show All. The users that are assigned with the selected user roles are displayed in the pane next to the list of roles.

To create a new user-role association, click New.

To edit the list of roles assigned to a user, click the user name in the list.
