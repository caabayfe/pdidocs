Page Route Maps

Page route maps redirect references to portal pages to a different page. View the page route maps configured for portals on the instance, where they route to and from, and their priority order. You can access all page route map records from this list by selecting the short description.

Service Portal(s)
Portals that apply the redirect. If this is empty, the redirect applies to all portals in the instance.
Route from
ID of the original page to redirect from.
Route to
ID of the new page to redirect to.
Order
A number that indicates in what order page route maps apply. If more than one active record has the same value in the Route from field, the record with the lowest order applies.
