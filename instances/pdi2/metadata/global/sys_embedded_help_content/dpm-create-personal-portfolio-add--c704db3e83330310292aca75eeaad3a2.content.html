Add items to a new personal portfolio

The second step to creating a new personal portfolio is to add items. You can add services, service offerings, business applications, and application services.

Before you begin

Role required: sn_dpm.dpm_manager

Procedure

  1. Search for the items you want to add.
    • In the Search field, enter the first few letters of a service, a service offering, a business application, or an application service to add.
    • You can also search a name to show all items owned by that name.
  2. Select the items that you want to add.
    The Add Items options are grouped by Business Applications, Service/Service Offerings, and Application Services. Use the page advancement option when there are multiple pages to select from.
  3. After you select the items to add, select the appropriate add option.
    • Add selected Business Applications
    • Add selected Services/Service Offerings
    • Add selected Application Services
  4. Select Next.
