Create alignment integrations

The ServiceNow Internal Alignment integration is created by default. In case the alignment integration is not available, you can create your alignment integration type.

  1. Select the ServiceNow Internal Alignment integration, to view the Strategic Planning integrations with Project Portfolio management (PPM), Agile Development 2.0, and Scaled Agile Framework (SAFe).
  2. If an Alignment integration is not available, select New, to create a new alignment integration.
  3. Enter the name of the alignment integration in the Name field.
    Alternatively, you can also click Create ServiceNow Internal Integration from the related links to create an internal alignment integration.
  4. Click Submit.
