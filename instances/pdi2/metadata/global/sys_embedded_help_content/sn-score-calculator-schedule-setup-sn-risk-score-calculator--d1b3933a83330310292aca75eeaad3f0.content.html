Configuring Risk Score Calculator for Operational Technology Obsolescence Management

Role required: sn_risk_score_calc.admin

Perform the following steps to configure the Risk Score Calculator:

  1. On the form, fill in the fields.
    Select the Active checkbox.
    This enables the default scheduler.
    Update scheduling frequency of the score calculation and handling score calculation ownership.
    The schedule is currently set to Run = On Demand by default. Admin can select a different value for Run to change the frequency of the score calculation.
    You can also assign a different user to run the score calculation. Select Run as to change the user.
  2. Select Execute Now.
