Track the progress of your solutions

In the build phase, track the progress of work being delivered for your solutions, including projects, changes, and improvement initiatives.

Build tab

The build phase of the plan-build-run life cycle enables you to track the progress of work being done for your solutions.
  • Select View roadmap to track the roadmap dependencies for your solutions.
  • View projects.
    • Select a graph status (color or month) to view the list of project records.
    • Select a card to see a list of the stated records.
    • Select an active project record to view its details, agile information, stories, epics, and more.
  • View changes.
    • Select a change graph status (color or month) to view a list of change records by state or changes that are overdue.
    • Select a change card to view a list of change records that are upcoming or backlogged.
  • View improvement initiatives.
    • Select an improvement initiative graph status (color or month) to view a list of Continual Improvement Management (CIM) records by state or CIM records that are overdue.
    • Select a change card to view a list of change records that are overdue or closed in the last month.
    • Select a CIM record to view its details, CIM phase, tasks, impacted key performance indicators (KPIs), approvers, demands, and projects.
