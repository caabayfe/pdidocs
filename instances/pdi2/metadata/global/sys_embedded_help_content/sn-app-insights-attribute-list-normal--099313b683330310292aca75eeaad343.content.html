Set up success indicator attributes

Configure attributes that can give you meaningful insights when comparing top-performing vendors.

The fields for a selected table display all supported string and numeric data types. The allowed data types are defined in the sn_app_ml_insights.attr_datatype_inclusion_list system property.

  1. Set up table attributes.
    1. Configure attributes for the Company [core_company] table.
      • To configure a field that has a string datatype, select the datatype, save the form, and create desired categories in the Success Indicator Attribute Categories related list.
      • To configure a field that has a numeric datatype, select the datatype and submit the form.
    2. Configure attributes for any table other than the Company [core_company] table.
      1. Select any table other than Company [core_company].
      2. Select the field name.
      3. Select the Field Value or Record Count collection type.

        The application sets the relationship between the base evaluating table and the table used for selecting the attribute using the sourceIDField and encodedQuery fields.

      4. Select Submit.
  2. Set up indicator attributes.
    On the form, fill in the fields.
    Name
    Unique name for the evaluating attribute.
    Type
    Choose Indicator.
    Indicator
    Indicator with the Company [core_company] breakdown from which you want to derive attributes.
  3. Select Submit.
