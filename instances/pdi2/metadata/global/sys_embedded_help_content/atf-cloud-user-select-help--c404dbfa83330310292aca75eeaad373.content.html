Cloud user selection

Set the cloud user credentials to generate and execute tests.

Note: This is a one time setup after the admin user installs the application.
Important points to ponder for this page:
  • Only admins can see the Select Cloud User module to setup the credentials
  • Select a dedicated admin user from the list
    Note: If the selected user is not an admin, an error message shows up. The error message may vary depending on the reason of the error.
  • Selecting and setting up an admin user usually takes time
