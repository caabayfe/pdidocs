Script only check form

Create a check without specifying a table or a column type by selecting Create a new Script Only Check. You can verify meta data, configurations, and execute complex checks by writing your own script.

Script
It contains custom script to generate findings. It runs only during a full scan and gets executed only once during a scan.
Version
Whenever you make an update to a check, the Version field auto-increments. It creates traceability to the version of the check that resulted a particular finding.
Note: To add or update a check, you can give a test run by clicking Test Check. The test runs don't show up in your reports.
