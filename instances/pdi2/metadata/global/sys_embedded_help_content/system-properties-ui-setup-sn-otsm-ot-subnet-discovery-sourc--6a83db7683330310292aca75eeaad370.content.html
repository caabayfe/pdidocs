Select discovery sources

Roles required: admin

  1. Map OT devices for all discovery sources:
    • Yes - all OT devices are considered for mapping (default)
    • No - only the discovery sources listed under Map OT devices for specific discovery sources are considered for mapping
  2. Map OT devices for specific discovery sources.

    Enter a single name or a comma-separated list of names appearing in the discovery_source field on the configuration item tables.

    For example, ServiceNow SG-OT, Excel Import

    Note: If the Map OT devices for all discovery sources field is set to No and the Map OT devices for specific discovery sources field is empty, no OT devices are mapped.
