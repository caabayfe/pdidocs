Create an application category

Create an application category to group the applications by their purpose and function, fields, or areas.

Before you begin

Role required: sn_apm.apm_admin

Procedure

  1. Select Application Categories.
  2. Select New.
  3. Enter a name, select a group, and add description for the application category.
  4. Select Save.
