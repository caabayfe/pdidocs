Create a Discovery process classification

A process classification allows Discovery to create a particular CI type from information gathered during the identification and exploration phases. When a process matches the classification criteria, Discovery uses the process classification record to create a CI.
  1. Complete the fields in the form.
  2. Right-click in the header bar and select Save from the context menu.
  3. Populate the information in the related lists.
