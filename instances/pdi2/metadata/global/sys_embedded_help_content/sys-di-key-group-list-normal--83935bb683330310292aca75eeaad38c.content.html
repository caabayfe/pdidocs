Field groups

Field groups help DocIntel extract data from documents with tables, check box lists, and other logical groupings of fields.

The Field Groups list shows the DocIntel field groups in your instance.
  • Select (or right-click) the column headers to sort, filter, and edit the list.
  • Select the Personalize list icon to choose the columns in your list.
  • Select a field group to view and edit the field group details.

The Field Groups list includes the following significant columns:

Display Name
Name of the field group
Use Case
Use case associated with the field group
Target Table
Table where you want to save the extracted data

For an improved DocIntel setup, configuration, and monitoring experience, install the Document Intelligence Admin application.
