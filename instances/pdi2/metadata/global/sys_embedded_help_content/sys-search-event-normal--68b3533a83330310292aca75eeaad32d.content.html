Create a Search Event

Role required: admin.

Use this form to create a Search Event, to generate and track relevant search suggestions.

  1. On the form, fill in the fields.
    Search query
    Search string that the user entered.
    Name
    Name of the search event.
    Has results
    Boolean value that specifies whether the search did (true) or didn't (false) return results.
    Click rank
    Ranking of the item selected from the list of suggestions.
    Refinements
    Number of actions taken to reduce the number of search results.
  2. Click Submit.
