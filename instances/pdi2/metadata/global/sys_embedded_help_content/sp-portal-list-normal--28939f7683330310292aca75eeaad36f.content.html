Service Portals

View the list of portals configured on the instance, the URL suffix to access them, their theme, and when they were last updated. You can access all portal records from this list by selecting the portal title.

URL suffix
The string appended to an instance URL to access a portal. For example, if you use sp, the instance URL for that portal would be <instance name>.service-now.com/sp.
Theme
The lowest-level theme that defines the style and branding for the portal.
