Edit columns in a list

Edit the columns that appear in a list, arrange the order of the columns, and save the list to the My Lists tab.

  1. Select the List Actions icon () at the top of a list.
  2. Select Edit columns.
  3. In the Edit List pop-up window, move the columns that you want to display to Selected columns.
  4. Select and drag the columns in Selected columns to the desired order.
  5. Select OK.
  6. To save this list to My Lists, select the List Actions icon and select Save as.
  7. Enter a name for the list in the Save as pop-up window and select Save.
