Automation logs

An automation log is a series of stages or checkpoints that occur when a bot process is executed. A log enables you to monitor and audit the automation process. These logs are generated from the robot for unattended and attended bot processes.

To view the automation logs of a bot process in RPA Desktop Design Studio, use the log component in the associated automation and populate the required details. For more information about the component, see Use the Log component.

Make sure that the Track Automation Logs check box on the Bot Process form is enabled. For more information, see Bot Process form in RPA Hub.

What you can do on this page

Open an automation log to view more details of the associated process job, message, and log level (error, exception, info, warning). For example, when a robot executes an Invoice Processing bot process, you can view the following messages in the Message field of an automation log:
  • Bot started the invoice processing automation.
  • Emails retrieved successfully.
  • Invoice data extraction in progress.
  • Invoice categorization initiated.
  • Update to accounting system in progress.
  • Invoice processed successfully.
