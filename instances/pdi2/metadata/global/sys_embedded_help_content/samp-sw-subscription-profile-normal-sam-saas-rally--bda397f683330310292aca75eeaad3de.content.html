Creating a Rally integration profile

Create an integration profile to connect your Rally applications with the ServiceNow AI Platform. Use this integration to view software usage information and optimize stale licenses.
Important:

Before you can save and publish the integration profile, you must register the Rally OAuth application to access the Rally API 2.0 and to receive a Client ID and Client secret.

In addition, you must create a connection between the Rally application and your ServiceNow instance so that you can retrieve user data from your Rally applications.

The Rally integration profile uses the Download Subscriptions and Reclaim Subscription subflows to retrieve user data from your applications.
