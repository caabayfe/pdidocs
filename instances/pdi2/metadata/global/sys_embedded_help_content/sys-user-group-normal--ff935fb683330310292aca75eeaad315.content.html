Create or modify groups for Advanced Work Assignment queues

Role required: awa_manager or admin

Create or manage groups that have associated Advanced Work Assignment queues.

  1. On the form, fill in the fields.
    Active
    Option that indicates whether the group is active or inactive.
    Parent
    Other group of which this group is a member. If a group has a parent, the child group inherits the roles of the parent group. The members of the child group are not members of the parent group. For example, if an incident is assigned to the parent group and you click the Assigned to look up icon, only the members in the parent group are available. The members of the child group are not available.
  2. Select Submit.
  3. If you want to configure the queue priority order for the group, select the group name on the list.
  4. Select the Queues related list at the bottom of the screen.
  5. Double-click in the order number field you want to change.
  6. On the pop-up Order dialog, enter the new order number.
  7. Select the green check mark to save the change.
