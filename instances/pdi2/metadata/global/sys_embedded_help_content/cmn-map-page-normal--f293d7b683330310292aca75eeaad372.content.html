Create a Map Page

Use this form to create a map page for use in the Classic Environment. Map pages display ServiceNow data graphically on a Google map page based on location data that you provide. You can create as many map pages as required to define the types of data to display, the links to show, and the appearance of the map. After creating the map pages, you can create modules to display the map pages.

  1. On the form, fill in the fields.
    Name
    Input a unique name to identify the map.
    Application
    Select an application scope for the map, if other than Global.
    Center map on
    Enter the location for centering the map using the decimal form of latitude and longitude.
    Controls size
    Select whether the Google navigation icons on the map should be large or small.
    Initial zoom
    Set the zoom level of the map on opening.
    Type
    Select a map background style: Satellite, Hybrid, Normal, or Terrain.
    Refresh on zoom
    Enable or disable to refresh map on zoom.
    Type selection
    Select which type of Google icons to display on the map: Buttons or Menu.
    Use advanced configuration
    Select to configure a map with lists and forms. The script hides and M2M forms display to configure your map.
    Note: Advanced configuration does not support mobile.
    Advanced configuration does not support mobile.
    Map overview
    Enable or disable a wide view map window for navigation.
    Show device location
    Enable or disable to show device locations.
    Script
    Create a script to define the type of data to display on this map. For more information, see Scripting for map pages.
  2. Click Submit.
