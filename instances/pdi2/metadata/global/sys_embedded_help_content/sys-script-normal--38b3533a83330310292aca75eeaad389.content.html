Create a business rule

Create a business rule to perform an action, such as automatically changing values in form fields, when the specified conditions are met. Business rules are server-side scripts that run when a record is displayed, inserted, deleted, or when a table is queried.

  1. On the form, enter a name for the business rule and then fill in the fields.
    Table
    Select the table that the business rule runs on and updates.
    Advanced
    Select to use advanced options for when to run the business rule and to write a script for the business rule.
    When to run
    Set the conditions for when the business rule runs.
    Actions
    Specify the actions to perform when the business rule runs.
  2. Optional: If you selected Advanced, select the Advanced tab and in the Script field create a script that runs when the defined condition is true.
    With Now Assist for code generation enabled, you can provide text or code prompts to return AI-generated code suggestions and create business rule scripts quickly.
  3. Select Submit.
