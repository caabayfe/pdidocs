Generate a response

Use the Now Assist for IT Service Management (ITSM) activity response generation skill to automatically add responses to work notes or comments.

Before you begin

Role required: itil

Procedure

  1. In the Work notes or Comments field:
    1. Select the Now Assist icon ().
      The following four options appear:
      Note: The options are displayed based on the configurations by your admin.
    2. Select one of the options based on the type of response that you want Now Assist to generate.

      The response appears in the Now Assist context menu.

    3. You can select the Refine menu and elaborate, shorten, or change the tone of the response.
  2. Select Insert.
