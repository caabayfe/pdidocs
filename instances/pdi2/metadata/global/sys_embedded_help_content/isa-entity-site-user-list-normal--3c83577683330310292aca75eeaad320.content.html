Assign user criteria

When OT Devices are in the CMDB, you can configure site access with user criteria.

  1. To add user criteria to a site for Can Read access, select the Can Read Equipment Models tab and select New.
  2. To add user criteria to a site for Can Edit access, select the Can Edit Equipment Models tab and select New.
For more information about creating and assigning user criteria, see the following topics:
  • Assign or remove equipment model site access for non-administrators
  • Assign the user criteria for Can Read access to a site
  • Assign the user criteria for Can Edit access to a site
