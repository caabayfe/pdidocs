Scheduled Email of Reports

This list includes the reports scheduled for distribution.

Scheduled reports can be distributed in PDF, CSV, or XLS format. Graphical reports can be distributed in PNG or PDF format. Multilevel pivot reports can only be scheduled in PDF format.

  • PDF — Generate a PDF in portrait or landscape orientation. PDF reports include the chart grid data. Map reports cannot be exported to PDF format.
  • Excel — Report visualization is exported as a Microsoft Excel (XLS) spreadsheet.
  • PNG — Report visualization is exported as a Portable Network Graphic (PNG) file. Also see How to embed reports as images in a scheduled report email.
  • CSV — Report visualization exported as a comma-separated value (CSV) plain-text file.
