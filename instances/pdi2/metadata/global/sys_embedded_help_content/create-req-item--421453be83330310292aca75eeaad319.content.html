Create a requested item

Create an inventory stock order request to order new hardware in bulk for your stockrooms.

Before you begin

Role required: inventory_user

About this task

A stock order is a catalog request to replenish the stock in a stockroom. You can manually create a hardware inventory stock order request. However, an inventory stock order request is automatically created from a stock rule trigger when the stock rule threshold breaches.

Procedure

  1. On the form, fill in the fields.
  2. Select Save.
