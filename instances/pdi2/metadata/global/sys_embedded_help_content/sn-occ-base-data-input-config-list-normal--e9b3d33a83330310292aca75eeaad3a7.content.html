Set up the inputs for log data

Role required: evt_mgmt_admin

Data input configuration lets you set up data input connectors to stream log data into your instance. Each connector can stream various types of logs from multiple applications.

  1. Ensure that your MID server meets the requirements, as described in the MID Server System configuration in the documentation.
  2. If the MID Server IP is exposed by NAT, load balancer or the like, set a public IP address as follows: Add a MID Server property named mid.public_ip, and enter your public IP address in the Value field.
  3. Select New.
  4. Choose what type of data input connector you want to create.
  5. Follow the setup guidelines for the selected connector.
  6. When you have configured the data input connector, return to the guided setup and proceed to the data mapping step.
  7. Optional: Check your configuration by selecting a data input.
  8. Optional: Preview logs by selecting the Test Line Preview column in the row for your new data input connector.
  9. Select Submit.
