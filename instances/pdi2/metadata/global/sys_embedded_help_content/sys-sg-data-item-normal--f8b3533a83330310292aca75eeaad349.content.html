Create a data item

Role required: none

Create a new data item with this form, to track how data is retrieved from a given table.

  1. On the form, fill in the fields.
    Name
    Name of the data item.
    Description
    Short description of the record.
    Condition Type
    Type of query condition used for the search: Declarative, Script, or URL based.
    Group by
    How data is grouped by this data item, such as by priority or assigned grouping.
  2. Click Submit.
