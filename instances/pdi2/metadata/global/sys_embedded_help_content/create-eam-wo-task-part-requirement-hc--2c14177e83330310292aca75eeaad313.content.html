Create new part requirement for a work order task

Create a part requirement for an asset or part that is missing for the enterprise asset associated with your work order task.

Before you begin

Role required: sn_eam.enterprise_asset_manager or wm_agent
Note: You can use the wm_agent role to create part requirements only for assigned work order tasks.

Procedure

  1. On the Part Requirements tab, select New.
  2. On the form, fill in the fields.
  3. Select Save.
