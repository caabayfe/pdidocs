Dependency Assessment

Dependency Assessment enables you to view, analyze, and edit your performance analytics components from a single view to see immediately what the effects of your changes are.

The top-down tree view shows the components of a performance analytics entity in a hierarchical view.

The bottom-up tree view shows where a widget is used in your instance. Select Show Used By from the context menu of a tree view component to show the bottom-up tree view. Click the refresh icon to return to the top-down view.

Click the info icon to see a summary of the component.

Click the context menu icon in any component to perform the actions available for that component in a pop-up window. These include editing the component, viewing the schema map of the component, and previewing a widget.
