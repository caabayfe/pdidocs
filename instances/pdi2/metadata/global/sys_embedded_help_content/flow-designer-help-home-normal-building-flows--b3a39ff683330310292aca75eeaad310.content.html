Building flows

Get started with building, testing, and running automated flows in Workflow Studio.

Learn how to add a trigger and actions to flows. Then, find out how to test and activate flows so that they run when triggered.

  1. On the Workflow Studio homepage, select New > Flow.
  2. On the Flow properties screen, give your flow a name.
    All other fields are optional. So, when you're ready to start building your flow, click Submit.
  3. In the trigger picker, search for and select any trigger to add to your flow.
    Trigger choices include:
    Record
    Start your flow when changes to records occur. Choices include:
    • Created: Start your flow when a record is created in the table you choose
    • Updated: Start your flow when a record is updated in the table you choose
    • Created or Updated: Start your flow when a record is either created or updated in the table you choose
    Schedule
    Start your flow on a schedule. Choices include:
    • Daily: Start your flow at a time you choose, every day
    • Weekly: Start your flow at a time and day of the week you choose, every week
    • Monthly: Start your flow at a time and day of the month you choose, every month
    • Run Once: Start your flow once at a time and day you choose
    • Repeat: Start your flow repeatedly on an interval of days, hours, minutes, and seconds that you choose
    Application
    Start your flow when record changes occur for certain ServiceNow applications. Choices include:
    • SLA Task: Start your flow when the conditions of a Service Level Agreement (SLA) Definition [contract_sla] record are met.
    • Inbound Email: Start your flow when your instance receives an email.
    • Service Catalog: Start your flow when a Requested Item [sc_req_item] record is created for your Service Catalog.
  4. Select Add an Action, Flow Logic, or Subflow.
  5. Select one of these choices:
    • Action: Automate a single operation.
    • Flow logic: Control how actions run in your flow.
    • Subflow: Automate a sequence of multiple operations.
  6. Choose an option from the list of actions, flow logic, or subflows.
    You can view a description for each action, flow logic, or subflow by selecting the (i) icon next to each choice.
  7. Continue adding more actions, flow logic, or subflows to your flow to automate your work on the ServiceNow AI Platform.
  8. When you're finished designing your automated flow, select Save in the main header.
  9. Select Test in the main header to test your flow and ensure that it runs with no errors.
  10. In the Test this flow screen, fill in any required fields, and then select Run Test.
  11. When your test finishes running, select Your test has finished running. View the flow execution details.
  12. On the Execution Details screen, you can view the State, Start time, and Time to Execute for the trigger and each action in your flow.
    Select any portion of your flow to view additional details such as its configuration or runtime values.
  13. Navigate back to the tab with your flow.
  14. In the main header, select Activate to publish your flow so that it runs when triggered.
Review the execution details of your flows. Navigate to Process Automation > Flow Designer, and select Executions from the main header.
