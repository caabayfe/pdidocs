Viewing available connectors

Connect to variety of external data sources to access data from across your organization.

Available connectors

You can access the entire list of connectors on the Available connectors tab.

  • Discover integration opportunities to external data warehouses including Snowflake, Google BigQuery, and Amazon Redshift, data lakes such as Databricks, and databases, including Oracle.
  • Access external data using primary connectors developed by ServiceNow or community connectors developed by the open-source community.
  • Create a zero copy connection to the data source, and grant data stewards access to create data fabric tables that retrieve data.
Note: You must have the df_connection_admin role to create a connection.
