Component libraries

Component libraries help you manage shared components. These shared components can be used across several applications with similar basic structure and require nearly identical configuration data.

On the left panel, you can:
  • Search for a component library or shared component.
  • Create component libraries.
  • Navigate between different component libraries or shared components.

Select a library to view its details on the right panel.

Open the library in a new tab by selecting the options icon () and then select Open library record.
  • The Details tab shows the basic details of the library and a list of applications using its shared components.
  • The Components tab provides a list of all shared components within the library.
  • The Config data tab shows the configuration data of shared components in the library in a tree view. Select a component to see its config data items (CDIs) in the Script or List view.
  • The Activity tab lists all committed and open changesets.

View a list of all CDM applications using components from this library.
