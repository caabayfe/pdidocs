Prepare data

Roles required: admin

  1. Download the Excel workbook attached to the data source record.
  2. Add the equipment model data to the first tab using the other tab for reference.
  3. Delete the worksheet attached to the data source record.
  4. Attach the updated workbook to the data source record.
    Note: Make sure that the data is in the first tab.
  5. Test load 20 records to make sure the data is imported correctly.
  6. Select Update.
