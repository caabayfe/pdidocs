Navigate lists

Navigate the provided lists to find services, service offerings, business applications, application services, and other related records.

Before you begin

Role required: sn_dpm.dpm_manager

Procedure

  1. In the List panel, select Lists.
  2. Expand each heading to see the options Owned by me and All.
    For demands, projects, and contracts, All is the only option.
  3. Select All to see all the records for that solution.
    Select Owned by me to see all records that you own.
  4. Customize your list view.
    • Select Refresh List () to refresh the list results.
    • Select List Actions () to edit the list columns and to save the list.
    • Select Show filter panel () to add or remove filters for the list.
