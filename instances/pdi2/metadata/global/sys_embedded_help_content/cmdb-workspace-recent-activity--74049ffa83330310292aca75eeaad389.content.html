What's new

Counts of newly created CIs within a recent time interval. The New CIs total counts all CI types including applications, hardware, and application services, which also appear in separate cards in the tile. By default, historical data is aggregated for the last 24 hours. You can specify other time intervals.

Select a card to view a Performance Analytics KPI Details pane that shows the trend for the respective item.
