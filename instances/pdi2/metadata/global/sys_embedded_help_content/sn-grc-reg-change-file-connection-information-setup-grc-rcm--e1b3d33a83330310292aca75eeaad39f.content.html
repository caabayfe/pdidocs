View the File Connection Information record.
Table 1. File Connection Information record
FieldDescription
ConnectionDisplays the connection record
ProviderDisplays the provider
StateDisplays the state of the connection
Source pathDisplays the source location where the provider places the feed files into the SFTP server
Destination pathDisplays the destination path to the directory where the imported files successfully should be moved

You can edit the Connection, Provider, Source path, and Destination path fields.
