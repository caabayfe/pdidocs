Configuration item (CI) class manager

CMDB maintains the state-related information of the CIs and the relationships amongst them. This information is helpful to understand the impact in case of an incident or a change. The CI class manager provides a tree view of the way CIs are organized in the CMDB, where each node in the tree represents a CI class.

Review the default CI class manager to determine whether it aligns with your business needs.

To view the details of a CI class, click the relevant node in the Class Hierarchy pane.

To modify a CI class:
  1. In the Class Hierarchy pane, select the CI class.
  2. In the Table pane, edit the details as required.
  3. Click Update .
To create a new CI class:
  1. Identify the CI class that you want to extend to create the new class.
  2. In the Class Hierarchy pane, right-click the relevant node, and select Extend .
  3. In the Table pane, enter the details as required.
  4. To add a column in the table, on the Columns tab, click New , complete the form, and then click Submit .
  5. Click Submit .
To delete all of the CI records in a CI class table:
  1. In the Class Hierarchy pane, select the CI class.
  2. In the Table pane, click Delete All Records .
