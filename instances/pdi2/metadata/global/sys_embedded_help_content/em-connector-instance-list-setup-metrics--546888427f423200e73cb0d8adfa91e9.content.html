Enable metrics collection for an existing connector instance

  1. Click on a connector instance for which you want to enable metrics collection.
  2. Select Collect metrics.
  3. Set Metrics database host to the IP address of the host on which the metrics database is stored.
  4. Select Database login with Windows authentication to use the Windows Authentication where the Windows user is defined on the MID Server service.
  5. Right-click the form header and select Save.
