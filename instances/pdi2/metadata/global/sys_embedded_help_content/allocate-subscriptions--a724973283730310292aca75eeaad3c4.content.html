Allocate subscriptions in Subscription Management

Give users entitlement to ServiceNow products by allocating subscriptions in Subscription Management.

Before you begin

Role required: admin

Procedure

  1. Determine whether you have subscriptions available for allocation by viewing either the number of available subscriptions on the details page or the list of unallocated subscriptions on the Insights tab.
  2. Allocate subscriptions by either adding recommended groups based on role type.
    1. On the details page, select Add groups.
    2. Select the check box next to one or more recommended groups.
    3. Select Add groups.

Result

Subscriptions are allocated to all group members that grant each member entitlement to use the product.
