MID Server upgrade history

Whenever an instance is upgraded, all MID Servers in the Up state are upgraded automatically. The MID Server Upgrade Histories list contains a record of each instance upgrade. Use this module to troubleshoot errors that occur during the MID Server upgrade process.

This list shows the following information:
  • The old instance version.
  • The new version.
  • The number of successfully upgraded MID Servers.
  • The number of MID Servers with pending upgrades. An upgrade is considered pending if it has failed or is in progress.

Select an instance record (Old Version) to see more details about the MID Servers upgraded with that instance.
