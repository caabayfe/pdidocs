Run the risk rollup calculator scheduled job for Operational Technology Obsolescence Management

Role required: sn_risk_score_calc.admin (OT Obsolescence Risk Score Calculator Admin)

You must run the Calculate Obsolescence Score Rollup for all EME entities scheduled job to get the rolled up risk score of equipment model entities in your OT environment.

  1. Select Active to enable scheduler.
    Scheduling frequency of the score calculation:
    The schedule is set to Run = On Demand by default. Admin can select a different value for Run to change the frequency of the score calculation.
    Handling score calculation ownership:
    In case you want to assign a different user to run the score calculation, change the Run as value, and assign the user ID according to your requirement.
  2. Select Execute Now.

Configure the properties required to use OT Obsolescence Risk Rollup Calculator.
