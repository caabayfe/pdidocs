Portal knowledge base list

This interface provides a list of knowledge bases for your applet to use. Knowledge bases contain articles on a given topic, such as Customer Service. By default, the app uses the IT knowledge base.

Active
Whether the entry is currently in use with your applet.
Knowledge Base
Knowledge base associated with the applet.
Order
Number indicating the order that the configurations should run. If there are multiple configurations on a portal, the system runs the configurations from the lowest to the highest order that you selected.
Portal
Portal associated with the applet.
