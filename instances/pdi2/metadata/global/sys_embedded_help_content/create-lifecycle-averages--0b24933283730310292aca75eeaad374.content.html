Create software life cycle averages

Create averages for calculating software End of Life (EOL) and End of Support (EOS) life cycles in the absence of vendor provided ones.

Before you begin

Role required: sam_admin

About this task

You can create averages that can be used globally for all products and publishers or you can create averages specific to a product or a publisher. These averages are used to create calculated life cycles for products.

Procedure

  1. On the Create New Software lifecycle averages page, fill in the form details.
  2. Select Save.
    The life cycle record is created and appears in the Software lifecycle averages list view page.
