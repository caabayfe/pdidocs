Create a new policy version

You can create new versions for any of your existing policies.

Before you begin

Role required: sn_pace.admin

Procedure

  1. Click Create New Draft on the Policy Version page.
  2. Enter a description for the policy version.
    Note: The Description field is the only editable field in the form. The version and revision numbering cannot be modified and are automatically assigned.
  3. Click the Policy Builder tab and select Mapping Inputs.
    • Click New to add new mapping inputs or edit existing inputs. Enter the variable name, type, and if required, enter a default value for the variable. Select the Mandatory checkbox if this is a mandatory variable and click Save.
    • Click an existing Variable Name and edit it as required. Click Save to save the changes.
    Note: Your administrator may have pre-configured policy versions that contain default caller and mapping inputs. You may not be able to edit these input variables, but you can add new inputs, as required.
  4. Click the Test Playground tab and evaluate the policy.
  5. Click Save to save any changes made to the policy version.
  6. Click Publish to publish the policy and make it current.
