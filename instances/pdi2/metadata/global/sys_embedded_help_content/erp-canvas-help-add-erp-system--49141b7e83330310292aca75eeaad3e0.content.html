Create an ERP system

Configure an ERP (Enterprise Resource Planning) system in Zero Copy Connector for ERP to organize your connections to the system of record.

Before you begin

You must first configure the Connections and Credentials that you use to connect to the system of record.

Role required: sn_erp_mining.erp_admin

About this task

Each installation of Zero Copy Connector for ERP supports adding up to 10 systems. However, Zero Copy Connector for ERP can connect to only one live ERP system at a time.

Alternatively, you can run Guided Setup.

Procedure

  1. Navigate to All > ERP Canvas > ERP Canvas Home.
  2. Open the ERP systems list by selecting the systems icon () in the side panel.
  3. Select New.
  4. On the form, fill in the fields.
    ERP system
    Name of the ERP system to help identify the business area.
    Latest heartbeat
    Date and time that ServiceNow AI Platform of the most recent connection to the ERP system.

    This field isn't editable, and has a value only if the ERP system has been successfully saved and contacted.

    Short description
    Brief description of what the ERP system is for, such as sales orders.
    Updated
    Date and time the ERP system settings were most recently saved.
    Connection
    Alias of the connection credential that you configured to connect to the system of record. You can select only from connections in the Zero Copy Connector for ERP scope.
    Remote tables
    Number of remote tables in the ERP system.

    Link a system to a remote table by adding the system to the ERP remote table record in Zero Copy Connector for ERP.

    ETL data sources
    Number of ERP extraction tables in the ERP system.

    Link a system to an extraction table by adding the system to the ERP extraction table record in Zero Copy Connector for ERP.

  5. Select Save.
