CMDB performance insights

CMDB performance insights helps you understand how your configurations affect overall speed.

CMDB performance insights is available starting with CMDB Workspace v3.6 and appears only for users with the sn_cmdb_admin (CMDB Admin) role.

You can use the charts and tools within CMDB performance insights to troubleshoot, debug, or diagnose performance issues. CMDB performance insights also analyzes your CMDB and Service Graph Connectors on your instance to generate recommendations on how you can improve the performance of your CMDB. The CMDB performance insights tile itself can show up to two of those recommendations.

Select View performance insights to access the CMDB performance insights data.
