Create an information object

Create an information object to capture the logical data for a business application.

Before you begin

Role required: sn_apm.apm_user

Procedure

  1. Expand Information Objects.
  2. Select All.
  3. Select New.
  4. Fill in the form fields.
    For field information, see Create information object form.
  5. Select Save.
