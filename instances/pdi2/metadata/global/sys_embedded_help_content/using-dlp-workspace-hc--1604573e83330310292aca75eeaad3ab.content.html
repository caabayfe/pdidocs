Using the DLP Dashboard

Access the DLP Dashboard to analyze the daily trends in your DLP incidents and effectively remediate them.

Before you begin

Role required:
  • sn_dlir.analyst - Edit and View DLP incidents.
  • sn_dlir.analyst_read and sn_dlir.read - View DLP Incidents.

Procedure

  1. Select a dashboard widget for which you want to perform a daily trend analysis.
  2. Review the dashboard widgets to identify trends.
  3. Click on Date Range.
  4. Select a date range from the calendar, and click Apply.
  5. Use the filters below the chart to drill down and perform a more in-depth analysis.
