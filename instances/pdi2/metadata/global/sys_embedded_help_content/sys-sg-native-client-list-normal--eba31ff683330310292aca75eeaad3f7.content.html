Mobile app config list

When users download a ServiceNow Mobile Platform application, they are prompted to log in with their credentials. When a user logs in to the instance, they are presented an experience that is created by a single mobile app config. The mobile app config that defines the user's experience depends on conditions defined in the config.

Name
Name of the mobile app config.
Mobile App Theme
Unique appearance of the config that works with your company identity.
Empty State
How users are informed that a page currently does not contain data.
Force Local Login
Whether the config provides local login experience on mobile apps even when the instance is configured with Single Sign On (SSO) configuration.
Geolocation Enabled
Whether the config locates users from latitude and longitude information provided by their mobile devices or browsers.
Navigation Bar
Type of navigation bar used to access launcher screens, screens, settings, and notifications with the navigation bar in the mobile app.
Offline Enabled
Whether the config lets users without an internet connection continue working from a mobile device.
Order
Order of the mobile app config.
Required Roles
Which roles can use this mobile config.
Type
Type of experience handled by the config.
