SSO integration

Provide single sign-on (SSO) access to your ServiceNow instance by integrating the instance with the SSO service used in your organization.

  1. Select an identity provider (IdP) or click Add New IdP, and then complete and save the form to configure an IdP.
    • If you have the URL to the XML document, enter it in the IdP Metadata URL field, click Fetch, and then click OK.
    • If you have the XML file and not the URL, click Manually enter metadata XML, copy the data into the text field, and then click Fetch. View the XML source code to ensure that it appears in the correct format.
      Note: Because manually entered XML metadata can render differently based on the browser in use, you should use a URL to import the XML metadata.
  2. Click Generate metadata, and copy the service provider metadata.
  3. Follow the instructions issued by your IdP and add a service provider using the service provider metadata generated in the previous step.
  4. Click Test connection and log in to the IdP.
