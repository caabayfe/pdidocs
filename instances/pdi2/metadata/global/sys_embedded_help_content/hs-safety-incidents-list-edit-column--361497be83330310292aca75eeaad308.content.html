Edit displayed columns in a list

Edit the columns that appear in a list, arrange the order of columns, and save the list to the My Lists tab.

Before you begin

Role required: sn_ohs_im.admin, sn_ohs_im.manager, or sn_ohs_im.agent

Procedure

  1. Select the List Actions icon () in the list.
  2. Select Edit columns.
  3. Select and order the columns as required.
  4. Select OK.
  5. To save this list to My Lists,
    1. Select the List Actions icon and select Save as.
    2. Enter a name for the list in the Save as pop-up window and select Save.
