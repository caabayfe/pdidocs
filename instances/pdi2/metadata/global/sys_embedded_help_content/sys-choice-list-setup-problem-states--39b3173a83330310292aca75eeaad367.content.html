Problem states

A problem is created with the Open state. It follows a process that finishes with the Closed/Resolved or Known Error state.

Review the labels of the default problem states to determine whether they align with your business needs.

To modify or delete a default state label, click the corresponding choice in the list.

To add a new label, click New.

Note: Do not modify the Value field of a state, because it may have an unintended effect.
