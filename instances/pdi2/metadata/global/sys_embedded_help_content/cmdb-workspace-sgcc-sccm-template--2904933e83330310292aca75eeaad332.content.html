Service Graph Connector for Microsoft SCCM template

Select an alias template before creating a connection.

Available templates are:
SCCM JDBC Connection Credentials
Select to use a user name and password to establish a JDBC connection to the SCCM database.
SCCM JDBC Conn Cred (Integrated Auth)
Select to use Windows JDBC-integrated authentication, which uses domain credentials, for authenticating a JDBC connection to the SCCM database.
