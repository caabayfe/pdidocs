Create an application service

Create an application service in the EA Workspace. An application service is a set of interconnected software products and hosts, which are configured to offer a service to the organization.

Before you begin

Role required: sn_apm.apm_analyst

Procedure

  1. Select Application Services.
  2. Select All.
  3. Select New.
  4. On the form, fill in the fields.
    For field information, see Application service form.
  5. Select Save.
