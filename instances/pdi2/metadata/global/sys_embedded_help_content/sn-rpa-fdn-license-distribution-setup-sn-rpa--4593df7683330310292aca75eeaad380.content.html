Create a robot license distribution record in RPA Hub

Role required: admin

  1. On the form, fill in the fields.
    Assigned (Unattended)

    Total number of the assigned unattended robots for the current domain.

    Assigned (Attended)

    Total number of the assigned attended robots for the current domain.

    Note: Based on these values, the remaining fields are auto-populated.
  2. Click Submit.
