Workforce Optimization for ITSM Admin Console

With the Admin Console, you can use a guided approach to simplify the set up and configuration of groups within the Workforce Optimization for ITSM application tailored to your organizational needs.

The Admin Console walks admins through a step-by-step process of configuring groups and user access in Workforce Optimization for ITSM. Admin can:
  • Add WFO assignment groups and then add managers and team members to the group.
    Note: WFO assignment groups are groups of type WFO_ITSM.
    • These are the only groups that you can view in the Admin Console.
    • To add groups from User Administration > Groups, they must be set to type WFO_ITSM.
  • Grant access to team members and managers to applications within Workforce Optimization for ITSM based on their needs.
