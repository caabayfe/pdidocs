Closed case list view

HR cases in a state that is no longer active.

The following are valid states for a closed case.
  • Canceled: Cases that are no longer needed.
  • Closed Complete: Cases closed with full resolution of all related records.
  • Closed Incomplete: Cases that are closed, but the related issues and tasks may not have been resolved.

Change displayed columns

Change the columns that are displayed to view only what you need.
  1. Select theList Actions icon (the gear icon).
  2. Select Edit columns.
  3. Select and order the columns.
  4. Select OK.
