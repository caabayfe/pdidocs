Create your own list

Create your own list to monitor services, service offerings, business applications, and application services.

Before you begin

Role required: sn_dpm.dpm_manager

Procedure

  1. In the List panel, select My Lists.
  2. Select Add new list.
  3. Follow the prompts to create a list.
    You can start a list from an existing list or you can create your own list.
  4. Select Create.
  5. Review your list in the My Lists column.
