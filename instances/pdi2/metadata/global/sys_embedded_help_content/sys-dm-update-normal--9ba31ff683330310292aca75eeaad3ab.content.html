Create an update job

Use this form to create an update job when you need to batch-update multiple records in your instance. Update jobs enable you to alter several records simultaneously without using scripts.

  1. On the form, fill in the fields.
    Table
    Select the table where the update job will be run.
    Condition
    Define the record conditions that the update job will follow.
    Fields & values
    Select which fields or values in a record will be updated.
    Auto updating system fields
    Click to enable updates of global default fields.
    Run business rules and engines
    Click to enable server-side scripts to run when the update job alters its target records.
  2. Click Submit.

Preview the number of affected records; see Mark records for updating.

Schedule the update job for later or execute it immediately; see Schedule or execute a job to update records.
