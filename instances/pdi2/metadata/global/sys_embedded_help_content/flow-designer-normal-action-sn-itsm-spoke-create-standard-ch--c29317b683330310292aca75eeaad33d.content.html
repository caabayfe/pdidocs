Create Standard Change Request action

Creates a Change Request record of type Standard.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Description
Data type: String

Detailed description for the Change Request record.

Short description
Data type: String

Brief description for the change request.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Change Request
Data type: Record

Reference to the change request created.
