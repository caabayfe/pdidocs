Create a digital integration

Create a digital integration to integrate two business applications.

Before you begin

Role required: sn_apm.apm_analyst

Procedure

  1. Expand Digital Integrations.
  2. Select All.
  3. Select New.
  4. On the form, fill in the fields.
    For field information, see Digital integration form (easy form) in EA Workspace.
  5. Select Save.
