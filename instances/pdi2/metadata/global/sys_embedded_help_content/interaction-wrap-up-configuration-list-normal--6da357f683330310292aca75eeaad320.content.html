Interaction wrap up configurations

Interaction wrap up provides agents with a brief wrap-up period at the end of customer conversations. Agents can use this time to complete their work before moving on to assist other customers.

Select New to create a new wrap up configuration.

Name
Name of the interaction wrap up configuration
Enforce wrap up duration
Indicates whether the system automatically ends the wrap up period
Duration in seconds
Length of time for the wrap up period
Order
Order of the configuration (lowest order is evaluated first)
