Create fulfillment instructions for an HR case

You can create instructions for your HR agents on how to complete an HR case based on an HR table and conditions. The fulfillment instructions you create appear as a separate tab on the HR case form and can also provide KB articles.
Table 1. HR Fulfillment Instructions
FieldDescription
NameThe name of the fulfillment instructions. Using the HR service name as the fulfillment name makes it easier to associate the two together.
TableThe name of the table associated with the case you want fulfillment instructions to appear.
ConditionCreate a filter using a set of conditions applied to a table to determine which fulfillment instructions appear for an HR case.
After creating a filter, the number of matching records appears.
Note: Refer to the Condition Builder documentation under ServiceNow AI Platform user interface.
ActiveCheck to indicate that this fulfillment instruction is active and available.
OrderIf there are multiple fulfillment instructions, the order this fulfillment instruction appears for an HR case.
InstructionsEnter the text of the fulfillment instruction that helps the HR agent complete the case.

You can use Rich Text Format (RTF) to format your instructions to emphasize words and provide a better experience for your agents.

Knowledge articlesAttach related knowledge articles relevant to the HR case.
Select Submit or Update.
