Configure the risk rollup calculator properties for OT Obsolesence Management

Role required: sn_risk_score_calc.admin (OT Obsolescence Risk Score Calculator Admin)

The score calculator uses the following properties:
  • sn_risk_score_calc.score_calculation_job_execution_time_ms - Max execution time in milliseconds to be used when performing score calculation job. The score calculator job runs continuously for max execution time and breaks for five seconds. The default max execution time is 10 mins (600000 ms).
  • sn_risk_score_calc.score_calculation_batch_size - Batch size (no of records) to be used when performing score calculation job. Score calculator job runs in batches of the batch size mentioned in this property. The default is 1000.
  1. Select the property that you want to modify.
  2. Change the values according to the requirement.
  3. Select Update.
