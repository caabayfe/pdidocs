Threat Intelligence Library

Threat Intelligence Security Center Library consists of various grouped objects and entities that helps your organization in data ingestion and processing, in both structured and unstructured formats.

This application enables you to do these tasks:
  • Define observables, indicators, and other objects.
  • Add Observables to case(s), watch list, allow list, and deny list.
  • View source records, related records, relationship graphs between object to object, internal intelligence data, and run enrichment actions and view the enrichment results.
  • Link and unlink threat intelligence records.
