Test updates to a policy

Use the Test Playground to test updates to a PaCE policy script. You can evaluate changes to the policy script in real time, enabling you to determine if the changes that are applied render the policy compliant or non-compliant.

Before you begin

Role required: sn_pace.admin

About this task

The Test Playground enables you to apply changes to the policy script, and see the impact of those changes in real time. After the changes have been evaluated, save the script to ensure that the changes are implemented when the policy is next invoked.

Procedure

  1. In the Policy Script section, modify the script according to your requirements.
  2. In the Test Parameters section, specify the following.
  3. After you have modified the script, click Evaluate.

Result

A decision is reached regarding the compliance or non-compliance of the policy, based on the changes you made to the script. In the Test Parameters section, either Compliant or Non-compliant is displayed, along with additional output on any warnings or failures, and the time taken to evaluate the policy.
