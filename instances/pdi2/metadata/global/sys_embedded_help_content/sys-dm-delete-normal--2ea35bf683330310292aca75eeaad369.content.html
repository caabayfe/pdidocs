Create a Delete Job

Role required: admin.

Use this form to create a delete job when you need to remove records from a given table. Delete jobs are used to safely delete records from a table without using scripts and without deleting the table.

  1. On the form, fill in the fields.
    Table
    Select the table where the delete job will be run.
    Condition
    Define the record conditions that the delete job will follow.
    Run business rules and engines
    Click the checkbox to indicate that any server-side scripts related to the targeted records should activate when the delete job is run.
  2. Click Submit.

Preview the job; see Preview affected records for deletion.

Schedule the delete job, or run it immediately; see Schedule or execute a job to delete records.
