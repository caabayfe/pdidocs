Move VTB Card action

Move a VTB card from one lane to another lane.
Note: For Flexible boards, use the Update Record action to change the state of the underlying task. For Guided boards, this action changes the field on the task associated with that card.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Card
Data type: Record

Reference to the VTB card to update.

Lane
Data type: Record

Reference to the VTB lane to update.

Outputs

This action has no outputs.
