Create a map marker click action

Set up a map marker icon before accomplishing this task.

Role required: admin.

Use this form to create a map marker click action. These enable you to define what happens when you click a map marker on your Map Page.

  1. On the form, fill in the fields.
    Name
    Input a name for the map marker click action.
    Action type
    Select Display dialog form to use Title and Form view fields, or select Script to input a script instead.
    Title
    Input a title for the map marker click action. The title is displayed on the dialog form on your Map Page.
    Form view
    Click the search icon to search for the Form view used for the dialog box UI on your Map Page.
    Script
    Input your script code here.
  2. Click Submit.
  3. Navigate to System Map Page > Map Markers.
  4. Select your Map Page marker.
  5. In the Map Marker Click Actions field, double-click the record and click the search icon ().
  6. Select your map marker click action, then click the check mark icon ().
  7. Click the menu icon () and select 'Save.

Select a map marker to complete your map marker setup.
