Building actions

Learn how to use inputs, steps, and outputs in Workflow Studio to build your own actions.

  1. On the Workflow Studio homepage, select New > Action.
  2. On the Action properties screen, give your action a name.
    All other fields are optional. So, when you're ready to start building your action, click Submit.
    Note: The Application that you choose for your action determines the category where your action shows up in the Workflow Studio action picker.
  3. In your action, take note of the Action Outline panel.
    This panel illustrates the structure of your action, which consists of inputs, steps, and outputs.
  4. Start by clicking + Create Input to add the first input to your action.
  5. Under Label, enter a label for your action input that appears in the Workflow Studio interface.
    The Name, or internal system name, for your action automatically populates with a value similar to your label by default. The Name value can also be accessed in scripts.
  6. For the Type, select a data type that you want to your input to have from the list.
  7. Optionally, you can toggle the Mandatory slider to make your action input required when your action is added to a flow in Workflow Studio.
  8. Keep adding inputs to your action, if necessary.
    An input is like a variable from a mathematical equation. The input is a placeholder whose actual value gets generated from the data you provide it.
  9. In the Action Outline, select the plus icon to add the first step to your action.
  10. From the list of available steps, choose a step to add to your action.
    Steps are similar to actions in flows. Steps are the individual pieces of automation in your action.
    Note: You can add more steps to this list and expand what you can do with action steps by requesting an Integration Hub subscription.
  11. Add values for your step's inputs.
    Inputs support static and dynamic values. A static value is one that you directly enter. An input with a static value always uses the value you enter. A dynamic value is a reference to a data pill. An input with a dynamic value gets generated each time the action runs. To add a data pill to an input, select it from the data pill picker icon, or drag it from the Data panel.
  12. Keep adding steps to your action, if necessary.
    A step is like a mathematical equation. The step performs a specific operation that generates an output value.
  13. In the Action Outline, select Outputs, and then click + Create Output.
  14. Under Label, enter a label for your action output that appears within the data pill in the Workflow Studio Data panel.
  15. For the Name, enter an internal system name that can be accessed in scripts.
  16. For the Type, select a data type that you want to your output to have from the list.
  17. Keep adding outputs to your action, if necessary.
    When you're done adding all the outputs you need for your action, select Exit Edit Mode in the Action Output header.
  18. In each output's Value field, assign a value to the output.
    Typically, you map output values to data pills for prior steps. An output value is like computing the value of a mathematical equation.
  19. When you're finished designing your automated action, select Save in the main header.
  20. Select Test in the main header to test your action and ensure that it runs with no errors.
  21. In the Test this action screen, fill in the values for your action's inputs, and then select Run Test.
  22. When your test finishes running, select Your test has finished running. View the action execution details.
  23. On the Execution Details screen, you can view the State, Start time, and Time to Execute for each step in your action.
    Select any step in your action to view additional details such as its configuration or runtime values.
  24. Navigate back to the tab with your action.
  25. In the main header, select Activate to publish your action so that you can add it to a flow in Workflow Studio.

Add your action to a flow in Workflow Studio. Your action shows up in the action picker as an option for the application it is associated with.
