Software discovery models

Software discovery models are automatically created during discovery to identify and normalize the software installed in your environment.

The difference between a software model and software discovery model is that a software model is a specific version or configuration of software purchased, while a software discovery model is a model created with discovered values of software publisher, product, version, and edition on a device.

Multiple software discovery models can be associated to one software model.
