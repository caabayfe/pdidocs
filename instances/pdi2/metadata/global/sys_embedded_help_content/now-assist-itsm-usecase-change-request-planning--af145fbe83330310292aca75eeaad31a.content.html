Generate change request plans agentic workflow

Monitor similar change requests autonomously and generate the necessary plans using the Generate change request plans agentic workflow.

Important: By default, all agentic workflow and AI agent records are read only.

To run the AI agents autonomously, you must first duplicate the agentic workflow, and then proceed with the following steps:

  • Activate the agentic workflow.
  • Activate all agents within the agentic workflow.
  • Activate the trigger to invoke the agentic workflow automatically. If you prefer to invoke it manually, activating the trigger isn’t necessary.
Important: When you modify a agentic workflow, AI agent, or tool, make sure that you update all instructions accordingly.
Using the Generate change request plans agentic workflow, generate change request implementation, backout, and test plans, analyze change risk and impact of a change request, and a proposal for the change. You can flush the cache after generating the change request plans using the Finish change plan AI agent.

Review all information and settings for the agentic workflow. To execute the agentic workflow using the AI agent, in the Select display screen, select Save and test.
