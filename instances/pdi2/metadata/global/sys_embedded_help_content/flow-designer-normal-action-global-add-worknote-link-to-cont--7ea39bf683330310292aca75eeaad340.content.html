Add Worknote Link to Context action

Add a journal field entry containing a link to the current flow context record. Use the link to view the flow execution details of the current flow. You can add a flow context link to any record that has a journal field.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Table
Data type: Table Name

Table name of the record to update with a work note.

Record
Data type: Record

Record containing journal field to update.

Journal Field
Data type: Field Name

Journal field to insert the link to the flow context record. For example, the work notes field of a task record.

Additional Comments
Data type: String

Text to add to the journal field before the context record link. For example, the name of the flow run.

Outputs

This action has no outputs.
