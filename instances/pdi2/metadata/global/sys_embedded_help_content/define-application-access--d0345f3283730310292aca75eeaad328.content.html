Define access to each application

Grant managers and team members access to each application based on organizational needs.

Before you begin

Role required: admin

Procedure

  1. Select any application that you want to configure and select Edit access.
  2. In the Group access tab, select Add groups and add the relevant groups.
  3. Select Submit.
  4. In the Manager access tab, select Add managers and add the managers that you want to grant access to this application.
  5. Select Submit.
