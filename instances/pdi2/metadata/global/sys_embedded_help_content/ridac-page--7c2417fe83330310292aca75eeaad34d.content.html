RIDAC page

Use RIDAC page to add and track Risk, Issue, Decision, Action, or Request Change (RIDAC) records in Project Workspace. You can create a risk record for your project on RIDAC page and convert it into other records.

On the RIDAC page, you can perform any of the actions:
  • Personalize the columns that you want to see on the data grid of the project record using personalize icon.
  • Group the records by record type.
  • Add risk, issue, decision, action, and request change using Add risk.
  • View RIDAC record for a specific project.
  • Create, edit, convert, and associate RIDAC records.

For more information on RIDAC, see Adding RIDAC (Risks, Issues, Actions, Decisions, and Request Changes) records for a project.
