Create a header or footer

Create a header or footer widget for your portal theme.

  1. On the form, enter a name for the header or footer and then fill in the following fields.
    Body HTML template
    HTML used to render the dynamic view that a user sees in the browser, bind client script variables to your markup, and gather data from the end user.
    CSS
    CSS that is specific to the styling the widget.
    Server script
    A server script used to set the initial state of the widget, send record data to the widget client script using the data variable, and run server-side queries.
    Client controller
    A client script used to map server data from JavaScript and JSON objects to client objects, process data before rendering it, pass data to the HTML template, and pass user input and data back to the server for processing.
  2. Select Submit.

For headers, create a header menu. Then add the header or footer to your portal theme.
