MID Server Issues form

The fields in the MID Server issue form are read-only and are populated by the instance with the details of the issue. The fields in the form show this information:
FieldDescription
MID ServerName of the affected MID Server.
Issue sourceThe process that identified the issue. For example, issues with MID Server user connectivity have a source of MIDUserConnectivity, and the source for an out-of-date JRE is JRE version check.
StateThe current state of the issue. Possible states are:
  • New: Starting state when the instance creates the issue.
  • Acknowledged: State set when the administrator first examines the issue.
  • Resolved: Ending state, set by the instance, indicating that the issue has been resolved. If the scheduled job does not encounter the issue when it runs again, the instance automatically sets this value.
DomainDomain associated with the MID Server user account.
Last detectedDate and time the issue was last detected.
CountNumber of times an issue has been detected. Each time the scheduled job runs and encounters the same issue, it increments this field.
Short descriptionContents of the generated message that specifies a possible issue with the named user or the MID Server.
