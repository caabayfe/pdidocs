Mark an alert as significant

Make an alert more likely to be included in a Log Analytics group when the associated metric behaves anomalously by labeling the alert as meaningful.

Before you begin

Role required: evt_mgmt_operator or evt_mgmt_admin

Procedure

  1. While viewing the alert in the Service Operations Workspace, select Apply ML feedback > Mark as significant.
  2. Confirm the action in the dialog box.
    Note: Processing this feedback might take a few seconds.
  3. Optional: Restore the significant alert.
    If you no longer want the alert that was marked as significant to be treated specially, you can restore normal significance to the metric involved in generating it.
    1. While viewing the alert, select Remove feedback.
    2. Confirm the action in the dialog box.
