Delete a defined Log Analytics alert rule

Delete a Log Analytics alert rule that you have defined if it is no longer necessary.

Before you begin

Role required: evt_mgmt_operator or evt_mgmt_admin

Procedure

  1. On the Log viewer, open a defined alert:
    1. Select the selection icon () and then choose Manage my defined alerts from the drop-down list.
    2. From the Defined alerts table, select the alert that you want to delete.
  2. Select Delete.
