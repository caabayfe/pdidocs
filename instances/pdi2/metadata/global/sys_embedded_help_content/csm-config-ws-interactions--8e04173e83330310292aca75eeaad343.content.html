Interactions

An interaction represents a customer's request for assistance through a chat, phone call, or walk-up.

Use an interaction record to gather information from a contact or a consumer about their question or issue. Then you can determine how best to resolve the request.
  • If the question or issue is simple, you can resolve it from the interaction record.
  • If the question or issue is more detailed, you can create a case from the interaction record by clicking Create Case. This opens a new case with the details from the interaction.
