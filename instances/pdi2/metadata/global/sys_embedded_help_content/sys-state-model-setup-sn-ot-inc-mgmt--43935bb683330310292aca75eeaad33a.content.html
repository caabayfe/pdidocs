State models

Roles required: admin or state_model_admin

  1. On the ServiceNow banner, select the globe symbol and change the application scope to Operational Technology Incident Management.
  2. Create a state model.
    1. Select New in the right top corner.​
    2. Enter the name of the state model in the Input field.
    3. Enter a description of the state model in the Description field.
    4. Set the order in the Order field.
      Note: The lower-order model matching criteria gets the higher preference.
    5. Set appropriate conditions to activate this state model.
      For example, you can set [Site] [is] [Atlanta]
    6. Set the common exit conditions to move from one state to another.
      For example, you can set [Assigned to] [is not empty]
    7. Select Submit.
  3. Create as many state transitions as needed in the State Transitions related list.
  4. Change the application scope back to Global.
