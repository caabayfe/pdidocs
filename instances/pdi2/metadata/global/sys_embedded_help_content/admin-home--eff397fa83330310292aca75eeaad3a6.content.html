Admin home dashboard

Use Admin home dashboard cards to instantly track your administrative work. You can now stay on top of any high priority incidents that might need immediate attention.

Each of the cards are clickable and gives you more information about the source.
Note: You can't add or remove any cards from the Shared admin dashboard. You can create a new customized dashboard by selecting Create new dashboard and add the required cards. The new dashboard is visible only to the author of the dashboard that has information about the instance.

The Get information about the instance section shows information about your instance that might include about the current version, violations, status of licensed applications, and scheduled upgrade.

This page enables you to do these tasks:
  • View information about the instance based on what is most important to you
  • Quick access to the high priority incidents
  • Configurable cards for quick and easy access to important information
Note: You can also submit your feedback by using the Share a suggestion section at the end of the page.
