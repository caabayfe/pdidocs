Get insights into your teams' performance

Gain insights into process bottlenecks and find potential areas that you could optimize.

Before you begin

Role required: sn_process_optimization_analyst

You must have mined the project for that KPI group for which you want to analyze process insights.

Procedure

  1. Using the Start date and End date fields, select the date range for which you want to analyze process insights.
  2. Select the Process analysis tab and perform process insights and variation analysis.
    Note: You can perform process analysis only on a leaf node KPI.
    You can analyze the process insights for the date range for which you have mined the data.
