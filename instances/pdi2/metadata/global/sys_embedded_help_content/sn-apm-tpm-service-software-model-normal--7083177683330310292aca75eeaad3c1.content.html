Associate an application service to a software model

  1. Enter the form details.
    Table 1. Application Service Software Model form
    FieldDescription
    Application ServiceSelect an application service from the choice list.
    Ignore Technical RiskEnable the check box to ignore the technical risk involved in the association.
    Primary Software ModelEnable the check box to indicate if it is a primary software model for this application service (indirectly with the business application).
    Software ModelSelect the software model from the list to be associated with the application service.
  2. Click Submit.
