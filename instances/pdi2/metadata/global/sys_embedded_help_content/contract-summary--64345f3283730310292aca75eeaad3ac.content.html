Contract Summary

Use contract summary in the Workplace Lease Administration dashboard to monitor the total number, state of contracts and so on.

The following types of scorecards are available. Select the card to see the list of records.
  • All Contracts: Total number of workplace contracts.
  • Active Contracts: Number of contracts currently in an active state.
  • Draft Contracts: Number of contracts yet to be worked on.
  • Expiring in 60 days: Number of contracts set to expire within 60 days.
Note: Workplace contracts without a location value aren't included in the total count.
