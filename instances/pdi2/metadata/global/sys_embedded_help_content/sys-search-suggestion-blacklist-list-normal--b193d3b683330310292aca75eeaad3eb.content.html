Search Suggestion Exclusion table

The search suggestion exclusion [sys_search_suggestion_blacklist] table holds expletive words or phrases that are blocked from being used in search suggestions or search results.

Active
Option to remove the excluded word or regular expression from suggestions.
Description
Explanation of why you excluded the word or regular expression if it's not obvious. This field is especially important for regular expressions.
Language
The language of the excluded word. Use the ISO 639-1 code for the language, such as "en" for English. Because regular expressions work for all languages, search suggestions ignores this field for regular expressions.
Phrase
Word or regular expression to exclude.
Type
Option that specifies whether the Phrase field represents one word or a regular expression.
