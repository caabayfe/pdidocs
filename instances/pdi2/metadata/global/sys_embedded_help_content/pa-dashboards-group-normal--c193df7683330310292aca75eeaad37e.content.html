Edit a dashboard group

Users with the admin, pa_admin, or pa_power_user roles can assign dashboards to groups so that users can find the dashboards they want more easily.

  1. Modify the following fields:
    FieldDescription
    NameThe name of the dashboard group.
    OrderEnter an Order number to indicate the order the dashboard group appears on the dashboard picker.
    Visible toSelect Everyone or Groups and Users. If the dashboard group is only visible to groups and users, specify them.
    Requires rolesIf the dashboard group is visible to Everyone, click the pencil icon to require the user have a specified role to view the dashboard group.
    • Click Update.
    • Optional: Click Launch Dependency Assessment to view the dashboard group in relation to its components.
