Insights dashboard

Quickly identify configuration errors using the DevOps Config Insights dashboad and take action.

Open changesets

Review the changeset details and either make changes to the configuration data and commit the changeset, or discard the changeset altogether. You generally want this number to be 0 on the dashboard.

Failed snapshots

Investigate the snapshots and fix misconfigurations, or identify changes that need to be made to a policy. You generally want this number to be 0 on the dashboard.

Policy exception and recommended actions

View the list of active exceptions and, for ones expiring soon, what the recommended action is.
