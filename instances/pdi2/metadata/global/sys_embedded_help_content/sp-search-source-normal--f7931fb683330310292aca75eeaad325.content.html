Define a search source

Configure a search source to query data from an instance table, across multiple tables and data sources, or to pull data from anywhere on the web.

  1. On the form, enter a name and ID for the search source and then fill in the following fields.
    Search page template
    The HTML template that displays the search results. If you are defining a basic search source that queries data from an instance table, you do not need to change the default template.
  2. On the Data Source tab, fill in the fields to define the data to query.
  3. On the Typeahead tab, fill in the fields to allow search results to populate the search field based on user input.
  4. Select Submit.

Add the search source to a portal.
