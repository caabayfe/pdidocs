Create a launcher screen

Role required: Admin.

Create a new launcher screen with this interface.

  1. On the form, fill in the fields.
    Name
    The name of the launcher screen record
    Application
    The application associated with the Launcher screen. Enter name, application scope, and short description.
  2. On the Header section of the form, fill in the fields.
    Title
    The title of the application associated with the Launcher screen
    Header function
    Function performed by the Launcher's header.
    Search config
    Search parameters associated with the Launcher screen.
  3. On the Body section of the form, fill in the fields.
    Launcher section mappings
    Sections of the launcher available. Click the gear icon to open a Personalize List Columns window, add or remove columns, and customize how the sections are displayed.
    Quick actions menus
    Quick actions associated with the Launcher screen record. Click the gear icon to open a Personalize List Columns window, add or remove columns, and customize how the sections are displayed.
  4. Click Submit.
