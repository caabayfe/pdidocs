Move request metrics

While working on multiple Move projects, monitor active tasks, state of projects, and so on by viewing Move request metrics.

As a move manager, view the metrics associated with the active projects that are assigned to you and the number of move requests and move tasks. Select each tile to view more details in a list view. The following types of metrics are available:
  • My active projects: Number of active projects that you’re currently working on.
  • Move requests: Number of active Move requests associated with active Move projects.
  • Move tasks: Number of active Move tasks created to fulfill active Move requests.
  • Planned vs unplanned requests: Visual representation of planned and unplanned Move requests in a pie chart. Requests that don’t have an Expected start or Due date specified are considered unplanned.
  • Move requests (pie chart): Visual representation of Move request states in a pie chart.
  • My active projects: Visual representation of each Move project and the number of cases associated with each project.
