Add filter parameters for Tenable.io imports

Without adding additional API calls or coding, you can customize your HTTP Request information with supported Tenable parameters in your ServiceNow AI Platform to further refine your imported data.

You can add parameters that are supported by the Tenable.io product for your scheduled queries to help you filter the vulnerability data you import with the Tenable.io Assets, and the Fixed and Open Vulnerabilities Integrations. You modify or add these values on your HTTP Method record under the REST method for the supported Tenable.io integrations of the Tenable Vulnerability Integration.

You might add these parameters if you find your imported data using the default filtering does not give you the specific granularity you need.

  1. Navigate to the Tenable developer website to view the supported parameters you can add to the integrations in your instance.

    Say, for example, you want to filter imported vulnerabilities so you only see data imported for critical vulnerabilities (CVSS score of 10.0). The supported Tenable parameter is: {"filters": {severity": ["critical"]}}.

  2. Open the record for the Tenable.io Integration you want to add parameters to from this list.
  3. Click the Tenable REST Details tab to select it.
  4. On the right of the page, click the information icon (I) for REST method followed by Open Record.
  5. Select the HTTP Request tab.
  6. Under the HTTP Query Parameters section, in the Content field, enter the parameter values you found on the Tenable developer site.

    For this example, enter: {"filters": {severity": ["critical"]}}.

  7. Separate values with commas if you want to enter more than one parameter.
  8. Click Update.

After the integration successfully completes, navigate to All > Tenable Vulnerability Integration. Select the record for the integration you want to verify and Vulnerability Integration Runs tab, open the record for the review the payload for the value you added or customized.
