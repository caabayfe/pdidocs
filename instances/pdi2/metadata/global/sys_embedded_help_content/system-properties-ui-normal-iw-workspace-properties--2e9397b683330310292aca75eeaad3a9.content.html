OT Home (Action-Oriented Landing Page) system properties

Configure the Important Actions section

Role required: configure_industrial_workspace

The default maximum of the number of cards under Important Actions is 50. This task provides the configuration for users with the configure_industrial_workspace role to edit the maximum number of records.
  1. In the sn_mfg_common.landing_page_important_actions_limit system property, change the number of cards.
  2. Select Save.

OT Progress Scorecard configuration

Role required: configure_industrial_workspace

  1. Edit the following system properties as needed.
    • sn_mfg_common.otpsc.page_title
    • sn_mfg_common.otpsc.records_per_page
    • sn_mfg_common.otpsc.low_threshold_color
    • sn_mfg_common.otpsc.medium_threshold_color
    • sn_mfg_common.otpsc.high_threshold_color
  2. Select Save.

Industrial Workspace List configuration

Role required: configure_industrial_workspace
  1. Edit the sn_mfg_common.workspace_list.record_count_limit system property as needed.
  2. Select Save.
