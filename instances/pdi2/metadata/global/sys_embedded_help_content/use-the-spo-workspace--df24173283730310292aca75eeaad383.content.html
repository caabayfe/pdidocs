Use the SPO Workspace

You can use the SPO Workspace to source or purchase products and services and raise self-service requests through the procurement organization.

Employees, shoppers, or requesters can use SPO to raise self-service requests, and source or purchase products and services through the procurement organization. Procurement specialists and sourcing managers can use SPO to work on various procurement objects such as purchase requisitions, sourcing requests, negotiations, procurement requests, cases, and more.

Learn more about:

  • Using ShoppingHub: Use this module to request pricing or place an order for products and services.
  • Using Shopping Hub Mobile: Use this module to engage with procurement organizations from a mobile device.
  • Using Procurement Case Management: Use this module to enable your employees to submit procurement cases and access your organization's knowledge base.
