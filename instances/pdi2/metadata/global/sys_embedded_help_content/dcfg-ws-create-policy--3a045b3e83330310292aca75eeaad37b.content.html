Create a policy

Create a PaCE policy to determine if changes to a software service or application comply with a set of pre-defined rules.

Before you begin

Role required: sn_pace.admin

Procedure

  1. On the Create New Policy page, fill in the details.
  2. Enter the Policy Name, Category, and a Description for the policy and click Save.

What to do next

When you create a policy, by default a draft policy version is created. Each policy version contains version meta-data, a policy script, and variable input definitions, which you can modify according to your requirements. You must publish a policy version to make it current and activate it before it can be invoked.
