Update, execute, or delete scheduled script execution

  • To create an scheduled script execution:
    1. Enter or modify the scheduled script execution Name .
    2. Select or deselect the Active check box.
    3. Select or modify the Run schedule from the list.
    4. Enter or modify the Time in hours.
    5. Select or deselect the Conditional check box.
    6. Check the Run this script .
    7. Click Update to save your changes or Execute Now to execute immediately.
  • To delete the scheduled script execution, click Delete .
