Create and train a similarity definition

  1. On the Similarity Definition Business Application Similarity from, fill in the fields.
    Processing Language
    Select the dominant language of the dataset that you are training the solution definition on. If the dataset language is Italian, choose Italian.
    Note: English processing is applied to all datasets by default.
    Stopwords

    Collection of words and phrases that function as the vocabulary the system uses to compare your instance records based on their textual similarity.

    When you select your processing language, the system automatically adds a Stopwords list that uses the same language. You can also add stopwords to the list, for example, words like Application.

    Training Frequency
    Retraining option from once daily or every 30 days in three months increments up to 180 days.
    Update Frequency
    Frequency at which you want to refresh the data you use to retrieve your similarity results.
  2. Click Update & Retrain to create your solution definition record and train it.
