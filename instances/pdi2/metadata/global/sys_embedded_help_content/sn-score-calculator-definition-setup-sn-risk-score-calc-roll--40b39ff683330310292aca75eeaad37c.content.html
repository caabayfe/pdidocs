Configure the risk rollup labels for OT Obsolesence Management

Roles required: sn_risk_score_calc.admin role or sn_risk_score_calc.user role

Preconfigured risk labels are available by default. If you want to modify the existing risk labels or add new labels, perform the following steps:

  1. Select the Score Range Labels related list.
  2. Modify the score labels according to your requirement.
  3. Select Update.
  4. You can also create a risk rollup label:
    1. Select the Score Range Labels related list.
    2. Select New.
    3. In the new form, you can provide the following details of the risk label: Score label, Low, High.
    4. Select Submit.
