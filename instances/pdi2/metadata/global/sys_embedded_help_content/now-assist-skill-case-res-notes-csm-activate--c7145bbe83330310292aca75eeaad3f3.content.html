Resolution notes generation: Review and activate

Review the settings for the resolution notes generation skill and then activate the skill for use in the CSM Configurable Workspace, Core UI, and Now Assist panel.

Review the settings on this page on this page and select Activate to complete the configuration. To make a change, select Back and make the changes for the trigger or display settings.

After you have activated the skill, you can make changes to these settings at any time by returning to the feature page and selecting Edit on the resolution notes generation skill.
