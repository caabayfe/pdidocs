Create SNMP community credentials

Credentials for SNMP do not include a user name, just a password (the community string). The default read-only community string for many SNMP devices is public, and the system will try that automatically. Enter the appropriate SNMP credentials if they differ from the public community string.

  1. Complete the fields in the form.
  2. To test your credential before you submit it, click Test credential under Related Links.
  3. Provide the connection specifics in the Test Credential dialog box and click OK.
  4. If the credential connects to the target, click Submit.
