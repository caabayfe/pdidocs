Case summarization: Choose input

Each Now Assist skill relies on input data from your instance to determine the contents of the case summarization.

In some cases, you can choose which table and fields you want to use as the input. For example, Summarization can be based on a table like the Case table and can pull information from the Short description and Description fields. Make changes to the table and fields if necessary.
