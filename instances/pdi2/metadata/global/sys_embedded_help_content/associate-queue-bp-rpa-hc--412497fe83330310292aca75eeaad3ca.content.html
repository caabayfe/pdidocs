Associate a queue to a bot process

Associate a queue to a bot process so that the bot process can interact with this queue. You can associate a bot process to multiple queues so that the bot process can interact with many queues.

Before you begin

Make sure that the bot process isn’t in a published state.

Role required: sn_rpa_fdn.rpa_release_manager or sn_rpa_fdn.rpa_admin

About this task

To assign a bot process to a queue from the Queues menu, see Assign a bot process to a queue from Queues menu in RPA Hub.

If the bot process is enabled for a robot pool, then only one queue that is not associated with any other bot process can be mapped to the current bot process. For more information, see Robot pool in RPA Hub.

Procedure

  1. In the Work Queue field, select the queue that you want to assign a bot process to.
  2. Select Save.
