Create a connection

Access data from an external source by creating a zero copy connection.

Before you begin

Work with your data source administrator to set up a service account with appropriate access to an external data source.

Role required: df_connection_admin

Procedure

  1. Enter a label and short description for the connection.
  2. Fill in the connection attributes for your specific data source.
    For details on each field, refer to the Connection Guide.
  3. Select the authentication method required by the data source.
  4. Optional: Secure the connection by uploading security details or by entering the details manually.
  5. Enter any additional required authentication information.
  6. Select Connect.

Result

The instance connects to the external data source using the provided credentials. The connection is added to the Established connections page.

What to do next

Configure data steward access for the established connection.
