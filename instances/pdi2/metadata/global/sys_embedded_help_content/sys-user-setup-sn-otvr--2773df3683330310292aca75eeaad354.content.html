Users and roles

Roles required: admin or user_admin

  1. Create any user records for any users that don’t already have an account in this instance.
  2. Assign roles to admin users  or user groups as needed.
    • OT VR Integration Viewer (sn_otvr.integration_viewer): Can view OT VR integration records.
    • OT VR Integration Admin (sn_otvr.integration_admin): Can view and edit OT VR integration records.
  3. Assign roles for the OT Vulnerability Remediation Owner.
    • OT viewer (cmdb_ot_viewer): Can read OT asset records.
    • OT ISA viewer (cmdb_ot_isa_viewer): Can view assigned Equipment Model Entity records.
    • VR Remediation Owner (sn_vul.remediation_owner): Can read and edit vulnerable items records.
    • VR Close (sn_vul.close_vi_vg): Can manually close Vulnerable Item records.
  4. Assign roles for the OT Remediation Task User.
    • VR Remediation Owner (sn_vul.remediation_owner): Will have access to Remediation task list views.
    • Remediation Task Manager (sn_vul.write_all): Can update all vulnerable items and remediation tasks.
    • VR Close (sn_vul.close_vi_vg): Can close Remediation task.
  5. Assign roles for OT Vulnerability Dashboard view access.
    OT VR Remediation Owner (sn_otvr.remediation_owner): Can view the OT Vulnerability Response dashboards.
