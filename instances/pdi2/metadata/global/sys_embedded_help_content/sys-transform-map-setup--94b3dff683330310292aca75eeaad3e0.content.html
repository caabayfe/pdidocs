Create or modify a transform map

To create or modify a transform map:

  1. Enter or modify the map Name.
  2. From the Source table list, select the source import set table.
  3. To make the transform map available for use, select the Active check box.
  4. To run business rules, workflows, approval engines, auditing, and field normalization while the transform inserts or updates data into the target table, select the Run business rules check box.
  5. From the Enforce mandatory fields list, select an option to determine whether mandatory fields are enforced on the target table.
  6. To set non-empty fields in the target table as empty fields if the corresponding fields in the import table are empty, select the Copy empty fields check box.
  7. Select the Application associated with the transform map.
  8. In the Target table field, select the table in which you want the transformed data to be placed.
    You can select only those tables that are within the scope of the currently selected application, those that have a global scope, or those that have write access granted to other applications.
  9. In the Order field, enter the order in which you want the transform map to be applied if there are other maps that fit the conditions.
    Transform maps are run from the lowest to the highest order.
  10. To view the script, select the Run script check box.
  11. Click Submit or Update.
  12. Under Related Links, click Mapping Assist or Auto Map Matching Fields to map the columns between the source table and the target table.
  13. Click Submit or Update.
