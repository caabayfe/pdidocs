Create KPI groups to track metrics for your vendors

Associate vendors with vendor KPI groups.

  1. Select New.
  2. From the KPI Group field, select the group for which you want to associate the vendor.
  3. From the Vendor field, select the vendor to associate with the selected KPI group.
  4. Click Submit.
