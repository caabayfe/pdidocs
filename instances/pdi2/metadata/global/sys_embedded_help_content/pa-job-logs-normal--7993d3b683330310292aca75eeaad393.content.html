Job Log

The Performance Analytics job log gives details of the settings and result of the data collection job. The data collection job involves executing an SQL query for each indicator source that uses the data collector. The query repeats for every collection time from the start date to the stop date. Then queries run for the next indicator source. Each step of executing a query is documented in the data collection job log.

Starting with the Tokyo release, a new, optimized data collector is available. The log details for this data collector differ from the log details of the classic data collector. Details of the logs of both optimized and classic data collectors and the results of the diagnostic tests are in the product documentation
