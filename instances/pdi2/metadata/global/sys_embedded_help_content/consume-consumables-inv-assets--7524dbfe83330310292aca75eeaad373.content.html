Consume consumable inventory assets

Consume the consumable inventory assets that are in the In Stock state and the Available substate.

Before you begin

Role required: sn_walkup.walkup_technician

About this task

  • My Stockrooms displays all the stockrooms that are linked to the walk-up location.
  • You can also use this task to consume other inventory assets available in the stockroom, such as hardware, bundles, software licenses and so on.

Procedure

  1. Select the stockroom from where you want to consume the consumables.
  2. Click the Related records tab.
  3. Click the Consumables related list.
    The consumable related list displays the list of consumables available in the stockroom.
  4. Click the consumable that you want to consume.
    The consumable record is displayed.
  5. Click Consume.
    The consume dialog box is displayed.
  6. Enter the Quantity to consume.
  7. Select the consumable Asset.
  8. Select the User to whom you want to assign the consumable.
  9. Select OK.

Result

The consumable is consumed and the quantity is reduced.
