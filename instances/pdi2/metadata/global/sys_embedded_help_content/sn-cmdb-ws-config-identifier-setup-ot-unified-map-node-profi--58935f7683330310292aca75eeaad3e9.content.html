Node Map Profiles

Role required: admin or sn_cmdb_ws.config_admin

Configure profiles that set default map filters and default map orientation for a class. For example, to show Service Mapping data for the Mapped Application Service class. These class profiles aid in identifying which layers are shown on the Unified Map for a given CI node.

Class profiles are applied when no filter preset is used with the current map. This typically happens when you initially load a map without a filter preset or when you set the filter preset to the Default view.

Class profiles let you configure only the Layer category in the filter panel.
Note: This setting affects all users. Individual users cannot configure this setting.
