Ingest vulnerabilities manually

Ingest vulnerabilities manually by downloading the template and populating the records with vulnerabilities data. Ensure that you follow the instructions provided in the template before entering the details. Role required: sn_vul.vulnerability_admin.

Third-party scanners help import vulnerability data into Vulnerability Response and process the data to report the findings. With manual ingestion of vulnerabilities using a template, you can process the data for a set of vulnerabilities before scanners can provide the findings. The vulnerability data can be imported manually by uploading a template in the Excel or CSV file formats.

  1. Navigate to All > Vulnerability Response > Manual Vulnerable Item Ingestion > Upload file.
  2. Click to download the template.xlsx or template.csv files.
  3. Enter the vulnerability data in the records.
  4. Click Import File to upload the updated template.
  5. Click Submit.

After you upload the file, navigate to All > Vulnerability Response > Manual Vulnerable Item Ingestion > Integrations to verify that the integration run is successful.
