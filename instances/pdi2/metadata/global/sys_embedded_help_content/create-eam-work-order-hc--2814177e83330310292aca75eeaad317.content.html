Create new work order

Create a work order to track and manage work for an enterprise asset.

Before you begin

Role required: sn_eam.enterprise_asset_manager

Procedure

  1. On the Create New Work Order form, fill in the fields.
  2. Select Save.
    The form closes and you are automatically redirected to the new work order record.
  3. On the work order record, select Ready for Work to initiate work for the given work order.
    The Enterprise Asset Management application automatically generates a work order task for the work order.
  4. On the Work Order Tasks tab of the work order record, select the task number for the new work order task.
    The work order task opens.
  5. On the Details tab of the work order task, fill in the fields.
  6. Select Save.
    The State of the work order task changes from Pending Assignment to Accepted.

What to do next

Work with the assigned agent to complete and close all subsequent tasks for your work order.
