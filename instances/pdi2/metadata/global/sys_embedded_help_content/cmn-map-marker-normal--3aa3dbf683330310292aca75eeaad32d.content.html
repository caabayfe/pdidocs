Create a map page marker

Set up a map data item before you accomplish this task.

Role required: admin.

Use this form to create a map marker. Combine map markers with with icons and click actions, to differentiate between data on your Map Page using the Classic Environment.

  1. On the form, fill in the fields.
    Name
    Input a name for your map marker.
    Data item
    Select the map data item that you previously configured.
    Coordinate definition
    Select the map coordinate definition that you previously configured.
    Title type
    Select Default display value to use default values; Field to use Data item table and Display value fields; or Script to use Display value script.
    Data item table
    Select the table to associate with the map marker.
    Display value fields
    Select the fields to display from the data item table.
    Display value script
    Input a script to run when a user clicks the icon.
    Map marker icons
    The M2M map marker icons record. Set up map marker icons, or create new ones.
    Note: Complete all the steps to set up map marker icons.
    Map marker click actions
    The M2M map marker click actions record. Select map marker click actions, or create new ones.
    Note: Complete all the steps to set up map marker icons.
  2. Click Submit.

Set up map marker icons and map marker click actions to finish configuring map markers.
