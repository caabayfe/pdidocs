Review execution activity details

Execute a policy to determine if it is compliant, non-compliant, or compliant-exception. Executions can be run as part of your policy evaluation process, or in real time when mapped to an object (table or document ID).

Recorded execution activity includes the time taken to execute, decisions of compliance, execution types, and the outcome of the execution.

Input

This tab shows the caller and mapping inputAPI Variable and Config parameters that were passed to the policy when it was invoked. The Caller InputAPI Variable is a variable that enables you to pass the value to the policy whenever the policy is invoked. For each PaCE policy, there is only one pre-defined Caller InputAPI Variable called SnapshotId. This Caller InputAPI Variable is Immutable and cannot be modified or deleted. You cannot define any additional Caller InputsAPI Variables for a policy.

Mapping inputsConfig Parameters, including any mandatory inputs, can be passed when mapping policies to an object (tables and document IDs). When a mapping inputconfig parameter is defined for a policy, you are actually creating a variable that enables you to pass values to the policy whenever the policy is mapped. If mandatory inputs are defined, you must specify values for those inputs when mapping the policy, otherwise the policy is not executed (will have an inactive mapping state) and no decision regarding compliance or non-compliance is reached.

Output

This tab shows the decision reached when the policy was executed. It provides a decision (compliant, non-compliant, or compliant-exception) related to this policy, with additional information such as errors, warnings, and result details.

Logs

The displayed logs include all execution data generated during the evaluation. Click on a log number to view the Execution Log details. To browse the logs, use the arrow icons at the bottom of the tab.

Policy Script

When a policy is executed, a set of parameters is passed and the policy developer can use these parameters in this policy script to make a decision whether it is compliant, non-compliant, or compliant-exception and return this decision back to the calling service.
