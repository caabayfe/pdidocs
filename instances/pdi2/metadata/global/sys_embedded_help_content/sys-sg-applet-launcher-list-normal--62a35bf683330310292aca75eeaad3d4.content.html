Launcher screens list

Launcher screens are used as landing pages or home pages. The Launcher screens list shows what launcher screens are available.

Use the various filters to narrow down your search for a particular launcher screen.

Name
Name of the Launcher screen.
Active
Whether the Launcher is active
Available offline
Whether the Launcher can be access offline
Header Function
Function performed by the Launcher
Launcher Header Titles
Header text displayed by Launcher
Hide empty sections
Whether empty sections are displayed in the Launcher
Required Roles
Necessary roles for working with the Launcher
Search config
Type of search performed by the Launcher
Title
The Launcher's title (often similar to its name)
