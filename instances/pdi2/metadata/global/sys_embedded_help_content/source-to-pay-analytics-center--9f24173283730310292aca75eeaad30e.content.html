Source-to-Pay Analytics Center

With Source-to-Pay Workspace Analytics Center, you can ask questions about your data, visualize, and analyze the performance of data over time.

The Analytics center is modeled using Natural Language Query (NLQ) which is helpful in converting natural language into database queries, thus fetching relevant data from the respective database tables. You can configure synonyms and semantic shortcuts using NLQ. NLQ is developed with the help of configurable synonyms and semantic shortcuts. You can add and configure synonyms to improve your search results. While using semantics, you can configure conditions for synonyms to further optimize your search results.
