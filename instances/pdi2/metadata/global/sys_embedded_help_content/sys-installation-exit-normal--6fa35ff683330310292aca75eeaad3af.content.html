Installation exit form

Use the installation exit form to review or modify an installation exit configured on your instance. Installation exits are customizations that exit from Java to call a script before returning back to Java.

ServiceNow provides several base system installation exits. See the link below for additional information on these exits.

Name
Name of the installation exit
Overrides
The installation exit that this installation exit overrides
Application
The scoped application that contains this exit
Active
Whether the installation exit is active
Description
Description of the installation exit
Script
Installation exit script
