View Application Total Cost of Ownership (TCO) insights

View the list of business applications without cost data in the Insights section of the .

Before you begin

Role required: admin

Procedure

  1. On the Home page, select Application Portfolio tab in the Insights section.
  2. See a card with name Business applications w/o cost data.
    This card shows the number of business applications that do not have cost data.
  3. Select View list to see the list business applications without cost data.
