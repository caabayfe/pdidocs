Create major incident from an alert

Alert rules help you to define alert conditions based on which a specific action is taken.

The Create Major Incident Candidate alert rule helps to create a major incident candidate for all alerts that are not in maintenance state and are not secondary alerts. The Create Major Incident for all alerts rule helps to create a major incident for alerts that are not in maintenance state and are not secondary alerts.

If you want to enable the rule, set the value of the Active field to true.

To create a new alert rule, click New.
