Create, modify, or delete the number format for a table

  • To create or modify the number format for a table:
    1. Select a Table.
    2. Enter or modify the prefix for every record number in the table.
      For example, the INC prefix can be used for the Incident table.
    3. Enter or modify the base number for the table.
      The default value is 1000.
    4. Enter or modify the minimum number of digits used after the prefix in the record number.
      The default number of digits is 7.
    5. Click Submit or Update.
  • To delete the number format for a table, click Delete.
