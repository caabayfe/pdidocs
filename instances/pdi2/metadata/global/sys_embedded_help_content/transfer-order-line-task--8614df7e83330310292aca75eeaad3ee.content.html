Transfer order line tasks

When you create a transfer order line, a transfer order line task is automatically created based on the model category specified in the asset. Transfer order line tasks are created to move transfer order lines from one stage to the other.

Transfer order line tasks also help you to track service levels and the time frame needed to complete a transfer order.

When you create a transfer order line and select an asset, that asset corresponds to a model category. If a customized template task exists for that model category, the template task is added to the transfer order line as a transfer order line task. If no customized template task match is found for the asset you selected, then the default template task is added as a transfer order line task.

Closing a transfer order line task completes the task and creates the next task in the process. For example, after you close the Ready for fulfillment task, the state for this task seems as Closed Complete and a new task is opened for the next stage, Ready for Shipment. This process continues until you close all the tasks required for completing the transfer order line. As you close a task and as a task moves from one stage to the next, the asset gets automatically updated too. For example, when the transfer order line moves from Ready to Fulfillment to Prepare for Shipment, the status of the asset also moves from available to reserved.

Note: If you skip a transfer order line task and select Closed Skipped, the asset isn’t updated automatically. After the asset is received or delivered, you can make the update manually.
