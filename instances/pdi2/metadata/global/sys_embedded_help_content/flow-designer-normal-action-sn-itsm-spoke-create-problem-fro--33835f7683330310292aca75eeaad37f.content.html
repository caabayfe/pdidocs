Create Problem from Incident action

Creates a problem from an incident. The problem inherits values from the incident.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Incident
Data type: Record

Reference to the incident to create a problem from.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Problem
Data type: Record

Reference to the problem created.
