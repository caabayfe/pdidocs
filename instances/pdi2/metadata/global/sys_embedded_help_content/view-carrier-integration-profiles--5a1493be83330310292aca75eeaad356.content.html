View the details of carrier API

View the details of the carrier API used to connect your ServiceNow instance to the third-party shipping carrier application.

Before you begin

Role required: admin, domain_admin, asset, and inventory_admin

Procedure

Select an integration profile to view the details.
Note the following about the fields of the carrier integration profile record:
  • All the fields except the Job field are populated by the third-party carrier application.
  • All the fields except the Active field are read-only.
