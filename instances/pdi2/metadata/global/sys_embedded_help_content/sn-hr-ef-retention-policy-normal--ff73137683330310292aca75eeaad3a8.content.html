Add or modify a retention policy

Table 1. Employee Documentation Create Retention Policy
Retention PoliciesThe retention policy associated with the document type.
The retention policy combines the retention period (determines how long a document should be saved) and criteria (who the policy is applicable to).
Note: document types can have multiple retention policies, but each retention policy is specific to the document type. Retention policies cannot be associated with multiple document types.

The base system provides a default retention policy for each document type. Edit the default retention policy by clicking Yes under the Default column.

When you have multiple retention policies, but there is an overlap in criteria, the retention policy with the longest retention period is used. For example:

Document type = Disciplinary Notice
  • Retention policies:
    • Use employees (retention period = End Date + 7 years)
    • US contract employees (retention period = End Date + 5 years)
  • If a user is both a US employee and contract employee, the US employees retention policy is used because it has a longer retention period.
