Auto-create a schedule

Guided Setup can auto-create a Discovery schedule only if the target IP ranges were auto-assigned to the MID Server. Guided Setup uses the configuration from the MID Server auto-assignment to populate the schedule. Use this task to determine the schedule's run time.
Note: You can only auto-create a schedule from within Discovery Quick Start.
  1. Select the window type and frequency for this schedule.
    WindowFrequency
    AnytimeDaily or weekly window that includes the time of day for this schedule to run.
    WeekendWeekend window that starts at 12:00 AM on Saturday and runs until Sunday at 11:59 PM.
    Daily Off-PeakDaily window of low network activity. Specify the start and stop times for this schedule, when Discovery is least likely to compete with other processes in your network.
  2. Click Create Schedule.
