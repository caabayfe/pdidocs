Assign a Role to a user

Assign an Investment Funding role to a user to give access to the functionality they need to perform their jobs.

In the Users related list, you can perform the following options:
Assign a role to a new user
Click New to add a user and assign an Investment Funding role.
Assign a role to an existing user
Click Edit to assign an Investment Funding role to an existing user.
