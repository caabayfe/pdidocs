Getting started with Application Manager

Application Manager provides admins the ability to install, update, and manage licensed applications and plugins for their instance.

This application enables you to do these tasks:
  • The instance automatically syncs with the store for every 24 hrs, if your entitled application isn't displayed, select the sync button to sync manually with the store.
  • The Available for you page displays applications and plugins that are included in your license and ready for you to install.
  • The Updates page displays applications and plugins that are ready for you to update. If there are updates available, they’re displayed and a green Update available message is displayed on the tile.
  • The Installed page displays applications and plugins that are currently installed on your instance. Installed applications and plugins display their current version, as well as notifying you that your version is up to date.
  • The Activity log displays a history of your updated and installed applications and their statuses or errors. These messages notify you if your installation has been completed, the reason your application may have failed, or other actions that must be completed for your application.
