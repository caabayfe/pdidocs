Customize the Incident Overview dashboard

You can add and arrange reports on the Incident Overview dashboard.

  1. Click Add content .
  2. Select Reports in the left column.
  3. Select the table the report is based on in the middle column.
  4. Select the report in the right column.
  5. Click Add here where you want to place the report on homepage.
  6. To add more reports, repeat steps 3 through 5.
  7. Click the close icon in the top-right corner when you finish adding reports..
