Creating a profile for Symantec DLP integration

Role required: sn_dlir.admin

Create an incident profile in your  ServiceNow AI Platform instance. Determine the  Symantec DLP incidents that are suitable for creating DLP incidents.

  1. From the Symantec DLP Incident Profiles page, click New.
  2. On the form, fill in the fields.
  3. Click Continue.
  4. In the Filtering page, select the API based filter for incident ingestion checkbox to apply the API filters and retrieve the incidents that match the filter criteria.
  5. Add the API filters, and click Validate Filter.
  6. Select Filter based on conditions to define the criteria that an incoming Symantec DLP incident must satisfy so that a DLP incident is created.
  7. In the condition builder, set the filters in the Filter Conditions field.
  8. Click Continue.
  9. In the Scheduling section, set a schedule to retrieve data and ingest incidents that match the criteria in the profile.
  10. On the form, fill in the fields.
  11. To save the created profile configuration, click Finish.
  12. To activate the profile, open the created profile and select the Active option.
  13. Click Update.

Now, you need to map the ServiceNow Incident Status field with the Symantec Incident Status field.
