Metric data table

The metric data table offers you an easy-to-use interface that resembles a spreadsheet. Using the metric data table, you can provide responses in bulk for multiple metrics.

Provide data for multiple metrics

To provide data for the metric data tasks, you can filter the metrics by the Group specified in the metric definition. After you’ve filtered the group for which you want to provide data, you can edit the cells to provide responses for both quantitative and qualitative metric data tasks. For qualitative metrics, use the Response field and provide your comments. The Response field offers generous space for you to enter your comments.

To select the cells, use the following keyboard shortcuts.
  • For macOS: Press CMD and click.
  • For Windows: Press CTRL and click.
  • To use the keyboard keys to select on Windows, press Shift and space bar

Use the Contextual side panel for more information about the metrics and to collaborate with various users. The Attachments and Links tab enables you to provide any supporting information for the metric. Browse for attachments and add them or add the link URL as required.

The Trends tab on the Contextual side panel displays how the data is trending for the last three metric data.

As an ESG program manager or a metrics manager, you can view the data submitted by the data owners and either approve the data, or reject it if the data needs modification. While rejecting, you can enter your comments so that the data owners can view the reason for rejection in the Activity tab. It’s important to note that while you can approve multiple responses at once, you can select only one cell at a time to reject the metric data.
