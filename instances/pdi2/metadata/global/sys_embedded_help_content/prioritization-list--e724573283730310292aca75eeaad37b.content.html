Prioritization List view

Group, sort, rank, and prioritize planning items.

In the List view, you can:
  • Add a new item to the pipeline by clicking New <item type> from the page header.
  • Update an item's details by double-clicking the cells.
  • Apply quick filters using Filter.
  • Rank the items using the Rearrange rows icon ().
  • Prioritize an item by changing its Planning state to Prioritized.
  • Show or hide columns using the Personalize side panel ().
  • Use Column actions () to group and sort the items by an attribute of your choice.
