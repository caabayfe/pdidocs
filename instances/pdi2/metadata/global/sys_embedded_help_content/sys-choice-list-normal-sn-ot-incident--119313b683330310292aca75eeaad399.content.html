Categories and Subcategories

This task requires admin role.

Change application scope

1. On ServiceNow banner click the globe symbol and change the application scope to "Operational Technology Incident Management".

Create a new category

  1. Click New button on right top corner
  2. Enter “category” word in the “element” field
  3. Enter category name in the “Label” field
  4. Enter category value in the “Value” field
  5. Enter sequence number in the “Sequence” field
  6. Click “Submit” button

Create a new subcategory

  1. Click New button on right top corner
  2. Enter “subcategory” word in the “element” field
  3. Enter subcategory name in the “Label” field
  4. Enter subcategory value in the “Value” field
  5. Enter sequence number in the “Sequence” field
  6. Click “Submit” button

Change application scope

1. Change the application scope back to "Global".
