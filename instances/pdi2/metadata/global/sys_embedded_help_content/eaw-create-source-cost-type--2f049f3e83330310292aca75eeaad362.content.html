Create a source cost type

Create a source cost type for the TCO source to specify the type of cost being ingested in Enterprise Architecture Workspace.

Before you begin

Role required: admin

About this task

After a source is created for the TCO, you can create a source cost type from the related list.

Procedure

  1. Select TCO.
  2. Select Sources.
  3. Select a source to open it.
  4. Select the TCO Source Cost Types tab.
  5. Select New.
  6. Enter a name and domain for the source cost type.
    The Source is field is auto populated with a source name.
  7. Select Save.
