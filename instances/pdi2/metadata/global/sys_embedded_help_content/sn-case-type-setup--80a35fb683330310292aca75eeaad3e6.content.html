Case Type form related lists

The Case Type form includes the following related lists. Use these lists to view items configured for specific case type and to create additional configurations.
  • Record producers: Catalog items that enable users to create records from the service catalog.
  • State Flows: Customized transitions from one state to another for a task record and the automated processes that the system performs during the transitions to specific states.
  • Special Handling Notes: Notes that bring important information about cases or related records to the user's attention.
  • SLAs: The service level agreements associated with the case type.
  • Email Templates: Reusable content for the subject line and message body of email messages.
  • Quick Messages: Predefined text that users can insert into email messages.
  • Reports: Reports created for the case type.
