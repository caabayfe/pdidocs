Change models

There are two available OT change models - OT Change Basic and OT Change Advanced.

The OT Change Basic model uses the change process without approvals. For more information about the OT Change Basic model, see Basic OT Change Model playbook.

The OT Change Advanced model uses the change process with approvals. You can create a change approval policy and assign an approval group to review your change request. For more information about change approval, see Change approval. For more information about the Advanced OT Change model, see Advanced OT Change Model playbook.
