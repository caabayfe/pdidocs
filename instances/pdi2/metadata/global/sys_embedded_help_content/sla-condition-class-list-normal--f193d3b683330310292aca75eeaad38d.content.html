SLA conditions

SLA condition rules control how the conditions in an SLA definition are combined to determine whether an SLA should attach, pause, complete, reattach, or cancel.

SLA condition rules vary the way that conditions in an SLA definition are interpreted to control state transitions. SLA condition rules are defined globally, and can be overridden for specific SLA definitions.

SLAConditionBase is the default set of SLA condition rules.

You must define some of the following parameters:

  • Name: Specify the name of the SLA condition rule.
  • Active: Select to track all active SLA records associated with the task. The SLA engine determines the changing stage of an SLA record.
  • Application: Specify whether the SLA condition rule is applicable in global application or it is specific to the current application.
  • Class Name: Specify the script Include in the class name reference field.
