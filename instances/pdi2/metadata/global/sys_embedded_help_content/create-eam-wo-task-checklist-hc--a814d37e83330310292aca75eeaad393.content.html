Create new checklist item for a work order task

Create a checklist of all activities that you must complete for your work order.

Before you begin

Role required: sn_eam.enterprise_asset_manager or wm_agent

Procedure

  1. Select the Checklist items tab.
  2. Use one of the following options to create a checklist.
    • Create a checklist by adding individual checklist items:
      1. Select New.
      2. On the form, fill in the fields.
      3. Select Save.
      4. Repeat steps a to c for every checklist item that you want to add to your checklist.
    • Create a checklist by applying a checklist template:

      1. Select Apply template.

        The Apply Template dialog box opens.

      2. In the dialog box, select the checklist template that you want to apply to your work order task.

      3. Select OK.

        The dialog box closes and you return to the Checklist items tab.

      4. Select the Refresh List icon () to populate the list of checklist items that were added based on the selected checklist template.
