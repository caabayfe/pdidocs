Review skills to add to your profile

Evaluate the skill proficiency for an existing skill or add a new skill and request approval to update those skills in your skill set. Get notified when your manager requests a skill review.

Before you begin

Role required: sn_wfo_skillreview.user

Procedure

  1. Select the List icon ().
  2. Send a request to review an updated skill proficiency or to review a new skill to be added to your skill set.
  3. Select Submit for review.
    When your manager approves or rejects the skill review request and completes it, you will receive a notification.
