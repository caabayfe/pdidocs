Define the change request input data.

Configure the base input table and fields with descriptions that you want to use as the source to generate a response. The table and fields with descriptions provide context for Now LLM Service to generate a response.
Important:
  • If you add a new field with the same name as an existing field, the name and description of the new field will override the description of the existing field.
  • When you add a new related table with the same name as an existing table, the fields and the descriptions in the new table will override the fields and descriptions in the existing table.
