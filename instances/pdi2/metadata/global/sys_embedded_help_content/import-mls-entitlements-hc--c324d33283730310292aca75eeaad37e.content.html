Import Microsoft entitlements from a Microsoft License Statement (MLS)

Import entitlements from an MLS.

Before you begin

Before you can import entitlements from an MLS, you must request the MLS from Microsoft. Microsoft provides the MLS as an Excel file.

Role required: sam_user or sam_admin

Procedure

  1. On the Create New Entitlement Import form, fill in the fields.
  2. Select Import.
