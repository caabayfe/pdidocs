List of application classifiers

Application classifiers use classification scripts to group discovered applications. Classifiers also provide criteria that you can use to specify when Discovery should use the classifier under the conditions that you define. The criteria is based on the parameters that a classify probe returns to Discovery.

  • The Table column refers to the table associated with that CI classifier.
  • The Order column refers to the order in which the CI classifiers are run. Smaller numbers are run before larger ones.
