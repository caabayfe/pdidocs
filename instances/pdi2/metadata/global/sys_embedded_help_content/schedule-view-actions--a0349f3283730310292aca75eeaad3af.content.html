Schedule view - Actions

On the Schedule view, you can use the various filter options that are available to view the reservations on the calendar accordingly.

By default, the calendar is displayed to you with a 30-minutes day view. Using the following filters you can change the view as you want:
  • Location filter: On the top-right corner, use the Campus, Building, and Floor location filters to filter the locations on the calendar accordingly.
  • Create a new reservation: Select Create new reservation to make a reservation.
  • Space filter: On the top-left corner, use the Space filter to filter out the spaces based on any category based on which you want to view them. By default, the filter is set as Reservable purposes.
  • Today: Use the Today option to view the current day's reservations.
  • Date filter: Use the Date filter to select any day on the calendar. If you’re viewing the calendar in a wee-view, then you can change the week on the calendar.
  • Change view: On the top-right corner, you can change the calendar view to display based on a 30-minutes day view, 1-hour day view or a weekly view.
  • Refresh: On the top-right corner, use the refresh option to refresh the view.
  • Legend: Next to the Refresh icon, select the Legend icon to view the color legend of the reservation states. Each state is displayed in different colors. The respective legend is detailed here.
