Analyzing KPIs and performance targets

Analyze the KPIs and the performance targets set by your manager.

If Workforce Optimization for ITSM is enabled, you can analyze indicator performance for the selected time period for each of your groups. You can also view the performance targets that your manager has set for each of your KPIs.
Note: If you do not see data in the performance section, have your manager add you to your primary assignment group with KPIs configured for that group. You can also select any additional group that you belong to if KPIs are configured for that group.
