Predict Configuration Item model creation

When creating models, consider the following criteria to achieve the best model-creation outcome.
  • Review filters
    • Filter out high importance incidents and incidents that are auto-generated through systems, such as Event Management.
    • Avoid fields such as Urgency, which have few values to select from, or datasets where most data falls into only a few CIs.
      Note: Common filter conditions include, Active CIs and Closed incidents in the last six months.
  • Select input fields
    • Determine how and where in your incident process you plan on using this model.
    • Consider whether incidents are created in your organization for specific locations or business divisions, when choosing input fields or data sets.
    • Review pre-populated input fields that are associated with this use case. You can select other supported fields that are most likely to correlate to a good prediction using the slush bucket.
      Note: When applicable, you will see recommended fields, based on your data, to help you make informed selections to create better models on the next reiteration.
    • Add input fields, such as particular routing channels or certain locations, for example, the United States.
    • Avoid inputs that have empty values.

What to do next

The next step in the process is to create additional iterations, by adding filters and input field combinations, to improve the baseline model.

You can then tune the models and select the best model.
Note: Optimally, configuring a use case requires domain expertise, details for which are provided on relevant pages.
