Map your raw log data

Mapping raw log data that streams into your instance defines how the system handles it. Health Log Analytics auto-maps log samples and metadata to one of three tags: Application Service, Component, and Source Type. When the system doesn’t discover properties automatically, you can adjust auto-mapping to extract the correct tags. Another option is using the JavaScript function to map data to a specific tag manually. The JavaScript function can also be used to reassign log samples to more relevant tags.

Note: Use the log preprocessor to edit your raw log data before the system maps and structures it.
