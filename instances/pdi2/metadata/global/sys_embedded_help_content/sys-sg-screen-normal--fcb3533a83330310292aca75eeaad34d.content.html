Create a screen

Role required: Admin

Use this form to create a new screen.

  1. On the form, fill in the following fields.
    Name
    Name of the screen.
    Description
    Short text description of the screen.
    Icon
    Image associated with the screen. Type in the name or search by clicking the magnifying glass.
    Application
    Scoped application related to the screen. Click the ⓘ and enter the name, scope of the app, and a short description.
    Fetch type
    How the applet should load before or during viewing.
  2. Click Submit.
