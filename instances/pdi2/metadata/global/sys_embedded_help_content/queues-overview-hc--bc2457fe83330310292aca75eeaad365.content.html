Queues

You can create a queue to distribute transactional data or the workload among different robots. A queue can hold a number of work items. The work items can store multiple types of data, such as transaction information, customer details, or information from a document.

You can't delete a queue that is associated to a published bot process.

What you can do on this page

Create a queue by selecting New. For more information, see Queue form in RPA Hub.
