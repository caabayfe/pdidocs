Create a work order for a case

Create a work order for a customer service case as part of the case resolution process.

Before you begin

Role required: sn_customerservice_agent

Procedure

  1. Open a case.
  2. Select the Work Orders tab.
  3. Click New.
  4. Fill in the fields on the Create New Work Order form.
  5. Select Update.
