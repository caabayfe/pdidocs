Investment Funding preferences

Set up the Investment Funding preferences as per your business requirements.
Funding frequency
Sets the frequency of periods in which you can fund investments. The list shows types based on the configured fiscal calendar. For example, if you set up Standard fiscal calendar, and you want to fund your investments quarterly, select Quarter from the list.
Number of editable past periods
Restricts the number of past periods for which you can modify the allocated or requested funds. For example, if you set up a Standard fiscal calendar and the funding fiscal type is Quarter, then you can modify funds for the last two quarters.
Hide actuals in tree view
Hides the actual amount of an investment in the tree view cards.
Allow fund overallocation
Enable the allocation of funds to investments in addition to the received funds.
