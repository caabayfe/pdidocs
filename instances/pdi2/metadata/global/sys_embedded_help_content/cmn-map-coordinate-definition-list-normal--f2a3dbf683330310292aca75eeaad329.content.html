Map Coordinate Definitions list

This list shows details map coordinate definitions available to you in the Classic Environment. These are used to create map marker icons, which users click to differentiate data on a map page in the Classic Environment.

Name
Name for the map coordinate definition.
Latitude field
Latitude field defining map coordinates.
Longitude field
Longitude field defining map coordinates.
Script
Script associated with the coordinate definition, if its Type is Script.
Table
Table for the condition. For example, incident [incident].
Type
Type of map coordinate definition. Field uses the Classic Environment (lists and forms), while Script uses scripts.
