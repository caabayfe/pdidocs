Configure the RPA system properties

Role required: admin

Configure the default system properties for the RPA Hub application.

  1. On the form, fill in the fields.
    Enable this to ensure the security of the published packages via code signing, where the package is digitally verified

    Option to ensure the increased security of the automation packages that are published from RPA Desktop Design Studio.

    Sets the instance and robot machine authentication mechanism
    Authentication type:
    • mTLS: Mutual Transport Layer Security.
    • Basic: Authentication that is based on the user name and password, via basic auth.
    Enable auto assignment of Attended Robot

    Option to auto-assign the attended robots to your users, on a first-come, first-served basis.

    Enable this to ignore certificate expiry while publishing digitally signed package/package version created with RPA Desktop Design Studio

    Option to ensure the automation packages that are created in RPA Desktop Design Studio are published and executed even after the certificate expires.

    Maximum limit for frequency, in seconds, to sync the execution logs
    Value to define the maximum limit for frequency, in seconds, for execution logs to synchronize. For example, 300.
    Enable tracking of execution logs.

    Option to track the execution logs.

  2. Click Save.
