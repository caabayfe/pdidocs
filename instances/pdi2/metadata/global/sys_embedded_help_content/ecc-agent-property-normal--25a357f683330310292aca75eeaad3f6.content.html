Create a MID Server property

  1. Complete these fields.
    FieldDescription
    NameProperty name.
    ValueValue you want the property to have. Multiple values must be comma-delimited.
    MID ServerLeave this field blank to set a MID Server property that affects all MID Servers. To set a MID Server property for a particular MID Server, select the MID Server.
  2. Click Submit.
  3. Restart the MID Server.
