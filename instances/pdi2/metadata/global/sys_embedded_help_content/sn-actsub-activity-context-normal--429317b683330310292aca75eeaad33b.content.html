Configure an Activity Context

Role required: sn_ssa_core.self_service_manager

Use this form to configure activity contexts for your instance, which define the activities collected as Self-Service Analytics data for user entities such as consumers and customer contacts.

  1. On the form, fill in the fields.
    Name
    Input a unique name for the activity context.
    Context table
    Input a table including the user entity whose actions will be tracked and displayed on the Self-Service Analytics dashboard. For example, to track all actions for a customer contact, select the Contact [customer_contact] table.​
    Module
    Module associated with the application that stores the activities data.
    Active
    Input the module to associate with the application that stores the activities data.
    Application
    Set the scope of the application. This field is automatically set based on the application scope selected in the application picker.
    Domain
    Input the domain in which the activities records exist.
  2. Click Submit.

If you are creating a new activity context, select the newly created activity context link from the Activity Contexts list, and map an activity context with activity groups.
