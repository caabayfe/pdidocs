Contexts

A context enables users to see recommendations for a specific type of record when certain rules are met. These recommendations can help users by suggesting actions to take based on the record context.

Contexts are created for tables, such as the Case table or Incident table. Creating a context includes the following steps:
  • Selecting a table.
  • Creating rules for the context. A rule shows recommendations to users with certain roles for records that meet specified conditions.
  • Creating recommendations for the rule. A recommendation is a way to suggest a helpful action to a user.

To create a context, click New and fill in the fields on the Context form.
