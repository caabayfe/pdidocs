Automation Status Set list

The Automation Status Set shows subnet Discoveries and the IP range assignments for associated MID Servers. The list is automatically populated by Discovery when it finds IP ranges, or subnets, in your environment. After Discovery identifies the subnets, it automatically assigns the IP ranges of these subnets to qualified MID Servers in preparation for the CI discovery phase.

  • The Number column contains the automatically generated identification numbers for discovered subnets.
  • The MID Server list column contains the names of MID Servers assigned to the subnet.
  • The State column displays the state of the discovery processes that auto-assign subnets to the MID Servers.
  • The Domain column displays the domain of the MID Servers associated with the subnet.

Each form contains read-only status information about the selected Discovery, the subnets found, and the range assignment process for the MID Servers you selected for auto assignment.
