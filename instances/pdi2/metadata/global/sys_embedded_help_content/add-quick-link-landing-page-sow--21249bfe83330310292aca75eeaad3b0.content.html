Add a quick link to the landing page

Refer to a link quickly from the Service Operations Workspace landing page.

Before you begin

Role required: admin or itil

Procedure

  1. Under the Quick links section, click Add quick link.
  2. In the URL field, specify the URL that you want to refer to.
  3. In the Display text field, specify the text that you want to display for the URL.
  4. Click Add.
