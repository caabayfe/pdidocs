Intent Discovery

Intent Discovery helps you build your model by identifying new intents expressed by your end users’ input. For applications that consume NLU, such as Virtual Agent, Intent Discovery helps you to better understand which prebuilt intents you can benefit from, and which custom intents would be useful to create.

Click Run analysis to receive recommendations for new intents.

You can select a taxonomy to use for the analysis. A taxonomy is a library of prebuilt intents in a specific domain (ex. ITSM), and your data is mapped against it to identify intents that should be in your model. The Records covered by recommendations tab of the summary report shows the intents mapped to the taxonomy.

Checking the Cluster unmapped utterances by keywords groups the remaining unmapped data into groups. The groups appear in the Remaining records tab of the summary report. If you don’t select a taxonomy, the analysis clusters all your data into groups that you can review to identify intents.

From the summary report, you can add recommended intents to your model or create a new intent from a cluster.
