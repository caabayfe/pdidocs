Create a problem task

Determine how the problem coordinator asks subject matter experts to help identify the root cause and proposed fix for a problem. Divide the problem into multiple problem tasks to help with the investigation. Assign the problem tasks to different assignment groups or users.

Before you begin

Role required: itil, sn_problem_write, problem_admin, problem_coordinator, problem_manager, or admin

Procedure

  1. Open the problem record that you want to create a problem task for.
  2. Click Create problem task.
  3. Select any one of the following problem task options, and click Create.
  4. On the form, fill in the fields.
  5. To add an attachment to a problem task, from the Contextual side panel, click the attachments icon ().
  6. To create templates for reuse, from the Contextual side panel, click the templates icon ().
  7. Click Save.
