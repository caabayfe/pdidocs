Add WFO assignment groups using the Admin Console

Identify existing groups that you need to add as WFO assignment groups in the Admin Console.

Before you begin

Role required: admin

Procedure

  1. Select Add groups.
    Note: The screen displays all groups that are in the User administration > Groups list which are not defined as WFO assignment groups yet.
  2. Select all groups that you want to add as the WFO assignment group to the admin console.

Result

All the selected groups are now defined as WFO assignment groups.
