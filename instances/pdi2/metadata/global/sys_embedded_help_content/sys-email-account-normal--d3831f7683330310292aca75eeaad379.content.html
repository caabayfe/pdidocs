Set up an email account

Email accounts store the connection details and credentials that the system uses to access external email servers and services. By default, instances come with email accounts for ServiceNow - managed SMTP and POP3 servers to send and receive email.

  1. On the form, fill in the fields.
    Name
    Name of the email account.
    Type
    Type of mail server. You can select one of the following:
    • –- None --
    • Password
    • OAUTH
    • OAUTH 2.0
      Note: The Email - OAUTH support for IMAP and SMTP (com.glide.email.oauth) plugin must be active for the OAuth options to be visible.
    Server
    Remote server to which this account connects. To activate a server for an on-premise installation, enter the full address (FQDN) of the node (for example, node.customerdomain).
  2. Click Submit.
