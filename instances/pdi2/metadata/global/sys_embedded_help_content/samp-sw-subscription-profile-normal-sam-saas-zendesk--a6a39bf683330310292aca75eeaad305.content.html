Creating a Zendesk integration profile

Create an integration profile to connect your Zendesk applications with the ServiceNow AI Platform. Use this integration to view software usage information and optimize stale licenses.

Important: Before you can save and publish the integration profile, you will need to create an OAuth client to enable access to the Zendesk API. You must also create a connection between your Zendesk applications and your ServiceNow instance so that you can retrieve user data from your applications.

The integration profile uses the Zendesk Download Subscriptions and Zendesk Reclaim Subscription subflows to retrieve user data from your Zendesk applications.
