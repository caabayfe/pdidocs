Create an OT Discovery schedule with an equipment model

Roles required: cmdb_ot_isa_admin

When you use an equipment model, you can add sites and equipment model entities to Discovery schedules to align OT devices with sites and production processes.

  1. Create or edit an OT Discovery schedule.
  2. Add the appropriate site where the OT device is located.
  3. Add the appropriate equipment model entity, which can be the area or production process that the OT device or devices on this network automate.
