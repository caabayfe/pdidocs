Map to equipment model

On the platform, OT devices can be assigned an Automated by:Automates relationship with one or more equipment model entities.
  1. Select the OT device that you want to assign to an equipment model.
  2. Scroll down and select the + (plus) icon in the Related Items section header.
  3. Select Automates (Child) for the Suggested relationship type field.
  4. Set any additional filter criteria in the Filter section.
  5. If you set additional filter criteria, select Run filter.
  6. Under the Configuration Items section header, select the check box next to the equipment model entity (or entities) that you want to build the relationship with.
  7. Under the Relationships section header, select the + (plus) icon to add the relationships.
  8. Select Save and Exit.
