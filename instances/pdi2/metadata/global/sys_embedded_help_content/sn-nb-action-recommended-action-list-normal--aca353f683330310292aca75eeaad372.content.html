Recommendations

A recommendation is a way to suggest a helpful action to a user. A recommendation includes the action and any relevant resources and inputs. There are three types of recommendations:
Guidance
A specific action that a user can take or information that a user can share. For example, a guidance can recommend that a user share a knowledge article or create a work order.
Guided decision tree
A guided flow to follow. A guided decision tree is a multi-step process that consists of a series of questions, answers, and a guidance.
Field recommendation
A field value to use.

New recommendations can only be created inside rules. To create a recommendation, open a rule record and click New in the Recommendations related list.

When you create a recommendation, the first step is to select the type from the New Recommendation screen. The selected type is added to the Action type field on the Recommendation form.
