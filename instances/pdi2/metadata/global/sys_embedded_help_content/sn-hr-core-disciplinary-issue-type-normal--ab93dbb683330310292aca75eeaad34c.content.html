Add or modify HR disciplinary issue type

  1. Complete the form.
    (The fields you see depend on how the form is configured and what fields are selected to display.)
    Table 1. Disciplinary issue type form
    FieldDescription
    IssueThe disciplinary issue.
    OrderNumber set to indicate the order in which the issue appears in the HR Disciplinary Issue Types list.
    ValueIssue value name, such as absenteeism, or improper_dress.
  2. Click Submit or Update.
