Create an Artifact Configuration

Role required: localization_admin and script_include_admin

Ensure you have activated the Localization Framework Installer plugin (com.glide.localization_framework.installer) before configuring a custom artifact of your choice.

Use this form to create and configure custom artifacts of your choice. Use the artifacts in the Localization Framework functionality to fulfill translation requests.

  1. On the form, fill in the fields.
    Name
    Input an identifier for the artifact record.
    Internal name
    Create an internal name for the artifact.
    Table name
    Select the table where the artifact information is stored, for example, the Catalog Items [sc_cat_item] table.
    Processor script
    Select a script include using the magnifying glass icon.

    For more information, see Processor script functions.

    To create a processor script for the artifact, see Create a processor script.

    Application
    The value is the current application selected for the logged-in user session.
    Active
    Click to activate the configuration record.
    Generate insights
    Click to enable localization insights for the artifact.
  2. Click Submit.
