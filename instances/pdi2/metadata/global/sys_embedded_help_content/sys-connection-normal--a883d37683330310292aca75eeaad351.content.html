Connection form

Use the connections table to set up a Basic, JMS, JDBC, or HTTP(s) connection to a target host.

Name
Name of the connection.
Credential
Specify the credential to use with this connection. This is optional.
Connection alias
The connection alias resolves your connection and credentials at run time.
Active
Make this connection active.
Domain
Domain to which the connection belongs.
