Do the following in parallel flow logic

Run actions and subflows in separate paths within an isolated flow logic block.

Inputs

Do the following in parallel flow logic does not have field inputs. Instead, you create a path to run actions, flow logic, or subflows. The items in each path run until all tasks within the flow logic block have completed.

Outputs

This flow logic produces no outputs, but the actions, flow logic, and subflows within each path can produce outputs. While the flow is running, outputs from a path are only accessible to other actions in the same path. After the Do the following in parallel flow logic completes, its final outputs are accessible to the rest of the flow.
