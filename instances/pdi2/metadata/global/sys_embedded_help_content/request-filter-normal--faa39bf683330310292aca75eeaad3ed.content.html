Create a My Requests filter

Role required: catalog_admin or admin

Use this form to create filters for your My Requests list. Filters refine incidents, requests, or tasks under the Self-Service > My Requests module in ServiceNow AI Platform, the My Requests widget in Service Portal, and the My Requests applet in the Now® Mobile app.

  1. On the form, fill in the fields.
    Title
    Name of the filter.
    Table
    Table on which the filter condition is applied.
    Application
    Application scope of the filter
    Active
    If set to true, the filter is active.
    Applies to
    Interface for which the filter is applicable. Possible values:
    • Desktop
    • Service portal
    • Desktop/Service portal
    • Mobile
    Filter
    Conditions used to filter requests.

    This section is displayed when the Applies to field is set to Service Portal or All.

    Portal page
    Portal page that opens when you click the request.
    Primary field to display
    Primary information displayed for the request.
    Secondary fields to display
    Secondary information displayed for the request.
    Note:
    • Add a maximum of three secondary fields.
    • Do not add an image field.
    • If the Request [sc_request] table is selected, the secondary field is not configured. If the request contains only one item, the Requested Item name is displayed. Else, it contains the requested item count.
  2. Click Submit.
