Occupancy dashboard

Check the Occupancy dashboard to know the occupancy status and the headcount at your workplace.

You can apply various filters on the dashboard. The occupancy dashboard displays the following information visually:
  • The total headcount, the highest on-site headcount in a day and the average daily on-site headcount.
  • On graphs, you can see the headcount trends based on the occupancy classification that you set using the filter. By default, Workplace Entity is set as the classification.
