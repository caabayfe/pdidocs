CI Discovery Quick Start

The Quick Start wizard finds all the configuration items (CI) in the discovered subnets using the credentials you provide.
  1. In the Add Credentials tab, create the credentials necessary to discover CIs in your subnets.
  2. Optional: In the Assign Router Location tab, assign a location to each router that subnet discovery found.
    When you configure router locations, you have the option of creating a schedule for each location. If you do not assign locations, a single Discovery schedule is created for all your subnets.
  3. In the Create Schedule tab, create a Discovery Schedule.
  4. Complete the Discovery Schedule by selecting either Finish or Finish and Run.

    • Finish and Run: Runs Discovery immediately, using the current configuration. All subsequent cloud discoveries run at the time scheduled.

    • Finish: Exits the wizard and runs Cloud Discovery at the time scheduled.
