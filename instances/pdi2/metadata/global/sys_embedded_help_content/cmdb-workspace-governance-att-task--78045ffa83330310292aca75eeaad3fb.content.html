Attestation tasks

Verify the existence of actual IT infrastructure and applications that you own, systematically and in bulk. Because CIs are continuously ingested into the CMDB from various data sources, you must ensure the integrity of the CMDB. You can use the CMDB Data Manager to remove any rejected, stale CIs that are associated with IT infrastructure or applications that no longer exist.

The attestation task page shows details about the task. The actions available to you can vary depending on your role.

Actions

You can perform a number of actions to an attestation task:
Cancel task
Deletes the task without further processing or action. You generally perform this action when the attestation task was created by mistake and want to signal that the task is no longer needed. This action is only available to CMDB Administrators.
Reassign
Changes the assignment of the task. Click Reassign and select how you want to handle the change in assignment.
  • To me: Assigns the task to yourself. You can assign a task to yourself if it isn't assigned to a specific user and you own or have access to the CIs.
  • To other user: Assigns the task to a specific user. You can reassign to another user if you aren't the actual owner of the CIs and there is a more appropriate user. In the Assign to prompt of the Reassign to other user dialog box, specify the user and provide a reason for reassignment. Then click Proceed.

    When you assign to another user, you can see only users from the assignment group associated with the task. As a CMDB Admin however, you can see any user with the data_manager_user role.

  • Send for reassignment: Notifies a CMDB Administrator that the task is incorrectly assigned. The task remains assigned to you until the administrator assigns it to another user. In the Send for reassignment dialog box, provide a reason for reassignment and then click Submit.
Review CIs to attest
Continues the attestation process. If the attestation process is not currently assigned to a user, then continuing the process assigns that attestation task to you.
