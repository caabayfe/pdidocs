Access personal portfolios

Access your personal portfolios by selecting one, by filtering, or by searching. You can also create a new personal portfolio.

Before you begin

Role required: sn_dpm.dpm_manager

Procedure

  1. Select a personal portfolio card to go to that item or select All personal portfolios to select the type of personal portfolios that you want to view.
  2. Optional: To create a new personal portfolio, select New personal portfolio. If there are no personal portfolios to select, then create a new portfolio.
  3. Optional: To search for a personal portfolio, use the Search field.
