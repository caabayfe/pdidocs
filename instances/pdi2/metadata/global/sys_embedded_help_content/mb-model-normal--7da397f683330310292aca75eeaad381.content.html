Create a MetricBase model

Create a model to determine significant anomalies in real-time using MetricBase triggers. Train the model using representative data that has already been stored in MetricBase.

  1. On the form, fill in the fields.
    Metric
    Name of the metric to train the model.
    Model class
    The algorithm to use when training data.
    Filter
    Filter data in the dataset.
    Group by
    Discriminator field for your model data.
    Model class
    Anomaly detection algorithm to use when training data.
    Training dataset start date
    Start date for collecting training data.
    Training dataset end date
    End date for collecting training data.
  2. Click Submit and Train.

MetricBase trains the model. When complete, the model appears on the MetricBase Model Instances tab. Next, create a Flow Designer trigger for this model.
