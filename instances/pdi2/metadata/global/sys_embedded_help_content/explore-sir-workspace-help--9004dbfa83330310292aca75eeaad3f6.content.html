Explore the SIR Workspace

You can use the SIR Workspace to understand how the security analysts and managers perform their day-to-day operations with an improved user experience, do a complete incident investigation, and get an overview of the security incidents, response tasks and SLAs assigned to the security analyst and team.

There are various widgets present under each filter grouped by priority, category, state, and SLA, which are in the security analysts’ queues and security analysts team's queue.
