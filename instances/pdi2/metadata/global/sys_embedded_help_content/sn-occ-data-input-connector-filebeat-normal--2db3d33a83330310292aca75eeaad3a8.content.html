Configure log data inputs for Beats

Role required: Role required: evt_mgmt_admin

This wizard guides you through the process of setting up an agent to stream logs from your servers into your instance. The configuration generated using this wizard must be installed on the servers. Before you begin, ensure that you have a MID Server with the Log Ingestion capability enabled.

  1. Fill out the form.
    In the Port field, select the port for the MID Server from the array.
  2. If changing a property requires restarting the application, submit a ticket to Customer Service and Support to apply your changes.
    When using a connector for which you need to download an agent, ensure that the listener port on the data input is open.
