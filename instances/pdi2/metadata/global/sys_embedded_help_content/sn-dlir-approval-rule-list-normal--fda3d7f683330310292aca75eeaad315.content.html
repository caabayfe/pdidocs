Configure approval rules

Role required:
  • sn_dlir.admin - Create, edit, and delete.
  • sn_dlir.analyst - View (read-only).

Set up approval rules to take approval from various levels of approver users whenever an advanced type of response option is selected. The DLP admin defines these approval rules to grant consent on requests raised by end users for the approval of advanced type of response option.

  1. To create an Approval Rule, click New.
  2. On the form, fill in the fields.
  3. For the Approver option, select Custom Approval List.
  4. Click Submit.
  5. In the Approval Levels section, click New.
  6. On the form, fill in the fields.
  7. Click Submit.
