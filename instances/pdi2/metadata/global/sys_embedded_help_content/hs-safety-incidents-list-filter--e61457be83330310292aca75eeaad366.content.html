Filter records in a list

After selecting a filtered list in the List view, you can continue filtering the records to quickly find the record you want.

Select a list to display the corresponding list of records. From this list, you can filter records in two ways:
  • Using the more actions menu next to the field name.
  • Using the Filter panel.

Filter records using the more actions menu

  1. Point the mouse to a column name in the list and select the more actions icon ().
  2. Depending on the type of column, the Filter section shows these options.
  3. Select Apply.

Filter records using the Filter panel

  1. Select the filter icon () to display the Filter panel.
  2. Select Advanced view.
  3. Build a filter by adding conditions that contain a field, operator, and values.
  4. Optionally, click or or and to add more conditions.
  5. Select Update to run the filter for the list.

To remove a filter condition from the filter panel, click the X next to the condition.
