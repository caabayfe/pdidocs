Run a scheduled job to update TRM technical debts data in EA Workspace

Run a scheduled job to fetch the TRM technical debts data for your application portfolio.

Before you begin

Role required: admin

Procedure

  1. Navigate to All >  System Definition  >  Scheduled Jobs.
  2. Find and open the  scheduled job Populate TRM technical debts in the EA Workspace.
  3. Select   Execute Now.

Result

After executing the scheduled job, the Technical Debt [sn_apm_trm_standards_technical_debt] table gets updated with the latest technical debt data for your application portfolio. It updates the values in the table each time after you run the job.
