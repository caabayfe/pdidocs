Create or modify a landing page

You can create a new landing page, or select and modify an existing landing page. If you modify a landing page, clone the landing page and this copies the layout and all associated containers and widgets.

Landing page attributes and layout form

  1. Name the landing page and set the order number. If you set up multiple landing pages, the page with a lower value takes precedence over the pages with higher values.
  2. Set the applicability for any page or a specific page. Set your page as Active in order to appear.
  3. Set a page title and select a layout and child slots.
  4. Click Update to save your landing page and proceed to permissions.
