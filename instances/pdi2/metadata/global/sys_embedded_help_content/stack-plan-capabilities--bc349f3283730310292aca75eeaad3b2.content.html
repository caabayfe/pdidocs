Stack plan capabilities

Plan you scenario efficiently using the stack plan. The stack plan represents space allocations based on their allocation types in the form of bars on each floor.

You can perform the following actions on the stack plan:
  • View space allocation based on different allocation types using the View by option
  • Select a bar on the plan to view more details such as the space count, capacity, and assignment-related details.
  • Drag and drop bars to different floors to change space allocations.
  • Move a bar to the clipboard temporarily.
