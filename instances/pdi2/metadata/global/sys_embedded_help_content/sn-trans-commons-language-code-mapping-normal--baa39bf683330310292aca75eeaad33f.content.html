Create a Language Code Mapping

Role required: admin.

Use this form to create a language code mapping, to map the ServiceNow language codes with the language codes of the translation service providers.

  1. On the form, fill in the fields.
    Language code
    Select the language for which the mapping is being done.
    Mapped language code
    Input the translation service provider's language code.
    Name
    The name is auto-filled using the language code and the mapped language code in the "language code -> mapped language code" format. For example, fq -> fr-CA. You may edit this field as needed.
  2. Click Submit.

Associate the language code mapping with a corresponding translator configuration to map the existing ServiceNow language code.
