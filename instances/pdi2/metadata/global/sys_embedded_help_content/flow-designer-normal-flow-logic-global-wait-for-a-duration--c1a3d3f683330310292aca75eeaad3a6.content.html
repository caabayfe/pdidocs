Wait for a duration flow logic

Use this flow logic to give your users time to act during automated processes or to wait for a specific date and time to complete actions

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Duration Type
Data type: Choice
  • Explicit Duration: Wait for a specific time period, such as 5 minutes.
  • Relative Duration: Wait for a specific time period from a selected Duration data pill or date/time value, such as 5 minutes after the flow start.
  • Percentage Duration: Type to specify a certain percentage of time duration between the start of the flow logic and specified end time.
    Note: The percentage value must be from 0 through 100 only.
Wait for
Data type: Duration
Set this value manually or select a Duration data pill. For example, use a Look Up Record action to select an SLA Definition record and return the value of the Duration field.
  • Explicit Duration: Wait duration in hours, minutes, and seconds.
  • Relative Duration: Wait duration in hours, minutes, and seconds before or after a specific time. Select Relative Duration to specify a wait duration from a specific date.
    Note: Past dates don't affect the wait duration.
You can enter a wait value of up to 999 hours.
Note: The actual wait duration can vary due to the instance processing time. The flow always waits for the time that you specify for this field, but other work in the queue may add to the wait time.
Wait for Percentage
Data type: Integer

Wait duration as a percentage of the time period between the start of flow logic and specified end time. If you select a past date for the end time, the wait duration is set to 0. This field appears when Percentage Duration is selected from the Duration Type list.

During the following schedule
Data type: Record

Select the schedule used to calculate the Scheduled End date/time value from the selected wait duration. For example, waiting for a 10-hour duration as part of an 8-5 weekdays schedule causes the flow to wait for one or more business days. If you leave this field blank, the timer runs without a schedule.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Duration
Data type: Duration

Total time that the flow ran in milliseconds. You can drag this data pill into the duration fields.

Date/time
Data type: Date/Time

Date/time that the flow completed. You can drag this data pill into the date/time fields.
