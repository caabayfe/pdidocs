Items that need attention

View changes, outages, risks, and critical incidents associated with the application service.

Needs attention pane

In the Needs attention pane, select an item or use the Search field to find specific changes, incidents, outages, or risks. You can select the filter icon () to filter by item type.

Alerts are in the list but due to a known technical issue, you can't search for alerts in the application service Needs attention pane.

Note: Toggle the Needs attention pane by selecting the needs attention icon. ().
Under the needs attention icon, you can view more information related to this solution.
  • Select the contacts icon () to view team members and teams.
  • Select the attachments icon () to view and to add attachments.
