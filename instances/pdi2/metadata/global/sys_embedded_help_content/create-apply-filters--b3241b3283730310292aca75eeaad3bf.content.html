Create and apply a filter to visualize the summary of active records

Create and apply filters to visualize the summary of filtered records in the Vulnerability Manager Workspace.

Procedure

  1. On the Home page, select the Gear icon in any of the Host vulnerabilities, Container Vulnerabilities, Application Vulnerabilities or Configuration Test Results tabs.
  2. On the Saved Filters modal, fill in the fields.
  3. Select Save.
    The created filter appears in the View by drop-down.
  4. Select the filter in the View by field to view the visualisations for the filtered records.
