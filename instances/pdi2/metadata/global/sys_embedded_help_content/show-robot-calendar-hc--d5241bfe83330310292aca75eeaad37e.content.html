Create a schedule for the unattended robots

View and create a schedule for your unattended robots by using the Show Robot Calendar. By scheduling your unattended robots, your robots can help you use your time more productively and finish a job more efficiently.

Before you begin

  • Create an unattended robot. For more information, see Create an unattended robot in RPA Hub.
  • Establish the robot connection to an unattended bot process. For more information, see Assign a robot to a bot process in RPA Hub.
  • Create a schedule within an unattended bot process to view some schedules on the robot calendar. Associate one or more active schedules with the robot. For more information, see Create a schedule within a bot process in RPA Hub.
  • Verify that the life-cycle stage of the associated bot process isn’t set to Retired. You can’t view the robot calendar for retired associated bot processes.

Role required: sn_rpa_fdn.rpa_release_manager, sn_rpa_fdn.rpa_business_user, sn_rpa_fdn.rpa_developer, sn_rpa_fdn.rpa_support_user, or sn_rpa_fdn.rpa_admin

Procedure

  1. In the form header, select Show Robot Calendar.
  2. In the Select the robot to view the calendar dialog box, select a robot from the Robot list.
  3. Select Continue.

Result

The Robot Calendar page opens.
