Diagnosing processing errors in SGC Central

You can diagnose processing errors in connections configured for a Service Graph Connector and resolve them within the SGC Central view of the CMDB Workspace using recommendations from Now Assist.

Verify that the Service Graph Connector diagnosis skill is enabled.
When an error count is displayed on the Processing status card, select the View details link in the error summary for the connection. On the Errors tab, select an error for a failed import set, then select Diagnose error.
Note: You can diagnose only one error at a time. The Diagnose Error button is enabled only when you select an error from the list.

Selecting Diagnose error triggers the diagnosis process for the processing error using Now Assist. The Error diagnosis window includes two key sections: Explanation and Recommendation, each focused on explaining the error and providing a solution to resolve it. The recommendation is based on a knowledge article matched using AI Search. A link to the knowledge article is provided in the Source section for additional guidance.
