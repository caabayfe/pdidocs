Create a validation script

Create a script to validate that values are in a specified format. For example, a validation script can verify that the only value allowed in a specific field is an integer.

  1. On the form, fill in the fields.
    Type
    Select a type of validation.
    Validator
    Create a script that validates field values.

    With Now Assist for code generation enabled, you can provide text or code prompts to return AI-generated code suggestions and create scripts quickly.

  2. Select Submit.
