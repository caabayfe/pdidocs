Create an interaction wrap up configuration

Create a configuration for each type of interaction that uses the interaction wrap up feature.

  1. On the form, fill in the fields.
    Name
    Name of the interaction wrap up configuration.
    Order
    Order of the configuration (lowest order is evaluated first).
    Conditions
    Conditions that apply to the interaction records included in this configuration.
    Enforce wrap up duration
    Enables the system to automatically end the wrap up period.
  2. Select Submit.
