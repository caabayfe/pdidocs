Integrations launchpad

Integrations Launchpad displays all Event Management connector integrations. Use them to pull or push events from external devices.

Browse Integrations tab

The Browse Integrations tab displays all pull, push, and custom connector integrations, including connectors available from the ServiceNow store as well as those from third parties.

Installed Integrations tab

The Installed Integrations tab displays all user-configured integrations.
Each integration tile displays the following information:
  • The name of the user who started configuring the integration
  • The integration's state: Active, Inactive, or Draft
  • Events, Metrics, or Logs that you can track from that connector
  • The average events according to minute in the last 12 hours
  • The last event
