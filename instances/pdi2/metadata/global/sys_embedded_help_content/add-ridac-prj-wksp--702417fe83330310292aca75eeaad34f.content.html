Add a RIDAC record

Create and add RIDAC records to your project to track and evaluate risks or issues during project development.

Before you begin

Role required: it_project_manager

Procedure

  1. Navigate to Workspaces > Project Workspace.
  2. Open a project from planning page.
    For more information on how to navigate to planning page, see Access the new Project Workspace.
  3. From the Planning menu, select RIDAC.
  4. From the More actions menu, select the type of RIDAC record that you want to create.
    For example, you can select Add risk if you want to create a risk record.
  5. On the form, fill in the fields and click Submit.
    For more information, see Add a RIDAC record to a project in Project Workspace.
