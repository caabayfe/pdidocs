Launch automations in Studio

Review, edit, and debug automations by opening the associated package version of the bot process in the RPA Desktop Design Studio.

Before you begin

If you are on a remote machine, make sure that you add the robot and connect to the Unattended Robot application.

If you are on a local machine, make sure that the package and associated package version are saved and available in the bot process.

Associate a package and a package version to the bot process. For more information, see Configuring a bot process record in RPA Hub .

Role required: sn_rpa_fdn.rpa_developer, sn_rpa_fdn.rpa_support_user or sn_rpa_fdn.rpa_admin

Procedure

  1. In the form header, select the down arrow in the Start Process button.
  2. Select Launch In Studio.
  3. Select one of the following options depending on whether you are on a remote or local machine.
