Configure form headers

Use form headers to display important information about a record at the top of the form. Select a field that agents can use to distinguish each record, such as the short description.

Define secondary headers that show additional information about the record, such as the priority, assignee, caller, or status.

To configure a form header, click New.

Select a table you want to define a header for, then choose a field to use as the primary value.

When you save the form, a secondary value field appears. Click New.

Define your secondary value, then click Submit.

Up to seven secondary values are supported.
