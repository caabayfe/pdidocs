Add or modify a retention period

Table 1. Employee Documentation Retention Period
FieldDescription
TitleName that describes the retention period.
Date fieldDetermines the starting point of the retention period. The fields that are available depend on the table selected.

Fields from the Employee Document [sn_hr_ef_employee_document] table used to define the beginning of the retention period.

Dot-walk and select a field to determine the starting point of the retention period.

Application typeThe application associated with the retention period for Employee Document Management.
Date offset typeDetermines if the retention period should start before or after what was selected in the Date field.

Combined with the Date field, Date offset units, and Date offset quantity determines the length of the retention period.

For example:
  • Date field = Created
  • Date offset type = After
  • Date offset units = Years
  • Date offset quantity = 1
Using this configuration, the retention period is one year after the created date of the document.
Date offset unitsDetermines if the retention period should be measured in months or years.
Date offset quantityDetermines the number of months or years of the retention period.
