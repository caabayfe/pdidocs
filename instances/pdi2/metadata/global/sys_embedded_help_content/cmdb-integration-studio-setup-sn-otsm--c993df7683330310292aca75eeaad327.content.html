Import OT devices

Role required: admin

  1. Create a new import set.
    1. Set sample import set to auto-pull a new import set.
    2. Click Save.
  2. Validate step 2 - Prepare source data for mapping.
  3. Validate step 3 - Map data to CMDB and add relationships.
  4. Run the import and check the results.
    If the results are okay, save. If not, rollback.
  5. Once validated, set up the schedule.
  6. Activate the ETL once all the steps are complete.
