Configure Vulnerability Solution Management for OT

Role required: admin

Configure Vulnerability Response for Operational Technology to work with each of your vulnerability solution providers. The supported file format is the Common Security Advisory Framework (CSAF), which is an open-source standard that provides JSON-based structured, machine-readable security advisories. OTVR supports File-based, URL, and API-based integrations for Vulnerability Solutions. For detailed guidance, see Operational Technology Vulnerability Solution Management.

  1. Select Add Integration.
    Configure the parameters to add an integration that helps in collecting solutions for vulnerabilities.
  2. For an existing integration, select Edit if you want to modify the parameters.
  3. Select Finish to save the changes.
  4. Select Execute Now to run the integrations.
