Create, modify, or delete a financial model

  • To create or modify a financial model:
    1. Enter or modify the financial model Name.
    2. Select a Data Source from the list.
    3. Select a Model Owner from the list.
    4. Select or deselect Cost lines with All combinations check box, if you are updating the default cost model.
    5. Select Used by Cost Allocation check box, to use the model hierarchy for cost allocation.
    6. Select Used by Budgeting check box, to use the model hierarchy for budgeting.
    7. Enter a Description.
    8. Click Submit or Update.
  • To generate detailed cost lines for a cost model, select Generate Detailed Cost Lines checkbox.
  • To generate budget keys for a budget model, click Generate Budget Keys.
  • To delete a financial model, click Delete.
