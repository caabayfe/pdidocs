MetricBase models

MetricBase creates a model by training a representative sample of your time series data. The training process determines the model parameters that best fit your data, to distinguish normal data from anomalous data.

Created
Date that you trained the model.
Model name
Name of the model.
Table name
Name of the table that contains the training data.
Metric
Name of the metric that you use to train the model.
Model class
The algorithm to use when training data.
Active
Option to use the trained model.
