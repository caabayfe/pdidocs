Search Events list

The Search Event list stores sets of search strings and their search results. Use the search fields to narrow down the list of Search Events.

Search query
Search string that the user entered.
Has results
Boolean value that specifies whether the search did (true) or didn't (false) return results.
Click rank
Ranking of the item selected from the list of suggestions.
User
User who performed the search.
