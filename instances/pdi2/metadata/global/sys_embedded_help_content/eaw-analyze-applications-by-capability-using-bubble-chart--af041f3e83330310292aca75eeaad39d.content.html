Analyze business applications using the bubble chart

You can narrow down the business applications based on their application indicator scores and values.

Before you begin

Role required: sn_apm.apm_analyst

Procedure

  1. Modify the bubble chart parameters as required by selecting the settings icon ().
    The following settings are available for modification:
    • X and Y axis: Dimension of the indicators that fall into the X and Y axis. The available options are derived from the Application Bubble Charts table (apm_bubble_chart.List).
    • Bubble size: The bubble size is based on the indicators related to business applications. The indicator scores determine the size of the bubble.
    • Bubble color: The bubble color is based on the planned disposition value of the application. You can refer to the legend displayed on the bubble chart to see the significance of each color.
      Note: The bubble color settings can’t be modified.
    • Bubble labels: Enable the toggle to display the bubble labels in the bubble chart. The bubble labels represent the business application names.
      Note: The bubble chart displays up to only 100 bubbles representing business applications. If you have more than 100 bubbles, use the available filters to reduce the number of applications or view the data in the list view.
  2. Select Apply.
