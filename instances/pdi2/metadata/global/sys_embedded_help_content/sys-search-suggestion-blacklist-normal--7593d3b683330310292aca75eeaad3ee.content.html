Create a Search Suggestion Exclusion

Role required: admin.

Use this form to add an expletive word or phrase to the search suggestions exclusion [sys_search_suggestion_blacklist] table. These exclusions are blocked from use in search suggestions or search results.

  1. On the form, fill in the fields.
    Phrase
    Enter the word or regular expression to exclude.
    Active
    Click to remove the excluded word or regular expression from suggestions.
    Language
    Select the language of the excluded word. Use the ISO 639-1 code for the language, such as "en" for English. Because regular expressions work for all languages, search suggestions ignores this field for regular expressions.
    Type
    Specify whether the Phrase field represents one word or a regular expression.
    Description
    Explain why you excluded the word or regular expression if it's not obvious. This field is especially important for regular expressions.
  2. Click Submit.
