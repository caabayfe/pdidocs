Resource Limits configuration on a form

Enable the com.glide.application_resource_limiter plugin to use the Resource Limits feature.
Note: You don’t need Application Insights installed to use Resource Limits.
Use one of the following ways to monitor the application groups leveraging the resources.
  • Xml stats
  • Application insights
Note: The xml stats have been imported to Application Insights for easier monitoring.

Configure the resource limits by either creating a new application resource limit record or by updating an existing record.

Name
Name of the group. It can have 1 or more applications in it
Applications
The applications that are a part of the group
Note: A group can have more than 1 application, but an application can belong to only 1 group. You will get a validation error if you try adding an application to more than 1 group
The application selected can only be a scoped application, it can’t be a global application.
API transaction Limit %
Total percentage of threads that are executing API requests for this group of applications
Note: You can use this data to make sure that no certain application is taking up all the resources while running.
Event Handler Limit %
Total percentage of threads that are executing event handlers for this group of applications
Interactive Transaction Limit %
Total percentage of threads that are executing UI requests for this group of applications
Scheduled jobs
Percentage of total processing time that are allocated to jobs for this group of applications
State
  • Log Only: If an application group goes beyond the set limit, the resource limit is just being logged
  • Enforced: If an application group goes beyond the set limit, API and UI events get rejected. The scheduled jobs and events get deferred to the next 5 minutes window
  • Disabled: The application resource limit record has been disabled
