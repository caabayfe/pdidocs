Edit an ERP remote table

Edit the details for an ERP (Enterprise Resource Planning) remote table, for example, to update its attachment settings or scheduled query.

Before you begin

Role required:
  • To modify remote tables: sn_erp_integration.erp_admin
  • To read remote tables: sn_erp_integration.erp_user

About this task

To ensure data integrity, you can't create new remote tables in Zero Copy Connector for ERP, but you can clone existing ERP models and extend standard ERP remote tables to customize them.

ERP remote tables have a limit of 1,000 records. If you need a larger amount of data, use an ERP extraction table.

Procedure

  1. Browse available remote tables by navigating to All > ERP Canvas > ERP Canvas Home.
  2. Open the Remote tables page by selecting the remote tables icon () in the side panel.
  3. View the details for a remote table by selecting the remote table Name.
  4. Edit the remote table details as needed.
  5. Optional: View the ERP remote table on the ServiceNow AI Platform by selecting the Open remote table list button.
  6. Select Save.
