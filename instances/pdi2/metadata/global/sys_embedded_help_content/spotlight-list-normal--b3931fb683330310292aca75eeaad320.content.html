Spotlight records

Each row in the Spotlights table represents a Spotlight record. Spotlight records are generated when a Spotlight job runs for a Spotlight group. Each facts table record with a Spotlight score that exceeds the threshold set on the Spotlight group generates a corresponding Spotlight record. The Spotlight score is equal to the weights of all Spotlight criteria that the facts table record meets. The Spotlight criteria and the selection of facts table records are specific to the Spotlight group.

Spotlight records are kept only for the most recent Spotlight job for each Spotlight group.

Clicking an entry in the ID column opens the related facts table record, not the Spotlight record. Clicking an entry in the Table column opens the Spotlight record.
