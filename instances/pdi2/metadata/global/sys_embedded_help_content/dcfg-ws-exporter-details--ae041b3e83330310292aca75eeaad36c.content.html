View exporter

View exporter to see details, work with versions, and access execution information, including the test playground.

  • Exporters with source ServiceNow cannot be deleted or modified, but can be copied to create a new exporter to modify.
  • Exporters must be published before they can be run.
  • Snapshots cannot exceed 10,000 config data items (CDIs) per deployable, or 100,000 CDIs per application.

Details

Lists the specific details for the exporter, including when it was created and updated.

Versions

Lists the versions for the exporter. The first draft version of an exporter is named Draft 0.1.

Executions

View a list of exporter executions to identify config updates that are successful and to isolate changes that caused failure in the pipeline.
