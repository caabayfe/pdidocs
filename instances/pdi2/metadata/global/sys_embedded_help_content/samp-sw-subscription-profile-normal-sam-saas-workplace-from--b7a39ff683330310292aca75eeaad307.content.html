Creating a Workplace from Facebook integration profile

Create an integration profile to connect your Workplace from Facebook applications with the ServiceNow AI Platform. Use this integration to view software usage information and optimize stale licenses.

The integration profile uses the Workplace from Facebook Download Subscriptions, Workplace from Facebook Update User Activity, and Workplace from Facebook Reclaim Subscription subflows to retrieve user data from your Workplace from Facebook applications. You can select the date and time that you want to analyze user activity from in the Analyze user activity from field on the Calculate Activity Subflow tab. You can start analyzing data from the current date or from up to 60 days prior.
