Map data items list

This list provides details on map data items available for your instance. These items render data on your Map Page in the Classic Environment.

Name
Name of the map data item.
Condition type
Whether the condition uses declarative or scripted conditions.
Conditions
Conditions chosen for the map data item, if the Condition type is declarative.
Query condition script
Condition for your map data item, if the Condition type is script.
Table
Table for the condition, for example, the Choice [sys_choice] table.
