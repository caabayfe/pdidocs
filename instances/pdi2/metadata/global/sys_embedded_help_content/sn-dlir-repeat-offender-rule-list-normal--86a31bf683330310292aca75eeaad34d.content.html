Configure repeat offense identification rules

Role required:
  • sn_dlir.admin - Create, edit, and delete.
  • sn_dlir.analyst - View (read-only).

Repeat Offense Identification Rule enables you to identify users who repeat the same issue multiple times. You can identify repeat offenders by using certain rules or criteria. Data Loss Prevention Incident Response provides fields that you can use to identify repeat offenders.

  1. To create a Repeat Offense Identification Rule, click New.
  2. On the form, fill in the fields.
  3. In the Repeat offense identification section, select the required DLP fields to be used for repeat offense identification.
  4. In the Repeat offense threshold section, define the violation criteria.
  5. Click Submit.
