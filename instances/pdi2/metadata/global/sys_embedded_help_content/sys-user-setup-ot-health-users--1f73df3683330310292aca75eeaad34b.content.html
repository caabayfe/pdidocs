Users and roles

Role required: admin or user_admin

  1. Create any new user records for any users that do not already have an account in this instance.
  2. Then assign one of each of the following roles to individual users or user groups as needed:
    Note:

    You might want to pair the Operational Technology Incident Management roles with these roles to view the OT incidents created for these alerts. If you want to manage incident creation for OT Alerts, assign the sn_ot_incident_write role to the user. If you want to view the OT incident created, assign the sn_ot_incident_read role.

    OT Health Admin (ot_health_admin)
    Has view, write and create access to all Event Management features to configure Industrial Process Health. Can configure Alert management rules. Includes evt_mgmt_admin, ot_health_write roles.
    OT Health Editor (ot_health_write)
    Can create, view and edit OT Alerts across list views and related lists. Includes ot_health_read and evt_mgmt_operator roles.
    OT Health Reader (ot_health_read)
    Can only view the OT alert records. Includes cmdb_ot_isa_viewer, cmdb_ot_viewer and evt_mgmt_user roles.
