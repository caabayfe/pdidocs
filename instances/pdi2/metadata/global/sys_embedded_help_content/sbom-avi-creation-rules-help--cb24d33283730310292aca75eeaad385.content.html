Add a rule for creating application vulnerable items (AVIs)

If you want to create application vulnerable items (AVI)s automatically for the components with vulnerabilities in SBOMs you ingest, you must set up your creation rules.

AVIs are created when the conditions you define in the rule are satisfied. You can view AVIs in the BOM Entities module on the Home page in the SBOM Workspace. You also can view them with all AVI records on the Application Vulnerable Items [sn_vul_app_vulnerable_item] table.
  • You can verify that an AVI is created from SBOM data by the values in the Source and Scan type fields on AVI records.
  • To view only AVIs that are created from SBOM data from the Application Vulnerable Items list, set the filters: [Source] [is] [SBOM] AND [Scan type] [is] [SBOM-SCA].

You cannot edit rules if a rule has created at least one active AVI.

If you’re using the SBOM applications with the Application Vulnerability Response application, AVIs from SBOMs are assigned automatically for remediation based on assignment rules and other remediation rules that you set up in the Application Vulnerability Response application.

What you can do on this page

Select New to add a rule. Use the condition builder to determine a set of conditions for your rule.

Select Deactivate to remove any rules on this page for AVI creation. If you deactivate a rule, its conditions aren’t considered for new AVI creation when the scheduled job runs.

Select Execute Now to trigger the scheduled job to create AVIs on-demand.
