Errors page

The Errors page displays the discovery error that occurred during the discovery runs.

Cloud Discovery supports the following error categories:
  • Configuration
  • Network
  • Credentials
  • Performance
  • Configuration Management Database (CMDB)
  • Customization
  • Internal

Within each error category, Cloud Discovery groups the errors by error code and displays each error code in a separate card. Select the card to view the list of grouped errors.
