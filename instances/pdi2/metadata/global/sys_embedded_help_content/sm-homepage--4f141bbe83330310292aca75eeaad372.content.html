Service Mapping Workspace

The Service Mapping workspace provides real-time information about servers, mapped application services, and application service candidates. It uses visualizations to summarize the information in different categories, allowing you to remain service-aware.

Using the workspace

The workspace displays statistics related to Service Mapping. Select a component to access more detailed information and take further action as needed.

Populate data
Select this button to run the job that produces the data displayed on the page. Use it to refresh the data and update the display.
Search for server
Begin typing to search for a specific server and view related information.
List navigation
Use the list navigation icon to select a desired list and view detailed information related to statistics on the workspace home page.
Application service readiness
To access the application service readiness dashboard, select the icon.

Default data

By default, the workspace displays the following:
  • Mapped application services
  • ML-powered candidates
  • Mapped servers
  • Unmapped servers
  • Reports for mapped application services in different categories
