Loaner asset orders

The Loaner Asset Orders list shows all the loaner orders the asset is serving or has served in the past. If a consumable isn’t in a stockroom, it shows only the current loaner asset order that it's serving currently.

View the loaner asset order details such as the order number, model and asset type, start and return date, stage of the order, and if your order is waitlisted.

Select a loaner asset order number to edit the details or to prepare, deploy, and reclaim loaner assets.
