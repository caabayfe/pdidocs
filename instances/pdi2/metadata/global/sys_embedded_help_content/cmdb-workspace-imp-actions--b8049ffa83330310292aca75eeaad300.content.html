Important actions

Important actions of various categories that require your attention or action.

Task categories can include:
  • Health tasks generated by CMDB Health: In health-related cards, such as Duplicate CIs, Orphan CIs, stale CIs, and De-duplication tasks, select View CIs or View Tasks to view the list of associated CIs or important tasks.
  • Data attestation and life cycle approval tasks generated by the Working with CMDB Data Manager: In data attestation-related cards, such as Reassignment Requests and Unassigned Overdue cards, select View Tasks to view associated important tasks.
Important actions are stored in the CMDB WS Imp Action Card Config [sn_cmdb_ws_imp_action_card_config] table. Only users with the sn_cmdb_admin role can edit the table. Users can modify attributes of an important action such as Active and Filter conditions, but cannot modify the Type, Persona, and Table attributes.
  • Important action cards are grouped by the logged-in user role, as specified in the CMDB WS Imp Action Card Config [sn_cmdb_ws_imp_action_card_config] table.
  • A card appears only if there is at least one record that meets the card's filter condition.
  • If you select a Health-related card and modify an associated CI, any resulting impact to health KPIs might appear only after the next cycle of the CMDB Health dashboard jobs.
