Set thresholds

Thresholds define a normal range of scores for an indicator and alert you when certain events occurs, like when a score reaches an all-time high.

Before you begin

Role required: Any role for your own personal thresholds. The pa_threshold_admin role or a role containing it (pa_power_user, pa_admin, or admin) for global thresholds and for personal thresholds created by other users.

About this task

A threshold can be personal or global. A personal threshold is visible only to the user that created it. It appears as a light grey dotted line. A global threshold is visible to all users and appears as a dark grey dotted line. Personal thresholds appear only on the KPI Details page. If the widget is configured to show global thresholds, they also appear on time series widgets.

Users receive an email notification when a threshold has been exceeded. Only the owners of a personal threshold are notified when it is exceeded. If you have the pa_threshold_admin role, you can set who receives global threshold messages.

Note: Thresholds are not available when multiple breakdown elements are selected.

Procedure

  1. Click the threshold icon ().
  2. Select either Global or Personal thresholds.
    You see all the existing Global or Personal thresholds on this indicator.
  3. Click the Create Threshold icon () or select an existing target to edit it.
  4. Choose the visibility of the threshold, either Global or Personal.
  5. Select or change the Threshold Type:
    • All time high
    • All time low
    • Less than
    • More than
  6. If you selected Less than or More than, Enter a threshold value to trigger a message if the value of the indicator drops below or exceeds the threshold, respectively.
  7. Click Save if you are creating a threshold or Update if you are modifying a threshold.

What to do next

With the required roles, you can set the contents of the comments on KPI Details and the Analytics Hub for an indicator that exceeds the threshold. You can also set which users receive notifications for global thresholds and distribute overview messages of all indicators that have exceeded a threshold. See the product documentation for details.
