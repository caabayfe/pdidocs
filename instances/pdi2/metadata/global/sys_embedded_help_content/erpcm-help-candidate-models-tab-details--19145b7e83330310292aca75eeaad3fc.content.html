Models tab details

Check and note which ERP (Enterprise Resource Planning) models that ERP Semantic Mining (ERP-CM) identified as being related to the candidate in the Models tab of the candidate details.

Model type
ERP model relevant to the candidate. This value can be a standard ERP model (which you work with in Zero Copy Connector for ERP), a workflow, or a custom business area.
Relevant for implementation
Whether the ERP model is required for replatforming.
Module
ERP business area for the model on the system of record, such as Sales.
Table name
Names of the tables in the ERP model on the ERP system.
