Monitoring Now Assist usage

View an account-level summary of your Now Assist entitlements and track Now Assist usage across all of your instances.

Total purchased

View the total number of Now Assist entitlements purchased across all of your production and non-production instances.

Total used assists

View the total number of Now Assist entitlements consumed across all of your instances. Compare the number of Now Assist entitlements purchased to the number of Now Assist entitlements consumed.

Available assists

Monitor the remaining number of available number of Now Assist entitlements.

Instances

View the number of assists consumed by each instance in the Used assists column.
  • Only instances on Washington DC Patch 2 and higher are listed in the Instances list.
  • If data sharing is restricted on an instance, usage data for that instance is hidden. You can disable the restriction by updating the trust configuration on that instance.

Subscriptions

View details for each of your products that include assists.
  • Determine whether assists are the primary or secondary line item in a purchase according to the value in the Entitlement type column.
  • Verify the start date and end date for each product.
  • View the number of purchased assists by product in the Purchased assists column.

Current instance details

Determine Now Assist usage by skill on your current instance.
  • View the number of times a skill has been used in the Number of actions column.
  • View the relative cost for each assist in the Assist ratio column.
  • Determine which skills are consuming the most assists in the Total assists column. Total assists are calculated by multiplying values in the Number of actions column by values in the Assist ratio column.
  • Analyze Now Assist usage history and compare usage by skill over time. If usage continues to grow every month, consider purchasing more entitlements to stay in compliance.
