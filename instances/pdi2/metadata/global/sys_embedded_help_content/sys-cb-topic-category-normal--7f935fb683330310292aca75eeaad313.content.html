Create a custom category

Create or change custom categories for organizing and grouping related Virtual Agent objects, such as topics. You can also make category labels visible in the Topic picker menu displayed to end users.

  1. On the form, fill in the fields.
    Name
    Label for the category.
    Visible to end user
    Option that makes the category label visible in the Category list on the Topics page.
  2. Click Submit.
