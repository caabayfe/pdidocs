Search context

Allow additional resources to be included in the source selector.

  1. If you are prompted with the message To edit this record click here, then click here.
  2. Click the Additional Resource Configurations tab.
    Note: There additional resources are already included for incident and problem.
  3. Select Search on tab.
    Note: Search on tab means do not run the search until the user has updated the search field and changed focus to somewhere else. For example, the user uses the tab key.
  4. Click Update.
