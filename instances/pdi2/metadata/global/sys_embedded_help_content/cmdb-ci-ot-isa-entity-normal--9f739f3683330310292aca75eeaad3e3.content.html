Create and Manage

To create an Equipment Model manually, you must create a top level entity (with no parent) - known as a "site" entity in the ISA model.

  1. Create a new record
  2. Leave the parent field blank
  3. Add a short code
  4. If you have configured a template, assign the template to be used by this Equipment Model for this site

To add Equipment Model entities to an existing model:

  1. Open the Equipment Model entity you wish to add children to
  2. Click the "Child Entities" related list tab
  3. Click the "New" button
  4. Fill in the form. If a Template has been assigned to this Equipment Model, the Level is required.
  5. Additional children levels can be added by repeating the previous steps

Assign user criteria

When OT Devices are in the CMDB, you can configure site access with user criteria.

  1. To add user criteria to a site for Can Read access, select the Can Read Equipment Models tab and select New.
  2. To add user criteria to a site for Can Edit access, select the Can Edit Equipment Models tab and select New.
For more information about creating and assigning user criteria, see the following topics:
  • Assign or remove equipment model site access for non-administrators
  • Assign the user criteria for Can Read access to a site
  • Assign the user criteria for Can Edit access to a site
