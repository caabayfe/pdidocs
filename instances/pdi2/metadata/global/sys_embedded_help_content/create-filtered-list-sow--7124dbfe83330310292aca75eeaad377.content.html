Create a filtered list

Create your own filtered list to display records of your choice.

Before you begin

Role required: itil or admin

Procedure

  1. From the List menu and select the My Lists tab.
  2. Click New list.
  3. To create a different version of the existing list, perform the following steps.
    1. In the New List dialog box, select theStart from existing tab.
    2. Specify the required details.
  4. To create your own list, perform the following steps.
    1. In the New List dialog box, select theCreate your own tab.
    2. Specify the required details.
  5. Click Create.
