Creating a Microsoft Entra ID integration profile

Create an integration profile to connect your Microsoft Entra ID account to the NOW platform. View software usage for all connected SSO applications and optimize stale licenses.

Important: Before you can create the integration profile, you will need to create a Microsoft Entra ID application in the Azure portal.

Enter a name for the integration profile in the Display name field, then click Submit. The remaining fields are automatically populated when you submit the form.

Update Connection and Credential Information

Click the Create New Connection & Credential related link. On the form, fill in the fields, then click Create and Get OAuth Token.
  • Auth URL - https://login.microsoftonline.com/<directory-id>/oauth2/v2.0/authorize, where <directory-id> is the directory (tenant) ID from the Azure portal.
  • Token URL - https://login.microsoftonline.com/<directory-id>/oauth2/v2.0/token, where <directory-id> is the directory (tenant) ID from the Azure portal.
  • Revoke token URL - https://login.microsoftonline.com/<directory-id>/oauth2/v2.0/revoke, where <directory-id> is the directory (tenant) ID from the Azure portal.
  • OAuth Client ID - Application (client) ID for the application you created in the Azure portal.
  • OAuth Client Secret - Client secret for the application you created in the Azure portal.
  • OAuth Redirect URL - https://<instance-name>.service-now.com/oauth_redirect.do, where <instance-name> is the name of your ServiceNow instance. This value is automatically populated.

Publish the integration profile

To start using the integration, click Publish.

Connect SSO apps

After you publish the integration profile, connect SSO apps to view all users and groups with access to each app.
