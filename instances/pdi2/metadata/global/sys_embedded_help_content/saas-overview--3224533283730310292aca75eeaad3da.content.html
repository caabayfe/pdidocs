SaaS overview

Use the SaaS overview dashboard to optimize how much your organization spends on SaaS and SSO licensing by analyzing the subscription usage, cost, and compliance of your SaaS applications and SSO providers.

You can also view compliance analysis results related to Microsoft Office 365 and Adobe Cloud.
Note: The SaaS overview dashboard is only visible if you activate the Software Asset Management - SaaS License Management Integrations plugin from ServiceNow Store.

Click any metric to see detailed information.

You can filter the dashboard by instance, publisher, software model, or domain.
Note: The Domain filter narrows your results based on the domain you select. The default value for the domain filter is global. You can select a domain at any given time for widgets to reflect the selected domain. Once you clear the selected domain, it defaults back to global. The Domain filter appears on the screen only if the following plugins are installed:
  • Domain Support - Domain Extensions Installer (com.glide.domain.msp_extensions.installer)
  • Performance Analytics - Domain Support (com.snc.pa.domain_support)
