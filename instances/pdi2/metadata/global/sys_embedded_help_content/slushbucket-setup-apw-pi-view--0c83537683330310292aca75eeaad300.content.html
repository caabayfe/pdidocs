Create the view in the planning item form

Role required: admin

  1. From the View name field, select New.
  2. In the Create New View window, enter one of the following names in the View name field and select OK:
    • Workspace APW Preview
    • Workspace APW Default
    • Workspace APW New
  3. Order the form fields according to your preference.
    For the APW New view, ensure that you select the Planning Organization field to be visible on the form.
  4. Save the form.
  5. Repeat the steps to create the other two views.
