Creating a calendar for unattended robots

View and create a schedule for your unattended robots by using the robot calendar in RPA Hub. With this calendar, you can manage and plan a robot's schedule in a single view.

If a robot is associated to multiple bot processes, the landing page of the robot calendar is the schedule view of a published bot process. You can have more than one published bot process associated with a robot.

What can you do on this page

Today
Highlight the current date.
Show Filter
View the filter options to display the schedules on the life-cycle stage status of the bot process and the bot process name.
View the filter options by selecting the filter icon ().
Schedule Timezones
View the time zones that are defined for the robot, such as the robot time zone (workstation time zone), user profile time zone, and schedule time zone. This field is a drop-down list. You can have multiple, scheduled time zones, based on the various schedules that are defined across the different time zones.
The workstation time zone contains information about the time zone of the machine on which the robot is running.
The schedule time zone is defined in the Timezone field when you create a schedule for a bot process.
The user profile time zone is defined at the instance level, where you can modify it from your profile.
Views
View the events in the calendar for a particular day by selecting Day.
View the events in the calendar for a particular week by selecting Week. The week view starts from Sunday to Saturday. The default first day of the week is Sunday.
View the events in the calendar for a particular month by selecting Month.
Refresh
View the new or updated schedules on the robot calendar by selecting the refresh icon ().
