Creating a portfolio plan

Create a personalized portfolio plan using a lens that matches your planning perspective.

Use the 4-step wizard to create a portfolio plan. Select a lens, choose entities, provide a name and dates for the plan.

Lens indicate the perspective in which you plan work. It can be for a department, value stream, goal, or product. Examples:
  • If you're the leader for the HR department, you might want to view existing and incoming work for your department and plan for it. Then, select the Organization lens.
  • If you're an EPMO, planning high-level items for your company, select the Strategic Investments lens.

Entity types represents the level that you plan your work in. For example, select Department as the entity type and HR as your entity. This step is not available for high-level planning.
