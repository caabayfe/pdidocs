Create a Portal Catalog

Role required: admin.

Use this form to create a new Portal Catalog. Enable your users to view and request their associated items in the Now Mobile app. If no catalogs are selected, users can view and request items from all catalogs in the system. By default, the app uses Service Catalog.

  1. On the form, fill in the fields.
    Portal
    Portal associated with the applet. Select Employee Center.
    Catalog
    Catalog associated with the applet.
    Order
    Number indicating the order that the configurations should run. If there are multiple configurations on a portal, the system runs the configurations from the lowest to the highest order that you selected.
    Active
    Whether the entry is currently in use with your applet.
  2. Click Submit.

Your users can view and request items from all added catalogs.
