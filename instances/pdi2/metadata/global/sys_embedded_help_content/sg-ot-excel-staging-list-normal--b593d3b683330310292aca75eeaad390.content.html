Prepare Data

Download template from easy import at the staging table.

  • Right click on the column header and select Import.
  • Click on Create Excel Template to download the excel template.
Once data is populated in the template, import data to staging table using easy import.
  • Right click on the column header and select Import.
  • Go to section - Upload the template file and select the excel data file and click Upload button to populate the excel.

Note: Column names shouldn’t be changed.

Create new OT Devices

This task requires ot_staging_user role.

Users will be able to create new devices in the staging table. Once the device is created, its status is set to Pending validation.

Validate records

This task requires cmdb_ot_admin or ot_staging_user role.

Once the import of records is successful in the staging table, run validations against this data by clicking "Run Validations" UI action.

This will update the Validation state of the records and provide relevant validation comments.

NOTE : You don't need to select any records on the list to run validations. Validations are run on all the records present in the staging table.

When records are in invalid state, users can group them into a staging task per site for further analysis.

Schedule Import

This task requires admin or cmdb_inst_admin role.

Once the validations are completed, click on Schedule Import UI action to import data from staging table to the import set table.

In the Scheduled Data Import, click on Execute Now to execute the import immediately.

Successfully imported records are updated with Validation state as "Imported".

Review the data imported in the OT list views and Workspace.
