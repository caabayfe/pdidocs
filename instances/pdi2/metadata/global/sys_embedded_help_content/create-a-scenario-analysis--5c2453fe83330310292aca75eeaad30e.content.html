Create a scenario analysis for a business service

Create a scenario analysis for your business services in Operational Resilience Workspace. You can analyze the impact of the scenarios and associated events. You can then calculate the disruptions and determine if any of your services are breached.

Before you begin

Role required: sn_oper_res.manager

Procedure

  1. Navigate to All > Operational Resilience Workspace > Lists > All scenario analysis and select New.
    The Create New Scenario analysis form is displayed.
  2. In the Scenario analysis panel, enter the name, description, and goal for the scenario analysis.
    The number for the scenario analysis is auto-filled by the system.
  3. In the Analysis start date field in the Milestones panel, enter the start date for the analysis in the YYYY-MM-DD HH:mm:ss format.
    A notification is sent to the participants to start their analysis on the Analysis start date.
  4. In the Plan approver field in the Assignees panel, select the plan approver for the analysis.
  5. In the Analysis approver field, select the analysis approver for the analysis.

    The logged-in user is automatically assigned as the owner of the analysis.

  6. Select Save.
