Start an unattended bot process

Start an unattended bot process in a robot machine that you specify to execute the automation by the selected robot.

Before you begin

  • Associate a package and a package version to the bot process. For more information, see Create a bot process configuration record in RPA Hub.
  • Verify that the life-cycle stage status of the bot process is either in Published, In Maintenance, or Build.
  • If the External Credential check box is selected in a robot credential record, then ensure that the associated external credential vault record is active. For more information, see Create a robot credential in RPA Hub.

Role required: sn_rpa_fdn.rpa_developer, sn_rpa_fdn.rpa_support_user, sn_rpa_fdn.rpa_business_user, or sn_rpa_fdn.rpa_admin

About this task

You can only select the robots that have assigned credential groups and are in the Available and Busy states. For more information about credential groups, see Create a credential group in RPA Hub.

Those robots are displayed here (in step 2) to facilitate a process job queuing. A job queue contains the processes that are executed in a defined order.

Procedure

  1. In the form header, select Start Process.
  2. Select the robot that is assigned to the current bot process that you want to start.
  3. Select Start Process.
