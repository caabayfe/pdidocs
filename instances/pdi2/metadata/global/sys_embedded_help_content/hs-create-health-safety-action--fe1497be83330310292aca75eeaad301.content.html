Create an action

Create and assign corrective actions to address issues and preventative actions to prevent future occurrences.

Before you begin

Role required: sn_ohs_im.manager or sn_ohs_im.agent

Procedure

  1. In the Type field, select the type of the action.
    • Corrective: An action taken to eliminate the causes of non-conformities or undesirable situations to stop them from happening again.
    • Preventive: An action taken to prevent the occurrence of such non-conformities.
  2. In the Due date field, select a date to complete this action.
  3. In the Assignment group field, select the group.
    Only a health and safety group can be assigned to an action record.
  4. Select Save.

Result

The action appears in the list of actions in the Health and Safety actions tab. The action is also listed in the Actions list on Health and Safety Workspace.
