Edit the robot schedule of a bot process

Edit the robot schedule of a bot process on the Robot Calendar tab to resolve any scheduling conflicts or to modify the details on the schedule form.

Before you begin

  • Create an unattended robot. On the robot form, make sure that you select the Robot Type field as Unattended. For more information, see .
  • Establish the robot connection to an unattended bot process. For more information, see Assign a robot to a bot process in RPA Hub.
  • Create a schedule for an unattended bot process so that you can view some schedules on the robot's calendar. For more information, see Create a schedule on the robot calendar in RPA Hub or Create a schedule within a bot process in RPA Hub.
  • Verify that the life-cycle stage of the associated bot process isn’t set to Retired.
  • Make sure that the RPA developer (sn_rpa_fdn.rpa_developer) or the RPA support user (sn_rpa_fdn.rpa_support_user) are in the Managed by Group list.

Role required: sn_rpa_fdn.rpa_release_manager, sn_rpa_fdn.rpa_developer, sn_rpa_fdn.rpa_support_user, or sn_rpa_fdn.rpa_admin

Procedure

  1. On the Robot Calendar tab, edit a schedule by either right-clicking an event or selecting the event's pop-up window.
  2. Optional: If the life-cycle stage status of the bot process is set to Published and you want to change the status to In Maintenance, select Continue in the Confirmation dialog box.
  3. On the Edit schedule form, update the fields as appropriate.
  4. Optional: To identify any further conflicts in the schedule or preview the schedule, select Preview.
  5. Save the schedule by doing one of these actions.
