Import OT Subnet Spreadsheet Using Simple Import

To import a spreadsheet containing subnet records, right click the header of the list view and select "Import". On the import external data screen:

  1. Select "Insert".
  2. Check the box to create an Excel template.
  3. Click the "Create Excel template" button and download the Excel template.
  4. Open the template and read the "Directions" tab.

  5. Paste your data into "Page 1" tab of the template. You must include these required fields:

    1. Name - this is the human readable name of the zone or VLAN imported
    2. Subnet - in CIDR notation
    3. Site - optional - use the entity name value from the "Industrial > Industrial Process Manager > Sites" application menu
    4. All other fields are optional
  6. Save the file to your computer.
  7. Click "Choose File" to select the file you just saved.
  8. Click " Upload".
  9. Click "Preview Imported Data".
  10. Scroll down and click "Complete Import"
  11. A list of imported records will be displayed. Clear the filter to display all OT subnet records.

Add Sites for OT Subnets to Map

Add the site value to the OT subnet records corresponding to networks at that site. Use the list view edit feature to edit multiple rows at the same time.

Add Equipment Model Entities for OT Subnets to Map

Add the equipment model entity value to the OT subnet records corresponding to the functional location or production process at that site. Use the list view edit feature to edit multiple rows at the same time.

Automatically Map OT devices for Selected OT Subnets or Individual OT Device Records

To automatically map OT devices to sites and equipment model entities, an ISA Editor with site access can trigger mapping in the following ways:
  • All OT devices associated with an OT subnet can be selectively mapped using the UI action "Map OT devices in this subnet" on the OT subnet form. This UI action works for selected active and inactive records.
  • An individual OT device can be mapped if the corresponding target OT subnet mapping record is set to "active." To automatically map an individual OT device, open the record and click the "Map OT device" related link UI action at the bottom of the form.

An ISA Admin can also trigger mapping in the following way:

  • All OT devices can be mapped with active OT subnet records.
  • Click the "Map all OT devices" UI action button on the OT subnet list view.
