Snapshots

View the snapshots of all deployables for an application and validate, publish or unpublish them.

To view and edit the details of a snapshot, select the name of the snapshot in the list to open it in a new tab.

On the snapshots list, you can select one or more check boxes next to the snapshot name to perform the following actions:
  • Validate: Select Validate to run the selected snapshots against the predefined set of policies.
  • Publish: Select the more actions button () next to the Validate button and select Publish from the menu.

    The snapshots that have the Published value as false and Validation as Passed are published.

  • Unpublish: Select the more actions button next to the Validate button and select Unpublish from the menu.

    The snapshots that have the Published value as true are unpublished.
