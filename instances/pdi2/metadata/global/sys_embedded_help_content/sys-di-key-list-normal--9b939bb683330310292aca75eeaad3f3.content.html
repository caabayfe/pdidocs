Fields

DocIntel uses fields in data extraction use cases to identify and extract data from documents. It uses fields in document classification use cases to define the classes or categories to apply to documents.

The Fields list shows the DocIntel fields in your instance.
  • Select (or right-click) the column headers to sort, filter, and edit the list.
  • Select the Personalize list icon to choose the columns in your list.
  • Select a field to view and edit the field details.

The Fields list includes the following significant columns:

Display Name
Name of the field
Type
Type of field (for example, text or check box)
Field Group
[Data extraction uses cases only] Field group associated with the field
Use Case
Use case associated with the field

For an improved DocIntel setup, configuration, and monitoring experience, install the Document Intelligence Admin application.
