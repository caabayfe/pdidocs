Create a demand using bubble chart

Create a demand for an application from the bubble chart.

Before you begin

Role required: sn_apm.apm_analyst

Procedure

  1. Select the bubble for the relevant application that you want to create a demand for.
  2. In the pop-up window, select the context menu icon () and select Create demand.
  3. In the Create demand form, fill in the fields.
    For a description of the field values, see Create demand form.
  4. Select Create.
