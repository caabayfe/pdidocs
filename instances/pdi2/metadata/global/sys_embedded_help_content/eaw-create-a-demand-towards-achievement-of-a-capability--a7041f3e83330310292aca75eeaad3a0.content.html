Create a demand towards achievement of a capability

Use a demand as a step to identify cost-saving opportunities on capabilities, to meet the target.

Before you begin

Role required: sn_apm.apm_user

Procedure

  1. Select the row context menu icon () and select Create Demand.
  2. Select Open in new tab.
  3. On the form, fill in the fields.
    For a description of the field values, see .
  4. Select Save to save the record and remain on the same form to add more details to the demand.
