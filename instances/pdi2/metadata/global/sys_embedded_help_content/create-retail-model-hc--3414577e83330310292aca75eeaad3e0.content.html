Create a retail model

Create retail models based on a top tier Enterprise Asset Management model category.

Before you begin

Role required: sn_eam.enterprise_admin or sn_eam.enterprise_asset_manager

Procedure

  1. On the Create New Medical model page, fill in the details.
    The model is in Build status by default and the model category is a read-only field set to the category that you chose. You can change the status only after you have saved the model record. For a detailed description of all the fields, refer to the Model field descriptions link in the Related information section at the end of this topic.
  2. Select Save.
    The model is created along with the related tabs such as Model Components, Assets, Enterprise Model Lifecycles, Compatibles,Substitutes, and Vendor Catalog Items. You can perform additional configuration on the model by entering details in the related tabs.
  3. Change the status of the model to In Production once you are done configuring the model.
  4. Select Publish to Enterprise Asset Catalog to publish your model to the Service Catalog.Publish to Enterprise Asset Catalog appears only when you change the status of the model to In Production.
    Enterprise models can be deleted only by the sn_eam.enterprise_admin role.
