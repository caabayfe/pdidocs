Create a new automated breakdown by wizard

Use this wizard to create a Performance Analytics breakdown based on an existing indicator. In the wizard you can create the breakdown source if necessary. You can also map the breakdown to the correct field on the indicator source.

To use this wizard, you still need to be trained in Performance Analytics and to be familiar with its concepts.

Create breakdowns only as part of an analytics strategy. Consider planning your breakdowns with KPI Composer.

Only a subset of configuration options are available through this wizard. If you need access to the full range of indicator parameters, go to Performance Analytics > Automated Breakdowns.
