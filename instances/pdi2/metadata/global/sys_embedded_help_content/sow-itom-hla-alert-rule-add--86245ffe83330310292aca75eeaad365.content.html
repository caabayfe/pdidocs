Add a Log Analytics alert rule

When you encounter log data that should generate an alert, you can define a Log Analytics alert rule. The alert rule generates an alert for the specified metric, with a threshold that you configure.

Before you begin

Define and run a search before performing this procedure.

Role required: evt_mgmt_operator or evt_mgmt_admin

Procedure

  1. On the Log viewer, select Define alert.
  2. On the form for creating an alert rule, provide a name and description for the new rule.
    The name appears on the Anomaly card for generated alerts.
  3. Set the Severity value for the alert generated by this alert rule.
    The available values are:
    • Low: Attention is required even though the resource is still functional.
    • Medium: Either performance has degraded or a partial, non-critical loss of functionality has occurred.
    • High: Major functionality is severely impaired or performance has degraded.
    • Critical: Immediate action is required. Either the resource is not functional or critical problems are imminent.
  4. Fill in the details for the query.
  5. Fill in the fields related to the threshold that will trigger the alert rule.
  6. Optional: Activate the rule by setting the State field to Enabled.
  7. Select Save.

Result

The new alert rule is saved. When enabled, the rule generates an alert when the threshold conditions are met in the log data.
