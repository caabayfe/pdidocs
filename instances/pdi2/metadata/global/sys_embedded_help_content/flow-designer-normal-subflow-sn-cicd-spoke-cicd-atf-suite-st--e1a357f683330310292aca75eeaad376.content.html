ATF Suite Start With ID subflow

Starts an ATF test suite on a specified instance, using the ID of the test suite, and returns the suite execution results.
Note: You must create a corresponding CICD connection and credential, and then associate them with the Instance URL input value.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Wait for Completion
Data type: True/False

Indicates whether or not every action within this subflow must finish running before the main flow can move on to the next step.

Test Suite Sys ID
Data type: String

System ID of the ATF test suite.

Credential Alias
Data type: String

Connection and credential alias of type Credential. This alias must have a user with the sn_cicd.sys_ci_automation role.

Instance URL
Data type: String

URL of the instance on which you want to start the test suite.

Browser Name
Data type: String
Name of the browser on which to run the scheduled client test runner. This value defaults to Any if no browser is named. A browser name must exactly match one of the following:
  • Chrome
  • Firefox
  • Edge
  • IE
  • Safari
Browser Version
Data type: String

Version of the browser on which the client test runner is running. This value defaults to Any.

OS Name
Data type: String
Name of the OS on which the browser is running. This value defaults to Any if no OS is named. An OS name must exactly match one of the following:
  • Windows
  • Mac OS X
  • Linux
OS Version
Data type: String

Version of the OS used to open the scheduled client test runner. This value defaults to Any.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Status
Data type: String

The status of the action. The flow execution details page displays one of these values:

  • 0: Pending
  • 1: Running
  • 2: Successful
  • 3: Failed
  • 4: Cancelled
Error
Data type: String

Reason for the error, if an error occurred.

HTTP Status
Data type: String

HTTP status code of the response.

Status Label
Data type: String

Label of the status code that was returned, such as Pending or Running.

Status Message
Data type: String

Message with a summary of why the operation failed (if an error occurred). This value can be null.

Status Detail
Data type: String

Details on why the operation failed (if an error occurred). This value can be null.

Result URL
Data type: String

URL of the ATF suite execution record containing test results.

Test Suite Duration
Data type: String

Total duration of the test, in seconds.

Rolledup Test Success Count
Data type: Integer

Number of tests that succeeded, including all successful child tests.

Rolledup Test Failure Count
Data type: Integer

Number of tests that failed, including all failed child tests.

Rolledup Test Error Count
Data type: Integer

Number of tests that produced an error, including all child tests that produced an errort.

Rolledup Test Skip Count
Data type: Integer

Number of tests that were skipped, including all skipped child tests.

Test Suite Name
Data type: String

Name of the test suite.
