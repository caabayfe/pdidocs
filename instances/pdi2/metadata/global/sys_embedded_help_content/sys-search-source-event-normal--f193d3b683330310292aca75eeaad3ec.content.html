Create a Search Source Event

Role required: admin.

Use this form to add a record to the Search Event per source [sys_search_source_event] table, which stores records correlating search strings with results from a specific table, here called a data source. A search can query multiple tables. The Search Events [sys_search_event] table lists one record for the entire search, while the sys_search_source_event table lists one record for each data source (table) queried.

  1. On the form, fill in the fields.
    Search query
    The search string that was entered.
    Has results
    Boolean value specifying whether the source did (true) or didn't (false) supply search results.
    Source
    System ID of the data source. For example, the system ID of the Knowledge Base might be c45067sample3c82eef3e. Suggestions from one source are used as suggestions for that source only. For example, a suggestion derived from the Service Portal wouldn't be used as a suggestion in Now Mobile.
  2. Click Submit.
