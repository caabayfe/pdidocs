Twilio SMS texter AI agent

Streamline communication processes and enhance workflow efficiency using the Twilio SMS texter AI agent.

Important: By default, all agentic workflow and AI agent records are read only.

To run the AI agents autonomously, you must first duplicate the agentic workflow, and then proceed with the following steps:

  • Activate the agentic workflow.
  • Activate all agents within the agentic workflow.
  • Activate the trigger to invoke the agentic workflow automatically. If you prefer to invoke it manually, activating the trigger isn’t necessary.
    Note: The Notify users with Twilio agentic workflow can only be invoked using a manual trigger.

Send text messages via SMS to recipients manually to help improve the time required for subject matter expert response.

In the AI Agent Studio, the human agent gets notified as soon as a text message is generated so that they can follow the on-screen instructions and complete the task.

Note: The itil role is added by default. You can change the role for the agent. If you change the role, you must also change the role in the following two flow action ACLs:
  • sn_itsm_aia.look_up_incoming_phone_numbers
  • sn_itsm_aia.send_sms
