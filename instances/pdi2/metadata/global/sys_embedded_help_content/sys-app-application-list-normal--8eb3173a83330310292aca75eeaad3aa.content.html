Application menus

Application menus are groups of modules in the application navigator. You can create menus, customize existing ones, or disable ones you no longer need. From the List view, you can update one or more records to change their active status, order, and the roles required to access them.

Active
Select to make the menu available in the navigator for users with the required roles.
Order
Specifies the order menus are presented in the navigator. If the Order field is empty or if two application menus have the same order, they're sorted alphabetically.
Roles
Restrict access to the menu based on roles. If the Roles field is empty, the menu is available for all users.
