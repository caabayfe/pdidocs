Viewing space requests

You can view the total number of space requests raised and details of each space request on the Space Optimization dashboard.

The Workplace Central Space Optimization module enables space planners to view only those workplace cases generated from a space request.

View space requests in one of the following ways:
  • In the Scenarios metrics board, select All space requests.
  • In the Space requests section, select View all.
