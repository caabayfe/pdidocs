Policy record

You can view details of an existing policy including the versions, mapping information, and any exceptions.

Details

The details of the policy including the policy name, category, date on which it was created, and a description is displayed.

Policy builder

When you create a policy, by default a draft policy version is created. Each policy version contains version meta-data, a policy script, and variable input definitions, which you can modify according to your requirements. Click the Policy builder tab to view the Policy builder page. You can:
  • Edit a policy version.
    Note: You can edit a policy version only if it is a Draft state.
  • View version details
  • Create a new version
  • Switch from low-code to the code editor
  • Save the policy as a template
  • Compare versions
  • Duplicate policy versions

Version management

The list of previous versions of the policy. You can also create a new version of the policy.

Mappings

The list of mappings the policy is mapped to.

Exceptions

The list of exceptions associated with the policy.

Executions

The Executions tab enables you to review the execution activity for the policy.
