Edit assigned tasks

Manually assign de-duplication tasks to de-duplication templates. When you run a template, assigned tasks are remediated to reconcile the duplicate CIs associated with the task.

Assign de-duplication task to template

  • Select Run template to remediate assigned tasks.
  • Select tasks in the Available de-duplication tasks list view and then select Add selected to assign the tasks to the current template. You can see the current template from Library and Template.
  • Drill into a particular task to see additional details.

The Available de-duplication tasks list view shows active and open tasks that aren't assigned to the current template. You can only manually assign the task to a template if the task fits the template conditions.

The Assigned de-duplication tasks pane on the right contains two tabs. Each tab shows the first 50 tasks currently assigned to the template. You can search either tab by entering a task number or class in the search bar.
  • All matching tasks: Shows tasks that match the condition of the selected template. To populate this tab with tasks, run the De-duplication: Populate Duplicate Task Data scheduled job and then run the De-duplication: Populate Suggested and Orphan Tasks scheduled job.
  • Your selected tasks: Shows the tasks that you’ve assigned to the template for remediation.

Tasks in the Your selected tasks tab are the tasks that you manually assigned to the template.

After manually assigning tasks and automatically assigning matching tasks to the template with scheduled jobs, select Run template to remediate the duplicate CIs.
