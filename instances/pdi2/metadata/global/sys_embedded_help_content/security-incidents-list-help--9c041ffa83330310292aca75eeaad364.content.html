List of Security Incidents

The list view consists of the security incidents, response tasks, phishing emails, and assessments that are assigned to the analyst.

When you click a record in a list view, the record opens in a new tab. This application enables you to do the following tasks:
  • Security Incidents: View the list of security incidents and navigate to the desired incident to start working on.
  • Response Tasks: View the list of response tasks and navigate to the desired response task to start working on.
  • Phishing Emails: View the list of all Phishing emails. The list view will be sorted based on the last update.
  • Assessments: View the list of assessments needed to perform post incident review.
