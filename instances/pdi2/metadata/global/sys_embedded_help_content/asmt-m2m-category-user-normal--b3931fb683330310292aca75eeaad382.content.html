Assessment Category User form

Category users are users who can potentially answer assessment questions about a particular metric category for scheduled assessments. Category users should have special knowledge of the categories and the metrics those categories contain. A category user becomes a stakeholder when associated to an assessable record. Create at least one category user for each category you want to use for assessment questionnaires.
Select the appropriate users for this category.
Note: The category must be associated to a metric type that has the Schedule type set to Scheduled.
