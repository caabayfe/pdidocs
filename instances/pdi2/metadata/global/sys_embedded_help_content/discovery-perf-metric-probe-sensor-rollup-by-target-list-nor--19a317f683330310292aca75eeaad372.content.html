Discovery performance metrics aggregated by IP address

Use the roll-up by target data to ensure that the processing times for probes/patterns and sensors remain consistent for each Discovery of a specific IP address.
  1. Sort the list by Target IP address.
  2. Filter by a specific IP address to see the aggregated processing times for the probes and patterns that performed the Discovery of that IP address.
  3. Open a record to see the statistics about the selected probe/pattern for the specific IP address.
