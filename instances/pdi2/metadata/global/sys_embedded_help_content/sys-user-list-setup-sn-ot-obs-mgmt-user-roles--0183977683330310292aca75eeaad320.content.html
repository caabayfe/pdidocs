Operational Technology Obsolescence Management roles required for users

Role required: admin or user_admin

Assign roles to users and user groups to give them privileges for various functions across Operational Technology (OT) Obsolescence Management.

  1. Assign users or user groups the following roles to give them administrator privileges for OT Obsolescence Management features:
    OT Obsolescence Risk Score Calculator Admin (sn_risk_score_calculator.admin)

    They can view, edit, run, create, or delete Risk Score Calculator (Configuration, System Properties, Risk Definition, Risk Label, Risk Factor, Risk Transformation, Risk Schedule). Users can create a new score definition within the scope of the existing calculator and run the score calculator. User can also access all Calculator Definitions, created by multiple users along with table level access.

    OT Obsolescence List and Dashboard Admin (cmdb_ot_admin)
    They can view life-cycle data for OT device records, OT Obsolescence Management Lists, and view OT tables for all sites. Users can also view the OT Obsolescence Dashboard and duplicate it across all sites.
    Asset Refresh Request Editor (inventory_user)
    Enables them to create Asset Refresh Requests.
    Asset Refresh Request List Viewer (sn_request_read)
    Enables them to view asset refresh request list view.
  2. Assign users or user groups the following roles to give them editor privileges for OT Obsolescence Management features:
    OT Obsolescence List Viewer (cmdb_ot_viewer)
    They can view life-cycle data for OT device records, and can also view Obsolescence Lists. If the user isn't assigned sites, then they can only view unmapped OT devices.
    OT Obsolescence Dashboard Editor (cmdb_ot_viewer and cmdb_ot_isa_viewer)
    Users can view the OT Obsolescence Dashboard and duplicate it. Can view data for assigned sites only.
    OT Obsolescence Risk Score Calculator Editor (sn_risk_score_calculator.user)
    They can view, edit, run, or create a Risk score calculator (Configuration, System Properties, Risk Definition, Risk Label, Risk Factor, Risk Transformation, and Risk Schedule). Users can also view, create, and edit Risk Calculator Definitions (Configuration, System Properties, Risk Definition, Risk Label, Risk Factor, Risk Transformation, Risk Schedule) created by them. User can perform Risk Score Calculation only for assigned sites. They can’t perform Risk Score Calculation for unassigned sites.
    Asset Refresh Request Editor (inventory_user)

    They can create Asset Refresh Requests.

    Asset Refresh Request List Viewer (sn_request_read)

    Can view asset refresh request list view.

  3. Assign users or user groups the following roles to give them viewer privileges across OT Obsolescence Management features:
    OT Obsolescence List Viewer (cmdb_ot_viewer)

    They can view life-cycle data for OT device records. If the user isn't assigned sites, then they can only view unmapped OT devices.

    OT Obsolescence Dashboard Viewer (cmdb_ot_viewer and cmdb_ot_isa_viewer)

    They can view the OT Obsolescence Dashboard and duplicate it. Can also view Obsolescence Lists. Can view data for assigned sites only.

    OT Obsolescence Risk Score Calculator Viewer (sn_risk_score_calculator.reader)

    They can view the Risk Score Calculator (Configuration, System Properties, Risk Definition, Risk Label, Risk Factor, Risk Transformation, Risk Schedule) and the Risk Score in Obsolescence list views.

    Asset Refresh Request List Viewer (sn_request_read)

    They can view asset refresh request list view.

  4. Select Save.
