Create a client access record

Create a client access record to track and manage the users or devices that are accessing a particular version of your server software using a client access license (CAL).

Before you begin

Role required: sam_admin
Note: You can also use the sam_user role to view and read client access records. However, you cannot use the sam_user role to create client access records.

Procedure

  1. On the Create New Client Access form, fill in the fields.
  2. Select Save.
    The form reloads with the Users, Devices, and Devices with Installations tabs. These tabs appear based on the type of CAL you select in the Type field.
