Create a write-back action item

Role required: admin.

Create a write-back action item when you need one to accompany an action function. Use action functions to change data, such as assigning a task to yourself or adding a comment to a record. Action functions require a write-back action item to operate.

  1. On the form, fill in the fields.
    Name
    The name of the write-back action item.
    Description
    Detailed information to identify the action item.
    Type
    Type of action item being created.
    Execution script
    Code block containing script to run for the action item.
    Use current record as condition
    Disables query conditions (filtering applied to the action item) field when checked.
  2. Click Submit.
