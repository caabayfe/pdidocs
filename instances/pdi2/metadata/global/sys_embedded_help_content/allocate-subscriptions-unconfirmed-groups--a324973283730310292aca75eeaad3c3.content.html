Allocate subscriptions to unconfirmed groups in Subscription Management

Provide entitlements to users with measured roles by allocating subscriptions to unconfirmed groups.

Before you begin

A group in Subscription Management that hasn't been added to a subscription yet but has one or more measured roles is considered an unconfirmed group. You can fix this issue by adding the group to a product subscription that provides entitlements for the role.

Role required: admin

Procedure

  1. Determine whether you have groups with roles that require a subscription.
    • Check the Unconfirmed users column on the Overview tab.
    • Check the Unconfirmed groups column on the details page.
  2. Add the group to a subscription.
    1. Navigate to the Unconfirmed groups column on the subscription details page.
    2. Select a group name.
    3. Select Allocate.
  3. In the dialog box, confirm that you want to allocate subscriptions from the recommended product subscription by selecting Allocate.

Result

Subscriptions are allocated to each group member, and the group is removed from the Unconfirmed groups tab.
