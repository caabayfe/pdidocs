Assign users to OT VR assignment groups

Roles required: admin or user_admin

When OT vulnerable items are created, visibility is limited to users with VR Remediation Owner (sn_vul.remediation_owner) role and membership in the OT VR assignment group associated with the site that the OT sevice belongs to. To add users to a OT VR assignment group:

  1. Select the group that corresponds to the OT VR assignment group for the site.
  2. Open the group.
  3. Select the Edit button on the Group Members tab.
  4. Add the users from the Collection slush bucket to the Group Members List slush bucket.
  5. Select Save.
