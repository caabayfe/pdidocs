Modify the HR case creation configuration

  1. Modify the Case Creation Configuration form.
    FieldDescription
    Page sizeUse this field to determine the maximum number of search results for each page break when using the Search for Employee form.
    Note: The default is 10. When there are more than 10 search results, the form divides the results in chunks of 10. It does not limit the search results to 10.
    Minimum input lengthThis field determines the minimum number of characters that can be entered in the Search for Employee form to return results.
    Employee SearchUse this tab to change the default search parameters when searching by employee.
    • Display table: This field cannot be edited. Search uses the HR Profile [sn_hr_core_profile] table when looking for an employee.
    • Limit users on search: Check to add filter conditions to your search. For example, you can add a filter for only active users.
    • Additional display fields: Use to add fields that appear during a user search. The base system provides user department, user employee number, and user location when applicable.
    • Links: Enter a URL link.
    • User field: This field cannot be edited and used to determine what users to show for a search and show employee information.
    • Force partial search: Check so you can enter a partial name to return search results. This field works with the Minimum input length field. For example:
      • Minimum input length = 4
      • Force partial search = checked
        You can enter a partial name, but must enter at least four characters. When searching for Abraham Lincoln, you must enter Abra to return search results.
        Note: When you leave this field unchecked, you must enter the complete first or last name.
    Case SearchUse this tab to change the default search parameters when searching by case number.
    • Case table: This field cannot be edited. It shows the HR Case [sn_hr_core_case] table used for case search purposes.
    • Limit cases on search: Check to add filter conditions to your search. For example, you can add a filter for only active cases.
    • User fields: Use to add fields to appear during a case search. The base system provides subject person, opened for, opened by, and watch list when applicable.
    Employee InformationUse this tab to change what fields appear in the Employee Information section of the Case Creation form.
    • Left fields: Determines the fields that appear on the left side of the Employee Information section of the Case Creation form. The base system shows the user name and user employee number.
    • Right fields: Determines the fields that appear on the right side of the Employee Information section of the Case Creation form. The base system shows the user email and user zip or postal code.
    • Link: Select a link you want to appear on the Case Creation form.
    Case CreationUse this tab to change what fields appear on the Case Creation form.
    • Task create table: This field cannot be edited. It provides the HR Case [sn_hr_core_case] table used when an HR case is created.
    • Left task fields: Determines the fields that appear on the Case Creation form. The base system provides the COE and HR service fields and are non-configurable.
      Note: COE and HR services work with HR criteria to select the correct HR service for the subject person on the HR case. When a subject person is selected for an HR case, these fields determine the HR services available.
    • Right task fields: Determines the fields that appear on the right side of the Case Creation form. The base system shows the opened for and subject person.
    • Bottom task fields: Determines the fields that appear on the bottom of the Case Creation form. The base system shows Work notes.
    The Related Case Information section is not configurable from Case Creation Configuration. It appears at the bottom of the form after a case has been created.
  2. Click Update to save the changes.
