Installed RPA plugins

The Robotic Process Automation (RPA) plugins are a bundle of Windows library files that are used in the RPA Desktop Design Studio, Unattended Robot, and Attended Robot.

Overview

The installed RPA plugin version contains the details of the different versions that are available for installed RPA plugins.

The RPA plugins reduce your development efforts, error rates, and implementation time. These plugins extend the capability of the RPA product. For example, the RPA Chrome plugin enables the RPA application to automate tasks on the Google Chrome browser. Similarly, the RPA Excel plugin enables RPA applications to interact with Microsoft Excel files.

What you can do on this page

View a list of the available RPA Hub plugins, the plugin versions, and dependency packs to verify the availability of a specific version that you want to install and use on RPA Desktop Design Studio. Open a plugin to view more details such as the latest installed version, installation order, type of the installed RPA plugin, and so on.
