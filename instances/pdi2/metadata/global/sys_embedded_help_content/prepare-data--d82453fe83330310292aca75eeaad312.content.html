Prepare data

Prepare the data needed to import into the Configuration Management Database (CMDB).

Before you begin

Role required: ot_excel_import_user

Procedure

  1. Download the template from the Attachments panel of a new OT Excel Import Task record.
  2. Once data is populated in the template, upload the file using the + button on the Attachments panel.
  3. Import the uploaded file by clicking the Import Attachment UI Action.
  4. Once import is complete, the staging records show up in the Staging Records related list.
