Add VTB Lane action

Add a lane to a Freeform or Flexible VTB. This action does not apply to guided or data-driven boards, which can only have lanes from field values.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Board
Data type: Record

Reference to the VTB to update.

Lane Name
Data type: String

Name of lane to add.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Lane
Data type: Record

Reference to the VTB lane added.
