Alert-based remediations

Use the Alert Action Rules form to create new alert action rules and also to configure remediations to associate workflows with alerts for manual or automated remediation.
  1. To create a new alert action rule, click New.
  2. To configure remediations to associate workflows with alerts, Find the alert that you want to remediate.
    OptionDescription
    From the Event Management dashboardNavigate to Event Management > Dashboard. You have these options for selecting an alert:
    • Select an alert from the list at the bottom of the dashboard.
    • Click a business service tile and select an alert from the list at the bottom of the service map.
    • Click a technical service tile and select an alert from the technical service object list, or select an alert from the Alerts tab.
    From the Alerts Console
    1. Navigate to Event Management > Alerts Console.
    2. Select an alert from the list.
    • Right-click the alert, and select Run remediation.
    • In the Remediation options dialog box, select the remediation workflow that you want to apply and click Run.
