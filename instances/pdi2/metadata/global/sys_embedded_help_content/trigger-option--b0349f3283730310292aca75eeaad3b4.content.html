New schedule trigger option

Option to create a duration or meter-based scheduled maintenance.

Duration: Maintenance to be performed based on time. The following additional fields are displayed when you select Duration.
  • Trigger type: Trigger type determines the schedule run time interval duration(weekly, monthly, annual, and so on).
  • Minimum lead time in days: Number of days prior to the scheduled due date on which the work should begin.
Meter: Maintenance to be performed based on count. The following additional fields are displayed when you select Meter.
  • Table: Workplace Location or Model selected by default based on your selection of Model or Location while creating a maintenance plan.
  • Field: Field value for Trigger type.
  • Every: The number of occurrences that must be recorded before the maintenance plan is executed.
