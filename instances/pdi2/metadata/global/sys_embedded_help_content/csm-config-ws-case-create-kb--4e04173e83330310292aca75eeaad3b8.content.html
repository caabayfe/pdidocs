Create a knowledge article from a case

Reuse information from a customer service case by creating knowledge articles from customer service cases.

Before you begin

Role required: sn_customerservice_agent, sn_customerservice.consumer_agent

The system administrator must enable this feature before you can create knowledge articles from cases.

Procedure

  1. Select the more actions () icon at the top of the Case form.
  2. Select Create Knowledge Article.
    This creates a new knowledge article in a sub-tab. By default, the new article is created from the KCS Article template.
  3. Enter the name of the Knowledge base for this article.
  4. Optional: Edit the article.
  5. Select Save.
