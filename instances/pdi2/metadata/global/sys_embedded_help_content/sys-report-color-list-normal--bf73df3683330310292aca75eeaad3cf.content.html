Color Definitions

The Color Definitions list consists of all the colors that are defined for reports.

Click the column headers to search, sort, filter, and edit data.

Click New to create a new color definition.

The Color Definitions list has the following columns:
  • Name – Table used for the report.
    Note: The list shows only tables and database views that are in the same scope as the chart colors record.
  • Color – Hexadecimal value used to specify a color that is not defined in the Color Definition table.
  • Display – Shows a bar in the color defined by hexadecimal value indicated in the Color or Color name field.
  • Updated – The date and time the color was last modified.
