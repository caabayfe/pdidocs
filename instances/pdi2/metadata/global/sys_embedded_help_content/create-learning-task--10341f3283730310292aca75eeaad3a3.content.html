Creating a learning task

Create learning tasks for agents to keep track of their learning activities.

Before you begin

Role required: sn_wfo_cfg_itsm.manager

About this task

Set learning task completion due dates to include or exclude weekends using the exclude_weekends_on_learning_task_due_date system property.

Procedure

  1. In the Learning tab, go to Learning Tasks > All Tasks.
  2. Click New.
  3. Fill in the fields on the form.
  4. Click Save.
