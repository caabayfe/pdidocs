Create a mobile app theme

Role required: admin.

Use this form to create a new mobile theme, for a unique appearance that works with your company's identity.

  1. On the form, fill in the fields.
    Name
    Descriptive name for your theme.
    Palette

    Palette property names. The palette field consists of six properties. Each property has a name and a color value in hexadecimal format. Enter or modify the color values to change the color for your theme. For details on how to use these properties in your mobile applications, see the Mobile theme color guidelines.

  2. Click Submit.

Your theme is ready to use on your instance.

After configuring a mobile theme, you can apply the mobile theme to your mobile apps. For details, see Assign a theme to your mobile application.
