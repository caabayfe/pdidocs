MID Server properties

Use a MID Server property to control either the behavior of all MID Servers or a particular MID Server. You set MID Server properties to override MID Server parameters. If a property is not visible, you can add it to the table and set its values.
Note: Configure MID Server properties in the MID Server plugin. Do not configure MID Server properties in the glide.properties file that is located in the properties folder of the agent. This file is overwritten during the upgrade process.
