Disposal orders

Disposal orders is the list view of all disposal orders. Search and select the disposal order number to view the details. You can also export the list or create a hardware disposal order.

Disposal orders are created for an asset reaching its end of lifecycle or an asset that is no longer functional. The hardware disposal order goes through various stages before it’s completed. Each stage is related with a hardware disposal task. To move through the various stages, close each task until you reach the last stage. After you complete the last task, the hardware disposal order is complete.
