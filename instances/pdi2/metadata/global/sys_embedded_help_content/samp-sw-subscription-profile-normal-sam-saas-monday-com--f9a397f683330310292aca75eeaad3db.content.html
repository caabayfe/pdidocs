Creating a monday.com integration profile

Create an integration profile to connect your monday applications with the ServiceNow AI Platform. Use this integration to view software usage information and optimize stale licenses.

Important: Before you can save and publish the integration profile, you will need to create a monday OAuth2 application to authorize access to the monday.com API.

The integration profile uses the monday.com Download Subscriptions and monday.com Update User Activity subflows to retrieve user data from your monday applications. You can select the date and time that you want to analyze user activity from in the Analyze user activity from field on the Calculate Activity Subflow tab. You can start analyzing data from the current date or from up to 60 days prior.

To enable your monday application to connect with the ServiceNow AI Platform, you must configure the connection and credential information for the application using the connection & credential aliases record associated with your integration profile. To open this record, click the preview icon next to the Connection & Credential field and then click Open Record. When the record opens, click the Create New Connection & Credential related link and then enter the following information:
Name
Name of the connection. For example, Monday Connection.
Connection URL
Base URL for the monday.com API. This field is automatically set to https://api.monday.com/v2.
OAuth Client ID
Client ID that is assigned to your monday application.
OAuth Client Secret
Client secret that is assigned to your monday application.
OAuth Redirect URL
URL of the OAuth provider that users are redirected to after authentication. This field populates automatically.
