AI Search Genius Result Configurations

The AI Search Genius Result Configuration table contains records that each represent a Genius Result definition usable with AI Search. A single Genius Result configuration can be linked to multiple search profiles.

In the table list view you can rename Genius Result configurations, make them active or inactive, and change their trigger conditions and answer types. For more information on these settings, see the Genius Results documentation.

When the Now Assist for Search Store application is installed on your instance, you can use the Q&A - Now Assist for Search Genius Result configuration to provide summaries of Knowledge articles as answers for user searches. For more details on how this Genius Result configuration operates, see the Configuring Now Assist for Search documentation.
