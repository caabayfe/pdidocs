Configure OT vulnerability assignment rules

Roles required: admin or sn_vul.manage_assignment_rules

When you import vulnerable items, you can assign them to the appropriate group based on the Vulnerability Assignment Rules. One OT VR Assignment Rule is provided with the product. You can configure the OT VR Assignment Role based on your remediation strategy.

  1. Configure the OT VR Assignment Role based on your remediation strategy:
    • If your remediation strategy is to assign all OT vulnerable items to the site, set the execution order of the OT VR Assignment rule to be less than all other rules.
    • If your strategy is to assign by class and then assign to sites for all other classes, set the execution order of the OT VR Assignment Rule to be greater than all class-based rules.
  2. After you update the execution order, select the check box next to the Active field.
