Asset life cycle by state

View the list of assets grouped by state. You can also export the list to your preferred file type for downloading or emailing the list.

You can view the list of assets that are in the state Consumed, In use, In stock, On order, Retired, and Other. The assets that are in the state Maintenance and In transit are listed under Other.

You can select New to create a hardware, consumable, facility, bundle, or software license asset.
