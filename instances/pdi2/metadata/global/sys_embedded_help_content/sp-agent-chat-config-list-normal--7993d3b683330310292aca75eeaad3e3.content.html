Service Portal Agent Chat Configurations

Your end users can initiate and maintain an Agent Chat conversation in any portal page. You can write scripts to pass portal-specific data to Agent Chat. For example, pass the name of your knowledge base to a Virtual Agent conversation.

View the agent chat configurations for portals on the instance. You can access all agent chat configurations records from this list by selecting the name.

Public
Whether Agent Chat is available to users before they log in.
Portal(s)
The portals in which the chat configuration is used. If no portal is selected, the configuration applies to all portals in the system.
Order
A number that indicates in what order chat configurations should run. If there are multiple chat configurations on a portal, the system runs the first configuration found from lowest to highest.
