Assign a robot to an unattended bot process

Assign a robot to an unattended bot process to execute the automation (package) that is mapped to it.

Before you begin

Role required: sn_rpa_fdn.rpa_release_manager or sn_rpa_fdn.rpa_admin

About this task

You can assign robots with a life-cycle stage status of In Use to a bot process.

Make sure that the Enable Robot Pool option isn’t selected in the Robot Pool section of the Details tab of the bot process.

If the bot process has enabled the robot pool option, you can’t assign robots to it. The Assigned Robots tab is hidden. For more information about a robot pool, see Robot pool in RPA Hub.

To assign robots via a robot pool, enable the robot pool option on the bot process form. For more information, see Enable robot pool for a bot process in RPA Hub.

Procedure

  1. On the Assigned Robots tab, select Add.
  2. On the Available Robots tab, select the robot that you want to assign to an unattended bot process.
  3. Select Add.
  4. Select Save.
