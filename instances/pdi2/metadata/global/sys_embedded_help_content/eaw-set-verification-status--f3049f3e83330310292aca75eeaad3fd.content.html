Technology Portfolio Audit: Update verification status

Set the verification status of a software product or hardware model to confirm or reject the applied heuristics.

Before you begin

Role required: sn_apm.apm_analyst

Procedure

  1. In the Needs Attention section, select the Technology Portfolio Audit tab.
  2. Select a product type (Software or Hardware) with a verification status of Need to verify.
  3. Set the Verification Status to either Verified or Rejected.
