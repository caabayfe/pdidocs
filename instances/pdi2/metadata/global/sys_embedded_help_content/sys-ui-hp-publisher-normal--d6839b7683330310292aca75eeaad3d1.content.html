Create an interactive filter

Interactive Filters allow you to filter all reports on a dashboard dynamically, without modifying the original reports. You can create Interactive Filters for multiple field types.

  1. In the Filter based on choice list, select a filter type.
  2. Configure the following fields if applicable.
    Some filter types do not require all fields. Each filter type has specific required information.
    NameDescription
    NameEnter a name for the filter.
    Look up nameEnter a lookup name for the filter. This name appears in the Add content menu for users adding a filter to a homepage or dashboard.
    DescriptionEnter a description of the filter.
    UI control typeSelect how the available filtering options for this filter appear on the homepage widget.
