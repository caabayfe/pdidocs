Create a script include

Create a script include to store JavaScript functions and classes for use by server scripts. Each script include defines either an object class or a function.

  1. On the form, fill in the fields.
    Name
    Defines the name of the script include. If you’re defining a class, the name must match the name of the class, prototype, and type. If you’re using a classless (on-demand) script include, the name must match the function name.
    Accessible from
    Sets which applications can access this script include. Script includes can be accessed either by any application or only from the current application scope.
    Client callable
    Makes the script include available to client scripts, list/report filters, reference qualifiers, or if specified as part of the URL. When selected, the Access Controls related list is available.
    Script
    Defines the server-side script to run when called from other scripts. The script must define a single JavaScript class or a global function. The class or function name must match the Name field.

    With Now Assist for code generation enabled, you can provide text or code prompts to return AI-generated code suggestions and create scripts quickly.

  2. Select Submit.
