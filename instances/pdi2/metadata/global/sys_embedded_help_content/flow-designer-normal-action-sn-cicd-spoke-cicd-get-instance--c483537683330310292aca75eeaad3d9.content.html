Get Instance Scan Results action

Returns instance scan execution results from a REST API call.
Important: A corresponding CICD connection and credential must be created and associated with the Instance URL input value.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Credential Alias
Data type: String

Connection and credential alias of type Credential. This alias must have a user with the sn_cicd.sys_ci_automation role.

Progress ID
Data type: String

System ID of the instance scan execution record.

Instance URL
Data type: String

URL of the instance on which you want to run the instance scan.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Status
Data type: String

The status of the action. The flow execution details page displays one of these values:

  • 0: Pending
  • 1: Running
  • 2: Successful
  • 3: Failed
  • 4: Cancelled
Error
Data type: String

Reason for the error, if an error occurred.

HTTP Status
Data type: String

HTTP status code of the response.

Status Label
Data type: String

Label of the status code that was returned, such as Pending or Running.

Status Message
Data type: String

Message with a summary of why the operation failed (if an error occurred). This value can be null.

Status Detail
Data type: String

Details on why the operation failed (if an error occurred). This value can be null.

Result URL
Data type: String

URL of the scan execution record, referencing the REST API.

Result ID
Data type: String

System ID of the instance scan result.

Source ID
Data type: String

System ID of the source record returned by the table API.

Source URL
Data type: String

Source record returned by the table API.

Progress ID
Data type: String

System ID of the execution tracker for the instance scan operation.

Progress URL
Data type: String

URL of the get progress REST endpoint that returns the progress of the scan.

Finding URL
Data type: String

URL pointing to the instance scan findings record for this scan.

Finding Label
Data type: String

Label of the record which stores the instance scan findings.
