Create a Change task

Change tasks provide a mechanism for the change owner to assign and manage the various tasks associated with a given change request.

Before you begin

Role required: itil, admin, or sn_change_write

Procedure

  1. Select the More actions icon (), and then select Create Change Task.
  2. Select the change task type, and click Create.
  3. On the form, fill in the fields.
  4. Optional: Add an attachment by clicking Browse and selecting the attachment.
  5. Select Save.
