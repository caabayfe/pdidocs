Reassign a work item from the Work Items tab

Reassign a work item from the Work Items tab to manage your work item more effectively. You can reassign a work item that is in the In Progress, Pending, Failed, or Success state.

Before you begin

Create a queue. For more information, see Create a queue in RPA Hub.

Role required: sn_rpa_fdn.rpa_developer, sn_rpa_fdn.rpa_business_user, sn_rpa_fdn.rpa_support_user, or sn_rpa_fdn.rpa_admin

About this task

There are two ways to perform this task. One way is from the Work Items tab. Another way is by selecting a work item and then reassigning it from the form header options.

Procedure

  1. On the Work Items tab, select one or more work items.
  2. In the form header, select Reassign.
  3. In the Remarks field, enter a comment for reassigning the work item.
  4. Select Reassign.
    The status of the work item changes to Pending.
