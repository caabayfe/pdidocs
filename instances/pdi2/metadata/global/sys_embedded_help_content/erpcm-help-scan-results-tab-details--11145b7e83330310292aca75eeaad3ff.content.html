ERP scan results tab in candidate details

View details on which tables were relevant to the candidate and the details of their latest scan on the ERP (Enterprise Resource Planning) system by selecting the ERP scan results tab in the details for a candidate.

ERP model
Relevant ERP model that the candidate uses, which is configured in Zero Copy Connector for ERP.

Select an ERP model to open the model in Zero Copy Connector for ERP.

Closest ERP model
The suggested closest matching ERP model that you can add the table to in Zero Copy Connector for ERP.

This column is helpful for custom tables, which aren't part of a standard ERP model and thus don't have a table listed in the ERP model column. Select an ERP model to open the model in Zero Copy Connector for ERP.

Technical cluster
The type of table of the ERP system.
ERP table name
Name of the table on the ERP system.
Table operation
Action that ERP-CM took on the scanned table: Create, Read, Update, or Delete.
Max number of rows (DB)
Maximum number of rows on the scanned table, which is useful for knowing candidate limitations.
