Identity providers list

Use the identity providers list to view the identity providers (IdPs) configured on your instance. These providers are used by the multi-provider SSO feature.

Name
Name of the identity provider
Active
Whether the identity provider is active
External logout redirect
URL to direct users to after logout
Single Sign-On Script
Script that executes during Single Sign-On
Default
Whether the identity provider is the default provider
Auto Redirect IdP
Whether users are automatically directed to the login page of the identity provider
