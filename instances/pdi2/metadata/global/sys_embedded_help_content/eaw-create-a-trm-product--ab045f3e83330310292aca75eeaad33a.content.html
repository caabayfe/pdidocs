Create a Technology Reference Model (TRM) product

Add a software product to the Technology Reference Model (TRM) library.

Before you begin

Role required: sn_apm.apm_analyst

Procedure

  1. Expand Technology Reference Model Products.
  2. Select All.
  3. Select New.
  4. On the form, fill in the fields.

    For field information, see Create new TRM product form.

  5. Select Save.
