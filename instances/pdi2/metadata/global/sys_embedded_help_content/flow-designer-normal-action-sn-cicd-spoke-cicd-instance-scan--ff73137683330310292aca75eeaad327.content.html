Instance Scan Execute Point Scan action

Starts a point instance scan on the specified instance that begins from the table and record provided. The action makes an internal REST API call that returns the instance scan progress results.
Note: You must create a corresponding CICD connection and credential, and then associate them with the Instance URL input value.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Credential Alias
Data type: String

Connection and credential alias of type Credential. This alias must have a user with the sn_cicd.sys_ci_automation role.

Target Table
Data type: String

Table name of the target record. The point scan starts scanning from this table.

Target Sys ID
Data type: String

System ID of the target record. The point scan starts scanning from this record.

Instance URL
Data type: String

URL of the instance on which you want to start the instance scan.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Status
Data type: String

The status of the action. The flow execution details page displays one of these values:

  • 0: Pending
  • 1: Running
  • 2: Successful
  • 3: Failed
  • 4: Cancelled
Error
Data type: String

Reason for the error, if an error occurred.

HTTP Status
Data type: String

HTTP status code of the response.

Status Label
Data type: String

Label of the status code that was returned, such as Pending or Running.

Status Message
Data type: String

Message with a summary of why the operation failed (if an error occurred). This value can be null.

Status Detail
Data type: String

Details on why the operation failed (if an error occurred). This value can be null.

Progress ID
Data type: String

System ID of the execution tracker for this request. Use this ID to track the progress of the request.

Progress URL
Data type: String

URL of the REST endpoint that returns the progress of the execution tracker for this request.
