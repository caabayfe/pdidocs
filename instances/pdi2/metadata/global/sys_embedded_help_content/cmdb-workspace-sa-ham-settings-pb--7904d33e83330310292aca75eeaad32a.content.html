Evaluate CMDB settings for HAM

Identify and evaluate settings including Hardware Asset Management (HAM) business rules, configuration item (CI) to asset field mappings, hardware model categories, and CMDB Data Manager policies that support synchronization and automation between hardware assets and CIs.

Before you begin

Role required: sn_cmdb_admin

Procedure

  1. Select a status tile to view Configuration Management Database (CMDB) settings by category.
  2. Evaluate each setting that requires attention and use the available actions to open the related configuration pages and make updates.
    Tip: Select Learn more next to a setting to open a related help topic in a new browser tab or window with additional details about that setting.
  3. To view any updated configuration status on the Settings tab, select the refresh icon.
