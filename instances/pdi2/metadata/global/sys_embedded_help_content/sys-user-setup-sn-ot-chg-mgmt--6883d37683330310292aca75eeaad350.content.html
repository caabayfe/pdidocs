Users and roles

Roles required: admin or user_admin

  1. Create any user records for any users that don’t already have an account in this instance.
  2. Then assign one of the following roles to individual users or user groups as needed:
    • OT Change Manager (sn_ot_change_manager): Can manage OT Change model records.
    • OT Change Admin (sn_ot_change_admin): Can create, view, delete, and edit OT Change records. Can configure categories and system properties.
    • OT Change Writer (sn_ot_change_write): Can create, view, and edit OT Change records.
    • OT Change Reader user (sn_ot_change_read): Can only view the OT Change records.
