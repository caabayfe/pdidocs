Cloud Analytics page

The Cloud Analytics page provides detailed insight into the data rendered in the Cloud Resources Explorer dashboard reports.

The following Cloud Resources Explorer dashboard reports are based on the Cloud Analytics [sn_disco_cd_analytics] table:
  • Configuration item classes
  • Configuration items by regions
  • Configuration items by service accounts
In addition, the Stale CIs > 30 days indicator is also based on the Cloud Analytics [sn_disco_cd_analytics] table.

Except the stale CI data, all the other CI-related data displayed in the Cloud Analytics page depends on the cloud resource filter applied in the Cloud Resources Explorer dashboard. You can select any referenced Configuration Item (CI) listed in this page to drill into it, and view its respective Configuration Management Database (CMDB) object.
