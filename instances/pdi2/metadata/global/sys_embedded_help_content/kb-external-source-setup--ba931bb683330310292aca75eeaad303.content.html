Create an external source and import content

  1. Complete the following fields.
    FieldDescription
    NameUnique name for the external source.
    Target Knowledge BaseKnowledge base in which you want to create articles for the external content.
    Connection AliasConnection alias to connect to the external source.

    Select an existing connection alias or click New to create a new connection alias.

    • Right-click the form header and click Save.
    • To set import parameters for the external content, click the Parameter related list.
      1. In the Name field, select the name of the parameter from the list.
      2. In the Value field, enter the desired value for the parameter.
    • To run an import job manually or set up a schedule to process the integrated external content, click the Handlers related list.
      1. Click Acquire and then Process to set a schedule to run the acquire and process content handlers.
    • In the Related Links section, click Run Scheduled Job.
    • To view all jobs scheduled and monitor the status, click Jobs.
