Service channels

A service channel is a means of assigning a specific type and scope work to agents. You can configure base system service channels to set the context and attributes that define work handled in the channel, or create your own custom service channel.

Advanced Work Assignment provides several service channels from which work items originate. These channels include Case, Incident, and Walk-up, to name a few. For each service channel, you can also set attributes such as agent capacity, work filters, and utilization.
