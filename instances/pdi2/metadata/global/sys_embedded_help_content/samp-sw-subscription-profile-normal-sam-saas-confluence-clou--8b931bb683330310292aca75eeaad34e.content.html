Creating a Confluence Cloud integration

Create an integration profile to connect your Confluence Cloud applications with the ServiceNow AI Platform. Use this integration to view software usage information and optimize stale licenses.

Important: Before you can save and publish the integration profile, you will need to create an OAuth 2.0 application to enable access to the Confluence Cloud API. You must also add the groups that have access to Confluence products in the Confluence Groups table on your ServiceNow instance.

The integration profile uses the Confluence Cloud Download Subscriptions, Confluence Cloud Update User Activity, and Confluence Cloud Reclaim Subscription subflows to retrieve user data from your Confluence Cloud applications. You can select the date and time that you want to analyze user activity from in the Analyze user activity from field on the Calculate Activity Subflow tab. You can start analyzing data from the current date or from up to 60 days prior.

To enable your Confluence Cloud application to connect with the ServiceNow AI Platform, you must configure the connection and credential information for the application using the connection & credential aliases record associated with your integration profile. To open this record, click the preview icon next to the Connection & Credential field and then click Open Record. When the record opens, click the Create New Connection & Credential related link and then enter the following information:
Name
Name of the connection. For example, Confluence Cloud Connection.
Site URL
URL of your Confluence Cloud site.
Note: This field appears only if you have requested and installed Software Asset Management - SaaS License Management Integrations version 6.0.0 or earlier.
Connection URL
API URL for Confluence Cloud. This field is automatically set to https://api.atlassian.com.
Note: This field appears only if you have requested and installed Software Asset Management - SaaS License Management Integrations version 7.0.0 or later.
OAuth Client ID
Client ID that is assigned to your Confluence Cloud OAuth 2.0 (3LO) application.
OAuth Client Secret
Client secret that is assigned to your Confluence Cloud OAuth 2.0 (3LO) application.
OAuth Redirect URL
URL of the OAuth provider that users are redirected to after authentication. This field populates automatically.
