Extraction table list columns

The ERP (Enterprise Resource Planning) extraction page lists the ETL (extract, transform, and load) processes in Zero Copy Connector for ERP that extract large amounts of data from the ERP system.

Extracted data is stored in Glide tables in the ServiceNow AI Platform.

Name
Name of the ERP extraction table.
Short description
Brief description of the ETL source.
Table transform map link
Link to the Glide table that the extracted ERP data is cached and stored in.

After you save the extraction table, when you select the link, the ServiceNow AI Platform table opens in a new browser tab.

ERP model
ERP model for the extraction table source, which must be configured for you to select.
