Monitor the performance of business applications

The run phase enables you to monitor critical key performance indicators (KPIs) and operational performance of business applications related to your solutions.

Run tab

The run phase enables you to monitor and track the business application work for your solutions.
  • Edit the start and end dates for the work effort.
  • View business application performance; drill down into each performance item to see its related records.
  • View the deployments breakdown for the solution.
