Normalization suggestion details

You can view details for a specific normalization suggestion record. Normalizations suggestion records are created for discovery models.

The normalization suggestion records are stored in the Normalization Suggestions [samp_normalization_suggestions] table.

You can accept or reject the normalization suggestion. Select Accept to make the suggested changes to the discovery model, or select Reject to keep the existing settings.
