Create user criteria for site users

Use user criteria to determine whether certain users can access equipment model entities for specific sites. After you create a user criteria record, you can assign it to a site to control who can read and edit equipment model entities. You can further assign OT roles to users or groups to allow access to OT devices assigned to those same sites.

You should create a user criteria record for read access and a user criteria record for edit access for each site as required. For more information, see Assign or remove equipment model site access for non-administrators.

Once you have created the user criteria records, you need to assign that user criteria to the site(s) for the relevant access (read or write). For more information, see:
  • Assign the user criteria for Can Edit access to a site
  • Assign the user criteria for Can Read access to a site
For example, create a Tucson Site - Can Edit user criteria record matching users who should edit equipment model entities for the Tucson Site.
Note: These same users will be able to view OT devices assigned to the Tucson Site if they are also assigned a cmdb_ot_viewer role. They will be able to edit OT devices assigned to the Tucson Site if they are also assigned a cmdb_ot_editor role
