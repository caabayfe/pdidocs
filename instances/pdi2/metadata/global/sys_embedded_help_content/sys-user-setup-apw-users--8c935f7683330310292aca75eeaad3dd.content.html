Assign APW admin and APW user roles

Role required: admin

  1. From the Roles related list, add the following roles to the user.
    sn_align_core.apw_admin
    • Can define the planning hierarchy in the workspace
    • Can configure the workspace integrations
    sn_align_core.apw_user

    Can create, update, and delete planning items and roadmaps.

    This role can be given to users such as portfolio or product managers, business unit leads and other planning personas.

  2. Click Update.
