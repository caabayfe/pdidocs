Create a report map

Create a map that can be used in a map hierarchy.
  1. Fill in the following fields:
    FieldDescription
    KeySpecify a unique key that links this map to other maps. For default maps, the key is the hc-key value. The key must be included in the geoJSON of the parent map.
    NameEnter a name for the map.
    LevelSpecify the level for this map in the map hierarchy.
    JSON definitionDefine the geoJSON for the map. You can download predefined maps from Highcharts, or use any map that follows geoJSON standards.
    ParentSelect a parent map for this map. Parent-child relationships define drill levels in a map hierarchy.
    ActiveClear this check box to make the map unavailable when creating map reports.
    Geographical mapIf your map is not geographical, clear this check box. For example, clear this check box for a floor map.
    • Right-click the form header and select Save.
    • Optional: To use conditions to filter the map data, click New in the Map conditions related list.
    • Click Update to save the map.
