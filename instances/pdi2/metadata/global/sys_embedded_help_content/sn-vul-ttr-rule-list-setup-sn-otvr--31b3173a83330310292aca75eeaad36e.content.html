Set OT remediation target tools

This task requires either admin or sn_vul.manage_remediation_target_rules role.

OT Remediation Targets may be different due to the infrequent opportunities to perform maintenance in an industrial environment. Remediation Target rules are applied in order from smallest target to largest target. Two demo data records are provided to demonstrate how this can be managed for various risk ratings:
OT Critical Risk Rating rule
This rule uses the condition of Configuration item.OT device details is not empty AND Risk rating = 1 - Critical. Update the Target (days) and activate the record.
Non-OT Critical Risk Rating rule
In order to apply a shorter target to Critical Risk non-OT items only, you need to first filter out the OT devices. This rule uses the condition Configuration item.OT device details is empty AND Risk rating = 1 - Critical. Update the Target (days), inactivate any existing critical target rule, and activate this rule in its place.
