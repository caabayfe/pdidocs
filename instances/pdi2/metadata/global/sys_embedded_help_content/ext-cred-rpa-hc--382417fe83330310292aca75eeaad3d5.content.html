External credential vault in RPA Hub

With the external credential vault feature, you can retrieve robot credentials, application credentials, or TOTP seed.

What you can do on this page

Create an external credential vault record by selecting New. For more information, see Create an external credential vault record in RPA Hub.

Important Information

To configure the external credential vault in RPA Hub, see Steps to configure an external credential vault in RPA Hub.

You must configure the external credential settings appropriately, so that the data is not stored or logged in the ServiceNow instance.

Ensure that the value of the Reporting field is set to Off for the subflow of your external credential vault, for example, Demo CyberArk Subflow. This setting ensures that the sensitive data is neither captured nor logged. For more information about configuring this setting, see Activate flow reporting.
