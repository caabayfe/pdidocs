Consumer replication sets

The consumer replication set defines the tables and columns on a consumer instance that receive the producer data. IDR replicates data from the producer to the tables and table columns of the same name on the consumer instance.

Name
The name of your consumer replication set.
Description
The description of your consumer replication set.
Producer ID
The unique ID of the producer replication set.
Producer Name
The matching name of the producer replication set.
