Process jobs

A process job represents the execution of a bot process by a robot.

What you can do on this page

Open a process job to view more details about it, such as what the State field is set to and what the Triggered By field shows as the source of the trigger.

The State field can be set to one of the following states:
  • Success
  • Failed
  • Running
  • Skipped
  • Canceled
  • Abandoned
The Triggered By field can be one of the following sources:
  • Schedule: If the automation is triggered via a schedule.
  • API: If the automation is triggered by a flow.
  • Manual: If the attended automation is triggered by a user or if the unattended automation is triggered by Start Process button.
  • Embedded Task Automation: If the attended automation is triggered from the ServiceNow form.
