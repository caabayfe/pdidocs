Agent Assist contextual search settings

Contextual search helps agents deflect or quickly resolve issues without navigating away from a record. Contextual search can also include results from other sources such as a knowledge article or service catalog, allowing an agent to directly order a catalog item from a search.

To define a contextual search, first define a search context to set parameters, then define where the contextual search results appear: in forms, record producers, and wizards.

For contextual search in Agent Workspace, you must select the Workspace UI type.

Select a predefined search context that defines which forms use that search.
