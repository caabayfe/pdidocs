Restore normal importance to an alert metric

Return normal significance to the metric involved in generating a Log Analytics alert. For example, do this if you no longer want a muted alert to be treated specially.

Before you begin

Role required: evt_mgmt_operator or evt_mgmt_admin

Procedure

  1. While viewing the alert in the Service Operations Workspace, select Restore ML feedback.
  2. Confirm the action in the dialog box.

Result

The metric that is associated with the alert returns to normal importance.
