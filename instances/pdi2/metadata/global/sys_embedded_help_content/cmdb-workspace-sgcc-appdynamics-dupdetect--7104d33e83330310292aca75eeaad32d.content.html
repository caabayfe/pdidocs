Configure duplicate detection rules for AppDynamics data

Configure duplicate detection rules for the AppDynamics data being imported into the Configuration Management Database (CMDB).

Before you begin

Role required: admin

Procedure

  1. In the Duplicate detection rules list, select the rule from the Name column.
  2. On the Edit duplicate detection rule window, select the Active check box to activate the rule.
    Note: To remove fields from being evaluated, add the field names in the Ignore Fields field for a rule. To ignore multiple fields, separate the fields with commas.
  3. Select Save.
  4. Repeat steps from 1 to 3 for each rule you want to activate.
