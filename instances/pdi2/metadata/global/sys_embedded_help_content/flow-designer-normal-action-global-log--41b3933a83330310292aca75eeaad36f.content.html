Log action

Adds a log message as a record in the Flow Engine Log Entries [sys_flow_log] table.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Level
Data type: Choice

Choose from these options:

  • Info: Log message is informational only.
  • Warning Log message contains warning information.
  • Error: Log message contains error information.
Log message
Data type: String

Body of the log message. Enter text or add data pills to this input.

Outputs

This action has no outputs.
