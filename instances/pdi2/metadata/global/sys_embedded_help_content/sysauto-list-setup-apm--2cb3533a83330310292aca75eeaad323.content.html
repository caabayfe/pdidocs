Scheduled Jobs

As a system administrator you must run the scheduled jobs from global scope. The base system offers different combinations of CIs related by various CMDB CI relationships rendered as eight APM reports that are displayed as bar charts.

Note: To run query on Projects on a Business Application, you must activate PPM Standard plugin.

To modify the frequency at which the job is to be executed, click the scheduled job.

To run the scheduled jobs for all the CMDB queries provided by the base system, click each scheduled job and execute.
