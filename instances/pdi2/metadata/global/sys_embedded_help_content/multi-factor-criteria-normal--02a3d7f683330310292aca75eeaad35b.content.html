Multi-factor criteria form

Use the Multi-factor criteria list to view multi-factor criteria configured on your instance. Multi-factor criteria to determine which users and roles must use two-step multi-factor verification.

Use the form to view details on the criteria. For roles based criteria, administrators can use the form to add or remove roles. Follow the guides at the links below for details on creating new multi-factor criteria.
