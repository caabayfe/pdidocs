Status tab

The Status tab displays additional information about the selected discovery run.

The Status tab displays the following information for the selected schedule:

  • Details of the schedule.
  • Discovery log: The Discovery log tab displays the activity that takes place during a discovery. Use the logs to debug failed discoveries.
  • Devices: The Devices list provides a summary list of all the devices scanned during the selected discovery run.
  • ECC queue: The ECC queue tab lists the records created during all stages of discovery. Each record is a message. A messages from the instance and another system are classified as Outputs. Whereas, a message from the external system to the instance is classified as Input. External Communication Channel (ECC) queue records provide you with a connected flow of probe and sensor activity, as well as the actual XML payload that is sent to or from an instance.
  • Errors: The Errors tab lists the discovery errors occurred during the selected discovery run.
