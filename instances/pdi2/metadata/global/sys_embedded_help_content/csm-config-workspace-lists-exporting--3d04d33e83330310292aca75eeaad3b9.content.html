Export a list

Select a filtered list in the List view and export the records to a selected file type.

  1. Select Export at the top of a list.
  2. In the Export pop-up window, select the File Type and the Delivery Type. When exporting data as a PDF, you can also select the Orientation.
  3. Select Export.

    The system generates the data in the selected file type and downloads the file or sends it to you in an email.
