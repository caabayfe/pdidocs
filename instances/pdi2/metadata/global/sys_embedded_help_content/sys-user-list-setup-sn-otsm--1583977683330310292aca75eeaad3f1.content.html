Users and roles

Roles required: admin

  1. Create any user records for any users that don’t already have an account in this instance.
  2. Assign roles to individual users  or user groups as needed:
    • Equipment Model Viewer (cmdb_ot_isa_viewer): Can view assigned ISA Equipment Model records (cmdb_ci_ot_isa_entity) and view associated Equipment Model Template records (isa_entity_template, isa_entity_level, isa_entity_type)
    • Equipment Model Editor (cmdb_ot_isa_editor): Can edit assigned ISA Equipment Model records (cmdb_ci_ot_isa_entity) and view associated Equipment Model Template records (isa_entity_template, isa_entity_level, isa_entity_type)
    • Equipment Model Admin (cmdb_ot_isa_admin): Inherits cmdb_ot_isa_editor and can edit Equipment Model Template tables (isa_entity_template, isa_entity_level, isa_entity_type)
    • Equipment Model Downtime Planner (sn_isa_schedule_admin): Can create, modify, and delete equipment entity schedules. Can also associate schedules with equipment entities.
