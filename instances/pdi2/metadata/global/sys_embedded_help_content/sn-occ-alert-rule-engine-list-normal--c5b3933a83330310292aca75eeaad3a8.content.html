Advanced alert filtering

You can control the system’s processing of certain alert metrics with feedback options, such as muting a metric. In addition, you can provide more complex feedback to the AI engine using advanced filtering. This capability lets you fine-tune alerts and achieve more robust noise reduction. Advanced Filtering uses a JavaScript engine to scan the different fields of the alert. When the specified condition is matched, the AI engine enables or discards the alert. For example, you can tell the system to do any of the following:
  • Alert only on anomalies that are shared across multiple hosts
  • Not alert on anomalies happening outside of working hours
  • Not generate an alert if the anomaly amplitude does not cross a certain threshold
  • Alert only on anomalies that are part of a correlation
Define custom filters or use a predefined advanced filtering template.
