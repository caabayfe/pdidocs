Validate records

Validate the imported staging records.

Before you begin

Role required: ot_excel_import_user

Procedure

  1. Upon successful import, click the Validate UI Action on the OT Excel Import Task record.
  2. Once validation is completed, navigate to the Staging Records related list to check the validation state of the staging records.
  3. Click the Create Remediation Tasks UI Action to create a Remediation Task for the invalid records.
    Note that a single Remediation Task is created for all invalid staging records belonging to the same site.
