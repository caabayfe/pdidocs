Create a case from a chat

Accepting a chat opens an interaction record that captures the work done during the chat session. You can create a case from the interaction if you need to continue working with a customer to resolve an issue.

Before you begin

Role required: sn_customerservice_agent, sn_customerservice.consumer_agent

Procedure

  1. Add information about the customer and issue to the interaction record and click Save.
  2. Click Create Case on the interaction record to open a case and transfer the information from the interaction to the case record.
    The case is automatically assigned to you.
  3. Fill in any additional details and save the case.
    Now you can work on the case or assign it to another agent.
