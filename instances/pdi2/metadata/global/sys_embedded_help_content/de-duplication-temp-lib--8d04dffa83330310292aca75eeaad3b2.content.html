De-duplication template library

Create de-duplication template libraries in CMDB Workspace to organize the templates. The structure helps you remediate de-duplication tasks by class in batches and in a consistent manner.

De-duplication templates

A de-duplication template enables a single action to apply a consistent remediation to multiple similar de-duplication tasks. A template contains the configurations needed to remediate tasks for a class. The configurations can include settings such as the main CI, the method to use to consolidate attributes, and what to do with duplicate CIs after remediation. A template also contains conditions that tasks are matched on. When you run a template, the remediation settings in the template are applied to all tasks that match the template conditions.

Organize your templates into libraries to group templates by categories that are meaningful in your organization and to help locate a template. For example, you can create multiple templates for the same CMDB class, such as cmdb_ci_win_server. Then, add all those templates to the 'De-duplication templates for cmdb_ci_win_server' library for easy access.

From the De-duplication template library, you can:
  • Select View de-duplication dashboard.
  • Select Create a template.
From the library list category, you can:
  • Select a library in the Library prompt to filter for templates in the specified library.
  • Enter a search term in Search to find all templates and libraries with the search string.
  • Select Create a library.
You can also select the context menu for a library and then:
  • Select Edit library.
  • Select Delete library. You must unpublish and then retire all templates in the library before you can delete the library.
When you select a template:
  • Select Publish to make a template available for remediating assigned tasks. The template can't already be published.
  • Select Unpublish to make a template temporarily unavailable for use remediating assigned tasks. Only published templates can be unpublished.
  • Select Edit. You cannot edit a published template.
You can also select the context menu for a template and then:
  • Select Edit template.
  • Select Retire to remove an unpublished template from use.

Create a new library

To create a library, specify name and description.
