Upload data

An import set acts as a staging table to store raw data from an external source.

  1. Under Import set table, choose to create a new table or to use an existing one to import the data.
    • Select Create table and enter a Label for the new table.
    • Select Existing table and select a table in Import set table.
  2. Under Source of the import, choose the source for importing the data.
    • Select File and specify the File, Sheet number, and Header row number.
    • Select Data source and select a data source connection in Data source.
  3. Click Submit.
