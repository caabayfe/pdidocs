Using data in a flow

Use data pills and transform functions to provide dynamic data to your flow. Data pill values populate when your flow runs.

Using dynamic data makes your flows reusable in multiple situations and use cases.

  1. On the Flow Designer homepage, select + New > Flow.
  2. On the Flow properties screen, give your flow a name.
    All other fields are optional. So, when you're ready to start building your flow, click Submit.
  3. In your flow, under Trigger, select Select to add a Trigger.
  4. In the trigger picker, search for and select any trigger to add to your flow.
  5. Fill in any required fields for your trigger, and click Done.
  6. Under Actions, select Select to add an Action, Flow Logic, or Subflow.
  7. From the list of options, select Action to open the action picker.
  8. In the action picker's search window, enter the name of the action that you want to add to your flow.
    Alternatively, you can browse for actions by spoke or application scope. Select a spoke name and then locate the associated action that you want to add to your flow.
  9. Use the action picker to add an action or flow logic to your flow.
  10. Set the inputs for the action or flow logic.
    Inputs support static and dynamic values. A static value is one that you directly enter. An input with a static value always uses the value you enter. A dynamic value is a reference to a data pill. An input with a dynamic value gets generated each time the action runs. To add a data pill to an input, select it from the data pill picker icon, or drag it from the Data panel.
    For example, suppose that your flow has a Record Created trigger. You can use this record as your action's input.
    1. Expand a data pill to see its data structure.
      Record data pills display their underlying table structure. Object data pills display their underlying object structure. You can select any node in the structure as your input data.
    2. Combine static and dynamic data within a single input.
      Some inputs support a combination of text and one or more data pills.
      For example, suppose that you want an email message to display a record number. You can enter Record Number: in a String input and then add a Number data pill to the same input. The action output generates both the static text and the dynamic record number.
  11. Add transform functions to clean up dynamic data.
    To apply a transform function to a data pill, point to or hover over the pill and select the function, or f(x), icon. From the list of available transforms, select a transform function to apply to your pill. Fill in any required fields for the transform function and click Done.
    For example, use the First Character transform function to return only the first alphanumeric character of a String data pill.

You're ready to test your flow for any errors. Review your flow's execution details to see its configuration and runtime values.
