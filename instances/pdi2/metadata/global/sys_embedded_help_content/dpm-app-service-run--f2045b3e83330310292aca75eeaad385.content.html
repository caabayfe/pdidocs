Monitor performance of application services

Application services offer the Run and Info tabs of the operations life cycle. The run phase enables you to monitor the service and operational performance of your application services.

Run tab

The run phase enables you to monitor and track the application service for your solutions.
  • View and modify the application service start and end dates.
  • Select each card to view service performance information, including trend charts and associated records.
  • View reliability indicator information. Select View all to see all reliability indicators.
  • View offerings that depend on the application service. Drill into each offering to view its life-cycle information.
  • View technology risk status for software and hardware models. Select a model to see its details, product life cycles, and vendor catalog items.
