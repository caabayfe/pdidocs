Configure response option for your DLP incidents

Role required:
  • sn_dlir.admin - Create, edit, and delete.
  • sn_dlir.analyst - View (read-only).

You can use response option to configure the type of response that an end user should perform. For the advanced type of response, you can configure the MID Server Application and MID Server Capability if the flow requires that support.

  1. To create an Incident Response Option, click New.
  2. On the form, fill in the fields.
  3. Click Submit.
