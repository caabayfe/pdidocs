Identification Rule

Role required: itil for reading, and itil_admin (on top of itil) for full access

Identification rules are used to uniquely identify CIs in the CMDB, as part of Identification and Reconciliation (IRE) processes. Each CMDB class can be associated with a single identification rule.

Narrow the scope of CIs that are included in the identification process by creating an identification inclusion rule. During duplication detection of independent CIs, the identification and reconciliation engine (IRE) processes only the CIs that satisfy the identification inclusion rules.

  1. Select Edit, Add, or Replace (for a class that has derived the CI identification rule), in the Identification Rule section to create one.
  2. In the Identifier Entries section, select an existing identifier entry to edit, or select Add to create one.
  3. Create or edit a rule and specify its criteria.
    1. In the Inclusion Rule (Advanced) section, select Add to create a rule or select Edit to edit an existing rule.
    2. In the Create Inclusion Rules dialog box, specify a criteria in the Active record condition field.
      CIs must meet this criteria to be included in the identification process and in the duplicate CMDB Health metric.
  4. Select Save.
