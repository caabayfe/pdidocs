Filter elements

Filter lists and data visualizations on a dashboard by possible data value, by whether the value is true or false, or by date.

Add a filter element in the dashboard in-line editor. Outside of editing mode, a user selects one or more filter values depending on how the filter is configured. The filter applies to the data visualizations and list components on the tab that contain a target of the filter.

You can add an existing filter from the filter library, or create a new filter. When you create a filter, you can add it to the library if you have the analytics_filter_admin role. This role also lets you delete or configure any filter. All users can configure and delete filters that they create. All these actions are in the More actions menu on the filter element.

On dashboards created in the in-line editor, filters retain their values across logins or page refreshes. However, these values are no longer retained when someone edits the filter configuration. Afterwards, the filter reverts to its default values for all users on their next login or page refresh.

When you create a filter, you first specify the filter type. All further configuration options depend on the selected type. Select from the following filter types:

  • Single select: A single value from a set of choices
  • Multiple select: More than one value from a set of choices, such as both High and Critical Priority
  • Date: A calendar date. You have the option to set a time. Automatically applies to all indicator data on page or tab, and optionally can apply to date fields on tables.
  • True/False: Whether a field value is true or false
Note: Single and multiple select filters can follow other filters of the same type in a cascade of filters. The analytics-filter-admin role is required to set up cascading filters. For filters to follow another filter, the filters must all target a field on the same table.
