Configure MID Server distributed cluster

  1. Fill out the MID Server Cluster form.
    FieldDescription
    NameName of the cluster.
    TypeCluster type which must be set to Distributed.
  2. Right-click the form banner and select Save.
  3. In the Includes MID Servers related list, click Edit to add MID Server to the cluster.
  4. Select the MID Servers configured for Metric Intelligence and select the right arrow button to move them to the right cell.
  5. On the MID Server Cluster form, click Update.
    Note: The Operational Intelligence MID Servers do not join the distributed cluster until you configure the Operational Intelligence extension, which is the next step.
