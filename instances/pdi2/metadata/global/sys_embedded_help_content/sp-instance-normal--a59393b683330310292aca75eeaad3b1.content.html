Create a widget instance

Create an instance of a widget to add to a page. A widget instance is a reference to a widget that contains a location, properties, and CSS specific to that instance. You can also create widget instances using the Widget Editor or Page Designer.

  1. On the form, enter a title for the widget instance.
  2. On the Widget tab, select the widget to use for the widget instance.
  3. Select Submit.

Add the widget instance to a portal page.
