Creating a Webex Meetings integration profile

Create an integration profile to connect your Webex Meetings subscription to the NOW platform. View software usage information and optimize stale licenses.

Set up the integration

Important: Before you can create the integration profile, you will need to create an OAuth integration application in Cisco DevNet.

Give the integration profile a name and choose a value for the Analyze user activity from field in the Calculate Activity Subflow form section. You can choose to start analyzing data from the current date or from up to 60 days in the past. Save the integration profile.

Update Connection and Credential Information

Open the Connection & Credential alias record by clicking the preview icon and then clicking Open Record. Click the Create New Connection & Credential related link. On the form, fill in the fields.
  • Connection URL - https://site.webex.com/WBXService/XMLService, where site is the name of your Webex site.
  • OAuth Client ID - Client ID you created in Cisco DevNet.
  • OAuth Client Secret - Client secret you created in Cisco DevNet.
  • OAuth Redirect URL - https://instance.service-now.com/oauth_redirect.do, where instance is the name of your ServiceNow instance.
  • Email address - Email address for an admin user on your Webex account.
After updating the connection and credential information, return to the integration profile.

Publish the integration profile

To start using the integration, click Publish.
