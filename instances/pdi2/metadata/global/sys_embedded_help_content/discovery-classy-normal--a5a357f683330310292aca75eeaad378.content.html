Create a Discovery classification

A CI classification allows Discovery to discover most common operating systems, network devices, and processes.
  1. Select the type of classification to create.
  2. Click New in the list of classifications for the type you selected.
  3. Select a CI table for your classifier.
    The fields that appear depend on the table selected.
  4. Complete the fields in the form.
  5. Click Submit.
