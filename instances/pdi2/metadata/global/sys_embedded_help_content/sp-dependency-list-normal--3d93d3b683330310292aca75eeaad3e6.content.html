Widget Dependencies

A widget dependency is an external resource used by your widget, such as JavaScript or CSS files. View the widget dependencies configured on the instance, any associated Angular modules, and whether the dependency loads on the initial page load. You can access all widget dependency records from this list by selecting the name.

Angular module name
An Angular module that provides JavaScript for the dependency.
Include on page load
Whether the dependency loads onto the page on the initial page load of a portal or only when the widget is loaded onto a page.
Portals for page load (optional)
The portals that include the dependency on page load.
