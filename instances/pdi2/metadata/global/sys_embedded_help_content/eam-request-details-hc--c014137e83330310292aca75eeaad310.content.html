Request details

View details of the request created in the Service Catalog application.

You can also view additional information such as requested items, approvers, group approvals, purchase orders, transfer orders, assigned licenses and catalog tasks.

You can also cancel, copy, and delete a request.

Select Cancel Request to cancel a request. Once the request is canceled, the request state changes to Closed Cancelled.

To delete a request, select the ellipsis located on the right hand side of the page and then select Delete. A confirmation message appears. Select Delete to proceed.
