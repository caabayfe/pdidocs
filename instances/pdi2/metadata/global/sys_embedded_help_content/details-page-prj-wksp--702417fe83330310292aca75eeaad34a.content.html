Details page

Use this page to view and manage details of your projects. Analyse project tasks, sub projects, resource plans and others in a central location.

On the details page, you can perform any of the actions:
  • View, update, and manage project information.
  • Track activity of your project and facilitate conversation between different stakeholders.
  • View and update project tasks, sub-projects, stories, resource plans and others using related tabs.
  • View related lists for a project on the details page to manage the project tasks, sub-projects, stories, resource plans and others.

For more information on details page, see Project Workspace.
