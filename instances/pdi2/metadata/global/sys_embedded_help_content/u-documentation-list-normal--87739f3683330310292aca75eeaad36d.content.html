Create a documentation request

Documentation (DOC) requests help you track your work. Create a DOC request for any documentation work you are doing.

Source

From the Sources list, select where the request came from. For example, if the request is related to an incident or story. Other possible sources include:
Enhancement Request
Source for work to enhance existing documentation.
Internal Initiative/Project
Source for initiatives or projects that don't relate to work on the documentation site.
Product Release
Source for documentation work that you do as part of a product release, if a story doesn't already exist for the work.

Type

From the Type list, select the type of documentation work that you are doing for this request.

Do not use these types because they are deprecated:
  • Positive vs. negative feedback
  • Rating 0-5
