Tags

Tags are text labels that you can associate with items like records and pages, which enables you to group and organize the items.

The Tags list shows the tags in your instance. Navigate to My Tags to see a list of the tags you own.
  • Click the column headers to sort, filter, and edit data.
  • Click the name to view and edit the tag details.
  • Select any row(s) and choose an action in the Actions on selected rows drop-down list to update the tag(s).

    You can merge tags using this feature.

  • Click New to create a new tag.

The Tags list includes the following significant columns:

Active
Specifies whether the tag is enabled.
Global
Indicates whether the tag is viewable to all users. Tags can be visible to any user (global), only to specific groups or users (shared), or to a single user (private).
Home page
Indicates whether the tag is visited from the home page.
Max entries
Determines the maximum number of items displayed for the label.
Navigation
Indicates whether the label is wanted on the navigation pane.
Order
Determines the order to appear in the Navigator.
