Configure the allocation status in Subscription Management

Identify when you're close to allocating all of your subscriptions by configuring an allocation status threshold if you prefer a threshold other than the default value of 90 percent.

Before you begin

Role required: usage_admin or admin

Procedure

  1. In Subscription Management, select the Settings tab.
  2. Enter a percentage value that represents near capacity for your instance.
    If you want the Status column to display Near capacity before reaching the 90 percent threshold, enter a lower percentage value.
  3. Select Save.

Result

When the number of allocated subscriptions exceeds the percentage you configured, the value Near capacity appears in the Status column.
