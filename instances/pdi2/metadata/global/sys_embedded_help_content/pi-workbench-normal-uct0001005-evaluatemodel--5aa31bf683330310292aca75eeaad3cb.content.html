Predict Service model evaluation and tuning

Determine the quality of your existing models and use your expertise to set values that deliver peak performance to your organization.

Balance tradeoffs, based on how much work can be automatically handled by machine learning for each service, while still delivering high quality predictions.

When considering the threshold of excellence for a machine learning process, compare its performance with the accuracy of routing incidents in your current processes based on human interactions.

Glossary

Net automation:
The percentage of incidents managed by machine learning that will be correctly predicted.
Precision:
The percentage likelihood that a machine learning prediction is accurate.
Coverage:
The percentage of your business that machine learning will impact.
Tuning:
Changing precision and coverage values to achieve the desired balance.

What to do next

Next, you'll prepare a test data set for the services you want the machine learning model deployed for. The data set will include a variety of incidents you typically see coming into your production environment. You may then test your model(s) using this familiar data set, by triggering predictions and comparing them against the actual service they have been routed to. For best results, use the data that is not used when training the model and is as close to production quality as possible.
