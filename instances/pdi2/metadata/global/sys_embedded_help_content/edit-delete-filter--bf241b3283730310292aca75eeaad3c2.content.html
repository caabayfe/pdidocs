Edit or delete a filter

Modify the condition in existing filters for the records to be filtered to view the summary of a different set of records. You can also delete these filters.

Procedure

  1. Select the Gear icon.
  2. On the Saved Filters modal, select Use existing filters and fill in the fields and select Update.
  3. To delete a filter, select Delete.
