Create a retention policy schedule

Create a retention policy schedule to specify how long MetricBase stores the time-series data in the MetricBase database. Retention policies include multiple retention schedules with coarser granularity the longer that the data is kept.

  1. On the form, fill in the fields.
    Description
    Enter a description for the schedule.
    Sampling period
    Define the length of the sampling period.
    Retention duration
    Define how long data is retained.
  2. Click Submit.

Select the schedule in a retention policy.
