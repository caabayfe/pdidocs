Create a field

Create fields as part of your DocIntel use case.

For an improved DocIntel setup, configuration, and monitoring experience, install the Document Intelligence Admin application.

  1. On the Field form, fill in the fields.
    Display Name
    Name of the field
    Use Case
    Use case associated with the field
    Field Group
    [Data extraction uses cases only] Field group associated with the field
    Type
    Type of field (for example, text or check box)
    Mandatory
    [Data extraction uses cases only] Option to indicate whether the field is required
    Target Field
    Field on the target table you want to align with this field
  2. Submit the field.
