Manage campaign bundles for a campaign

FieldDescription
Trigger typeHow the campaign bundle starts.
  • Immediate: The campaign bundle triggers immediately after the campaign is published and within the start and end date/time of the campaign.
    • Specify duration: When checked, indicates the number of days, hours, minutes, or seconds the content is available.
  • Fixed date: The campaign bundle triggers according to a specific start and end date/time and within the start and end date/time of the campaign.
  • Relative date: The campaign bundle triggers based on a trigger table (sn_hr_core_profile or sys_user), trigger field, and date offsets.
    • Specify duration: When checked, indicates the number of days, hours, minutes, or seconds the content is available.
    • Trigger table: Table to provide the trigger field. (HR Profile requires HR Service Delivery to be licensed and activated.)
    • Trigger field: Field from the selected table you want the trigger to key on.
    • Date offset type: Indicates if the trigger date should be before or after what you select in the trigger field.
    • Date offset units: The unit of time (days, weeks, or months) the date offset type should trigger.
    • Date offset quantity: The number of date offset units the trigger date should occur.
    • For example, you want the bundle to trigger two weeks before an employee start date. Enter:
      • Trigger table: HR Profile.
      • Trigger field: Employment start date.
      • Date offset type: Before.
      • ß
      • Date offset units: Weeks.
      • Date offset quantity: 2.
  • Advanced: The campaign bundle triggers based on a script you define.
    Note: The campaign must be in the Published state to launch based in the start time. Scheduled jobs and properties affect when and how a campaign is launched.
Specify durationSpecifies the campaign bundle is active for a specific amount of time.
