Select Discovery Source(s)

Map OT devices for all discovery sources:

  • Yes - all OT devices will be considered for mapping (default)
  • No - only the discovery sources listed under **Map OT devices for specific discovery sources** will be considered for mapping

Map OT devices for specific discovery sources:

  • Enter a single name or a comma separated list of names appearing in the discovery_source field on the configuration item tables
  • Example: "ServiceNow,SG-OT Excel Import"

Note - if "Map OT devices for all discovery sources" is set to "No" and "Map OT devices for specific discovery sources" is blank, no OT devices will be mapped.
