Monitoring cases

The CSM/FSM Configurable Workspace landing page provides real-time data about important items, such as high priority cases, assigned cases and tasks, and performance metrics. Use this data to quickly scan your current workload and handle cases efficiently.

Important items

Components in this section display important case or task information. For example, High-priority cases includes P1 cases, escalated cases, and cases that need attention. Click the data in a component to display a filtered list of cases or case tasks.

Cases

This section includes two lists of active cases: those assigned to you and to your team. Highlighted fields in the lists help you quickly identify case priority and action status. Click a case number to open a case record.

Performance

Components in this section display performance analytics data. Select a component to display either a filtered list of records or a KPI details page.
