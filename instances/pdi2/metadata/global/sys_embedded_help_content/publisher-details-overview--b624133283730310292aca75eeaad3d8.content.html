Publisher details overview

View detailed compliance information for a specific publisher.

View a summary of the key metrics of the publisher such as true up cost, potential savings, actual savings, unlicensed entities, and progress indicators. The key metrics are specific to each publisher.

Drill down to a specific product, software model, or license metric using the navigation tree in the left hand side of the page.

In the navigation tree, select a product, software model, or license metric to view its results, removal candidates, entitlements, and remediation options which are based on the latest reconciliation results. For example, if you are on the Publisher details page for Microsoft, and you drill down to Office 365, you get to view related lists for Software Model Results, Removal Candidates, Entitlements, and Remediation options.
