Create a map marker icon

Role required: admin.

Use this form to create a map marker icon to add to your Map Page in the Classic Environment. Select a relative or absolute URL for a map marker icon to display a data item on the Map Page, and determine the map marker priority on the Map Page.

  1. On the form, fill in the fields.
    Name
    Input the name for your map marker icon.
    Level
    Select the marker priority on your Map Page. When multiple markers share coordinates, the lowest level marker is displayed.
    Application
    Select the application scope for your map marker icon, if other than Global.
    Single icon URL
    Input a relative or absolute link to an icon for a single data item from a map coordinate on your Map Page.
    Co-located icon URL
    Input a relative or absolute link to an icon for multiple data items from a map coordinate on your Map Page.
    Scripted condition
    Input optional scripting for map markers.
  2. Click Submit.
  3. Navigate to System Map Page > Map Markers.
  4. Select your map page marker.
  5. In the Map Marker Icons field, double-click the record and click the search icon.
  6. Select your map marker icon, then click the check mark icon.
  7. Click the menu icon and select Save.
