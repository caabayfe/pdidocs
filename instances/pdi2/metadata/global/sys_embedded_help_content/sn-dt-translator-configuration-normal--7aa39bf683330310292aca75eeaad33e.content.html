Create a Translator Configuration

Use this form to create a translator configuration, which dynamically translates user-entered text in your application.

  1. On the form, fill in the fields.
    Name
    Input an identifier for the configuration.
    Version
    Select the version for the configuration. v3 is the default.
    Active
    Click this check box to enable the configuration.
    Choose a translate subflow
    Select a subflow to handle language translation.
    Choose a detect subflow
    Select a subflow to handle language detection.
    Mark as default for translation
    Click this check box to set the translation subflow as the default.
    Mark as default for detection
    Click this check box to set the detection subflow as the default.
    Language code mappings
    Click the magnifying glass icon and select the language code mapping to associate with the translator configuration record.
    Note: Only languages for which the language code mapping was created are available for selection and you can select only one language code mapping per language.
  2. Click Submit.
