Create New Custom Enterprise Product Model

If you have a product model that is not represented in the Enterprise Asset Management Content Service yet, you can create a custom product model.

Before you begin

Role required: sn_eam.enterprise_admin

Procedure

  1. In the Create new Custom Enterprise Product Models page, fill in the details.
  2. Select Save.
    The product model is created and the Custom Enterprise Model Libraries related list appears. After the product model is created, normalize the product model.
