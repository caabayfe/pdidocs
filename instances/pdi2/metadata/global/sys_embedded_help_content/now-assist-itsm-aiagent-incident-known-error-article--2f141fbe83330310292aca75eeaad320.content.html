Incident known error article AI agent

Using Incident known error article AI agent, search for similar Known error (KE) articles if the resolution code is Known error. You can select any of the recommended and relevant KE which is then attached to the incident record and the incident is resolved.

Important: By default, all agentic workflow and AI agent records are read only.

To run the AI agents autonomously, you must first duplicate the agentic workflow, and then proceed with the following steps:

  • Activate the agentic workflow.
  • Activate all agents within the agentic workflow.
  • Activate the trigger to invoke the agentic workflow automatically. If you prefer to invoke it manually, activating the trigger isn’t necessary.
Important: In the Define availability screen for the AI agent, make sure that the Status field is enabled to activate the AI agent.

Using Incident known error article AI agent, search similar Known error (KE) articles if the resolution code is Known error. You can select any of the relevant recommended KE which is then attached to the incident record and the incident is resolved. In case, no relevant KE articles are available, you can enter any KE article which is then attached to the incident record.

In the Incident known error article AI agent screen, review all information and settings for the AI agent.
