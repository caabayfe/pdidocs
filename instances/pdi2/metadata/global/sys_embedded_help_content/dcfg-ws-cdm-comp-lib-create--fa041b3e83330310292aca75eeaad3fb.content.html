Create a component library

Create a component library to manage components that can be reused across multiple applications.

Before you begin

Role required: cdm_admin

Procedure

  1. On the tree view, click +Create new library.
  2. On the form, fill in the fields.
  3. Click Save to save the information.
  4. Click Edit to open a new or existing changeset to modify the config data in the library.
