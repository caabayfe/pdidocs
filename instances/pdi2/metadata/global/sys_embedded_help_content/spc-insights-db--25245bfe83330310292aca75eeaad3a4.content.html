Custom insights dashboard

You must create an insight record in the Custom insights builder module and activate it before your you can view your data on this dashboard.

  • Select a visualization on a card to view details about it.
  • You must create an insight record and activate it with an activated policy before you can view your data on this dashboard.
  • To create a custom insight, navigate to the Custom insights builder module and select New insight and review the help for that module.
