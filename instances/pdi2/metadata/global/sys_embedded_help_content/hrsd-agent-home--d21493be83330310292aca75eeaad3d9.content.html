HR Service Delivery Workspace

HR agents use the HR Service Delivery workspace to interact with employees' requests and resolve issues.

Start work in HR Service Delivery Workspace from one of these areas:
  • Landing page: The landing page shows high priority cases, cases at risk for violating service level agreements (SLA), and cases with recent changes.
  • List queue: Select to view a list of HR cases, interactions, HR tasks, and more. You can access the list icon from any screen.
  • Agent inbox: Shows any work items assigned to you. Indicate if you are:
    • Available
    • Offline
    • Away
    Note: Requires activation of the Advanced Work Assignment (com.glide.awa) and Agent Chat (com.glide.interaction.awa) plugins.
  • Analytics Center: Shows analytic data related to HR cases. Dashboards containing actionable data reports that help you improve your business processes and practices.
