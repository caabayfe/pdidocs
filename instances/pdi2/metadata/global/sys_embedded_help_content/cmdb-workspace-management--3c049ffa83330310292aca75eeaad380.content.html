Management view

View information about your Configuration Management Database (CMDB) such as health and recent activities. Access key management tools like CI Class Manager and CMDB Data Manager that you can use to manage your CMDB.

Drill into individual cards to see additional metrics such as trends, to view the list of associated records, and to view specific records.

CMDB Data Manager

The cards provide insight into CIs and policies associated with CMDB Data Manager:
Rejected CIs
Records that could not be attested and were therefore rejected. Records that are rejected and then archived or retired by CMDB life cycle states are also considered in this count. Queries the Configuration Item [cmdb_ci] table for records with an attestation status of Rejected.
Excluded CIs
Records that are explicitly excluded from evaluation by CMDB Data Manager. Queries the CMDB Policy CI Exclusion List [cmdb_policy_ci_exclusion_list] table.
Draft policies
Data manager policies that are currently in Draft status. Queries the CMDB Data Management Policy Runtime Attributes [cmdb_data_management_policy_runtime_attributes] table.

CI Correctness

Shows CIs with issues, such as duplicates, orphans, and stale CIs, as reported by CMDB Health within the time window you specify. You can specify up to one month, and can drill into each card.
Duplicate CI count
Duplicate CI records reported by CMDB Health. Checks the Duplicate Audit Result [duplicate_audit_result] table for results that also appear in the Configuration Item [cmdb_ci] table.
Orphan CI count
Orphan CIs reported by the CMDB Health orphan metric. Queries the CMDB Health Result [cmdb_health_result] table for active CIs with a status of Orphan.
Stale CI count
Stale CIs reported by the CMDB Health staleness metric. Queries the CMDB Health Result [cmdb_health_result] table for active CIs with a status of Staleness.

Recent CI activity

Tracks the number of new and updated CIs from the past week. Queries the Configuration Item [cmdb_ci] table and updates daily. The query filters for the following records:
  • Records created today for new CIs.
  • Records updated since yesterday for updated CIs.

Recent application services activity

Tracks application services from the past week as well as application service outages. The tile updates daily and sorts activity into the following groups:
  • Total application services.
  • New application services.
  • Updated application services.

Queries the Service Instance [cmdb_ci_service_auto] table for CIs in the Application Service class.

For application service outages, queries the Outage [cmdb_ci_outage] table for CIs with a Class of Application Service and a Type of Outage.
