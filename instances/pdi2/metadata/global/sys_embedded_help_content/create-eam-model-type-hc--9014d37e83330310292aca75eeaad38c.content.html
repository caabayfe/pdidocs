Create New Custom Enterprise Model Type

If you have an enterprise model type that isn't represented in the Enterprise Asset Management Content Service yet, you can create a custom model type.

Before you begin

Role required: sn_eam.enterprise_admin

Procedure

  1. On the Create new Custom Enterprise Model Type page, fill in the details.
  2. Select Save.
    The model type is created and the Custom Enterprise Product Models related list appears. After the model type is created, normalize the model type.
