Dashboards

You can view all company-certified dashboards you have rights to access on your instance. You can also see the dashboards that you have bookmarked.

Dashboard tiles

Dashboard tiles show the dashboard creator, a Certified badge if certified, and a Bookmark icon if bookmarked. You can apply the following filters to the tiles:
Bookmarked
See all dashboards that you have bookmarked. To bookmark a dashboard, select a dashboard to open it, then select Bookmark from the context menu ().
Certified
Dashboards that have been certified for use throughout your organization.

On the Your Analytics page, you can see only bookmarked or certified dashboard tiles.

Creating a new dashboard

The Create a dashboard button has two possible results, depending on your role:

  • If you have the admin or ui_builder_admin role, you are given the choice to create a dashboard in either the in-line editor or the technical editor. The in-line editor is a feature in the Platform Analytics experience where you can add a limited number of commonly used elements, such as data visualizations. It creates a Dashboard component which itself can contain data visualizations, filters, and a few other elements. You can include this Dashboard component in your own workspace.

    The technical editor is the UI Builder itself, opening in the special Advanced Dashboards experience. You have the full features of the UI Builder, but also the complexities. The technical dashboard is for experts with deep knowledge of UI Builder.

  • If you have any other role, the in-line editor opens.
