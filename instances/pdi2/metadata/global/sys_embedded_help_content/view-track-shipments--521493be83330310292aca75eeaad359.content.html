View hardware shipment details

View details of all hardware asset shipments in a single place.

Before you begin

Role required: inventory_user (read) and inventory_admin

About this task

The Shipment list shows all the shipment records initiated by the shipment tasks of various flows. A shipment record is created automatically in the Shipments list whenever a shipment task of a workflow or process is closed.

Procedure

  1. Select a shipment record to view the shipment details.
  2. Select the Shipment assets tab to view the assets included in the shipment.

    A shipment can have assets from different sources. For example, a shipment with assets from two different transfer orders or assets from a transfer order and an asset donation order.

    The Source column shows the source flow or process to which the asset belongs. For example, Source column with value Transfer Order: TO0000001 indicates that the asset in the shipment is from a transfer order. You can select the item in the Source column to view the details.

    The Stage column shows the status of the asset in the shipment. When the assets in shipment are received, the stage of the asset changes to Delivered.
