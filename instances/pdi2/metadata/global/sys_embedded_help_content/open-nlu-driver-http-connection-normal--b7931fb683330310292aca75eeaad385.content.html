Modify an NLU driver HTTP connection record

Role required: admin

Depending on your environment, you may want to configure Virtual Agent to recognize different HTTP connections for your NLU provider, depending on the context.

  1. On the form, fill in the fields.
    Name
    Describes the NLU provider and the function (models, intents, and so forth).
    Http Method
    Select GET, POST, or None.
    Http Connection
    The corresponding HTTP connection mapping record in the HTTP Connections [http_connection] table.
    NLU Resource Type
    Function for the connection. For example, to return a list of models, select Models. Other options are Intents, Entities, and Prediction.
    Open NLU Driver
    The record for the supported NLU provider as configured in the Open NLU Driver [open_nlu_driver] table.
  2. Click Submit.
