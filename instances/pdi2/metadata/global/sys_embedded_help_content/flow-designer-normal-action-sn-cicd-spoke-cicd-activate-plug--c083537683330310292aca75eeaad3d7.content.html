Activate Plugin action

Activate a plugin by ID on the specified instance URL.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Credential Alias
Data type: String

Connection and credential alias of type Credential. This alias must have a user with the sn_cicd.sys_ci_automation role.

Plugin id
Data type: String

The ID of the plugin you want to activate. The ID identifies a record in the System Plugin [v_plugin] table. For example, com.glide.role_admin.

Instance URL
Data type: String

The URL of the instance where you want to activate a plugin.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Status
Data type: String

Displays one of these status codes:

  • 0: Pending
  • 1: Running
  • 2: Successful
  • 3: Failed
  • 4: Cancelled
Status Label
Data type: String

Label of the status code that was returned, such as Pending or Running.

Status Message
Data type: String

Message with a summary of why the operation failed (if an error occurred). This value can be null.

Status Detail
Data type: String

Details on why the operation failed (if an error occurred). This value can be null.

Percent Complete
Data type: String

Status of percent complete.

Error
Data type: String

Reason for the error (if an error occurs).

Progress URL
Data type: String

URL of the REST endpoint to track the progress of this request.

Progress id
Data type: String

System ID of the execution tracker record for this request.

HTTP Status
Data type: String

HTTP status code of the response.
