Use the SIR Workspace

Security Analysts and managers use the security incidents, response tasks and SLAs to perform day-to-day operations with an improved user experience, do complete incident investigation, and get an overview.

The SIR Workspace enables you to perform the following tasks:
  • Work with Security Incident Records.
  • Work with MSI Records.
  • Work with Form UI actions.
  • Security Incident Closure workflow.
