Approval State
Data type: Choice

Completion state of the approval request. The flow execution details page displays one of these values.

  • Not Yet Requested [not requested]
  • Requested [requested]
  • Approved [approved]
  • Rejected [rejected]
  • Cancelled [cancelled]
  • No Longer Required [not_required]
  • Skipped [skipped]
