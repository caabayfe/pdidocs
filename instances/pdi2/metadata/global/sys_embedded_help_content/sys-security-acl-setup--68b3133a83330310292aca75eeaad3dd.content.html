The conditions specify when someone can access the named object and operation. Security administrators can specify permission requirements by adding:
  • One or more user roles to the Requires role list.
  • One or more conditions.
  • A script that evaluates to true or false or sets the answer variable to true or false.

To gain access to an object and operation, a user must pass all permissions listed in an access control.

Whenever a session requests data, the system searches for access control rules that match the requested object and operation. If there is a matching access control rule, then the system evaluates if the user has the permissions required to access the object and operation. If the user fails to meet the permissions of any matching access control rule, the system denies access to the requested object and operation.
