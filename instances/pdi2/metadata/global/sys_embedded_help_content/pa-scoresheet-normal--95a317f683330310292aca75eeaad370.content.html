Scoresheet

In the scoresheet, set indicator scores manually, including breakdown scores.

As an admin, you can set the scores for an indicator and its breakdowns directly in the scoresheet. Do so when working with a manual indicator. You can also set the scores manually when you need better demo data than you are able to collect. Exercise extreme caution if editing the scores of an automated or formula indicator on a production instance. You will overwrite the collected or calculated scores, which are based on facts tables.
