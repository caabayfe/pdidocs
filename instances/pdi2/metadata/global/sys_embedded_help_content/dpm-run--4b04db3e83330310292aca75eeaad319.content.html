Monitor the performance of your solutions

The run phase enables you to monitor critical key performance indicators (KPIs) and operational performance of your solutions.

Run tab

The run phase of the plan-build-run life cycle enables you to monitor and track the work for your solutions.
  • Edit the start and end dates for the work effort.
  • View the performance snapshot KPIs based on ServiceNow® Performance Analytics indicators. This widget is configurable so that you can add different KPIs to this view using the ServiceNow® UI Builder application.
  • View the offering breakdown for the solution and select one to view its plan-build-run life cycle.
