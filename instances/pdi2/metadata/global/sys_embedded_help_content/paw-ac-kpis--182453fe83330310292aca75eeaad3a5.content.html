Indicators

See the Performance Analytics indicators (KPIs) that you can access. Drill down to their details.

The Indicators library features a list of the indicators that you can access. You cannot change the columns that are displayed. You can apply the following filters.
All
See all indicators that you can access. If you have the admin or pa_admin role, you can see all configurable workspace dashboards on the instance.
Bookmarked
See all indicators that you have bookmarked. You can bookmark a dashboard here in the list, with the All or Created by me filter selected.
Created by me
Those indicators that you have created.
To see a summary of the indicator, select an information icon.

To see the full details of an indicator, set targets, and explore statistics, select the name of the indicator. A KPI Details tab opens.
