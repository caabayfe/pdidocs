Adding a data visualization

You can configure a new data visualization or reuse a saved visualization from the library.

New visualizations

Specify the visualization chart type and its data source. These choices determine which other configuration options are available.

The key decision to make when configuring a data visualization is the visualization type and data source to choose. Separate help topics on this page assist you with this decision. The other configuration options depend on your choice. A complete guide to these options in all their permutations and combinations is outside the scope of this help. Tooltips are provided on each field to assist you. Also refer to the product documentation, through the link at the end of this topic.

Saved visualizations

The library contains data visualizations that you have created yourself or that have been shared with you.

For each visualization, you see a description (if one was written), the visualization type, and whether it was certified for use across your organization. You cannot change these columns.

If you see a line about rows removed by security constraints, this sentence refers to data visualizations that have not been shared with you.

After you add a visualization from the library, you can reconfigure it, unless the visualization was shared with you only as a viewer. Then when saving the dashboard, you can save your reconfiguration to this dashboard alone or to the visualization in the library. In the latter case, carefully read the list of the dashboards that contain the visualization. All these dashboards are affected if you save your reconfigured visualization to the library.
