Modify a saved search

As the owner of a saved search, you can modify the search values and save your changes.

Before you begin

If you are not the owner of the saved search, save the search with a different name. You can then update search values, save your changes, and share the search with others.

Define and save a search before performing this procedure.

Role required: evt_mgmt_operator or evt_mgmt_admin

Procedure

  1. On the Log viewer, select the selection icon () and then choose Manage my searches from the drop-down list.
  2. On the form, modify the settings.
  3. Optional: Revert changes you have made to the search values by selecting the selection icon () and then selecting Discard Changes.
    The changes that you made to the search values are discarded. You can continue to update the search settings.
  4. Save the updated search.
    1. Select Save as.
    2. In the Search name field, specify a unique and descriptive name for the search and then click Save.
