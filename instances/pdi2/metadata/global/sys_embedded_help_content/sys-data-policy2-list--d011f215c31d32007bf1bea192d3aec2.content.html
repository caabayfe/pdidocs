Mandatory fields data policy

A mandatory field helps capture critical information for resolving an incident more efficiently. However, you must compromise between capturing critical information and impacting user experience.

By creating a data policy to define mandatory fields, you can enforce data consistency not only on data records entered through the Incident form but also on the data records entered through alternate channels such as import sets and web services.

To create a data policy to define a field as mandatory, click New .
