Set targets

Set targets in days to remediate the vulnerabilities, security incidents, and misconfigurations.

Before you begin

Role required: admin

Procedure

  1. Select Set target on the widget.
  2. Select the Targets icon on the KPI Details page.
  3. Select the For everyone box.
  4. In the Target field, enter the number of days in which you want to achieve the target.
  5. Select the target start date.
  6. Select the target review date.
  7. Select Update.
