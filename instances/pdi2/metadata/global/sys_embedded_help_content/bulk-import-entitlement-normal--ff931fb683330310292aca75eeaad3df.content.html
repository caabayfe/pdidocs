Entitlement import

A list of software entitlements can be imported from a Microsoft Excel spreadsheet using the template file (samp_entitlement_import.xlsx).

The first tab of the template contains the Quick Start Guide on how to import entitlement data.

When the import completes, the total number of entitlements imported is shown, and an Entitlement Import Error record is created for any errors (that can be fixed or ignored).
