Document tasks

The Document Tasks list shows the document tasks in your instance.

Navigate to My Document Tasks to see a list of the document tasks assigned to you.
  • Click the column headers to sort, filter, and edit data.
  • Select a document task to view and edit the task details.

The Document Tasks list includes the following significant columns:

Number
Number of the task
Short description
The title of the task
State
State of the task
Assigned to
The person primarily responsible for working on the task
