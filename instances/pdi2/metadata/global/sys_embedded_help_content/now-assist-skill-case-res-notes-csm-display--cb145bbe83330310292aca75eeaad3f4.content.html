Resolution notes generation: Select display

Select where you'd like to display the resolution notes generation skill, either in the product or in the Now Assist panel, or both.

In-product
Display the skill on forms in CSM Configurable Workspace or in the Core UI.
Now Assist panel
Display the skill in the Now Assist panel. To restrict access to the content in the Now Assist panel by role, select the down arrow to identify the roles that can use the skill.
