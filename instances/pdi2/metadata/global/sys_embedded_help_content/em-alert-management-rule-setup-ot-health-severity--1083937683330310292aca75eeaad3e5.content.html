Manage the severity of an OT alert

This task requires the admin or ot_health_admin role.

Determine which OT attributes and factors to use when calculating the severity of an alert on an OT device. In OT, additional factors can include the OT device criticality, the Purdue Level, and the criticality of the equipment model entity that the OT device automates.
Note: Make sure to turn the default OT severity rule (OT Alert severity change) to Active and change the order to ensure the OT rule is at the top and gets executed first. This rule considers OT device criticality during the severity calculation. In case you want to consider other OT attributes in the priority calculation, you might need to update the logic accordingly.
