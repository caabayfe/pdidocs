View calculations for your licenses

View and understand the calculations for all your required licenses in the Software Asset Workspace.

Before you begin

You can view the following information on licenses required:
  • detailed description of the license metric
  • the cluster for which calculations are shown
  • total number of licenses required
  • current licensing status
  • rights allocated on the cluster that are not being used
  • rights used for license calculations but not allocated
  • relationship of hosts to the current Configuration Item (CI)
  • license consumption breakdown where the cluster is broken into multiple hosts
  • metric attributes applied
  • details of the installations covered by licensing related to a CI
  • licensing status of an installation across multiple hosts on a cluster
  • host affinity rules configured for a cluster
  • downgrades, if the specified license is used by a downgrade version of the software.

Role required: sam_admin or sam_user

Procedure

  1. On the Publisher details page, drill-down in the navigation tree and select a license metric.
  2. On the License Metric Results related list, select the value in the Licenses required column.
  3. On the Licenses Required By related list, select the value in the License required column.
    The Licenses required calculation page appears on the right hand side.
  4. Scroll down to view the detailed information.
