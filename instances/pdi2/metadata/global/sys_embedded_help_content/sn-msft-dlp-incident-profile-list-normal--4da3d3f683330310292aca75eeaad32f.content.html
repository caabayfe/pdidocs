Data Loss Prevention Incident Response with Microsoft

The Data Loss Prevention Incident Response with Microsoft provides a core framework to import Data Loss Prevention (DLP) incidents from multiple sources such as Microsoft purview apps (Microsoft Teams, Exchange Online, SharePoint Online, OneDrive for Business). Endpoint devices enable remediation workflow involving end users, managers, and  DLP  operations team with automated incident assignment and escalations.
