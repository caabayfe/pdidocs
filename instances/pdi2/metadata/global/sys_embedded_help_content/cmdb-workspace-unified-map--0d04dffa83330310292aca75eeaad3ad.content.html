Unified Map

Unified Map combines the capabilities of Dependency Views and Service Mapping in a hierarchical map of CIs and the relationships between them. Each node represents a CI, and each line represents a relationship. Unified Map also shows the application services that a CI is a part of. The map centers on the home node — the CI you specify.

Access

Unified Map requires these roles:
  • To access maps: sn_cmdb_user, sn_cmdb_editor or sn_cmdb_admin roles
  • To access maps with operational application services: app_service_user, and sm_user or sm_admin
  • To access maps with operational and non-operational application services: app_service_admin, and sm_user or sm_admin
  • To access and view related items: itil

Map content and appearance

Administrators can configure general Unified Map settings to control the initial content and appearance of maps for all users in a workspace. See Configuring Unified Map — admin settings.

Non-admin users can control which elements appear on the map, isolate and analyze relationships between CIs, and simplify the map to isolate issues. See Controlling Unified Map contents and appearance.

Working on the map

Drag a node to reposition a CI. For details on any of the following items, see Controlling Unified Map contents and appearance.

CI search field
The CI you select after searching becomes the home node — the center of the map. All other CIs and relationships are rendered with respect to the home node.
Level setting
The map level determines the number of CI hierarchy levels that Unified Map shows. Starting with the home node, the map shows all CIs up and down the hierarchy, up to the specified level.
Filter panel
Filter CIs and relationships. Filtered items don't appear on the map unless you select the Show filtered items icon. You can create preset filters that you can apply to any map. A blue dot appears on the filter icon when filters are being applied. See Use filters to specify which nodes should appear on a map.
Toolbox
Modify visual aspects of the map.
Mini-map navigator
Reposition your view to move quickly to an area of interest. When you select an area on the mini-map navigator, you pan to that section of the map.
Group CIs and service instances

You can select the number badge on a group CI to expand the group and show its member CIs. The group parent and any CI members are temporarily highlighted by a light purple color. Select the badge again to collapse the group.

Timeline

The map shows the configuration of CIs at the moment in time that you specify on the timeline. You can pan the marker across the timeline to see changes to the CI over time. See Viewing related items on the Unified Map timeline.

Contextual side panels

Select a side panel to view details for items selected on the map. For some panels, if nothing is selected, details appear for all CIs on the map.
Overview panel
The Overview panel displays summary data for items on the map that are associated with the home node — counts and types of CIs and connections, discovery sources, and so on. See View a summary of map contents on the Overview panel.
Attributes panel
  • For non-group CIs, the top section shows attributes common across all CIs. The bottom section shows attributes that uniquely extend the CI's class in the CMDB hierarchy.
  • For group CIs, the top card shows attributes of the group CI and the Configuration items cards show attributes for each of the group member CIs.
  • When you select a relationship, you see a card with attributes for each relationship in the relationship set, representing each different type of relationship between the CIs.

See View the attributes of a CI or a relationship.

Service instances panel

Use the Search box to find a specific service instance. Use the filter panel to sort the cards by category. If nothing is selected on the map, then all service instances related to any CI appear. See View service instances for a CI.

Changes panel

The Changes panel includes tools that help you to find changes and improve visibility for important changes. See View historical changes for a CI.

Related items panel

This panel shows related items grouped by related items categories. Administrators configure the categories that are globally available. You can hide and rearrange the categories when you access the Related items settings. If nothing is selected, all related items that are associated with any CI on the map appear. See View related items for a CI and Configure the Related items panel.

Mapped services

Mapped services appear on the map as group CIs that you can expand and collapse to show or hide members. Mapped services are descendents of the service instance [cmdb_ci_service_auto] class, such as service instances and dynamic CI groups. A badge on a group CI shows the number of members in the group.

Select the badge to expand the group to show all members. In its expanded mode, point to any CI in the group to temporarily highlight all CI members.
