Create a data fabric table

Fetch data from an outside source and make it accessible from your instance by creating a data fabric table.

Before you begin

Role required: One of the following role combinations or admin.
  • delegated_developer with sn_dd_<application_scope_name>_tablesforms OR sn_dd_<application_scope_name>_delegatedadmin, and a role containing the df_data_steward role
  • delegated_developer with sn_dd_<application_scope_name>_tablesforms OR sn_dd_<application_scope_name>_delegatedadmin, and df_connection_admin
Note: Only a user with the admin role can create a data fabric in the global scope.

Procedure

  1. Enter a name for the data fabric table in the Label field.
    An internal name is automatically generated in the Name field.
  2. Select Continue.
  3. Map source columns to the data fabric table.
    Each source column that you select is automatically created in the data fabric table with the same name and data type.
  4. Optional: Select one or more columns that contain unique values using the Primary Key toggle switch.
    • If this data fabric table will be referenced by other tables, you must designate a primary key column for each reference.
    • Choosing a primary key doesn't enforce primary key constraints on the data fabric table or on the remote system. You must verify that records identified by the primary key are unique.
  5. Optional: Link data between tables by creating a reference to another table.
    1. In the Type column, change the column type to Reference.
    2. Select Set reference.
    3. In the Set Reference Label dialog box, enter the name of table that you want to reference.
    4. In the Set Reference Label dialog box, select a primary key in the Reference key field.
    5. Select Set reference.
  6. Select Finish.

Result

The data fabric table is created and connected to a data source. Data consumers can access the data fabric table and its data just like any physical table on the instance.
