Select an application service candidate based on Automated Service Suggestions

View a list of suggested application service candidates. Examine preview maps and select one candidate to create a new service or to map to an existing service.

Before you begin

Ensure that Predictive Intelligence is enabled, verify Machine Learning readiness, and confirm that the data is trained. For more information, see.Application service readiness dashboard in configurable workspace

Role required: sm_admin

Procedure

  1. Select the box for the desired candidate.
    If you select the candidate number, the candidate platform page appears in a new tab. Close this tab and continue.
  2. Select Preview map.
  3. Close the preview tab and return to the ML-powered candidates list page.
  4. Select Map application service.
