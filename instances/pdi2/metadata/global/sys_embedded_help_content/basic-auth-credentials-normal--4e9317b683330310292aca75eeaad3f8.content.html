Configure Basic Auth Credentials

Role required: admin

Add the IBM Watson NLU API key in your ServiceNow instance for each of the following Basic Auth Credentials records:
  • IBM Watson NLU Models
  • IBM Watson NLU Intents
  • IBM Watson NLU Entities
  • IBM Watson NLU Prediction
  1. On the form, fill in the fields.
    User name
    Enter apikey.
    Password
    Your IBM Watson NLU password.
  2. Select Update.
