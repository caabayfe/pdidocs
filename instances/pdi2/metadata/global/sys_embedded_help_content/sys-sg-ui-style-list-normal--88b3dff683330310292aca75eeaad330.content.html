Mobile UI Styles list

Use this list to track UI styles, which define the font and background color of fields in your applets.

Associate one or more UI styles to a legacy card record to change the appearance of the fields in that legacy card. Each UI style applies to a single table, and only applies under conditions set within the UI style record.
Note: Mobile UI styles can only be applied to legacy cards.
Name
A name for the UI style. Choose an easily identifiable name. Use this name to apply the style to a specific field in an applet.
Active
Whether the UI Style is in use.
Condition
The conditions in which the field style will appear. For example, you can configure the State field to appear blue, but only when State is Assigned.
Field Name
The name of the field you want to add style to. Only fields available on the table you selected appear in this list.
Legacy Card
Patterns that define the appearance and location of fields in an applet. Legacy cards are specific to a screen, each screen has its own unique legacy card record.
Item View Element
This field appears when the Use item view elements option is selected. The field contains a list of the elements from the item view selected in the Item view field. These elements represent the JSON elements found in the selected Item view record.
Style
The style field supports multiple entries. Each entry has a Name and Value elements.
Table
The table containing the field you want to add a style to.
Use Item View Elements
Whether the entry allows elements from that record to be used elsewhere.
