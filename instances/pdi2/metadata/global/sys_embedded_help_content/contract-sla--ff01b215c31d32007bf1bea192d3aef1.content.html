Create, modify, or delete an SLA definition

  • To create or modify an SLA definition:
    1. Enter or modify the SLA Name .
    2. In Type , select a category for the SLA.
    3. In Workflow , select the workflow that determines what activities occur in response to the SLA.
    4. Select a Duration type .
    5. If you select User specified duration from the Duration type list, enter or modify the Duration .
    6. From the Schedule source list, select the schedule for the SLA timer to run in.
    7. Select a Timezone source .
    8. Under Start condition , Pause condition , Stop condition , and Reset condition , add or modify the respective conditions for the SLA.
    9. Click Submit or Update .
  • To delete an SLA definition, click Delete .
