Create an ACL rule

Create a custom ACL rule to secure access to new objects or to change the default security behavior.

  1. On the form, fill in the fields.
    Type
    The type of object this ACL rule secures. For example, record or UI page.
    Application
    The scope of the application. The default option is global.
    Operation
    The operation this ACL rule secures. For example, create or delete.
    Name
    The name of the object being secured. For example, record or table.
  2. Optional: If you selected Advanced, in the Script field, create a script that specifies the permissions required to access the object.
    With Now Assist for code generation enabled, you can provide text or code prompts to return AI-generated code suggestions and create ACL rule scripts quickly.
  3. Select Submit.
