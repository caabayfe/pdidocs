Using CMDB groups

Role required: admin or cmdb_ot_admin

  1. This process requires:
    • Defining a CMDB Group with the required filter criteria to identify the right IT CIs.
    • Creating a new scheduled job record associated with a CMDB Group to automatically convert IT records belonging to the CMDB Group into OT devices by adding the OT entity details.
    • Creating a new record in the sn_automated_it_ot_bulk_conversion_m2m_cmdb_group to associate the CMDB Group with the scheduled job.

      For example, if you want to add OT entity details for all computers that have a specific HISTORIAN software installed, you can create a CMDB Group that matches this filter criteria. Then, create a scheduled job and link it to the CMDB Group for computers that have the HISTORIAN software installed.

  2. Once the schedule is defined, set a scheduled time using the Run field and set the schedule to Active.
    Note: Acknowledging that there are different ways of identifying the CIs for which OT entity records need to be created, here are some best practices to follow:
    1. Ensure the filter conditions on the CMDB Group returns unique set of CI records every time. For example, adding a filter condition such as OT device details is EMPTY ensures that only records without OT device details are considered.
    2. Make sure the indexed fields used are applicable as part of the filter criteria conditions. Ensure that the data set does not exceed 1M records to avoid performance related issues.
    3. Make sure to create separate scheduled job definitions per CMDB Group to have filtering at a group level and define respective OT entity default values.
    4. Validate the data in the OT Entity Default Configuration tab. OT entity records are created using these default values.
