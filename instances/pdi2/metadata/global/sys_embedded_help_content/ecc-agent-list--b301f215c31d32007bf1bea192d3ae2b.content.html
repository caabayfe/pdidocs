Validate the MID Server

After you install the MID Server, you must validate it. Validation restricts access to automation credentials to trusted MID servers only.
  1. In the list view, locate the MID Server you just installed and ensure that the Status is Up .
    This means that the MID Server is running and communicating with the instance.
  2. Select the check box in the left column next to the MID Server you want to validate.
  3. In the Action choice list, select Validate .
