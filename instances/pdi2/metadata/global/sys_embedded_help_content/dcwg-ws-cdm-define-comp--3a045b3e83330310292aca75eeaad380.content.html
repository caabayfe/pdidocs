Define or update a component

Define or update a component while working in a changeset.

Before you begin

Role required: cdm_editor or cdm_admin

Procedure

  1. In the application changeset record, select the more actions icon () for the components node and select Create component.
  2. In the Create component dialog box, enter a unique and meaningful name for the component, and select Create.
  3. Use the more actions icon next to the component node to add a component, CDI, or a file node.
    • To add a component, select the more actions icon and select Create component from the menu.
    • To add a CDI, select the more actions icon and select Create CDI.
    • To attach a file, select the more actions icon and select Add file.
    • To include the selected component in one or more collections, select the more actions icon and select Include in collections.
    • To rename the component, select the more actions icon and select Rename.
    • To delete the component, select the more actions icon and select Delete.
      Note: The options to rename and delete the component are available only if it isn’t being used in any application.
  4. Select Save to save all changes in the changeset.
  5. Select Commit to commit all changes made to the components.
