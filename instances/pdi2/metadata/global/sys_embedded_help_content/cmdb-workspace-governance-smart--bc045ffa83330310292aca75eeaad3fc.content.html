Smart detection for attestation

Smart detection automatically identifies CIs in your attestation tasks that are detected by Discovery or Service Graph Connectors. Smart detection enables you to auto-attest your CIs in batches, without needing to physically or manually verify the existence of the CIs.

Activation

Smart detection requires that you enable Discovery or implement Service Graph Connectors. Activate either of these plugins:
  • com.snc.discovery
  • com.snc.cmdb.integration_util

Ensure that the sn_cmdb_ws.attestation.smart_detection.disabled system property is set to false.

Using Smart detection

Smart detection uses the following properties to filter your discovered CIs for auto-attestation candidates:
  • sn_cmdb_ws.attestation.smart_detection.discovery_window: The number of days (discovery window) that Smart detection uses to determine whether a CI is a candidate for auto-attestation. Only CIs that were discovered within this discovery window can be candidates for auto-attestation.
  • sn_cmdb_ws.attestation.smart_detection.discovery_source.exclusion: A comma-separated list of discovery sources that are explicitly excluded from smart detection processing. For example, a data source that is unreliable in detecting CIs. Smart detection only detects CIs from discovery sources that aren't excluded by this property.
You can use the Smart detection status card to perform the following actions:
  • Review the list of CIs found by Smart detection that are candidates for automatic attestation. The list is filtered by your configured system properties
  • Review the details of CIs in the list.
  • Click Auto-attest to attest all the CIs in the list and move them to the Attested CIs list.
  • Click Cancel auto-attestation to leave all the CIs in the Not Yet Reviewed list. You can return at a later time to continue attestation.
