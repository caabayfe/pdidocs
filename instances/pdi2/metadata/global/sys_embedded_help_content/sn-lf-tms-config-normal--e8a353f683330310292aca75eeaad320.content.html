Create a Translation Management System configuration

Roles required: localization_admin and flow_designer

Ensure that the Localization Framework Installer plugin (com.glide.localization_framework.installer) is activated.

Use this form to create a configuration for the translation management system, with a third-party translation management system of your choice to localize an artifact.

  1. On the form, fill in the fields.
    Name
    Input a unique identifier for the TMS configuration.
    Request translation subflow
    Select a subflow to interact with the third-party translation management system to request translations.
    Receive translation subflow
    Select a subflow to interact with the third-party translation management system to receive translations.
    Application
    Set the scope of the application. The default scope is Global.
    Version
    Select the version of the contract used in subflows. The default version is v1.
    Enable auto retrieval
    Click to retrieve the translated content automatically. When selected, the translations are retrieved as per the scheduled jobs which run daily.
    Language code mappings
    Select the desired language code mapping for the TMS to use for translation.
  2. Click Submit.
