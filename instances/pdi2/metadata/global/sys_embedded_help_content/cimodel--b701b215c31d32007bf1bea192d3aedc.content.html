Orphan rule

  1. Select a class from the Class Hierarchy .
  2. Double click the default rule for the cmdb_ci class to edit it. Or, if an orphan rule exists for the selected class, double-click it to edit, or click New .
  3. Complete or edit the CMDB Health Orphan Rule form.
    ControlDescription
    ClassThe class for which the orphan rule applies.
    ConditionThe filter that determine which CIs are considered orphans. For example, the filter conditions in which both the Assigned to and the Owned by fields are empty, will identify the matching CIs as orphans.
    No RelationshipSelect to add the requirement that the CI should have no relationships to be considered an orphan CI.
  4. Click Submit or Update to save the rule.
