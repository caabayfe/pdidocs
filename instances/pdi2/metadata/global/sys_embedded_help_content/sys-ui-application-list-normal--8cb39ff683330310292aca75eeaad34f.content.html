Mobile Application Menu list

This list details the available application menus available for the ServiceNow Classic Mobile app. You cannot hide the application navigator from users, but you can control contents based on role.

Name

Title of the application menu.

Order
Order in which the menu is listed. For example, an entry of 100 would place this application menu before one with an Order entry of 200.
Roles
Roles assigned to access modules under this application menu.
Active

Whether the application menu is currently in use.
