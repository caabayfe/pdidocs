Creating a G Suite integration profile

Create an integration profile to connect your G Suite subscription to the NOW platform. View software usage information and optimize stale licenses.

Before you can save the integration profile, you will need to create an OAuth application in the Google API Console.

After you create your application, use the following information from the Google API Console to update the integration profile.
  • Client ID
  • Client secret

After you save the integration profile, click the Get OAuth Token related link to complete the connection.
