Configure interaction connectors

  1. To configure a new connector for an interaction, click New.
  2. In the Name field, create a name for the interaction connector based on the type of channel you are configuring.
    For example, Chat.
  3. In the Description field, include more information about the connector.
  4. For each point in the interaction life cycle, use the Interaction, Interaction Queue, Conversation, and Queue APIs to determine how the interaction behaves.
  5. Click Submit.
