Create a new security incident

In addition to automatic methods for creating security incidents, you can create them manually based as per your requirements.

Before you begin

Role required: sn_si.basic

Procedure

  1. In the Workspace Overview page, click New to create a new security incident.
  2. To create a new security incident from the Lists, click New in any of the lists.
  3. On the form, fill the fields.
  4. Click Save.
