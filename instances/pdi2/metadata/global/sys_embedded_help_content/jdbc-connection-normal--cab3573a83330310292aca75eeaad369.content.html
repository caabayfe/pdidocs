JDBC connection

The JDBC Connection provides the information custom JDBC actions or activities used to connect to various target databases.

Name
Unique name of this JDBC connection.
Active
Check the box to make this an active connection.
Credential
Add credentials for JDBC provider.
Connection alias
Select the alias record to associate with this connection.
Query timeout
Maximum elapsed time the JDBC driver is allowed to run without a response.
Connection timeout
Number of seconds the system waits for a successful JDBC connection.
Format
Database type for this connection: MySQL, Oracle, SQLServer, and None.
Host
Host name or IP address of the database server.
Connection URL
URL that the MID Server uses to connect to the specified database.
JDBC driver
The JDBC driver to use for this connection when it is not a default database.
