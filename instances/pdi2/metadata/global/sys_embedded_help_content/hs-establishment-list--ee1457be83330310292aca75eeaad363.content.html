Establishment list

A list of all establishments under your organization. The recordable injury and illness records are grouped using this establishment information for reporting, such as OSHA forms.

You can view this list if you have the safety compliance manager [sn_ohs_im.compliance_manager] role assigned to you.

  • To add an establishment record, select New.
  • To edit an existing establishment record, select the establishment in the list and select Edit.
  • To view the exported reports for an establishment, for example, OSHA forms, open the establishment record in the list and then open the report from the Attachments section.
