Create entitlements using form layout

Create entitlements in the Software Asset Workspace to enter your license details and allocate purchased software rights to users or devices.

Before you begin

When you start creating the entitlement it's in the build status. Once you publish the entitlement, the status changes to in use and makes the entitlement eligible to be included in the reconciliation process.

Role required: sam_admin or sam_user

Procedure

  1. On the Create New Software Entitlement page, fill in the fields.
  2. Once you have entered the required details, select Submit.
    The entitlement is created.
  3. Select Publish for the entitlement to be picked up for the reconciliation process.
    The entitlement is published and the state of the entitlement is changed to in use from build. You can perform additional configuration on the new entitlement by entering details in the other tabs such as Contracts, Downgrade Rights, Expense Lines, Entitlement History.
