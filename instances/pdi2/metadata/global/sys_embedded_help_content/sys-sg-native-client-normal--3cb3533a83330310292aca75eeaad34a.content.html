Create a mobile app config

Role required: admin.

Use this form to create a new mobile app config. This will define the user's experience based on conditions selected in the config.

  1. On the form, fill in the fields.
    Name
    Title of the mobile app config.
    Type
    Type of experience handled by the config.
    Navigation Bar
    Which navigation bar is used in this config.
    Empty State
    How users are informed that a page currently does not contain data.
    Order
    Order of the mobile app config.
    Required Roles
    Which roles can use this mobile config.
    App ID
    Identification number of the Android or iOS app related to the config.
    API Key
    Web API key related to the config.
    Force Local Login
    Whether the config provides local login experience on mobile apps even when the instance is configured with Single Sign On (SSO) configuration.
  2. Click Submit.
