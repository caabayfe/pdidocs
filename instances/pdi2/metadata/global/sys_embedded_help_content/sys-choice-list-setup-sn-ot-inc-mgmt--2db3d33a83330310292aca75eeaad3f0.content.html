Categories and subcategories

Roles required: admin or sn_ot_incident_admin

Create an OT incident category or subcategory that you want to use to classify incidents.

  1. Change the application scope.
    1. On the ServiceNow banner, select the globe symbol.
    2. Filter the list to find a select Operational Technology Incident Management.
  2. Create a category.
    1. Select the New button in the right top corner.
    2. Enter the category word in the Element field.
    3. Enter the category name in the Label field.
    4. Enter the category value in the Value field.
    5. Enter the sequence number in the Sequence field.
    6. Select Submit.
  3. Create a subcategory.
    1. Select the New button in the right top corner.
    2. Enter the subcategory word in the Element field.
    3. Enter the subcategory name in the Label field.
    4. Enter the subcategory value in the Value field.
    5. Enter the sequence number in the Sequence field.
    6. Select Submit.
  4. Change the application scope back to Application Scope: Global.
