Artifact Configurations list

This list shows details of the artifact configurations available for your instance. These are used in the Localization Framework to fulfill translation requests.

Name
Unique identifier for the artifact record.
Internal name
The internal name of the artifact.
Table
The table where the artifact information is stored, for example, the Catalog Items [sc_cat_item] table.
Active
Boolean value showing whether the artifact is in use.
