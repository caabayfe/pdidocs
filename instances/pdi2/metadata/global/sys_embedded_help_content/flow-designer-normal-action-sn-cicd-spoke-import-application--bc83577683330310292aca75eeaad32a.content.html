Apply Changes From Source Control With Scope action

Applies remote changes from source control to an application identified by its unique scope name.

Important: A corresponding CICD connection and credential must be created and associated with the Instance URL input value.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

App Scope
Data type: String

Name of a unique application scope to which you want to apply changes from source control. For example, sn_va_web_client. To apply changes a global application, use the Apply Changes From Source Control With ID action.

Credential Alias
Data type: String

Connection and credential alias of type Credential. This alias must have a user with the sn_cicd.sys_ci_automation role.

Instance URL
Data type: String

The URL of the instance where you want to update the application.

Branch Name
Data type: String

Name of the source control branch that contains application changes.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Status
Data type: String

Displays one of these status codes:

  • 0: Pending
  • 1: Running
  • 2: Successful
  • 3: Failed
  • 4: Cancelled
Error
Data type: String

Reason for the error (if an error occurs).

HTTP Status
Data type: String

HTTP status code of the response.

Status Label
Data type: String

Label of the status code that was returned, such as Pending or Running.

Status Message
Data type: String

Message with a summary of why the operation failed (if an error occurred). This value can be null.

Status Detail
Data type: String

Details on why the operation failed (if an error occurred). This value can be null.

Progress ID
Data type: String

ID of the execution tracker for this request. Use this value to track the progress of the request.

Progress URL
Data type: String

URL of the REST endpoint. Use this URL to return the progress of the request, using the ID of the execution tracker.
