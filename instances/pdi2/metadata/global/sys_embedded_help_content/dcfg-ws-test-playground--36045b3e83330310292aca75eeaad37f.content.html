Exporter test playground

Use the Test playground feature to test the exporter and snapshot before you export the configuration data.

Before you begin

Role required: sn_devops_config.admin

Procedure

  1. Specify the Test playground settings.
  2. Select Evaluate and review the data in the Output and Executions tabs.
  3. When you are satisfied with the exporter, you can publish it by selecting Publish on the Exporter builder tab.
    Note: You must set an exporter to active for it to be executed in a pipeline.
