IP Address Access Control Form

Use the IP Address Access Control form to control inbound, outbound, and bidirectional traffic. The system blocks an IP address if a matching Deny rule exists while no matching Allow rule is available.

Type
The type of access rule to include. For example, Allow or Deny.
Range start
The starting range of IP addresses to allow or deny.
Direction
Rules that specify how traffic move: Inbound, Outbound, or Bidirectional.
Range end
The ending range of IP addresses to allow or deny.
Active
Determines if the rules of the IP will be applied.
