Select a planning item type to configure related lists

Role required: admin

  1. From the list of planning item types here, select one for which you want to configure the related lists.
  2. Click the Show Form related link so that you can open the actual form view of this planning item type.
  3. Use the Additional actions menu to configure related lists for this planning item type.

    For details on how to add related lists to a form, refer to the documentation from the Related information section below.
