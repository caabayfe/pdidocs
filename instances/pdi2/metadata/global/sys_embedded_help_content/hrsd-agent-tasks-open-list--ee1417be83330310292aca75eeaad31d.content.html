Open task list

View and manage all open tasks.

Filter a list

Filter the list of all your cases to find cases by subject person, opened for, or other key fields.
  1. Select the Filter icon (the funnel icon).
  2. Select Advanced view.
  3. Build a filter by adding conditions that contain a field, operator, and values.
  4. Select Update to run the filter for the list.

Change displayed columns

Change the columns that are displayed to view only what you need.
  1. Select theList Actions icon (the gear icon).
  2. Select Edit columns.
  3. Select and order the columns.
  4. Select OK.
