Add tables to an ERP model

Build an ERP (Enterprise Resource Planning) model by adding remote tables and ERP extraction tables to the model.

Before you begin

The ERP model must have an ERP system specified in the system details before you can add tables.

Note: To add tables to a standard ERP model, you must first clone the model.

Role required: sn_erp_mining.erp_admin, sn_erp_integration.erp_user

About this task

The ERP model serves as a blueprint for configuring, customizing, and integrating the ERP system to meet your business requirements. An ERP model functions as a staging area that contains all potential fields that you can add to remote and extraction tables. You can then use the remote tables and extraction tables as a data source on the ServiceNow AI Platform.

When you add a remote table to an ERP model, the remote table is added only to your application scope.

You can have the ServiceNow AI Platform scan the linked ERP system on demand to see if new fields are available by selecting the Fetch model fields button.

Procedure

  1. Navigate to All > ERP Canvas > ERP Canvas Home.
  2. Open the ERP model page by selecting (the ERP model icon) in the side panel.
  3. Select the ERP model name for the model that you want to add tables to.
  4. View the ERP tables on the system connected to the ERP model by selecting the Model tables tab.
  5. Select the New button.
  6. On the form, fill in the fields.
    Name
    Name of the ERP table on the system of record.
    The table must exist with the exact name on the system of record.
    Note: The same ERP table can exist in multiple ERP models.
    ERP model
    Name of the current ERP model that you're adding the remote table to.

    To add a remote table for a different ERP model, you must select that ERP model from the list of ERP models.

    Alias
    Unique label for the ERP table.

    When you add a new ERP table to the ERP model, the alias is an alternative or substitute name. An alias enables you to assign and customize a recognizable name for easier reference and identification.

    The same table can have multiple aliases for different table joins.

    The alias can be a maximum of 40 characters, and contain a-z, A-Z, 0-9, and underscores.

  7. Select Save.
    The list of model tables refreshes, and displays the Status for each table:
    • Retrieved table data
    • Pending
    • Connection error

Result

The Table fields tab automatically populates for the new table if the table is connected to an ERP system.
