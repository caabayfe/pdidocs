Getting started with Zero Copy Connector for ERP

Zero Copy Connector for ERP is a ServiceNow scoped app that enables you to simplify the use of ERP (Enterprise Resource Planning) data from the system of record, such as SAP.

Legacy systems of records, such as SAP, can have old, complex custom code and data that require more time and effort to move to newer versions of the system of record. Use Zero Copy Connector for ERP and ERP Semantic Mining to scan the system of record to find and replace custom code with digitized workflows, resulting in a clean ERP core.

Zero Copy Connector for ERP connects to and scans ERP systems, such as the SAP system of record. You can then use a standard ERP model, for example, Material Stock or Purchase Documents, or clone them to make changes.

Using ERP models, you can work with remote tables and extraction tables to transform data, making it available for use on the ServiceNow AI Platform. After you build ERP models, you can use that extracted and transformed data to build apps quickly (for example, with App Engine Studio) that access the ERP models.

ERP models
ERP models function as templates for sets of tables that give you access to ERP data. You can use the standard Zero Copy Connector for ERP models as-is, or clone them to make changes.
Remote tables
Remote tables enable you to view and query data from the ERP system of record on the ServiceNow AI Platform. Remote tables have a limit of 1,000 rows.
ERP extraction tables
Extraction tables use an ETL process to extract large amounts of data from the ERP system at regular intervals and transform and save them to a Glide table.

Build your ERP model on a development or non-production instance. You must then promote your changes to a production instance when ready.
