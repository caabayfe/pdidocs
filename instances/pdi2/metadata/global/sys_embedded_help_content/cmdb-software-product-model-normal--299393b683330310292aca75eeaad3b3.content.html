Software Models

A software model is a profile of the software you have purchased, including information about the publisher, version, and discovery map. Create software models for all software to be monitored to tie software installations (discovered) with entitlements (purchased software and rights).

Use the Version condition and Edition condition fields to distinguish between the versions and editions of the software that you own. For example you may own different versions of Microsoft Office- Microsoft Office Professional 2010 and Microsoft Office Professional 2007. Similarly, you may own different editions- Microsoft Office Professional 2010 and Microsoft Standard 2010.

For any software model you create, you can specify whether the model is a parent (a suite) or child (a component). A software suite is a group of related products. For example, Microsoft Office 365 would be considered a suite. Each software that is included as part of that suite is considered a component. So, PowerPoint, Word, Excel, Outlook, and Access are components within the Microsoft Office 365 suite.
