Generate a knowledge article using Now Assist for IT Service Management (ITSM)

As an agent or knowledge writer, quickly generate knowledge articles from resolved and closed incidents within the Service Operations Workspace for ITSM application and classic environment by using the Now Assist application.

Before you begin

Role required: itil

Procedure

  1. Navigate to Workspaces > Service Operations Workspace.
  2. Open an incident that is assigned to you.
  3. Create knowledge.
    Note: For detailed information on how to create a knowledge article in Core UI or in Service Operations Workspace, see the documentation link in the Related topics section.
