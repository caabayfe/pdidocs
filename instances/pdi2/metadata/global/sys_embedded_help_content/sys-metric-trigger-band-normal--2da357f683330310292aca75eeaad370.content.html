Create a band trigger

Create a MetricBase band trigger that detects when a metric value falls within a range of values.

  1. On the form, fill in the fields.
    Table name
    Table in the MetricBase database that contains the metric that you want to monitor.
    Metric
    Table metric that you want to monitor that is specified by the Table name.
    Aggregator
    Aggregation value that you select. None means that you use the last value in the collection interval.
  2. Click Save.

In the MetricBase Band Trigger Levels table, add values that specify trigger parameters.
