Viewing all connections within SGC Central

You can view installed and draft connections that were added using Service Graph Connectors within SGC Central.

The following connection types are available for viewing:
Installed connections
The installed tab provides a list of installed connections. Selecting a connection from the Connection column reveals its details, including data sources, import schedules, and associated errors.
Draft connections
The Drafts tab provides a list of draft connections. After reviewing the drafts, complete the setup for each connection by selecting Configure to continue from the last configuration point or select Resume setup to initiate the setup of a single instance connector for the first time.
