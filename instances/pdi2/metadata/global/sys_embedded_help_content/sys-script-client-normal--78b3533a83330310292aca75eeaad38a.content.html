Create a client script

Create a client script to run JavaScript on the client (web browser) when client-based events occur, such as when a form loads, after form submission, or when a field changes value. Use client scripts to configure forms, form fields, and field values while the user is using the form.

  1. On the form, enter a name for the client script and then fill in the fields.
    Type
    Specifies when the client script runs.
    Field name
    Specifies the field to which the script applies if the script responds to a field value change. Field name is available if the script type is onChange or onCellEdit.
    Script
    Defines the client-side script to run.

    With Now Assist for code generation enabled, you can provide text or code prompts to return AI-generated code suggestions and create scripts quickly.

  2. Select Submit.
