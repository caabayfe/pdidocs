Bot process

A bot process is a predefined sequence of actions that a robot follows to accomplish a task or achieve a goal so that you don't have to do this work manually.

A bot process configuration is a record that contains the bot process settings. The bot process configuration record is mapped to a bot process record. It’s a one-to-one mapping.

Let's say that you have an Accounting System Update bot process. The associated robot logs in to your company's accounting system, such as SAP. The robot enters the extracted invoice data, which creates the entries for your accounts payable. The robot then attaches the original invoice to the accounting system for reference.

What you can do on this page

Create a bot process configuration record and then assign your assets to the record by selecting Create Configuration.

You can also associate a bot process configuration record with a bot process. Select the down arrow in the Create Configuration button and then select Assign Configuration.

For more information, see Create a bot process configuration record in RPA Hub and Associate a bot process to a bot process configuration record.
