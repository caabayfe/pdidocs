Create a TCO cost

Create a new entry for total cost of ownership record to evaluate the cost of your business applications.

Before you begin

Role required: admin

Procedure

  1. Select the expand row icon () next to TCO.
  2. Select All.
  3. Select New.
  4. Fill in the form fields.
  5. Select Save.
