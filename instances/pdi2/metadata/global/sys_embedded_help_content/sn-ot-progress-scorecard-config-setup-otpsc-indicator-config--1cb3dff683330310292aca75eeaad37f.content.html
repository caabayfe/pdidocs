[OPTIONAL] Configure indicator by threshold, weightage, and order

Role required: ot_progress_scorecard_editor or configure_industrial_workspace

To provide a better experience to configure the indicators, we will provide an OT Progress Scorecard table for customers to modify easily based on needs.

  1. Click Configure to open the OTPSC config table.
  2. Edit the low threshold of each indicator to modify the low threshold.
  3. Edit the high threshold of each indicator to modify the high threshold.
  4. Edit the weightage of each indicator that contributes to the overall score.
  5. Edit the order to rank the indicator from left to right by importance.
  6. If you do not need an indicator to be shown, set the indicator to Active = false.
