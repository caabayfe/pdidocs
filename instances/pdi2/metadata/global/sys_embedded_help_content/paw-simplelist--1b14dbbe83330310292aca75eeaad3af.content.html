List of records

When you click a value in a visualization of table data, you open a list of the table records that contribute to the value.

Select columns

Each table has a set of default columns that appear in the simple list. You can change the selected columns by opening the Settings list action and selecting Edit columns.

After you make changes in the Edit List window, select OK. The next time you edit the columns in this list, you see the option to Restore to column defaults. Select this button to reverse all previous changes.

Open individual records

By default, you have a Number column showing the record numbers for whichever table the list is showing. Clicking on a record number opens that record in a new tab. Similarly, clicking a value in any column that references records opens the record. For example, you have a simple list of Incident [incident] records that includes a column for Assignment Groups. Clicking a value in the Assignment Group column opens the record for that Assignment Group, even though that record is not an Incident record.

Export the list of records

Select Export to export the list to one of the following formats:
  • Excel
  • CSV
  • JSON
  • PDF

Select whether to download the export or send it as an email.
