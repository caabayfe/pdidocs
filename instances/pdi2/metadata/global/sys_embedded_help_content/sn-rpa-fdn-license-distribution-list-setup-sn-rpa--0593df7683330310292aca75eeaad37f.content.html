Robot license distribution in RPA Hub

Create a license distribution record in a top-down approach, starting with the top-level or primary domain.

If the instance you are using is domain separated, create a license distribution record in the top level or the primary domain. Do not create it in the global domain.

If the instance you are using is not domain separated, then the license distribution record is created in the global domain.

As an administrator, you can create only one license distribution record per domain.

A record in this table is necessary to create any robots in the instance, for each domain.

If you have more robots than the assigned licenses, then the instance or the specific domain (and its child domains) get locked up and the robots do not execute automations in the current and child domains.

Click New to create a license distribution record per domain.
