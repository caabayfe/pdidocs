Removal candidates

View a list of all removal candidates in this tab. Removal candidates are used to reclaim software installations that are not being used.

Select on a removal candidate record to view specific details.

You can also create new removal candidates.

You can reclaim rights for removal candidates individually or in bulk.
Note: Removal candidates need to be in a ready state to be reclaimed.

To reclaim all removal candidates displayed in the list view, select Reclaim All.

To reclaim an individual removal candidate, open the removal candidate record and select Reclaim in the Removal Candidate form view page.
