Creating a DocuSign integration profile

Create an integration profile to connect your DocuSign subscription to the NOW platform. View software usage information and optimize stale licenses.

Before you can save the integration profile, you will need to create an OAuth application in the DocuSign admin portal.

After you create your application, use the following information from DocuSign to update the integration profile.
  • Enter your integrator key in the Client Id field.
  • Enter your secret key in the Client secret field.
  • Enter your API account ID in the Technical account id field.

After you save the integration profile, click the Get OAuth Token related link to complete the connection.
