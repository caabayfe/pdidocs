Create translation and workflow preferences settings

Role required: localization_admin or localization_manager

Use this form to configure translation and workflow preferences settings for activated languages, to request machine translations or bulk translations.

  1. On the form, fill in the fields.
    Name
    Input a name for the setting.
    Artifact
    Select All Artifacts or an artifact of your choice.
    Languages
    Select the languages into which you want the articles translated.
  2. Select the Translation preferences tab.
  3. On the form, fill in the fields.
    Enable machine translate
    Click to enable machine translation service.
    Translator
    Select from available translators for machine translation.
    Enable TMS
    Click to enable Translation Management System (TMS).
    TMS
    Select from TMS services available for machine translation.
    Enable send via email
    Click to enable email service for content localization for selected languages.
    Email subflow
    Select from available subflows for your email.
    Default file format
    Select a file format to send and receive content.
    Default recipient(s) list
    Select email addresses through which content is sent to the translator.
    Enable export/import
    Click to enable export/import of content for translating selected languages.
    Default file format
    Select a file format to send and receive content.
  4. Select the Workflow preferences tab.
  5. On the form, fill in the fields.
    Workflow
    Select a workflow for the translation process.
    Business approver group
    Select from available business approver groups. This field appears when a workflow requiring business approvals is selected from the Workflow field.
    Localization fulfiller group
    Select from available localization fulfiller groups.
    Auto translation mode
    Select the auto-translation mode.
    Translation approver group
    Select from available translation approver groups. This field appears when a workflow requiring translation approvals is selected from the Workflow field.
  6. Select the Project preferences tab.
  7. On the form, fill in the fields.
    Enable projects
    Click to enable creation of localization projects.
    Enable auto creation
    Click to enable auto creation of localization projects.
    Localization manager group
    Select from available user groups.
  8. Click Submit.
