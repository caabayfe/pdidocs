CMDB success advisor for HAM dashboard

The CMDB success advisor for HAM dashboard enables Configuration Management Database (CMDB) administrators to identify and address data quality issues specific to HAM in the CMDB.

The CMDB success advisor for HAM dashboard provides clear, consolidated insights into hardware asset data quality and asset status. Use the dashboard to identify and resolve data quality issues within the CMDB through dedicated sections, filters, indicators, and visual reports. Gain valuable insights into CMDB performance related to HAM.

The dashboard data is filtered based on the Selected model categories and Date range filters.

Filters enable narrowing the data shown in graphs and metrics based on connector type, connection, data source, or date range.

Dashboard features

Targeted CMDB metrics focus remediation efforts. Regularly monitor these metrics and follow suggested remediation actions to systematically improve CMDB data quality over time.

Note: Select a segment or count on a chart to open the KPI Details page and analyze how specific metric trends over time. To learn more about the KPI Details feature, see KPI Details.
