Findings overview

Any assets that match your policy conditions are reported as 'Findings' and displayed in categories on the Findings list on this page in the workspace. These categories are provided as a way to organize the results on this page. They are not grouped and assigned for remediation in these lists.

Key terms

Findings are generated, grouped, prioritized and stored in records in the Configuration Compliance application. The Security Posture Control and Configuration Compliance applications use different terms to describe data and records. Refer to the following table for more information.

You configure findings from a policy record. When you configure findings, you can choose to automatically close any findings that pass your audits (policy conditions).
