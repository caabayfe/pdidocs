Embedded help qualifiers

The embedded help administrator can use qualifiers to customize content for a common page in the instance. The home.do page is opened for every Homepage module and for many Dashboard modules. The specified query parameters in the URL define which homepage to open. For example, the URL for the SLA homepage is home.do?sysparm_view=SLA, where sysparm_view=SLA is the query parameter. To create custom embedded help content for the SLA homepage, create a qualifier for the home.do page and the query parameter sysparm_view=SLA.

Identify pages you want custom help for that are used in many applications. Plan the qualifiers to use, for example sla-homepage. Create the qualifier, and then associate it with custom embedded help content that you write.
