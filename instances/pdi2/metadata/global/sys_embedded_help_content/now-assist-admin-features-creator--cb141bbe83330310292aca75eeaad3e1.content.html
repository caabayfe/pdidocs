Now Assist features for creator

The Now Assist features for Creator panel displays skill capabilities for the Creator workflow.

Each capability appears as a card, which displays the associated skills and whether they’re active on your instance. Select View details on any card to continue on your Now Assist Admin journey by turning on and configuring skills.

Consider your use cases for generative AI and explore the skill capabilities that best fit them. To learn more about different ways you can use Now Assist, check out our documentation.
