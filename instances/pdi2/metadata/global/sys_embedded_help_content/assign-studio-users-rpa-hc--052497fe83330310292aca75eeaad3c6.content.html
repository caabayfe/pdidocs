Add assigned studio users to an unattended robot

Assign one or more users (RPA developers or RPA admins) to an unattended robot, so that the users can access the specific robot in the Assigned Bot Process section of the RPA Desktop Design Studio application.

Before you begin

Familiarise yourself with the Assigned Bot Process feature in RPA Desktop Design Studio. For more information, see Assign bot process to an automation project.

Only users with the RPA developer or RPA admin roles can be associated to a robot.

Role required: sn_rpa_fdn.rpa_release_manager or sn_rpa_fdn.rpa_admin

Procedure

  1. On the Assigned Studio Users tab, select Add.
  2. On the Available Studio Users tab, select the required user.
  3. Select Add.
  4. Select Save.
