Manage incidents in Service Operations Workspace

Manage the incident workflow using various options on the incident record.

Before you begin

Role required: admin

About this task

You can manage the incident workflow and progress using various options. For example, copy and delete incidents. You can propose or promote the incident record as major incident.

If resolving the incident involves creating a record, you can create the record directly from the incident record. Such records can be about creating a problem, booking a walk-up appointment, and so on.

Procedure

Perform any of the following actions on the incident record page.
