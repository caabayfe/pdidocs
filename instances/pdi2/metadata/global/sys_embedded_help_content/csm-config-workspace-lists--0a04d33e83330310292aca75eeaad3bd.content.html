Lists in CSM Configurable Workspace

The List view provides access to different categories or groupings of records. Use these filtered lists to quickly access records such as cases, customer accounts, or knowledge articles.

Selecting the List icon displays the List view, which includes the following tabs.
Lists
Includes categories of records, such as Cases and Case Tasks, and filtered lists of the category record type. The system administrator creates the categories and filtered lists that appear in this tab.
My Lists
Includes a personalized set of record categories and filtered lists that you can create. Select +New list at the bottom of the tab, name your list, and select the desired table and filter conditions.

Selecting a filtered list in either tab displays the corresponding list of records.
