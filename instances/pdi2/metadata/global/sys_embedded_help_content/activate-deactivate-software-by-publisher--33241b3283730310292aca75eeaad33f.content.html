Activate or deactivate software by a publisher for exposure assessment

Activate or deactivate software by a publisher to stop delta processing of the software and remove it from the active list of software.

Before you begin

Role required: sn_vul_analyst.vul_event_manager

Procedure

  1. To deactivate, select the required active software by a publisher and select the Deactivate option under the Reassess button.
    The publisher is deactivated.
    Note: To activate the software by a publisher, follow the same process and select the Activate option.
  2. Refresh the page to view the updated status (false) in the Active column.
