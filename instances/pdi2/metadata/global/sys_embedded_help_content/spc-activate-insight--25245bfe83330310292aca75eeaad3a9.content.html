Create and activate a custom insight

You must activate insights so that you can view data in the visualizations that are displayed on the Home and Custom insights modules in the workspace.

Before you begin

Role required: SPC Admin Group and SPC Analyst Group

Procedure

  1. Select the pencil icon in the upper left of the record to edit the metadata.
  2. Fill in the Name and Short description fields.
  3. Select Save metadata.
  4. Select the type of visualization you want from the choice list for the Type field.
  5. Select Add policy to add the base policy.
    • Level 1 is the base. This policy queries an extensive sample size in (N), for example, all your assets in your Active Directory reported by the Active Directory service graph connector.
    • Level 2 evaluates the results of the first policy. This policy evaluates only a subset of (N). For example, from all the assets in your Active Directory, return only those assets with vulnerability assessment tools that are not scanned for vulnerabilities.
    • Level 3 evaluates the results of policies 1 and 2, and so on. For example, from all the assets in your Active Directory with vulnerability assessment tools that are not scanned for vulnerabilities, return only those missing endpoint protection agents.
    • Any policies that you use for custom insights must be activated prior to activating the custom insight.
  6. Select an insight label for your custom insight visualization.
    The label might depend on what type of graph you selected. For example, you might enter "Scanned" and "Not scanned" for a comparison chart that compares scanned assets with unscanned assets.
    A sample image of your visualization is displayed on the right side of the page.
  7. Add a second policy.
    This policy is a child policy that evaluates a subset of the results returned by the base policy.
  8. Select a label for your second policy.
    Your visualization results might be based on your first policy. For example, if you select a second policy for a custom insight that is based on a matched percentage of assets, the visualization is based on totals from policy one to find its results. For example, if policy 1 returns 100 assets, and the conditions of policy 2 refines that total to count 20 assets, the percentage of matched assets is 20% for the visualization.
  9. Continue to add policies and labels.
    The third policy evaluates the results of policies 1 and 2, and so on.
  10. When you are satisfied with your policies and visualization choices, select Save.
    The Inactive tab lists your saved and deactivated insights. To activate a record on this list, open it and select Activate. Your insight is displayed on the Custom insights dashboard module in this workspace.
