Discovery Manager

To create a schedule, you must have at least one validated MID Server, with a status of Up, that is capable of reaching the IP ranges you intend to discover. Make sure you configure MID Servers used for Cloud Discovery with the Cloud Management capability. To move between phases, click the desired tab. Completed phases display a solid, green line in the tab.
  1. In the Welcome screen, click Discover Cloud Resources.
  2. Select the name of your cloud provider and enter a unique and descriptive name for the schedule you want to create.
  3. Select the name of your service account and provide the appropriate credentials.
    You can add service accounts and credentials in the Discovery Manager.
  4. Click Test Account to validate the account.
    If validation is successful, Discovery finds any member (sub-accounts) and datacenters associated with the service account and displays them in selection lists.
  5. Select member accounts (sub-accounts) and datacenters to discover.
  6. Optionally, you can discover the virtual machines (VM) in your service account.
    Discovery automatically selects the IP addresses of the virtual machines in the datacenters you selected.
  7. Select the MID Server to use for VM discovery or let Discovery select one automatically.
  8. Advance to the scheduling phase and configure when and how often the schedule should run.
  9. Complete the configuration process by selecting one of these options:
    • Finish and Run: Runs Discovery immediately, using the current configuration. All subsequent cloud discoveries run at the time scheduled.
    • Finish: Exits the wizard and runs Cloud Discovery at the time scheduled.
  10. Check the results in the Discovery Home Page.
