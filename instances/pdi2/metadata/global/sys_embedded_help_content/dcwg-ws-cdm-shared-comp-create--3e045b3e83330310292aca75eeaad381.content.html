Create a shared component

Add or update a shared component in a component library.

Before you begin

Role required: cdm_editor or cdm_admin

Procedure

  1. In the component library record, select Edit to edit it in a new or an existing changeset.
  2. On the Config data tab of the library changeset record, select the more actions icon () for the components node and select Create shared component.
  3. In the Create shared component dialog box, enter a unique and meaningful name for the shared component, and select Create.
  4. Use the more actions icon next to the component node to add a component, CDI, or a file node.
    • To add a component, select the more actions icon and select Create component from the menu.
    • To add a CDI, select the more actions icon and select Create CDI.
    • To attach a file to the component, select the more actions icon and select Add file.
    • To rename the component, select the more actions icon and select Rename.
    • To delete the component, select the more actions icon and select Delete.
      Note: The options to rename and delete the component are available only if it isn’t being used in any application.
  5. Select Save to save all changes in the changeset.
  6. Select Commit to commit all changes made to the shared components.
    A new version of the updated shared components is created.
