Save a search

Save a useful search for future use.

Before you begin

Define a search before performing this procedure.

Role required: evt_mgmt_operator or evt_mgmt_admin

Procedure

  1. On the Log viewer, select Save As.
  2. In the Search name field, specify a unique and descriptive name for the search and then click Save.
    Note: The saved search includes any selected filters, but does not include time range settings.
