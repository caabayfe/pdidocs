Windows classification

The Windows classify probe uses WMI commands for all Windows machines. After the sensor processes the results of this probe, the system uses the Windows classification record to define the order, match the criteria, and launch the appropriate exploration probes.
  1. Complete the fields in the form, including these related lists:
    • Classification Criteria: Select the classification criteria, which includes a parameter, an operator, and a value.
    • Triggers probes: Specify the additional exploration probes that this classifier launches.
  2. Click Submit.
