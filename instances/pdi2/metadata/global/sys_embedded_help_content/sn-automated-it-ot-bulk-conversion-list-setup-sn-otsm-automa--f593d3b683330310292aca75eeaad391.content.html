Using Table

Role required: admin or cmdb_ot_admin

  1. Create a new scheduled job record with specific filter criteria to automatically convert IT records into OT devices by adding the OT entity details. This process requires the following.

    1. Source table and filter criteria to identify the right CIs in the Filter Criteria – OT Devices tab. The source table provided is Hardware and/or its extended classes.

    For example, if you want to add OT entity details for all computers that are imported into the system that have a prefix of COMP, select the source table ascmdb_ci_computer and then add the filter criteria as [Name][starts with][COMP], [Class][is][Computer] and [OT device details][is empty]. For more details, see Automatically convert your IT records to OT devices.

    2. Use the Preview button to verify the count of records that will be selected based on the filter condition. OT entity details will be added for these records.

    3. Provide OT-related metadata in the OT Entity Default Configuration tab. These are the default values which will be added the OT entity records.

  2. Once the schedule is defined, set a scheduled time using the Run field and set the schedule to Active.
    Note: Acknowledging that there are different ways of identifying the CIs for which OT entity records need to be created, here are some best practices to follow:
    • Make sure the index fields used are applicable as part of the filter criteria conditions. Ensure that the data set does not exceed 1M records to avoid performance related issues.
    • Make sure to create separate scheduled job definitions for separate CI classes to have filtering per CI level and define respective OT entity default values.
    • Make sure to always use the Class type filter to only query specific CI classes.
    • Use the Preview button to verify the records selected for further review.
    • Validate the data in the OT Entity Default Configuration tab. OT entity records are created using these default values.
