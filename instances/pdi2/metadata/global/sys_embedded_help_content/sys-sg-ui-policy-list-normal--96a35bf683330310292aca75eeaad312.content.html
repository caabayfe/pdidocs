Screen UI Policies list

Use this interface to manage mobile screen UI policies for your applet. UI policies define custom process flows for tasks.

A UI policy condition evaluates all fields even if they are not visible on the form. This function removes the requirement that a field must be on a form for it to be evaluated.

Name
Name of the screen UI policy.
Active
Whether the screen policy is currently applied.
Condition
Conditions that must be fulfilled to apply this screen UI policy.
Order
Order in which the mobile UI rule executes. If multiple rules affect the same element, the rules execute according to this value. Lower numbered rules execute before higher numbered rules.
Reverse If False
Indicates if the UI policy actions will reverse, if conditions in the UI policy are unmet.
Short Description
Brief summary of the screen UI policy.
Table
Table for the screen that modified by the UI policy.
