ERP system list details

Check the ERP (Enterprise Resource Planning) systems list to monitor and troubleshoot the connections to your ERP systems.

ERP system
Name of the ERP system.
ERP heartbeat
Indicates whether a ping to the ERP system connection is currently successful.
Latest heartbeat
Date and time that the ServiceNow AI Platform most recently connected to the ERP system.
Connection
Alias of the credentials for the connection. Select a value to open the saved connection and credentials.
Short description
Brief description of what the ERP system is used for. For example, sales orders or vendor invoices.
Remote tables
Number of remote tables in the ERP system.
ETL data sources
Number of ERP extraction sources in the ERP system.
