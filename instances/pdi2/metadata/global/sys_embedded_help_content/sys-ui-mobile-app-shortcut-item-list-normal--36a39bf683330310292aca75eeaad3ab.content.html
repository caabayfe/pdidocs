Mobile App Shortcut Items List

This UI details the list of shortcut items available for your instance. 3D Touch allows users to access shortcuts to items in an app with a hard press on the app. 3D Touch is only available on the iPhone 6s and newer.

Title
Name for the shortcut that appears in the 3D Touch menu. For example, Create new incident.
Subtitle
Optional secondary title for the shortcut that appears in the 3D Touch menu. For example, Create a new incident if there's a problem.
Icon
A visual indicator for the shortcut.
Order
The order in which shortcuts appear. Lower numbers appear in the list first. Configured shortcuts also appear before user favorites in the 3D Touch menu.
Module
Module that opens when a user taps the shortcut. The module must be configured to appear in a mobile device. For example, the create new incident module.
Active
Whether the shortcut is currently in use.
Roles
Limit the users who can access the 3D Touch menu item by role.
