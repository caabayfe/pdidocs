Reclamation rules

Reclamation rules are configured to specify a period or amount of time the software must be used, or date last used, before being flagged for reclamation.

Monthly usage details (last used, and total usage time) are imported to the Software Usage list for products being monitored through Microsoft SCCM.

A software product must have a product process, which consists of a filename, that is required for SCCM Usage to pull data.
