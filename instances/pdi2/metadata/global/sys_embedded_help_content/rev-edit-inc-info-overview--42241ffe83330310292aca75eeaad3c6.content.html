Review and edit information on the Overview tab

Review the incident information on the Overview tab of the incident record and edit, if required.

Before you begin

Role required: itil

Procedure

  1. Add or edit the Short Description and Description of the incident by clicking the edit summary icon () on the Summary field.
  2. On the Compose section, add or edit the comments by clicking the Comments tab.
  3. On the Compose section, add or edit work notes related to the incident by clicking the Work notes (Private) tab.
  4. Add or edit the reason for the incident by clicking the edit cause icon () on the Cause section.
  5. Review the associated CIs on Affected CI.
  6. Optional: Add additional CIs by clicking Add.
  7. Click Save.
