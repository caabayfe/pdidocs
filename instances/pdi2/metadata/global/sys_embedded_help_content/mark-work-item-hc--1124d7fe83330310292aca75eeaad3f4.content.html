Mark a work item as complete from the Work Items tab

Mark a work item as complete from the Work Items tab to manage your work items more efficiently.

Before you begin

Create a queue. For more information, see Create a queue in RPA Hub.

Role required: sn_rpa_fdn.rpa_developer, sn_rpa_fdn.rpa_business_user, sn_rpa_fdn.rpa_support_user, or sn_rpa_fdn.rpa_admin

About this task

There are two ways to perform this task. One way is from the Work Items tab. Another way is by selecting a work item and then marking it as complete from the form header options.

Procedure

  1. On the Work Items tab, select one or more work items.
  2. If the work item is complete, in the form header, select Mark as Complete.
  3. In the Remarks field, enter a comment for marking the work item as complete.
  4. Select Mark as complete.
    The status of the work item changes to Success.
