Assign Group tasks

Onboard groups by assigning them tasks.

Before you begin

Role required: sn_devops.admin

Procedure

  1. Select Group tasks.
  2. From the Group tasks page, select Assign task. If you want to assign the task to yourself, select Assign to me.
  3. Select the task from the Task list.
    For example, create an application or connect a tool.
  4. Select the group from the list.
    Only groups whose roles allow them to perform the task are available in the list.
  5. Enter a due date and add your comments for the task if required.
  6. Select Done.
