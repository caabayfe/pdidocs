Creating a GitHub Enterprise Server Integration

Create an integration profile to connect your GitHub Enterprise Server applications with the ServiceNow AI Platform. Use this integration to view software usage information and optimize stale licenses.

Important: Before you can save and publish the integration profile, you will need to generate a personal access token that grants access to the GitHub Enterprise Server APIs. Use this personal access token to create a connection between your GitHub Enterprise Server applications and your ServiceNow instance so that you can retrieve user data from each application.
Important: If you want to use a MID Server for communication between your ServiceNow instance and your GitHub Enterprise Server applications, you will need to set up a MID Server on your instance before you can create a GitHub Enterprise Server connection and integration profile.
