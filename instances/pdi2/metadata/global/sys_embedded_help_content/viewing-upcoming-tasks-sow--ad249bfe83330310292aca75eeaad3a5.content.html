Reviewing upcoming tasks

In the Upcoming section, you are reminded of the upcoming tasks for the same day and next day. If there is single record for the task type, it opens the record. If there are multiple records for the task type, it opens a list of all records in a new tab.

If you are an agent using the Workforce Optimization for ITSM Service Operations Workspace, you can see links to your upcoming tasks at a glance in the Upcomingsection. The Today tab shows tasks that you may want to attend to on the current day and the Tomorrow tab shows tasks coming up the day after the current day. You can select the link to access the task.
