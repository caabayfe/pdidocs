Creating a Roadmunk integration profile

Create an integration profile to connect your Roadmunk applications with the ServiceNow AI Platform. Use this integration to view software usage information and optimize stale licenses.

Important: Before you can save and publish the integration profile, you will need to generate an API access token that authorizes access to the Roadmunk GraphQL API. You must also create a connection between your Roadmunk applications and your ServiceNow instance so that you can retrieve user data from your applications.

The integration profile uses the Roadmunk Download Subscriptions and Roadmunk Update User Activity subflows to retrieve user data from your Roadmunk applications. You can select the date and time that you want to analyze user activity from in the Analyze user activity from field on the Calculate Activity Subflow tab. You can start analyzing data from the current date or from up to 60 days prior.
