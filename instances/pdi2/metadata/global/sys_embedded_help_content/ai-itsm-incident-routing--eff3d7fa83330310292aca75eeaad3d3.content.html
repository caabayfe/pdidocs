Incident routing

Incident routing helps with identifying the right user group or user who is skilled to work on an incident.

Incident routing can be configured by defining conditions and triggers to auto-assign cases and trigger relevant subflows. You can also use the Incident routing configuration agent that provides conversational & simplified experience for incident routing configurations.
