Deflection Configurations list

This list details the deflection configurations available to your instance. These configurations associate periods of time with activity contexts, which define how long a system waits for a case to be created to match a deflection pattern.

Name
Unique identifier for the deflection configuration.
Activity context
Type of activities for which you want to collect data. For more information, see Configure activity contexts for Self-Service Analytics.
Description
Summary of the configuration.
Window
Activity context window (duration) for tracking activities that match a deflection pattern.
