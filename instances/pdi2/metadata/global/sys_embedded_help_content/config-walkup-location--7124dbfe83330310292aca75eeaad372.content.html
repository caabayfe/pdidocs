Configure a walk-up location

Configure a walk-up location to manage the walk-up interactions, schedules, and appointment bookings.

Before you begin

Role required: sn_walkup.walkup_technician, sn_walkup.walkup_admin, sn_walkup.walkup_manager

Note: If you have the sn_walkup.walkup_technician role, you can only modify the Enable away state option and specify the Away message field.

Procedure

  1. Select the walk-up location that you want to configure.
  2. On the Details tab, fill in the fields.
  3. Click the Related records tab.
    The Related records tab displays all the entity records associated with the walk-up location grouped under the related list. The related lists include Interaction, Walk-up Appointments, Reason of visit and so on.
  4. Click each related list to view the list of entity records.
    For example, click the Interactions related list to view the list of interactions associated with the walk-up location.
  5. On each related list, you can use the following options.
  6. Click Save.
