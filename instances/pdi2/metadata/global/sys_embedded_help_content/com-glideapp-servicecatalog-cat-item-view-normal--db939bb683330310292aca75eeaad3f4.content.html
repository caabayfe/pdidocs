Configure an agent's maximum universal capacity

Role required: admin

Prevent an agent from being assigned too many work items by configuring the agent's maximum universal capacity.

  1. On the form, fill in the fields.
    Max Universal Capacity
    Maximum capacity for an agent across all service channels. If an agent's current capacity equals the maximum universal capacity, additional work items will not be assigned to the agent.
    Users
    The max universal capacity will be assigned to the users (agents) in the Selected list. Select agents in the Available list and then select the right-pointing arrow to add them to the Selected list. To filter the agents in the Available list, create a new filter by selecting Add Filter or run an existing filter by selecting Run Filter.
  2. Select Submit.
