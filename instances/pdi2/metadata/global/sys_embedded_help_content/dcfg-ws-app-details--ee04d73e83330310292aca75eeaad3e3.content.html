View application

View all application details including snapshots, config data, policy mapping and exceptions, and changesets.

Overview

Overview details for the application further identify the service. The CSDM application model (name, owner, manufacturer) functions as the link between DevOps features. There is an SDLC component of the CDM for each CSDM application model.

You can also click Manage deployables to create and manage the deployables for your application, and their connections to services.

Snapshots

List of snapshots for all deployables for the application. Click a snapshot to view its details, including config data and validation results.

Config data

Tree containing all of the config data for the application relating its deployables, collections, and components. You can click an entry in the tree to view specific configuration details.

Settings

List of mapped policies and policy exceptions for the application.
  • Click a policy to view it in the Admin view, or click its input to view the mapping details.
  • Click an exception to view request and request response information.

Activity

List of changesets for the application. Click a changeset to view its details including config data and activity changes.
