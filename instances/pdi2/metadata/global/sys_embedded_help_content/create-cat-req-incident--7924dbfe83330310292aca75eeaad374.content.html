Create a catalog request from an incident

Create a catalog request to initiate a catalog request flow from an incident. You can create a request and associate the request with the incident to help track requests associated with the incident and vice versa.

Before you begin

Role required: itil

Procedure

  1. Navigate to All > Workspace Experience > Service Operations Workspace.
  2. Initiate a catalog request from an incident.
  3. Select Order Now.
    By default, the value in the Request for field is set to the person who called in the incident.
  4. Optional: On the Order Confirmation page, specify the shipping address in the Delivery Information field.
  5. Optional: On the Order Confirmation page, provide any additional information in the Special Instructions field.
  6. Select Checkout.
    The request is created and associated with the parent incident.
  7. Select Close.
  8. Optional: View the created request by selecting View Details.
