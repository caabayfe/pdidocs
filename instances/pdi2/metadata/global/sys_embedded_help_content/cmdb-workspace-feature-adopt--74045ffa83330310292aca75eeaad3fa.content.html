CMDB feature adoption

The CMDB feature adoption tile shows the adoption rate of the following broad CMDB feature categories.

  • Data ingestion: Features and tools that enable importing data into the CMDB: Service Graph Connectors, IntegrationHub ETL, and Identification and Reconciliation Engine (IRE).
  • Data governance: Shows the level of usage of CMDB Data Manager for governing CI life cycles. This includes usage of the Retire, Delete, Archive, and Attestation policies.
  • Search & analytics: Features and tools that you can use to gain insight into the health of your CMDB and the usage of your CMDB data. These include CMDB Data Foundations dashboard, CMDB 360, CMDB Health, CMDB Query Builder, and Intelligent Search.

Each adoption rate is a percentage based on the adoption level of one or more of the features within the category. A different criterion is used to determine adoption level of each CMDB feature and tool.

If you haven't installed, activated, or used a CMDB feature, the associated card shows Not Installed, and you can instead access the following additional resources through the CMDB Insights view:
  • Learn more to review documentation of the feature.
  • View demo to watch a demo of the feature or tool.
  • Install app to install the feature from the ServiceNow Store.
  • Get started to directly access the feature or tool and begin using it.

As you review the CMDB Insights view, consider implementing any features that can help you better use the CMDB.
