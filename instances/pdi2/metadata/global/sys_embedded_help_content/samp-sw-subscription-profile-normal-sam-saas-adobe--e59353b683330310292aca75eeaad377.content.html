Adobe Cloud integration

Create an integration profile to connect your Adobe subscription to the NOW platform. Download subscription information that is compared with software installations for compliance.

To set up an Adobe integration, you must have a valid digital signing certificate consisting of a public key and a private key. You can either create a self-signed certificate manually or purchase one from a Certificate Authority. The public key (PEM format) is used in the Adobe Console to obtain client credentials, and the private key (PKS format) is used for Software Asset Management integration in your ServiceNow instance.

Create and validate a ServiceNow X.509 certificate using the private key.

Before you can save the Adobe integration profile on your ServiceNow instance, you will need to create an integration on the Adobe I/O Console.

After you create the integration, use the following information from the Adobe I/O Console to update the integration profile.
  • Client ID
  • Client secret
  • Organization ID
  • Technical account ID

After you save the integration profile, click the Validate Adobe Credential related link to complete the connection.
