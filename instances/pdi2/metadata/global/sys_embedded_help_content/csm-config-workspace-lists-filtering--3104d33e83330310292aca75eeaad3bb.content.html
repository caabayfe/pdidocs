Filter records in a list

After selecting a filtered list in the List view, you can continue filtering the records to easily find the record you want.

Select a filtered list to display the corresponding list of records. From this list, you can filter records in two different ways:
  • Using the more actions menu next to the field name.
  • Using the Filter panel.

Filter records using the more actions menu

  1. Point the mouse to a field name at the top of the list and click the more actions icon ().
  2. Depending on the type of field, the Filter section provides different options.

Filter records using the Filter panel

  1. Select the filter icon () at the top of the list to display the Filter panel.
  2. Select Advanced view.
  3. Build a filter by adding conditions that contain a field, operator, and values.
  4. Optionally, click or or and to add more conditions.
  5. Click Update to run the filter for the list.

To remove a filter condition from the filter panel, click the X next to the condition.
