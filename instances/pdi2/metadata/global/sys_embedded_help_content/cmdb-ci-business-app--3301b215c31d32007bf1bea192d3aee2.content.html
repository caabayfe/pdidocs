Create, modify, or delete a business application

  • To create or modify a business application:
    1. Enter or modify the business application Name .
    2. Select or modify the Business process from the list.
    3. Select or modify the Portfolio from the list.
    4. Select or modify the Application type from the list.
    5. Select or modify the Architecture type from the list.
    6. Select or modify the Install type from the list.
    7. Select or modify the Application strategy from the list.
    8. Optionally edit the Application URL .
    9. Select or modify the Status from the list.
    10. Select or modify the Application scoring profile from the list.
    11. Select or modify the Application category from the list.
    12. Select or modify the Application family from the list.
    13. Select or modify the Technology stack from the list.
    14. Select or modify the User base from the list.
    15. Select or modify the Platform from the list.
    16. Select or modify the Last change applied date from the calendar.
    17. Enter or modify the Description .
    18. Click the Software Model tab.
    19. Select or modify the Software model from the list.
    20. Select or modify the Last change applied date from the calendar.
    21. Enter or modify the Version .
    22. Select or modify the GA release date from the calendar.
    23. Enter or modify the Age .
    24. Select or modify the Manufacturer from the list.
    25. Select or modify the Next version from the list.
    26. Select or modify the End of life date from the calendar.
    27. Click the Contract tab.
    28. Select or modify the Vendor from the list.
    29. Select or modify the Support vendor from the list.
    30. Select or modify the Contract end date from the calendar.
    31. Click the Owners tab.
    32. Select or modify the Portfolio manager from the list.
    33. Select or modify the Business owner from the list.
    34. Select or modify the IT Application owner from the list.
    35. Enter or modify the Last updated by field.
    36. Click the Compliance tab.
    37. Select or modify the Business criticality from the list.
    38. Select or modify the Emergency tier from the list.
    39. Select or modify the Data classification from the list.
    40. Select or deselect the Certified check box.
    41. Click Submit or Update to save.
  • To delete a business application, click Delete .
