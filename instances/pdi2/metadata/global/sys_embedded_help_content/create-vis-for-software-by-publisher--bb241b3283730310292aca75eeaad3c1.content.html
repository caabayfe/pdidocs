Create VITs for software by publisher

Create vulnerable items (VITs) from the Exposure Assessment page to analyze the list of VITs and recommend solutions and patches that can help the IT team to patch the vulnerabilities.

Before you begin

Role required: sn_vul_analyst.vul_event_manager

Procedure

  1. Select the records for which you want to create VITs.
  2. Select the Create Vulnerable Items option.
  3. In the Create vulnerable items dialog box, select from:
    • Existing vulnerability
    • New vulnerability
  4. Select the Create Vulnerable Items option.
