Stockroom details

You can view detailed information about the stockrooms that your enterprise, hardware, consumable, bundle, loaner, and other assets reside in.

Use the following tabs to view and manage your enterprise asset stockroom:
  • Details: Get a detailed overview of the stockroom, including open stockroom tasks and general stockroom details.
  • Task Timeline: View the timeline of all stockroom tasks.
  • Hardware: Create and view the hardware assets that reside in the stockroom.
    Note: This tab appears only if you have installed and activated the Hardware Asset Management application.
  • Enterprise Assets: Create and view the enterprise assets that reside in the stockroom.
  • Consumables: Create and view the consumable assets that reside in the stockroom.
  • Bundles: Create and view the asset bundles that reside in the stockroom.
    Note: This tab appears only if you have installed and activated the Hardware Asset Management application.
  • Pallets: Create and view the pallet assets that reside in the stockroom.
  • Software Licenses: Create and view the software licenses that reside in the stockroom.
    Note: This tab appears only if you have installed and activated the Hardware Asset Management application.
  • Other Assets: Create and view all other types of assets that reside in the stockroom.
    Note: This tab appears only if you have installed and activated the Hardware Asset Management application.
  • Hardware Loaner Pool: View all hardware loaner assets that reside in the stockroom.
    Note: This tab appears only if you have installed and activated the Hardware Asset Management application.
  • Enterprise Loaner Pool: View all enterprise loaner assets that reside in the stockroom.
  • Service Locations: View all service locations that are supported by the stockroom.
  • Distribution Channel: Create and view the list and ranking of all linked stockrooms that you can source and transfer enterprise assets between.
  • Hardware Asset Audits: Create and view audits for your hardware asset inventory.
    Note: This tab appears only if you have installed and activated the Hardware Asset Management application.
  • Enterprise Asset Audits: Create and view audits for your enterprise asset inventory.
