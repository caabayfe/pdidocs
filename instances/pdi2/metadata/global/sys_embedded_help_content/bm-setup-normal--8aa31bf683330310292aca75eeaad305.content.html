Enable a benchmark KPI

Role required: admin

You must opt in to the Benchmarks application to enable a benchmark KPI. To opt in, read the Opt-In Agreement, select the check box to accept, and click Opt-In.

Once you have opted in, enable a benchmark KPI.

  1. To enable or disable a KPI, select the KPI slider.
  2. Optional: Select the pencil icon next to a KPI to view more information about the KPI, including the description, conditions, and table from which the data is collected.
  3. Select Save.
    Allow one to two months for aggregate monthly data to accurately reflect changes made to KPI status.
    Note: In some environments, resolved incident KPIs may require further configuration to retrieve resolved incident data.
