Mobile app theme list

Use this list to track themes, which customize your mobile applications' appearance so that your customers and employees can recognize your unique company identity.

Name
Descriptive name for your theme.
Palette
Palette property names. The palette field consists of six properties. Each property has a name and a color value in hexadecimal format. For details on how to use these properties in your mobile applications, see the Mobile theme color guidelines.
