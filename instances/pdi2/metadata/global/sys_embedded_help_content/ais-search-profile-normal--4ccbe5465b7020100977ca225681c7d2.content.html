Configuration

Search Sources:

Search Sources reflect the content to be searchable in Search Profiles, including internal and external content, each Search Source is configured based on an Indexed Source with filter conditions.

Synonyms:

There are multiple ways of saying the same thing. For example: One user might search for "vacation" and another might search for "holiday". Both expect the same search result.Synonyms allow us to search for similar words and provide a natural experience to the end user.

Stop Words:

Stop words are words the search engine will ignore – words like "the", "a", "an" that are highly frequent will be ignored so they don't affect relevancy score.

Typo Handling:

AI Search can autocorrect typos based on content in its index. The Typo Handling section allows customers to fine tune the autocorrect experience.

Genius Results:

Genius Result cards will show users the best answer for their questions. We currently support: People Search, Q&A, Catalog Item. In this section customers can customize the out-of-the-box configuration and fine tune the Genius Results.

Result Improvement Rules:

While we have a self-learning system powered by AI, in some cases customers may want to control what content will be promoted or blocked from the search results for specific queries. Results improvement allow customers to define what content to promote and what content to block when the user runs a certain query.
