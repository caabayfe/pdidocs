Configure Exception Management for Vulnerability Response

By default, an exception is requested using Exception Management in the Vulnerability Response application. Use questionnaires to help you define specific time periods for exceptions and add false positives from the requestor. Role required: sn_vul.vulnerability.admin.

If you add a questionnaire, it is sent to the person raising the exception or false positive request. You can either use the default questionnaire or create one based on your requirements.

  1. Review the following key terms and field descriptions to help you edit the questionnaire.
    Enable questionnaire to mark false positive
    Select this option to permit the questionnaire request that remediation tasks (VUL) or vulnerable items (VI) are marked as false positives. For example, if a configuration item has been decommissioned, but the scanner is still raising an issue related to it, it might be marked as a false positive.
    Enable questionnaire to request exception
    Select this option to permit the questionnaire settings to request an exception to defer the remediation for remediation tasks or vulnerable items.
  2. Make any additional changes.
  3. Click Save.

After an exception rule is approved, a remediation task (VUL) is created in a Deferred state by default. Starting from the Valid from date you entered for it, the exception rule runs on all the VIs that are created, in addition to any that are moved from the Closed to the Open states.
