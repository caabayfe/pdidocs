Add or remove items in a personal portfolio

The second step to editing a personal portfolio is to add or remove items.

Before you begin

Role required: sn_dpm.dpm_manager

Procedure

  1. Remove items from your portfolio.
    1. Select View items in your portfolio.
    2. Select the items that you want to remove.
    3. Click Remove.
  2. In the Search field, enter the first few letters of a service, a service offering, or a business application to add.
  3. Select the items that you want to add.
    The Add Items options are grouped by Business Applications, Service/Service Offerings, and Application Services. Use the page advancement option when there are multiple pages to select from.
  4. After you select the items to add, select the appropriate add option.
    • Add selected Business Applications
    • Add selected Services/Service Offerings
    • Add selected Application Services
  5. Select Next.
