Add enterprise assets to a move order

After you create a move order, add the enterprise assets that you want to include in that order.

Before you begin

Role required: sn_eam.enterprise_asset_manager

Procedure

  1. On your move order record, select the Enterprise move lines tab.
  2. Select Add.
    The Add assets dialog box opens.
  3. In the dialog box, select the check box for every enterprise asset that you want to include in the move order.

    You can select from any of the enterprise assets that reside in the location specified in the From location field of the move order.

    Note: If you select an enterprise asset that contains any child assets, all child assets are also included in the move order.
  4. Select Add.

Result

The selected enterprise assets are added to the move order.
