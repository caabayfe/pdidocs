Create a new incident profile for Microsoft DLP integration

Create an incident profile in your  ServiceNow AI Platform instance to retrieve the data from the Microsoft Purview and add the data into the ServiceNow DLP IR incident table. Configure the Now platform to retrieve the events from the Microsoft Purview. Store these events on the DLP IR Incident table on your ServiceNow instance.

  1. In the Incident Profile page, click New.
  2. On the form, fill in the fields.
  3. Click Continue.
  4. In the Filtering section, select the Filter based on conditions option.
  5. Using the lists and fields of the condition builder, set the filters in the Filter Conditions field.
  6. Click Continue and move to the Match Content Configuration section.
  7. In the Match Content Configuration section form, fill in the fields.
  8. Click Continue and move to the Scheduling section.
  9. In the Scheduling section, set a schedule to retrieve data and ingest incidents that match the criteria in the profile.
  10. On the form, fill in the fields.
  11. To save the created profile configuration, click Finish.
  12. To activate the profile, open the created profile and select the Active option.
  13. Click Update.
