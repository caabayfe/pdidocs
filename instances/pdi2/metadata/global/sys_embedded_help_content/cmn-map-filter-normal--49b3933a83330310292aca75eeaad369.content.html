Create a map page filter

Configure a map data item before accomplishing this task.

Role required: admin.

Use this form to create a map filter, which enables you to see only the map markers for the data that you want. Map filters can be configured using lists and forms, or scripting. Create a container for your map filters first, configure filter items, and then choose a Map Page for your filter.

  1. On the form, fill in the fields.
    Name
    Enter a name for the map filter.
    Application
    Define the application scope, if other than Global.
  2. Click the menu icon, and select Save.
  3. In the Map filter item field, double-click the record and click the search icon ().
  4. Select a map filter item from the list, or click New to create a new map page filter item.

Continue to the next task to configure a map filter data mapping.
