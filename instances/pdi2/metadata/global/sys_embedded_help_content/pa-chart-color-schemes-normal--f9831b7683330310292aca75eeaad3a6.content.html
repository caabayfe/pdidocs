Create a chart color scheme

Role required: pa_power_user or pa_admin

Create a reusable set of colors available for reports, Performance Analytics widgets, and Platform Analytics data visualization components.
  1. Select colors in the Color 1 and Color 2 fields.
    A color scheme must have at least two colors. You can use more.
  2. Optional: Select up to 32 total colors to include in the color scheme.
  3. Click Submit.
