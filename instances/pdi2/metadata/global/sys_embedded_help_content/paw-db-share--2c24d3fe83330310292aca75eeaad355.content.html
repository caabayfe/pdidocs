Share a dashboard

Share with other users, groups, or roles to create a single view of data that you can use to collaborate.

Before you begin

Role required: You can share any dashboard that you created. You can share dashboards that have been shared with you, if sharing is allowed. If a dashboard is shared with you as a viewer and sharing is allowed, the people you share it with can only view it; they cannot edit it. Users with the admin or dashboard_admin role can share all dashboards.

Procedure

  1. In the context menu, select Share.
  2. Enter the names of one or more users, groups, or roles you want to share the dashboard with as a viewer.
  3. To allow the people you share the dashboard with also to share the dashboard, select Allow sharing.
  4. Select one of the following options.
    When you add a user, group, or role as a viewer, they can only share the dashboard with others as viewers. When you add a user, group, or role as an editor, they can share the dashboard with others as viewers or as editors.
  5. Select Confirm.

What to do next

To view who the dashboard has been shared with and which workspaces contain the dashboard, open the dashboard details.
