Create Discovery range sets

A range set is a collection of IP ranges of different types that define a network or network segment for Discovery to query. A range set can contain one or more of these types:
  • IP Address List
  • IP Address Range
  • IP Network
  1. Give this range set a unique name.
  2. Optionally, select an Overriding behavior for this range set.
    This setting overrides the Discovery behavior configured for your MID Servers.
  3. Click New in the Discovery IP Ranges related list to create the different types of IP ranges contained in this range set.
