Create a script action

Use script actions to create server-side scripts that perform a variety of tasks, such as modifying a configuration item (CI), or managing failed login attempts. Script actions are triggered by events only.

  1. On the form, enter a name and fill in the fields.
    Event name
    Select the event to use for this script. If you don’t find an event for your script action that suits your purpose, you can create one.
    Execution order
    The order in which the script is executed.
    Condition script
    Create a statement for a condition under which this script should execute.
    Script
    Create a script that runs when the condition you define evaluates to true.

    With Now Assist for code generation enabled, you can provide text or code prompts to return AI-generated code suggestions and create scripts quickly.

  2. Select Submit.
