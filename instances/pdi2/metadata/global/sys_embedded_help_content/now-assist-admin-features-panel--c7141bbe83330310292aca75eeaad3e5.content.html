Now Assist admin features

The Now Assist Admin console Features panel allows you to explore the skills available on your instance with your installed plugins.

Plugins are categorized into workflows that appear on the left edge of the panel. Select a workflow to see cards representing collections of skills called capabilities.

If there are multiple products for the workflow, you can filter by product using the Select product list, and see only capabilities related to that product.

To see more information on the capability, and to enable and configure skills, select the View Details button on that card.

Note: If there are no plugins installed in a workflow, you instead see a prompt to install the related plugins.
