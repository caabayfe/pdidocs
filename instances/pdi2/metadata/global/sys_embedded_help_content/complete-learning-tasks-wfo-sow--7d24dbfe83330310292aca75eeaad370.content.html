Complete learning tasks using Service Operations Workspace

Enhance your skills set by completing learning tasks from internal or external learning content.

Before you begin

Role required: sn_wfo_cfg_itsm.employee

Procedure

  1. Select the My Learningtab.
    You can view the details of the path and course items that you are working on.​
    • Select the Active tab to view all tasks that you have not yet started or the ones that are in progress.
      • The tasks also highlight which tasks are due on the current day, due soon, or are overdue.
      • The most recently created tasks are highlighted as New.
      • You can view and filter tasks that you've self-enrolled or the ones that were assigned to you.
    • Select the Completed tab to view the list of tasks sorted by the date they were completed.
  2. Select a learning task.
    • If the task is associated with a learning path, you can select the task and view details of the task such as the path description, the path objective, skill associated with that task, and the task progress. You can select a task that's in progress and complete it.
    • If the task is associated with a course item, you can view the course description and the skills associated with the course item.
  3. Select a learning task.
