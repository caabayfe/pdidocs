Schedule view - Capabilities

The Schedule view provides you with a calendar view of all the locations and the reservations created on them during that current week.

The schedule view displays all the locations of the building that you selected using the location filter. If you selected a floor, only the locations on that floor of the building are displayed.

As a reservation planner, you can perform the following actions on the schedule view:
  • Drag a reservation to another date and time to reschedule.
  • Select open a reservation from schedule view directly. The reservation details are displayed and furthermore you can also:
    • Open the reservation to view or modify any reservation details.
    • View the reservation details on the side panel using the Show reservation details option.
  • Using the side panel, you can
    • View reservation details
    • Change the timing or location of the reservation.
    • Cancel a reservation
    • Open a reservation and make advanced changes and also add services
