Hardware Vulnerability Assessment roles required for users

Roles required: admin or user_admin

  1. Assign the sn_vul.manage_exposure_assessment role to admin users  or user groups, which enables them to view or edit properties for Hardware Vulnerability Assessment.
  2. Assign the sn_otvr.vul_event_manager role to Hardware Vulnerability Analyst users  or user groups, which enables them to view and perform assessments related to hardware vulnerability assessment.
  3. Click Save.
