Remediate VIs with a vulnerable item record

Use vulnerable item (VIT) records to view your remediation progress.

Before you begin

Review the vulnerability information to help you resolve and close vulnerable items that are assigned to you.

Procedure

  1. From an open remediation task, click a record (VIT) to open it.
  2. Click a related item link to view more vulnerability information.
    Overview
    View details that include the state, the remediation target date, Risk rating, the associated vulnerability, affected CI, and initial detection the state of the task record, and your remediation progress.
    Details
    View the preferred and potential solutions that you can use to fix this vulnerability. Open a record to see details such as associated Common Vulnerabilities and Exposures (CVEs) and links to solutions.
    Detections
    View the detection data imported from your scanners.
    Impacted Services
    View the services impacted by the vulnerability.
    Remediation Tasks
    View the other remediation tasks associated with this vulnerable item.
    State Change Approvals
    View the existing change requests and state and approval additional information.
    More Actions menu
    At the upper right, next to the UI actions, click the see More Actions menu (three horizontal dots).
    Activity stream
    View the Work notes for this record
  3. Use the UI actions at the top right of the record to help you close vulnerable items.

    When all the VIs in a remediation task are closed, the remediation task is closed.

    When a VI is closed that is associated with multiple remediation tasks, the closed state rolls up to any remediation tasks that have that VI.
