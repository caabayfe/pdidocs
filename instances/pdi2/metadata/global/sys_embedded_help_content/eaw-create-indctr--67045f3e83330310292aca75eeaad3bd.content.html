Create an application indicator

Create an application indicator to assess the applications across dimensions such as cost, quality, technical risk, investments, user satisfaction, and business value.

Before you begin

Role required: sn_apm.apm_admin

Procedure

  1. Select Indicators.
  2. Select New.
  3. On the form, fill in the fields.

    For field information, see .

  4. Select Save.
