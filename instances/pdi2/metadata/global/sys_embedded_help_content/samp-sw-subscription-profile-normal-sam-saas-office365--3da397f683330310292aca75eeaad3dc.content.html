Microsoft Office 365 integration

Create an integration profile to connect your Microsoft Office 365 subscription to the NOW platform. Download subscription information that is compared with software installations for compliance.

Before you can save the integration profile, you will need to register an application in the Microsoft Azure portal.

After you register your application, use the following information from the Microsoft portal to update the integration profile.
  • Enter your application ID in the Client Id field.
  • Enter your tenant ID in the Tenant name or Id field.

After you save the integration profile, open the OAuth application record and update the Client Secret field with the client secret you received in the Microsoft portal.

Open the REST message record and click the Get OAuth Token related link to complete the connection.
