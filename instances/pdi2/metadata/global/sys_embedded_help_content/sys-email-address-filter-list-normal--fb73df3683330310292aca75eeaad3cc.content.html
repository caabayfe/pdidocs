Email address filter

System address filters control who can communicate with your instance via email. You can improve email security by filtering domains and email addresses that you find suspicious.

Name
Name of the address filter.
Type
  • Allow List: Allow all specified domains. All other domains are disallowed.
  • Deny List: Disallow all specified domains. All domains that do not match the denied list domains are allowed.
