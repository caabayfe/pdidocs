Create a linear predictor trigger

Create a MetricBase linear predictor trigger to detect when a metric is likely to cross a specified threshold within a specified period of time.

  1. On the form, fill in the fields.
    Table name
    Table in the MetricBase database that contains the metric that you want to monitor.
    Metric
    Table metric that you want to monitor that is specified by the Table name.
    Window
    Length of time used to calculate the line that predicts the future course of the value.
    Confidence level
    Percentage that specifies how tolerant you are of the real data fitting the linear prediction of the data.
    Trend
    Direction of the trend: upward or downward.
    Threshold
    Target value that the metric is expected to reach before the trigger executes.
  2. Click Save.

In the MetricBase Linear Predictor Trigger Levels table, add values that specify trigger parameters.
