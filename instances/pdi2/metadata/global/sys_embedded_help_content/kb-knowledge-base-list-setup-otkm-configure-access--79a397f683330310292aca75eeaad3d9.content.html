Configure access to knowledge bases for unauthenticated users

Role required: knowledge_admin or admin

Review knowledge bases accessible to unauthenticated users based on the user criteria and glide.knowman.block_access_with_no_user_criteria property settings. If you want to restrict unauthenticated users for a knowledge base, you can use user criteria or set the glide.knowman.block_access_with_no_user_criteria system property to true.

For additional information, see the following topics:
  • Review access to OT knowledge bases for unauthenticated users
  • Knowledge Management properties
  • Managing access to knowledge bases and knowledge articles
  1. Select an available knowledge base.
  2. Configure its user criteria settings as needed.
  3. Click Update.
