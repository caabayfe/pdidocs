Translation Management System configurations list

This list shows details of the configurations available to the Translation Management System (TMS) for your instance. These configurations are combined with third-party translation systems to localize artifacts.

Name
Identifier of the TMS configuration.
Request translation subflow
IntegrationHub subflow that interacts with the third-party translation management system to request translations.
Receive translation subflow
IntegrationHub subflow that interacts with the third-party translation management system to retrieve translated content.
Application
Scope of the application. The default value is Global.
Version
Version of the contract used in subflows. The default value is v1.
Enable auto retrieval
Boolean value showing whether translated content is received automatically.
