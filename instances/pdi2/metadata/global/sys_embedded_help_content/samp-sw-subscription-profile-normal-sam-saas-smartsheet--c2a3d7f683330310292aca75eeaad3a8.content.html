Creating a Smartsheet integration

Create an integration profile to connect your Smartsheet application with the ServiceNow AI Platform. Use this integration to view software usage information and optimize stale licenses.

Important: Before you can save and publish the integration profile, you will need to create an API access token in Smartsheet. You can use this API access token to authenticate Smartsheet API requests from your ServiceNow instance.
To enable your Smartsheet application to connect with the ServiceNow AI Platform, you must configure the connection and credential information for the application using the connection & credential aliases record associated with your integration profile. To open this record, click the preview icon next to the Connection & Credential field and then click Open Record. When the record opens, click the Create New Connection & Credential related link and then enter the following information:
Name
Name of the connection. For example, Smartsheet Connection.
API Key
API key for your Smartsheet application. Enter an API key in the Bearer <api-access-token> format, where <api-access-token> is the API access token that you created in Smartsheet.
