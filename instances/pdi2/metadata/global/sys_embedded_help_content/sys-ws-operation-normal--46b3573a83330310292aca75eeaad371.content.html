Create a scripted REST resource

Create a scripted REST API resource to define the HTTP method to execute, the processing script, and any override settings from the parent API. You can define one or more resources per API. A scripted REST API resource is equivalent to a REST endpoint.

  1. On the form, enter a name and then fill in the fields.
    HTTP method
    Specifies the HTTP method this resource implements, such as GET.
    Script
    Defines how the operation parses and responds to requests.

    With Now Assist for code generation enabled, you can provide text or code prompts to return AI-generated code suggestions and create scripts quickly.

  2. Select Submit.
