Review and Confirm

Perform the reconciliation.
  1. Review the summary of the expected updates for this duplicate CIs reconciliation. Updates are based on the selections and therefore the summary includes only the details that are applicable. This summary can include details of the relationships and related items that will be merged to the main CI, the attribute values that the main CI will be set with, and the number of CIs that will be deleted.
  2. Select Attributes, Relationships, Related Items, or Duplicate CI Actions if applicable, to display further details such as changes to attribute values.
  3. Click Back to modify any setting.
  4. Select Remediate to complete the reconciliation according to your reconciliation settings.
