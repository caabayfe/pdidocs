Create user criteria

Role required: user_criteria_admin
Note: To create a user criteria record from the Knowledge module, you must have the user_criteria_admin role in addition to the knowledge role. For more information about access, see Managing access to knowledge bases and knowledge articles.

Create a user criteria record to determine the users who can read or contribute to an OT knowledge base.

  1. Click New.
  2. On the User Criteria form, fill in the fields.
    For more information about the User Criteria form fields, see the User Criteria form.
  3. Click Submit.
