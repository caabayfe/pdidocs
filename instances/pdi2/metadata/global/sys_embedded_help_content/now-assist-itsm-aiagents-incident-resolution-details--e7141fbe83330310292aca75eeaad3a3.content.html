Incident resolution details AI agent

Using Incident resolution details AI agent, generate resolution notes and select resolution code. After you approve, the resolution notes and codes are added to the incident record when incident is resolved. You can also update duplicate incident information to the incident record if the selected resolution code is Duplicate.

Important: By default, all agentic workflow and AI agent records are read only.

To run the AI agents autonomously, you must first duplicate the agentic workflow, and then proceed with the following steps:

  • Activate the agentic workflow.
  • Activate all agents within the agentic workflow.
  • Activate the trigger to invoke the agentic workflow automatically. If you prefer to invoke it manually, activating the trigger isn’t necessary.
Important: In the Define availability screen for the AI agent, make sure that the Status field is enabled to activate the AI agent.
Using Incident resolution details AI agent:
  1. Generate resolution notes (root cause and resolution steps) based on the work notes and comments in the activity stream of the incident record. After you approve, the resolution code is added to the incident record.
  2. Select the resolution code from the available resolution codes. After selection, the resolution code is added to the incident record.
  3. Update duplicate incident information to the incident record when the resolution code is Duplicate.

In the Incident resolution details AI agent screen, review all information and settings for the AI agent.
