Create or modify email digest intervals

Admins can create or modify the email digest intervals (length of time) during which activity for a selected notification is accumulated in an email digest. Users select a digest interval when they enable an email digest in their notification preferences.

  1. On the form, fill in the fields.
    Name
    Interval name that describes the interval length of time, for example: Every 2 hours.
    Interval
    Length of the interval, either number of Days or Hours (hours, minutes, and seconds). The minimum time length allowed is one hour, and the maximum time length allowed is seven days (one week).
  2. Click Submit or, if you changed an interval, click Update.
  3. To delete an interval, select the interval to be deleted in the Digest Intervals [sys_email_digest_interval] table and click Delete.
    Note: If the interval is in use, the system does not remove the interval.
