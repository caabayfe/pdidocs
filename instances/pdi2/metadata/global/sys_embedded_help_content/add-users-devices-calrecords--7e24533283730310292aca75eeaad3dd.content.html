Add users or devices to your CAL records

To assign the associated CALs to specific users or devices, add those users or devices to your client access record based on the CAL type that you selected in the Type field.

Before you begin

Role required: sam_admin.

About this task

By assigning CALs to specific users or devices, you can prevent those users or devices from being counted multiple times across different client access records during reconciliation.

Procedure

  1. Assign CALs to specific users or devices, to prevent those users or devices from being counted multiple times across different client access records during reconciliation.
    • If you set the Type field to User CAL or User/Device CAL, add the users that you want to assign your User CALs to.
      Note: If you are using a Citrix software model and User/Device CAL type, add the users that you want to assign a user/device license to.
      1. Select the Users tab and then click New.

        The Create New Client Access User Breakdown form opens in a new tab.

      2. In the User field, search for and select a user that you want to assign a User CAL to.

        The Active, User Type, and Source fields populate automatically for the specified user. However, you can modify the Active and User type fields as needed.

      3. Select Save.
      4. Close the form to return to your client access record.
      5. Repeat steps a-d for each user that you want to assign a User CAL to.
    • If you set the Type field to Device CAL or User/Device CAL, add the devices that you want to assign your Device CALs to.
      Note: If you are using a Citrix software model and User/Device CAL type, add the devices that you want to assign a user/device license to.
      1. Select the Devices tab and then click New.

        The Create New Client Access Device Breakdown form opens in a new tab.

      2. In the Device field, search for and select a device that you want to assign a Device CAL to.

        The Active and Source fields populate automatically for the specified device. However, you can modify the Active field as needed.

      3. Click Save.
      4. Close the form to return to your client access record.
      5. Repeat steps a-d for each device that you want to assign a Device CAL to.
  2. To track and license the configuration items (CIs) that the associated server is installed on, add them to the client access record.
    Important: This step is applicable only if you have not enabled the License all installs accessed by clients option on the associated software model. If this option is enabled, CIs are licensed based on conditions that you specify on the software model, such as software install conditions.

    Software Asset Management supports CAL licensing in conjunction with installation-based licensing. If a server deployment requires both CALs and installation-based licenses, Software Asset Management can account for both license types during reconciliation. For example, four users are accessing a server that is installed on two CIs. The corresponding software entitlement must include four User CALs to grant all four users access to the server and two installation-based licenses to enable both CIs to run the associated server.

    You must add CIs to the client access record when licensing is required for both server installations and the users or devices that are accessing the server. Only the CIs that are added to the client access record are licensed to run the server.

    1. Select the Devices with Installations tab and then select New.
      The Create New Client Access Installed Device form opens in a new tab.
    2. In the Device field, search for and select a CI that the associated server is installed on.
      The Active field populates automatically for the specified CI. However, you can modify this field as needed.
    3. Select Save.
    4. Close the form to return to your client access record.
    5. Repeat steps a-d for each CI that the associated server is installed on.
