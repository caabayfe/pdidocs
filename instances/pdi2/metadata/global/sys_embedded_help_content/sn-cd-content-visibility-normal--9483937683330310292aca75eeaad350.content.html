Table 1. Content Delivery - Schedule Content
FieldDescription
ContentThe content or information made available to employees.

Content is created from Portal Content, or Notification Content.

PageFilters widget instances for the page you select.

Select a page and only the widget instances that appear on the page and are available in the Widget instance choice list.

Widget instanceThe service portal widget instance. A widget instance is a reference to a widget that contains a location, properties, and CSS specific to that instance.

When you select a page from the Page choice list, a list of widget instances are filtered.
