Monitoring records with watch topics

The watch topics included with the application filter imported vulnerabilities based on specific criteria that might be of interest to you. Click the related list tabs on each watch topic to view and monitor related vulnerability data and vulnerability types. When you're ready to create a list of remediation tasks to IT to fix vulnerabilities, create a remediation effort.

About imported data

Data for the dashboards and visualizations displayed on this page are gathered nightly. If you change the filtering for a topic, you might notice a delay before current data are displayed.

Monitor records

Click the related list links on each watch topic to view more vulnerability information:

Overview
View the number of active records as it changes over time. See the number of records that are already in existing remediation efforts as well as a list of remediation efforts.
Impacted CIs
See the number of your distinct configuration items (assets) impacted by these vulnerabilities, as well as a breakdown of the types of records.
Distinct Vulnerabilities
See active records that have known exploits, PCI (Payment Card Industry) data, and the number of distinct vulnerabilities on your assets.
Vulnerable Items
See the list of all vulnerable items.
Distinct Configuration Tests
See number of active test results that are categorised by criticality and number of distinct configuration tests on your assets.
Note: This tab is available only for the watch topics in Configuration Test Results module.
Configuration Test Results
See the list of configuration test results associated with the watch topic.
Note: This tab is available only for the watch topics in Configuration Test Results module.
