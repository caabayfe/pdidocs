Assign a learning path to agents

Assign a learning path to one of more agents and add a due date for them to complete the path.

Before you begin

Role required: sn_wfo_cfg_itsm.manager

Procedure

  1. Select the Learning tab.
  2. Select Learning learning paths > All learning paths.
  3. Select the Assign icon () for the path you want to assign to agents.
    The Assign icon is only available when the path is in Published state.
  4. In the Assign learning path screen, assign the learning path to groups or team members.
    1. If the agents have to complete the path within a given date, select the Mandatory check box.
    2. In the Due date field, select the date by which they need to complete the path.
    3. Select Assign.
    You can see the progress your agents have made as they work on a path.
