Create a portal knowledge base

Role required: admin.

Use this form to create a new portal knowledge base, to enables users to view knowledge articles from the mobile app.

  1. On the form, fill in the fields.
    Active
    Whether the entry is currently in use with your applet.
    Portal
    Portal associated with the applet. Select Mobile Employee Service Portal.
    Knowledge Base
    Knowledge base associated with the applet. If no knowledge bases are selected, users can view articles from all knowledge bases in the system. By default, the app uses the IT knowledge base.
    Order
    Number that indicates the order that the configurations should run. If there are multiple configurations on a portal, the system runs the configurations from the lowest to the highest order that you selected.
  2. Optional: Change the default knowledge base that is associated with the Now Mobile app.
    1. In the Portal field, open the record withMobile Employee Service Portal.
    2. In the Knowledge Base field, select the knowledge base that you would like to associate with the app.
    3. Click Update.
  3. Click Submit.
Users can select the icon on the applet launcher page to open the quick action.
