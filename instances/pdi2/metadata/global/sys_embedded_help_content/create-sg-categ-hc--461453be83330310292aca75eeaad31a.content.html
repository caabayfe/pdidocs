Create a success goal category for hardware assets

Create a success goal category for adding the category to the Hardware Asset Management success goal.

Before you begin

Role required: ham_admin

Procedure

  1. On the Success Goal Category form, fill in the category that you want to add and select the Hardware asset category check box.
  2. Select Save.

Result

The category that you add gets listed as an option in the Category field while creating a success goal for Hardware Asset Management.
