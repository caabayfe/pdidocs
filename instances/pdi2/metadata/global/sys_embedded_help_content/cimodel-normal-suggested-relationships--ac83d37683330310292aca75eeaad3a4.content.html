Suggested Relationships

Role required: itil_admin
Displays suggested relationships for a class in a diagram format. Lets you add suggested relationships which are then available when you use suggested relationships to add a new relationship to a CI of that class. You can select a suggested relationship and edit or delete it. Use the filter to display only inbound, outbound, or specific relationship types.
  1. Click New.
  2. In the Add Suggested Relationship dialog box, select a Relationship and a Target Class for the relationship. This Class and the Target Class become parent or child in the suggested relationship, based on your selection of the Relationship.
  3. Click Save.
