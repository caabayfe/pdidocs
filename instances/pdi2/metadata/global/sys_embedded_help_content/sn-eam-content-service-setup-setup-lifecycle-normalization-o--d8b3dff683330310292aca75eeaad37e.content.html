Enable Normalization opt-in for OT Obsolescence Management

Role required: sn_eam.enterprise_admin or admin

Select all Enterprise Model Data Opt-in options that enables ServiceNow to collect firmware details of Operational Technology (OT) devices.

  1. Select Yes.
  2. Enable the toggle button for:
    • Enterprise Models
    • Enterprise Model Lifecycles
    • Custom Enterprise Product Models
    • Firmware Discovery Models
    • Firmware Model Lifecycles
    • Custom Firmware Models

    Expand each Enterprise Model Data Opt-in options to view their purpose and details.
