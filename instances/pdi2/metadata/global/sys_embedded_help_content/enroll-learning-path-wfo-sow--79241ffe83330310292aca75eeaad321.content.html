Enroll in Learning in Service Operations Workspace

When you enroll in a learning course or learning path, the application creates a learning task. You can track the progress of the course or path using the learning task.

Before you begin

Role required: sn_wfo_cfg_itsm.employee

Procedure

  1. Select the Learning icon .
  2. Select the Discover tab.
  3. Select a course or a path in which you'd like to enroll.
  4. Select Enroll.
