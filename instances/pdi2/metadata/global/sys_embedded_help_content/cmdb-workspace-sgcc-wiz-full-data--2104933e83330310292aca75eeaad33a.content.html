Service Graph Connector for Wiz full data retrieval

Retrieve full data periodically by setting the Reset Last Run Datetime for SG-Wiz as active.

To set the Reset Last Run Datetime for SG-Wiz as active, select the Active check box, then fill in the run schedule and time details.
Note: When active, the script clears the Last Run Date Time field value in a data source, ensuring that the SG-Wiz Organization scheduled job retrieves all Wiz-related data sources periodically.

To skip this step, select Skip for the Enable full data retrieval activity.
