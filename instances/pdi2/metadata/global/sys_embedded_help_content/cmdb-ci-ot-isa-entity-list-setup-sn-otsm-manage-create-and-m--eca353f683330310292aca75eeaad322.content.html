Create and manage

Roles required: admin

  1. To create an Equipment Model manually, create a top level entity with no parent, known as a site entity in the ISA model.
    1. Create a new record.
    2. Leave the Parent field blank.
    3. Add a short code.
    4. If you have configured a template, assign the template to be used by this equipment model for this site.
  2. To add equipment model entities to an existing model:
    1. Open the equipment model entity you wish to add children to.
    2. Click the Child Entities related list tab.
    3. Click New.
    4. Fill in the form.
      If a Template has been assigned to this Equipment Model, the Level is required.
    5. Additional children levels can be added by repeating the previous steps.
