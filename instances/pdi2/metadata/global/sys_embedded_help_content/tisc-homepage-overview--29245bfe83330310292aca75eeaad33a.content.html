TISC Homepage

TISC homepage which is the landing page or dashboards helps you to visualize the threat intelligence related data.

The homepage view consists of two sections where you can view the data that is coming from various sources such as observables, indicators, and data feeds.

This application enables you to do these tasks:
  • View Feeds Overview: The widgets on this section provides insights to the data that is ingested from various sources and also the sources that configured for data ingestion process.
  • View Trending Threats: The widgets on this section provides insights to the data on the trending threats.
