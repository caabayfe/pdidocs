Viewing the details of your bot process

After you create a bot process, you can add some details for your bot process, such as information about the credential groups, business applications, and more.

What you can do on this page

Depending on what you selected for the Process Type field on the Bot Process Configuration form, you can add the following related details to the bot process:
  • Business applications. For more information, see Business applications.
  • Attended users/groups. For more information, see Attended users or groups.
  • Credential groups. For more information, see Create a credential group in RPA Hub.
  • Assigned robots. For more information, see Robots.
  • Process robot credentials. For more information, see Process robot credentials.
  • Schedules. For more information, see Schedules.
  • Process parameters. For more information, see Process parameters.
  • Queues. For more information, see Queues.
  • Override skills. For more information, see Override a skill version for a bot process in RPA Hub.
  • Process jobs. For more information, see Process Jobs.

You can also enable the robot pool option on the Bot Process form. For more information, see Enable robot pool for a bot process in RPA Hub.

You can also migrate the bot process configuration and associated assets to another instance. For more information, see Migrating the bot process configuration in RPA Hub.
