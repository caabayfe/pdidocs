Dashboards

Dashboards help share meaningful information about your business. Add widgets that you regularly use to a dashboard, then share that dashboard with other users.

Every ServiceNow instance uses either responsive or non-responsive dashboards. Use the following options in the header to work in the dashboard:
Context menu (hamburger icon)
Create, delete, and duplicate a responsive dashboard; view dashboard properties; launch dependency assessment; and reset filters.
Card view icon (a grid of four small squares)
Open the (responsive) Dashboards Overview.
Dashboard picker (drop down list)
Search for and open a different dashboard.
Plus icon (+)
Add content to the open dashboard.
Sharing icon
Share a responsive dashboard with groups, users, and roles.
Configuration icon
Add a tab, change the layout, and apply a background color to a responsive dashboard.

On breakdown dashboards, you can filter Performance Analytics widgets on one or more breakdown elements. On any responsive dashboard, you can add interactive filters to filter reports on table data.

The Admin Console enables administrators to manage widgets and dashboards; diagnose and resolve errors; view usage analytics; modify configuration settings; and access ServiceNow help.
