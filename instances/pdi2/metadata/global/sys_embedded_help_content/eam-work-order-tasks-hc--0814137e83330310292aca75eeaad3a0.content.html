Work order task details

View details for the work order task that you must perform to complete an Enterprise Asset Management work order.

Use the following tabs to view and manage your work order task:
  • Details: View details for your work order task.
  • Depends on: Create and view upstream task dependencies for your work order task.
  • Dependents: Create and view downstream task dependencies for your work order task.
  • Checklist items: Create and view checklist items for your work order task.
  • Part Requirements: Create and view asset or part requirements for your work order task.
  • Requested Items: Create and view requested assets or parts for your work order task.
  • Pick Up Asset Tasks: View pick up tasks for the enterprise asset that is associated with your work order task.
  • Asset Usages: Indicate what actions you are taking on the assets or parts that are required for your work order task.
  • Attached Knowledge: View attached knowledge articles that are related to your work order task.
