Create a data policy for a mandatory field

If the Data Policy Rules related list is already displayed, skip to the last step.

  1. To create a new policy rule:
    1. Select the Use as UI Policy on client option and any other options that cater to your business needs.
    2. Click the context menu () and select Save .
    The Data Policy Rules related list is displayed.
  2. Click New in the Data Policy Rules related list to create the policy rule for a mandatory field.
