Email accounts

Email accounts store the connection details and credentials the system uses to access external email servers and services. By default, instances come with email accounts for ServiceNow - managed SMTP and POP3 servers to send and receive email. These accounts cannot be modified, but can be deactivated if you don’t want to use them.

Name
Name of the email account.
Type
Type of mail server.
Server
Remote server to which this account connects.
Port
TCP port connection.
