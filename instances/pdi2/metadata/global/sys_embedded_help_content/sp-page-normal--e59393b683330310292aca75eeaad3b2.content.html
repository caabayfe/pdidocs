Create a portal page

Create a portal page that you can design using CSS and layouts that organize widgets on the page. You can also create a page using the Page Designer.

  1. On the form, enter an internal title and a unique ID for the page and then fill in the following fields.
    Page Specific CSS
    Page-specific CSS that overrides the portal's theme and branding.
    Dynamic page title
    Dynamic page variables that generate descriptive titles depending on the content loaded into a page.
    Use SEO script
    Option to enable a script include that adds SEO tags for canonical URLs and hreflang tags. If selected, specify the script include to use in the SEO script field.
    Human readable url structure
    Keywords to include in the page URL to improve search engine optimization (SEO) and click through rates for public pages. Keywords can be populated using static content or dynamic page variables.
  2. Select Submit.
