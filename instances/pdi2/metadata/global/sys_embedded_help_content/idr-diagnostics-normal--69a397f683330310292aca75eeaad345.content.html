IDR diagnostics

Check the status of the key management service (KMS) and certificate management service (CMS), and verify the connection to the message queue system (MQS).

  1. On the form, select the Local or Remote configuration.
  2. Select one or more of the following:
    • Key Management Service

      Verify the KMS is enabled.

    • Certificate Management Service

      Verify the CMS is enabled.

    • Message Queue System

      Verify the system can read and write messages to the MQS.

  3. Click Run Diagnostics.

Review the diagnostic test results. If the MQS write test succeeds but the read test fails, there may be an issue with the replicator. Contact Support for help.
