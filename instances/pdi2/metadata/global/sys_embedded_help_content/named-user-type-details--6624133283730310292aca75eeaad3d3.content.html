SAP named user type details

You can view details for a specific named user type record that is used with your SAP entitlement.

View details such as the name, the default price list, value associated with the named user type, priority of the named user type during reconciliation.

View the roles mapped to the named user type in the SAP Roles tab. Mapping roles to a named user type helps in optimizing your SAP licenses.

View the SAP transaction codes actively used by your SAP users in the SAP Transaction Codes tab. You can also create a new transaction code by selecting New.
