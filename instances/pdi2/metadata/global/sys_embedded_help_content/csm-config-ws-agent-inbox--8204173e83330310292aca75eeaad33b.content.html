Using the agent inbox

Use the agent inbox to manage your incoming work items, such as cases and chats, and to set your current status.

Work items appear as cards in the agent inbox and can include information about the customer and issue.

From the agent inbox, you can monitor work items, accept or reject work items such as cases and chat requests, or route work items to other agents.

Accepting a case opens the case record. Accepting a chat opens an interaction record that captures the conversation and the work done during the chat session. During a chat session, you can:
  • Add attachments using the Action toolbar.
  • Add another agent to the chat.
  • Transfer the chat to another agent or queue.
  • Create a case from the interaction record.
From the agent inbox, you can also indicate your availability.
  • Set your status to Available when you are ready to accept work items.
  • Set your status to Away or Offline when you are not available to assist customers so that no new work items are assigned to you.
