Manage content for a campaign

Table 1. Content Automation - Content
  
ContentThe link, banner, video link, calendar, email, or other content for the campaign bundle.
Note: You can select existing content. To create content, go to Content Delivery.
PageFilters widget instances for the page you select.

Optional.

Select a page and only the widget instances that appear on the page are available in the Widget instance choice list.

Widget instanceThe service portal widget instance. A widget instance is a reference to a widget that contains properties and CSS specific to that instance.

When you select a page from the Page choice list, the list of widget instances are filtered.

Refine audienceNarrows your audience selected at the campaign level.

Selecting an existing audience creates a subset of the original audience.

Campaign bundleThe campaign bundle the content is associated with.
