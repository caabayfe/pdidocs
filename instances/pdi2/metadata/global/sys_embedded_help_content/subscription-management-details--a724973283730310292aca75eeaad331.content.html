Viewing product subscription details

View subscription details to match a product subscription to your product order form and monitor usage over time.

Meter type

Determine how a subscription is measured and what it's used for by viewing the meter type field on the details page.
  • Entitlements for users with Fulfiller-type access are tracked through a per-user subscription with a Fulfiller meter type.
  • Entitlements for users who have fewer access rights than Fulfiller users are tracked through a per-user subscription with a Business stakeholder meter type.
  • Entitlements for users with the now.assist.creator role are tracked through a per-user subscription with a Creator User meter type.
  • The creation and retention of platform objects such as custom tables is tracked through a capacity subscription with a Capacity meter type.

Allocation summary

View a real-time summary of your subscription allocation in the Allocation summary chart. If an allocation is nearing capacity, consider reducing the number of allocated subscriptions or purchasing more subscriptions.

Account-level allocations

View a summary of Creator Plus allocations across all of your instances. If the account-level allocation is nearing capacity, consider reducing the number of allocated subscriptions or purchasing more subscriptions.

Allocation history

Track the rate of subscription allocations over time in the Allocation history chart. Prepare for future purchases or plan for changes according to the allocation trends.

Custom table usage

Track the rate of custom table usage on your instance over time in the Custom tables chart. Anticipate when to increase your custom table allotment by monitoring the number of available custom tables month-to-month.

Insights

Identify when subscriptions are over-allocated and view actions you can take to maximize subscription usage by viewing important insights in Subscription Management.

  • Address over-allocated subscriptions by removing groups, removing roles, removing users from groups, or purchasing more subscriptions
  • Allocate available subscriptions by adding one or more groups with relevant roles to a subscription

Adding groups

Maximize subscription usage and grant entitlements to the right users by allocating subscriptions. You allocate per-user subscriptions by adding one or more groups to a product subscription. Subscription Management helps you with the allocation process by recommending groups based on their assigned roles.

Subscription details

For per-user subscriptions, view details about additional entitlements included with a product subscription.

Subscribed groups
View the groups you've added to a subscription. View the total number of users who belong to each group in the Users column.

View the total number of active users in the Active users column. The count of active users excludes those who haven't logged into the instance in the last 365 days, those assigned Web service access only, or those with an empty User ID.

Only active users count toward the subscription allocation totals that appear throughout Subscription Management.

Subscribed users
View each active user who belongs to the subscribed groups. Only active users with allocated subscriptions appear in this list.
Bundled items
View entitlements for custom tables, portal visits, and transactions. You can view the quantity you've purchased, the quantity you've allocated, and the current allocation status.
Custom tables
View the custom tables included with the product subscription. For each table, you can view the associated application and application scope.
Subscription applications
View the applications included with the product subscription.
  • View related plugins and associated roles by selecting an application.
  • Determine whether an application is available to install from the current product subscription by checking the Installation status column.

For capacity subscriptions, view the capacity definition record by selecting the product subscription name.
