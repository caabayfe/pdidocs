Copy Attachment action

Copies an attachment from the Attachments [sys_attachment] table to a target record.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Attachment
Data type: Record

Reference to attachment from the Attachments [sys_attachment] table.

Target Record
Data type: Record

Reference to record to add attachment.

Table
Data type: Table Name

Table containing the target record.

Outputs

This action has no outputs.
