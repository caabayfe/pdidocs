OT Discovery Schedules

Create a schedule using a MID server that can reach the target IP range(s) of your OT network.

Select the Purdue Level to be assigned to all OT devices discovered with this schedule.

Create OT Schedule with Equipment Model

When an Equipment Model is used, add Sites and Equipment Model Entities to Discovery Schedules to align OT Devices with sites and production processes.

Create or edit an OT Discovery Schedule and add the appropriate:

  • Site - the site where the OT Device is located
  • Equipment Model Entity - for example, the area or production process that the OT Devices on this network automate
