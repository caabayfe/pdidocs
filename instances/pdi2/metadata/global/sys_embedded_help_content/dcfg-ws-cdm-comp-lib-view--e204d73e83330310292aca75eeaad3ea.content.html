View a component library

View details of a component library, including its shared components, config data, and components usage in applications.

  • The Details tab shows the basic details of the library and a list of applications using its shared components.
  • The Components tab provides a list of all shared components within the library.
  • The Config data tab shows the configuration data of shared components in the library in a tree view. Select a component to see its config data items (CDIs) in the Script or List view.
  • The Activity tab lists all committed and open changesets.
  • The Requests tab lists all requests for adding components to the component library. The tab is available only when there’s at least one open request. You can review the component and approve the request to add the component to the library.

View a list of all CDM applications using components from this library.

Select Edit to open the library in a new or an existing open changeset.
