Smartphone Map Page Module List

This list details the smartphone map page modules available for your instance. A module links directly to a Google Maps page to assist users with travel navigation.

Name
Title of the module.
Order
Specifies the order of the module within the application menu. For example, an entry of 100 would place this module before one with an Order entry of 200.
Application menu
The application menu where you want this module to appear. By default, this field displays the application menu that you opened to create the module.
Table
Table associated with the module.
Updated
Displays the date and time when the module record is updated.
Roles
Roles permitted to access this module. If this field is blank, all roles can access the module.
Active
Whether the module is ready for use. Only active modules appear in the application menu.
Filter
Filter condition associated with the module.
Path
The sys_id of the map page. For example: map/c86c5feac0a80a6600706f0102968196.
