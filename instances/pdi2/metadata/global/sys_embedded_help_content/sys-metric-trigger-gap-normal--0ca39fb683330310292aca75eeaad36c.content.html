Create a gap trigger

Create a MetricBase gap trigger to alert you when MetricBase stops receiving data.

  1. On the form, fill in the fields.
    Name
    Name of the trigger.
    Table name
    Table in the MetricBase database that contains the metric that you want to monitor.
    Metric
    Value the trigger monitors in the MetricBase database.
  2. Click Save.

In the MetricBase Gap Trigger Levels table, add values that specify trigger parameters.
