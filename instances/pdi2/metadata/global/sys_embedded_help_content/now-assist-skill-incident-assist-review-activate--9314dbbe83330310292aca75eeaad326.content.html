Incident assist: Review and activate

Review the settings for the incident assist skill and then activate the skill for use in the Now Assist panel.

Review the settings on this page and select Activate to complete the configuration. To make a change, select Back and make the changes for the topics or display settings.

After you have activated the skill, you can make changes to these settings at any time by returning to the feature page and selecting Edit on the incident assist skill.
