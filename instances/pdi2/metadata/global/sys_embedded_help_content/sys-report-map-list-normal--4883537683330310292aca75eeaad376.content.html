Report Maps list

Map objects define the different levels that users can drill down into on a map report and the data displayed on these levels. Admins can create and manage these objects. This list contains all the maps in your instance.

Click the column headers to search, sort, filter, and edit data.

Click New to create a new report map.

The Report Maps list has the following important columns:

Key
Shows the ISO 3166 code for countries and their subdivisions. Click the value in the key to edit the map object.
Name
The name of the map object.
Level
Indicates the subdivision of the map object. Level 1 is World. Level 2 can indicate a continent, a region, or a country.
Parent
The map object one level up from the selected object. The parent-child relationships define drill levels in a map hierarchy.
Geographical map
Boolean value. Non-geographical maps include objects such as floor plans.
Active
Indicates if a map object is active in your instance. If false, the map is unavailable when creating map reports.
