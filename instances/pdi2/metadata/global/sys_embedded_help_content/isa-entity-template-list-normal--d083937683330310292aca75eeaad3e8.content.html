Equipment Model Templates

To create a new Equipment Model Template:

Create a Template

  1. Create a new Equipment Model Template record and submit it

Create Template Levels

  1. Edit the Equipment Model Template Template record you want to define levels
  2. Create new template levels by clicking the "new" button on the Template Level related list
  3. If the Template Level is not the top level, add the parent record
  4. Use the Order column to define the hierarchy levels for sorting (smallest number is the highest level)

Create Template Level Types

  1. Edit the Template level that you want to define Level Types for
  2. On the Template Level Type related list, click the new button
  3. Create a Level type name and submit
