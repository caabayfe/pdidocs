Software entitlements

Use this form to manually create software entitlements, Microsoft Software Assurance (SA), or maintenance entitlements.

If you enter a publisher part number, the software model, the metric group, the agreement type, and software lifecycle data (if it exists) automatically appears in the software entitlement form.

You can view the downgrade rights for the software entitlement, the history of all maintenance entitlements that you have purchased till date, manage license keys, and view the history of the newly upgraded software model related to your entitlement.
