Create custom named user type

Create a custom named user type record to be used with your SAP entitlements. The named user type record allows users to track licenses that are specific to their SAP systems.

Before you begin

Note: Custom named user types that are created on your ServiceNow instance using the SAP publisher pack are not reflected in your SAP system. You must make the same changes in your SAP system.

Role required: sam_admin

Procedure

  1. On the Create New Custom Named User Type page, fill in the details.
  2. Select Save.
    The named user type record is created and appears in the SAP named user types list.
