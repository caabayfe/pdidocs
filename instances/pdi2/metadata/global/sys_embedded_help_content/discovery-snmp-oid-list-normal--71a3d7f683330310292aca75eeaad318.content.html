List of Discovered SNMP OIDs

Classification probes return data on the devices and process they find in your environment. Discovery process classification occurs during the exploration phase of Discovery, after device classification. For SNMP Classification, SNMP System OIDs are the primary mechanism for matching known network devices by their unique sysObjectID value. Upon matching the OID value, Discovery uses the information to populate the CMDB with the specified Manufacturer, Model, and Classification.

These CIs are classified as SNMP object identification configuration items.

  • The Operator column refers to the operator used to match the record against discovered OIDs.
  • The Table column refers to the table associated with that CI classifier.
