Incident resolution codes

A resolution code provides the reason for the resolution of an incident. For example, the Not Solved (Too Costly) code indicates that even though an incident is closed, the reported incident is not solved because of budget constraints.
Note: Customers who upgrade to Jakarta from a previous release see Close code instead of Resolution code as the field name.

Review the default incident resolution or close codes to determine whether they align with your business needs.

To modify or delete a default resolution or close code, click the corresponding choice in the list.

To add a new resolution or close code, click New.
