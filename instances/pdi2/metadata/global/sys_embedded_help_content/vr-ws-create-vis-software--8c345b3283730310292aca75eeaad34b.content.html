Create VITs for software for exposure assessment

Create vulnerable items (VITs) from the Vulnerability Assessment Workspace. Vulnerability analysts then analyze this list of VITs and recommend solutions and patches that help the IT team to patch these vulnerabilities.

Before you begin

Procedure

  1. Select the records for which you want to create VITs.
  2. Select the Create Vulnerable Items option.
  3. In the Create vulnerable items dialog box, select from:
    • Existing vulnerability
    • New vulnerability
  4. Select the Create Vulnerable Items option.
