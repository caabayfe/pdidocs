Scenario planning

You can plan your scenario in different views.

A scenario can viewed and created using the following views
  • Stack plan view: View space allocations on each floor of a building as bars with different colors. The Y-axis of the plan shows the different floors of a building and the X-axis shows the length of the bar, which is determined from the total capacity of the building.
  • Floor map view: View the floor map of the selected floor and make space allocation directly if the floor has a floor map configured. View user assignments, space types, allocation to which each space belongs and more.
