Create Flexible VTB action

Creates a Flexible VTB bound to a single Task table. The default lanes are Todo, Doing, and Done. These lanes can be modified with the actions Add Lane, Rename Lane, Reorder Lane, and Delete Lane.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Name
Data type: String

Name of VTB.

Task Table
Data type: Table Name

Name of the associated Task table.

Filter
Data type: Conditions

Filter applied to Task table records.

Owner
Data type: Record

Reference to the user who owns the VTB.

Default View
Data type: String

Default view applied to VTB card.

Picker Visibility
Data type: True/False

Option to show or hide VTB in picker.

Label Visibility
Data type: True/False

Option to show or hide VTB label.

Background color
Data type: String

Color of the VTB background as a name or hex value.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Board
Data type: Record

Reference to VTB created.
