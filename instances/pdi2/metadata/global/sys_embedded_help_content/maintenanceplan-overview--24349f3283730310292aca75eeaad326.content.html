Maintenance Plan - Overview

View the maintenance plan details and all plan-related information using the plan overview.

The Overview tab of the plan is displayed with a calendar view by default.
  • The left column of the calendar displays the location where maintenance is planned.
  • The right columns display the dates across the current week or the selected week above the calendar view. You can select a date range on the top left of the calendar view.
  • Overall, the calendar is displayed in a daily and a weekly view.
  • You can select a maintenance case on the calendar to view more details.
  • You can select the Details tab to view the details of the maintenance plan.
  • To view the maintenance items involved in the plan, select Maintenance items.
  • To view the plan schedules, select Schedules.
