List of Discovered SNMP CIs

Classification probes return data on the devices and process they find in your environment. Discovery process classification occurs during the exploration phase of Discovery, after device classification.

These CIs are classified as SNMP configuration items.

  • The Table column refers to the table associated with that CI classifier.
  • The Order column refers to the order in which the CI classifiers are run. Smaller numbers are run before larger ones.
