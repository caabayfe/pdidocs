Get Email Header action

Provide a header value from an Email [sysemail] record as a data pill to use in your flow.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Email Record
Data type: Record

Email [sysemail] record whose header values you want to access.

Target header
Data type: String

Header value from an Email [sysemail] record, such as Subject, To, or From.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Header value
Data type: String

Value for an Email [sysemail] record's header item.
