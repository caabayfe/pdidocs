Open the planning item form to configure related lists

Role required: admin

  1. Click the Show Form related link so that you can open the actual form view of this planning item type.
  2. After the form opens, use the Additional actions menu to configure related lists for this planning item type.

    For details on how to add related lists to a form, refer to the documentation from the Related information section below.
