Multi-factor browser fingerprint form

Use the multi-factor browser fingerprint form to view the details of an existing browser fingerprint. These records are created when Multi-factor authentication (MFA) users log into your instance. When a MFA user logs in again using the browser identified by this fingerprint, they are not challenged for MFA until the fingerprint expires. The length of time before the fingerprint expires is determined by the glide.authenticate.multifactor.browser.fingerprint.validity system property.

Browser fingerprint records are created and deleted automatically by you instances and do not need to be created or modified by an administrator.
