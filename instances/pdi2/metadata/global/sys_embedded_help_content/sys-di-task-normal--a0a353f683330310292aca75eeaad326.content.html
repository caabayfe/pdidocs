Create a document task

Use a document task to upload single or multi-page documents and process them for classification or data extraction.

  1. On the Document Task form, fill in the fields.
    Display Name
    Name of the document task
    Use Case
    The use case created for this document type
  2. Attach the files you want to upload for processing.
  3. Process the task.

    Document Intelligence analyzes the document and extracts data or classes for the fields defined in the use case.
