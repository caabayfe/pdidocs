Conflict properties

Conflict properties help to define the scope when analyzing the potential conflicts in the requested changes.

Review the conflict properties and customize them to align with your business needs.

To run conflict detection automatically when a change request is updated, select the Yes check box for the Run conflict detection automatically after changes to Configuration item, Planned start date, Planned end date or State when a change request is updated property.

To schedule conflict detection to run at specific intervals, select the Yes check box for the Enable the scheduled change conflict checker property.
