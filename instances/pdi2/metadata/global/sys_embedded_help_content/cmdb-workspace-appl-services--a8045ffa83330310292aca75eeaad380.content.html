Application services

The Application services tile shows the number and trend line of records in your Application Services [cmdb_ci_service_auto] table on your instance over the last seven days.

You can drill into the tile to see cards that show data about the following application services:
  • Application services with a defined population method.
  • Application services with population method not yet defined.
  • Application services broken down by types.
  • Application services with missing data.

Drilling into the tile also enables you to see Application service charts of coverage for application servers, databases, and hardware servers.

You can drill further on any cards in the Application services tile to review the lists of associated application services.
Note: Some population methods for application services are available only with Service Mapping and therefore will not appear in the tile if Service Mapping isn't installed.
