Look Up Attachment action

Looks up an attachment for a record and returns the Attachment [sys_attachment] record.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

File Name
Data type: String

Entire a file name for the attachments you want to look up.

Note: If multiple files with the same name are found, then the first attachment the system finds is returned.
Source Record
Data type: Record

Add a Record data pill, or select the record that the attachment is associated with.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Attachment Sys ID
Data type: String

Sys ID for the Attachment [sys_attachment] record.

Attachment List
Data type: String

Stringified JSON Object that has all the attachments returned with File name and File size properties.
