Schedules page

The Schedules page displays details of the selected discovery run.

Schedules filter

By default, the list shows all the Cloud Discovery schedules in alphabetical order, regardless of their current running status. Use the schedule filter to filter the Cloud Discovery schedules. You can filter the schedules by cloud provider, schedule name, or both. You can also sort the filtered list by any one of the following criteria:

  • Alphabetically: Sort the schedule names alphabetically.
  • Errors: Sort by the count of errors encountered during the discovery.
  • Discovery in progress: Sort by status of the discovery.

After filtering the schedule, select the discovery run from the Report drop-down list to visualize its data in the schedules dashboard displayed on the Results tab.

Note:

Only the last 10 discovery runs appear in the Report drop-down list.

Indicators

The schedules page displays the following indicators:

  • Total Resources: Total count of CIs discovered during the selected discovery run.
  • Newly discovered: Count of new CIs discovered during the selected discovery run.
  • Absent from last: Count of CIs missing during the selected discovery run. That is, CIs were discovered during the previous discovery run, but are missing during the selected discovery run.
  • Errors: Count of discovery errors that occurred during the selected discovery run.
  • Duration: Time taken to complete the selected discovery run.
Note: Cloud Discovery calculates the Newly discovered and Absent from last indicators only for the pattern-based discoveries.

Default data

By default, the workspace displays the following data:

  • Resource counts from recent discovery run
  • Time taken for recent discovery runs
  • Newly discovered CIs
  • Absent discovered CIs
