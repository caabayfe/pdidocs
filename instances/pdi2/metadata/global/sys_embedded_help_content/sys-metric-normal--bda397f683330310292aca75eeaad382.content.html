Create a time series definition

Specify the metric that you want to store and how often to collect it. Determine how long to store it in the MetricBase database.

  1. On the form, fill in the fields.
    Label
    Intuitive name for the metric field name.
    Table name
    Name of the table to add the metric to in the MetricBase database.
    Metric field name
    Name of the time-series metric that records.
    Retention policy
    Sampling frequency and how long MetricBase keeps the values in the database.
    Retention policy aggregator
    Operator that aggregates the data in a sampling period.
    Display value aggregator
    The aggregation method in use when using <table-name>.list where <table-name> is a table in the MetricBase database.
    Display value aggregate duration
    Duration that is used to calculate the aggregation only when using the list view.
    Subject field
    Unique table column to use as your subject for the metric.
    Data type
    Data type of the subject field.
  2. Click Submit.

Sample the data according to the time-series specification and send it from an instance to the MetricBase database server.
