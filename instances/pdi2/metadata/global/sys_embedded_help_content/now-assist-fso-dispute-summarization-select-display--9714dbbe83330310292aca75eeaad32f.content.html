Dispute Summarization: Select display

Select where you'd like to display the dispute summarization skill, either in the product, the Now Assist panel, or in both places.

In-product
Display the skill on forms in Financial Services Workspace or in the Core UI.
Now Assist panel
Display the skill in the Now Assist panel.

To restrict access to the content by role, select the down arrow to identify the roles that can use the skill.
