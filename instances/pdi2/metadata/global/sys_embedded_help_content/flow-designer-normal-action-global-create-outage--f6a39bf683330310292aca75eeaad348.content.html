Create Outage action

Create an Outage [cmdb_ci_outage] record associated with a configuration item in the Configuration Management Database (CMDB).

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Configuration Item
Data type: Record

Reference to configuration Item associated with outage.

Type
Data type: Choice

Type of outage to create. Choices are from the Outage [cmdb_ci_outage] table, which include:

  • Degradation: The outage is a result of degradation with the configuration item.
  • Outage: There has been a general outage.
  • Planned Outage: The outage for the configuration item is a planned outage.
Begin
Data type: Date/Time

Date and time when the outage began.

Source Record
Data type: Record

Reference to Task record associated with outage.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

outageGr
Data type: Record

Outage [cmdb_ci_outage] record created for the configuration item in the CMDB.
