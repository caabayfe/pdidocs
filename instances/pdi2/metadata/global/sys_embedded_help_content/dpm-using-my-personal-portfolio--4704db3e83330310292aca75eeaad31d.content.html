Using personal portfolios

Your personal portfolio enables you to access items in the portfolio, view general information about an item, and filter the item layout. You can also edit and share your personal portfolio.

Access personal portfolio items

The Overview tab displays all items in your personal portfolio. Select an item to go to its details.

In cases where there are many items to choose from, use the page navigation or filter by item type.

Select All Items to filter by type.

The Info tab displays a description, general information, and collaborators for this personal portfolio.

Edit and share personal portfolios

Edit enables you to edit your personal portfolio. You can add or remove items as well as add or remove editors.

Share enables you to share your personal portfolio with others. You can choose the access level as editor or viewer.

Access items that need attention

The side panel displays items that need attention. You can select an item or you can select Search to find specific items that need attention. You can also select the filter icon () to filter by item type.
