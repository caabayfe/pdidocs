Create a recommendation

Role required: sn_nb_action.next_best_action_author, admin

Use the Recommendation form to create a recommendation. This form stores information about a recommendation, including the selected action and any inputs and resource generators that the action requires.

When you create a recommendation, you select an action type and an action. The next steps depend on the action type that you select. For example, guidances and field values need action inputs as a next step, while guided decision trees don’t.

  1. Provide a name for the recommendation.
  2. Select an action based on the Action type.
  3. Optional: For guidances and field value recommendations, select a resource generator.
    Some action types and actions may need a resource generator, which automatically finds relevant resources for the Action input or Recommendation hint fields. If the resource generator finds multiple resources for the action inputs, it displays multiple recommendations. To use values provided by a resource generator, define a resource generator and save the record.
  4. For guidances and guided decision trees, provide a recommendation hint.
    The hint explains to users why a recommendation was recommended to them. This field does not appear if the Action type is Field recommendation.
  5. Click Save.
    After saving the record, the system checks for action inputs and displays the Action inputs form section.
  6. Define the action inputs.
    Some action types and actions require inputs. To see if an action requires inputs, select the action and save the record. Action input values can be chosen manually from the context record or from a resource generator. To see action inputs, select the action, then save the record.
  7. Click Save.
