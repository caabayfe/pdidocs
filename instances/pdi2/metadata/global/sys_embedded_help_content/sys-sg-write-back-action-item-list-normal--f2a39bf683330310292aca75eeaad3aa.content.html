Write-back action items list

This view provides a full list of write-back action items. These are used by action functions to change data, such as assigning a task to yourself or adding a comment to a record. Action functions require a write-back action item to operate.

Name
Name of the write-back action item.
Description
Brief description of the action item.
Execution Script
Code block containing script used by the action item.
Parameter Screen
Screen associated with the action item, with inputs for users to quickly enter information.
Query Condition
Filtering applied to the list
Table
Data table associated with the action item.
Set field values
Values of key:value pairs affected by the action items.
Type
Format for the action item, as either a script or an update.
Use current record as condition
Whether the action item disables query conditions.
Use field values for reference lookup
Whether the action item shows field values shown by clicking the reference lookup icon
