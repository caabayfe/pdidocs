Data Source Configuration

Enter your configuration details to your Microsoft SCCM 2019 data sources on the ServiceNow instance:

  • Use MID Server: Select MID Server, if you require an integrated authentication, then check the 'User Integrated Authentication' check box
  • Instance Name: Name of the database instance, leave empty if you're using a default name.
  • Database Name: Name of the database
  • User name: User name for connecting to the JDBC server
  • Password: Password for the JDBC server
  • Server: Server name or IP address for JDBC server
