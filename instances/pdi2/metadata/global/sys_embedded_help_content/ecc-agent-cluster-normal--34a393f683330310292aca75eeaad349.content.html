MID Server cluster configuration

Ensure that each MID Server in the cluster has the appropriate capabilities for the job. A MID Server in a fail-over cluster must have the same capabilities (or expanded capabilities) as the MID Server it is expected to replace.
  1. Name the cluster and select the cluster type: Failover or Load Balance.
  2. Right click in the header bar and select Save from the context menu.
  3. Click Edit in the Includes MID Servers Related List.
  4. Select appropriate MID Servers for this cluster from the slushbucket.
