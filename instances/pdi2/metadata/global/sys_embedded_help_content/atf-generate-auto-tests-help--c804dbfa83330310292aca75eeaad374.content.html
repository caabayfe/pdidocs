Generate automatic tests

Generate automated tests for forms and service catalog with a single click or by using the Advanced option.

This page enables you to do these tasks:
  • Make a Test Type selection of either Form Tests or Service Catalog Tests
  • You can make a catalog item selection
    Note: This field is visible only if you select Service Catalog Tests as the test type.
  • Select a specific catalog item in the Catalog Item field
    Note: This field is visible only if you select Specific Catalog Item as the Catalog Selection.
  • You can also make a specific scope selection
  • Select either all tables or a specific table for the test generation
  • Get notified over your email when the test generation completes
