De-duplication tasks

When the instance encounters duplicate CIs during identification and reconciliation (IRE), it groups each set of duplicate CIs into a de-duplication task for review and remediation.

De-duplication tasks provide details about the duplication, including a list of all the duplicate CIs. Review the details of each duplicate CI in the task and the data that was used to determine that the CI is a duplicate.

To remediate a task (eliminate the duplication) reconcile the associated duplicate CIs into a single CI. From a de-duplication task, you can run the Duplicate CI Remediator wizard to remediate a single task or create and run templates to remediate tasks in bulk.

  • Select Only show tasks that do NOT match any template conditions to show only those tasks that are unassigned or unmatched to any template class.
  • Select tasks and then select Assign to template to manually assign a task to a template.
  • Select List Actions > Edit columns to edit the columns that the list view shows.
  • Drill into a task or template to access the record view.
    Note: Drill into a task and then select Remediate to manually remediate the task.
