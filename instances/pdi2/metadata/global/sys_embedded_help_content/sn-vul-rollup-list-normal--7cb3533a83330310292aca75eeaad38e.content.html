Vulnerability rollup calculators

The Vulnerability Response application includes three vulnerability rollup calculators: Remediation Task Rollup, Vulnerability Entry Rollup, and Remediation Effort Rollup. These calculators configure how the cumulative risk score is computed for all the vulnerable items (VI)s in remediation tasks, remediation efforts, and for all VIs that have the same vulnerability. Cumulative scores are based on weights that indicate how much value the maximum risk score, the average risk score, and the vulnerable item (VI) count influence the scores. You can adjust the default weights (percentages) for these calculators on the records on this list. Click a record on the list to open it.

The Rollup vulnerable item values to vulnerability and groups job runs every 15 minutes to pick up changes and roll up the details. Additionally, risk scores are calculated for VIs in remediation tasks, remediation efforts, or imported vulnerabilities if:
The risk score, remediation target, remediation status, or vulnerability changes.

Vulnerable item states change to Open, Deferred, or Closed.

Vulnerable items are added or removed.

Include deferred
If selected, all deferred vulnerable items are included in the rollup calculation for the vulnerable group. Depending on how the weights are configured, including all deferred VIs might impact the total calculation.
