Creating a free-form roadmap

Build a roadmap on any ServiceNow table that you want to plan and track work from.

Use this 2-step wizard to select a source table, filter the data that you need, and provide dates for the roadmap.

For example, you want to roadmap the active initiatives created for all departments in and after 2023. Then your field selections can be:
  • Source table: Initiative [sn_align_core_initiative].
  • Filter conditions: Created at or after 2023 AND Active is true.
