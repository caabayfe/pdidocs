Create a new automated indicator by wizard

Use this wizard to create a Performance Analytics automated indicator quickly, with breakdowns, widgets, and data collection jobs.

To use this wizard, you still need to be trained in Performance Analytics and to be familiar with its concepts.

Create indicators only as part of an analytics strategy. Consider planning your indicators with KPI Composer.

This wizard requires that an appropriate indicator source for the indicator already exists. To create an indicator source, go to Performance Analytics > Indicator Sources.

Only a subset of configuration options are available through this wizard. If you need access to the full range of indicator parameters, go to Performance Analytics > Automated Indicators.
