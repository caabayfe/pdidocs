System user

You can add a user to your instance to allow them to authenticate and use the features.

User ID
Create a unique identifier to represent this user's ServiceNow login name. View the fields that you can customize for the user.
Calendar integration

Select Outlook to have this user receive meeting notifications from email directly to the calendar.

Password needs reset
Select this check box to require the user to change the password during the first login.
Locked out
Select this check box to lock the user out of the instance and terminate all their active sessions.
Web service access only
Select this check box to make this user a non-interactive user.
Internal Integration User
Select this check box to designate this user as an Mark service accounts as internal integration user.
