Creating a Calendly integration profile

Create an integration profile to connect the Calendly service with the ServiceNow AI Platform. Use this integration to view software usage information and optimize stale licenses.

Important: Before you can save and publish the integration profile, you will need to register a public application with the Calendly service so that you can access the Calendly API using OAuth 2.0.

The integration profile uses the Calendly Download Subscriptions, Calendly Update User Activity, and Calendly Reclaim Subscription subflows to retrieve user data from the Calendly service. You can select the date and time that you want to analyze user activity from in the Analyze user activity from field on the Calculate Activity Subflow tab. You can start analyzing data from the current date or from up to 60 days prior.

To enable the Calendly service to connect with the ServiceNow AI Platform, you must configure the corresponding connection and credential information using the connection & credential aliases record associated with your integration profile. To open this record, click the preview icon next to the Connection & Credential field and then click Open Record. When the record opens, click the Create New Connection & Credential related link and then enter the following information:
Name
Name of the connection. For example, Calendly Connection.
Connection URL
Base URL for the Calendly API. This field is automatically set to https://api.calendly.com.
OAuth Client ID
Client ID that is assigned to the public application that you registered with the Calendly service.
OAuth Client Secret
Client secret that is assigned to the public application that you registered with the Calendly service.
OAuth Redirect URL
URL of the OAuth provider that users are redirected to after authentication. This field populates automatically based on your instance name.
