Create a demand using list view

You can create a demand for an application from the list view.

Before you begin

Role required: sn_apm.apm_analyst

Procedure

  1. Select the row context menu icon () next to the business application that you want to create a demand for and select Create demand.
  2. On the Create demand form, fill in the fields.
    For a description of the field values, see Create demand form.
  3. Select Create.
    The new demand is displayed under the business application.
