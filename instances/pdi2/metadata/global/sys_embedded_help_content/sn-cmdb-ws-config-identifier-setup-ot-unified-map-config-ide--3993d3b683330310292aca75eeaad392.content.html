Configuration Identifier

The Unified Map feature graphically shows a hierarchical map of CIs and the relationships between them, while centered on a CI that you choose (the home node). The Unified Map feature combines some of the capabilities of Dependency Views and Service Mapping into a single map experience.

Role required: admin or sn_cmdb_ws.config_admin

A Configuration Identifier represents a set of properties and table-driven configurations used in a UX Application.
Note: If a property is not set or if there are no entries in the table-driven configuration, lookup will instead use the values in the default Configuration Identifier.
When the Industrial Workspace is set up, it adds one default configuration called the Industrial Workspace Config Identifier. This Config Indentifier is specific to the Industrial Workspace.
