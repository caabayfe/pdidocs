Create a function

Role required: Admin

Use this form to create a new function.

Action functions perform tasks such as assigning a task to yourself or adding a comment to a record. Action items can optionally include an input parameter, which collects input from your user to update a record.

Each action function includes an action item, which defines what the action function is and how it works.

  1. Select your record type.
    Action Item
    This function has an action item to match.
    Navigation
    Loads a new screen.
    URL
    Loads a web address.
    Phone
    Sends SMS to a phone number.
    Email
    Sends a message to an email address.
    Spannable Rating, Select One Rating
    These respectively allow a user to select a rating, such as 4 out of 5 stars, or a thumbs-up or thumbs-down.
    Aside from the Context dropdown, the form fields change to match your selection. Global context provides universal options. Record context adds a Take source value from field checkbox. Click the checkbox to add a customizable dropdown option or convert a relevant field into one.
  2. In the tabs below the main form, input the appropriate data.
    Condition
    Criteria that must be met to activate the function.
    Messages
    Creates success, failure, confirmation, and cancellation messages related to the function.
    Acknowledgment Messages
    Creates messages displayed by the Action Item type.
    Offline Properties
    Alters available fields when not online.
    Action Completion
    Performs selected actions when the function is completed.
    Attributes
    Creates attributes related to buttons for this function.
  3. Click Submit.
