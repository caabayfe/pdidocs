Creating a Looker integration profile

Create an integration profile to connect your Looker applications with the ServiceNow AI Platform. Use this integration to view software usage information and optimize stale licenses.
Important:

Before you can save and publish the integration profile, you will need to configure Looker API key settings to receive a Client ID and Client secret.

In addition, you must create a connection between the Looker application and your ServiceNow instance so that you can retrieve user data from your Looker applications.

The Looker integration profile uses the Download Subscriptions and Reclaim Subscription subflows to retrieve user data from your applications.
