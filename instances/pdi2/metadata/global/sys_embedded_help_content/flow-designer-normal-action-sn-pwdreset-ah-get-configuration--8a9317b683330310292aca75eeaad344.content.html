Get Configuration Variables for Master Flow action

Validates a password reset request and returns the configuration variables for the credential store provider's password reset process. The output variables from this action are used in the Password Reset subflow.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Reset Request Record
Data type: Record

Reference to the password reset request to fulfill.

New Password
Data type: Password (2 Way Encrypted)

New password to set.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Status
Data type: Choice

The completion status of the password reset request. The flow execution details page displays one of these values.

  • Success
  • Error
Error message
Data type: String

The error message the password reset request produced if any.

Is Flow
Data type: True/False

Flag indicating whether Workflow Studio fulfilled the password reset request.

Action Type
Data type: Choice

Type of subflow to call to fulfill password reset request, such as Change Password or Reset Password.

Request Status
Data type: Integer

The completion status of the reset request. The flow execution details page displays one of these numeric values.

  • Success [0]: The reset request succeeded.
  • Error [1]: The reset request produced an error.
Subflow
Data type: String

Internal name of the subflow to call to fulfill password reset request.
