Creating an Asana integration profile

Create an integration profile to connect your Asana applications with the ServiceNow AI Platform. Use this integration to view software usage information and optimize stale licenses.
Important:

Before you can save and publish the integration profile, you will need to register an Asana OAuth application to access the Asana API 1.0 to receive a Client ID and Client secret.

In addition, you must create a connection between the Asana OAuth application and your ServiceNow instance so that you can retrieve user data from your Asana applications.

The Asana integration profile uses the Download Subscriptions, Update User Activity, and Reclaim Subscription subflows to retrieve user data from your applications. You can also select the date and time that you want to analyze user activity from in the Analyze user activity from field on the Calculate Activity Subflow tab. You can start analyzing data from the current date or from up to 60 days prior.
