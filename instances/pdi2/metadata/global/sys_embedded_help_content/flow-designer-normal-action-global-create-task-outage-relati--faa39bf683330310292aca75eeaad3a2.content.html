Create Task Outage Relationship action

Creates an Outages Tasks Link [task_outage] record by creating a relationship between an Outage [cmdb_ci_outage] record and a Task record.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Outage
Data type: Record

Reference to Outage [cmdb_ci_outage] record to associate to Task record.

Task
Data type: Record

Reference to Task record to associate with the outage.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.
