Configure MID Server IP ranges

This is a manual configuration procedure. Click the link below to learn how to use the MID Server IP range auto-assignment feature.

You can also use the ALL IP range, which allows the MID Server to be used with any range of IP addresses that an application specifies. This only allows the MID Server to access IP ranges, it does not mean that the MID Server can actually reach all of the IP ranges. To function with an application, the MID server must have access to the IP ranges that the application needs.

  1. Complete the form, using the fields in the table.
    Name
    Descriptive name of the range for reference.
    Application
    Application scope for this IP range. The default is Global.
    Type
    • Include: Include the specified IP range.
    • Exclude: Exclude the IP address range.
      Note: If a MID Server is configured for ALL applications, any IP addresses configured for exclusion are ignored by the system. If your goal is to configure default MID Servers for separate applications in your system, configure a default MID Server for each application.
    Range
    IP range, entered in a valid format.
  2. Save the record.
  3. In the MID Servers related list, click Edit.
  4. Select the MID Servers that use this range.
