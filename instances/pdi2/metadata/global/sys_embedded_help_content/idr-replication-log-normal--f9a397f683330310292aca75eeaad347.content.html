Replication log

View log message details and search for log entries. The timestamp, log level, thread name, session ID, and message are returned in a tabular view.

  1. On the form, fill in the fields.
    Start time
    Enter a start time or use the default.
    End time
    Enter an end time or use the default.
    Level
    Select for messages by log level.
    Max rows
    Enter a the maximum number of rows to return.
    Session ID
    Filter by session ID. Select Submit, copy the session ID, and then use that ID to filter the list.
    Message
    Filter by text in the message.
    Session ID
    Filter by session ID. Run a query, copy the session ID, and then use that ID to filter the list.
  2. Click Submit.
