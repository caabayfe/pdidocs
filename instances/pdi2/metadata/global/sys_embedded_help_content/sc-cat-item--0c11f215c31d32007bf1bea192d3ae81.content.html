Create, modify, or delete a service catalog item

  • To create or modify a service catalog item:
    1. Enter or modify the item Name .
    2. Select the Active check box if you want the item to be active.
    3. From the Availability list, select which devices can display the item.
    4. Select the Catalogs that you want the item to appear in.
    5. Select the Category for the item.
      The Category field is available only after the Catalogs field is populated.
    6. From the Workflow list, select a workflow for the fulfillment of the item request.
    7. Next to Icon , upload the icon image file that you want to associate with the item.
    8. In the Price field, set or modify a price for the item and select the currency.
    9. In the Recurring price field, set or modify a price that recurs repeatedly at regular intervals.
      For example, a printer maintenance service that has a $100.00 monthly recurring price.
    10. If you set a recurring price, select an option from the Recurring price frequency list to specify how often the item recurs.
    11. Next to Picture , upload the image of the item.
    12. Enter or modify the Short description of the item.
    13. Enter or modify the Description of the item.
    14. From the Mobile picture type list, select the type of picture to display on a mobile device.
      Select Desktop to use the standard desktop picture, Mobile to use a specific picture for the mobile devices, or None to display no picture.
    15. To hide the item price on mobile devices, select the Hide price (mobile listings) check box.
    16. Click Submit or Update .
  • To delete a service catalog item, click Delete .
