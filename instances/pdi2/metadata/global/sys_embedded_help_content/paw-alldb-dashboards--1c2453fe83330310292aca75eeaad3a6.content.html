Dashboards

You can view all the dashboards you have rights to access on your instance. You can filter the dashboard tiles to limit the number that are visible.

Dashboard tiles

Dashboard tiles show the dashboard owners, a Certified badge if certified, and a Bookmark icon if bookmarked. You can apply the following filters to the tiles:
All
See all dashboards that you own or that have been shared with you. If you have the admin or dashboard_admin role, you can see all Platform Analytics dashboards on the instance.
Recent
See the dashboards that have most recently opened. The tile for a dashboard shows when someone last opened it.
Bookmarked
See all dashboards that you have bookmarked. To bookmark a dashboard, select a dashboard to open it, then select Bookmark from the context menu ().
Certified
Dashboards that have been certified for use throughout your organization.
Created by me
Those dashboards that you have created.
Shared with me
Those dashboards created by other users that have been shared with you.

Creating a new dashboard

The Create a dashboard button has two possible results, depending on your role:

  • If you have the admin or ui_builder_admin role, you are given the choice to create a dashboard in either the in-line editor or the technical editor. The in-line editor is a feature in the Platform Analytics experience where you can add commonly used elements, such as data visualizations. It creates a Dashboard component which itself can contain data visualizations, filters, and a few other elements. You can include this Dashboard component in your own workspace.

    The technical editor is the UI Builder itself, opening in the special Advanced Dashboards experience. You have the full features of the UI Builder, but also the complexities. Many configuration details are preset in an in-line dashboard but require you to set them up in a technical dashboard. The technical dashboard is for experts with deep knowledge of UI Builder.

  • If you have any other role, the in-line editor opens.
