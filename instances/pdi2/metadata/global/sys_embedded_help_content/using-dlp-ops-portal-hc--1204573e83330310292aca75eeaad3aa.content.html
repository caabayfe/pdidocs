Using the DLP Analyst Workspace

Access the DLP Ops portal so that you can review the DLP incidents and assign or resolve them. You can track trends on incidents by severity, top offenders, incidents by scan source, and incidents by policy.

Before you begin

Role required:
  • sn_dlir.analyst - Edit and View DLP incidents.
  • sn_dlir.analyst_read and sn_dlir.read - View DLP Incidents.

Procedure

  1. Review the dashboard widgets to identify trends by incidents by severity, top offenders, incidents by scan source, and incidents by policy.
  2. Select the appropriate filters on the home page to view the widgets by their various categories.
  3. Select one or more DLP incidents that you want to review or resolve, and select the check box next to the incidents.
  4. Choose the action that is appropriate for you.
