Apply Change Approval Policy action

Set the approval rules for a Change Request [change_request] record based on the policies defined in a Change Approval Policy [chg_policy_approval] record.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Action Label
Data type: String

Name of the applied change policy to add to the Activity name field. You can use this value for auditing purposes.

Policy
Data type: Record

Reference to the Change Approval Policy [chg_policy_approval] record whose approval rules you want to apply to your change request.

Change Request
Data type: Record

Reference to the change request to attach approval rules.

Policy Inputs
Data type: String

Additional policy Inputs that you want to apply to the change request. A policy input is part of the Change Approval Policy [chg_policy_approval] record.

Due Date
Data type: Schedule Date/Time

Due date for the approval. You can define an approval state to set at the due date to prevent a flow from endlessly waiting for approval.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

State
Data type: Choice
Approval state of the Change Request [change_request] record. The flow execution details page displays one of these values.
  • Not Yet Requested [not requested]
  • Requested [requested]
  • Approved [approved]
  • Rejected [rejected]
  • Cancelled [cancelled]
  • No Longer Required [not_required]
  • Skipped [skipped]
