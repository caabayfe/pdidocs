Map Page Filter Item list

This list provides details on the available map page filter items available for your instance. Map filters can be configured using lists and forms, or scripting. These filters enable you to see only the map markers for the data that you want.

Name
Name of the Map Page filter item
Data item
Data item for the Map Page filter item.
Data item table
Data item table for your Map Page filter item.
Note: This field is automatically populated when a data item is selected.
Data item value field
Data item value field for the Map Page filter item.
Data type
Data type for the Map Page filter item; either Data item or Scripted. A data item enables you to configure or select data items using lists and forms.
Default value script
Scripting field for the Map Page filter item.
Label
Title for the Map Page filter item displayed in the map filter in your Map Page.
Script
Script associated with the Map Page filter item.
UI Type
UI type for the Map Page filter item, chosen from Single selection, Multiple selection, or Date picker.
