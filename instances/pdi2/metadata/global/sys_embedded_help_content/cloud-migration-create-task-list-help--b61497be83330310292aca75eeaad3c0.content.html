Create assessment tasks

Create assessment tasks and associate them with migration waves for migration management.

Before you begin

Role required: sn_cloud_migration.operator.

Procedure

  1. Select New.
  2. Fill in values on the Create New Cloud Migration Assessment Task form.
  3. Optional: Add attachments.
    1. Select Browse in the Attachments section.
    2. Navigate to a file and select it.
    3. Select Upload.
      The attached file appears under Attachments.
  4. Select Save.
