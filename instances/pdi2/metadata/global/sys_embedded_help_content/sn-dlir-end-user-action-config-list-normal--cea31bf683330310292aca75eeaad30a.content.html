Set up the incident response option rules for your DLP incidents

Role required:
  • sn_dlir.admin - Create, edit, and delete.
  • sn_dlir.analyst - View (read-only).
Set up the incident response option rules that end users can use while responding to the incident. You can configure the type of response that an end user should perform based on the type of DLP incident. The base system DLP Incident Response application provides the following options for users:
  • Deleted content
  • Required for business process
  • Encrypted file
  • Report false positive
  • Report wrong owner
  • Reviewed entitlements
  1. To create an Incident Response Option Rule, click New.
  2. On the form, fill in the fields.
  3. In the Response Option Mappings section, click New.
  4. On the form, fill in the fields.
  5. Click Submit.
