Search and filter solution cards

You can search for solutions cards to display on your homepage. You can also filter to display solutions by their status, type or both.

Before you begin

Role required: sn_dpm.dpm_manager

About this task

Search for solution cards to display on your homepage. For example, if you want to see all solutions that have IT in the name, you would enter IT in the Search field, and then press Enter. You can't search by a name (for example, a service owner's name).

Filter by status or by solution type, or by both. After you select a filter, a check mark displays after the selection. To close the filter pane, select out of the filter pane on the homepage.

To clear the filtered items, de-select the statuses and types that you previously selected. When you de-select them, a check mark doesn't display.

Procedure

  1. Select the Search field.
    Enter a portion of the solution name and then press Enter. You can also enter any letters that are in a solution name but you can't search for a person's name (for example, a solution owner name).
  2. Select Filter.
  3. Select a status.
    Solution cards display with the status that you select (severe, moderate, or good). The status is based on an aggregate of the solution's Needs attention attributes, for example, incidents, changes, and outages. You can select more than one status to see more solutions.
  4. Select a type.
    Solution cards display with the type that you select. The selected items have a check mark. You can select more than one type to see more solutions.
