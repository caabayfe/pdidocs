Working with move project

Manage move requests using the Move scheduler.

The move scheduler is a workspace where you can perform various actions on the selected move projects. The move scheduler displays a move project in the following views:
  • Scheduler: All the move requests of the move project is displayed on a calendar. The calendar is marked with the start and end date of the move request and the requester.
  • Move project details: The details of the move project is displayed. You can view details such as the state of the project, the assigned user, the work notes, activities performed on the project and more.
