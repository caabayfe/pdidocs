Create a Localization Project

Enable Localization Projects in Localization Framework settings.

Role required: localization_manager.

Use this form to create a record of a Localization Project. These projects are used to bundle multiple localization requested items under one task, and help fulfillers to translate items in bulk.

  1. On the form, fill in the fields.
    Number
    The project number is automatically generated.
    State
    The current state of the project, set to Draft by default.
    Assigned to
    Click the magnifying glass to search for a person to assign to the project.
    Assignment group
    Click the magnifying glass to search for the group of the person assigned.
    Short description
    Input a brief description of the project.
    Work notes
    Write any notes related to the project in this field.
    Additional comments (Customer Visible)
    Add any further comments here that you wish customers to also see.
  2. Click Submit.
