Investment entity

Enable a transaction table for funding so that you can start receiving fund to it or allocating funds through it. Additional options include:

Condition
Condition to filter records from the table for the investment entity to use for investments.
Owner field
List of user columns from the selected table to map to the owner field. The user in the mapped column becomes the entity owner.

If the selected table does not have any user column or to assign a specific user as the entity owner, select from the User table in the Owner tab.

Generic
Option to create a generic entity, which is not associated with a transaction table.
Owner filter
Condition to filter records from the owner table for the investment entity to use for generic investments.
