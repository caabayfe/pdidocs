Create a transportation asset

Create transportation assets for the enterprise model category in the Enterprise Asset Workspace.

Before you begin

Enterprise asset classes have a one to one mapping to product model classes and model categories​. Enterprise asset classes are mapped to existing CI classes where applicable.

Role required: sn_eam.enterprise_admin or sn_eam.enterprise_asset_manager

Procedure

  1. On the Create New Transportation asset page, fill in the details.
    Note: For a detailed description of all the fields, refer to the Asset fields description link in the Related information section at the end of this topic.
  2. Select Save.
    The asset is created along with a Configuration Item (CI) for this asset. Child assets are automatically created for the newly created asset. You can perform additional configuration on the asset by entering details in the other tabs such as Child Assets, Contracts, and Expense Lines.
  3. After you have completed additional configuration on the asset, you can change the status of the asset to In Use. The asset can be deleted only by the sn_eam.enterprise_admin role.
