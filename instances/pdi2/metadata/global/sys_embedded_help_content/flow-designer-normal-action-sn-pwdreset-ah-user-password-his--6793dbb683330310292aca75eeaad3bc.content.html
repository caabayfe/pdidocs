User Password History Check action

Validates the password of a user account on the local instance.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

User
Data type: Record

Reference to the user record to authenticate.

Password
Data type: Password (2 Way Encrypted)

Current password to authenticate.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Status
Data type: Choice

The completion status of the password reset request. The flow execution details page displays one of these values.

  • Success
  • Error
Error message
Data type: String

The error message the password reset request produced if any.

History Check Passed
Data type: Choice

Flag indicating whether the password history check succeeded. The value is True if the password isn't blocked by reuse history limits. The value is not populated if the password history check fails.
