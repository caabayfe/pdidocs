Complete the Prepare task for a moving enterprise asset

After you create a move order, complete the Prepare task for an associated enterprise asset so that you can proceed with moving it between locations.

Before you begin

Role required: sn_eam.enterprise_asset_manager, sn_eam.enterprise_admin, or enterprise_asset_technician

Procedure

  1. On your move order record, select the Enterprise move lines tab.
  2. From the list of available enterprise move lines, select the enterprise move line for the enterprise asset that you want to move.
    The enterprise move line record opens.
  3. On the Enterprise move tasks tab, select the task number for the Prepare task.

    Alternatively, select the task number that is displayed in the Current task field of the enterprise move line record header.

    The Prepare task opens.
  4. On the Details tab of the Prepare task, fill in the fields.
  5. Select Close Task.

Result

The Prepare task is automatically updated with a state of Closed Complete.

If you set the Move type field to Local Move, the Enterprise Asset Management application automatically generates a corresponding Local move task for the enterprise move line. If you set the Move type field to Ship, the Enterprise Asset Management application automatically generates a corresponding Ship task for the enterprise move line.

What to do next

If you set the Move type field to Local Move, proceed with the local move for the enterprise asset.

If you set the Move type field to Ship, proceed with shipping the enterprise asset.
