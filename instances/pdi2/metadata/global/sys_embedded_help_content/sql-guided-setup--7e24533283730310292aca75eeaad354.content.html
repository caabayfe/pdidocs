Microsoft SQL Server License Management Guided Setup

Get started faster with Microsoft SQL Server licensing by using the Microsoft SQL Server License Management Guided Setup. The Guided Setup provides a prescriptive guidance for the tasks that you must perform to configure SQL Server licensing and organizes the configuration activities into various categories for ease of use.

Microsoft SQL Server License Management Guided Setup enables you to do the following tasks with a prescriptive guidance:
  • Verify the prerequisites for managing Microsoft SQL Server licenses
    • Install the Software Asset Management publisher pack for Microsoft plugin to access the Microsoft Publisher pack features in Software Asset Management.
    • Install the Health check application for an accurate and reliable overview of your Software Asset Management configurations and view recommendations to correct errors.
    • Install the Discovery plugin for a unified and connected view of your entire IT network and the services that the plugin supports.
      Note: You must install the ITOM Visibility tools for discovering Microsoft SQL Server installations at your datacenter and cloud infrastructure.
    • Install the latest Discovery and Service Mapping Patterns application to use ITOM at its full capacity, you can deploy the latest out-of-band upgrades from the ServiceNow Store.
    • Run a health check on the Health check dashboard by selecting SQL Server CMDB to verify Microsoft SQL Server CMDB configurations and address the findings.
  • Configure Software Asset Management
    • Verify SQL Server setup.
    • Set up installation conditions for Microsoft SQL Server that would apply to all the SQL Server software models.
    • Set up installation conditions for using Visual Studio only in your non-production environment. These conditions would apply across all software models, including downgrades and editions.
    • Set up installation conditions for the non-licensed Microsoft SQL Server Developer edition.
    • Set up software models for non-licensed Microsoft SQL Server Express edition.
    • Set up software models with passive failover and disaster recovery installation conditions.
  • Verify SAM configurations
    • Run a health check on the Health check dashboard by selecting SQL Server Config to verify Microsoft SQL Server configurations and address the findings.
    • Create a success goal to manage your Microsoft SQL Server licenses.
    • Run reconciliation on the Software Asset Overview page to verify that the licenses are consumed according to the Software Asset Management configurations. Ensure you run the reconciliation only for Microsoft as the Publisher to verify the Microsoft SQL Server license consumption.
