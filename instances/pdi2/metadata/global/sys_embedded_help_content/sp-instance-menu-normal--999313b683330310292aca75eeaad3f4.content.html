Create a portal header menu

Create a menu with menu items to display in the header of a portal.

  1. On the form, enter a title for the menu and then fill in the following fields.
    Additional options, JSON format
    Advanced configuration options defined using JSON. For example, you could enable the shopping cart in the header menu.
    Widget
    A menu widget that the header menu is based on.
  2. Select Submit.

Add menu items and then add the menu to a portal.
