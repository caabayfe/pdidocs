Create connection

  1. Click Create New Connection & Credential under Related Links for Thomson Reuters SFTP.
    Table 1. Create Connection and Credential SFTP alias form
      
    Connection informationName of the SFTP connection type, SFTP server host, and port of the server
    Credential informationName of the credential, user name, and password for an access to the SFTP server
    Post processing informationSource path to the directory that contains the feed files, destination path to the directory where the successfully imported files should be moved
  2. Click Create for the SFTP alias form.

    Creates your Connection and Credential alias form and the File Connection Information record.

    Note: Once a new connection is created, a file connection information record is created. If you click New under the Connections related list after a connection has been created, a new file connection information record will not be created.
