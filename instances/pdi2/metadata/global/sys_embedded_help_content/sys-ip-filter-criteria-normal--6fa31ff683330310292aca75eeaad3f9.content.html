Create IP Filter Criteria

IP filter criteria allows you to filter users based on the user's IP addresses.

Role required: admin

You can configure an authentication policy to allow or deny access to a specific address or range of addresses using the IP Filter criteria.

  1. On the form, fill in the fields.
    Name
    Name to identity the IP network.
    Description
    Short description of the IP network.
    Application
    Scope of the application.
  2. Click Submit.

You can also define IP Range and Subnet (CIDR) with this configuration.
