Create watch topics in Vulnerability Response

The watch topics on this list are included with the application, and their related data are also visible in the Vulnerability Manager Workspace. Watch topics filter and import vulnerabilities based on specific criteria that might be of an interest to you. You can also create your own watch topics. Role required: sn_vul.vulnerability_analyst.

Data counts displayed on the records listed on this page are gathered nightly. Open a record to view remediation efforts and vulnerable configuration items (CIs) associated with this vulnerability. Alternatively, navigate to the Vulnerability Manager Workspace. After you review the filtered data on a watch topic, you can create a remediation effort directly from a watch topic in the Vulnerability Manager Workspace to automatically create a remediation task (VUL) of actionable steps that can be assigned to remediation owners for fixing vulnerabilities.

  1. To create a watch topic, click New.
  2. Review the following key terms and field descriptions to help you create a new watch topic.
    Display order
    Enter a value between 100-1000. Lower values starting with 100 are displayed in ascending order on lists.
    Condition builder
    Set specific criteria for the vulnerable items you want to filter with this watch topic. An example might be, Active is true. And Risk Rating is 1 - Critical. And Remediation status is Target Missed..
  3. On the form, fill in the fields.
  4. Click Submit.
  5. Alternatively, click a record to open it.
    On the Watch Topic Counts tab, view critical overdue VIs by date. On the Remediation Efforts tab, view the associated remediation efforts for this watch topic. On the Vulnerable CIs tab, view the configuration items associated with this watch topic.

Click the related list tabs on each watch topic to view and monitor related vulnerability data and vulnerability types. When you're ready to create a list of remediation tasks to IT to fix vulnerabilities, open a watch topic record in the Vulnerability Manager Workspace and create a remediation effort.
