Calculated metric definition

A calculated metric definition aggregates the scores from its children. It can include the quantitative automated and manual metric definitions, metrics, and other calculated metric definitions of identical frequency. As the metrics manager, you have to specify how you want to calculate the metric definitions score and how frequently you want to calculate them.

Build a formula for metric definition score

Before you save the calculated metric definition form and build the formula for metric definition score calculation, you must specify the calculation level. The two levels are as follows:
  • Metric definition: If you choose this level, then the data across all child metric definitions or child metrics is used for calculation.
  • Entity: If you choose this level and specify the calculation method using the formula builder, the data is calculated for each entity, and then aggregated to get an overall score at the metric definition level.

You can also specify the formula that you want to use to calculate the metric definition score. You can either select a predefined set of functions such as Sum, Average, Minimum, and Maximum, or you can create a custom formula to aggregate the score. A custom formula can be used, for example, when you want to calculate ground water consumption as a percentage of the total water consumption.

When you build the formula, only the following metric definitions are available:
  • Metric definitions with the frequency that is the same as the calculated metric definition.
  • Calculated metric definitions with the same calculation level.
