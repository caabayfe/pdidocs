Formula indicators

Indicators (KPIs) define a performance measurement taken at regular intervals of a business service, an activity, or organizational behavior. These performance measurements result in a series of indicator scores over time.

Calculate scores from the scores of one or more other indicators. Apply mathematical operations or a preset method, such as the method to calculate the gap between an indicator score and the indicator target. The formula in an indicator has two main types of input:
  • Scores of other indicators.
  • Calculated values from the Analytics Hub for other indicators or for the formula indicator itself. Such calculated values include the change in indicator score between dates or the gap between the indicator score and the target on a specific date.

To insert an indicator score into a formula, click Browse for an indicator and select the indicator.

To insert a calculated value from the Analytics Hub, click Browse for a method. Select the method that returns the desired analytic. Tip: If the method requires you to specify another indicator as a parameter, highlight the parameter and use Browse for an indicator. Note that since the parameter is a calculated value for the indicator instead of the indicator score, a dollar sign $ precedes the name of the indicator.

You can use formula indicators as index indicators. Index indicators generate a single score that represents multiple indicators. In the following example, you want a single index that aggregates the gap between score and global target for the following indicators:
  • The percentage of incidents that are overdue.
  • The average age of the last update of open incidents.
  • The total number of open incidents.

In this example, the Direction of the indicator is set to Maximize, which is required for index indicators. The following formula is used:

var a = pa.getGap($[[% of open overdue incidents]], score_start) / pa.getGlobalTarget($[[% of open overdue incidents]], score_start);

var b = pa.getGap($[[Average age of last update of open incidents]], score_start) / pa.getGlobalTarget($[[Average age of last update of open incidents]], score_start);

var c = pa.getGap($[[Number of open incidents]], score_start) / pa.getGlobalTarget($[[Number of open incidents]], score_start);

var res = 100 - (100 * (a + b + c) / 3);

res;
