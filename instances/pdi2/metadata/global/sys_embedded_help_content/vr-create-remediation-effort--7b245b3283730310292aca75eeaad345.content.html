Create a remediation effort

When you want to hand over a list of remediation tasks to IT to fix vulnerabilities, create a remediation effort.

Before you begin

When you create a remediation effort, remediation tasks (VUL) are also created and automatically assigned to IT teams based on the group that is associated with the vulnerable items in the remediation effort.

Procedure

  1. Select the watch topic you want to create a remediation effort for.
  2. Click Create Remediation Effort.
  3. In Step 1 of the Effort details modal, verify or edit the fields and click Next.
  4. In Step 2, Task generation, choose one method for bundling the records into remediation tasks.
    If you choose, None, no remediation tasks are created from this remediation effort and you will have to add VIs manually.
  5. Click Next.
  6. In Step 3, Transfer, see how many additional, matching VIs are available for transfer into this effort and select any records that you want to include.
  7. Click Create remediation effort.
    • All active records are automatically pulled in that are not already part of an existing remediation effort for that Watch Topic.
    • If there are no records available from the watch topic, or no records are selected for transfer, the Create Remediation Effort button is deactivated.

    Also, remediation efforts are automatically deactivated and become inactive if there are no active records in them.
