Work with ERP systems

An ERP (Enterprise Resource Planning) system represents a connection to a section of your ERP system of record. For example, sales orders or vendor invoices.

The system plays a crucial role in data synchronization, sharing, and collaboration, enabling seamless integration and operation between the ERP model and the connected ERP system.

ERP systems are configured by ServiceNow® admins. Each installation of Zero Copy Connector for ERP supports adding up to 10 systems. However, Zero Copy Connector for ERP can connect to only one live ERP system at a time.

Zero Copy Connector for ERP regularly scans all connected ERP systems for the latest heartbeat, which indicates whether a ping to the ERP system connection is successful.
