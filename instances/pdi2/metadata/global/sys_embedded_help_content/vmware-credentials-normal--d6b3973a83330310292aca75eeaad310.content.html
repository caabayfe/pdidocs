Create VMware credentials

The VMware credentials type manages access to vCenter credentials. Applications that access VMware cloud resources need access to VMware credentials The VMware Discovery and automation API (vCenter API) now provides the globally unique serial number for computer CIs. CIM credentials aren’t needed to enable access to each VMware host.
Note: Windows credentials aren’t necessary for vCenter Discovery, when valid VMware credentials are used.
  1. Complete the fields in the form.
  2. To test your credential before you submit it, click Test credential under Related Links.
  3. Provide the connection specifics in the Test Credential dialog box and click OK.
  4. If the credential connects to the target, click Submit.
