Classic approvals

Important: Classic approvals have been replaced by the Workflow Studio. Use Workflow Studio to create approval logic. Some existing approval logic is still managed by classic Workflow. Use classic Workflow to edit existing workflow-driven approval logic.

The Approvals list shows the approval records in your instance.

Navigate to My Approvals to see a list of the approvals designating you as the approver.
  • Click the column headers to sort, filter, and edit data.
  • Select any row(s) and choose an action in the Actions on selected rows drop-down list to update the approval(s).
Note: The system can automatically generate an approval request to individuals or groups when specific criteria are met. The automatic generation of approval requests is driven using the System Policy feature.

The Approvals list includes the following columns:

State

Approval states include Not Yet Requested, Requested, Approved, and Rejected.

The Not Yet Requested state indicates that the approval request is not yet pending an action by the approver. Until you set the status to Requested, the approver will receive no email notifications about the request.

Approver
The user responsible for approving the related record
Comments
A journal field for storing comments about the approval
Approval for
The related record for which the approval is requested
Created
The date and time the approval was created
