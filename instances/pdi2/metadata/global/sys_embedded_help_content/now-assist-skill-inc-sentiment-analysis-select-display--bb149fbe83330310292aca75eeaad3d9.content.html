Incident sentiment analysis: Select display

Select whether you'd like to display the incident sentiment analysis skill in the product and the roles that you want sentiment analysis to be displayed.

Note: The itil role can view sentiment analysis by default. If you want additional roles to view the sentiment analysis, you can add them in the User roles field.
