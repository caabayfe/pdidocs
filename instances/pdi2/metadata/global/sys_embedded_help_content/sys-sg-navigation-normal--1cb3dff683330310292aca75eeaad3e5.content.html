Create a navigation bar

Use this interface to create a new navigation bar that appears at the bottom of the mobile app. Your users use the navigation bar to quickly navigate to screens, screen launchers, settings, and notifications.

  1. On the form, fill in the fields.
    Name
    Name of the app that uses this navigation bar. For example, Mobile Agent is the navigation bar name for the Mobile Agent app.
    Color
    The hexadecimal value for the color of the navigation bar. If this field is left blank, the default colors of the mobile theme are used.
    Quick Actions Menu Color
    The hexadecimal value for the color of the quick actions icon that appears on the screen. If this field is left blank, the default colors of the mobile theme are used.
  2. Click Submit.
