Export a list

Select a list in the List view and export its records to a selected file type.

Before you begin

Role required: sn_ohs_im.admin, sn_ohs_im.manager, or sn_ohs_im.agent

Procedure

  1. Select Export in the list.
    • To export only a few records, select the check boxes for records to be export.
  2. In the Export pop-up window, select the File Type and the Delivery Type.
    When exporting data as a PDF, you can also select the Orientation.
  3. Select Export.

Result

The system generates the data in the selected file type and downloads the file or sends it to you in an email.
