View solution relationships

View the taxonomy nodes and layers associated with the solution.

View relationships

The View relationships window displays the taxonomy nodes and layers of the solution. In the relationship map, the spinning circle indicates the source node. For each node, you can view a summary and current issues.

Summary

The Summary tab provides the solution details including its description, solution owner, support group, phase, and status. Display the summary details by selecting the summary icon ().

Current issues

The Current issues tab provides critical incidents and current outages associated with the solution. Select each card to navigate to the record. Display the current issues by selecting the current issues icon ().
