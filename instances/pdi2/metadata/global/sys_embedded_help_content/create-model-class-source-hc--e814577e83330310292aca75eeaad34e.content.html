Create new enterprise model classification source

Create sources that you can then assign to classification codes.

Before you begin

Role required: sn_eam.enterprise_asset_manager

Procedure

  1. On the Create New Enterprise model classification source page, enter the name of a source in theSource field.
  2. Enter a description of the source in the Description field.
  3. Select Save.
    The source appears in the Create sources page.
