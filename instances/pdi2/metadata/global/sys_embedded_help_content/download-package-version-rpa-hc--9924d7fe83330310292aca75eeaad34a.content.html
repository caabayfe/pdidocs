Download package version

Download a package version in the RPA Hub, so that it can be opened in the RPA Desktop Design Studio to build, debug, or modify the automation.

Before you begin

Create a package. For more information, see Create a package to assign to a bot process.

Role required: sn_rpa_fdn.rpa_release_manager, sn_rpa_fdn.rpa_developer, sn_rpa_fdn.rpa_robot, sn_rpa_fdn.rpa_support_user, sn_rpa_fdn.rpa_assisted_user, or sn_rpa_fdn.rpa_admin

About this task

Package version file is an ibot file that contains the automation logic that you can open in RPA Desktop Design Studio. To view this automation file (ibot), install the RPA Desktop Design Studio application in your machine. For more information, see Install RPA Desktop Design Studio.

Procedure

In the Attachments section, select an attachment, select the three-dot menu, and select Download.
