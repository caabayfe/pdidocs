Create internal learning content

Add internal courses so that agents can learn new content and enhance their skill set.

Before you begin

Role required: sn_lc.content_creator

Procedure

  1. In the Learning tab, go to Learning Courses > Internal Courses.
  2. Click Learning Courses and select Internal Courses.
    1. Click New.
    2. Fill in the field on the form.
    3. Click Save.
  3. Add a skill to the internal content.
    1. Click the Associated skills tab.
    2. Click New.
    3. In the Skill field, select a skill you want to associate with the internal content.
    4. In the Skill level field, select a skill you want to associate with the internal content.
    5. Click Save.
  4. Add a learning task to the internal content.
    1. Click the Learning Tasks tab.
    2. Click New.
    3. In the Assigned to field, select a trainee to whom you want to assign the learning task.
    4. In the Catalog field, select a catalog to associate with the learning task.
    5. In the Due date field, click the calendar icon and select the date and time when you want to trainee to complete the learning task.
    6. Click Save.
