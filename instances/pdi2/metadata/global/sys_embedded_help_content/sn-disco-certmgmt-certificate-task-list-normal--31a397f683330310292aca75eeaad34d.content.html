List of certificate tasks

The Certificate Inventory and Management application discovers and takes inventory of all your TLS certificates. It creates certificate tasks via flows to renew expiring certificates, creates incidents for already expired certificates, and prioritizes certificate importance.

Tasks for certificate renewals are automatically generated 60 days prior to expiration. Certificate tasks are automatically flagged with Priority 3 - Moderate. For renewal certificate tasks and incidents, various fields are pre-populated automatically based on the certificate CI. If there is already a certificate task existing for the current certificate, no additional tasks are created.

If a certificate is expired, a new incident is created if the expired certificate is not replaced. Only one incident is created for an expired certificate.
