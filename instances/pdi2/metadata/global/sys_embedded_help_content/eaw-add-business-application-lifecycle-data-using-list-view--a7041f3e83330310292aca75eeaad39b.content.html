Add business application lifecycle data using list view

Create or edit the life cycle of a business application to better manage the business application.

Before you begin

Role required: sn_apm.apm_analyst

Procedure

  1. Select the row context menu () next to the business application that you want to add business application lifecycle data for and select Add lifecycle data.
  2. On the Application model lifecycle details form, fill in the fields.
    For a description of the field values, see Application model life-cycle details form.
  3. Select Create.
