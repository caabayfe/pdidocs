Create a push action

Role required: admin.

Use this form to create a push action for your instance. A push action is a server-side script that runs when the instance receives a response to an actionable push message.

  1. On the form, fill in the fields.
    Label
    Label for the push action. This is the text your users will see in the notification for this action.
    Name
    Name of the push action.
    Response Type
    Select Simple or Text response. Actions using Text response prompt your users to enter text before completing the action.
    Placeholder Text
    Text displayed as a placeholder to your users when they initiate the actionable push.
    Application
    The scoped application for this record. This field automatically populates.
    Foreground
    Whether the app will open when your users select this action.
  2. Click Submit.
