Create a portal theme

Create a custom portal theme to expand on styles configured with the Branding Editor. Only users with an understanding of CSS should create custom themes.

  1. On the form, enter a name for the theme and then fill in the following fields.
    CSS variables
    Custom CSS properties that you can use to change the colors and styles of a portal. For example, $sp-logo-margin-x or $sp-tagline-color. Do not use CSS variables to define CSS rules.
  2. Select Fixed header or Fixed footer to affix the header or footer to portal pages so they remain on screen when a user scrolls.
  3. Select Submit.
