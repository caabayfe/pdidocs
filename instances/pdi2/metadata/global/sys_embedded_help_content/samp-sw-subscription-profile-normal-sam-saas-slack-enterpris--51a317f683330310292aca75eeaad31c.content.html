Creating a Slack Enterprise integration

Create an integration profile to connect your Slack subscription with the ServiceNow AI Platform. Use this integration to view software usage information and optimize stale licenses.

Important: Before you can save and publish the integration profile, you will need to create a Slack Enterprise Grid application to manage and connect the workspaces across your organization. You must also create a Slack application for each workspace that you want to track user activity on. After you create your applications, you must create a connection between each application and your ServiceNow instance so that you can retrieve user data from your workspaces.
