Viewing rule activities

View a summary of records in the backlog and the execution history for a specific rule on the table in context.

Rule details

View basic information about a rule including the following details:

Table
Table the data management rule was created against.
Data policy
Data policy that the rule belongs to.
Application scope
Application scope of the table that the rule was created against.
Type
The type of data management rule: archive, cleanup, or one-time delete.
Status
Current status of the rule. Either active or inactive.

You can stop a rule from running by selecting Deactivate.

Records in backlog

View the total number of records that meet the conditions for the rule but haven't been processed yet. The count is updated once a day.

Trend of backlog records

Track the backlog of records that meet the conditions for the rule but haven't been processed yet over time.

  • Track the progress of the rule over time.
  • Monitor data management rule efficiency and consider adjusting the conditions based on the trend in the backlog record count.
  • Check for bottlenecks that indicate a large number of records in the backlog waiting to be processed.

Execution history

View a detailed summary of the rule's execution history.

  • Determine when a rule last executed by checking the Execution time column.
  • Determine how many records were archived or deleted by checking the Records impacted column.
  • Determine how long the rule took to complete by checking the Duration column.
