Categories and subcategories

Roles required: admin or sn_ot_change_admin

  1. To change the application scope, do these actions:
    1. On the ServiceNow banner, select the globe symbol.
    2. Filter the list to find and select Operational Technology Change Management.
  2. Create a category.
    1. Select New in the right top corner.
    2. Enter the word category in the Element field.
    3. Enter the category name in the Label field.
    4. Enter the category value in the Value field.
    5. Enter the sequence number in the Sequence field.
    6. Select Submit to save the new category.
  3. Create a subcategory.
    1. Select New in the right top corner.
    2. Enter the word subcategory in the Element field.
    3. Enter the subcategory name in the Label field.
    4. Enter the subcategory value in the Value field.
    5. Enter the sequence number in the Sequence field.
    6. Select Submit to save the new subcategory.
  4. Change the application scope back to Global.
