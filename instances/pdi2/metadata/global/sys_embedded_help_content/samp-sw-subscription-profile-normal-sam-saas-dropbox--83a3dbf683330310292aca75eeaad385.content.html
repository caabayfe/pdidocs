Creating a Dropbox integration profile

Create an integration profile to connect your Dropbox subscription to the NOW platform. View software usage information and optimize stale licenses.

Before you can save the integration profile, you will need to create two OAuth applications on the DBX Platform. One application is for user subscriptions and one is for reclamation.

After you create your applications, use the following information from the DBX Platform to update the integration profile.

Using information from the application for user subscriptions:
  • Enter your app key in the Client Id field.
  • Enter your app secret in the Client secret field.
Using information from the application for reclamation:
  • Enter your app key in the Client Id field in the Reclamation Credentials section.
  • Enter your app secret in the Client secret field in the Reclamation Credentials section.

After you save the integration profile, click the Get OAuth Token and Get OAuth Token for reclamation related links to complete the connection.
