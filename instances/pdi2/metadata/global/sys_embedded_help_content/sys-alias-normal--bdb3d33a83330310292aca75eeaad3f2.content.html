Connection and credential aliases form

Define an alias to label a credential or connection record.

Name
Name of the alias; an only contain alpha, number, and underscore characters.
ID
Unique identifier for the Connections & Credentials alias.
Application
Application scope against which the Connection & Credentials alias is assigned.
Type
Select either Credential or Connection and Credential.
Connection type
Name of the connection type: Basic, HTTP, JDBC and JMS. Default is HTTP.
Support Multiple Active Connections
Indicates whether the alias supports multiple active connections.
Default Retry Policy
Retry policy for the alias.
Configuration Template
Configuration template to use to create a connection and credential record.
