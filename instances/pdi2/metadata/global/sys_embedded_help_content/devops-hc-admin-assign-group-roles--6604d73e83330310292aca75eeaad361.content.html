Assign Group roles

Onboard groups by assigning them roles.

Before you begin

Role required: sn_devops.admin

Procedure

  1. Select Group roles.
  2. From the group roles page, select Assign role.
  3. Select the group for which you want to assign a specific DevOps role.
  4. Select the DevOps role from the list.
    For more information on the roles, see Roles installed.
  5. If you want to also assign the same role to the child groups of the selected group, then select the Assign selected role to child groups option.
  6. Select Done.
