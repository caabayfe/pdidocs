Required Fields Scorecard

Role required: itil for reading, itil_admin (on top of itil) for full access.
Configure the threshold for best, at risk, and critical state definition for the required fields metric.

The required fields metric measures the percentage of CIs in which fields that are defined as mandatory, are not populated. Required fields are equivalent to the fields that are specified as mandatory in the system dictionary.

  1. If need to, click New to display the scorecard slider.
