Add an embedded help qualifier

  1. To get the information for the qualifier, open the module in a new browser window and record the query parameter.
    The query parameter follows the question mark after the page name, for example, home.do?sysparm_view=SLA.
  2. Enter the page to display the embedded help content. Do not include .do. For example, for the SLA homepage, enter home.
  3. Enter the query parameters.
  4. Enter the qualifier to use, for example sla-homepage. Record the qualifier to use in the embedded help content record.
  5. Enter the qualifier in the custom embedded help content you wrote for the page.
  6. Test the qualifier by opening the page you added the content for, and then opening the help panel.
