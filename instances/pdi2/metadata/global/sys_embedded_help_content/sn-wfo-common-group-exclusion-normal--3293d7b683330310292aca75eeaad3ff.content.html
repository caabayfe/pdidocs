Specify access for assignment group data in the manager workspace

Exclude access to assignment group data and display only the assignment groups that are relevant for the logged-in user.

  1. On the form, fill in the fields.
    Name
    Unique name for the one or more groups you want to exclude from displaying in the Workforce Optimization for ITSM manager workspace.
    Filter
    Add conditions to exclude specific groups.
  2. Click Submit.
    Note: You can also use scripted extension points to extend the definition of the groups that you manage in the Workforce Optimization for ITSM manager workspace.
