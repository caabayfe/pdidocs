Navigation bars list

Use the navigation bar list to view navigation bars configured in your instance.

Name
Name of the app that uses this navigation bar. For example, Mobile Agent is the navigation bar name for the Mobile Agent app.
Color
Hexadecimal value for the color of the navigation bar. If this field is left blank, the default colors of the mobile theme are used.
Legacy Application
Whether a given navigation bar is an outdated application.
Quick Actions Menu Color
Hexadecimal value for the color of the quick actions icon that appears on the screen. If this field is left blank, the default colors of the mobile theme are used.
