Create a catalog request from an interaction

Create a catalog request to initiate a catalog request flow from an interaction. You can create a request and associate the request with the interaction to help track requests associated with the interaction and vice versa.

Before you begin

Role required: itil

Procedure

  1. Navigate to All > Workspace Experience > Service Operations Workspace.
  2. Navigate to Lists > Interactions > All.
  3. Open the interaction for which you want to create a request.
  4. Select Create request from the drop-down menu next to Create incident.
  5. On the Service Catalog categories page, navigate to the catalog item or order guide that you want to order.
    Note: You can order items only from the catalogs that you have access rights to.
  6. Select Order Now.
    By default, the value in the Request for field is set to the person with whom the interaction is happening.
  7. Optional: On the Order Confirmation page, specify the shipping address in the Delivery Information field.
  8. Optional: On the Order Confirmation page, provide any additional information in the Special Instructions field.
  9. Select Checkout.
    The request is created and associated with the interaction.
  10. Select Close.
  11. Optional: View the created request by selecting View Details.
