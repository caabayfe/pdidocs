Create an enterprise asset shipment

Add a shipment for a transfer order, purchase order, move order, Return Merchandise Authorization (RMA) order, disposal order, resale order, recall order, reclamation request, Advanced Shipment Notification (ASN), or lease contract.

Before you begin

Role required: sn_eam.enterprise_admin

Procedure

  1. On the Create New Shipment form, fill in the fields.
  2. Select Save.
