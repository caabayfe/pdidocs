Users and roles

Roles required: admin

  1. Create user records for users that don’t already have an account in this instance.
  2. Assign the following roles to individual users or user groups as needed.
    CMDB OT Viewer (cmdb_ot_viewer)
    Can view OT device records
    CMDB OT Editor (cmdb_ot_editor)
    Can view and edit OT device records
    CMDB OT Editor (cmdb_ot_admin)
    Inherits Editor role and also can edit the OT Entity Type table.
