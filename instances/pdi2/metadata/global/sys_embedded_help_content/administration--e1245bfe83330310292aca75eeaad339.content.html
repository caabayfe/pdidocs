Administration

This section will let you create and define the administration tasks.

This application enables you to do these tasks:
  • Define the approval rules and integrate the approval flow within the Import Intelligence section after submitting the data import.
  • Define expiration rules for observables.
  • Create filter rules in order to filter the incoming source records data.
  • Customize threat score calculator that assigns threat score to the observables.
  • Manage email notifications.
  • Create report templates in both design time and runtime experience.
  • Configure and Manage Webhooks.
  • Manage the analyst actions through automation flows.
