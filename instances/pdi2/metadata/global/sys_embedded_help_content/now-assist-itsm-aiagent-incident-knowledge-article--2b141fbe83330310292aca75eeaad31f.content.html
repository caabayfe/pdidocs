Incident knowledge article AI agent

Using Incident knowledge article AI agent, search similar Knowledge Base (KB) and attach it to the incident record. You can also create a draft KB and attach it to the incident record.

Important: By default, all agentic workflow and AI agent records are read only.

To run the AI agents autonomously, you must first duplicate the agentic workflow, and then proceed with the following steps:

  • Activate the agentic workflow.
  • Activate all agents within the agentic workflow.
  • Activate the trigger to invoke the agentic workflow automatically. If you prefer to invoke it manually, activating the trigger isn’t necessary.
Important: In the Define availability screen for the AI agent, make sure that the Status field is enabled to activate the AI agent.
Using Incident knowledge article AI agent:
  1. Resolve the incident and search for similar KBs. You can select any of the recommended KB or enter any KB irrespective of any similar KBs found which is then attached to the incident record.
  2. If no similar KBs are available or you do not want to select from the available similar KBs, you can still choose to create a draft KB anyway. You can provide the input as ‘Draft’ in the Now Assist panel. In such case, the AI agent drafts and recommends a KB which you can link to the incident record.

In the Incident knowledge article AI agent screen, review all information and settings for the AI agent.
