Discovery probe and sensor performance metrics

By default, Discovery tracks the performance of individual probes, sensors, and patterns by measuring the processing time. When patterns are used, Discovery measures the Identification and Reconciliation Engine (IRE) processing time.
  1. Sort the result list by Discovery status to see the list of probes and patterns that ran in a specific Discovery.
  2. To open a record, click the build version for the Discovery you want to view.
