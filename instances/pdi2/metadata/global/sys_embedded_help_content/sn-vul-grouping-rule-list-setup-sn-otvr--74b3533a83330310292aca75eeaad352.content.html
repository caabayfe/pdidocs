Configure remediation task rules

Roles required: admin or sn_vul.manage_group_rules

When vulnerable items are imported, they can be added to remediation tasks based on Remediation Task Rules. If you use Vulnerability Response for both IT and OT networks, a change may be required if you group vulnerable items for remediation differently between IT and OT networks. A sample Remediation Task Rule record is provided to demonstrate how this can be managed if OT network vulnerabilities should not be grouped automatically.

Configure any new or existing Remediation Task Rules based on your remediation strategy:
  • If your remediation strategy is to create remediation tasks only for vulnerabilities in your IT environment, add the following condition to every existing remediation task rule to exclude OT vulnerabilities: [Configuration item.OT asset details][is empty]
  • If your remediation strategy is to automatically create remediation tasks for all OT vulnerable items, create an appropriate rule.
