Create a business calendar group

For Performance Analytics and Reporting to use business calendars, organize several calendars into a business calendar group. An application might also contain a business calendar group.
  1. On the form, fill in the fields.
    Name
    The name for the business calendar group.
    Description
    A description for the business calendar group.
  2. Select Submit.
  3. In the list of groups, select the group that you just created to view the record.
  4. In the Business calendars related list, select Edit.
  5. Select the business calendars that you want to add to the group.
  6. Select Save.
