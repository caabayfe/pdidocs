Workspace Config Properties

Role required: admin or sn_cmdb_ws.config_admin

By default, there are 4 config properties listed on sn_cmdb_ws_config_property.list that are assigned to the Default Config Identifier.
  • unifiedmap.map_search.max_nodes
  • unifiedmap.map_search_filter.default_levels
  • unifiedmap.map_search_filter.max_levels
  • unifiedmap.map_search_filter.endpoint_deduplication_fields
Note: :If you need to change the default settings, make a copy of these properties against the specific Config Identifier. This setting affects all users, and individual users cannot configure this setting.
