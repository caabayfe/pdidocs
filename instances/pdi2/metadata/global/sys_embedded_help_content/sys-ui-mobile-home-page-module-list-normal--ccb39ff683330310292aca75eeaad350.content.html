Mobile Home Page Module list

This list details the available home page modules available for your instance. Home Page Modules define what information appears on a mobile home page. Modules must be enabled for information to appear on a mobile home page. Administrators can also configure Home Page Modules by role.

Title
Name of the module that appears in the app or mobile web.
Subtitle
Optional module description that appears beneath the title.
Module
The module selected from the list of available mobile modules.
Active
Whether the module is currently in use.
Roles
Which roles have access to the module.
Icon
Icon associated with the module.
Image
Image associated with the module
Background Color
Background color for the module, in either a name or hexadecimal code. For example, #81878e or light gray.
Content Style
Style used for the module.
