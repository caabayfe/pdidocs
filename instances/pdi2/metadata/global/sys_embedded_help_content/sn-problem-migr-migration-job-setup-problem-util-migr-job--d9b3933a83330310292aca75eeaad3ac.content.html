Migration Job

Get your instance ready for the problem state model and migrate your records:

  1. Pre-check: Resolve blocking modifications and Review warning modifications before activating the problem state model plugin.
  2. Mapping: Problem mapping and Problem task mapping to define how to migrate records.
  3. Plugin activation: Activate the problem state model plugin.
  4. Migrate: Prepare base plugins and Restore base plugins to restore required base functionality, then Resolve blocking and warning modifications before migrating records, and finally, Migrate active records and Migrate inactive records.
  5. Migrated: Completed migrating.
