Track delayed shipments

Continue to track stale hardware asset shipments that are delayed due to known and valid reasons.

Before you begin

Role required: inventory_user (read) or inventory_admin

Procedure

  1. Select a shipment record that you want to track.
  2. On the Shipment Details form, select Ignore stale check check box.
  3. Select Save.

Result

  • The Stale shipment check box on the Shipment details form is automatically cleared.
  • The tracking number of this shipment is sent to the carrier for tracking but this shipment record isn’t marked as stale again.
