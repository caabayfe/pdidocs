Resource exchange request form

Resource Exchange is a KMF feature that gives you the capability to exchange resources between instances in a secure manner.

Exchange frequency
Specifies the frequency that keys are exchanged from source to target.
Source instance sys id
Enter the sys_id for the source instance to request keys from.
Source instance host
Enter the host location or name of the source or target instance.
Crypto specifications
Defines the keys to clone.
Enable rekeying after key imported
Option to enable auto rekey.
