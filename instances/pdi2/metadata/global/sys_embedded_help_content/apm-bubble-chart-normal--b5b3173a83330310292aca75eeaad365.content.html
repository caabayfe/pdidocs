Create, modify, or delete an application bubble chart

  • To create or modify an application bubble chart:
    1. Enter or modify the application bubble chart Name.
    2. Select or modify the Top left label from the list.
    3. Select or modify the Top right label from the list.
    4. Select or modify the Bottom right label from the list.
    5. Select or modify the Bottom left label from the list.
    6. Enter or modify the Top left color.
    7. Enter or modify the Top right color.
    8. Enter or modify the Bottom right color.
    9. Enter or modify the Bottom left color.
    10. Enter or modify the Quadrant label color.
    11. Select or modify the X Indicator from the list.
    12. Select or modify the Y Indicator from the list.
    13. Select or modify the Z Indicator from the list.
    14. Enter or modify the X Label from the list.
    15. Enter or modify the Y Label from the list.
    16. Enter or modify the Z Label from the list.
    17. Click Submit or Update to save.
  • To delete an application bubble chart, click Delete.
