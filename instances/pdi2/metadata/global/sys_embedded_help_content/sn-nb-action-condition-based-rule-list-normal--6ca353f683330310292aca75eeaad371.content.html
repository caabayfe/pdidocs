Rules

A rule is a set of conditions that applies to a context. A rule shows recommendations to users with certain roles for records that meet certain conditions.

Creating a rule includes the following steps:
  • Selecting the user roles that can see the recommendations associated with the rule.
  • Defining the conditions that apply to the rule.
  • Creating recommendations for the rule. A recommendation is a way to suggest a helpful action to a user.

New rules can only be created from within a context. To create a rule, open a context record and click New in the Rules related list and fill in the fields on the Rule form.
