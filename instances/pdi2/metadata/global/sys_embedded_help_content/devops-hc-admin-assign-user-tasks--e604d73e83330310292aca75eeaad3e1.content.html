Assign User tasks

Onboard users by assigning them tasks.

Before you begin

Role required: sn_devops.admin

Procedure

  1. Select User Tasks.
  2. From the User tasks page, select Assign task. If you want to assign the task to yourself, select Assign to me.
  3. Select the task from the Task list.
    For example, create an application or connect a tool.
  4. Select the user from the list.
    Only users whose roles allow them to perform the task are available in the list.
  5. Enter a due date and add your comments for the task if required.
  6. Select Done.
