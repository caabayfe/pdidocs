Create a catalog UI policy

Apply UI policies for catalog items ordered in the service catalog to control the behavior of catalog item forms when presented to your users. Catalog UI policies can be applied to a catalog item or a variable set.

  1. On the form, fill in the fields.
    Applies to
    Select the type of item this UI policy applies to: a catalog item or variable set.
    Catalog Item or Variable Set
    Select the catalog item or a variable set this UI policy applies to.
    Short description
    Enter a brief description of the policy.
    When to Apply
    Specify the conditions for when the catalog UI policy applies.
    Script
    Select the Run scripts check box to use the Execute if true and Execute if false scripting fields. Scripts are necessary to apply a UI policy other than Read Only, Mandatory, or Visible. For example, you must create a script to apply a UI policy to a specific role.

    With Now Assist for code generation enabled, you can provide text or code prompts to return AI-generated code suggestions and create catalog UI policy scripts quickly.

  2. Select Submit.
