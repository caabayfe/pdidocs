Policy administration

View and create policies, add categories, and view decisions of executed policies.

Policies

You can view a list of policies created by all users or view only policies that you have created. You can:
  • Click New to create a new policy.
  • Select a New blank policy or an existing policy template.

Tags and Categories

Categories and tags can be used to manage and group policies more efficiently.
