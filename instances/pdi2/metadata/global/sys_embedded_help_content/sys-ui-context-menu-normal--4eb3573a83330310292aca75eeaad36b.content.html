Create a UI context menu

Define a right-click menu, where it appears, and the menu choices.

  1. On the form, fill in the fields.
    Table
    Select the table to which this context menu option is attached.
    Menu
    Select the list context menu in which this option appears.
    Type
    Select the type of menu option to create. Depending on the type you select, additional fields are available. Action and dynamic actions include corresponding script fields.
    Run onShow script and onShow script
    Select this option to make the onShow script field available. An onShow script runs before the context menu is displayed to determine which options appear in the context menu.
    Condition
    Define conditions that restrict when the menu option appears, such as restricting it to certain users.
    Action script
    If you select action or dynamic actions for Type, create a script that runs when someone selects the context menu option.
    Dynamic actions script
    If you select dynamic actions for Type, create a script that populates the context menu with dynamic options, such as filters or views.

    With Now Assist for code generation enabled, you can provide text or code prompts to return AI-generated code suggestions and create scripts quickly.

  2. Select Submit.
