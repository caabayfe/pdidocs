Vulnerability Response risk calculators

Vulnerability calculators automate the initial values for the fields on vulnerable items (VIT) records. The Vulnerability Response application includes two vulnerability calculators that set the base Risk score based displayed on vulnerable item records, the Default Risk Calculator and the Vulnerability Severity calculator. Only one of these calculators can be active to determine the values for Risk score. Some key terms and more details about these calculators and rollup calculators are included in the following list.

Vulnerability Severity
Risk scores calculated with Vulnerability Severity are based on conditions such as: 1 - Critical, 2 - High, 3 - Medium, 4 - Low, 5 - None. These scores are referred to as, Normalized Vulnerability Severity.
Default Risk Rule
Risk scores calculated with the Default Risk Rule use weighted parameters that determine values that incorporate each parameter's weight in overall risk score calculations. You can change these weights and customize the parameters for this rule. Default parameters include: Service Business criticality, Vulnerability Severity, Vulnerability Exploit skill level, Vulnerability Exploit exists, and Vulnerability Exploit attack vector.
Risk Rule
Calculators use Risk Rules to determine vulnerable item Risk Scores. You can only create new risk rules for calculating values for the Risk Score as a target field on a VI.
Calculate Risk Score
Risk score is determined by the active calculator when a VI is created, when an configuration item (CI) or vulnerability changes, or if you click the Calculate Risk Score link on a VIT record.
Create a vulnerability calculator
You can create vulnerability calculators to prioritize and rate the impact of vulnerable items based on any criteria by using condition filters. Additionally, you can use attributes in the configuration_item [cmdb_ci] in the Configuration Management Database (CMDB) to help you create logic for your Vulnerability Response risk calculators.
Rollup Calculators
Vulnerability rollup calculators configure how the cumulative, overall risk score is computed and rolled up for all the VIs in remediation efforts, remediation tasks, and for all VIs with the same imported vulnerabilities. Three rollup calculators are shipped with the base system: Remediation Task (VUL) Rollup, Vulnerability Entry Rollup, and Remediation Effort Rollup.
