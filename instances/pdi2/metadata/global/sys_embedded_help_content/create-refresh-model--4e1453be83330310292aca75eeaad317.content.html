Create a Zero Touch Refresh model

Create a Zero Touch Refresh model and associate it with replacement models so that they’re available for Zero Touch Refresh requests. A Zero Touch Refresh model is the asset model that is refreshed and replaced with the replacement model.

Before you begin

Role required: admin

Procedure

  1. On the form, fill in the fields.
  2. Select Save.
  3. In the Replacement models tab, select Add.
  4. In the Replacement Model window, select the models that you want to add as replacement for the refresh asset model and select Add.
  5. Select Save.
