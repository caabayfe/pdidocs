Create a new improvement initiative

Create an improvement initiative for a vendor to track and manage tasks for improving a service, process, or tasks related to vendors.

Before you begin

Role required: sn_vlm.vendor_manager, sn_vlm.vendor_admin, or admin

Procedure

  1. To create a new improvement initiative, fill in the fields on the form.
  2. To add an attachment to the initiative, do the following:
    1. Select the attachments icon ().
    2. Select Browse.
    3. Select the file you want to attach to the initiative.
    4. Select Upload.
  3. Select Save to create the initiative.
