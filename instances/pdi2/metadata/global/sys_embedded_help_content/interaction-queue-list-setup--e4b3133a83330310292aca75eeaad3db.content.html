Interaction queues

Interaction queues define a category that interactions can be grouped for assignment, for example, a queue called IT support would contain any IT inquiries. Queues define the default messages, schedule and escalation path.

Users can be assigned as agents for an interaction queue if they are a member of the group associated with the interaction queue. For example, the IT support interaction queue has the ITSM Engineering group associated with it. Any agents in the ITSM Engineering group are agents for the IT support queue.
