Users and roles

Role required: admin

  1. Create any new user records for any users that do not already have an account in this instance.
  2. Then assign the following roles to individual users or user groups as needed:
    Amazing reader (sn_ot_amazing_read)
    Users with this role can access OT Subnet Mapping records in the ot_subnet_mapping table.
    Amazing writer (sn_ot_amazing_write)
    Users with this role can edit OT Subnet Mapping records in the ot_subnet_mapping table.
    Amazing admin (sn_ot_amazing_admin)
    Inherits sn_ot_amazing_write. Users with this role can edit OT Subnet Mapping records in ot_subnet_mapping table and also edit OT Subnet Mapping properties.
