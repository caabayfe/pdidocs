Move project- Schedule view

Work on move requests using a calendar view.

The schedule view is an interactive calendar view displayed according to your local time zone. You can also switch from a calendar view to a list view using the calendar icon placed at the top right of the calendar.

This scheduler view enables you to do these tasks:
  • Know the user who raised the move request.
  • View the current state of that move request.
  • View and edit the expected start and due date if necessary.
  • Change the calendar dates, switch between a week and a month view.
  • Schedule a move request to another date by simply dragging the bar of the request.
