Run NVD Integrations for OT Hardware Vulnerability Assessment

Role required: Admin

Run the National Vulnerability Database (NVD) integrations to import data from the NIST NVD product to help you determine the severity and details of CVEs found in your environment.

  1. Use the Scope Picker to change your scope to Vulnerability Response Integration with NVD.
  2. Click Configure to open the jobs for NIST National Vulnerability Database Integration - CVE, CPE and Unmapped CPE.
  3. In the Integration Details tab of each job, set the Import Since field value to 1999-01-01 or earlier.
  4. Click Execute Now.
