Create, modify, or delete a knowledge base

  • To create or modify a knowledge base:
    1. Enter or modify the Title of the knowledge base.
    2. Next to Icon, upload the icon image file that you want to associate with the knowledge base.
    3. To prevent users from commenting on articles in the knowledge base, select the Disable commenting check box.
    4. To prevent users from suggesting edits to articles in the knowledge base, select the Disable suggesting check box.
    5. To prevent contributors from creating or editing the knowledge base categories, select the Disable category editing check box.
      If this check box is selected, only knowledge managers can edit the knowledge base categories.
    6. In the Owner field, enter or modify the name of the knowledge base owner.
      Knowledge managers cannot update the Owner field.
    7. Under Managers, add or modify the list of users who you want to designate as knowledge managers.
    8. From the Publish workflow list, select the publishing workflow for articles within the knowledge base.
    9. From the Retire workflow list, select the retiring workflow for articles within the knowledge base.
    10. To make the knowledge base active, select the Active check box.
    11. To enable social questions and answers in the knowledge base, select the Enable social questions and answers check box.
    12. Enter or modify the Description of the knowledge base.
    13. From the Set default knowledge field values lists, select the default values for knowledge articles in the current publication.
    14. Click Submit or Update.
  • To delete a knowledge base, click Delete.
