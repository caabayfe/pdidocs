Working with flow logic

Use flow logic to control when and how to run actions.

Use code-like logic, such as If and For Each, to create conditional and looping sections in your flow.

  1. On the Flow Designer homepage, select + New > Flow.
  2. On the Flow properties screen, give your flow a name.
    All other fields are optional. So, when you're ready to start building your flow, click Submit.
  3. Search for and select any trigger to add to your flow.
  4. Fill in any required fields for your trigger, and click Done.
  5. Under Actions, select Select to add an Action, Flow Logic, or Subflow.
  6. From the list of options, select Action to open the action picker.
  7. In the action picker's search window, enter the name of any action that you want to add to your flow.
  8. Fill in the action's inputs, and then click Done.
  9. Under Actions, select Select to add an Action, Flow Logic, or Subflow.
  10. From the list of options, select Flow Logic.
  11. Choose from the list of flow logic options.
    Flow logic choices include:
    If
    Run one or more actions only when the conditions that you set are met.
    Else If
    Only for use within an If flow logic block. Run one or more actions only when:
    • The conditions you set in the If block are not met, and
    • More conditions that you set are met
    Else
    Only for use within an If flow logic block. Run one or more actions only when the conditions you set in the If block are not met.
    For Each
    Loop through a list of records and run one or more actions for each record. For example, update the short description for each record in a list of incidents.
    Do the following until
    Repeat one or more actions until the conditions that you set are met.
    Do the following in parallel
    Run several actions in the same order within separate, parallel paths.
    Make a decision
    Use a decision table to choose between multiple branching paths. Typically, you use a decision table as an alternative to a sequence of If, Else If, and Else flow logic.
    Wait for a duration of time
    Pause the flow until an exact, relative, or percentage of time that you choose.
    Call a Workflow
    Run a published and active workflow from your flow. You can use the flow data as a workflow input.
    Dynamic Flow
    Identify which flow or subflow to run using dynamic runtime data. Typically, you use dynamic flows instead of creating multiple flows with nearly identical triggers.
    Get Flow Outputs
    Get outputs and runtime values from dynamic flows.
  12. Under your flow logic's name, set the values for the flow logic's inputs.
    Inputs support static and dynamic values. A static value is one that you directly enter. An input with a static value always uses the value you enter. A dynamic value is a reference to a data pill. An input with a dynamic value gets generated each time the action runs.To add a data pill to an input, select it from the data pill picker icon, or drag it from the Data panel.
    Note: Try using a data pill from the action that you added in the previous step.
  13. When you're done setting the values for all of your flow logic's inputs, click Done.
    The Data panel displays the data pills generated by your flow logic.
You're ready to test your flow for any errors.
