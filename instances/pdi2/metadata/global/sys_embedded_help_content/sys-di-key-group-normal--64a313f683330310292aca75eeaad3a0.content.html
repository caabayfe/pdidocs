Create a field group

Create a field group to extract data from documents with tables, check box lists, and other logical groupings of fields.

For an improved DocIntel setup, configuration, and monitoring experience, install the Document Intelligence Admin application.

  1. On the Field Group form, fill in the fields.
    Display Name
    Name of the field group
    Use Case
    Use case associated with the field group
    Type
    Type of fields in the group (for example, text fields, check boxes, table fields)
    Target Table
    Table where you want to save the extracted data
    Parent Mapping to Field
    Field on the target table you want to align with this field
    Mandatory
    [Text field groups and tables only] Option to indicate whether the field group is required
  2. Submit the field group.
    The field group is created and can be associated with the field.
