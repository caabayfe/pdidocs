Set up the response due date rules for your DLP incidents

Role required:
  • sn_dlir.admin - Create, edit, and delete.
  • sn_dlir.analyst - View (read-only).

Set up the response due date to determine how much time that you want to give your end users to respond to the assigned Data Loss Prevention (DLP) incidents.

  1. To create a Response Due Date Rule, click New.
  2. On the form, fill in the fields.
  3. If you want to define escalation rules, select the Escalate option.
  4. Define the conditions to escalate such as whom to escalate the issue to, the maximum escalation levels, and so on.
  5. Click Submit.
