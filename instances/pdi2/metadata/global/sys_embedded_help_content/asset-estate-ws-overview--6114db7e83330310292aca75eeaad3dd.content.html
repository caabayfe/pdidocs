Asset estate view

View the asset functions and notifications such as expiring assets, expiring lease contracts, and take appropriate actions.

Select any widget or chart to view in detail and take the required actions. For details on the widgets, scroll down to the Asset overview table.

You can also use Domain, Location, Stockroom, and Model category lists to narrow down your results.
Note: The Domain filter is available only when you’ve enabled the Domain Extensions Installer (com.glide.domain.msp_extensions.installer) and Domain Separation (plugin com.snc.pa.domain_support) plugins.
Note: The Software license tab is hidden when Software Asset Management (com.snc.software_asset_management) or Software Asset Management Professional (com.snc.pa.samp) is active. You can view this Software license tab in Software Asset Workspace.
