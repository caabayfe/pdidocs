System event alerts list

This is a list of system alerts on an instance level.
Note: The alerts are usually validated every 15 minutes approximately.

By default, 5 alerts are provided along with the instance. You can also edit the existing 5 alerts and can also configure more alerts.

In order to open the Event Alert form, use either of the following 2 ways.
  • Selecting the Created column of the required alert.
  • Selecting the 'i' icon.
Note: If you select the Alert Configuration column, the Event Alert Configuration form for the selected alert shows up.
