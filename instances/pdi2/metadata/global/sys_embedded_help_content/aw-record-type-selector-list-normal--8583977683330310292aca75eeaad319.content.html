Workspace record type selectors

Workspace record type selectors are used to configure the record types that are available when you create a change from a related list in Workspace. This configuration enables you to categorize your change records according to your preferred categorization.

Target table
Table associated with the change or problem request. For example, Change Request or Problem Task.
Target field
Field type for the record. This field determines the selections in the Type field on the Workspace form.
Value
Specific value from the target field that is displayed on the Workspace form. Change the value on the Workspace form by selecting another value from the list.
Application
Application that this Workspace record types selector applies to. Global means that the Workspace record types selector applies to all Workspace applications.
Active
Option to activate the Workspace record types selector.
Order
Integer that determines the placement of this Workspace record types selector in the Workspace Record Types Selectors list. The lower the number, the earlier it appears in the list. Typically, these numbers are in the hundreds. For example, 100, 200, 300, and 400.
