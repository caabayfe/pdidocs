Claim Summarization: Review and activate

Review the settings for the claim summarization skill and then activate the skill for the Financial Services Workspace, Core UI, and the Now Assist panel.

Review the settings on this page and then activate the skill by selecting Activate. If you want to make a change to a setting, select Back and then make your change.

After you activate the skill, you can change these settings at any time. In Now Assist Features > Customer > FSO, select the Insurance skill category. Access the skill by selecting the skill name from the Active skills list, and then make your changes.
