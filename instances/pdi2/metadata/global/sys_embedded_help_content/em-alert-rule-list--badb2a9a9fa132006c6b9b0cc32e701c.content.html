Configure launch application within alert action rule

Use the Alert Action rules form to configure how to launch an application. You can also use the Alert Action rules form to create alert action rules, to configure remediations to associate workflows with alerts for manual or automated remediation.

  1. To create a new alert action rule, click New or click an existing alert action rule to modify it.
  2. Click the Launcher tab.
    Table 1. Alert Action Rule form - launch application
    FieldDescription
    Launcher tab
    EnableSelect to launch web-based applications from the Alert Console or dashboard alert panel. This action occurs once only for each event.
    Display NameDescriptive name for the window that appears when users launch the application.
    URLA dynamic URL that uses specified fields in the alert, including the Source and Additional Information fields. For example, the values in these fields in the alert replace the parameters in the URL: http://${source}.com/${cmdb_ci.name}.

    In an alert, the value in the Source field is used for the {source} section of the URL.

    The Additional Information field contains a JSON code with the value of {my_application}, such as {'my_application':'application_name'}.
  3. Click Submit or Save.
