Config data

The Config data tab contains a read-only tree view structure containing all of the config data for the application relating to its deployables, collections, and components.

Select a node in the tree to view the config data for that node in the application service or infrastructure service. To edit the config data, you have to open a changeset.

An application's config data tree has a fixed folder structure: Deployables, collections, and components. Search for a node name or select an entry in the config data tree to view its configuration details.

Select the copy name path to clipboard icon () to copy the name path of the node.
  • List view toggle: Select the List view toggle switch to view config data in a list.

    You can export the config data items (CDIs) of the selected node from the list view by selecting Export.

  • Edit config data: Select Edit config data to edit the CDIs in a new or existing changeset.
