Providing context for NLU provider HTTP connections

The HTTP Connections [http_connection] table defines connection information, but the Open NLU Driver HTTP Connections [open_nlu_driver_http_connection] table defines when to use it. In other words, the Open NLU Driver HTTP Connections table provides context for the connection.

Each supported NLU provider has multiple records in the table (one per function). Each record describes the HTTP method and the function that it performs. You can also link it to a new or existing record in the HTTP Connections table, where you configure the host URL and path.
