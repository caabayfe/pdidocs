Decrease sensitivity to similar anomalies

Make anomaly detection less sensitive to anomalies like the one that triggered the alert.

Before you begin

Role required: evt_mgmt_operator or evt_mgmt_admin

About this task

The Raise feedback option raises the threshold for generating a Log Analytics alert when similar anomalies are identified in the future.

Note: This option is not available for customer alerts and new signal alerts.

Procedure

  1. While viewing the alert in the Service Operations Workspace, select Apply ML feedback > Raise.
  2. Confirm the action in the dialog box.
    Note: Processing this feedback might take a few seconds.
  3. Optional: Restore normal sensitivity to anomalies like the one that triggered the alert.
    1. While viewing the alert, select Remove feedback.
    2. Confirm the action in the dialog box.
