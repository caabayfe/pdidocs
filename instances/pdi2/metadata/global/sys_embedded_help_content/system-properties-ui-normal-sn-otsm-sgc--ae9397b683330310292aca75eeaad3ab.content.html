Staging table configuration

This task requires either the admin or cmdb_ot_admin role.

To determine which factors constitute in identifying a unique name for a CI, we have introduced 3 new system properties:

  • Enable CMDB Validations - sn_otsm_sgc.enable.cmdb.validations
  • Transformed name - sn_otsm_sgc.excel.fields.for.transformed.name
  • Transformed name Delimiter - sn_otsm_sgc.excel.transformed.name.delimiter

Note: Set this system property before importing to staging table.
