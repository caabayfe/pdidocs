Review class mappings

Role required: admin or cmdb_ot_admin

  1. Select the class mapping record that you want to review.
  2. Review and update the following fields in the class mapping records as needed.
    Source Class
    The class of the source CI.
    Target CMDB class
    The expected ServiceNow class that for the CI.
    OT Device type
    The category type that the OT device is classified as. The device type is also the function that the device plays on the OT network. For example:

    An IT device, such as a server, can be converted to an OT device, and the function it plays on the network is an HMI. Therefore, its class is server and its device type is HMI.

    Note: In some cases, there are OT devices with no OT function or OT devices where the device type is unknown. For OT devices with no OT function, select No OT Function. For OT devices where the device type is unknown, select Unknown.
    Allow OS classification
    When set to True, if an operating system is found on the CI, the target is switched away from this map's target class to a ServiceNow class that matches its OS.
    Active
    When checked, the class mapping is set to Active for classification.
