Understanding user criteria for event types

Manage user access for any event type such as meeting, training, and time-off requests in the team calendar.

You can include or exclude Create, Read, Write or Update, and Delete (CRUD) rights for users, groups, or roles to event types using the inclusion and exclusion user criteria access.

By default:
  • Users have role-based access to manage event types.
  • Team members do not have read-access to event types of type Actual work.
