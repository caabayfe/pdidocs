Table Migration

In the non-scoped version of HR, there are 7 base tables that are automatically mapped for migration to scoped. There are 26 total tables if the Human Resources Scoped App: Service Portal plugin (com.sn_hr_servie_portal) is included. These tables have default columns and choice lists that are also automatically mapped for migration. By default, all base tables (and their corresponding columns and choice lists) should map automatically. You can verify that the mapping is correct.
