Create a mobile home page section

Role required: admin.

Use this form to create a Home Page Section for use in your applet. Home Page Sections determine how apps appear in a mobile home page.

  1. On the form, fill in the fields.
    Title
    Title of the home page section. This appears in the app or mobile home page above the list of modules.
    Hide Title
    Click to enable this and hide the home page section title so it doesn't appear on the page.
    Module Style

    How the modules appear in the section. Regular shows the modules as rectangles that stretch the length of the app or mobile web. Compact displays the modules as smaller "app-like" squares.

    Active
    Click to enable the Home Page Section to be put into use.
    Roles
    Configure Home Page Sections by role.
  2. Click Submit.
