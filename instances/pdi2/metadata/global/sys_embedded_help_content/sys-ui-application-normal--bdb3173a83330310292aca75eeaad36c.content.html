Create a Mobile Application Menu

Role required: admin.

Use this form to create a menu for the ServiceNow Classic Mobile app, to define which application menus and modules are available on the navigator. You cannot hide the application navigator, but you can control contents based on role. Use the Roles field to configure the application navigator specifically by role.

  1. On the form, fill in the fields.
    Name
    Enter a name for the application menu.
    Order
    Enter a number to specify the order of the menu. For example, an entry of 100 puts this application menu before an entry of 200.
    Roles
    Click the lock icon to select the roles for this application menu. Only users with the designated roles can access the modules under this application menu.
    Active
    Select the check box to set this application menu in use.
  2. Save the Application Menu.
    Note: Until you add at least one module, the new application menu does not appear on the mobile application navigator.
  3. Click New.
  4. Fill in the fields as appropriate.
    Name
    Enter a name for the module.
    Order
    Enter a number to specify the order of the module within the application menu.
    Application Menu
    Displays the application menu from which you accessed this screen. Select a different application menu, if appropriate.
    Table
    Select the table for this module.
    Updated
    Displays the date and time when the module record is updated.
    Roles
    Click the lock icon and select the roles for this module. Only users with the designated roles can access this module.
    Active
    Select the check box to activate this module. Only active modules appear in the application menu.
    Filter
    Create a filter for identifying which fields this module uses from the selected Table.
    Path

    Enter a custom URL for the module in this format: <type_of_link>/table/parameters.

    You can also use the URL format $__.do.

    Path Relative to Root
    Allows mobile navigator modules that link to desktop pages. Select this check box to use mobile URL in the Path field, such as $sp.do, $chat.do, or $vtb.do. When the Path Relative To Root is cleared, the path is considered a mobile specific path and is relative to $m.do.
    Note: If you are creating a module for a map page, see Create a smartphone map page module.
  5. Click Submit.
