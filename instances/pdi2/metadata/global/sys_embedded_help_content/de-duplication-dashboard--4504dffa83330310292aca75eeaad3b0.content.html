De-duplication dashboard

Use the De-duplication dashboard in CMDB Workspace to see an overview and insights about duplicate CIs in your CMDB. The De-duplication dashboard lets you create de-duplication templates and organize these templates into libraries. You can also examine tasks and then run or schedule a template to remedy multiple tasks in a single operation.

The De-duplication dashboard in CMDB Workspace is a central location for remediating de-duplication tasks. Review the de-duplication templates and ensure that they're properly configured to remediate duplicate CIs that are being added to the CMDB. From the dashboard, you can also perform the following actions:
  • Select Run all to run all templates, with each template remediating its assigned and matching tasks.
  • Select View de-duplication tasks to open a list of de-duplication tasks with details such as the template assignment.
  • Select the context menu icon and then select View template libraries to create and manage templates and libraries.

De-duplication templates

Each card shows details about a template. The cards are split among these tabs:
Ready
Cards for published templates. You can select Assign task to assign tasks to the template and then run the template to remediate its associated tasks.
Running
Tracks templates that are currently running. Select Cancel to stop a running template. If there are no running templates, the tab instead shows View list of tasks and Create a template.
Completed
Status and details on the final state of a run.

You can create a schedule for a published de-duplication template so it can automatically run on a recurring interval. Select the More options icon for the template that you want to create a schedule for.

Note: Various fields, such as Time zone and Time appear on the form according to your choice in the Run field. If Run is Periodically, you must set the Repeat internal (day) or the Repeat interval (time) fields (or both) before you can save the schedule.

De-duplication insights pane

The cards on the De-duplication insights pane help with the ongoing de-duplication processes. Some cards provide links to help you resolve issues:
De-duplication tasks remediated
Tasks that were remediated in the past week.
De-duplication tasks completed with errors.
Tasks that need your attention. Provides the View de-duplication tasks that need your attention link to access a list view of the associated tasks. You can examine error messages and drill down tasks for further troubleshooting details.
De-duplication tasks that don't match a template.
Tasks that can't be assigned for remediation by a template. Provides the View de-duplication tasks that don't match link to access a list view of the associated tasks. You can drill into tasks for details.
