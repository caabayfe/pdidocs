Space optimization dashboard

Use the Space Optimization dashboard in Workplace Analytics to analyze space capacity and utilization trends to achieve optimal use of workspaces.

The following default reports are displayed in the Space Optimization dashboard:
Note: The reports displayed only show data for the past year. You can adjust the data range by using the available filters for Date, Region, and Allocation.
  • Capacity vs utilization: This report displays the available space resources versus its occupancy.
  • Peak utilization days: This report displays the average utilization for days of the week.
    Note: Average utilization is calculated as follows:Average utilization = [Total utilization in hours for a weekday/Number of spaces available for the week day]
  • Space utilization by workplace entity: This report displays the average capacity and average utilization based on the workplace entity.
  • Space type utilization: This report displays the average capacity and average utilization for a type of space.

For more information, see View Space Optimization metrics.
