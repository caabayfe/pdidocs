Add details to a new personal portfolio

Create a personal portfolio to combine a group of services, service offerings, business applications, and application services. The first step to creating a new personal portfolio is to add the details.

Before you begin

Role required: sn_dpm.dpm_manager

Procedure

  1. Enter the Details of your new personal portfolio.
    • Name
    • Description
    • Editors (optional)
    • Viewers (optional)
    The Owned by field defaults to your name. You can change the Owned by field if you want another user to own the personal portfolio.
  2. Select Next.
