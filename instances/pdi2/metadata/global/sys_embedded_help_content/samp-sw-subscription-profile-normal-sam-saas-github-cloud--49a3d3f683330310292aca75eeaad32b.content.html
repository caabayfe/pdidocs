Creating a GitHub Enterprise Cloud Integration

Create an integration profile to connect your GitHub Enterprise Cloud applications with the ServiceNow AI Platform. Use this integration to view software usage information and optimize stale licenses.

Important: Before you can save and publish the integration profile, you will need to generate a personal access token that grants access to the GitHub Enterprise Cloud APIs. Use this personal access token to create a connection between your GitHub Enterprise Cloud applications and your ServiceNow instance so that you can retrieve user data from each application.
Important: If you want to use a MID Server for communication between your ServiceNow instance and your GitHub Enterprise Cloud applications, you will need to set up a MID Server on your instance before you can create a GitHub Enterprise Cloud connection and integration profile.

The integration profile uses the GitHub Cloud Download Subscriptions, GitHub Cloud Update User Activity, and GitHub Cloud Reclaim Subscription subflows to retrieve user data from your GitHub Enterprise Cloud applications. You can select the date and time that you want to analyze user activity from in the Analyze user activity from field on the Calculate Activity Subflow tab. You can start analyzing data from the current date or from up to 60 days prior. To avoid performance issues, ServiceNow recommends setting this field to a maximum of seven days prior to the current date.
