Now Assist Admin overview

Begin your exploration of generative AI features with the Now Assist Admin console. The Now Assist Admin console is the central hub for the administrative side of generative AI implementation on the ServiceNow AI Platform .

The Overview panel displays information about the status of your skills and plugins in a graphical format, including:

  • Summary of installed plugins and skills
  • Prompts to install additional plugins and features
  • Performance information for your active skills
