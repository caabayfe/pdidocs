Configure UI Actions

In order for a UI action to appear in Agent Workspace, each UI action needs to have the appropriate workspace-specific check box selected.

To enable a UI action for the workspace, click New or open an existing UI action. Then, on the Workspace tab, select one of the following:
  • Workspace Form Button: Appears as a button on the form in the workspace.
  • Workspace Form Menu: Appears under the ellipsis form menu.
