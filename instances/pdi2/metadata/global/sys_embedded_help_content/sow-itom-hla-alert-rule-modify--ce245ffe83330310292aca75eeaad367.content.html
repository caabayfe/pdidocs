Modify a defined Log Analytics alert rule

Modify a Log Analytics alert rule that you have defined.

Before you begin

Role required: evt_mgmt_operator or evt_mgmt_admin

Procedure

  1. On the Log viewer, open a defined alert:
    1. Select the selection icon () and then choose Manage my defined alerts from the drop-down list.
    2. From the Defined alerts table, select the alert rule that you want to modify.
  2. On the form, update the settings.
    For a description of the settings, see Add a Log Analytics alert rule.
  3. Select Save to save your changes.
