Filter the integrations launchpad display

Filter the Integrations Launchpad Browse and Installed integrations tabs to help you focus on the integrations that you need.

Before you begin

Role required: evt_mgmt_integration

Procedure


  2. In the primary navigation, select the Integrations Launchpad icon ().
  3. Determine the integrations you want to view in the Browse Integrations tab and Installed Integrations tab.
    1. Select the All integrations drop-down list in the respective tab.
    2. Select the integrations to display.
      • All integrations - View all existing integrations (default)
      • Pull - View only pull connectors.
      • Push - View only push connectors.
      • Custom - View only custom connectors.
      • ACC-M - View Agent Client Collector Monitoring connector metrics.
      • HLA - View Health Log Analytics data inputs.
  4. Determine the integrations you want to view by their statuses in the Installed Integrations tab.
    1. Select the All Statuses drop-down list.
    2. Select the integrations you want to display by status.
    • All statuses - View all the integrations (default).
    • Active - View active integrations that were successfully installed
    • Inactive - View inactive integrations that were successfully installed.
    • Draft - View in-progress integrations with a configuration that was started but not completed.
    • No data- View integrations that were successfully installed with no data.
