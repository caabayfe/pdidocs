Create a role filter criteria

Configure an authentication policy to allow or deny access to a list of specific user roles.

  1. On the form, fill in the fields.
    Name
    Name to identify the role.
    Description
    Short description of the role.
    Application
    Scope of the application.
  2. From the Roles for criteria, double-click Insert a new row.
  3. Create a condition for a specific role using the Condition Builder.
    For example, you can create a condition that allows only users with admin, itil, or snc_internal roles.
    Note: Currently, Dot-walking is not supported in Role filter criteria.
  4. Click Submit.
