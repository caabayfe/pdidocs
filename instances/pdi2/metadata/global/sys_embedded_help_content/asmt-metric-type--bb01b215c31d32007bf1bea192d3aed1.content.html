Create, modify, or delete an assessment metric type

  • To create or modify an assessment metric type:
    1. Enter or modify the assessment metric type Name .
    2. Enter or modify the Assessment duration in days and hours.
    3. Select or deselect the Live feed check box.
    4. Select or deselect the Notify manager if overdue .
    5. Select or modify the Assessment Manager .
    6. Enter or modify the Scale factor from the list.
      The scale factor enables the definition of a custom numerical scale for a metric type's assessment results.
    7. Enter or modify the Signature .
    8. Enter or modify the Return URL .
    9. Select or modify the Schedule type from the list.
    10. Select or deselect Allow retake check box.
    11. Select or edit the user Roles from the list.
    12. Select or deselect Active check box.
    13. Enter or modify the Description .
    14. Select the Conditions tab.
    15. Select or Modify the Table from the list.
    16. Select or deselect Enforce condition .
    17. Add or modify filter condition or set the OR clause in Condition .
    18. Select the Decision Matrix tab.
    19. Select a Filter field from the list.
    20. Set the filter conditions.
    21. Select Default matrix filter from the list.
    22. Click Update to add the record or Publish to publish the assessment.
  • To delete an assessment metric type, click Delete .
