Predictive Intelligence Workbench use case templates

To plan which use cases to implement, it's important to have a good understanding of your existing business processes within the ServiceNow AI Platform. Engage with your business process stakeholders to create a change management plan for each respective process to deploy machine learning use cases into production.

Predict Assignment Group template

To implement your first use case, it's a good idea to start with the Predict Assignment Group for incoming incidents use case template. Similar to the Predict Category for incoming incidents use case template, this use case template helps streamline your triaging and incident resolution process by automatically assigning incidents to the correct group of people. After implementing this use case, depending on your data maturity, you can implement other use case templates.

Predict Category template

Categorization helps to route incidents to the right team and saves a lot of time in troubleshooting. You can prioritize using both the Predict Category for incoming incidents use case template along with the Predict Assignment Group for incoming incidents use case template.

Predict Service template

A service delivers value to you by facilitating outcomes you want to achieve without needing to own specific associated costs and risks. Services typically have three aspects:
  • Interaction,
  • Offering
  • Service system

If you have a well-populated Configuration Management data base (CMDB), prioritize using the Predict Service for incoming incidents use case template before using the Predict Configuration Item for incoming incidents use case template.

Predict Configuration Item template

The CMDB creates and maintains the logical configurations your network infrastructure needs to support a service. These configurations consist of entities called configuration items (CIs), which are part of your environment. A CI can be any of the following:
  • Physical entity, such as a computer or router
  • Logical entity, such as an instance of a database
  • Conceptual, such as a Requisition Service

Try to prioritize using the Predict Configuration Item for incoming incidents use case template after the Predict Service for incoming incidents use case template and based on your data maturity and relationship between CIs and Services.

Note: To ensure the relationship between the service and CI are in sync and are inline with Common Service Data Model (CSDM) principles, enable the com.snc.incident.ci.bs.ml.validation.enable property, which is false by default.

Glossary

Use case template:
A card representing a predefined use case seeded within Predictive Intelligence Workbench.
Use case:
A task that uses machine learning alongside existing business processes to drive the outcomes it describes. Each use case will have a machine learning model operating within it.
Models:
Data-driven business rule created by machine learning by gaining knowledge about your existing use-case data.

What to do next

Next, you will create your own use case. It's recommended that the use case name and description you provide reflect the purpose of the use case. Typical purposes include the process task for which the use case will apply, as well as, the business outcomes it will benefit.

If you know the KPI that might benefit from the use case, track those metrics in a Performance Analytics dashboard.

Note: Optimally, configuring a use case requires domain expertise, details for which are provided on relevant pages.
