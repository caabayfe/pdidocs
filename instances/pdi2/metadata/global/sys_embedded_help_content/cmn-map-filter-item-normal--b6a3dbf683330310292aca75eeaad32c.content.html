Create a map page filter item

Configure a map data item before accomplishing this task.

Role required: admin.

Use this form to create a map page filter item. Map filters can be configured using lists and forms, or scripting. These filters enable you to see only the map markers for the data that you want.

  1. On the form, fill in the fields.
    Name
    Choose a name for your map page filter item.
    Label
    Select a title for your Map Page filter item to display with the map filter in your Map Page.
    UI type
    Select a UI type for the Map Page filter item: Single selection, Multiple selection, or Date picker. When you select Date picker, the data item fields hide and the default value script appears.
    Data type
    Select a data type for the Map Page filter item, Data item or Scripted. A data item enables you to configure or select data items using lists and forms.
    Data item
    Select a data item for the Map Page filter item.
    Data item table
    Select a data item table for your Map Page filter item.
    Note: This field is automatically populated when a data item is selected.
    Data item value field
    Select a data item value field for the Map Page filter item.
    Default value script
    Add a script for the Map Page filter item.
  2. Click Submit.
