Map to sites

To limit visibility of OT devices to OT users who have been assigned to those sites only, add a site to the OT device. After sites are added to OT devices, only users with both a cmdb_ot_viewer, editor or admin role and a cmdb_ot_isa_viewer or editor role and have been assigned the same site as the OT device will have visibility. To assign sites to OT devices individually:
  1. Open the OT device you want to assign a site to.
  2. Update the ISA entity site field with the appropriate site value.
To assign sites to multiple OT Devices at the same time:
  1. Filter the list to show only the OT devices you want to assign to a single site that have already been created in the Equipment Model (an entity with no parent is considered a "site").
  2. Click the ISA Entity Site cell on the first row you want to update.
  3. Hold down SHIFT and press the down arrow until all the rows you want to edit are highlighted.
  4. Click ENTER and then select the Site you want to assign to all the OT devices.
