Schedules

Role required: admin

  1. Create a schedule.
    1. Enter schedule name in the Name field.
      As a practice, prefix the schedule name with short code of the site it's meant for.
    2. Enter the purpose of the schedule in the Type field.
    3. Pick a suitable time zone.
    4. Enter a description in the Description field.
    5. Click Submit.
  2. Create a schedule entry.
    1. Click New in the Schedule Entries tab​.
    2. Enter a suitable name in the Name field.
    3. ​Select a start date-time and an end date-time in the When field.
    4. Select repetition unit in the Repeats dropdown​.
    5. Optional: Select repeat frequency in the Repeat every field.
    6. ​Select the granular repetition unit as appropriate in either the Repeats on, Monthly type, or Yearly type fields.
    7. ​Select the repetition end date in the Repeat Until field.
    8. Click Submit.
