Create, modify, or delete an application indicator

  • To create or modify an application indicator:
    1. Enter or modify the application indicator Name.
    2. Enter or modify the Short description.
    3. Enter or modify the Result limit check box.
    4. Select or deselect the Active check box.
    5. Select the Category from the list.
    6. Select or modify the Automatic refresh interval from the list.
    7. Enter or modify the Order.
    8. Select the Data Source Configuration tab.
    9. Select the Data source from the list.
    10. Select the Indicator from the list.
    11. Select the Default breakdown from the list.
    12. Enter or modify the Normalization script.
    13. Select the Click Through tab.
    14. Select the Click through URL navigation type from the list.
    15. Use the default script or modify the Click through URL script.
    16. Click Submit or Update to save.
  • To delete an application indicator, click Delete.
