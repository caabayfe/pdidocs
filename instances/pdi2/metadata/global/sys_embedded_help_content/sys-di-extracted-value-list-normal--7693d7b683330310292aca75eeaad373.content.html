Field values

The Field Values list shows the field values that were generated from DocIntel document tasks.
  • Select (or right-click) the column headers to sort, filter, and edit the list.
  • Select the Personalize list icon to choose the columns in your list.
  • Select a field value to view and edit the value details.

The Field Values list includes the following significant columns:

Data
Field value extracted from the document
Field
Field from the use case that the value belongs to
Is Reviewed
Indicates whether the field value has been reviewed
Keystrokes
Number of keystrokes that were needed to produce the field value

For an improved DocIntel setup, configuration, and monitoring experience, install the Document Intelligence Admin application.
