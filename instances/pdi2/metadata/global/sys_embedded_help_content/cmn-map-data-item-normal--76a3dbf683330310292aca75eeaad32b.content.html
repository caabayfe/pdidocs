Create a map data item

Role required: admin.

Use this form to create map data items for your instance, to render data on your Map Page in the Classic Environment. Create a container for your map data items first, then configure and select the data items for your Map Page.

  1. On the form, fill in the fields.
    Name
    Select a name for the map data item.
    Table
    Select the table for the condition. For example, select the Choice [sys_choice] table.
    Condition type
    Select whether the condition uses declarative or scripted conditions.
    Conditions
    Select the declarative conditions for your map data item.
    Query condition script
    Insert the script condition for your map data item.
  2. Click Submit.
