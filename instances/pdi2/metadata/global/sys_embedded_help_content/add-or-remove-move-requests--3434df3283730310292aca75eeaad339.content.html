Add or remove move requests

You can add more move requests to the project or remove a request if it is no longer required.

Before you begin

Role required: sn_wsd_move.manager

Procedure

  1. To add move requests, do the following:
    1. Select Add new requests.
      A new tab opens.
    2. Select the move requests that you want to add using the check box next to them.
      You can also apply a filter on the requests if necessary.
    3. Select Add.
    The selected move requests are added to the move project.
  2. To remove move requests, do the following:
    1. Select the List option to view the move requests in a list view.
    2. Select the move requests that you want to remove using the check box next to them.
    3. Select Remove.
    The selected move requests are removed from the move project.
