Expected OT Devices

Role required: ot_progress_scorecard_editor role and cmdb_ot_isa_viewer with site access assigned for relevant sites
Note: See Create User Criteria for Site Users guided setup step for more information. To navigate to the Create User Criteria for Site Users guided setup step, complete the following actions:
  1. Open the Industrial Process Manager Guided Setup.
  2. In the Manage the Equipment Model section, select Create User Criteria for Site Users.
  3. Select Configure.
  4. Create the user criteria records as needed.

To use the % of Expected OT Devices in CMDB indicator, you need to enter the expected number of devices per site.

  1. Click Configure.
  2. If the record for the site does not exist, click New.
    Otherwise, open the record for the relevant site.
  3. Update the Site field if necessary.
  4. Choose Expected OT Devices as the attribute.
  5. Edit the Value field and update it with the number of expected devices.
    Do not include OT control modules.
  6. Save and close the record.
