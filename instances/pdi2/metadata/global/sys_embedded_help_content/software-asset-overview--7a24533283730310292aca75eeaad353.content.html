Software asset overview

Use the Software asset overview landing page to understand and mitigate your compliance risk, manage your software usage, optimize your software spend, and view life cycle information for all your products.

You can filter the dashboard by publisher or products. Select a widget to take you to that page. All the widgets are updated whenever a new reconciliation result is available. For details on the widgets, scroll down to the Software asset overview dashboard metrics table.

Use the Activity center to gain valuable insights into your software assets via time sensitive alerts and notifications. To learn more about an alert or notification, click on it.

Perform routine tasks such as creating entitlements or running the reconciliation process to calculate your products' compliance status.

Select Create entitlement to perform any of the actions:
  • Import all your entitlements at one go using a Microsoft Excel spreadsheet.
  • Create entitlements with step by step instructions using the Playbook for Software Asset Management.
  • Create entitlements using the standard form layout.
