Optimization and savings

View actual and potential cost savings for your software assets. You can also view recommended licensing optimizations for specific third-party software publishers, including Microsoft, Red Hat, Adobe and SAP. Use this information to downgrade or reclaim licenses so that you can optimize your licensing costs.

You can use the Domain filter to narrow your results based on the domain that you select. The default value for the Domain filter is global. You can select a domain at any given time for widgets to reflect the selected domain. If you clear the selected domain, it defaults back to global.

The Domain filter appears on the screen only if the following plugins are installed:
  • Domain Support - Domain Extensions Installer (com.glide.domain.msp_extensions.installer)
  • Performance Analytics - Domain Support (com.snc.pa.domain_support)
