Document tasks

The Document Tasks list shows the DocIntel document tasks in your instance.
  • Select (or right-click) the column headers to sort, filter, and edit the list.
  • Select the Personalize list icon to choose the columns in your list.
  • Select a document task to view and edit the task details.

The Document Tasks list includes the following significant columns:

Display Name
Name of the document task
Is Processed
Indicates whether DocIntel has completed the analysis of the attached document(s)
Is Straight Through Processed
Indicates whether the task was automatically completed using auto-filled fields in Fully automated mode
Status
Status of the task
Use Case
Use case associated with the task

For an improved DocIntel setup, configuration, and monitoring experience, install the Document Intelligence Admin application.
