Translation and workflow preferences settings list

This list provides details of the available translation workflow process settings in your instance. These settings are defined for one or more activated languages to request translations in Localization Framework.

Name
The unique identifier for the setting.
Artifact
Artifact for the settings being defined.
Languages
Target records of the languages available in the instance.
Workflow
Selected workflow for translations in one or more selected languages.
Enable machine translate
Option to enable machine translation service for one or more selected languages.
Enable TMS
Boolean value showing whether the Translation Management System for one or more selected languages is active.
Enable send via email
Boolean value showing whether the email service for content localization for one or more selected languages is active.
Enable export/import
Boolean value showing whether the export and import of content for translation for one or more selected languages is active.
