Data visualization types

When you configure a data visualization, you select the type of chart to display. Each visualization type is suited to show different data.

Score visualization types

Scores are single data points either across ranges or as a single value.

Time series visualization types

Time Series visualizations show data over time. All time series visualization types share the same configuration options. They differ in use case, depending on whether you want to emphasize data trends or the differences between individual data points.

Bar visualization types

Bar visualizations enable you to compare scores across data dimensions. Horizontal and vertical bar visualization types are available. They share all configuration options. In general, use horizontal bars for nominal or categorical data. Use vertical bars for ordinal or sequential data.

Pie and Donut visualization types

Pie and donut visualizations show the relationship between parts and the whole of a data set. The segments of these charts should total to 100%.

Multidimensional charts

Multidimensional charts show more than two attributes of the data.
