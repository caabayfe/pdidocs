Assign Incident to CI Support Group action

Set the incident assignment group to the assignment group of the associated configuration item.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Incident
Data type: Record

Reference to the incident whose assignment group you want to update.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Incident
Data type: Record

Reference to the updated incident.
