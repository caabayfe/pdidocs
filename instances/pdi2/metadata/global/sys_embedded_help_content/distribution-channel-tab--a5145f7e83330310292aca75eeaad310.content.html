Distribution channel

Distribution channel is a list view of the channel stockrooms that are preferred for sourcing assets to the base stockroom.

You can select New to link a stockroom to the base stockroom to create a distribution channel. When a distribution channel is created, the base stockroom uses the channel stockroom for sourcing the assets. Also, the base stockroom is added as an outbound channel for the channel stockroom.

Note: You can't create distribution channels for a stockroom that doesn't support sourcing assets through distribution channels.
