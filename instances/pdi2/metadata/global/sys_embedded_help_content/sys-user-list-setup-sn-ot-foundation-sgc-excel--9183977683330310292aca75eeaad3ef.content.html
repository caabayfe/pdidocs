Users and roles

Roles required: admin or user_admin

Assign roles to individual users  or user groups as needed to manage the Excel Service Graph Connector staging table and ETL.
ot_staging_user
Can create, edit, and view records in the staging table.
cmdb_inst_admin
Can view and edit the ETL.
ot_excel_import_user
Can create, edit, and view Import Tasks. This is the minimum role to perform Excel SGC imports via Import Tasks. This role contains ot_staging_user.
cmdb_ot_editor
Can view and reassign Excel SGC Remediation Tasks. Needs additional ot_staging_user role to perform Remediation Tasks.
cmdb_ot_admin
Can perform both Import and Remediation Tasks. This role contains both ot_excel_import_user and cmdb_ot_editor.
