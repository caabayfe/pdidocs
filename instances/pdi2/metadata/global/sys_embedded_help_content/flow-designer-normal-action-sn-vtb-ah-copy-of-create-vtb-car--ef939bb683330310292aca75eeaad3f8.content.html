Create VTB Card action

Create a task card on a Freeform VTB board.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Board
Data type: Record

Reference to the VTB to update.

Lane
Data type: Record

Reference to the VTB lane to update.

Task
Data type: Record

Reference to the task record to associate.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Task
Data type: Record

Reference to the VTB task card created.
