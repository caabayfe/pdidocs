View the SIR Workspace Dashboards

You can view important metrics to analyze your Security Incident Response process such as new security incidents or the average age of open security incidents.

The SIR Workspace includes data visualizations that can help you monitor your remediation progress.

The SIR Workspace supports two types of dashboards:
  • Standard dashboards:
    • Security Analyst Overview
    • Security Incident Manager Overview
    • CISO Overview
  • Performance Analytics (PA) for Security Incident Response Dashboards:
    • Security Incident Explorer
    • CISO
    • Security Incident Management
    • CISO Reporting Overview
    • Security Operations Efficiency
    • Security Incident Management Premium KPIs
    • Context Sensitive Analytics – SI
