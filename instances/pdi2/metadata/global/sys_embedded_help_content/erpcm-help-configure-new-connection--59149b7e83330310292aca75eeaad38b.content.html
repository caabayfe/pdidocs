Configure a new ERP Semantic Mining connection

Specify the Connections and Credentials alias for ERP Semantic Mining (ERP-CM) to connect to the ERP (Enterprise Resource Planning) system.

Before you begin

You should install Zero Copy Connector for ERP and add credentials there before you install and configure ERP-CM.

Role required: sn_erp_integration.erp_admin, sn_erp_mining.erp_admin

Procedure

  1. Navigate to All > ERP Foundation > ERP Customization Mining.
  2. Select the connection status icon () in the side panel.
  3. Select the Select connection button.
    If you've already configured a connection and want to use a different connection and credential, you should update the connection instead.
  4. In the Connection and credential alias box, choose the credentials you configured in Zero Copy Connector for ERP from the Select connection & credential alias field.
  5. Select Connect.
    ERP-CM begins extracting data from the connection.
  6. Refresh the Issues to review and Executed tasks lists by selecting the refresh icon ().

Result

After the connection is complete, you can check the connection status and investigate errors at any time on the Connection status page.
