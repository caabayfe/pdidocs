Define a custom planning item type

Role required: admin

Define a new planning item type so that you can later use it to configure your planning hierarchy.

  1. Ensure the application scope in your instance is set to Alignment Planner Core.
  2. On the form, fill in the fields.
    For details on the form fields, refer to the documentation from the Related information section below.
  3. In the Controls section, set the User role field to sn_align_core.apw_user so that you grant access to Alignment Planner user to this table.
  4. In the Application Access section, enable the Can read, Can create, Can update, and Can delete fields.
  5. Save the form.
