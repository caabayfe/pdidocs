Create a problem

Identify the root cause of incidents to try to prevent them from happening again. Generate a problem record manually from a problem module and an incident. Create a record producer to log problems from the service catalog. Generate a problem from email when an appropriate inbound email action is configured.

Before you begin

Role required: itil, sn_problem_write, problem_admin, problem_manager, or problem_coordinator, and admin

Procedure

  1. Perform one of the following actions to start creating a problem.
  2. On the form, fill in the fields on the Details tab.
  3. To add an attachment to a problem task, from the Contextual side panel, click the attachments icon ().
  4. To create templates for reuse, from the Contextual side panel, click the templates icon ().
  5. Click Save.
