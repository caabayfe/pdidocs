List filters

Initially, the list of records has the same filters applied as the section of the visualization you clicked. Change them in the Filter Panel.

For example, if you have a donut visualization of incidents grouped by priority and you click in the Priority 1 - Critical segment, you see a list of the Incident records where the Priority is 1 - Critical. You can clear filters in the Filter Panel, which you open from the list actions.

The basic view of the Filter Panel lets you remove any of the filters on the list. To restore filters that you have removed, select Restore defaults. To add more filters, select Advanced view.

Advanced view

In the advanced view, you can do the following:
  • Replace the current filter with a predefined "existing filter."
  • Save the current filter, adding it to the list of existing filters.
  • Replace the current filter with one you construct using the condition builder.
  • Add more conditions, which you construct using the condition builder.
Note: You cannot add filters from the Use existing filter list. You can only use that list to replace the currently selected filters.
