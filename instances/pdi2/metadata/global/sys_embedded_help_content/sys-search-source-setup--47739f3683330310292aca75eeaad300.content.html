Configure search sources

  1. In the Name field on the search source form, type a name for the search source.
    The name of the search source appears as a category in the search results. Make sure you choose a name that agents can easily identify.
  2. From the Table list, select the table you want to create a search source for.
  3. Use the condition builder to create a filter to limit the search results.
