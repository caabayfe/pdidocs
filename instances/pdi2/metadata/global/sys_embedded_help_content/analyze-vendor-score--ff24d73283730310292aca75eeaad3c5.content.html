Analyze vendor score

Monitor the average vendor score and analyze the trend over a given time period.

Before you begin

Role required: sn_vlm.vendor_manager

About this task

You can access the vendor score page when you click on the Performance icon (), select a vendor, and click on a vendor KPI.

Procedure

  1. Click the calendar icon () and select the start and end date for which you want to view the vendor score trend.
  2. Add or edit targets for the vendor KPI.
