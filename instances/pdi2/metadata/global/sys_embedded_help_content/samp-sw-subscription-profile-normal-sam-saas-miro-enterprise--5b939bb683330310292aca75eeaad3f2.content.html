Creating a Miro Enterprise integration

Create an integration profile to connect your Miro Enterprise applications with the ServiceNow AI Platform. Use this integration to view software usage information and optimize stale licenses.

Important:

Before you can save and publish the integration profile, you will need to create an OAuth 2.0 application to enable access to the Miro API. You will also need to enable SCIM (System for Cross-domain Identity Management) on your Miro Enterprise account so that you can generate an API access token for authenticating your Miro API requests.

In addition, you must create a connection between the OAuth 2.0 application and your ServiceNow instance and a connection between the Miro Enterprise SCIM and your ServiceNow instance so that you can retrieve user data from your Miro Enterprise applications.
