Add software by a publisher for exposure assessment

Add software by a publisher to the Exposure Assessment module to assess the impact of a new vulnerability or zero-day vulnerability.

Before you begin

Role required: sn_vul_analyst.vul_event_manager

Procedure

  1. Select New.
  2. In the New assessment window, select the publisher for which you want to perform the assessment.
  3. Select a date in the CVE published from field.
    If any of the Common Vulnerability Entries (CVEs) associated with the software is modified after the selected date, then that software is considered for exposure assessment.
  4. Select the severity level of the CVE in the CVE Severity section.
  5. Select Start assessment.
    Once the job is completed, the selected records are created.
