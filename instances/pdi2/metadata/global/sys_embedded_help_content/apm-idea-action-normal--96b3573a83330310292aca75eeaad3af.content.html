Create, modify, or delete an idea action

  • To create or modify an idea action:
    1. Enter or modify the action Name.
    2. Enter or modify the Description.
    3. Select a Strategy from the list.
    4. Enter or modify the Title.
    5. Select a Business Application from the list.
    6. Select a Rollout Entity from the list.
    7. Select a date for Implement by Fiscal year from the list.
    8. Select the Estimates tab.
    9. Select an Effort size from the list.
    10. Select an Estimated financial benefit from the list.
    11. Click Submit to save the record or Update to save the modified record.
  • To delete an action, click Delete.
