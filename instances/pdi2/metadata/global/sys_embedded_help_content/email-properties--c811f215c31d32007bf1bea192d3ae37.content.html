Email properties

Your ServiceNow instance can send email notifications for specific system events, such as updates to incidents or change requests. To support notifications, the default email configuration includes a POP3 mailbox on a ServiceNow email server and a ServiceNow SMTP server to process outbound email messages.

To test email notifications, enter a comma-separated list of email addresses in the Send all email to this test email address (non-production testing) field.
