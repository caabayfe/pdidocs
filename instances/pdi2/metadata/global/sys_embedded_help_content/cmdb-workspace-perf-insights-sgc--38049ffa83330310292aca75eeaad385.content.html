CMDB performance insights: Service Graph connectors

The Service Graph connectors tab contains charts, tools, and aggregations that enable you to evaluate the performance of your service graph connectors.

Note: To edit data source or scheduled data import records from CMDB Workspace, you might need to set Application scope to the Application of the data source or data import.

Connectors data source

Configurations on your Service Graph Connector data sources affect handling and processing of incoming data. Changing your Service Graph Connector data source configurations can streamline data handling, making your CMDB more efficient and improving performance.
Sources with batch processing turned off

Shows the percentage of Service Graph Connector data sources in the Data Sources [sys_data_source] table with disabled Use Batch Import. It also lists the total number of data sources, and the number of data sources with enabled or disabled batch processing.

To enable batch processing, access the record of a specific data source from the list view and select Use Batch Import. For more information on batch processing, see Data source fields.

You can also select Edit to update a data source from the list view. See Edit a data source from CMDB performance insights.

Sources with concurrent import turned off

Shows the percentage of scheduled data imports of Service Graph Connector data sources in the Scheduled Data Imports [scheduled_import_set] table with Concurrent Import turned off. It also lists the total number of scheduled data imports and the number of scheduled data imports with Concurrent Import turned on or off.

To improve performance with concurrent import, access the record of a specific scheduled data import from the list view and select Concurrent Import. See Concurrent imports.

You can also select Edit from the list view to update a scheduled data import. See Edit a scheduled data import from CMDB performance insights.

Sources with non-custom size partition method

Shows the percentage of scheduled data imports of Service Graph Connector data sources on the Scheduled Data Imports [scheduled_import_set] table that use a non-custom size partition method. It also lists the total number of scheduled data imports and the number of scheduled data imports that use a non-custom size partition method.

To use a custom size partition method, access the record of a specific scheduled data import from the list view. Ensure that Concurrent Import is selected. From the Partition Method drop-down menu that appears, select Custom size. For more information on partition methods, see Schedule a data import.

You can also select Edit from the list view to update a new scheduled data import. See Edit a scheduled data import from CMDB performance insights.

Connectors execution trends

Aggregates Service Graph Connectors with outlier connector executions, where the number of imported rows or the rate of processing is significantly higher or lower than the 30-day trend.

Connectors with processing rate outliers

Shows the number of Service Graph Connectors that are considered outliers with connector execution processing rates outside the expected trend lines within the past 30 days.

You can drill into Connectors with processing rate outliers card to access the Service Graph connector execution trends window and view additional information on processing rates.

Connectors with import count outliers

Shows the number of Service Graph Connectors that are considered outliers with connector execution import counts outside the expected trend lines within the past 30 days.

You can drill into the Connectors with import count outliers card to access the Service Graph connector execution trends window and view additional information on import counts for Service Graph Connectors.
