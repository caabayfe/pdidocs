Using the DLP User Workspace

Access the Data Loss Prevention Incident Response (DLP) End User portal, and review the assigned DLP incidents and report or resolve them.

Before you begin

Role required:
  • End user
  • sn_dlir.analyst_read and sn_dlir.read - View DLP Incidents.

Procedure

  1. Select a list view to review the incidents that are assigned to you.
  2. Select one or more DLP incidents that you want to review, and select the check box next to the incidents.
  3. Choose the action that is appropriate for you.
