Creating a SAP HANA integration profile

Create an integration profile to connect your SAP HANA applications with the ServiceNow AI Platform. Use this integration to view software usage information and optimize stale licenses.

Important:

Before you can save and publish the integration profile, you will need to create an OAuth 2.0 application to enable access to the SAP HANA API.

In addition, you must create a connection between the OAuth 2.0 application and your ServiceNow instance so that you can retrieve user data from your SAP HANA applications.
