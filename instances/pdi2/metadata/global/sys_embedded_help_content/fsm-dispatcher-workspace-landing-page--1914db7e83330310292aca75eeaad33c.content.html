Dispatcher Workspace

Dispatcher Workspace is a configurable scheduling application that enables you to efficiently route work to field service agents and monitor their performance.

To access the Dispatcher Workspace, navigate to Workspaces > CSM/FSM Configurable Workspace > Dispatcher Workspace.

The CSM/FSM Configurable Workspace contains the Dispatcher Dashboard and Dispatcher Workspace
  • Dispatcher Dashboard is a home page and displays the following real-time data of the operations and performance of field service agents across their assignments in your organization.
    • Statistics on critical pending dispatch tasks and SLAs breached.
    • Field service agents who are behind the schedule.
    • Instant visibility into the agents' presence status such as On site, Off shift, On Route etc.
    • Dispatch map with the visual indicators for location of the field service agents and work order tasks.
  • Dispatcher Workspace is the main working space for dispatchers to schedule work order tasks, bringing speed and efficiency to field service scheduling. It offers dispatchers and managers a complete view of tasks, teams, locations, and statuses.
    • Schedule and dispatch work order tasks.
    • Apply filters to manage task visibility.
    • Personalize task cards with customized information.
    • View schedules and availability of technicians.
    • Monitor performance metrics of technicians.
    • View the locations of tasks and agents on the dispatch map.

Dispatcher Workspace views

Dispatcher Workspace provides a filter to display the work order tasks and agents related information in various views, such as map view, hybrid view, and schedule view.

Map
Display the geographic positions of various tasks and agents on a map within the context of workspace.
Schedule
Display a tabular representation of scheduled tasks within the calendar view. This view include daily, weekly, or flexible days schedules displaying both task appointments and employee schedules.
Hybrid
Display a merged map and schedule view, offering a flexible approach that enables dispatchers to seamlessly select tasks or agents from the calendar while simultaneously viewing their geographic locations on the map. This enhances the user experience of a dispatcher.
