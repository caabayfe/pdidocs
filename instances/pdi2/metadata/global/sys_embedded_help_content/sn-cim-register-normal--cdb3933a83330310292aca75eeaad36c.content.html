Configure an improvement

  1. Add the Short description for the improvement.
  2. Describe Why this improvement is important.
  3. Align the improvement with one or more strategic objectives in the Strategies field.
  4. Set these attributes on the Goals tab.
    • Success measurement method
    • Improvement KPI
    • Target value
    • Target review date
  5. Once the improvement has been submitted, configure these related lists.
    1. CIM Phases: Configure a high-level phase for tracking tasks.
    2. CIM Tasks: Create one or more tasks for the work required to complete the improvement.
    3. Impacted KPIs: Add any other KPIs (leading or lagging) to monitor with the improvement initiative.
  6. On the header bar, click the next state to progress the improvement.
