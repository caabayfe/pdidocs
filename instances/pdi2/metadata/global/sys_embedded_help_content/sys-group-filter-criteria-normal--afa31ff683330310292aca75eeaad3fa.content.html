Create a group filter criteria

Use the Group filter criteria to allow or deny user access based on the user group to which the user belongs.

  1. On the form, fill in the fields.
    Name
    Name to identify the group.
    Description
    Short description of the group.
    Application
    Scope of the application.
  2. From the Groups for criteria tab, double-click Insert a new row.
  3. Click the search icon, look up, and select a user group.
  4. Click the save icon.
  5. Click Submit.
