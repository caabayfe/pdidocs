Create a tag

You can create and assign tags to records directly from the form or list view. You can also add tags to a homepage.

To create a new tag using the Tag form, fill in the following fields and submit the form.

Name
Name of the tag
Owner
Owner of the tag
Type
Specifies the type of tag.
  • Standard is controlled by users who have access to the tag. These users can add or remove records from the tag.
  • Most Active displays the most frequently accessed modules.
  • Most Recent displays the most recently accessed modules.
  • Most Active Record displays the most frequently viewed records.
  • Most Recent Record displays the most recently viewed records.

Only tags with Standard or Most Recent Record types appear on the Tagged Documents page. You can view other types of tags by adding them to a homepage.

Viewable by
Users who can view the tag. Tags can be visible to any user (global), only to specific groups or users (shared), or to a single user (private).
Active
Specifies whether the tag is enabled.
