Configure a push connector

Integrate with a push connector to connect to an external event source to push event information to your ServiceNow instance.

Before you begin

Role required: evt_mgmt_admin

Procedure

  1. .
  2. In the primary navigation, select the Integrations Launchpad icon () from the left navigation panel.
  3. In the Browse Integrations tab, select the All integrations drop-down list and select Push.
    Only push connectors are displayed.
  4. Select a push connector type tile.
  5. Provide details about the connector type on the Provide details screen.
    For information about a field, select its information icon ().
    1. In the Connector name field, enter a unique name for the connector type.
    2. Optional: In the Description field, enter information to help identify this connector type.
    3. Optional: From the Assignment group drop-down list, select the record from the assignment groups table containing the assignment group of the connector.
    4. Verify that the vendor name in the Source field is correct.
    5. Select Next.
  6. Optional: Set the tags.
    Tags help locate and identify connectors of this type and are added to the events.
    1. Next to the Tags field, select the plus sign.
    2. In the pop-up menu, enter a tag Key and Value.
    3. Select Add.
    4. Optional: Add more tags by repeating this process.
  7. In the Set-up push connector screen, in the URL parameter value field, select Copy to clipboard to copy the auto-generated URL parameter value to the clipboard.

    This URL is generated by the code that depends on the ServiceNow instance and connector type to receive events from the third-party connector. Pasting the URL in your third-party connector configuration creates a webhook that enables it to send events to the ServiceNow instance.

  8. Select Activate and then select OK in the pop-up message.
  9. In the Details tab, follow the displayed instructions for integration in your third-party console.
    The Details tab enables you to view the connector details, the URL link, and gives step-by-step instructions to integrate your third-party connector with Event Management.
  10. Optional: View related events to verify that the process was successfully completed and events are flowing into the system on the Related events tab.

    Each connector has its own related events table.

  11. Optional: Select Add automation to add business context to these alerts, group them, escalate to incidents and notify your team.
    The source and assignment group is auto-populated in the alert automation.

Result

The connector is saved and a notification is sent after the connector is active.
