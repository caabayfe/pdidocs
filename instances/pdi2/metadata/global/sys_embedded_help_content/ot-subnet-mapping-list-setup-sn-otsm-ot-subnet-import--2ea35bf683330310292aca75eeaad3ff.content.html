Import the OT subnet spreadsheet using simple import

Roles required: admin

You can import a spreadsheet containing subnet records. Importing subnets from network management platforms helps accelerate the mapping of OT devices to sites and equipment model entities.

  1. Right-click a column header.
  2. Select Import.
    Note: The Import external data into OT Subnet Mapping form opens.
  3. For Do you want to insert or update data?, select Insert.
  4. Check the box next to Do you want to create an Excel template to enter data?.
  5. Under Step 1: Create an Excel template file to enter data, select Create Excel Template.
  6. After the export is complete, select Download.
  7. Open the downloaded template and read the Directions tab.
  8. Paste your data into the Page 1 tab of the template.
    You must include the following required fields:
    Name
    Human-readable name of the imported zone or VLAN
    Subnet
    CIDR notion
    Site
    Entity name value from Industrial > Industrial Process Manager > Sites.
  9. Save the file to your computer.
  10. Navigate back to the Import external data into OT Subnet Mapping form.
  11. Under Step 2: Upload the template file, select Choose File and select the file you saved.
  12. Select Upload.
  13. Select Preview Imported Data.
  14. Scroll down and select Complete Import.
    A list of the imported records is displayed.
  15. Clear the filter to display all OT subnet records.
