Create a UI script

Create UI scripts to provide a way to package client-side JavaScript into a reusable form, similar to how script includes store server-side JavaScript. UI scripts run when called from client scripts and other client-side script objects and from HTML code. UI scripts aren’t supported for mobile.

  1. On the form, fill in the fields.
    API Name
    Enter a name for the UI script, including the scope and script name (for example, x_custom_app.HelloWorld).
    Script
    Create a client-side script to run when called from other scripts.

    With Now Assist for code generation enabled, you can provide text or code prompts to return AI-generated code suggestions and create scripts quickly.

  2. Select Submit.
