Create a self-attestation for a business service

Create a self-attestation for a business service so that you can certify its resilience status in Operational Resilience Workspace. You can use the attestation template that is provided with the base system to create a self-attestation.

Before you begin

Role required: sn_oper_res.manager

Procedure

  1. Navigate to All > Operational Resilience Workspace > All self attestations.
  2. Click New.
  3. Navigate to the Details tab in the Create New Self attestation form.
  4. In the Name and Description fields, enter the name and description for the self-attestation.
  5. In the Owner field, select the owner of the self-attestation.
  6. In the Attestation Template field, select the Operational Resilience Attestation Template option.

    The attestation template contains the pre-defined questions for the assessment.

  7. In the PDF Template field, select Default Self Attestation HTML Template.
  8. In the Signature field, click Attach image to attach the signature image for the self-attestation.
  9. In the Assignees panel, update the Owner field to select the owner of the self-attestation.
  10. In the Milestones panel, add the attestation due date, additional comments, and work notes (private).
  11. Click Save.
    You’ve created a self-attestation in the Draft state. The Details tab is updated with the self-attestation information and the Services tab is displayed for the self-attestation.
  12. Navigate to the Services tab.
    You can select one or more services that you want to certify the status for in the self-attestation.
    Note: You must add at least one service to proceed with the self-attestation.
    1. Click Add.
    2. In the Services form, select a service from the list and click Add.
      In the Services list, the selected service is displayed.
  13. Click Attest.
    You’ve created an assessment for a self-attestation in the Awaiting attestation state.
