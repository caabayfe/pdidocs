Create a context

Role required: sn_nb_action.next_best_action_author, admin

Use the Contact form to create a context for a table. A context includes rules and recommendations, which are stored in related lists.

  1. Provide a name and description for the context.
  2. In the Table field, select a table for the context.
    Note: You can create one context record per table.
  3. Click Save.
    After saving the context record, the system displays the Rules and Recommendations related lists.
  4. Use the Rules related list to view or create rules for this context.
    A rule is a set of conditions that applies to a context. A rule can only be created from the Rules related list on the Context form.
  5. Use the Recommendations related list to view the recommendations associated with the context rules.
    A recommendation is a way to suggest a helpful action to a user. To create a recommendation, open a rule record and create a recommendation from within the rule.
