Assign users to sites

Roles required: admin or cmdb_ot_isa_admin

When OT devices are in the CMDB, Site access can be configured to limit visibility of OT devices to users with both a cmdb_ot_viewer, editor or admin role and a cmdb_ot_isa_viewer or editor role. To assign sites to a user:

  1. Select a parent equipment model entity.
  2. Select the Site Users tab.
  3. Complete the form and select Submit.
