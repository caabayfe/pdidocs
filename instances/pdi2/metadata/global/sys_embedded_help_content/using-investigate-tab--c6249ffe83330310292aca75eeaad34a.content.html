View CI metrics on the Investigation tab

Use the various options on the Investigation tab to view the CI metrics information of the affected CI. This helps you to analyze and resolve the CI related issues.

Before you begin

Role required: itil, admin

Procedure

  1. Select the Investigation tab.
    The Investigation tab displays the metric information of the affected CI that is selected.
  2. View the metric information for the affected CI by selecting the following metric options.
    • Initial metrics: Metrics information of the affected CI that is retrieved from the time period that is from 30 minutes before to 30 minutes after the incident is created. The metrics information of the CI is displayed only if the CI is populated in the one hour time period. You can configure the sn_sow.initial_metric_fetch_window property to customize the one hour time period.
      Note: Initial Metrics is available only for the primary CI.
    • Recent metrics: Latest metrics information available for the affected CI.
      Note: By default, the Recent Metric option is selected.
  3. Refresh, retrieve, and display the latest metrics on demand by clicking the get latest metrics icon ().
    This option is available only when you’re viewing data in the Recent Metrics.
