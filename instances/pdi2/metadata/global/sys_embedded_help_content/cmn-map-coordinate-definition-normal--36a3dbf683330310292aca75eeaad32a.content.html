Create a Map Coordinate Definition

Set up a map data item before you accomplish this task.

Role required: admin.

Use this form to create a map coordinate definition. These are used to create map marker icons, which users click to differentiate data on a map page in the Classic Environment.

  1. On the form, fill in the fields.
    Name
    Choose a name for the map coordinate definition.
    Type
    Type of coordinate definition. Select Field to use the Classic Environment (lists and forms), or select Script to use a script instead
    Table
    Select the table for the condition, for example, incident [incident].
    Latitude field
    Latitude field to define map coordinates. SelectLocation, then Latitude.
    Longitude field
    Longitude field to define map coordinates. SelectLocation, then Longitude.
  2. Click Submit.

Continue building a map marker; see Related Links below for more information.
