Producer replication sets

Use Instance Data Replication to replicate data updates on one instance, called the producer instance, to one or more other instances, called the consumer instances.

The producer replication set specifies the tables and table columns to replicate to one or more consumer instances.

Name
The name of your producer replication set.

The consumer replication set must have the same name as the producer replication set, so the name should not be producer-specific.

Description
The description of your producer replication set.
