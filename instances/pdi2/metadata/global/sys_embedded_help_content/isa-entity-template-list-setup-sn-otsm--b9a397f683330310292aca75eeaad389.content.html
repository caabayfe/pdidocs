Equipment model templates

Roles required: admin

You can create a new equipment model template.

  1. Create a template
    1. Create a new Equipment Model Template record and submit it.
  2. Create template levels
    1. Open the equipment model template record that you want to add levels to.
    2. In the Template Level related list, select New.
    3. If the template level is not the top level, add the parent record.
    4. Use the Order column to define the hierarchy levels for sorting.
      The smallest number is the highest level.
  3. Create template level types
    1. Open the template level record that you want to define level types for.
    2. On the Template Level Type related list, select New.
    3. Create a Level type name and submit.
