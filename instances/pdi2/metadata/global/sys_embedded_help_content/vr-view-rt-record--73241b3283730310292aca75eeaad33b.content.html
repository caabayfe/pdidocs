Resolve records with a remediation task

Review the data to help you resolve vulnerabilities assigned to you.

Before you begin

Remediation tasks (VUL) are created and assigned automatically to IT groups from remediation efforts based on the group that is associated with its records.

Procedure

  1. Click a remediation task (VUL) to open it.
  2. To review more vulnerability information, click a related item link.
    Overview
    View a list of the records associated with this remediation task and other information such as Risk rating, state, remediation progress, etc.
    Details
    View details of the remediation task and update state, assignment group, remediation owner, short description and description if necessary. You can also post comments and work notes.
    Change Requests
    View any existing change requests for this remediation task.
    Note: This tab doesn't appears for the remediation tasks containing application vulnerable items (AVIs).
    Solutions
    View the preferred and potential solutions that you can use to fix this vulnerability. Open a record to see details such as associated Common Vulnerabilities and Exposures (CVEs) and links to solutions.
    Note: This tab appears only for the remediation tasks containing vulnerable items (VIs).
    More Actions menu
    At the upper right, next to the UI actions, click the see More Actions menu (three horizontal dots).
    Activity stream
    View the comments and work notes for this record.
  3. When you are ready, use the UI actions at the top-right to help you resolve the remediation task.

    When all the records in a remediation task are closed, the remediation task is closed.

    When a record is closed that is associated with multiple remediation tasks, the closed state rolls up to any remediation tasks that have that record.
