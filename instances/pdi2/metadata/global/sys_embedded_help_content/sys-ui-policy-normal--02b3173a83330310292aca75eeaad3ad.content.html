Create a UI policy

Create a UI policy to change the behavior of information on a form and control custom process flows for tasks dynamically. You can add as many actions to take when the policy is triggered as necessary.

  1. On the form, fill in the fields.
    Table
    Select the table of the form to be modified.
    When to Apply
    Define the conditions that, if fulfilled, cause the UI policy to be applied using the available options and condition builder.
    Script
    Select the Run scripts option to use create scripts for both true and false conditions.

    In the Execute if true field, create a script that executes when the conditions of the UI policy are fulfilled. In the Execute if false field, create a script that executes when the conditions of the UI policy aren’t fulfilled and the Reverse if false option is selected.

    With Now Assist for code generation enabled, you can provide text or code prompts to return AI-generated code suggestions and create scripts quickly.

  2. Select Submit.
