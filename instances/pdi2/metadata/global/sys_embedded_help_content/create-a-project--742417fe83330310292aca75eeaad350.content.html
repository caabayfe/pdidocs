Create a Project from Project Workspace

Create a project in Project Workspace and assign tasks under your project.

Before you begin

Role required: it_project_manager

Procedure

  1. Navigate to Workspaces > Project Workspace.
  2. Select the New Project.
  3. On the form, fill in the fields.
  4. Select Confirm.
    For more information on how to create a project, see Create a project from Project Workspace.
