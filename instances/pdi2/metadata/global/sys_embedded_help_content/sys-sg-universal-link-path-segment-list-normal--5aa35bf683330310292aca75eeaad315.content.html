Universal link path segment list

This list details all path segments available for your instance. Path segments are combined with universal link supported URLs, to create universal linking to display a mobile banner. Users see this banner when they land on specific platform web pages.

Title for the universal link path segment.

The system evaluates the regular expression string and then performs the matching process on the supported URLs.
