Configure Contract Management Pro

Install and configure Contract Management Pro to effectively manage contract life cycle for your organization.

Use the following steps to configure Contract Management Pro:
  1. Install Contract Management Pro.
  2. Configure the Microsoft Word add-in for ServiceNow Contracts.
  3. Configure external applications for Contract Management Pro.
  4. Set up Contracts Core.
  5. Set up record producers for legal contracts.
  6. Configure Now Assist in Contract Management.
