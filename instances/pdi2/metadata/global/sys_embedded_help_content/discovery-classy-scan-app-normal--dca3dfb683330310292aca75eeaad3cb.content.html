IP address application classification scanning

Classification is available for the IP Addresses Discovery type and returns information about applications running on CIs (Scan Application) Discovery uses IP address scanning to identify software based on the open ports and banners it finds without the use of credentials. Discovery uses the classification criteria defined in the Scan Results Application Classifier form to generate a report of the applications that match the criteria.
Note: IP address classification attempts to classify applications when no credentials are available. However, Discovery will use credentials when they are available, even when IP address classification is configured.
