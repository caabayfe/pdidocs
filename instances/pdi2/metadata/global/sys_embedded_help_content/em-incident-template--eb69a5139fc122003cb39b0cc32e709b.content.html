Configure Task Templates

Configure Task Templates to associate with alert rules for automatic task creation.

  1. Fill in the fields, as appropriate.
    Table 1. Task Template form
    FieldDescription
    NameThe template name.
    TableThe table for the task type. For example, Change Request.
    ActiveA check box to enable use of this template in alert rules.
    UserThe email address of the user to notify when the task is created.
    GroupThe group alias of recipients to notify when the task is created.
    GlobalA check box to notify all members of a corporation when the task is created.
    Short DescriptionThe subject line to appear in the email notification.
    TemplateThe fields and corresponding values to add to the task.
  2. Right-click the form title and click Save.
  3. To schedule when and how often the template generates a task until the alert or alert group is resolved:
    1. Click Schedule.
    2. Add the schedule conditions, and then click Submit.
      Table 2. Scheduled Entity Generation form
      FieldDescription
      NameThe schedule name.
      ActiveA check box to activate this schedule for generating tasks.
      RunThe interval for generating a task until the alert or alert group is resolved:
      • Daily: Every day at the specified Hour, Minute,and Second until the alert or alert group is resolved.
      • Weekly: Every week on the specified Day, Hour, Minute, and Second until the alert or alert group is resolved.
      • Monthly: A day of each month on the specified Day, Hour, Minute, and Second until the alert or alert group is resolved.
      • Periodically: The Repeat Interval with Days, Hours, Minutes, and Seconds with a Starting date.
      • Once: Generate a single task on the specified Day, Hour, Minute, and Second.
      • On Demand: Generate a single task only when a user clicks Create Incident on the alert form.
      ConditionalThe set of conditions in which to apply this schedule.
      Generate ThisThe task template that can use this schedule for generating tasks.
  4. Click Submit.
