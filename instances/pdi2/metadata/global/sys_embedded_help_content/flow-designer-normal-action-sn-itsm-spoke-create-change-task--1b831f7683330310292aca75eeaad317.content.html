Create Change Task on Change Request action

Creates a change task from a change request.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Change Request
Data type: Record

Reference to the change request to attach a change task.

Assignment Group
Data type: Record

Reference to the group to assign the change task.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

Change Task Record
Data type: Record

Reference to the change task created.
