Create an adhoc assessment

Assess the quality of an agent's completed task using an adhoc assessment.

Before you begin

Role required: sn_coaching.coach

About this task

You can create an assessment from an interaction or any task type. When you manually create an assessment, you can add a survey to it.

Procedure

  1. On the form, fill in the fields to assess the agent.
  2. Select Save.
