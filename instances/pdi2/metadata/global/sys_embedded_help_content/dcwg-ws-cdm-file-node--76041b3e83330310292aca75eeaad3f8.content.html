File nodes

Add and manage files using file nodes in the config data model of a CDM app or in a component library.

When you attach a file to an applicable node, a file node is created under that node. The file node contains a link to the attached file. For example, a properties file or a logo image file.

In an app, you can add a file node to a node under the component, collection, or deployable, but not directly at the respective folder level. In a shared library, you can add a file node to a node under a shared component.

In the config data tree, select the more actions icon () next to a node to which you want to add a file node, and then select Add file from the menu.

The file node appears in the config data tree. Select it to see its metadata in the File information pane and preview its contents in the File content pane. Preview is available for selected file types.

App developers and members of app authoring groups can access the file nodes and download the attached files. They can manually validate the content of the file and then publish the snapshot.

DevOps users can export the validated config data, including file nodes with URLs to the attached files.
