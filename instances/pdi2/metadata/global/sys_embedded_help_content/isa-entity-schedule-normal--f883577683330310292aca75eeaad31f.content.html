Schedules

This task requires admin role.

Create a new schedule

  1. Click new button on right top corner
  2. Enter schedule name in the “name” input box. As a practice prefix schedule name with short code for the site it is meant for​
  3. Pick a suitable time zone​
  4. Enter description in the “description” input box​
  5. Click “Submit” button

Create a new schedule entry

  1. Open the recently created schedule record
  2. Click “new” on the “Schedule Entries” tab​
  3. Enter suitable name in the ”name” input box​
  4. Select start date-time and end date-time in the “When” input boxes​
  5. Select repetition unit in the “Repeats” dropdown​
  6. Select repeat frequency in the “repeat every” input box​
  7. Select granular repetition unit as appropriate in the either of “repeats on” or “monthly type” or “yearly type” input box​
  8. Select repetition end date in the “Repeat Until” input box​
  9. Click the “Submit” button
