Create entitlement consumption rule

After you have created a consumption rule, link that consumption rule to one or more entitlements.

Before you begin

Role required: sam_user

Procedure

  1. On the Create New Entitlement Consumption Rule page, fill in the fields.
  2. Select Save,
    The consumption rule appears in the Entitlement Consumption Rules related list.
