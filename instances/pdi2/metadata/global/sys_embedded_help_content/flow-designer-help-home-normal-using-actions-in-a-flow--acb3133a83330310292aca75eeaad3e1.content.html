Using actions in a flow

Use actions to automate your work on the ServiceNow AI Platform.

Actions are individual operations of an automated flow. Each time you add an action to a flow, you must set its inputs so that it has data to work with.

  1. On the Workflow Studio homepage, select New > Flow.
  2. On the Flow properties screen, give your flow a name.
    All other fields are optional. So, when you're ready to start building your flow, click Submit.
  3. In your flow, under Trigger, select Select to add a Trigger.
  4. Search for and select any trigger to add to your flow.
  5. Fill in any required fields for your trigger, and click Done.
  6. Under Actions, select Select to add an Action, Flow Logic, or Subflow.
  7. From the list of options, select Action to open the action picker.
  8. In the action picker's search window, enter the name of the action that you want to add to your flow.
    Alternatively, you can browse for actions by spoke or application scope. Select a spoke name and then locate the associated action that you want to add to your flow.
  9. Under your action's name, set the values for your action's inputs.
    Inputs support static and dynamic values. A static value is one that you directly enter. An input with a static value always uses the value you enter. A dynamic value is a reference to a data pill. An input with a dynamic value gets generated each time the action runs.
  10. When you're done setting the values for all of your action's inputs, click Done.
  11. Keep adding actions to your flow from the action picker.
    Action outputs appear as data pills in the Data panel. You can use the data pill output from one action as an input for another action. To add a data pill to an input, select it from the data pill picker icon, or drag it from the Data panel.
  12. If necessary, rearrange the actions in your flow.
    You can rearrange actions in your flow by dragging and dropping them into the order you want.

You're ready to test your flow for any errors.
