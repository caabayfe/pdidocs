Perform root cause analysis

The application includes the Five whys technique of root cause analysis (RCA). You can add as many root cause analyses as you need.

Before you begin

Role required: sn_ohs_im.manager or sn_ohs_im.agent

Procedure

  1. In the Problem field, enter the problem statement.
  2. To identify the precise one underlying reason, ask why to each of the subsequent responses and enter in Why? fields.
  3. In the Root cause field, enter the answer to the last Why.
  4. Optional: If necessary, add more root cause analysis for this incident.

What to do next

Add an action based on your root cause analysis.
