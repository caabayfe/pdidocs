Discovery Quick Start

Use Discovery Quick Start tasks to discover subnets in your environment and then to identify the configuration items (CI) in those subnets. You must have a valid MID Server in the up state to run Discovery.
  1. In the Select MID Servers tab, select qualified MID Servers for subnet discovery.
  2. Select Automatically include new MID Servers to use all new MID Servers that meet the setup criteria.
  3. In the Add Credentials tab, add credentials for the routers you are going to discover.
  4. Click Test Router Access to verify that Discovery can use your credentials to access routers.
  5. In the Create Schedule tab, create a Subnet Discovery Schedule.
  6. Complete the Subnet Discovery Schedule by selecting either Finish or Finish and Run.

    • Finish and Run: Runs Discovery immediately, using the current configuration. All subsequent cloud discoveries run at the time scheduled.

    • Finish: Exits the wizard and runs Cloud Discovery at the time scheduled.

    After subnet discovery is complete, the Quick Start wizard reports the results for review. Click the tiles in Subnet Discovery Results for details about each.
Click the Create Discovery Schedules button to find configuration items (CI) in the discovered subnets.
