Create custom lists

Create and access your custom lists from the My Lists tab.

Before you begin

Role required: asset

Procedure

  1. In the My Lists tab, select Add new list.
  2. In the New List window, do any of the following:
    • To create a list from the existing lists, select Start from existing and do the following:
      1. Select a list from the available Inventory, Procurement, Hardware asset normalization, or Contract Renewal Lists.
      2. In the List Name field, enter a name for the list.

        By default, the List Name is automatically populated with the name of the selected list followed by the word Copy.

      3. Select the columns that you want to display in your list.

        All the columns of the selected list are added by default.

        Note: You can apply an existing filter to your list or create a filter for your list. You can also sort your list based on the columns.
      4. Select Create.
    • To create your own list, select Create your own and do the following:
      1. In the List Name field, enter a name for your list.
      2. Select the source table from the Select Source list.
      3. Select the columns that you want to display in your list.

        All the columns of the selected list are added by default.

        Note: You can apply an existing filter to your list or create a filter for your list. You can also sort your list based on the columns.
      4. Select Create.

Result

The list that you created is displayed under the My Lists tab.
