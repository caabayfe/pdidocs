Add KPIs to a KPI group and initiate mining

Add KPIs and create process projects for each KPI group for which you want to mine the data.

Role required: sn_process_optimization_analyst

Associate the KPI groups with your vendors, set thresholds to monitor indicator status, and initiate process mining.

  1. Add KPIs to the KPI group.
    1. In the KPI tab, select New.
    2. On the form, fill in the fields.
      KPI group

      The group to which you want to associate the indicator.

      KPI

      Business-friendly name for the indicator. This name displays in the Vendor Score Metrics widget in Vendor Manager Workspace.

    3. Click Submit.
  2. Set KPI thresholds for a KPI group.
    1. In the KPI Group Thresholds tab, select New.
    2. Add the upper and lower thresholds for the KPI group.
    3. Click Submit.
  3. Add vendors to the KPI group.
    1. In the Vendors tab, select Edit.
    2. Move the desired vendors from the Collection to the Vendors list.
    3. Click Save.
  4. Initiate process mining.
    1. Select a KPI group.
    2. Select Initiate Process Mining.
