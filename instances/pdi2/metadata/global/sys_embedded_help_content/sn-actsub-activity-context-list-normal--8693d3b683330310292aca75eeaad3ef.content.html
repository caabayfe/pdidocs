Activity Contexts list

This list shows details on the activity contexts available for your instance. These context items define the types of activities collected as Self-Service Analytics data for user entities such as consumers and customer contacts.

Name
Unique identifier for the activity context.
Context table
Table which includes the user entity whose actions need to be tracked and displayed on the Self-Service Analytics dashboard.
Active
Binary value denoting whether the context is currently in use.
Module
Module associated with the application which stores the activities data.
Domain
Domain in which the active records exist.
