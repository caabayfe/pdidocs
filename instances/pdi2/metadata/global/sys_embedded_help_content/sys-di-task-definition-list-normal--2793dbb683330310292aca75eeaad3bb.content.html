Use cases

DocIntel use cases enable you to define the type of documents you want to extract data from or apply categories to.

The Use Cases list shows the use cases in your instance.
  • Select (or right-click) the column headers to sort, filter, and edit the list.
  • Select the Personalize list icon to choose the columns in your list.
  • Select a use case to view and edit the use case details.

The Use Cases list includes the following significant columns:

Display Name
Name of the use case
Target Table
Database table used to store the document processing results for this use case
Autofill
Indicates whether tasks for this use case are processed using auto-filled fields in Auto-fill mode
Enable Straight Through Processing
Indicates whether tasks for this use case are automatically completed using auto-filled fields in Fully automated mode

For an improved DocIntel setup, configuration, and monitoring experience, install the Document Intelligence Admin application.
