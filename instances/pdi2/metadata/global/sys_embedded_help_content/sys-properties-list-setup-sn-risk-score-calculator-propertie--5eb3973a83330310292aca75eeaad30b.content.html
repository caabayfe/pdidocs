Risk Score Calculator properties for Operational Technology Obsolescence Management

Role required: sn_risk_score_calculator.admin

Configure the following properties required for Risk Score Calculator:

  1. Select the property.
    sn_risk_score_calc.score_calculation_job_execution_time_ms

    This is the maximum execution time in milliseconds required to perform a score calculation job.

    The score calculator job runs continuously for maximum execution time and breaks for 5 seconds. The default max execution time is 10 minutes (600000 ms).

    sn_risk_score_calc.score_calculation_batch_size

    This is the batch size (number of records) required to perform a score calculation job. Score calculator job runs in batches according to the batch size mentioned in this property. The default is 1000.

  2. Change the value according to your requirement.
  3. Select Update.
