Create a widget Angular Provider

Create an Angular Provider to reuse components injected into multiple widgets.

  1. On the form, enter a name for the Angular Provider and then fill in the following fields.
    Type
    The type of Angular Provider: Directive, Factory, or Service.
    Client Script
    A client script to reuse with multiple widgets.
  2. Select Submit.

Add the Angular Provider to the Angular Providers related list for each widget and update the client scripts in your widgets to inject the Angular Provider into the widget.
