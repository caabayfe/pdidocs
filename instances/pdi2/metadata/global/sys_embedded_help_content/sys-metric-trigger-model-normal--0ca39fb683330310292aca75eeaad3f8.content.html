Create a model trigger

Create a model trigger that executes when the time-series data deviates from expected values.

  1. On the form, fill in the fields.
    Model
    Trained model this trigger uses.
    Spike direction
    Trigger execution criteria. Trigger only on anomalies that occur above predicted values, below predicted values, or both.
  2. Click Save.

In the MetricBase Model Trigger Levels table, add values that specify trigger parameters.
