View service health

Monitor the health of services and customize the information that appears on the dashboard.

Before you begin

Role required: evt_mgmt_operator

Procedure

  1. Optional: Make the tile size larger or smaller.
    1. Select the Display settings icon () on the right side of the page.
      The Display settings pop-up window appears.
    2. In the Service dashboard view section, select the relevant tile size.
    • Auto: (Default) Adjusts automatically to the size of your screen, based on the screen size and resolution.
    • Small
    • Large: Displays the name of the service
  2. Group services by selected criteria.
    1. Click the arrow next to the Group By indicator and select the criteria by which to group services.
      The available options are:
      • No Grouping
      • Severity
      • Business criticality
      • Location
      • Service group. Selecting this option opens the Service Tree dialog box, where you can select a service group to filter the display on the dashboard. The currently selected group displays above the service tiles in breadcrumb format.
      Each group is preceded by a header with a number indicating the number of services in the group. In the figure, the severity groups are Critical, Major, and Warning.
    2. Optional: Sort the criteria in Ascending or Descending order by selecting the arrow next to the Group order filter.
      For criteria unique to Event Management such as Severity or Business criticality, the Sort Group by filter sorts in ascending or descending order by severity or business criticality level.

      For criteria outside Event Management such as location, the Sort Group by filter sorts in ascending or descending alphabetical order (A-Z or Z-A).

  3. Sort grouped services by selected criteria by clicking the arrow next to the Segment each group by filter.
    The available options are:
    • Severity
    • Business criticality
    • Cost
  4. Filter the information displayed on the dashboard by either setting a global filter or excluding severities from the display.
    • To set a global filter, select the Filter icon () and set the global filter condition.
    • To exclude a severity from the display, click it in the Severity Breakdown ribbon at the top of the page.
      • An indicator appears above the tiles with the severities currently appearing on the dashboard.
      • Severities filtered out of the dashboard display appear dimmed. To return a dimmed excluded severity to the display, select it.
  5. Optional: Cancel your display modifications and return the dashboard display to its default view.
    1. Select the Display settings icon ().
      The Display settings pop-up window appears.
    2. In the User settings section, click Reset settings.
