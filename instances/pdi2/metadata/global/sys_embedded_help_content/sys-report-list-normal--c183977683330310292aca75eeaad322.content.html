Report administration

The Reports list shows all the reports in your instance. Click a report title to view the properties of the report, filter the report, and to edit the roles the report is available to.

Click the column headers to search, sort, filter, and edit data.

The Reports list has the following important columns:

Edit
Navigates to the report where the user can edit and configure.
Published
Shows a check mark if a report is published.
Scheduled
Indicates if the report is scheduled to run in the future.
You can filter the Reports list with the following tabs:
  • My reports lists reports you created.
  • Global indicates that the report is visible to all users.
  • Group indicates that the report is visible only to you and with the groups that you are a member of.
  • All lists all reports that you have access to (Global, Group, and My reports)

Click the report title to view the report configuration.
