Create a Discovery schedule

You can use a Discovery schedule to launch probes, sensors, and pattern operations for a range of IP addresses, at any time of day, and on a specific interval.
  1. Complete the Discovery Schedule form.
  2. Right-click in the record's header and select Save from the context menu.
  3. To create a range of IP addresses to discover, click Quick Ranges under Related Links .
  4. Enter the IP ranges and specific IP addresses to scan.
  5. Click Make Ranges .
    The instance automatically displays the entries in the proper format.
  6. To make any changes to IP address ranges, select the IP address records in the Discovery Range Sets related list.
