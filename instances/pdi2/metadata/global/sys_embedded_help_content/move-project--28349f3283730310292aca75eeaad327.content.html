Grouping multiple Move requests in a Move project

Logically group Move requests that match conditions through a Move project.

Using a Move project, you can group multiple Move requests into a single project so you can more easily oversee and manage them. Specify conditions to filter Move requests and group them under the project. You can set conditions to group workplace Move requests, for example, based on their workplace location, building, space type, assignment group, department, and so on.

The default Move scheduler view enables you to work on requests in an interactive Calendar view in which the start and end dates are set based on the minimum expected start date and the maximum due date from all Move requests associated with the project. You can switch from the Schedule view to a List view using the calendar icon.

Use Move projects to do the following:
  • Identify the user who raised the Move request.
  • View and change the current state of a Move request.
  • Change the expected start and due date by when the request must be fulfilled.
  • Check the number of Move requests to be fulfilled per day.
  • Reschedule a Move request by dragging the request bar.
You can create a Move project from any of the following locations:
  • In the Move management workspace, select Create project.
  • Select the My active projects tile, and select Create in the list view.
  • In the All move projects section, select View all. In the list view, select Create.
