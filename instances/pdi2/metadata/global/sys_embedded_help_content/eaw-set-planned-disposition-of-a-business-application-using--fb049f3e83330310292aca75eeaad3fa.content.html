Set the planned disposition of a business application using list view

Set the planned disposition of a business application to track future decisions on the application.

Before you begin

Role required: sn_apm.apm_analyst

Procedure

  1. Select List.
  2. Select the row context menu icon () next to the business application that you want to set the planned disposition status for and select Set planned disposition.
  3. In the Set planned disposition window, do the following:
    • Select the planned disposition status from the Planned disposition drop-down list.
    • Enter the justification for selecting that planned disposition status in the Reasoning field.
  4. Select Update.
