Catalog items

Create OT catalog items to provide standardized, preconfigured products and services that can be delivered and fulfilled efficiently and seamlessly. Each catalog item represents an OT product or an OT service available for users to request; ordering a catalog item creates a request that then follows a fulfillment process. A fulfillment process defines the steps to request approval, assign fulfillment tasks, and fulfill requests.
Note: A catalog item can exist in multiple categories.
