Review Knowledge Management properties

As an administrator, you can configure the look and functionality of many knowledge base features with Knowledge Management properties.

List of roles (comma separated) that can flag incomplete/inaccurate articles (glide.knowman.show_flag.roles)
Enter role names exactly as they appear in User Administration > Roles. If both the Show article rating section and Show "Flag Article" option properties are selected, users with the roles listed here see the flag article option in article view.

All roles listed here must also be listed in the List of roles that can see an article's rating section property.
