Create an IP network

An IP network includes the range of available IP addresses in that network, including the network address (the lowest address in the range) and the broadcast address (the highest address in the range). If your IP Networks are created through network Discovery, the fields in this form are populated automatically. If you enter the IP Networks manually, you must provide the information required.

To convert the IP networks that were found to range sets for use in discovering other devices:

  1. Open the list of IP networks.
  2. In Related Links, click Create Range Sets.
    The Discovery status record appears, displaying the progress of the conversion. The system increments the Started and Completed count of IP networks, until all the networks are converted.
