Add work shifts and agents to the schedule plan

Include your team's work shifts and agents to the schedule plan.

Before you begin

Role required: admin

Procedure

  1. Click the schedule plan to add a work shift.
  2. Click the Work Shifts tab.
    1. In the Shift field, select the work shift that you want to assign for the schedule plan.
    2. Click Save.
    Note: The Total coverage/demand row displays the number of agents covering each shift in a day. The day view displays the demand for the number of agents forecast for every hour in a day. For example, 4/5 shows that you have four agents scheduled for an hourly time slot, 11 AM to 12 PM and the agent demand forecast for that hour is 5.
  3. Add agents to the work shift.
    1. Click the Agents tab.
    2. Click Add Agents.
    3. In the Agents field, search for agents and add one or more agents to add to the shift.
    4. Click Add.
    5. Click Save.
