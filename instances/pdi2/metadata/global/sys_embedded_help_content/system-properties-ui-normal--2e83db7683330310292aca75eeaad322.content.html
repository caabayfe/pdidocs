Service catalog properties

You can control the behavior of your Service Catalog using the properties that are made available to you.

The Catalog Variables > Variable Default Size submodule lets you configure the default width size for variables in all catalog forms. The options include:

  • 25%: Configures the variable to occupy 25% of the available screen size.
  • 50%: Configures the variable to occupy 50% of the available screen size.
  • 75%: Configures the variable to occupy 75% of the available screen size.
  • 100%: Configures the variable to occupy 100% of the available screen size.

You can override the default width of a variable. To do so, customize the width size of a variable under Type Specifications in the Variable form.
