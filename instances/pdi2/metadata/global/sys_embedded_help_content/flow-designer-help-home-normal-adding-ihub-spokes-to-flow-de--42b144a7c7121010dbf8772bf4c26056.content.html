Adding IntegrationHub spokes to Flow Designer

Request a subscription to IntegrationHub, or install the spokes you need from the ServiceNow Store.

Requesting an IntegrationHub subscription provides you with a package of multiple spokes. You can also install specific spokes from the ServiceNow Store.

  1. To purchase an IntegrationHub subscription with a package of spokes, contact your ServiceNow account manager.
    The account manager can arrange to have the appropriate plugin activated on your organization's production and non-production instances, generally within a few days. If you don't have an account manager, decide to delay activation after purchase, or want to evaluate the product on a non-production instance without charge, follow these steps:
    1. In your non-production instance's filter navigator, navigate to System Applications > All Available Applications > All.
    2. On the All Applications page, select Request Plugin in the main header to open the plugin request form on HI.
    3. In HI, select Take me to the HI Service Portal Activate a Plugin Service Catalog.
    4. In the Activate Plugin request form, fill in these fields:
      Target Instance
      Enter the name of the instance where you want to activate the plugin.
      Plugin Name
      Enter the system name of the plugin you want to activate, such as com.sn.ms_teams.ah. You can double-check the plugin's system name by searching for the plugin you want in System Applications > All Available Applications > All. The plugin's system name is next to "id:"
      Specify the date and time you would like to enable the plugin
      Choose a data and time when you want to activate the plugin. The date and time must be at least two business days from the current time.
      Reason/Comments
      Optionally, enter any information you want to provide to the fulfilling ServiceNow personnel.
    5. When you're done entering this information, select Submit to submit your plugin activation request.
  2. Search for and install additional spokes from the ServiceNow Store.

Add the spoke's actions to your flow in the same way that you'd add any action to your flow.
