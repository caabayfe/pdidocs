Merge Attribute Values

Review attribute values of the master CI and the duplicate CIs. Optionally, select duplicate CIs attribute values to override master CI attribute values.
  1. For each attribute, choose to retain the master CI's value, or choose a value from a duplicate CI that the master CI will be set with.
    ColumnDescription
    AttributeAttribute for which there are different values.
    Main CI ValueAttribute value in the main CI.
    Other ValuesThe number of unique Attribute values within the duplicate CIs.

    To override the main CI attribute value with a duplicate CI value:

    1. Select the Other Values link.
    2. In the attribute dialog box, select Unique Values to display only unique attribute values, or All to display all attribute values including identical values.
    3. Select a value for the main CI Attribute to be set with.
      You can select Reset to Original to undo the selection of a different attribute value for the main CI.
    4. Select Select.
    Note: Attributes, such as system fields, discovery fields (discovery_source, last_discovered, first_discovered), and read-only fields (such as the asset field) don't appear in the list.
  2. Click Next.
