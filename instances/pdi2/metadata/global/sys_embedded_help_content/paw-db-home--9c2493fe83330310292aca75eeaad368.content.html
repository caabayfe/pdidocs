Editing dashboards

Edit a dashboard in the in-line editor.

To get the editing functions for a dashboard, select Edit. When you are finished editing, select 'Save then Exit editing mode.

The actions you can take in the in-line dashboard editor are:
  • Name or rename the dashboard.
  • Add, delete, duplicate, or rename a dashboard tab, or open the tab record.
  • Add, configure, delete, drag, or resize an element in a dashboard tab.
  • View the dashboard details.

Dashboard name

Generally, you name the dashboard before you start to edit it, as part of the dashboard creation dialog. To rename the dashboard, select the pencil icon next to the dashboard name.

After typing in the new name, press Enter/Return to save it.

Tabs

To add a tab, select + Add a tab next to the dashboard name, or the plus (+) sign at the end of the tabs. To name or rename a tab, select the Edit tab label pencil icon next to the tab name.

To delete or duplicate a tab, or open its record, open the More actions menu on the tab header.

Depending on your roles, you have the options to duplicate the tab, delete the tab, or open the tab record.

Elements

To add an element, select the tab in which you want the element and then select Add new element. If the dashboard has tabs and you do not select one, the element appears above the tabs. If you add a filter above the tabs, it applies to all tabs. A list opens from which you select the element.

To configure an element, select either the Configure icon or the Configure option from the context menu. The Configuration panel opens. This panel is different for every element. The use and configuration of each element is described in the help topic for that element.

You can also delete an element from the context menu. Deleting the element on a dashboard only removes it from the dashboard but does not remove it from your instance.

To drag an element, just click on the element body and drag. For accessibility, there is also a keyboard drag option. To resize an element, click on a corner or the center of a side and drag. You cannot drag an element to another tab.
