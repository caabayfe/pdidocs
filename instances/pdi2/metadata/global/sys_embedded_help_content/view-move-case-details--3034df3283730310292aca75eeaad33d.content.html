View move case details

View a move case's details for more information.

Before you begin

Role required: sn_wsd_move.manager

Procedure

  1. On the calendar, select the move request of which you want to view the case details.
    The move request details are displayed on the right in the Case details panel.
  2. To update the move request details, do the following:
    1. In the Case details panel, edit the fields that you want to change.
    2. Select Update.
  3. To view or update other case details such as the child cases, child tasks, approvers, case SLAs and more, select Open case details.
    The move request opens in a separate tab with various tabs.
    1. Edit the fields that you want change.
    2. Select Save.
