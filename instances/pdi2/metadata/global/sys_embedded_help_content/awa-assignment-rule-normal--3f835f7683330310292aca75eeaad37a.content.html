Configure agent assignment rules

Role required: admin or awa_admin

Set the criteria for assigning work items to agents. Choose the assignment rule that considers the agent with the most capacity or the agent who has gone the longest without work. Select the timeout period for rejecting work items and indicate whether agent skills are to be considered during assignment.

  1. On the form, fill in the fields.
    Auto-assign handling
    Specify if agents can automatically accept work items without selecting Accept or Reject.
    Rejection handling
    Specify how work items are rejected and handled. If auto-assign handling is activated, this tab is not available.
    Skill handling
    Enable skill-based work assignments.
    Shift handling
    Enable assigning work items to agents based on shifts. The Shift handling field is available only if the Advanced Work Assignment plugin (com.glide.awa) is activated and the Workforce Optimization for Customer Service plugin (com.snc.wfo.csm) or the Workforce Optimization for ITSM plugin (com.snc.wfo_itsm) plugin, or both, is activated. As a manager, you must have planned schedules for agents to assign them shifts.
  2. Select Submit or Update.
