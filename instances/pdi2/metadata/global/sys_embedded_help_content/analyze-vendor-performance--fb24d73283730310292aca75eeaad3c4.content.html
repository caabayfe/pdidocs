Analyze vendor performance for your KPI groups

Monitor vendor scores assigned to specific KPI groups and analyze metrics for each of your teams for a given time period.

Before you begin

Role required: sn_vlm.vendor_manager

Procedure

  1. Click the performance icon ().
  2. From the KPI groups menu, select the team for which you want to analyze vendor performance.
  3. Click the calendar icon (in the Start date or End date field and select the start and end date for which you want to analyze the data.
  4. Analyze the data.
    • The Weight represents the relative order of importance for each KPI that contributes towards the vendor score.
    • The vendor score shows threshold values for the KPI group and is highlighted with the color based on the defined threshold range.
