Service catalog items

Catalog items are the goods and services that users can order. You can specify variables for any catalog item. Variables let you specify user information needed to fulfill the order for this catalog item. For example, for a server, you may need to know how much additional memory the user needs. Catalog items are grouped into categories and subcategories so fulfillment can be assigned to appropriate teams.

To modify an existing catalog item select it from the list.

To create a new catalog item click New .
