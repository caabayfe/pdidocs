Now Assist admin plugin settings

The plugins section of the Now Assist admin settings panel displays all available Now Assist plugins. If you're just getting started, install plugins to unlock all Now Assist features and their skills.

This panel enables you to do these tasks:
  • Install Now Assist plugins by selecting the Get plugins button in a plugin card.
  • Select the Installed section to view plugins already installed on your instance.
  • View helpful resources and answers to common questions using the links on the right edge of the panel.
