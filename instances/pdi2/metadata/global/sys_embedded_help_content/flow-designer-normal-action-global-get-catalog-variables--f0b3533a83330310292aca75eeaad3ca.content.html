Get Catalog Variables action

Gets the catalog variables from a Requested Item [sc_req_item] record for use in your flow. Uses an existing Catalog Item [sc_cat_item] as a template to populate the list of available Service Catalog variables.

Inputs

Provide a value for each input that your flow needs. To add dynamic values, you can also drag and drop pills from the Data panel or select them from the pill picker.

Submitted Request
Data type: Record

Requested Item [sc_req_item] record whose Service Catalog variables you want to use in your flow.

Template Catalog Item
Data type: Record

Catalog Item [sc_cat_item] record whose variables you want to use in your flow.

Catalog Variables
Data type: Template Catalog Item

Based on the Catalog Item you select as your Template Catalog Item input, a list of available Catalog Item variables appears. Move the variables you want to use as outputs for this action to the Selected list.

Outputs

These outputs appear in the Data panel. You can use them as inputs elsewhere in your flow.

The outputs for this action vary depending on which variables you select for the Catalog Variables input. Each Catalog Item variable output appears in the Data panel as type String.
