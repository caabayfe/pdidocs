Configure Aggregation Score Weight definitions for OT Obsolesence Management

Role required: sn_risk_score_calc.admin role or sn_risk_score_calc.user role.

Preconfigured Aggregation Score Weight definitions are available by default. If you want to modify the existing Aggregation Score Weight definitions or add a new definition, perform the following steps:

  1. Select Aggregation score weight definitions related list.
  2. Modify the Aggregation Score Weight definition according to your requirement.
  3. Select Update.
  4. You can also create a weight definition:
    1. Select Aggregation score weight definitions related list.
    2. Select New.
    3. In the new form, you can provide the following details of the Aggregation Score Weight definition: Aggregation type, Weightage.
