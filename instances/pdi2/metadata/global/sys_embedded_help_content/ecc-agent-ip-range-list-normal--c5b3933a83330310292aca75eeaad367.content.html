MID Server IP ranges

Applications, such as Discovery and Orchestration, can specify an IP range or the specific IP address of a target. When the application looks for a MID Server to use during auto-selection, it chooses a MID Server whose IP range includes the application's range or specific IP address.

These applications use IP ranges:
  • Orchestration: Uses the IP address of the target machine (together with the capability) to select the correct MID Server for Orchestration activities.
  • Service Mapping: Uses the MID Server whose IP address range matches the IP in the discovery request.
  • Discovery: Can select an IP address range using the same criteria as Service Mapping. Discovery can also use a "quick IP range" that you specify in the Discovery schedule.
