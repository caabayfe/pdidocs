Create a universal link path segment

Role required: admin

Use this form to create a path segment. Path segments are combined with universal link supported URLs, creating universal linking to display a mobile banner. Users see this banner when they land on specific platform web pages.

  1. On the form, fill in the fields.
    Name

    Title for the universal link path segment.

    Path Segment Regex

    Regular expression of the string that defines the category path of the URL.

    The system evaluates the regular expression string and then performs the matching process on the supported URLs.

  2. Click Submit.

Create a universal link supported URL to match the path segment.
