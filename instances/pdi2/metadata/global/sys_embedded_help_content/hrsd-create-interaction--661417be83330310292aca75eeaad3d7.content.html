Create an interaction

Most interaction creation takes place in other applications as interactions are merely a method of controlling channels. However, if needed you can create an interaction from the Interaction application.

  1. Select the plus sign, and select Create interaction.
  2. Type a name in the search field to verify the user requesting the case and select the user.
  3. Select Next.
  4. Select an interaction from the Type list.
    You can also add a Short description and assign the interaction to an agent.
    1. Add a Short description of the interaction.
    2. Start typing an agent's name then select an agent from the Assigned to list.
  5. Select Create interaction.
