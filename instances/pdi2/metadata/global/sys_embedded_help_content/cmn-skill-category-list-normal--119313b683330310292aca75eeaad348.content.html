Define the skill taxonomy

Organize related skills into categories and subcategories so that you can manage skills and create reports quickly and efficiently. A skill category can contain parent and child categories that together create a category hierarchy. You can add skills to the lowest category in the hierarchy. You can build your skill taxonomy from scratch or use the sample data provided with your application.

  1. Select New.
  2. On the form, fill in the fields.
    Name
    Unique name for the category.
    Parent
    Parent category
  3. Right-click the form header and click Save.
  4. Click Submit.
