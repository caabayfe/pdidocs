Security Posture Control workspace landing page

The landing page in the Security Posture Control workspace displays data visualizations about your assets. Before you can view data, you must install and activate service graph connectors and then activate policies.

Overview

The Overview section on this page shows you the following data:
Assets
Breakdown of your on-premise and cloud assets.
Findings by criticality
Findings (test results) broken down by severity for the assets that match your polices.
Assets monitored by top 5 sources
Top five Service Graph Connectors reporting on assets.
Cloud accounts
Number of cloud accounts monitored by AWS and Azure.
Open vs closed findings
Comparison of records still in process or awaiting resolution and those that are resolved.

Key insights

The Key insights section provides you with data about the use cases that are provided with the application.

Endpoint protection installed
Total number of assets that have or do not have endpoint protection.
Managed device coverage
Number of managed assets compared to those that are unmanaged.
Vulnerability scan coverage
Total number of scanned assets compared to the number that are not scanned for known vulnerabilities by a third-party vulnerability scanner.
Assets with critical vulnerabilities
Number of assets out of the total number of assets that have critical vulnerabilities.
Vulnerable items by criticality
Total number of vulnerable items broken down by their severity. A known vulnerability that matches an asset in your CMDB results in a vulnerable item. You must have the Vulnerability Response application to view this data.
Top 3 policies by findings
The policies that return the most findings (matches) on your assets.

Key use case coverage

Key use cases included with the application provide you with status updates on how well you are performing with your configuration. Select Help improve on a card to view a list of service graph connectors and activated policies, and how you might improve your coverage.
