Event field mapping

You can configure event field mapping rules to map values from specific fields to values in other fields. Use event field mappings to provide more comprehensive information in an event alert by substituting values from the event field mapping rule into the event.

Event field mapping rules apply after event rule processing and prior to alert generation. The mapping values from the Event Mapping Pair [em_mapping_pair] table apply to fields in the alert. The original event fields and values remain unchanged.
To configure event field mapping, click New.
