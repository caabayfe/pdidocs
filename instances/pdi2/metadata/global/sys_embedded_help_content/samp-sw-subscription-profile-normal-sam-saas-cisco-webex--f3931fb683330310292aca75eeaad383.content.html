Creating a Cisco Webex integration profile

Create an integration profile to connect your Webex subscription to the ServiceNow AI Platform. View software usage information and optimize stale licenses.

Set up the integration

Important: Before you can create the integration profile, create a Webex Meetings OAuth integration application in Cisco DevNet and Webex Teams OAuth integration application in Cisco Webex for Developers.

Provide a name for the integration profile and choose a value for the Analyze user activity from field in the Calculate Activity Subflow form section. You can choose to start analyzing data from the current date or from up to 60 days in the past. Save the integration profile.

Update Connection and Credential information

In the Download Subscription Subflow, click the preview icon next to the Connection & Credential field and then click Open Record in the record preview. Click the Create New Connection & Credential related link. On the form, fill in these fields and leave all other fields as-is.
  • OAuth Client ID and OAuth Client Secret- Values you had saved while creating Webex Teams OAuth application.
In the Calculate Activity Subflow, click the preview icon next to the Connection & Credential field and then click Open Record in the record preview. Click the Create New Connection & Credential related link. On the form, fill in the fields.
  • Connection URL - Replace <subdomain> with Webex Meetings site domain configured for the organization.
  • Webex Admin User Name - User name or email address to log in to Webex.
  • OAuth Client ID and OAuth Client Secret- Values you had saved while creating Webex Meetings OAuth application.
After updating the connection and credential details, return to the integration profile.

Publish the integration profile

To start using the integration, click Publish.
