Create an application menu

You can create new application menus or edit existing ones to direct your users to the applications they need. Choose the roles that are required to access the application and specify the order it appears in the navigator.

  1. On the form, fill in the fields.
    Order
    Specifies the order menus are presented in the navigator. If the Order field is empty or if two application menus have the same order, they're sorted alphabetically.
    Roles
    Restrict access to the menu based on roles. If the Roles field is empty, the menu is available for all users.
  2. Click Submit.

After you have created an application menu, you can use the Modules related list to add or remove modules.
