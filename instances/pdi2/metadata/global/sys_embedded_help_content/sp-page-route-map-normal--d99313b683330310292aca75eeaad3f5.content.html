Redirect from one portal page to another

Redirect all references to a portal page, such links from widgets, to a different page to avoid manually replacing the hard-coded page ID.

  1. On the form, enter a short description of the page route map and then fill in the following fields.
    Service Portal(s)
    Portals that apply the redirect. If you don't select a portal, the redirect applies to all portals in the instance.
    Route from
    ID of the original page to redirect from.
    Route to
    ID of the new page to redirect to.
    Order
    A number that indicates in what order page route maps apply. If more than one active record has the same value in the Route from field, the record with the lowest order applies.
  2. Select Submit.
