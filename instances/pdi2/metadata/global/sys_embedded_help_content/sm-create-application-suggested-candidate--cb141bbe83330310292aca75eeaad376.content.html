Create an application service based on Automated Service Suggestions

Use the selected application service candidate to map a new application service in a few steps.

Before you begin

Role required: sm_admin

Procedure

  1. Select Create new service.
  2. Name the new application service.
    A name suggestion is provided. Use this name or select Other name suggestions for other options. For more information about application service name suggestions, see Name suggestions for application service candidates
  3. Write a description for the new application service.
  4. Begin typing to select service owner.
  5. Begin typing to select service group.
  6. Select Map service.
  7. To verify the creation of your new service, navigate to All > Service Mapping > Home > Services > Application services.
