DevOps applications

A DevOps application is the focus of the up-to-date data that tools send about plans, repositories, and pipelines. The result is traceability for user stories, commits, test results, and more. An application enables pipeline modeling, change governance, and metrics reporting.

Application Model vs Application Service

If you will be creating a new DevOps application from an existing application model or service, here’s more info about the differences between the two.

An application model is a type of model that can be managed and tracked within a scrum development process. It is the reference object to which your application's data will be tied.

An application service represents an instance of a business application or system in different types of development environments, like development, test, or production. It is the target environment to where your data will be deployed, and is consequently linked to a deployable in your application.

Application services typically link back to an application model, where the intended state of configuration data for an application is defined.
