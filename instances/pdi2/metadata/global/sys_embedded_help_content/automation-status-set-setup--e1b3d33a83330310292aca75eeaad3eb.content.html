View subnets and MID Server assignments

When you select MID Server for auto-assignment, the system launches a Discovery of the subnets in your environment. Discovery finds all subnets accessible to the MID Servers you have selected and displays results in the Automation Status Set form.
  1. Select the Subnets related list to view all the subnets that Discovery finds using the selected MID Servers.
  2. Select the MID Servers related list to view the MID Servers that were automatically assigned to those subnets.
