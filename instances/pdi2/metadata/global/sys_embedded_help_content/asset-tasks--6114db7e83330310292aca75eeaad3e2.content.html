Asset tasks

View the list of tasks related to assets. Search and select the record to view the details. You can also export the list or create an asset task.

You can view and create the following type of asset tasks:

  • Contract Renewal
  • Hardware Asset Reclamation
  • Asset RMA
  • Contract Asset
  • Loaner Asset

Select New to create an asset task. You can also select an asset task and then select Assign to me to assign an asset task to you.
