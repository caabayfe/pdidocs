Verify existing planning organization types

Gather details of organizational structure and the planning process of your company.

Role required: admin

Review the existing planning organization types in Alignment Planner Workspace and verify if they suit your company’s planning needs.

  1. In the list of system tables, review the tables that have Planning Organization in the Extends table column.
  2. After reviewing, you can mark this task as complete.
