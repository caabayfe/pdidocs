New CIM Query Tool Help 

1. Double click on a heading to put that query in the query box
2. Double click on an identifier to set it as the current object
3. Click the 'Response' or 'History' headers to change table sizes
4. Click on the light cyan labels to hide all result objects
5. Click on a the blush labels to collapse all result objects
6. Click on the lavender labels to collapse a single object
7. The query language is similar to the old CIM query (but less strict):
  a. A class name by itself will execute CIM's EnumerateInstances command for that CreationClassName
  b. A class followed by qualifiers in braces will execute GetInstance with those qualifiers
  c. Anything followed by a dot will will get associators of the object(s) returned by the first part of the query
  d. Associations can be nested
  e. A query that begins with a dot will use the current object
  f. If there's no _ in the class it's assumed to be a CIM method
  g. Filters are incuded in double braces
  h. GetProperty is _not_ supported.  You can only query for all properties of an object.
8. Some useful predefined queries are available
9. Examples:
  a. CIM_ManagedElement                   EnumerateInstances with CreationClassName CIM_ManagedElement
  b. CIM_ManagedElement{Name=Clar+01000}  GetInstance with Name "Clar+01000"
  c. CIM_ManagedElement.CIM_Dependency    Enumerate managed elements.  Get all associations of class CIM_Dependency for each
  d. EnumerateInstances{ClassName=CIM_ManagedElement}.Associators{AssocClass=CIM_Dependency}
                                          Wordier version of (c)
  e. .CIM_SystemDevice                    Get all CIM_SystemDevice associations of the current object
  f. CIM_RegisteredProfile{{RegisteredName='Array'}}
                                          Get all registered profiles but filter out profiles which don't have
                                          a RegisteredName of 'Array'
10. Errors will appear below any objects that were returned
11. Debug output will appear below errors.  (Don't get both JSON and XML at the same time.  A bug will cause the
    JSON to be displayed as "[object Object]".)
12. You can get both JSON and XML output by enabling the "CIM Query" debug option.  Output will be included
    in the 'Answer' box.
13. When CIM Query debugging is enabled you can edit the JSON of the request before it's made.  Be careful -
    your changes will be overwritten if you put the cursor in either the Current Object or Query edit controls.
