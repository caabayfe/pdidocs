Pre-setup Checklist

Here is information to collect in advance to ease into the setup process:

Event Properties

  • Handling impact calculation

  • Flapping detection

  • When to auto-close or re-open

  • Performance settings

Event Sources

  • Hostnames or IPs for event sources

  • Credentials for connectors to pull events

  • Email formats (if using email)

  • Any special SNMP trap port requirement

Rules

  • Ability to identify each source of events

  • Know what to keep and what to ignore

  • How to map incoming severities to ServiceNow severity

  • Understand how to bind nodes/services to the CMDB

Automation

  • What type of tasks to open (typically incident)

  • How alerts should be associated with Knowledge articles

  • Types of automated remediations to execute

  • Filters on alerts to vary above items
