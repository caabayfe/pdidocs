Ribbon settings

There are several settings you can configure for the ribbon that appears in the form header in Agent Workspace.
  1. Click New to add a new ribbon setting.
  2. For each ribbon setting, do the following:
    1. Type a name for the ribbon setting.
    2. Select the ribbon component. You can choose from:
      Depending on the component you select, additional options appear in the form.
    3. Select the table you want the ribbon to appear for. For example incident or sn_customerservice_case.
    4. Choose a width for the ribbon component.
      The width is based on a 12 column layout. When added together, the components cannot equal more than 12.
    5. Type the order you want the component to appear. The lowest numbered component appears on the left in the ribbon.
    6. Click Submit.
