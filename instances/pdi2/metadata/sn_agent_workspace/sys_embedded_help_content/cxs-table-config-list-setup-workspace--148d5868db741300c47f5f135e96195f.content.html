Agent Assist contextual search settings

Contextual search helps agents deflect or quickly resolve their issues without involving the service desk operators. Contextual search can also include results from other sources such as a service catalog, allowing an agent to directly order a catalog item from a search.

To define a contextual search, first define a search context to set parameters, then define how the results appear in a form.

For contextual search in Agent Workspace, you must select the Workspace UI type.

Select a predefined search context that defines which forms and record producers use that search.
