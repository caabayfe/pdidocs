Agent Workspace Roles

Access to Agent Workspace is set up for specific roles

Role

Description

workspace_admin

Provides Access to Agent Workspace Application and Modules to configure Agent Workspace in Production instances.

workspace_list_admin

Provides the ability to create list categories, and to create and assign filtered lists in Agent Workspace in Production instances. This is an elevated role.

agent_workspace_user

Provides access to Agent Workspace.

Update Sets

Working with Update Sets within Guided Setup

If you are a new customer, run Agent Workspace Guided Setup in your production instance and clone the production instance over sub-production instances after going live.

If you are an existing customer or if you want to run Agent Workspace Guided Setup in a sub-production instance, use our product documentation to learn more about using $[SP]Update Sets$[SP]and$[SP]Exporting Data.

To enable the update set and application scope pickers, click $[SP]$[SP] in the header and navigate to the Developer tab.
