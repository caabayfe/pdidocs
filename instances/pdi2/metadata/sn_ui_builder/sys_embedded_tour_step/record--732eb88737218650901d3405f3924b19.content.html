In any page or page variant row, hover over the area just to the right of any Settings link. A three-dot menu icon appears.

Select the three-dot icon for easy access to page or page variant options such as:
  • View settings
  • Create new variant
  • Delete page
  • Open editor
  • Duplicate variant
  • Delete variant
Do not select these options, instead, select the Next button to continue the guided tour.
