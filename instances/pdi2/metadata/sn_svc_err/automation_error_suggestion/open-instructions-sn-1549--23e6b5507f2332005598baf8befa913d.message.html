The payload has a lookup class name (the class of the items that are specified within lookup key in the payload), but the corresponding lookup rule is missing.

1. Navigate to CI Identifiers.

2. Select the identifier for the CI table from the error message.

3. Add an Identifier Entry and define the lookup rule by setting  the Search on table parameter to the required lookup class name.

4. Click Retry Discovery.

For more information, refer to documentation on Identification engine error messages.
