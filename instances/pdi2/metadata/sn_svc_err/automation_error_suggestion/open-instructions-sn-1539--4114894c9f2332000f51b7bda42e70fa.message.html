Failed to communicate with the Internal WMI Collector process on the MID Server.
It seems that the WMI Collector is bound to a specific address.


On the MID Server that caused the problem, create or modify the MID Server property "mid.servicewatch.wmi.host" to P address , to which this WMI collector is bound.

Troubleshoot the problem as described in KB0621673: Resolve the failure to communicate with the WMI Collector during top-down discovery.
