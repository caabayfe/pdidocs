This issue may arise due to one of the following conditions :

a. Duplicate dependent records exist with the same relationship to the same main Configuration Item (CI).

b. Duplicate records are present in the lookup table.

  • Refer to https://www.servicenow.com/docs/csh?topicname=de-duplication-tasks.html&version=latest to remediate these errors
  • Review the discovery pattern responsible for creating these duplicate records to prevent the issue from recurring. Use the Pattern Debugger to identify the root cause
  • If necessary, update the pattern accordingly, rerun the discovery process, and verify that no duplicates are generated
  • Use the IRE Payload Explorer tool under 'Diagnostics' → 'Support Tools' in the 'Discovery Admin Workspace' app to run an IRE simulation based on of the ECC records

c. Multiple relationships have been identified between items in the payload.

  • Review the discovery pattern to understand how these multiple relationships were created.
  • If required, modify the pattern accordingly and reinitiate the discovery process.

Use the Discovery Customization Report tool under 'Diagnostics' → 'Support Tools' in the 'Discovery Admin Workspace' app to identify any custom changes made to out-of-the-box discovery-related records. You can find the steps to enable debug logs for the IRE in KB0750382. For additional information about CMDB Identification and Reconciliation Engine (IRE) errors, refer to: https://www.servicenow.com/docs/csh?topicname=id-engine-error-messages.html&version=latest
