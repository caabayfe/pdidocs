There is no active data source for ServiceWatch or ServiceNow. It is required to have an active data source for ServiceWatch and ServiceNow for discovery to work correctly.

1. Check the list of data sources by navigating to System Definition > Choice Lists.

2. Filter the table by Element=discovery_source and Table=cmdb_ci.

3. Make sure that the desired data source exists in the list, and that its Inactive value is set to false.

4. Click Retry Discovery.

For more information, refer to documentation on Identification engine error messages.
