When the CMDB identification process detects duplicate Configuration Items (CIs), it groups each set of duplicates into a de-duplication task for review and remediation. For more details on how duplicate CIs are identified, see: https://www.servicenow.com/docs/csh?topicname=id-detect-dup-ci.html&version=latest

  • To resolve duplicate CIs, follow the steps outlined here: https://www.servicenow.com/docs/csh?topicname=de-duplication-tasks.html&version=latest
  • Review the discovery pattern responsible for creating these duplicate records to prevent the issue from recurring
  • If necessary, update the pattern accordingly, rerun the discovery process, and verify that no duplicates are generated

For additional information about CMDB Identification and Reconciliation Engine (IRE) errors, refer to: https://www.servicenow.com/docs/csh?topicname=id-engine-error-messages.html&version=latest

Use the Discovery Customization Report tool under 'Diagnostics' → 'Support Tools' in the 'Discovery Admin Workspace' app to identify any custom changes made to out-of-the-box discovery-related records and the IRE Payload Explorer tool to run an IRE simulation based on of the ECC record
