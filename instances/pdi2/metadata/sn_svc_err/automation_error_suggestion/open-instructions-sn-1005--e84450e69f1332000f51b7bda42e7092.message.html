No valid SSH credential can authenticate on the target.

Either an existing credential is incorrect, or the credential is missing.

To see more error details for each attempted credential, enable debug logs in MID [Add mid.log.level as DEBUG in Configuration Parameters under mid server record].

Remediation choices:

  • Click "Test credential" in existing SSH credentials records to verify access.
  • Add and validate SSH credentials.
Refer to this KB0657528 for more troubleshooting steps if the above remediations didn't work.
