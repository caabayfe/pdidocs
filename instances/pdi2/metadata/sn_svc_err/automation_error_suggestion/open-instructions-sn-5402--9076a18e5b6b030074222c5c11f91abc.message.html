The discovery has been canceled because it exceeds the number of concurrent active Discovery schedules as specified by the system property “glide.discovery.max_concurrent_invocations_per_schedule'.

Remediation choices:

  • Wait for the other invocations to finish.
  • Cancel the other invocations if they might not complete.
  • Increase the number of concurrent invocations per schedule in the system property if there is a good reason to have more.

Troubleshoot the problem as described in KB0623510: Max concurrent schedule invocation if the above remediations didn't work.
