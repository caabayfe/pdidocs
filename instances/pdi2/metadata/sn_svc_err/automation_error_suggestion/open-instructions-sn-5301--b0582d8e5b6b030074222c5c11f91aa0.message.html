This error typically indicates that a probe executed successfully, but there is no active sensor configured to handle its output. Probes gather raw data during Discovery, while sensors are responsible for interpreting that data and creating CI records. Without an appropriate sensor, the system cannot process the probe results.

Remediation Steps:

  • Ensure a sensor is active for the probe: Each active probe must have a corresponding active sensor. If the probe runs without an associated active sensor, this error will occur. Go to Discovery Definition → Sensors, find the sensor matching the probe mentioned in the error message, and ensure the "Active" checkbox is selected. If you're working with a new probe and no sensor exists, create one. Instructions on how to link sensors can be found here: KB0547844
  • If the probe is not intended to trigger a sensor, you can suppress the error by setting the probe parameter 'skip_sensor' to 'true'. Instructions on how to add this parameter are available here: KB0724976
