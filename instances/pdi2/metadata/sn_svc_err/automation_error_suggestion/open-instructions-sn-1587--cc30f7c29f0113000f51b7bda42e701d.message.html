A pattern with a connection section creating connections to storage has created a connection with file system that doesn't exist on the host.

Connection Section has created bad connections

Review the discovery the log, mainly the "Create Connections" step under the Connection Section creating connections to storage. If the values if "file_system" are not correct, fix the pattern.

Host discovery didn't discover all file systems

Review the form of the host which has the IP address of the error, mainly "File Systems" related list.

If the file system in the connection created by the pattern is not in the list, you can try the following:

  1. Run quick discovery on the ip of the host
  2. Look for errors during the discovery, and try to resolve them.
