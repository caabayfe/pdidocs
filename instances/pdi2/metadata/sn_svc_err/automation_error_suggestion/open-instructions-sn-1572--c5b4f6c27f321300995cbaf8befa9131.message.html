1. Navigate to Metadata Editor.

2. Find the containment rules for the relevant CI type.

3. Verify that there is a pattern which is associated with at least one of the contained items.

4. Do one of the following:

  • Delete the containment rule.
  • Set the pattern which is associated with the contained item to be inactive.
  • Change the pattern of the given CI type to create an inclusion connection.

5. Click Retry Discovery.
