Discovery cannot reach the target machine via SSH.

Remediation Steps :

 

  1. Confirm port accessibility from the MID Server
    • Access the MID Server host directly (via SSH or RDP).
    • Use tools like telnet to verify that the target IP and the desired port (port number 22 for SSH)can be reached from the MID Server host : telnet <target-ip> 22
    • Ensure firewalls between the MID Server and the target allow traffic on the required port
    • If the machine isn't reachable, try connecting to it from a different MID Server

 

  1. Verify credentials are correct
    • In ServiceNow, navigate to Discovery → Credentials, and select the relevant credential
    • Use the Test Credential button to validate access against the targeted IP and port 22
    • For detailed guidance on credential testing—covering common issues —see this KB article: KB0657528
