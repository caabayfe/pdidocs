No valid SNMP credential can authenticate the target.

Either an existing credential is incorrect, or the credential is missing or the target might take more time to respond.

To see more error details for each attempted credential, enable debug logs in MID [Add mid.log.level as DEBUG in Configuration Parameters under mid server record].

Remediation choices:

  • Verify that the target can be reached from the MID Server host via a tool like snmpwalk.
  • Increase the timeout [mid.snmp.request.timeout SNMP MID Server configuration parameter] if a credential is known to be correct and still no OIDs are returned.
  • Verify that the credentials are valid.
  • Use a different MID Server.

Refer to this KB0657528 for more troubleshooting steps if the above remediations didn't work.
