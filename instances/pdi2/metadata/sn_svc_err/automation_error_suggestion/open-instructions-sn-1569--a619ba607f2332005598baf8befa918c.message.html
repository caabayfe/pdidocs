The identification section of the discovery pattern failed to fill all required attributes necessary to apply the identification rules.

1. Navigate to CI Identifiers.

2. Find the CI Identifier for the table.

3. On the Identifier Entries tab, notice the Criterion attributes in the relevant Identifier Entry.

4. Review the discovery log of the CI to which the error applies.

5. Locate the Creating CI step in the discovery log.

6. Verify that the criterion attributes for this CI exist. If not, adjust the identification rule or the pattern so that the criterion attributes in the rule are the same as the CI attributes in the pattern.

7. Click Retry Discovery.

For more information, refer to documentation on Identification engine error messages.
