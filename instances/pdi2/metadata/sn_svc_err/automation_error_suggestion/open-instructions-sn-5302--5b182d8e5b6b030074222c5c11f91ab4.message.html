There is a customization in either the probe or sensor.  Due to incompatibility concerns, the sensor was not executed.

  1. Go to the probe record and switch to the "Advanced" view to display the major and minor versions.
  2. Compare this with the version in the related list for "Sensors That React To This Probe". 
  3. Revert to the default version.
  4. Reapply the customization.

Troubleshoot the problem as described in KB0683387: Probe sensor major version mismatch.
